# Prototypes

Deze map bewaart de speelbare prototypes uit ontwerpfasen: één zelfstandig HTML-bestand per lab, dat nooit in de app wordt gebundeld en alleen als referentie bij het bijbehorende ontwerpdocument hoort.

`2026-08-27-b1c-interface-lab.html` is het Interface-lab van B1c: het zette vier bedieningen voor het verdelen van restcapaciteit naast elkaar zodat ze echt te proberen waren, en variant 4 (de fasestrook-handles) werd op 2026-08-27 het eigenaarsbesluit — zie `docs/superpowers/specs/2026-08-17-b1c-nivelleren-restcapaciteit-design.md` §6.

Openen doe je door het HTML-bestand gewoon in een browser te laden; er is geen build, server of afhankelijkheid voor nodig.
