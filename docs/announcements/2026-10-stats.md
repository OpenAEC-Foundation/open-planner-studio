# Open Planner Studio v2026.10.0: stats and key improvements

For whoever makes the social posts. Released 21 Oct 2026. Period measured: v2026.9.0 (1 Sep) → v2026.10.0 (21 Oct), 7 weeks. All numbers measured from git and GitHub on 23 Oct 2026. The "do not say" lines keep the posts correct.

## Key improvements

1. **Opens Primavera P6 files (.xer) directly.** Each project in its own tab; the original file is kept inside the saved IFC.
2. **Calculation profiles.** Calculate like P6, like MS Project, or with Open Planner Studio's own rules. Imported files first show the dates exactly as P6 or MS Project saved them.
3. **Seven new reports** (11 in total), including a DCMA 14-point schedule health check, plus a resource diagram.
4. **Progress through a spreadsheet.** Export a sheet (.xlsx or .csv), fill it in on site, read it back.
5. **Task types** (fixed duration, units or work) and **split tasks** in the Gantt.
6. **28 languages**, up from 14. The Help was rewritten into 78 articles.
7. **Large schedules are much faster** (see performance below).
8. **Feedback without a GitHub account**, straight from the app.

## Performance on a large P6 schedule

Measured 7 Oct 2026 on a real P6 schedule: 6,978 activities, 10,730 relationships, 52,640 resource assignments. Longest freeze of the app per action:

| Action | Before | After | |
|---|---|---|---|
| Select a task | 47 s | 0.2 s | ~250× faster |
| Edit a field | 105 s | 0.3 s | ~330× faster |
| Recalculate (F5) | 117 s | 2.7 s | ~43× faster |
| Scroll the table (40 steps) | 94 s | 4 s | ~24× faster |
| Open the file | 27 s | 10 s | ~3× faster |

Good wording: "Tested on a real P6 schedule with 6,978 activities: recalculating used to freeze the app for 2 minutes, now for under 3 seconds."

Do not say:
- "X× faster than the previous version". "Before" is a development build from early October; v2026.9.0 could not open .xer files at all.
- That every schedule is this much faster. On a 4,236-activity schedule the gain was about 10–40 %.

## Not in this version (save for the next one)

- Resource levelling up to 6.7× faster (10,000 tasks: 51 s → 7.7 s). Merged on 22 Oct, after v2026.10.0.

## Do not use

- The GitHub download counter (7,180): it includes the app's update checks. Real installer downloads: 2,850. Browser use is not counted.
- "Rust-based core": the scheduling engine is TypeScript.
- "Actual Dates" progress mode: not supported.
