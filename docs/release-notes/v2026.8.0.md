- Resource libraries: a new occupancy overview shows, per library item, how much of it is committed across all your open documents — as a table and as a histogram — so double-booking one crew or machine across projects becomes visible instead of implicit.
- Relations on milestones and summary tasks: dragging a relation from a milestone works again, relations that cannot have any effect are now marked in the relations panel, and opening a file reports how many it found instead of leaving them to do nothing unnoticed. Such relations are kept, not discarded — an imported file keeps everything it came with.
- New tasks inherit their task type from the parent task, both when you add them yourself and when the AI assistant creates them.
- The bundled examples now ship with resource sets, so the demo projects show resource planning and the occupancy overview with real data.
- Fixes: WBS numbering stays in sync when moving tasks, deleting several tasks at once is a single undo step, the saved theme is applied before the first paint, Resources opens in Project view, and baselines are included in the MS Project (MSPDI) export.
- Gantt: text scales correctly on the canvas, panning with the middle mouse button works, and tasks without dates no longer break the drawing.
