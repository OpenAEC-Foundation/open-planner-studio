- New OpenAEC icons and neutral themes make the ribbon, document tabs and baseline comparisons easier to read. Baselines can also be distinguished by line style and labels, including in monochrome reports.
- A progress-curve report shows planned and actual progress at the status date. After F5, a shift panel explains supported reasons for changed task dates, including calendar and resource constraints.
- Progress workbooks preserve the export snapshot so importing an XLSX can show conflicts with changes made since export. Rows that would overwrite protected current values are refused.
- Milestones can be dragged on the Gantt with calendar-aware placement and cancelled with Escape. Scheduling, night-shift boundaries and resource levelling have targeted correctness and performance improvements.
- XML and experimental XER exchange report supported losses more explicitly. Recent files retain granted access across restarts; macOS has native window controls and menus; Linux AppImages include input-method modules. Installers use the platform signing and verification pipeline.
- Update every workstation before sharing newly saved files with old app versions. Versions 2026.9.0 and older can lose calendar details; version 2026.9.0 can also turn tasks with times, hour durations or fractional days into zero-duration tasks (known issue 150).
