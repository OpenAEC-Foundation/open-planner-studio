- MS Project (.mpp) import is now date-faithful to the minute: across a 216-file test corpus, every file opens and recalculates to exactly the dates MS Project shows — no start, finish, or same-day deviations, no accepted exceptions — and a permanent regression gate keeps it that way.
- Split tasks, resource leveling delays, timephased (contoured) assignments and manually scheduled tasks are now real features: read from the file, scheduled like MS Project schedules them, and drawn as interrupted bars in the Gantt, print preview and PDF export.
- Nothing from your source file gets lost: raw hour distributions, task types and effort-driven flags survive saving, reopening, undo and crash recovery — even after you edit the task.
- When an edit releases an imported MS Project hour distribution, the app now tells you: a one-time notification and a marker in the task properties panel, each with a read-more link straight to the relevant guide page.
- Also new since v2026.8.0: a "dates as recorded" mode that shows a file exactly as its stored dates say, a clickable WBS jump button on every dependency row, an "active between" task filter, and an auto-save fix for fresh installs.
- All notifications and confirmations now happen inside the app — no more native dialogs (only the file open/save pickers stay native).
- Fixes: two calendars sharing a name could silently swap after save-and-reopen; a deadline constraint could push a milestone forward; editing the duration of a task with a frozen work distribution visibly did nothing.
