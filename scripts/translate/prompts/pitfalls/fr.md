# Known pitfalls: French (fr)

- **Space before ; : ! ? and inside « ».** As in the UI: "Remarque : …", « Calculer ». No space
  before a period or a comma.
- **Quotation marks.** « … » with a space inside, in the whole article; not "…" or “…”.
- **Past participle agreement.** With être it agrees with the subject: "la tâche est déplacée", "les
  jalons sont placés". With avoir only when the direct object comes first: "les tâches que vous avez
  ajoutées".
- **Singular below 2.** "0,5 jour", "1,5 jour", but "2 jours". Decimal comma; WBS codes such as 1.2
  keep the period.
- **Dates.** "lundi 7 juin 2027": lower case, no comma; the first of the month is "1er juin".
- **Cliquez sur.** "Cliquez sur *Enregistrer*", "Choisissez *Enregistrer*"; never "Cliquez
  *Enregistrer*".
- **Capitals in headings.** Only the first word: "Ajouter des relations", not "Ajouter des
  Relations". Task headings use the infinitive in every heading.
- **False friends.** "actuel" = current (actual start is "début réel", see `terms`); "éventuellement"
  = possibly, not eventually (→ "finalement"); "librairie" = bookshop (→ "bibliothèque"); "supporter"
  = to bear (→ "prendre en charge"); "compléter" = to add to, not to finish (→ "terminer").
- **Word senses.** décalage is only the lag on a relation; a task that moves "est déplacée" or
  "est repoussée d'un jour", a late task "prend du retard". A house extension is agrandissement, not
  extension. The break in the working day is pause (`terms`), not interruption.
- **Calques.** "court en retard" (runs late) → "prend du retard"; "fait sens" → "a du sens"; "comme
  si c'était" (as it were) → "pour ainsi dire"; "retombe à zéro" (falls back) → "revient à zéro".
