# Known pitfalls: Czech (cs)

- **Clitics in the second position.** *se, si, ji, mu, jsem, by* stand after the first stressed unit
  of the clause. Wrong: "Když první ji využije" → right: "Když ji první využije". Wrong: "Pak každý
  úkol … se počítá" → right: "Pak se každý úkol … počítá".
- **Double negation.** *žádný, nic, nikdy* need a negated verb: "které úkoly nemají téměř žádnou
  rezervu", not "mají téměř žádnou rezervu".
- **Gender with *oba/obě* and numerals.** Agree with the noun: "oba řetězce" (masculine), "obě
  cesty" (feminine). Check *dva/dvě* the same way.
- **Prepositions *z/ze*, *s/se*, *v/ve*.** Use the vowel form only before a hard consonant cluster:
  "z vašich závislostí", not "ze vašich".
- **Imperative in a relative clause.** After *ve kterém, který* use the indicative: "okno, ve kterém
  si necháte vygenerovat", not "nechte".
- **calculate ≠ recalculate.** *přepočítat* is the command (*Přepočítat*). In a sentence that only
  says the app calculates something, write *vypočítat / vypočtený*.
- **Calques.** "je pozdě / běží pozdě" → "má zpoždění / se zpozdí"; "na místě" → "zadány";
  "začne na zahájení projektu" → "začne v den zahájení projektu"; "úkol o době 12 hodin" → "úkol
  s dobou trvání 12 hodin".
- **Labels need a case.** A command label stays in the nominative; put a carrier word in front for the
  case: "po přepočítání (**Přepočítat**)", "s vlastním polem *Prahová hodnota*".
- **Ribbon tab vs menu.** A ribbon tab takes "na kartě *X*", not "v nabídce *X*".
