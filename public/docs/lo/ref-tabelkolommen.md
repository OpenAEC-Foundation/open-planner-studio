# ຖັນຕາຕະລາງ

ຕາຕະລາງໜ້າວຽກມີ 86 ຖັນຄົງທີ່, ບວກໜຶ່ງຖັນຕໍ່ລະຫັດກິດຈະກຳ ແລະ ຕໍ່ຊ່ອງກຳນົດເອງຂອງໂຄງການ, ແລະ ແປດຖັນຕໍ່ແຜນຫຼັກ. ບົດນີ້ບອກສຳລັບແຕ່ລະຖັນ ວ່າມັນສະແດງຫຍັງ ທ່ານແກ້ໄຂໄດ້ຫຼືບໍ່ ແລະ ຄ່າຖືກຂຽນໃນຮູບແບບໃດ. ວິທີເລືອກ ແລະ ຈັດລຽງຖັນ ຢູ່ໃນ [ການປັບແຕ່ງຖັນຕາຕະລາງ](docs://howto-tabelkolommen-aanpassen).

## ບ່ອນທີ່ທ່ານເລືອກຖັນ

ຕາຕະລາງໜ້າວຽກຂ້າງ Gantt ແລະ ຕາຕະລາງໃນແທັບ *ຕາຕະລາງ* ແຕ່ລະອັນມີການເລືອກຖັນຂອງຕົນເອງ. ເຄື່ອງໝາຍບວກທາງຂວາຂອງສ່ວນຫົວ ເປີດຕົວເລືອກຖັນ (ຊື່ໜ້າຕ່າງ *ເລືອກຖັນ*); ໃນ *ຕາຕະລາງ* ທ່ານກໍ່ໃຊ້ *ຕາຕະລາງ › ຖັນ › ຖັນ…* ໄດ້ເຊັ່ນກັນ. ຕົວເລືອກສະແດງຖັນຕາມປະເພດ: *ໜ້າວຽກ*, *ການວາງແຜນ*, *ເງື່ອນໄຂບັງຄັບ*, *ສາຍພົວພັນ*, *ຊັບພະຍາກອນ*, *ຄວາມຄືບໜ້າ*, *ຄິດໄລ່ແລ້ວ*, *ແຜນຖານ*, *ກຳນົດເອງ* ແລະ *ດ້ານເຕັກນິກ*. ທ່ານຄົ້ນຫາຕາມຊື່ໄດ້, ແລະ *ໃຊ້ຫວ່າງມໍ່ໆນີ້* ຢູ່ດ້ານເທິງສຸດ. *ຕັ້ງຄ່າເລີ່ມຕົ້ນຄືນໃໝ່* ນຳຖັນເລີ່ມຕົ້ນກັບຄືນມາ.

ໂດຍຄ່າເລີ່ມຕົ້ນ ຕາຕະລາງຂ້າງ Gantt ສະແດງ *WBS*, *ຊື່ໜ້າວຽກ* ແລະ *ໄລຍະເວລາ*. ຕາຕະລາງໃນແທັບ *ຕາຕະລາງ* ສະແດງ *WBS*, *ຊື່ໜ້າວຽກ*, *ໄລຍະເວລາ*, *ເລີ່ມຕົ້ນ*, *ສິ້ນສຸດ*, *ໝວດວຽກ*, *ວິກິດ*, *ໄລຍະຜ່ອນຜັນລວມ* ແລະ *ຄວາມຄືບໜ້າ*, ບວກໜຶ່ງຖັນຕໍ່ລະຫັດກິດຈະກຳ ແລະ ຕໍ່ຊ່ອງກຳນົດເອງຂອງໂຄງການ.

## ວິທີອ່ານ ແລະ ແກ້ໄຂຄ່າ

- **ຖັນທີ່ຄິດໄລ່ແລ້ວ** — ຖັນໃນປະເພດ *ຄິດໄລ່ແລ້ວ* ແລະ ຖັນອື່ນອີກຈຳນວນໜຶ່ງເປັນອ່ານຢ່າງດຽວ: ມັນມາຈາກການຄິດໄລ່. ຖ້າທ່ານພະຍາຍາມແກ້ໄຂຊ່ອງອ່ານຢ່າງດຽວ ແອັບບອກວ່າ *ຖັນທີ່ຄິດໄລ່ແລ້ວນີ້ບໍ່ສາມາດດັດແກ້ໄດ້.* ຂໍ້ຄວາມນັ້ນເປັນຂໍ້ຄວາມທົ່ວໄປສຳລັບທຸກຊ່ອງອ່ານຢ່າງດຽວ, ເຖິງແມ່ນຖັນນັ້ນບໍ່ແມ່ນຖັນທີ່ຄິດໄລ່. ຖ້າພວກມັນບໍ່ເປັນປັດຈຸບັນ ເພາະທ່ານປ່ຽນບາງສິ່ງ ຈະມີ *ບໍ່ເປັນປັດຈຸບັນ* ຢູ່ຂ້າງພວກມັນ ຈົນກວ່າທ່ານຈະກົດ *ຄິດໄລ່*.
- **ວັນທີ** — ສະແດງໃນຮູບແບບທີ່ທ່ານເລືອກໄວ້ໃຕ້ *ການຕັ້ງຄ່າແອັບ*, ແທັບ *ຮູບລັກສະນະ*, ຫົວຂໍ້ *ຮູບແບບວັນທີ*.
- **ໄລຍະເວລາ ແລະ float** — ໄລຍະເວລາສະແດງໃນຫົວໜ່ວຍຂອງໜ້າວຽກ (`5d`, `12h`), ຫຼື ຕາມ *ການສະແດງໄລຍະເວລາ* ໃນແທັບດຽວກັນ (*ອັດຕະໂນມັດ (ຕາມຫົວໜ່ວຍເດີມຂອງແຕ່ລະໜ້າວຽກ)*, *ເປັນມື້ສະເໝີ* ຫຼື *ເປັນຊົ່ວໂມງສະເໝີ*). float ສະແດງເປັນມື້ເຮັດວຽກ ດ້ວຍສອງຕຳແໜ່ງທົດສະນິຍົມ ແລະ ເຄື່ອງໝາຍທົດສະນິຍົມຂອງພາສາຂອງທ່ານ.
- **ແມ່ນ/ບໍ່** — ຄ່າແມ່ນ/ບໍ່ ສະແດງເປັນ *ແມ່ນ* ຫຼື *ບໍ່*; ຄ່າຫວ່າງສະແດງເປັນຂີດ (—).
- **ການແກ້ໄຂ** — ພິມ ຫຼື ເລືອກຄ່າ. ຄ່າທີ່ບໍ່ຖືກຕ້ອງຖືກປະຕິເສດ ພ້ອມເຫດຜົນໃຕ້ຊ່ອງ, ຕົວຢ່າງ *ປ້ອນໄລຍະເວລາທີ່ຖືກຕ້ອງ ເຊັ່ນ: 5d ຫຼື 8h.* ຫຼື *ປ້ອນເປີເຊັນລະຫວ່າງ 0 ຫາ 100.* ການວາງຫຼາຍຊ່ອງເຮັດວຽກເປັນຊ່ອງໆ; ຊ່ອງອ່ານຢ່າງດຽວຖືກຂ້າມ ແລະ ແອັບບອກວ່າມີຈັກຊ່ອງ.

## ໜ້າວຽກ

- **ຊື່ໜ້າວຽກ** — ຊື່ຂອງໜ້າວຽກ. ແກ້ໄຂໄດ້; ຈຳເປັນຕ້ອງມີ. ໜ້າວຽກຫຼັກສະແດງເປັນຕົວໜາ ພ້ອມສີພື້ນອ່ອນຢູ່ຊ່ອງຊື່. ຫຼັກໝາຍສະແດງເປັນຕົວໜາ ດ້ວຍໂທນສີດຽວກັນກັບຫຼັກໝາຍໃນ Gantt. ໜ້າວຽກທຳມະດາບໍ່ປ່ຽນ. ນີ້ເປັນພຽງການຈັດຮູບແບບ: ການເລືອກ, ການລາກ ແລະ ການແກ້ໄຂເຮັດວຽກຄືເດີມ.
- **ຄຳອະທິບາຍ** — ຄຳອະທິບາຍ. ແກ້ໄຂໄດ້; ເປັນຂໍ້ຄວາມອິດສະຫຼະ.
- **WBS** — ລະຫັດ WBS. ແກ້ໄຂໄດ້ ແລະ ຈຳເປັນຕ້ອງມີ, ແຕ່ເປັນອ່ານຢ່າງດຽວ ໃນຂະນະທີ່ *WBS ອັດຕະໂນມັດ* ເປີດຢູ່.
- **ໝວດວຽກ** — ໝວດຂອງໜ້າວຽກ (*ການກໍ່ສ້າງ*, *ການຕິດຕັ້ງ*, *ການຮື້ຖອນ*, *ໂລຈິສຕິກ*, *ການກວດກາ*, *ການຍົກຍ້າຍ*, *ການສ້ອມແປງປັບປຸງ*, *ການບົວລະບັດຮັກສາ* ຫຼື *ອື່ນໆ*). ແກ້ໄຂໄດ້ດ້ວຍລາຍການ.
- **ໝວດວຽກກຳນົດເອງ** — ໝວດວຽກກຳນົດເອງຂອງໂຄງການ ຫຼື ຂີດ. ແກ້ໄຂໄດ້ດ້ວຍລາຍການໝວດວຽກກຳນົດເອງຂອງໂຄງການ.
- **ສີ** — ສີທີ່ເກັບໄວ້ຂອງໜ້າວຽກ ເປັນລະຫັດສີ ເຊັ່ນ `#1a73e8`. ແກ້ໄຂໄດ້ດ້ວຍຕົວເລືອກສີ. ມັນຖືກເກັບໄວ້ໃນໄຟລ໌ IFC, ແຕ່ບໍ່ມີແຖບໜ້າວຽກ ຫຼື ລາຍງານໃດໃຊ້ມັນ; ທ່ານຕັ້ງສີແຖບພາຍໃຕ້ *ມຸມມອງ › ແຜນຖານ ແລະ ຄວາມຄືບໜ້າ › ສີແຖບ*.
- **ໝາຍເຫດ** — ໝາຍເຫດເປັນ `✓ text; ○ text`. ແກ້ໄຂໄດ້ ຕາບໃດທີ່ມີໝາຍເຫດບໍ່ເກີນໜຶ່ງ (ທ່ານແກ້ໄຂຂໍ້ຄວາມຂອງມັນ); ຖ້າມີຫຼາຍກວ່ານັ້ນ ເປັນອ່ານຢ່າງດຽວ.

## ການວາງແຜນ

- **ຫຼັກໝາຍ** — ວ່າໜ້າວຽກເປັນຫຼັກໝາຍຫຼືບໍ່. ແກ້ໄຂໄດ້. ການເປີດມັນເຮັດໃຫ້ໄລຍະເວລາເປັນ 0; ແອັບປະຕິເສດສຳລັບໜ້າວຽກຫຼັກ ແລະ ສຳລັບໜ້າວຽກທີ່ມີການມອບໝາຍ.
- **ປະເພດຫຼັກໝາຍ** — *ຫຼັກໝາຍເລີ່ມຕົ້ນ* ຫຼື *ຫຼັກໝາຍສິ້ນສຸດ*, ຫຼື ຂີດສຳລັບອັດຕະໂນມັດ. ແກ້ໄຂໄດ້ສະເພາະໃນຫຼັກໝາຍ.
- **ຫຼັກໝາຍບັງຄັບ** — ທຸງ *ບັງຄັບ (ຕາມສັນຍາ)*. ແກ້ໄຂໄດ້ສະເພາະໃນຫຼັກໝາຍ.
- **ລຳດັບຄວາມສຳຄັນໃນການປັບສົມດຸນ** — ຈຳນວນເຕັມຈາກ 0 ຫາ 1000, ຄ່າເລີ່ມຕົ້ນ 500. ແກ້ໄຂໄດ້. 1000 ປັກໝຸດໜ້າວຽກໄວ້ສຳລັບການປັບສົມດຸນ.
- **ແຍກຊ່ວງ** — ຈຳນວນຊ່ວງແຍກ ເປັນ `Split gaps: 2` ຫຼື ຂີດ. ເປັນອ່ານຢ່າງດຽວ; ທ່ານແກ້ໄຂພວກມັນໃນແຜງ *ຄຸນສົມບັດ*.
- **ປະເພດໜ້າວຽກ** — ປະເພດໜ້າວຽກຂອງໜ້າວຽກນີ້; ວ່າງໝາຍເຖິງຄ່າເລີ່ມຕົ້ນຂອງໂຄງການ. ແກ້ໄຂໄດ້ດ້ວຍລາຍການ, ແຕ່ໃນຫຼັກໝາຍ, ໜ້າວຽກຫຼັກ ຫຼື ແຮມມັອກ ມັນວ່າງ ແລະ ເປັນອ່ານຢ່າງດຽວ. ມັນສະແດງໃນຕົວເລືອກເທົ່ານັ້ນ ເມື່ອ *ໃຊ້ປະເພດໜ້າວຽກ* ເປີດຢູ່ ຫຼື ໄຟລ໌ມີປະເພດໜ້າວຽກ.
- **ແຮມມັອກ (ໄລຍະເວລາທີ່ໄດ້ມາ)** — ວ່າໜ້າວຽກເປັນແຮມມັອກຫຼືບໍ່. ແກ້ໄຂໄດ້, ຍົກເວັ້ນໃນຫຼັກໝາຍ ຫຼື ໜ້າວຽກຫຼັກ.
- **ປະຕິທິນ** — ໄອດີຂອງປະຕິທິນຂອງໜ້າວຽກ; ຂີດ (—) ແມ່ນປະຕິທິນຂອງໂຄງການ. ທ່ານພິມ ຫຼື ເລືອກໄອດີຈາກຄຳແນະນຳ; ໄອດີທີ່ບໍ່ຮູ້ຈັກຖືກປະຕິເສດ. ໝາຍເຫດ: ຊ່ອງນີ້ປັດຈຸບັນສະແດງໄອດີພາຍໃນແທນຊື່. ດີກວ່າເລືອກປະຕິທິນໃນແຜງ *ຄຸນສົມບັດ*.
- **ປະເພດໄລຍະເວລາ** — *ເວລາເຮັດວຽກ* (ໄລຍະເວລານັບເປັນມື້ເຮັດວຽກ ຫຼື ຊົ່ວໂມງເຮັດວຽກຂອງປະຕິທິນ) ຫຼື *ເວລາລ່ວງເລີຍ* (ໄລຍະເວລານັບເປັນເວລາຕໍ່ເນື່ອງ ໂດຍບໍ່ໃຊ້ປະຕິທິນ). ແກ້ໄຂໄດ້.
- **ຫົວໜ່ວຍໄລຍະເວລາ** — *ມື້* ຫຼື *ຊົ່ວໂມງ*. ແກ້ໄຂໄດ້, ຍົກເວັ້ນໃນໜ້າວຽກຫຼັກ, ແຮມມັອກ ຫຼື ຫຼັກໝາຍ. ການປ່ຽນໃຊ້ໄດ້ພຽງເມື່ອການແປງຖືກຕ້ອງແນ່ນອນ ແລະ *ເປີດໃຊ້ການວາງແຜນລາຍຊົ່ວໂມງ* ຕ້ອງເປີດຢູ່.
- **ໄລຍະເວລາ** — ໄລຍະເວລາຂອງໜ້າວຽກ ໃນຫົວໜ່ວຍຂອງໜ້າວຽກ ຫຼື ຕາມ *ການສະແດງໄລຍະເວລາ*. ແກ້ໄຂໄດ້: ພິມ `5d`, `12h` ຫຼື `1h 30m`; ຫຼື ຕົວເລກໃນຫົວໜ່ວຍຂອງໜ້າວຽກ. ເປັນອ່ານຢ່າງດຽວໃນໜ້າວຽກຫຼັກ, ແຮມມັອກ ແລະ ຫຼັກໝາຍທີ່ມີໄລຍະເວລາ 0.
- **ເລີ່ມຕົ້ນ** — ວັນເລີ່ມທີ່ສະແດງ ຄືວັນດຽວກັນກັບແຖບໜ້າວຽກໃນ Gantt. ສຳລັບໜ້າວຽກທີ່ເລີ່ມແລ້ວ, ນັ້ນແມ່ນວັນເລີ່ມຕົວຈິງ. ແກ້ໄຂໄດ້. ໜ້າວຽກທີ່ມີໜ້າວຽກກ່ອນໜ້າ ແລະ ທ່ານໃຫ້ວັນເລີ່ມໃໝ່ ຈະໄດ້ເງື່ອນໄຂ *ເລີ່ມບໍ່ກ່ອນ (SNET)* ໃນວັນນັ້ນ. ເປັນອ່ານຢ່າງດຽວໃນໜ້າວຽກຫຼັກ ຫຼື ແຮມມັອກ, ເວັ້ນແຕ່ໜ້າວຽກກຳນົດເວລາດ້ວຍຕົນເອງ, ແລະ ໃນໜ້າວຽກທີ່ເລີ່ມແລ້ວ (*ໜ້າວຽກນີ້ໄດ້ເລີ່ມແລ້ວ, ວັນເລີ່ມຕົວຈິງ. ກະລຸນາປ່ຽນຜ່ານຄວາມຄືບໜ້າ.*).
- **ສິ້ນສຸດ** — ວັນສິ້ນສຸດທີ່ສະແດງ. ສຳລັບໜ້າວຽກທີ່ສຳເລັດແລ້ວ, ນັ້ນແມ່ນວັນສິ້ນສຸດຕົວຈິງ. ແກ້ໄຂໄດ້: ວັນສິ້ນສຸດໃໝ່ກາຍເປັນໄລຍະເວລາໃໝ່. ແອັບປະຕິເສດສຳລັບຫຼັກໝາຍ, ໜ້າວຽກໃນເວລາລ່ວງເລີຍ ແລະ ໜ້າວຽກທີ່ມີຊ່ວງແຍກ, ແລະ ສຳລັບວັນສິ້ນສຸດທີ່ກ່ອນວັນເລີ່ມ *ມື້ສິ້ນສຸດມາກ່ອນມື້ເລີ່ມຕົ້ນ.* ເປັນອ່ານຢ່າງດຽວໃນໜ້າວຽກຫຼັກ ຫຼື ແຮມມັອກ, ເວັ້ນແຕ່ໜ້າວຽກກຳນົດເວລາດ້ວຍຕົນເອງ, ແລະ ໃນໜ້າວຽກທີ່ສຳເລັດແລ້ວ (*ໜ້າວຽກນີ້ສຳເລັດແລ້ວ; ມື້ສິ້ນສຸດຂອງມັນແມ່ນມື້ສິ້ນສຸດຕົວຈິງ. ປ່ຽນມັນຜ່ານຄວາມຄືບໜ້າ.*).
- **ວັນເລີ່ມຕາມແຜນງານ** — ຈຸດອ້າງອີງທີ່ການຄິດໄລ່ເລີ່ມຈາກມັນ (ບໍ່ຈຳເປັນຕ້ອງເທົ່າກັບວັນເລີ່ມທີ່ສະແດງ). ແກ້ໄຂໄດ້; ຜົນເໝືອນການພິມໃນ *ເລີ່ມຕົ້ນ*.
- **ວັນສິ້ນສຸດຕາມແຜນງານ** — ວັນສິ້ນສຸດທີ່ປ້ອນ. ແກ້ໄຂໄດ້ສະເພາະໜ້າວຽກທີ່ກຳນົດເວລາດ້ວຍຕົນເອງ; ຖ້າບໍ່ດັ່ງນັ້ນ ແອັບບອກວ່າ *ວັນສິ້ນສຸດຕາມແຜນງານໃຊ້ໄດ້ພຽງໜ້າວຽກທີ່ກຳນົດເວລາດ້ວຍຕົນເອງ. ປ່ຽນວັນສິ້ນສຸດຜ່ານຖັນສິ້ນສຸດ ຫຼື ໄລຍະເວລາ.*

## ເງື່ອນໄຂບັງຄັບ

- **ປະເພດເງື່ອນໄຂ** — ປະເພດຂອງເງື່ອນໄຂ ຕັ້ງແຕ່ *ໄວເທົ່າທີ່ຈະໄວໄດ້ (ASAP)* ຫາ *ຕ້ອງສິ້ນສຸດໃນວັນທີ (MFO)*. ແກ້ໄຂໄດ້. ໜ້າວຽກທີ່ບໍ່ມີເງື່ອນໄຂສະແດງ *ASAP*.
- **ວັນເງື່ອນໄຂ** — ວັນຂອງເງື່ອນໄຂ. ແກ້ໄຂໄດ້.
- **ເງື່ອນໄຂເຂັ້ມງວດ** — ທຸງ *ບັງຄັບ (ປັກໝຸດແໜ້ນ)*. ແກ້ໄຂໄດ້ສະເພາະໃນ *MSO* ແລະ *MFO*.
- **ປະເພດເງື່ອນໄຂສຳຮອງ** — ປະເພດຂອງຂອບທີສອງ ຫຼື ຂີດ. ແກ້ໄຂໄດ້. ຕາຕະລາງສະເໜີທຸກປະເພດ, ແຕ່ການປະສົມທີ່ບໍ່ອະນຸຍາດຖືກປະຕິເສດ: ມັນຕ້ອງເປັນ *SNET*, *FNET*, *SNLT* ຫຼື *FNLT*; ເງື່ອນໄຂຫຼັກຕ້ອງເປັນຂອບ (ບໍ່ແມ່ນ *ASAP*, *ALAP*, *MSO*, *MFO* ຫຼື ເງື່ອນໄຂເຂັ້ມງວດ); ແລະ ສອງອັນຕ້ອງຂີດຂອບຄົນລະດ້ານ (ຂອບລຸ່ມ *SNET*/*FNET* ກັບຂອບເທິງ *SNLT*/*FNLT*, ຫຼື ກັບກັນ).
- **ວັນເງື່ອນໄຂສຳຮອງ** — ວັນຂອງຂອບທີສອງ. ແກ້ໄຂໄດ້.
- **ກຳນົດສົ່ງ** — ວັນເປົ້າໝາຍສຳລັບການສິ້ນສຸດ. ແກ້ໄຂໄດ້.

## ສາຍພົວພັນ

- **ໜ້າວຽກກ່ອນໜ້າ** — ໜ້າວຽກກ່ອນໜ້າ, ເປັນ `WBS type±lag`, ແຍກດ້ວຍ `; `, ຕົວຢ່າງ `1.2 FS+2d`. ແກ້ໄຂໄດ້ດ້ວຍການພິມຮູບແບບດຽວກັນ. ທ່ານບໍ່ເພີ່ມສາຍສຳພັນພາຍນອກຢູ່ບ່ອນນີ້; ທ່ານເພີ່ມມັນດ້ວຍ *ການວາງແຜນ › ສາຍພົວພັນ › ເຊື່ອມໂຍງ › ເພີ່ມສາຍສຳພັນພາຍນອກ…*.
- **ໜ້າວຽກຖັດໄປ** — ໜ້າວຽກຖັດໄປ, ໃນຮູບແບບດຽວກັນ. ແກ້ໄຂໄດ້.
- **ສາຍພົວພັນຄວບຄຸມ** — ສາຍສຳພັນທີ່ກຳນົດວັນຂອງໜ້າວຽກນີ້, ເປັນ `← 1.2` (ໜ້າວຽກກ່ອນໜ້າ) ຫຼື `→ 1.4` (ໜ້າວຽກຖັດໄປ). ເປັນອ່ານຢ່າງດຽວ; ມັນບໍ່ເປັນປັດຈຸບັນ ຈົນກວ່າທ່ານຈະກົດ *ຄິດໄລ່*.
- **ໄລຍະຜ່ອນຜັນອິດສະຫຼະ** (ໃນປະເພດ *ສາຍພົວພັນ*) — free float ຕໍ່ສາຍສຳພັນ, ເປັນ `← 1.2: 3d`. ມັນບໍ່ແມ່ນຖັນດຽວກັນກັບ *ໄລຍະຜ່ອນຜັນອິດສະຫຼະ* ພາຍໃຕ້ *ຄິດໄລ່ແລ້ວ* ທີ່ສະແດງ float ຂອງໜ້າວຽກເອງ. ເປັນອ່ານຢ່າງດຽວ.
- **ຄຳເຕືອນ** — ຄຳເຕືອນຕໍ່ສາຍສຳພັນ, ຕົວຢ່າງ *ຂ້າມລຳດັບຂັ້ນຕອນ* ຫຼື *ບໍ່ໄດ້ລວມເຂົ້າໃນການຄິດໄລ່*. ເປັນອ່ານຢ່າງດຽວ. ເບິ່ງ [ການແຈ້ງເຕືອນ ແລະ ຄຳເຕືອນ](docs://ref-meldingen).

## ຊັບພະຍາກອນ

- **ຊັບພະຍາກອນທີ່ມອບໝາຍ** — ຊື່ຂອງຊັບພະຍາກອນທີ່ມອບໝາຍ, ແຍກດ້ວຍຈຸລະພາກ. ແກ້ໄຂໄດ້: ການເພີ່ມຊື່ຈະມອບໝາຍຊັບພະຍາກອນນັ້ນດ້ວຍ 1 ໜ່ວຍຕໍ່ມື້; ການລຶບຊື່ຈະລຶບການມອບໝາຍ. ເປັນອ່ານຢ່າງດຽວໃນຫຼັກໝາຍ ຫຼື ໜ້າວຽກຫຼັກ.
- **ຫົວໜ່ວຍການມອບໝາຍຕໍ່ມື້** — ໜ່ວຍຕໍ່ຊັບພະຍາກອນ, ເປັນ `Name: 1; Name: 0.5`, ເຖິງສອງຕຳແໜ່ງທົດສະນິຍົມ. ຄ່າທີ່ເກັບໄວ້ຍັງຄົງແນ່ນອນ. ແກ້ໄຂໄດ້ໃນໜ້າວຽກທີ່ມີການມອບໝາຍ.
- **ຫົວໜ່ວຍຕາມແຜນຕໍ່ມື້** — ອັດຕາຕາມແຜນຕໍ່ຊັບພະຍາກອນ, ເປັນ `Name: 1.11`, ເຖິງສອງຕຳແໜ່ງທົດສະນິຍົມ, ຄືກັບ *ຫົວໜ່ວຍການມອບໝາຍຕໍ່ມື້*. ມີສະເພາະການມອບໝາຍຈາກ Primavera P6 ທີ່ມີອັດຕາທີ່ເຫຼືອຕ່າງກັນ; ໃນກໍລະນີນັ້ນ *ຫົວໜ່ວຍການມອບໝາຍຕໍ່ມື້* ສະແດງອັດຕາທີ່ເຫຼືອ. ເປັນອ່ານຢ່າງດຽວ.
- **ເສັ້ນໂຄ້ງການມອບໝາຍ** — ເສັ້ນໂຄ້ງຕໍ່ຊັບພະຍາກອນ, ເປັນ `Name: Uniform`. ແກ້ໄຂໄດ້ໃນໜ້າວຽກທີ່ມີການມອບໝາຍ.
- **ເລີ່ມໜ້າຕ່າງວຽກ** ແລະ **ສິ້ນສຸດໜ້າຕ່າງວຽກ** — ໜ້າຕ່າງວຽກຕໍ່ຊັບພະຍາກອນ, ຈາກໄຟລ໌ທີ່ນຳເຂົ້າ, ເປັນ `Name: date`. ເປັນອ່ານຢ່າງດຽວ.
- **ວຽກຕາມແຜນ (ຊົ່ວໂມງ)** ແລະ **ວຽກຕົວຈິງ (ຊົ່ວໂມງ)** — ວຽກຕາມແຜນ ແລະ ວຽກຕົວຈິງຕໍ່ຊັບພະຍາກອນເປັນຊົ່ວໂມງ, ເປັນ `Name: 617.14`, ເຖິງສອງຕຳແໜ່ງທົດສະນິຍົມ, ຈາກໄຟລ໌ທີ່ນຳເຂົ້າ. ເປັນອ່ານຢ່າງດຽວ.
- **ວຽກທີ່ເຫຼືອ (ຊົ່ວໂມງ)** — ວຽກທີ່ເຫຼືອຕໍ່ຊັບພະຍາກອນເປັນຊົ່ວໂມງ, ເປັນ `Name: 6` ຫຼື `Name: 26.67`: ຄ່າປະລິມານວຽກທີ່ເກັບໄວ້; ຖ້າບໍ່ມີ ແມ່ນໄລຍະເວລາທີ່ເຫຼືອ × ໜ່ວຍ. ແກ້ໄຂໄດ້ໃນໜ້າວຽກທີ່ມີການມອບໝາຍ ທີ່ປະເພດໜ້າວຽກໃຊ້ໄດ້, ໂດຍໃຊ້ເຄື່ອງໝາຍຈຸດ ຫຼື ເຄື່ອງໝາຍຈຸລະພາກເປັນຕົວແຍກທົດສະນິຍົມ. ມັນສະແດງໃນຕົວເລືອກເທົ່ານັ້ນ ເມື່ອປະເພດໜ້າວຽກສະແດງຢູ່. ຖ້າມີ ⚠ ສີເຫຼືອງໃນຊ່ອງ ໝາຍວ່າວຽກທີ່ເກັບໄວ້ແຕກຕ່າງຈາກ ໜ່ວຍ × ໄລຍະເວລາທີ່ເຫຼືອ, ຄືກັບ ⚠ ທີ່ *ວຽກ (ທີ່ເຫຼືອ)* ໃນແຜງໜ້າວຽກ.

## ຄວາມຄືບໜ້າ

- **ສະຖານະ** — *ຍັງບໍ່ໄດ້ເລີ່ມ*, *ກຳລັງດຳເນີນການ* ຫຼື *ສຳເລັດແລ້ວ*. ແກ້ໄຂໄດ້, ຍົກເວັ້ນໜ້າວຽກຫຼັກ.
- **ຄວາມຄືບໜ້າ** — ເປີເຊັນ, ເປັນ `40%`. ແກ້ໄຂໄດ້ດ້ວຍຕົວເລກ 0 ຫາ 100, ຍົກເວັ້ນໜ້າວຽກຫຼັກ.
- **ວັນເລີ່ມຕົວຈິງ** — ວັນທີ່ໜ້າວຽກເລີ່ມ. ແກ້ໄຂໄດ້, ຍົກເວັ້ນໜ້າວຽກຫຼັກ.
- **ວັນສຳເລັດຕົວຈິງ** — ວັນທີ່ໜ້າວຽກສຳເລັດ. ແກ້ໄຂໄດ້, ຍົກເວັ້ນໜ້າວຽກຫຼັກ.
- **ໄລຍະເວລາຕົວຈິງ** — ໄລຍະເວລາຕົວຈິງ, ເປັນຕົວເລກ. ແກ້ໄຂໄດ້, ຍົກເວັ້ນໜ້າວຽກຫຼັກ.
- **ທີ່ເຫຼືອ** — ໄລຍະເວລາທີ່ເຫຼືອ, ໃນຫົວໜ່ວຍຂອງໜ້າວຽກ. ແກ້ໄຂໄດ້, ຍົກເວັ້ນໜ້າວຽກຫຼັກ.
- **ວັນດຳເນີນຕໍ່** ແລະ **ວັນຢຸດ** — ການດຳເນີນຕໍ່ ແລະ ການຢຸດຂອງໜ້າວຽກທີ່ກຳລັງເຮັດ ຈາກໄຟລ໌ MS Project ຫຼື Primavera. ເປັນອ່ານຢ່າງດຽວ.

ຖັນຄວາມຄືບໜ້າປະຕິບັດຕາມກົດຂອງແອັບ: ວັນທີຕົວຈິງຫຼັງຈາກວັນທີສະຖານະ ຖືກປະຕິເສດ. ໃນໜ້າວຽກຫຼັກ ແອັບບອກວ່າ *ຄວາມຄືບໜ້າຂອງໜ້າວຽກສະຫຼຸບແມ່ນຄິດໄລ່ຈາກໜ້າວຽກຍ່ອຍ ແລະ ບໍ່ສາມາດປ່ຽນແປງຢູ່ນີ້ໄດ້.*

## ຄິດໄລ່ແລ້ວ

ທຸກຖັນໃນປະເພດນີ້ເປັນອ່ານຢ່າງດຽວ.

- **ຄວາມຊັກຊ້າຈາກການປັບສົມດຸນ** — ຈຳນວນມື້ເຮັດວຽກທີ່ການປັບສົມດຸນເຮັດໃຫ້ໜ້າວຽກຊັກຊ້າ; ຂີດ ຖ້າບໍ່ໄດ້ນຳການປັບສົມດຸນມາໃຊ້.
- **ເລີ່ມຕົ້ນໄວສຸດ** ແລະ **ສິ້ນສຸດໄວສຸດ** — ວັນທີ່ໄວທີ່ສຸດຈາກການຄິດໄລ່. ສຳລັບໜ້າວຽກທີ່ເລີ່ມແລ້ວ ມັນອາດແຕກຕ່າງຈາກ *ເລີ່ມຕົ້ນ* ແລະ *ສິ້ນສຸດ*: ໂປຣໄຟລ໌ການຄິດໄລ່ *Primavera P6* ໃຫ້ເລີ່ມຕົ້ນໄວສຸດຂອງໜ້າວຽກທີ່ກຳລັງດຳເນີນ ຫຼື ສຳເລັດແລ້ວ ຢູ່ວັນທີສະຖານະ.
- **ເລີ່ມຕົ້ນຊ້າສຸດ** ແລະ **ສິ້ນສຸດຊ້າສຸດ** — ວັນທີ່ຊ້າທີ່ສຸດທີ່ໜ້າວຽກຍັງເລີ່ມ ຫຼື ສິ້ນສຸດໄດ້ ໂດຍບໍ່ເຮັດໃຫ້ໂຄງການຊັກຊ້າ.
- **free float** — ຈຳນວນມື້ເຮັດວຽກທີ່ໜ້າວຽກອາດເລື່ອນໄດ້ ໂດຍບໍ່ເຮັດໃຫ້ໜ້າວຽກຖັດໄປຊັກຊ້າ.
- **ໄລຍະຜ່ອນຜັນລວມ** — ຈຳນວນມື້ເຮັດວຽກທີ່ໜ້າວຽກອາດເລື່ອນໄດ້ ໂດຍບໍ່ເຮັດໃຫ້ວັນສິ້ນສຸດໂຄງການຊັກຊ້າ. ເປັນລົບ ຖ້າເງື່ອນໄຂ ຫຼື ກຳນົດສົ່ງບໍ່ສາມາດບັນລຸໄດ້.
- **ວິກິດ** — *ແມ່ນ* ຖ້າໜ້າວຽກຢູ່ເທິງເສັ້ນທາງວິກິດ.
- **ການແຊກແຊງ float** — ໄລຍະຜ່ອນຜັນລວມ ລົບ free float.
- **ໃກ້ວິກິດ** — *ແມ່ນ* ສຳລັບໜ້າວຽກໃກ້ວິກິດ. ມີຄ່າພຽງເມື່ອ *ໝາຍວ່າເກືອບວິກິດ* ເປີດຢູ່ (*ການຕັ້ງຄ່າໂຄງການ*, ສ່ວນ *ໂປຣໄຟລ໌ການຄິດໄລ່ ແລະ ຕົວເລືອກ*); ຖ້າບໍ່ດັ່ງນັ້ນ ເປັນຂີດ.
- **ເສັ້ນທາງຜ່ອນຜັນ** — ໝາຍເລກຂອງເສັ້ນທາງຜ່ອນຜັນ, 1 ສຳລັບເສັ້ນທີ່ວິກິດທີ່ສຸດ. ມີຄ່າພຽງເມື່ອ *ເສັ້ນທາງຜ່ອນຜັນຫຼາຍສາຍ* ເປີດຢູ່; ຖ້າບໍ່ດັ່ງນັ້ນ ເປັນຂີດ.
- **ແຫຼ່ງວັນທີທີ່ບັນທຶກ** — ຕາບໃດທີ່ແອັບສະແດງວັນທີຈາກໄຟລ໌: *ບໍ່ໄດ້ບັນທຶກບາງສ່ວນ* ໃນໜ້າວຽກທີ່ໄຟລ໌ບໍ່ມີທຸກຢ່າງ. ມັນສະແດງໃນຕົວເລືອກ ໃນມຸມມອງນັ້ນເທົ່ານັ້ນ. ໃນແກນທີ່ບໍ່ໄດ້ບັນທຶກ *ບໍ່ໄດ້ບັນທຶກ* ປາກົດໃນຖັນວັນທີຊ້າສຸດ ແລະ float.

ເບິ່ງ [ເສັ້ນທາງວິກິດ ແລະ float](docs://uitleg-kritiek-pad).

## ແຜນຫຼັກ

ສຳລັບແຕ່ລະແຜນຫຼັກຂອງໂຄງການ ມີການເພີ່ມຖັນ ໂດຍມີຊື່ແຜນຫຼັກຢູ່ໜ້າຊື່ຖັນ (`<baseline> — Scheduled start`). ຖັນເຫຼົ່ານີ້ເປັນອ່ານຢ່າງດຽວ. ໜ້າວຽກທີ່ບໍ່ຢູ່ໃນແຜນຫຼັກ ສະແດງຂີດ ພ້ອມຂໍ້ຄວາມຊ່ວຍເມື່ອວາງເມົ້າ *ບໍ່ມີໃນແຜນຖານນີ້*.

- **ວັນເລີ່ມຕາມແຜນງານ**, **ວັນສິ້ນສຸດຕາມແຜນງານ** ແລະ **ໄລຍະເວລາ** — ວັນເລີ່ມ, ວັນສິ້ນສຸດ ແລະ ໄລຍະເວລາ ຕາມທີ່ແຜນຫຼັກບັນທຶກໄວ້.
- **ຄວາມແຕກຕ່າງມື້ເລີ່ມຕົ້ນ** ແລະ **ຄວາມແຕກຕ່າງມື້ສິ້ນສຸດ** — ຈຳນວນມື້ເຮັດວຽກລະຫວ່າງແຜນຫຼັກກັບວັນເລີ່ມ ຫຼື ວັນສິ້ນສຸດທີ່ສະແດງ ໃນປະຕິທິນຂອງໂຄງການ; ເປັນບວກ ຖ້າໜ້າວຽກຊ້າກວ່າ.
- **ຄວາມແຕກຕ່າງໄລຍະເວລາ** — ໄລຍະເວລາປັດຈຸບັນລົບໄລຍະເວລາໃນແຜນຫຼັກ, ເປັນມື້ເຮັດວຽກ.

## ກຳນົດເອງ

- **ລະຫັດກິດຈະກຳ** — ໜຶ່ງຖັນຕໍ່ລະຫັດກິດຈະກຳ ພ້ອມຊື່ຂອງລະຫັດ. ສະແດງລະຫັດຂອງຄ່າທີ່ເລືອກ. ແກ້ໄຂໄດ້: ທ່ານພິມລະຫັດ ຫຼື ເລືອກຈາກຄຳແນະນຳ; ລະຫັດທີ່ບໍ່ຮູ້ຈັກຖືກປະຕິເສດ, ແລະ ຖ້າລະຫັດປາກົດຫຼາຍກວ່າໜຶ່ງຄັ້ງ ແອັບຂໍໃຫ້ທ່ານເລືອກຈາກລາຍການ.
- **ຊ່ອງກຳນົດເອງ** — ໜຶ່ງຖັນຕໍ່ຊ່ອງກຳນົດເອງ ພ້ອມຊື່ຂອງມັນ. ການປ້ອນຂໍ້ມູນເໝາະກັບປະເພດ: ຂໍ້ຄວາມ, ຕົວເລກ, ຈຳນວນເຕັມ, ຕົ້ນທຶນ, ວັນທີ ຫຼື ແມ່ນ/ບໍ່. ແກ້ໄຂໄດ້.

ຖັນເຫຼົ່ານີ້ເປັນຂອງໂຄງການທີ່ລະຫັດ ຫຼື ຊ່ອງນັ້ນຢູ່. ເບິ່ງ [ລະຫັດ ແລະ ຊ່ອງກຳນົດເອງ](docs://howto-codes-en-velden).

## ດ້ານເຕັກນິກ

ທຸກຖັນໃນປະເພດນີ້ເປັນອ່ານຢ່າງດຽວ. ພວກມັນສະແດງຂໍ້ມູນທີ່ແອັບເກັບໄວ້ ແຕ່ບໍ່ສະແດງໃນຖັນທຳມະດາ, ຕົວຢ່າງສຳລັບການກວດສອບການນຳເຂົ້າ.

- **ໄອດີໜ້າວຽກ** — ໄອດີພາຍໃນຂອງໜ້າວຽກ.
- **ໄອດີໜ້າວຽກແມ່** ແລະ **ໄອດີໜ້າວຽກລູກ** — ໄອດີຂອງໜ້າວຽກແມ່ ແລະ ໜ້າວຽກລູກ.
- **ໄອດີຊັບພະຍາກອນ** — ໄອດີຂອງຊັບພະຍາກອນໃນໜ້າວຽກ.
- **ໄອດີການມອບໝາຍ**, **ໄອດີໜ້າວຽກຂອງການມອບໝາຍ** ແລະ **ໄອດີຊັບພະຍາກອນຂອງການມອບໝາຍ** — ໄອດີຂອງການມອບໝາຍ, ໜ້າວຽກ ແລະ ຊັບພະຍາກອນຂອງໜ້າວຽກນີ້.
- **ໄລຍະເວລາ (ນາທີ)** ແລະ **ທີ່ເຫຼືອ (ນາທີ)** — ໄລຍະເວລາ ແລະ ໄລຍະເວລາທີ່ເຫຼືອເປັນນາທີ; ມີຄ່າພຽງໜ້າວຽກທີ່ເປັນຊົ່ວໂມງ.
- **ຄວາມຊັກຊ້າຈາກການປັບສົມດຸນ (ນາທີ)** ແລະ **ຄວາມຊັກຊ້າຈາກການປັບສົມດຸນໃນເວລາລ່ວງເລີຍ** — ຄວາມຊັກຊ້າຈາກການປັບສົມດຸນຈາກ MS Project ເປັນນາທີ, ແລະ ວ່າມັນນັບເປັນເວລາຕໍ່ເນື່ອງ ຫຼື ບໍ່.
- **ກຳນົດເວລາດ້ວຍຕົນເອງ** — ວ່າໜ້າວຽກຖືກກຳນົດເວລາດ້ວຍຕົນເອງ ຫຼື ບໍ່.
- **ປະເພດໜ້າວຽກ MS Project (ນຳເຂົ້າ)** ແລະ **ຂຶ້ນກັບປະລິມານວຽກ** — ປະເພດໜ້າວຽກ ແລະ ທຸງຂຶ້ນກັບປະລິມານວຽກ ຕາມທີ່ MS Project ມີ.
- **ຂໍ້ມູນຕົ້ນທາງ Primavera P6** — ຂໍ້ມູນຕົ້ນທາງຈາກໄຟລ໌ Primavera, ເປັນ `key: value`.
- **ໜ້າວຽກຫຼັກແບບຊັດເຈນ** — ວ່າໜ້າວຽກເປັນໜ້າວຽກຫຼັກແບບຊັດເຈນທີ່ບໍ່ມີໜ້າວຽກຍ່ອຍ ຫຼື ບໍ່ (ຈາກໄຟລ໌ Primavera).
- **ຂັ້ນຕ່ຳວັນສິ້ນສຸດຕາມເວລາ**, **ຈຸດຍຶດວັນເລີ່ມຕາມເວລາ**, **ສ່ວນໄລຍະເວລາຕາມເວລາ** ແລະ **ຮູບແບບການກະຈາຍຕາມເວລາ** — ການກະຈາຍຊົ່ວໂມງຈາກໄຟລ໌ MS Project, ເປັນວັນທີ ແລະ ຈຳນວນ.
- **ຂໍ້ມູນລະຫັດກິດຈະກຳ**, **ຂໍ້ມູນຊ່ອງກຳນົດເອງ** ແລະ **ຂໍ້ມູນໝາຍເຫດ** — ຈຳນວນການມອບລະຫັດ, ຊ່ອງກຳນົດເອງ ແລະ ໝາຍເຫດ.
- **ຂໍ້ມູນສາຍສຳພັນພາຍໃນ** ແລະ **ຂໍ້ມູນສາຍສຳພັນພາຍນອກ** — ຈຳນວນສາຍສຳພັນພາຍໃນ ແລະ ພາຍນອກ.
- ຂອງແຕ່ລະແຜນຫຼັກ **ຫຼັກໝາຍ** ແລະ **ປະເພດຫຼັກໝາຍ** ແມ່ນຢູ່ບ່ອນນີ້ເຊັ່ນກັນ, ຕາມທີ່ແຜນຫຼັກບັນທຶກໄວ້.
