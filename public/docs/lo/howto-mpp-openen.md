# ການເປີດໄຟລ໌ MS Project (.mpp)

ເປົ້າໝາຍ: ເປີດແຜນງານຈາກ Microsoft Project ໂດຍກົງໃນແອັບ, ໂດຍບໍ່ຕ້ອງສົ່ງອອກກ່ອນ.

## ເມື່ອທ່ານຕ້ອງການ

ຜູ້ຮັບເໝົາ, ທີ່ປຶກສາ ຫຼື ລູກຄ້າສົ່ງແຜນງານຂອງເຂົາເຈົ້າໃຫ້ທ່ານເປັນໄຟລ໌ `.mpp`. ທ່ານຕ້ອງການເບິ່ງ, ຄິດໄລ່ ຫຼື ພັດທະນາຕໍ່. ແອັບອ່ານໄຟລ໌ `.mpp` ຈາກ MS Project 2010 ຈົນຮອດ 2021 ລວມ. ມັນອ່ານຢ່າງດຽວ: ມັນບໍ່ຂຽນ `.mpp` ແລະ ບໍ່ປ່ຽນແປງໄຟລ໌ຂອງທ່ານເລີຍ. ຈາກໄຟລ໌, ມັນເອົາແຜນງານເອງ: ໜ້າວຽກພ້ອມໂຄງສ້າງ, ໄລຍະເວລາ ແລະ ເງື່ອນໄຂ, ສາຍສຳພັນພ້ອມຄ່າ Lag, ປະຕິທິນ, ຊັບພະຍາກອນ, ການມອບໝາຍ ແລະ ຄວາມຄືບໜ້າ. ມັນຍັງອ່ານວັນທີ ແລະ float ທີ່ MS Project ຄິດໄລ່ເອງ, ແຕ່ໃຊ້ພຽງແຕ່ສຳລັບມຸມມອງ *ວັນທີຕາມທີ່ບັນທຶກ*, ບໍ່ເຄີຍໃຊ້ເປັນຂໍ້ມູນນຳເຂົ້າ.

## ຂັ້ນຕອນ

1. ເລືອກ *ໜ້າຫຼັກ › ໄຟລ໌ › ເປີດ* ຫຼື ກົດ Ctrl+O. ເລືອກໄຟລ໌ `.mpp`.
2. ໂຄງການເປີດໃນແຖບໃໝ່, ຫຼື ໃນແຖບປັດຈຸບັນ ຖ້າແຖບນັ້ນຍັງຫວ່າງ ແລະ ບໍ່ໄດ້ປ່ຽນແປງ. ໂຄງການນີ້ບໍ່ມີໄຟລ໌. *ບັນທຶກ* ໃນພາຍຫຼັງຈະຂຽນໄຟລ໌ IFC ໃໝ່. ຫຼັງຈາກນັ້ນ ກ່ອງໂຕ້ຕອບໜຶ່ງຈະອະທິບາຍສັ້ນໆວ່າແອັບໄດ້ຮັບເອົາຫຍັງຈາກໄຟລ໌ ແລະ ການບັນທຶກເຮັດວຽກແນວໃດ. ເບິ່ງ [ການເປີດ ແລະ ການບັນທຶກໄຟລ໌](docs://howto-bestand-openen-en-opslaan).
3. ອ່ານຂໍ້ຄວາມດ້ານລຸ່ມ: *ໂຄງການນີ້ຄິດໄລ່ຕາມໂປຣໄຟລ໌ Microsoft Project. ປ່ຽນແປງໄດ້ທີ່ ໄຟລ໌ → ຂໍ້ມູນໂຄງການ → ໂປຣໄຟລ໌ການຄິດໄລ່ ແລະ ຕົວເລືອກ.* ແອັບຄິດໄລ່ໂຄງການນີ້ດ້ວຍກົດລະບຽບການຄິດໄລ່ຂອງ MS Project: ໂປຣໄຟລ໌ການຄິດໄລ່ *Microsoft Project*. ດ້ວຍ *ເປີດໂປຣໄຟລ໌ການຄິດໄລ່* ທ່ານໄປຫາການຕັ້ງຄ່າ. *ອ່ານເພີ່ມເຕີມ* ເປີດຄູ່ມືຊ່ວຍເຫຼືອກ່ຽວກັບໂປຣໄຟລ໌ການຄິດໄລ່.
4. ກວດເບິ່ງວ່າມີແຖບຂໍ້ຄວາມຢູ່ລຸ່ມແຖບເຄື່ອງມືຫຼືບໍ່: *ທ່ານກຳລັງເບິ່ງວັນທີຕາມທີ່ບັນທຶກໄວ້ໃນໄຟລ໌; ການຄິດໄລ່ຄືນໃໝ່ຈະເຮັດໃຫ້ 4 ໜ້າວຽກຖືກຍ້າຍ.* ຫຼັງຈາກນັ້ນ, ໃນໜ້າວຽກເຫຼົ່ານັ້ນ ຜົນຂອງແອັບແຕກຕ່າງຈາກວັນທີທີ່ MS Project ບັນທຶກໄວ້. ຢູ່ດ້ານລຸ່ມຂໍ້ຄວາມຈາກຂັ້ນຕອນ 3 ຍັງມີແຖວໜຶ່ງນຳອີກ: *4 ໜ້າວຽກສະແດງວັນທີຕາມທີ່ບັນທຶກໃນໄຟລ໌ (ບໍ່ໄດ້ຄິດໄລ່ຄືນໃໝ່).* ຄວາມໝາຍຂອງສິ່ງນີ້ ແລະ ວິທີສະຫຼັບໄປຄິດໄລ່ແບບຂອງແອັບ ຢູ່ໃນ [ວັນທີຕາມທີ່ບັນທຶກ](docs://uitleg-datums-zoals-opgeslagen).
5. ຖ້າມີຂໍ້ຄວາມ *ໄຟລ໌ນີ້ມີການວາງແຜນແບບລາຍຊົ່ວໂມງ.* ພ້ອມປຸ່ມ *ເປີດໃຊ້ການວາງແຜນລາຍຊົ່ວໂມງ*, ໄຟລ໌ນັ້ນມີຂໍ້ມູນເປັນຊົ່ວໂມງ. ເບິ່ງ [ການເປີດໃຊ້ການວາງແຜນລາຍຊົ່ວໂມງ](docs://howto-urenplanning-aanzetten).

ຖ້າໄຟລ໌ມີໜ້າວຽກທີ່ແບ່ງຊ່ວງ, ການປັບສົມດຸນ ຫຼື ແຜນງານທີ່ຂັບເຄື່ອນດ້ວຍຊັບພະຍາກອນ, ຈະມີຂໍ້ຄວາມເພີ່ມອີກໜຶ່ງ ເຊັ່ນ *ໄຟລ໌ MS Project ນີ້ມີ 3 ໜ້າວຽກທີ່ຖືກແບ່ງຊ່ວງ, ປັບສົມດຸນຊັບພະຍາກອນ ຫຼື ຂັບເຄື່ອນດ້ວຍຊັບພະຍາກອນ. ລະບົບໄດ້ນຳເຂົ້າ ແລະ ສະແດງຜົນຕາມນັ້ນ.* ຖ້າມີພຽງໜ້າວຽກດຽວ ຂໍ້ຄວາມຈະໃຊ້ຮູບແບບສຳລັບໜ້າວຽກດຽວ.

## ບັນຫາທີ່ອາດເກີດ ແລະ ແອັບເຮັດຫຍັງ

**ບໍ່ແມ່ນທຸກຢ່າງຈະຕິດມາ.** ຫຼັງຈາກເປີດ, ແອັບບອກທ່ານໃນຂໍ້ຄວາມດຽວວ່າມີຫຍັງທີ່ມັນບໍ່ໄດ້ຮັບເອົາ: *ບໍ່ແມ່ນທຸກຢ່າງໃນໄຟລ໌ MS Project ນີ້ຖືກນຳເຂົ້າ.* ດ້ານລຸ່ມມີໜຶ່ງແຖວຕໍ່ລາຍການ ພ້ອມຈຳນວນ, ຕົວຢ່າງ *2 ແຜນຫຼັກບໍ່ໄດ້ຖືກນຳເຂົ້າ.* ສຳລັບ `.mpp`, ປະໂຫຍກກ່ຽວກັບໂປຣໄຟລ໌ການຄິດໄລ່ຈາກຂັ້ນຕອນ 3 ຈະເປັນແຖວທຳອິດຂອງຂໍ້ຄວາມນີ້. ຂໍ້ຄວາມຈະຢູ່ຈົນກວ່າທ່ານຈະກົດປຸ່ມປິດ (×). ຖ້າບໍ່ມີຫຍັງສູນເສຍ ທ່ານຈະບໍ່ເຫັນຂໍ້ຄວາມນີ້. ແຖວໜຶ່ງອາດກ່ຽວກັບ:

- ໂຄງການແຊກເຂົ້າ (ໂຄງການຍ່ອຍ): ແອັບອ່ານເປັນໜ້າວຽກປົກກະຕິ, ໂດຍບໍ່ມີການເຊື່ອມໂຍງກັບໄຟລ໌ອື່ນ;
- ໜ້າວຽກພາຍນອກຈາກໂຄງການອື່ນ: ແອັບອ່ານເປັນໜ້າວຽກປົກກະຕິ;
- ແຜນຫຼັກ: ຈາກ `.mpp` ແອັບບໍ່ຮັບເອົາແຜນຫຼັກໃດໆ, ຈາກ XML ຂອງ MS Project ພຽງແຕ່ແຜນຫຼັກ 0 ຂອງໜ້າວຽກ, ແລະໃນນັ້ນພຽງແຕ່ວັນທີ ແລະ ໄລຍະເວລາ (ສຳລັບໜ້າວຽກເປັນຊົ່ວໂມງ ກໍລວມເວລາດ້ວຍ; ບໍ່ແມ່ນປະລິມານວຽກ ແລະ ຕົ້ນທຶນ, ແລະ ບໍ່ມີແຜນຫຼັກຂອງຊັບພະຍາກອນ ແລະ ການມອບໝາຍ);
- ດ້ວຍ XML ຂອງ MS Project: ການມອບໝາຍທີ່ມີແຜນຫຼັກທີ່ວັນທີຕ່າງຈາກໜ້າວຽກຂອງມັນ. ແອັບຮັກສາໄວ້ພຽງແຜນຫຼັກຂອງໜ້າວຽກ; ຖ້າວັນທີຄືກັນ ບໍ່ມີຫຍັງສູນເສຍ ແລະ ແອັບບໍ່ແຈ້ງຫຍັງ. ເວລາທີ່ຕ່າງກັນໃນມື້ດຽວກັນກໍນັບວ່າເປັນຄວາມແຕກຕ່າງເຊັ່ນກັນ;
- ຊ່ອງກຳນົດເອງທີ່ມີຄ່າ, ເຊັ່ນ ຊ່ອງກຳນົດເອງ, ຄ່າຈາກຕາຕະລາງຄ່າ ແລະ ລະຫັດໂຄງຮ່າງ (ແອັບບໍ່ນັບຊ່ອງແບບ ແມ່ນ/ບໍ່ແມ່ນ ໃນ `.mpp`);
- ໝາຍເຫດ (ລວມທັງໝາຍເຫດທີ່ມີແຕ່ຮູບ) ຂອງຊັບພະຍາກອນ ແລະ ການມອບໝາຍ, ແລະ ຈາກ `.mpp` ກໍລວມຂອງໜ້າວຽກ (ຈາກ XML ຂອງ MS Project ໝາຍເຫດຂອງໜ້າວຽກຕິດມາເປັນຄຳອະທິບາຍຂອງມັນ);
- ການເຊື່ອມຕໍ່ໄປຍັງບ່ອນອື່ນ;
- ຕົ້ນທຶນຄົງທີ່ຂອງໜ້າວຽກ;
- ອັດຕາຄ່າໃຊ້ຈ່າຍຂອງຊັບພະຍາກອນ: ຈາກ `.mpp` ບໍ່ມີອັດຕາເລີຍ, ຈາກ XML ຂອງ MS Project ພຽງແຕ່ອັດຕາມາດຕະຖານ;
- ພຽງແຕ່ກັບ XML ຂອງ MS Project: ໜ້າວຽກທີ່ກຳນົດເວລາດ້ວຍຕົນເອງ (ແອັບຄິດໄລ່ວັນທີໃຫ້ອັດຕະໂນມັດ), ໜ້າວຽກທີ່ບໍ່ເຄື່ອນໄຫວ (ລວມຢູ່ໃນການຄິດໄລ່) ແລະ ຄວາມຊັກຊ້າຈາກການປັບສົມດຸນ;
- ພຽງແຕ່ກັບ `.mpp`: ເກນກຳນົດວິກິດຈາກ MS Project; ແອັບໃຊ້ເກນກຳນົດ 0.

ລະຫັດ WBS ທີ່ທ່ານໃສ່ເອງໃນ MS Project ຈະຖືກຮັບເອົາ; ຖ້າບໍ່ດັ່ງນັ້ນ ແອັບຈະໃສ່ເລກໃຫ້ໜ້າວຽກຕາມໂຄງສ້າງ.

**ໄຟລ໌ຈາກ MS Project 2007 ຫຼື ເກົ່າກວ່າ.** ແອັບປະຕິເສດມັນ ແລະ ແຈ້ງ: *ໄຟລ໌ .mpp ນີ້ໃຊ້ຮູບແບບເກົ່າ (Project 2007 ຫຼື ເກົ່າກວ່າ). ໃນ MS Project, ໃຫ້ສົ່ງອອກເປັນ XML (File → Save As → XML) ແລ້ວເປີດໄຟລ໌ນັ້ນແທນ.* ຢູ່ດ້ານລຸ່ມຂໍ້ຄວາມ ແອັບເພີ່ມເຫດຜົນທາງເທັກນິກເປັນພາສາອັງກິດ.

**ໄຟລ໌ທີ່ມີລະຫັດຜ່ານ.** ແອັບແຈ້ງ: *ໄຟລ໌ .mpp ນີ້ຖືກປ້ອງກັນດ້ວຍລະຫັດຜ່ານ. ໃນ MS Project, ໃຫ້ສົ່ງອອກເປັນ XML (File → Save As → XML) ແລ້ວເປີດໄຟລ໌ນັ້ນແທນ.* ບ່ອນນີ້ກໍເຊັ່ນກັນ ຂໍ້ຄວາມມາພ້ອມເຫດຜົນທາງເທັກນິກເປັນພາສາອັງກິດ.

**ໄຟລ໌ທີ່ປາກົດວ່າບໍ່ແມ່ນ `.mpp`.** ທ່ານຈະເຫັນ *ບໍ່ສາມາດເປີດໄຟລ໌ໄດ້* ພ້ອມເຫດຜົນທາງເທັກນິກ.

**ເສັ້ນທາງ XML ຄິດໄລ່ຕ່າງກັນ.** ຖ້າທ່ານເປີດການສົ່ງອອກ XML ຂອງ MS Project ແທນ `.mpp`, ແອັບຄິດໄລ່ດ້ວຍໂປຣໄຟລ໌ການຄິດໄລ່ *Open Planner Studio* ແລະ ທ່ານຈະບໍ່ເຫັນຂໍ້ຄວາມກ່ຽວກັບ *Microsoft Project*. ວັນທີອາດອອກມາຕ່າງຈາກໄຟລ໌ `.mpp`. ແມ່ນແຕ່ກັບການສົ່ງອອກ XML, ແອັບກໍບອກທ່ານວ່າມີຫຍັງທີ່ມັນບໍ່ໄດ້ຮັບເອົາ; ເບິ່ງ *ບໍ່ແມ່ນທຸກຢ່າງຈະຕິດມາ*.

**ການແກ້ໄຂເຮັດໃຫ້ MS Project ບໍ່ຄວບຄຸມອີກຕໍ່ໄປ.** ຖ້າທ່ານແກ້ໄຂໜ້າວຽກທີ່ການວາງແຜນຖືກຄວບຄຸມໂດຍຊ່ວງວັນທີຂອງ MS Project, ແອັບຈະແຈ້ງໜຶ່ງຄັ້ງຕໍ່ໂຄງການ: *ຊ່ວງວັນທີຂອງ MS Project ບໍ່ໄດ້ກຳນົດ 2 ໜ້າວຽກອີກຕໍ່ໄປຫຼັງຈາກການແກ້ໄຂນີ້; ແຕ່ການກະຈາຍຊົ່ວໂມງຍັງຄົງມີຜົນ ແລະ ຖືກບັນທຶກໄວ້ໃນໄຟລ໌.* ສຳລັບໜ້າວຽກດຽວ ຂໍ້ຄວາມຈະໃຊ້ຮູບແບບສຳລັບໜ້າວຽກດຽວ.

**ການບັນທຶກບໍ່ເຄີຍຂຽນທັບ `.mpp` ຂອງທ່ານ.** ໂຄງການບໍ່ມີໄຟລ໌. *ບັນທຶກ* ຈະຖາມວ່າໄຟລ໌ IFC ໃໝ່ຄວນໄປໄວ້ໃສ.
