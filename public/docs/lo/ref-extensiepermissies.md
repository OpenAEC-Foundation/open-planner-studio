# ສິດອະນຸຍາດຂອງສ່ວນເສີມ

ທຸກສິດອະນຸຍາດທີ່ສ່ວນເສີມອາດລະບຸໃນ manifest ຂອງມັນ: ສິ່ງທີ່ອະນຸຍາດ, ສິ່ງທີ່ເກີດຂຶ້ນເມື່ອບໍ່ມີສິດນັ້ນ ແລະ ສິ່ງທີ່ທ່ານເຫັນເມື່ອຕິດຕັ້ງສ່ວນເສີມ. ວິທີຈັດການ ແລະ ຕິດຕັ້ງສ່ວນເສີມຢູ່ໃນ [ການຕິດຕັ້ງ ແລະ ຈັດການສ່ວນເສີມ](docs://howto-extensie-installeren).

## ສິດອະນຸຍາດແມ່ນຫຍັງ ແລະ ບໍ່ແມ່ນຫຍັງ

ສິດອະນຸຍາດແມ່ນ **ຄຳປະກາດຂອງຜູ້ພັດທະນາ**: ສ່ວນໃດຂອງສ່ວນຕິດຕໍ່ແອັບທີ່ສ່ວນເສີມຕ້ອງການໃຊ້. ມັນບໍ່ແມ່ນກຳແພງກັ້ນ. ໂຄດຂອງສ່ວນເສີມເຮັດວຽກໃນສະພາບແວດລ້ອມດຽວກັນກັບແອັບເອງ, ດັ່ງນັ້ນມັນອາດເຮັດຫຼາຍກວ່າສິດທີ່ລະບຸ. ບໍ່ມີການແຍກສະພາບແວດລ້ອມ (sandbox). ແອັບບອກເລື່ອງນີ້ໃນໜ້າຕ່າງຕິດຕັ້ງເຊັ່ນກັນ. ຕິດຕັ້ງພຽງສ່ວນເສີມຈາກຜູ້ພັດທະນາທີ່ທ່ານໄວ້ໃຈເທົ່ານັ້ນ.

ແອັບບັງຄັບໃຊ້ສິດອະນຸຍາດໄດ້ສາມວິທີ ແລະ ຄວາມແຕກຕ່າງນັ້ນສຳຄັນ:

**ບັງຄັບໃຊ້ເດັດຂາດ.** ຖ້າບໍ່ມີສິດອະນຸຍາດ ວິທີທີ່ກ່ຽວຂ້ອງຈະສົ່ງຂໍ້ຜິດພາດ ກ່ອນທີ່ຈະມີຫຍັງເກີດຂຶ້ນ (ເປັນພາສາດັດ ຕົວຢ່າງ *Extensie "…" mist permissie: ribbon*).

**ເຕືອນ.** ຖ້າບໍ່ມີສິດອະນຸຍາດ ວິທີນັ້ນຍັງເຮັດວຽກໄດ້, ແຕ່ແອັບຂຽນຄຳເຕືອນລົງບັນທຶກເຫດການ (log). ໃນເວີຊັນໃໝ່ໃນອະນາຄົດ ມັນຈະກາຍເປັນການປະຕິເສດ.

**ສະແດງຂໍ້ມູນເທົ່ານັ້ນ.** ສິດອະນຸຍາດນີ້ບໍ່ໄດ້ຜູກກັບສ່ວນໃດຂອງສ່ວນຕິດຕໍ່. ແອັບສະແດງມັນຕອນຕິດຕັ້ງ ແລະ ບໍ່ເຮັດຫຍັງອີກກັບມັນ.

ສິ່ງທີ່ບໍ່ຕ້ອງການສິດອະນຸຍາດ ເປັນພື້ນຖານຂອງສ່ວນຕິດຕໍ່ຂອງສ່ວນເສີມ: ອ່ານໂຄງການ, ປະຕິທິນ, ໜ້າວຽກ, ສາຍສຳພັນ, ຊັບພະຍາກອນ ແລະ ການມອບໝາຍ; ເພີ່ມ ແລະ ປ່ຽນໜ້າວຽກ ແລະ ສາຍສຳພັນ; ໂຫຼດໂຄງການ, ຄິດໄລ່ຄືນໃໝ່ ແລະ ລວມຫຼາຍການປ່ຽນແປງເປັນຊຸດດຽວ; ເກັບການຕັ້ງຄ່າຂອງຕົນເອງ, ອ່ານໄຟລ໌ທີ່ມາພ້ອມຂອງຕົນເອງ ແລະ ສະແດງການແຈ້ງເຕືອນ.

**ໄຟລ໌ manifest.** ສິດອະນຸຍາດຢູ່ໃນ manifest ເປັນລາຍການ. ສ່ວນເສີມທີ່ທ່ານຕິດຕັ້ງດຽວນີ້ ຖ້າມີສິດທີ່ເວີຊັນແອັບນີ້ບໍ່ຮູ້ຈັກ ຈະຖືກປະຕິເສດ. ສຳລັບສ່ວນເສີມເກົ່າທີ່ເກັບໄວ້ແລ້ວ ແອັບຕັດສິດທີ່ບໍ່ຮູ້ຈັກອອກ ແລະ ແຈ້ງໃນບັນທຶກເຫດການ.

## ແອັບຖາມແນວໃດ

ຕອນຕິດຕັ້ງ ຈາກລາຍການ (*ໄຟລ໌ › ສ່ວນເສີມ › ຄົ້ນຫາ › ຕິດຕັ້ງ*) ຫຼື ຈາກໄຟລ໌ (*ZIP* ຫຼື *JS*), ແອັບສະແດງໜ້າຕ່າງ *ຕິດຕັ້ງສ່ວນເສີມຫຼືບໍ່?*. ຄຳຖາມນີ້ມາພຽງຄັ້ງດຽວ ຕອນຕິດຕັ້ງ: ບໍ່ແມ່ນທຸກຄັ້ງທີ່ທ່ານເປີດສ່ວນເສີມ.

ໜ້າຕ່າງສະແດງຊື່, ເວີຊັນ, ຄຳອະທິບາຍ, ຜູ້ພັດທະນາ ແລະ ທີ່ເກັບໂຄດ (repository) ຖ້າມີ. ພາຍໃຕ້ *ແຫຼ່ງທີ່ມາ* ມັນບອກວ່າສ່ວນເສີມມາຈາກໃສ (*ຈາກລາຍການສ່ວນເສີມອອນລາຍ*, *ຈາກໄຟລ໌ ZIP ໃນເຄື່ອງນີ້* ຫຼື *ຈາກໄຟລ໌ JavaScript ໃນເຄື່ອງນີ້*) ແລະ ວ່າການດາວໂຫຼດຖືກກວດສອບແລ້ວຫຼືບໍ່: ດ້ວຍ checksum ຈາກລາຍການ, ບໍ່ໄດ້ກວດສອບ ເພາະລາຍການບໍ່ໃຫ້ checksum, ຫຼື ເປັນໄຟລ໌ທີ່ທ່ານເລືອກເອງ. ພາຍໃຕ້ *ຂໍ້ຕົກລົງທີ່ທ່ານຍິນຍອມ* ມັນບອກວ່າສ່ວນເສີມເປັນໂຄດໂປຣແກຣມທີ່ເຮັດວຽກດ້ວຍສິດດຽວກັນກັບແອັບ ແລະ ໝາຍເຖິງຫຍັງໃນທາງປະຕິບັດ: ໃນແອັບເດັສທັອບ ລວມທັງອ່ານ ແລະ ຂຽນໄຟລ໌ຢູ່ບ່ອນໃດກໍໄດ້ໃນໂຟນເດີຜູ້ໃຊ້ຂອງທ່ານ ພ້ອມການເຂົ້າເຖິງໂຄງການ, ການຕັ້ງຄ່າ ແລະ ຄລິບບອດຂອງທ່ານ; ໃນບຣາວເຊີ ການເຂົ້າເຖິງໂຄງການ ແລະ ການຕັ້ງຄ່າທີ່ເກັບໄວ້, ໄຟລ໌ທີ່ທ່ານອະນຸຍາດໃຫ້ເຂົ້າເຖິງ ແລະ ເຄືອຂ່າຍ.

ພາຍໃຕ້ *ສິ່ງທີ່ສ່ວນເສີມນີ້ແຈ້ງວ່າຈະໃຊ້* ແມ່ນສິດອະນຸຍາດຈາກ manifest ເປັນປ້າຍສັ້ນໆ ພ້ອມຊື່ດັ່ງດ້ານລຸ່ມ. ມັນບອກວ່າ *ນີ້ແມ່ນຂໍ້ຄວາມແຈ້ງຈາກຜູ້ພັດທະນາ ເຊິ່ງບໍ່ແມ່ນການຈຳກັດສິດ — ຕົວໂຄດຕົວຈິງອາດເຮັດວຽກຫຼາຍກວ່ານັ້ນໄດ້*. ຖ້າສ່ວນເສີມບໍ່ມີສິດອະນຸຍາດ ມັນບອກວ່າ *ບໍ່ມີການແຈ້ງການໃຊ້ງານໃດໆ*. ສິດອະນຸຍາດສອງຢ່າງມີຄຳອະທິບາຍ: *importSource* ແລະ *help*. ອີກຫົກຢ່າງມີພຽງປ້າຍຂອງມັນເທົ່ານັ້ນ.

ດ້ວຍ *ຕິດຕັ້ງ* ທ່ານຍິນຍອມ. *ບໍ່ຕິດຕັ້ງ*, Esc ແລະ ການຄລິກນອກໜ້າຕ່າງ ປະຕິເສດການຕິດຕັ້ງ.

## ສິດອະນຸຍາດແຕ່ລະຢ່າງ

**ribbon** — ວາງປຸ່ມໃນແຖບເຄື່ອງມື. ຜົນ: ສ່ວນເສີມອາດເພີ່ມປຸ່ມເຂົ້າໃນກຸ່ມຂອງແທັບໃດໜຶ່ງ. ສ່ວນເສີມທີ່ບໍ່ມີສິດນີ້ຈະໄດ້ຂໍ້ຜິດພາດເມື່ອພະຍາຍາມ. ປຸ່ມຈະປາກົດຢູ່ທ້າຍແທັບທີ່ເລືອກ, ພາຍໃຕ້ປ້າຍກຸ່ມຂອງສ່ວນເສີມ, ແລະ ຫາຍໄປເມື່ອທ່ານປິດສ່ວນເສີມ ຫຼື ລຶບມັນ. ຄ່າເລີ່ມຕົ້ນ: ບໍ່ໄດ້ຮັບອະນຸຍາດ; ມີພຽງສິ່ງທີ່ຢູ່ໃນ manifest. ບັງຄັບໃຊ້: ເດັດຂາດ. ຢູ່ໃສ: ໃນແທັບທີ່ສ່ວນເສີມເລືອກ.

**events** — ຕິດຕາມເຫດການຂອງແອັບ ແລະ ສົ່ງເຫດການເອງ. ຜົນ: ສ່ວນເສີມອາດລົງທະບຽນ ແລະ ຍົກເລີກການຮັບເຫດການ ແລະ ສົ່ງເຫດການເອງ. ແອັບສົ່ງເອງສີ່ຢ່າງ: ໂຄງການຖືກໂຫຼດ (ຫຼັງນຳເຂົ້າ, ເປີດ ຫຼື ໂຫຼດໂດຍສ່ວນເສີມ), ໂຄງການເປົ່າຖືກສ້າງ, ແຜນງານຖືກຄິດໄລ່ຄືນໃໝ່ ແລະ ຜູ້ໃຊ້ຂໍບົດຮຽນແນະນຳ. ເຫດການສຸດທ້າຍນີ້ໄປພຽງສ່ວນເສີມບົດຮຽນແນະນຳເທົ່ານັ້ນ. ຄ່າເລີ່ມຕົ້ນ: ບໍ່ໄດ້ຮັບອະນຸຍາດ; ມີພຽງສິ່ງທີ່ຢູ່ໃນ manifest. ບັງຄັບໃຊ້: ເດັດຂາດ. ຢູ່ໃສ: ບໍ່ມີບ່ອນ; ສ່ວນເສີມຕອບສະໜອງຕໍ່ເຫດການ.

**backstage** — ສະເໜີຮູບແບບນຳເຂົ້າ. ຜົນ: ສ່ວນເສີມອາດລົງທະບຽນຕົວນຳເຂົ້າ; ມັນຈະປາກົດໃນ *ໄຟລ໌ › ນຳເຂົ້າ*, ບ່ອນທີ່ທ່ານຄລິກຮູບແບບ ແລ້ວເລືອກໄຟລ໌. ຮູບແບບທີ່ແອັບມີມາໃນຕົວແຍກຕ່າງຫາກຈາກອັນນີ້ (ເບິ່ງ [ຮູບແບບນຳເຂົ້າ ແລະ ສົ່ງອອກ](docs://ref-import-exportformaten)). ຄ່າເລີ່ມຕົ້ນ: ບໍ່ໄດ້ຮັບອະນຸຍາດ; ມີພຽງສິ່ງທີ່ຢູ່ໃນ manifest. ບັງຄັບໃຊ້: ເຕືອນ. ຖ້າບໍ່ມີສິດນີ້ ການລົງທະບຽນຍັງເຮັດວຽກໄດ້, ພ້ອມຄຳເຕືອນໃນບັນທຶກເຫດການ. ນີ້ແມ່ນການຈັດການຊົ່ວຄາວ ເພາະສ່ວນເສີມທີ່ມີຢູ່ແລ້ວບໍ່ໄດ້ລະບຸສິດນີ້ສະເໝີ. ຢູ່ໃສ: *ໄຟລ໌ › ນຳເຂົ້າ*.

**pdf-fonts** — ໃຫ້ຟອນສຳລັບການສົ່ງອອກ PDF. ຜົນ: ສ່ວນເສີມອາດລົງທະບຽນຜູ້ໃຫ້ຟອນ. ການສົ່ງອອກ PDF ໃຊ້ມັນສຳລັບຕົວອັກສອນທີ່ຟອນໃນຕົວບໍ່ຄອບຄຸມ ເຊັ່ນ ຕົວອັກສອນຈີນ, ຍີ່ປຸ່ນ ແລະ ເກົາຫຼີ. ຄ່າເລີ່ມຕົ້ນ: ບໍ່ໄດ້ຮັບອະນຸຍາດ; ມີພຽງສິ່ງທີ່ຢູ່ໃນ manifest. ບັງຄັບໃຊ້: ເດັດຂາດ. ຢູ່ໃສ: ໃນ PDF ຂອງລາຍງານ; ໃນໜ້າຕ່າງຕິດຕັ້ງມີພຽງປ້າຍເທົ່ານັ້ນ.

**importSource** — ອ່ານໄບຕ໌ຕົ້ນສະບັບຂອງໄຟລ໌ທີ່ນຳເຂົ້າ. ຜົນ: ສ່ວນເສີມອາດຂໍເນື້ອຫາທັງໝົດຂອງໄຟລ໌ຕົ້ນທາງຂອງໂຄງການທີ່ນຳເຂົ້າ (ໃນຕອນນີ້: ໄຟລ໌ Primavera), ລວມທັງຟິລດ໌ທີ່ແອັບຕັ້ງໃຈບໍ່ນຳເຂົ້າສູ່ໂຄງການ ເຊັ່ນ ຟິລດ໌ການກວດສອບ ແລະ ແຫຼ່ງທີ່ມາ, ຕົ້ນທຶນ, ຟິລດ໌ການທົບທວນ ແລະ ສະຖານທີ່. ນີ້ກວ້າງກວ່າສ່ວນອື່ນຂອງສ່ວນຕິດຕໍ່ຫຼາຍ ດັ່ງນັ້ນມັນເປັນສິດແຍກຕ່າງຫາກ. ຖ້າບໍ່ມີສິດນີ້ ແອັບຈະບໍ່ອ່ານແມ່ນແຕ່ໄບຕ໌ດຽວຂອງໄຟລ໌ຕົ້ນທາງ: ທຸກວິທີຈະສົ່ງຂໍ້ຜິດພາດ ກ່ອນທີ່ຈະດຶງຂໍ້ມູນ. ຄ່າເລີ່ມຕົ້ນ: ບໍ່ໄດ້ຮັບອະນຸຍາດ; ມີພຽງສິ່ງທີ່ຢູ່ໃນ manifest. ບັງຄັບໃຊ້: ເດັດຂາດ, ປະຕິເສດເປັນຄ່າເລີ່ມຕົ້ນ. ຢູ່ໃສ: ໃນໜ້າຕ່າງຕິດຕັ້ງ ມີຄຳອະທິບາຍນຳ: *importSource — ຂໍ້ມູນຕົ້ນສະບັບທັງໝົດຂອງທຸກໄຟລ໌ທີ່ນຳເຂົ້າ (ເຊັ່ນ: ໄຟລ໌ດິບຂອງ Primavera), ລວມທັງຟິລດ໌ທີ່ບໍ່ໄດ້ນຳເຂົ້າສູ່ໂຄງການ*.

**help** — ເພີ່ມບົດຄວາມວິທີໃຊ້ ແລະ ຄຳແນະນຳ. ຜົນ: ສ່ວນເສີມອາດລົງທະບຽນ ແລະ ຖອນບົດຄວາມວິທີໃຊ້ (ບົດຮຽນແນະນຳ), ເປີດໄຟລ໌ `.ifc` ທີ່ມາພ້ອມເປັນເອກະສານໃໝ່ ແລະ ເລີ່ມ ແລະ ຢຸດຄູ່ມືທີ່ຊີ້ໄປຍັງສ່ວນຕ່າງໆຂອງແອັບ. ໂຄງການທີ່ມາພ້ອມບໍ່ເຄີຍທັບເອກະສານທີ່ທ່ານກຳລັງເຮັດວຽກຢູ່: ມັນເປີດເປັນເອກະສານໃໝ່, ຫຼື ເອົາແທັບທີ່ວ່າງເປົ່າ ແລະ ບໍ່ໄດ້ປ່ຽນແປງເທົ່ານັ້ນ. ນັບແຕ່ເວີຊັນສັນຍາ 1.4.0. ຄ່າເລີ່ມຕົ້ນ: ບໍ່ໄດ້ຮັບອະນຸຍາດ; ມີພຽງສິ່ງທີ່ຢູ່ໃນ manifest. ບັງຄັບໃຊ້: ເດັດຂາດ. ຢູ່ໃສ: ໃນໜ້າຕ່າງ *ຊ່ວຍເຫຼືອ* (ບົດຄວາມ), ເປັນແທັບໃໝ່ (ໂຄງການ) ແລະ ເປັນຄູ່ມືທີ່ຊີ້ໄປຍັງປຸ່ມ. ໃນໜ້າຕ່າງຕິດຕັ້ງມີຄຳອະທິບາຍນຳ: *help — ອາດເພີ່ມບົດຄວາມວິທີໃຊ້, ເປີດໂຄງການທີ່ຕິດມານຳເປັນເອກະສານໃໝ່ ແລະ ສະແດງຄູ່ມືທີ່ຊີ້ບອກສ່ວນຕ່າງໆຂອງແອັບ*.

**filesystem** — ສ່ວນເສີມແຈ້ງວ່າມັນໃຊ້ໄຟລ໌. ຜົນ: ບໍ່ມີ; ບໍ່ມີສ່ວນໃດຂອງສ່ວນຕິດຕໍ່ຜູກກັບມັນ ແລະ ແອັບບັງຄັບໃຊ້ບໍ່ໄດ້. ຄ່າເລີ່ມຕົ້ນ: ບໍ່ໄດ້ຮັບອະນຸຍາດ; ມີພຽງສິ່ງທີ່ຢູ່ໃນ manifest. ບັງຄັບໃຊ້: ສະແດງຂໍ້ມູນເທົ່ານັ້ນ. ຢູ່ໃສ: ເປັນປ້າຍໃນໜ້າຕ່າງຕິດຕັ້ງ.

**network** — ສ່ວນເສີມແຈ້ງວ່າມັນໃຊ້ເຄືອຂ່າຍ. ຜົນ: ບໍ່ມີ; ຄືກັນກັບ *filesystem*. ຄ່າເລີ່ມຕົ້ນ: ບໍ່ໄດ້ຮັບອະນຸຍາດ; ມີພຽງສິ່ງທີ່ຢູ່ໃນ manifest. ບັງຄັບໃຊ້: ສະແດງຂໍ້ມູນເທົ່ານັ້ນ. ຢູ່ໃສ: ເປັນປ້າຍໃນໜ້າຕ່າງຕິດຕັ້ງ.
