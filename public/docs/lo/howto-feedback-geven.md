# ການສົ່ງຄຳຕິຊົມ

ເປົ້າໝາຍ: ແຈ້ງຂໍ້ຜິດພາດ ຫຼື ສະເໜີແນວຄິດ, ຈະແນບຮູບໜ້າຈໍດ້ວຍກໍໄດ້, ໂດຍກົງຈາກແອັບ.

## ເມື່ອທ່ານຕ້ອງການສິ່ງນີ້

ແຜນງານຄິດໄລ່ບາງຢ່າງທີ່ທ່ານບໍ່ເຂົ້າໃຈ, ປຸ່ມບໍ່ເຮັດຕາມທີ່ມັນຄວນເຮັດ, ຫຼືທ່ານພາດບາງຢ່າງໃນແອັບ. ລາຍງານທີ່ດີຊ່ວຍທີມພັດທະນາຊອກຫາບັນຫາ. ນັ້ນແມ່ນເຫດຜົນທີ່ແອັບໃສ່ເວີຊັນ, ລະບົບປະຕິບັດການ ແລະ ພາສາໄວ້ໃນລາຍງານຂອງທ່ານເອງ. ສິ່ງທີ່ທ່ານອະທິບາຍເອງ ກຳນົດວ່າພວກເຂົາຈະດຳເນີນການໄດ້ບໍ່: ທ່ານເຮັດຫຍັງ, ທ່ານຄາດຫວັງຫຍັງ ແລະ ເກີດຫຍັງຂຶ້ນ.

## ຂັ້ນຕອນ

1. ກົດປຸ່ມ *ສົ່ງຄຳຕິຊົມ* ຢູ່ດ້ານເທິງຂອງໜ້າຕ່າງ. ປຸ່ມນັ້ນຢູ່ໃນແຖບຊື່ໜ້າຕ່າງສະເໝີ. ຂໍ້ຄວາມຂອງປຸ່ມປ່ຽນທຸກສິບນາທີ: *ສົ່ງຄຳຕິຊົມ*, *ລາຍງານຂໍ້ຜິດພາດ* ແລະ *ສະເໜີຄຸນສົມບັດໃໝ່*. ມັນເປັນປຸ່ມດຽວກັນສະເໝີ. ໜ້າຕ່າງ *ສົ່ງຄຳຕິຊົມ* ເປີດຂຶ້ນ.
2. ເລືອກປະເພດຂອງຂໍ້ຄວາມແຈ້ງ. *ມີບາງຢ່າງບໍ່ເຮັດວຽກ* ແມ່ນສຳລັບຂໍ້ຜິດພາດ: ມີບາງຢ່າງບໍ່ເຮັດຕາມທີ່ມັນຄວນເຮັດ. *ແນວຄິດ* ແມ່ນສຳລັບສິ່ງທີ່ທ່ານຂາດ ຫຼື ຢາກໃຫ້ເປັນອີກແບບໜຶ່ງ. *ຄຳຖາມ ຫຼື ຄຳເຫັນ* ແມ່ນສຳລັບສິ່ງອື່ນ. *ມີບາງຢ່າງບໍ່ເຮັດວຽກ* ຖືກເລືອກເປັນຄ່າເລີ່ມຕົ້ນ.
3. ຕື່ມ *ຫົວຂໍ້* ແລ້ວຕໍ່ດ້ວຍ *ລາຍລະອຽດ*. ຊ່ອງທີ່ຍັງຫວ່າງສະແດງຕົວຢ່າງ: ຫົວຂໍ້ເຊັ່ນ *ຕົວຢ່າງ: ເສັ້ນທາງວິກິດກະໂດດຫຼັງບັນທຶກ*, ແລະສຳລັບລາຍລະອຽດ ຄຳຖາມ *ທ່ານໄດ້ເຮັດຫຍັງ, ທ່ານຄາດຫວັງຫຍັງ ແລະ ເກີດຫຍັງຂຶ້ນ?*. ຕາບໃດທີ່ປຸ່ມ *ສົ່ງ* ເປັນສີເທົາ, ແຖວສີເທົາຢູ່ຂ້າງມັນຈະບອກເຫດຜົນ, ເຊັ່ນ *ກະລຸນາປ້ອນຫົວຂໍ້.* ຫຼື ວ່າທ່ານຕ້ອງຂຽນຢ່າງໜ້ອຍ 10 ຕົວອັກສອນລວມກັນໃນຫົວຂໍ້ ແລະ ລາຍລະອຽດ.
4. ຖ້າທ່ານຕ້ອງການຄຳຕອບ, ໃຫ້ຕື່ມ *ທີ່ຢູ່ອີເມວ* ຂອງທ່ານ. ຊ່ອງນັ້ນເປັນທາງເລືອກ. ແອັບຈື່ທີ່ຢູ່ນັ້ນຫຼັງຈາກການສົ່ງຂໍ້ຄວາມແຈ້ງສຳເລັດ, ສະນັ້ນມັນຈະຢູ່ແລ້ວຄັ້ງໜ້າ.
5. ຖ້າທ່ານຢາກສະແດງບາງຢ່າງ, ໃຫ້ເປີດ *ແນບຮູບໜ້າຈໍ*. ແອັບຈະຖ່າຍຮູບແອັບໂດຍບໍ່ລວມໜ້າຕ່າງນີ້. ອີກບໍ່ດົນ ທ່ານຈະເຫັນຕົວຢ່າງນ້ອຍໆ ພ້ອມສາມປຸ່ມຢູ່ຂ້າງມັນ: *ຂຽນໝາຍເຫດໃສ່ຮູບ*, *ຖ່າຍໃໝ່* ແລະ *ເອົາອອກ*.
6. *ຂຽນໝາຍເຫດໃສ່ຮູບ* ເປີດຕົວແກ້ໄຂ. ໃນນັ້ນ ທ່ານວາງລູກສອນ, ສີ່ຫຼ່ຽມ, ເສັ້ນມືເປົ່າ ແລະ ຂໍ້ຄວາມໃສ່ຮູບ. ດ້ວຍ *ປົກປິດ* ທ່ານແຕ້ມພື້ນທີ່ສີດຳໃສ່ສິ່ງທີ່ບໍ່ຄວນໄປນຳ, ເຊັ່ນ ຊື່ ຫຼື ຈຳນວນເງິນ. ພາກນັ້ນຈະຫາຍໄປຈາກຮູບທີ່ແອັບສົ່ງແທ້ໆ. ທ່ານເລືອກສີໄດ້, ກັບຄືນການກະທຳສຸດທ້າຍດ້ວຍ *ຍົກເລີກຄຳສັ່ງ* ຫຼື ເລີ່ມໃໝ່ທັງໝົດດ້ວຍ *ລຶບລ້າງທັງໝົດ*. ກົດ *ສຳເລັດ* ເພື່ອເກັບການປ່ຽນແປງ, ຫຼື *ຍົກເລີກ* (ຫຼື Esc) ເພື່ອຖິ້ມມັນ.
7. *ຖ່າຍໃໝ່* ຖ່າຍຮູບໜ້າຈໍໃໝ່ ແລະ ລຶບການຂຽນໝາຍເຫດຂອງທ່ານອອກ. *ເອົາອອກ* ລຶບຮູບໜ້າຈໍອອກ ແລະ ປິດຊ່ອງໝາຍຖືກ.
8. ເບິ່ງແຖວສີເທົາ *ສົ່ງພ້ອມ* ໃຕ້ແບບຟອມ. ມັນສະແດງສິ່ງທີ່ແອັບສົ່ງໄປເອງ: ເວີຊັນ, ລະບົບປະຕິບັດການ ແລະ ພາສາ, ຕົວຢ່າງ *ສົ່ງພ້ອມ: v2026.10.1 · Windows · English*.
9. ກົດ *ສົ່ງ*. ໃນຂະນະທີ່ສົ່ງ, ປຸ່ມຂຽນວ່າ *ກຳລັງສົ່ງ…*.
10. ທ່ານເຫັນ *ຂອບໃຈ, ຂໍ້ຄວາມແຈ້ງຂອງທ່ານຖືກສົ່ງແລ້ວ.* ຖ້າມີ issue ໃນ GitHub ຖືກສ້າງສຳລັບຂໍ້ຄວາມແຈ້ງຂອງທ່ານ, ກໍມີປຸ່ມ *ເບິ່ງໃນ GitHub* ນຳ. ກົດ *ປິດ*.

## ຂໍ້ຄວາມແຈ້ງຂອງທ່ານໄປໃສ

ແອັບສົ່ງຂໍ້ຄວາມແຈ້ງຂອງທ່ານໄປຫາ Open Feedback Studio ໂດຍ OpenAEC. ທ່ານບໍ່ຕ້ອງມີບັນຊີສຳລັບອັນນັ້ນ, ແມ່ນແຕ່ໃນ GitHub. ຜູ້ສ້າງເຫັນຂໍ້ຄວາມແຈ້ງຂອງທ່ານໃນພາບລວມຂອງພວກເຂົາ. ຖ້າແອັບເຊື່ອມກັບ GitHub ຢູ່ບ່ອນນັ້ນ, Open Feedback Studio ຈະປ່ຽນມັນເປັນ issue ສາທາລະນະໃນ GitHub ນຳ. ດ້ວຍ *ມີບາງຢ່າງບໍ່ເຮັດວຽກ* issue ຈະໄດ້ປ້າຍ *bug*, ດ້ວຍ *ແນວຄິດ* ປ້າຍ *enhancement*. ໃຕ້ລາຍລະອຽດຂອງທ່ານ ຈະມີແຖວໜຶ່ງທີ່ມີເວີຊັນຂອງ Open Planner Studio, ລະບົບປະຕິບັດການຂອງທ່ານ ແລະ ພາສາຂອງແອັບ.

## ຂໍ້ຄວນລະວັງ ແລະ ແອັບເຮັດຫຍັງໃນກໍລະນີນັ້ນ

**ຂໍ້ຄວາມແຈ້ງຂອງທ່ານອາດກາຍເປັນສາທາລະນະ.** ຢ່າໃສ່ສິ່ງໃດໆທີ່ທ່ານບໍ່ຢາກແບ່ງປັນ. ນັ້ນຮວມເຖິງຮູບໜ້າຈໍດ້ວຍ: ຮູບສະແດງທຸກສິ່ງທີ່ເຫັນໄດ້ໃນແອັບໃນຕອນນັ້ນ, ເຊັ່ນ ຊື່ໜ້າວຽກ ແລະ ຊັບພະຍາກອນຂອງໂຄງການທ່ານ. ແອັບຖ່າຍຮູບໜ້າຈໍໃນຕອນທີ່ທ່ານເປີດ *ແນບຮູບໜ້າຈໍ*. ຖ້າໜ້າຈໍຍັງບໍ່ຖືກຕ້ອງ, ໃຫ້ປິດໜ້າຕ່າງ, ຕັ້ງໜ້າຈໍໃຫ້ຖືກ, ເປີດໜ້າຕ່າງອີກຄັ້ງ ແລ້ວກົດ *ຖ່າຍໃໝ່*. ໃຊ້ *ປົກປິດ* ເພື່ອເຊື່ອງສິ່ງທີ່ທ່ານບໍ່ຢາກໃຫ້ເຫັນ.

**ຮູບໜ້າຈໍໃຫຍ່ເກີນໄປ.** ແອັບຫຍໍ້ຮູບໜ້າຈໍກ່ອນສົ່ງ. ຖ້າມັນຍັງໃຫຍ່ເກີນໄປຫຼັງຈາກນັ້ນ, ຂໍ້ຄວາມແຈ້ງຂອງທ່ານຈະໄປໂດຍບໍ່ມີຮູບ. ໜ້າຈໍຂອບໃຈຈະສະແດງ *ພາບໜ້າຈໍໃຫຍ່ເກີນໄປ ແລະ ບໍ່ໄດ້ຖືກສົ່ງໄປ.*

**ການສົ່ງບໍ່ເຮັດວຽກ.** ຂໍ້ຄວາມໜຶ່ງປາກົດໃນໜ້າຕ່າງ ແລະ ຂໍ້ຄວາມຂອງທ່ານຍັງຢູ່. ມີສີ່ກໍລະນີ:

- *ຂໍ້ຄວາມແຈ້ງບໍ່ໄດ້ຮັບການຍອມຮັບ.* ກວດຂໍ້ຄວາມ ແລະ ທີ່ຢູ່ອີເມວ. ຂໍ້ຄວາມທີ່ສ່ວນໃຫຍ່ເປັນການເຊື່ອມຕໍ່ເວັບຈະຖືກປະຕິເສດ.
- *ທ່ານສົ່ງຂໍ້ຄວາມຫຼາຍໃນເວລາສັ້ນໆ.* ລອງໃໝ່ພາຍໃນໜຶ່ງຊົ່ວໂມງ.
- *ການສົ່ງບໍ່ສຳເລັດ.* ບໍ່ມີການເຊື່ອມຕໍ່ ຫຼື ເຊີບເວີບໍ່ຕອບ. ລອງໃໝ່, ຫຼື ກົດ *ເປີດໃນ GitHub*. ປຸ່ມນັ້ນບໍ່ມີ ຖ້າຄວາມພະຍາຍາມກ່ອນໜ້ານີ້ບໍ່ແນ່ນອນ (ເບິ່ງຂ້າງລຸ່ມ).
- *ພວກເຮົາບໍ່ແນ່ໃຈວ່າຂໍ້ຄວາມແຈ້ງຂອງທ່ານມາຮອດແລ້ວ ຫຼື ບໍ່. ກະລຸນາລໍຖ້າໜຶ່ງນາທີ ແລ້ວສົ່ງໃໝ່; ຖ້າມີຢູ່ແລ້ວ ພວກເຮົາຈະເຫັນເອງ.* ການເຊື່ອມຕໍ່ຂາດຫຼັງຈາກແອັບໄດ້ສົ່ງຂໍ້ຄວາມແຈ້ງຂອງທ່ານແລ້ວ. ຂໍ້ຄວາມຂອງທ່ານຍັງຢູ່. ບໍ່ມີປຸ່ມ *ເປີດໃນ GitHub*, ເພາະຂໍ້ຄວາມແຈ້ງຂອງທ່ານອາດຈະມາຮອດໄດ້ຢູ່. ສະພາບນີ້ຍັງຄົງຢູ່ຈົນກວ່າຂໍ້ຄວາມແຈ້ງຂອງທ່ານຖືກສົ່ງ ຫຼື ຖືກຮັບແລ້ວ, ເຖິງແມ່ນທ່ານປິດໜ້າຕ່າງໃນລະຫວ່າງ ແລະ ເປີດອີກຄັ້ງກໍຕາມ.

**ຂໍ້ຄວາມແຈ້ງນີ້ຖືກຮັບແລ້ວ.** ຖ້າທ່ານສົ່ງຂໍ້ຄວາມແຈ້ງທີ່ມີຢູ່ແລ້ວ, ແບບຟອມຈະຢູ່ກັບຂໍ້ຄວາມນີ້ຢູ່ເໜືອມັນ: *ຂໍ້ຄວາມແຈ້ງນີ້ມາຮອດພວກເຮົາແລ້ວ. ທ່ານຕ້ອງການເພີ່ມບາງຢ່າງບໍ? ຖ້າແມ່ນ, ກະລຸນາແກ້ໄຂຂໍ້ຄວາມ ແລ້ວສົ່ງອີກຄັ້ງ.* ຂໍ້ຄວາມຂອງທ່ານຍັງຢູ່ ແລະ ທີ່ຢູ່ອີເມວຂອງທ່ານຖືກຈື່ໄວ້. ກົດ *ປິດ* ຖ້າທ່ານບໍ່ຢາກເພີ່ມຫຍັງ; ແບບຟອມຈະຫວ່າງຄັ້ງໜ້າ. ຖ້າທ່ານພິມບາງຢ່າງເພີ່ມເຕີມ, ຂໍ້ຄວາມທີ່ຢູ່ເໜືອແບບຟອມນັ້ນຈະຫາຍໄປ ແລະ ທ່ານສາມາດສົ່ງອີກໄດ້; ປຸ່ມຈະຊື່ວ່າ *ບັນທຶກ ແລະ ປິດ* ອີກຄັ້ງ ແລະ ຂໍ້ຄວາມຂອງທ່ານຖືກເກັບໄວ້.

**ເປີດໃນ GitHub.** ນີ້ແມ່ນເສັ້ນທາງທີ່ບໍ່ຜ່ານ Open Feedback Studio. ສຳລັບອັນນີ້ທ່ານຕ້ອງມີບັນຊີ GitHub. ໂດຍບໍ່ມີຮູບໜ້າຈໍ, ໜ້າ GitHub ທີ່ທ່ານສ້າງ issue ໃໝ່ຈະເປີດທັນທີໃນເວັບເບຣາວເຊີ, ພ້ອມຫົວຂໍ້ ແລະ ລາຍລະອຽດທີ່ຕື່ມໄວ້ແລ້ວ. ດ້ວຍຮູບໜ້າຈໍ ທ່ານເຫັນກ່ອນ *ເກືອບສຳເລັດແລ້ວ — ຮູບໜ້າຈໍຂອງທ່ານຢູ່ໃນຄລິບບອດແລ້ວ.* ພ້ອມສີ່ຂັ້ນຕອນ. ກົດ *ຕົກລົງ, ໄປທີ່ GitHub*, ກົດໃນພື້ນທີ່ຂໍ້ຄວາມໃຫຍ່ຂອງໜ້າ issue, ແລ້ວກົດ Ctrl+V (Cmd+V ໃນ Mac). ຈາກນັ້ນກົດ *ສົ່ງ issue ໃໝ່* ຢູ່ລຸ່ມສຸດ. ຫຼັງຈາກນັ້ນເທົ່ານັ້ນຂໍ້ຄວາມແຈ້ງຂອງທ່ານຈຶ່ງຖືກສົ່ງ.

**ການວາງບໍ່ເຮັດວຽກ.** ເສັ້ນທາງ GitHub ຍັງບັນທຶກຮູບໜ້າຈໍເປັນໄຟລ໌ໃນຄອມພິວເຕີຂອງທ່ານ. ໃນແອັບເດັສທັອບ ໜ້າຕ່າງບອກເສັ້ນທາງ: *ວາງບໍ່ໄດ້? ພວກເຮົາຍັງບັນທຶກຮູບໜ້າຈໍໄວ້ທີ່* ເສັ້ນທາງນັ້ນ *— ລາກໄຟລ໌ນັ້ນໄປໃສ່ພື້ນທີ່ຂໍ້ຄວາມ.* ໃນເວັບເບຣາວເຊີ ແອັບດາວໂຫລດຮູບເປັນ `feedback-` ພ້ອມເລກ ແລະ ນາມສະກຸນ `.png`. ທ່ານຊອກພົບມັນໃນໂຟນເດີດາວໂຫລດ ແລ້ວລາກມັນໄປໃສ່ພື້ນທີ່ຂໍ້ຄວາມ.

**ການຖ່າຍຮູບໜ້າຈໍບໍ່ສຳເລັດ.** ແອັບຂຶ້ນວ່າ *ຖ່າຍຮູບໜ້າຈໍບໍ່ສຳເລັດ. ທ່ານຍັງສາມາດສົ່ງຄຳຕິຊົມໂດຍບໍ່ມີຮູບໄດ້.* ຊ່ອງໝາຍຖືກປິດ ແລະ ທ່ານສາມາດສົ່ງຂໍ້ຄວາມແຈ້ງໂດຍບໍ່ມີຮູບໄດ້.

**ທ່ານປິດໜ້າຕ່າງກ່ອນສົ່ງ.** ຖ້າມີບາງຢ່າງໃນແບບຟອມ, ປຸ່ມລຸ່ມສຸດຊື່ວ່າ *ບັນທຶກ ແລະ ປິດ*; ຖ້າແບບຟອມຫວ່າງ ມັນຊື່ວ່າ *ປິດ*. *ບັນທຶກ ແລະ ປິດ*, ປຸ່ມກາກບາດ ແລະ Esc ປິດໜ້າຕ່າງ, ແລະ ຂໍ້ຄວາມແຈ້ງຂອງທ່ານຖືກເກັບໄວ້ເປັນຮ່າງ ຈົນກວ່າທ່ານຈະສົ່ງ ຫຼື ກົດ *ລຶບລ້າງ*. ເມື່ອທ່ານເປີດໜ້າຕ່າງອີກຄັ້ງ, ປະເພດ, ຂໍ້ຄວາມ, ທີ່ຢູ່ອີເມວ ແລະ ຮູບໜ້າຈໍພ້ອມການຂຽນໝາຍເຫດ ຍັງຢູ່. ຮ່າງຖືກເກັບໄວ້ຕາບໃດທີ່ແອັບຍັງເປີດຢູ່; ຫຼັງຈາກທ່ານອອກຈາກແອັບ ມັນຫາຍໄປ. ຫຼັງຈາກສົ່ງສຳເລັດ ແບບຟອມຈະຫວ່າງອີກຄັ້ງ. ຖ້າທ່ານຢາກເລີ່ມໃໝ່ດ້ວຍຕົນເອງ, ກົດ *ລຶບລ້າງ* ຢູ່ລຸ່ມຊ້າຍ. ການກົດຂ້າງໜ້າຕ່າງຈະບໍ່ປິດມັນ. ໃນຂະນະທີ່ສົ່ງ, Esc ຈະບໍ່ປິດໜ້າຕ່າງ.
