# ການນຳເຂົ້າຄວາມຄືບໜ້າຈາກສະເປຣດຊີດ

ເປົ້າໝາຍ: ໃສ່ຄວາມຄືບໜ້າທີ່ພະນັກງານໜ້າງານປ້ອນໃນສະເປຣດຊີດ ເຂົ້າໃນແຜນງານໃນຄັ້ງດຽວ, ໂດຍບໍ່ຕ້ອງຄລິກທຸກໜ້າວຽກດ້ວຍຕົນເອງ.

## ເວລາທີ່ທ່ານຕ້ອງການອັນນີ້

ຜູ້ຮັບເໝົາຊ່ວງ ຫຼື ຜູ້ຈັດການໜ້າງານ ບໍ່ມີແອັບ, ແຕ່ລາວລາຍງານສະຖານະຂອງຕົນທຸກອາທິດ: ເຮັດສຳເລັດແລ້ວເທົ່າໃດເປີເຊັນ, ເລີ່ມເມື່ອໃດ, ສຳເລັດເມື່ອໃດ. ທ່ານສົ່ງຊີດທີ່ມີໜ້າວຽກຂອງທ່ານໃຫ້ລາວ, ລາວປ້ອນສາມຖັນ ແລ້ວສົ່ງຄືນ. ຈາກນັ້ນແອັບອ່ານພຽງສາມຄ່າຕໍ່ໜ້າວຽກ: ເປີເຊັນສຳເລັດ, ວັນເລີ່ມຕົວຈິງ ແລະ ວັນສຳເລັດຕົວຈິງ. ສ່ວນທີ່ເຫຼືອຂອງແຜນງານຈະບໍ່ຖືກແຕະຕ້ອງ. ສິ່ງທີ່ແອັບເຮັດກັບຄວາມຄືບໜ້ານັ້ນ ອະທິບາຍໄວ້ໃນ [ຄວາມຄືບໜ້າ, ວັນທີສະຖານະ ແລະ ແຜນຫຼັກ](docs://uitleg-voortgang).

## ຂັ້ນຕອນ

### 1. ຕັ້ງວັນທີສະຖານະ ແລະ ຄິດໄລ່

ຕັ້ງວັນທີສະຖານະຕາມທີ່ອະທິບາຍໄວ້ໃນ [ການອັບເດດຄວາມຄືບໜ້າ](docs://howto-voortgang-bijwerken). ຜູ້ຈັດການໜ້າງານປ້ອນວັນທີຕົວຈິງຈົນຮອດມື້ນັ້ນ, ລວມທັງມື້ນັ້ນ. ຖ້າແຜນງານບໍ່ເປັນປັດຈຸບັນ, ແອັບຈະຄິດໄລ່ຄືນໃໝ່ກ່ອນສ້າງຊີດ.

### 2. ສ້າງຊີດ

ເລືອກ *ການວາງແຜນ › ຄວາມຄືບໜ້າ › ສົ່ງອອກໃບຄວາມຄືບໜ້າ*. ປຸ່ມດຽວກັນນີ້ຢູ່ແຖບ *ຕາຕະລາງ* ແລະ *ລາຍງານ*. ແອັບສ້າງໄຟລ໌ Excel ແລະ ແນະນຳຊື່ *(ຊື່ໂຄງການ)-voortgang.xlsx*; ໃນບຣາວເຊີ ໄຟລ໌ຈະໄປຢູ່ໃນໂຟນເດີດາວໂຫຼດ. ຕ້ອງການ CSV ບໍ? ເລືອກ *ໄຟລ໌ › ສົ່ງອອກ › ໃບຄວາມຄືບໜ້າ (CSV)*. ຊີດ Excel ກໍມີຢູ່ເຊັ່ນກັນ, ເປັນ *ໃບຄວາມຄືບໜ້າ (Excel)*.

ຊີດນີ້ມີແປດຖັນ. ຊື່ຖັນຄົງເປັນພາສາອັງກິດ, ມີຄຳອະທິບາຍສັ້ນໆເປັນພາສາຂອງແອັບຕາມຫຼັງ:

- `OPS Task ID`, `WBS` ແລະ `Name` ມີໄວ້ພຽງເພື່ອຈຳແນກໜ້າວຽກເທົ່ານັ້ນ. ຢ່າແກ້ໄຂມັນ.
- `Start` ແລະ `Finish` ແມ່ນວັນທີຕາມແຜນ, ເພື່ອໃຫ້ຮູ້ໄວ້. ແອັບຈະບໍ່ຂຽນຄ່າເຫຼົ່ານີ້ກັບຄືນເລີຍ.
- `Completion (%)`, `Actual Start` ແລະ `Actual Finish` ແມ່ນຄ່າທີ່ທ່ານປ້ອນ.

ຊີດ Excel ຖືກປ້ອງກັນ ໂດຍບໍ່ມີລະຫັດຜ່ານ: ແກ້ໄຂໄດ້ສະເພາະສາມຖັນທີ່ປ້ອນຂໍ້ມູນເທົ່ານັ້ນ. Excel ກວດວ່າເປີເຊັນຢູ່ລະຫວ່າງ 0 ຫາ 100 ແລະ ວັນທີຕົວຈິງເປັນວັນທີ. ໜ້າວຽກຫຼັກ (ໄລຍະ) ຈະຖືກໝາຍເປັນສີເທົາດ້ວຍ *— ວຽກສະຫຼຸບ: ຫ້າມປ້ອນຂໍ້ມູນ*.

### 3. ໃຫ້ຜູ້ກ່ຽວປ້ອນຂໍ້ມູນ

ສຳລັບແຕ່ລະໜ້າວຽກ, ຜູ້ຈັດການໜ້າງານປ້ອນ:

- `Completion (%)`: ຕັ້ງແຕ່ 0 ຈົນເຖິງ 100 ລວມທັງສອງຄ່າ. ແອັບກໍອ່ານເລກທົດສະນິຍົມໄດ້ ທັງດ້ວຍຈຸລະພາກ ແລະ ດ້ວຍຈຸດ (ຕົວຢ່າງ 33,3 ຫຼື 33.3). ຄຳແນະນຳໃນ CSV ຍັງຂໍໃຫ້ໃສ່ເປັນຈຳນວນເຕັມ: ສະເປຣດຊີດທີ່ໃຊ້ການຕັ້ງຄ່າພາກພື້ນຕ່າງກັນອາດອ່ານ 8,38 ເປັນ 838.
- `Actual Start` ແລະ `Actual Finish`: ໃນ Excel ເປັນວັນທີຕາມການຕັ້ງຄ່າພາກພື້ນຂອງທ່ານ; ໃນ CSV ເປັນ dd-mm-yyyy ຫຼື yyyy-mm-dd.

ຊ່ອງທີ່ຫວ່າງຈະບໍ່ປ່ຽນແປງຫຍັງ. ດັ່ງນັ້ນ ຊ່ອງວ່າງກໍບໍ່ລຶບຄວາມຄືບໜ້າທີ່ມີຢູ່ເດີມອອກເຊັ່ນກັນ; ການລຶບນີ້ເຮັດໄດ້ພຽງໃນແອັບເທົ່ານັ້ນ. ໜ້າວຽກທີ່ຍັງບໍ່ເລີ່ມ, ຜູ້ກ່ຽວປ່ອຍຊ່ອງໄວ້ໃຫ້ຫວ່າງທັງໝົດ.

### 4. ອ່ານຊີດເຂົ້າ

1. ເລືອກ *ການວາງແຜນ › ຄວາມຄືບໜ້າ › ອັບເດດຄວາມຄືບໜ້າຈາກສະເປຣດຊີດ* (ຍັງມີຢູ່ແຖບ *ຕາຕະລາງ* ແລະ *ລາຍງານ* ເຊັ່ນກັນ), ຫຼື *ໄຟລ໌ › ນຳເຂົ້າ › ອັບເດດຄວາມຄືບໜ້າຈາກສະເປຣດຊີດ*. ໜ້າຕ່າງ *ອັບເດດຄວາມຄືບໜ້າຈາກສະເປຣດຊີດ* ຈະເປີດຂຶ້ນ.
2. ກົດ *ເລືອກໄຟລ໌…* ແລ້ວເລືອກໄຟລ໌ `.xlsx` ຫຼື `.csv` ທີ່ຖືກປ້ອນແລ້ວ.
3. ຖ້າວັນທີໃນ CSV ບໍ່ຊັດເຈນ, ແອັບຈະຖາມ *ຂຶ້ນຕົ້ນດ້ວຍມື້ ຫຼື ເດືອນ?* ໂດຍສະແດງວັນທີຈາກໄຟລ໌ຂອງທ່ານໃນສອງແບບ. ກົດວັນທີທີ່ຖືກຕ້ອງ.
4. ທ່ານເຫັນຕົວຢ່າງແລ້ວ. ດ້ານເທິງມີສີ່ຕົວນັບ: *ນຳໃຊ້ແລ້ວ*, *ບໍ່ປ່ຽນແປງ*, *ລໍຖ້າການເຊື່ອມໂຍງ* ແລະ *ຖືກປະຕິເສດ*. ດ້ານລຸ່ມ, ສຳລັບແຕ່ລະໜ້າວຽກ, ສະແດງສິ່ງທີ່ປ່ຽນແປງ, ຕົວຢ່າງ *ເປີເຊັນສຳເລັດ: 0% → 100%*.
5. ກວດຕົວຢ່າງ ແລ້ວກົດ *ນຳໃຊ້*. ໜ້າຕ່າງຈະສະແດງ *ຜົນໄດ້ຮັບ*, ພ້ອມຕົວນັບ ແລະ ແຖວທີ່ຖືກປະຕິເສດ ພ້ອມເຫດຜົນ. ກົດ *ປິດ* ເພື່ອຈົບ.

ທ່ານບໍ່ສາມາດຂ້າມຕົວຢ່າງໄດ້. ປຸ່ມ *ນຳໃຊ້* ຖືກປິດການໃຊ້ງານ ຕາບໃດທີ່ບໍ່ມີຫຍັງໃຫ້ນຳໃຊ້.

### 5. ຄິດໄລ່ແຜນງານຄືນໃໝ່

ການອ່ານເຂົ້າບໍ່ໄດ້ຄິດໄລ່ຄືນໃໝ່ດ້ວຍຕົວເອງ. ກົດ **ຄິດໄລ່** (F5), ຕົວຢ່າງຜ່ານ *ການວາງແຜນ › ຕາຕະລາງເວລາ › ຄິດໄລ່*, ເວັ້ນເສຍແຕ່ *ຄິດໄລ່ອັດຕະໂນມັດ* ເປີດຢູ່.

## ແຖວທີ່ບໍ່ຈັບຄູ່ງ່າຍໆ

ແອັບເຊື່ອມໂຍງທຸກແຖວກັບໜ້າວຽກ, ກ່ອນດ້ວຍ `OPS Task ID` ແລະ ຖ້າບໍ່ມີ ດ້ວຍເລກ WBS.

**ການເຊື່ອມໂຍງຍັງບໍ່ແນ່ນອນ.** ຖ້າແອັບພົບໜ້າວຽກພຽງແຕ່ດ້ວຍເລກ WBS, ແຖວນັ້ນຢູ່ໃນ *ການເຊື່ອມໂຍງຍັງບໍ່ແນ່ນອນ*, ພ້ອມ *ຢືນຢັນ* ແລະ *ປ່ຽນແປງ*. ແຖວນັ້ນຈະຖືກນຳໃຊ້ດ້ວຍເຊັ່ນກັນ ຖ້າທ່ານບໍ່ເຮັດຫຍັງ; ດັ່ງນັ້ນ ໃຫ້ກວດວ່າໜ້າວຽກຖືກຕ້ອງ. *ຢືນຢັນ* ເອົາແຖວອອກຈາກລາຍການນີ້; ມັນບໍ່ປ່ຽນແປງສິ່ງທີ່ຖືກນຳໃຊ້. *ປ່ຽນແປງ* ໃຫ້ທ່ານເລືອກໜ້າວຽກອື່ນ. ດ້ວຍ *ລຶບການເຊື່ອມໂຍງ* ທ່ານລຶບການເຊື່ອມໂຍງທີ່ທ່ານສ້າງເອງອອກ. ໝາຍເຫດ: ຊີດຈາກໂຄງການອື່ນທີ່ມີເລກ WBS ດຽວກັນ ກໍຍັງຖືກເຊື່ອມໂຍງ, ຢູ່ໃນ *ການເຊື່ອມໂຍງຍັງບໍ່ແນ່ນອນ*, ແລະຖືກນຳໃຊ້ເມື່ອທ່ານກົດ *ນຳໃຊ້*.

**ລໍຖ້າການເຊື່ອມໂຍງ.** ຖ້າແອັບບໍ່ພົບໜ້າວຽກ, ຫຼືພົບຫຼາຍໜ້າວຽກທີ່ມີເລກ WBS ດຽວກັນ, ແຖວນັ້ນຢູ່ໃນ *ລໍຖ້າການເຊື່ອມໂຍງ*. ທີ່ *ເລືອກໜ້າວຽກ…* ໃຫ້ເລືອກໜ້າວຽກທີ່ຖືກຕ້ອງ; ທ່ານຄົ້ນຫາດ້ວຍເລກ WBS ຫຼື ຊື່. ຖ້າທ່ານບໍ່ເຊື່ອມໂຍງ, ແຖວນັ້ນຈະຖືກປະຕິເສດ.

## ຂໍ້ຜິດພາດທົ່ວໄປ ແລະ ສິ່ງທີ່ແອັບເຮັດ

ແຖວທີ່ບໍ່ຈັບຄູ່ຈະຖືກປະຕິເສດພ້ອມເຫດຜົນ. ສ່ວນທີ່ເຫຼືອຂອງຊີດຈະດຳເນີນຕໍ່ໄປ. ນີ້ແມ່ນຂໍ້ຄວາມຫຼັກ:

- *ວັນທີຕົວຈິງຢູ່ຫຼັງວັນທີສະຖານະ.* ຕັ້ງວັນທີສະຖານະໃຫ້ຊ້າກວ່ານີ້ ຫຼື ແກ້ໄຂຊີດ.
- *ໜ້າວຽກນີ້ຖືກວາງແຜນໃຫ້ເລີ່ມຫຼັງວັນທີສະຖານະ: ກະລຸນາປ້ອນວັນເລີ່ມຕົວຈິງໃນຊີດກ່ອນ.* ແອັບຈະບໍ່ສ້າງວັນເລີ່ມຂຶ້ນເອງ; ໃຫ້ປ້ອນມັນໃນຊີດ.
- *ເປີເຊັນຢູ່ນອກຊ່ວງ 0–100. ກະລຸນາກວດສອບເຄື່ອງໝາຍຈຸດທົດສະນິຍົມ: ຄ່າ 8.38 ອາດຖືກອ່ານເປັນ 838 ຕາມການຕັ້ງຄ່າພາສາຂອງບາງໂປຣແກຣມ.*
- *ໜ້າວຽກຫຼັກບໍ່ສາມາດຮັບຄ່າຄວາມຄືບໜ້າຈາກຊີດໄດ້.* ຄວາມຄືບໜ້າຂອງໄລຍະຈະມາຈາກໜ້າວຽກທີ່ຢູ່ລຸ່ມມັນ.
- *ວັນສຳເລັດຕົວຈິງມາກ່ອນວັນເລີ່ມຕົວຈິງ.*
- *ວັນທີອ່ານບໍ່ໄດ້.* ແລະ *ເປີເຊັນອ່ານບໍ່ໄດ້.*
- *ຄ່າທີ່ປ້ອນມີຄວາມຂັດແຍ່ງກັນ.* ຕົວຢ່າງ ວັນສຳເລັດຕົວຈິງ ພ້ອມເປີເຊັນຕ່ຳກວ່າ 100.
- *ບໍ່ພົບໜ້າວຽກສຳລັບແຖວນີ້.* ຊີດອ້າງເຖິງລະຫັດໜ້າວຽກ ແລະ ເລກ WBS ທີ່ບໍ່ມີໃນໂຄງການນີ້.
- *ລະຫັດ WBS ນີ້ກົງກັບຫຼາຍໜ້າວຽກ — ກະລຸນາເຊື່ອມໂຍງແຖວດ້ວຍຕົນເອງ.*
- *ມີແຖວອື່ນເຊື່ອມໂຍງກັບໜ້າວຽກນີ້ແລ້ວ.* ສອງແຖວຊີ້ໄປທີ່ໜ້າວຽກດຽວກັນ.
- *ຖືກປະຕິເສດໂດຍນັກວາງແຜນ.* ການປະຕິເສດອີກຢ່າງໜຶ່ງຈາກແຜນງານເອງ, ໂດຍບໍ່ມີຂໍ້ຄວາມຂອງມັນເອງ.

ຖ້າທັງໄຟລ໌ຖືກປະຕິເສດ, ຂໍ້ຄວາມໜຶ່ງໃນນີ້ຈະປາກົດໃນໜ້າຕ່າງ: *ໄຟລ໌ນີ້ບໍ່ມີຖັນ “OPS Task ID” ຫຼື “WBS” ເພື່ອເຊື່ອມແຖວກັບໜ້າວຽກ.*, *ໄຟລ໌ນີ້ບໍ່ມີຖັນ ເປີເຊັນສຳເລັດ, ວັນເລີ່ມຕົວຈິງ ຫຼື ວັນສຳເລັດຕົວຈິງ ເລີຍ.*, *ໄຟລ໌ນີ້ໃຫຍ່ເກີນໄປທີ່ຈະອ່ານເປັນຊີດຄວາມຄືບໜ້າ.* (ຫຼາຍກວ່າ 16 MB), *ໄຟລ໌ນີ້ມີຈຳນວນແຖວຫຼາຍເກີນໄປທີ່ຈະອ່ານເປັນຊີດຄວາມຄືບໜ້າ.* (ຫຼາຍກວ່າ 50,000 ແຖວ) ຫຼື *ໄຟລ໌ນີ້ຖືກປ້ອງກັນດ້ວຍລະຫັດຜ່ານ ແລະ ບໍ່ສາມາດອ່ານໄດ້.* ຫຼື *ບໍ່ສາມາດອ່ານໄຟລ໌ນີ້ເປັນຊີດຄວາມຄືບໜ້າໄດ້.*

**ບໍ່ມີວັນທີສະຖານະ.** ຖ້າຍັງບໍ່ມີວັນທີສະຖານະ ແລະ ການນຳເຂົ້ານຳໃຊ້ຄວາມຄືບໜ້າ, ແອັບຈະຕັ້ງມັນເປັນມື້ນີ້ ແລະ ແຈ້ງທ່ານ. ສະນັ້ນ ໃຫ້ຕັ້ງມັນດ້ວຍຕົນເອງກ່ອນ.

**ກັບຄືນທັງໝົດໃນຄັ້ງດຽວ.** ທັງຊີດນັບເປັນໜຶ່ງຂັ້ນຕອນສຳລັບ Ctrl+Z.

**ສະເພາະສິ່ງທີ່ທ່ານປ້ອນ.** ແຖວທີ່ບໍ່ມີຄວາມແຕກຕ່າງຈາກແຜນງານນັບເປັນ *ບໍ່ປ່ຽນແປງ*. ໜ້າວຽກທີ່ບໍ່ມີແຖວໃນຊີດຈະຄົງເດີມ.
