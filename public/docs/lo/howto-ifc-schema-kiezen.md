# ການເລືອກສະກີມ IFC

ເປົ້າໝາຍ: ບັນທຶກແຜນງານຂອງທ່ານໃນສະກີມ IFC ຂອງແບບອາຄານທີ່ທ່ານຕ້ອງການລວມເຂົ້າກັນ.

## ເມື່ອທ່ານຕ້ອງການສິ່ງນີ້

ຕາມຄ່າເລີ່ມຕົ້ນ ແອັບບັນທຶກໂຄງການເປັນ IFC 4.3 ADD2. ນີ້ແມ່ນຊື່ຂອງ IFC 4.3 ໃນໄຟລ໌ທີ່ IfcOpenShell ແລະ Bonsai ສ້າງຂຶ້ນ. ຖ້າທ່ານຕ້ອງການລວມແຜນງານເຂົ້າກັບແບບອາຄານເປັນໄຟລ໌ 4D ໄຟລ໌ດຽວ ຕົວຢ່າງດ້ວຍສູດ *MergeProjects* ຂອງ IfcOpenShell (ifcpatch), ທັງສອງໄຟລ໌ຕ້ອງມີສະກີມດຽວກັນ. ຖ້າແບບອາຄານເປັນໄຟລ໌ IFC4, IfcOpenShell ຈະບໍ່ລວມມັນກັບແຜນງານ IFC 4.3. ຈາກນັ້ນ ກະລຸນາເລືອກສະກີມຂອງແບບຢູ່ບ່ອນນີ້.

## ຂັ້ນຕອນ

1. ເປີດ *ການຕັ້ງຄ່າໂຄງການ*: *ການຕັ້ງຄ່າ › ໂຄງການ › ການຕັ້ງຄ່າໂຄງການ*, ຫຼື *ໄຟລ໌ › ການຕັ້ງຄ່າໂຄງການ*.
2. ພາຍໃຕ້ *ສະກີມ IFC ເມື່ອບັນທຶກ*, ເລືອກສະກີມຂອງແບບອາຄານຂອງທ່ານ.
3. ກົດ *ນຳໃຊ້*. ໂຄງການຢູ່ໃນສະຖານະ *ຍັງບໍ່ໄດ້ບັນທຶກ*.
4. ບັນທຶກດ້ວຍ *ບັນທຶກ* (Ctrl+S) ຫຼື *ບັນທຶກເປັນ*.

ສາມທາງເລືອກມີດັ່ງນີ້:

- *IFC 4.3 ADD2 (ຄ່າເລີ່ມຕົ້ນ)* ຂຽນ `IFC4X3_ADD2` ໃນສ່ວນຫົວຂອງໄຟລ໌.
- *IFC 4.3* ຂຽນ `IFC4X3`. ນັ້ນແມ່ນວິທີທີ່ແອັບລຸ້ນເກົ່າຂຽນ IFC 4.3.
- *IFC4* ຂຽນ `IFC4` ສຳລັບແບບອາຄານໃນ IFC4.

## ຈຸດທີ່ຕ້ອງລະວັງ ແລະ ສິ່ງທີ່ແອັບເຮັດ

**ລວມເປັນຂັ້ນຕອນສຸດທ້າຍ.** ຢ່າເປີດໄຟລ໌ 4D ທີ່ລວມແລ້ວ (ແບບອາຄານບວກແຜນງານ) ໃນແອັບເພື່ອບັນທຶກອີກຄັ້ງ. ແອັບເກັບໄວ້ພຽງແຕ່ແຜນງານ: ຝາ ແລະ ສ່ວນອື່ນຂອງແບບອາຄານຈະຫາຍໄປ, ເຖິງແມ່ນທ່ານຈະຮັກສາສະກີມໄວ້ກໍຕາມ. ໃຫ້ປ່ຽນແຜນງານໃນໄຟລ໌ຂອງທ່ານເອງ ແລ້ວລວມອີກຄັ້ງພາຍຫຼັງ.

**ແອັບຖາມກ່ອນເມື່ອໄຟລ໌ທີ່ເປີດມີສະກີມອື່ນ.** ຖ້າທ່ານເປີດ, ຕົວຢ່າງ, ໄຟລ໌ IFC4 ຫຼື ໄຟລ໌ IFC 4.3 ຈາກແອັບລຸ້ນເກົ່າ, ແອັບຈະບໍ່ປ່ຽນປະເພດໄຟລ໌ໂດຍກົງ. ຄັ້ງທຳອິດທີ່ທ່ານໃຊ້ *ບັນທຶກ* ຫຼື *ບັນທຶກເປັນ*, ແອັບຈະຖາມກ່ອນວ່າທ່ານຈະຮັກສາສະກີມຂອງໄຟລ໌ ຫຼື ປ່ຽນເປັນ IFC 4.3 ADD2. *ຮັກສາ IFC4* (ຫຼື *ຮັກສາ IFC 4.3*) ແມ່ນປຸ່ມທີ່ປຸ່ມ Enter ເລືອກ. ຖ້າທ່ານປິດຄຳຖາມດ້ວຍ Esc ຫຼື ປຸ່ມປິດ, ແອັບຈະບໍ່ບັນທຶກຫຍັງເລີຍ.

**ແອັບຖາມພຽງຄັ້ງດຽວຕໍ່ໄຟລ໌.** ການເລືອກຂອງທ່ານຖືກເກັບໄວ້ໃນໄຟລ໌ເອງ. ຖ້າທ່ານເປີດມັນອີກໃນພາຍຫຼັງ ແອັບຈະບໍ່ຖາມອີກ. ຖ້າທ່ານເລືອກສະກີມເອງໃນ *ການຕັ້ງຄ່າໂຄງການ* ແລ້ວກົດ *ນຳໃຊ້*, ແອັບກໍຈະບໍ່ຖາມເຊັ່ນກັນ.

**ສະກີມທີ່ແອັບຂຽນບໍ່ໄດ້** ເຊັ່ນ IFC2X3, ສາມາດເປີດໃນແອັບໄດ້. ຄັ້ງທຳອິດທີ່ທ່ານບັນທຶກ ຄຳຖາມຈະບອກເລື່ອງນີ້ ແລະ ທ່ານເລືອກໜຶ່ງໃນສາມສະກີມຂ້າງເທິງ.

**ບັນທຶກອັດຕະໂນມັດ ແລະ ລະບົບກູ້ຄືນຂໍ້ມູນບໍ່ຖາມຫຍັງ.** ມັນຂຽນສະກີມຂອງໄຟລ໌ ແລະ ເກັບຄຳຖາມໄວ້ສຳລັບການບັນທຶກຄັ້ງທຳອິດທີ່ທ່ານເຮັດເອງ. ສຳລັບສະກີມທີ່ແອັບຂຽນບໍ່ໄດ້, *ບັນທຶກອັດຕະໂນມັດ* ຈະບໍ່ຂຽນໃສ່ໄຟລ໌ຈົນກວ່າທ່ານຈະຕອບຄຳຖາມ.

**ໂຄງການໃໝ່ບໍ່ຖາມຫຍັງ.** ໂຄງການໃໝ່ ແລະ ໂຄງການຈາກຮູບແບບອື່ນ ເຊັ່ນ XER, MPP ຫຼື CSV ເລີ່ມຕົ້ນທີ່ *IFC 4.3 ADD2 (ຄ່າເລີ່ມຕົ້ນ)*.

**ເນື້ອໃນຂອງໄຟລ໌ບໍ່ປ່ຽນ.** ທັງສາມສະກີມຮອງຮັບຂໍ້ມູນແຜນງານທີ່ແອັບຂຽນໃນແບບດຽວກັນ. ມີແຕ່ແຖວ `FILE_SCHEMA` ໃນສ່ວນຫົວຂອງໄຟລ໌ເທົ່ານັ້ນທີ່ຕ່າງກັນ. ສະນັ້ນ ທ່ານບໍ່ເສຍຫຍັງເລີຍເມື່ອທ່ານເລືອກສະກີມອື່ນ.

**ແບບ IFC 4.3 ຈາກ IfcOpenShell ຫຼື Bonsai** ມັກມີ `IFC4X3_ADD2` ໃນສ່ວນຫົວ, ຄືກັບຄ່າເລີ່ມຕົ້ນຂອງແອັບ. IfcOpenShell ບໍ່ລວມແຜນງານທີ່ມີ `IFC4X3` ເຂົ້າກັບມັນ. ຖ້າບໍ່ແນ່ໃຈ, ໃຫ້ເບິ່ງແຖວ `FILE_SCHEMA` ເທິງສຸດຂອງໄຟລ໌ແບບ.

**ຍົກເລີກຄຳສັ່ງບໍ່ປ່ຽນສະກີມ.** ສະກີມເປັນຂອງໄຟລ໌, ຄືກັບບ່ອນທີ່ໄຟລ໌ຖືກເກັບໄວ້. ການເລືອກໃນ *ການຕັ້ງຄ່າໂຄງການ* ແລະ ຄຳຕອບຂອງຄຳຖາມຕອນບັນທຶກ ຈຶ່ງບໍ່ແມ່ນຂັ້ນຕອນໃນ *ຍົກເລີກຄຳສັ່ງ*. ເພື່ອກັບຄືນ, ໃຫ້ເລືອກສະກີມອື່ນໃນ *ການຕັ້ງຄ່າໂຄງການ*. ແບບນັ້ນ *ບັນທຶກອັດຕະໂນມັດ* ຈະບໍ່ຂຽນສະກີມອື່ນໂດຍບໍ່ໃຫ້ຮູ້ຕົວ ຫຼັງຈາກທ່ານຍົກເລີກການແກ້ໄຂ.
