# ການເຊື່ອມຕໍ່ໄຄລເອັນ MCP

ເປົ້າໝາຍ: ໃຫ້ໄຄລເອັນ MCP ອ່ານຕາມ ແລະ ເຮັດວຽກກັບແຜນງານຂອງທ່ານ, ໂດຍທ່ານສາມາດເຫັນວ່າມັນເຮັດຫຍັງ ແລະ ມີຂໍ້ຈຳກັດທີ່ທ່ານຕັ້ງເອງ.

## ວິທີໄວ: ໃຫ້ Claude ເຮັດໃຫ້

ທ່ານໃຊ້ງານ Claude Desktop ຫຼື Claude Code ບໍ? ຖ້າໃຊ້, Claude ສາມາດຕິດຕັ້ງການເຊື່ອມຕໍ່ດ້ວຍຕົນເອງໄດ້:

1. ກົດ *ຄັດລອກຄຳສັ່ງ* ຢູ່ຂ້າງລຸ່ມ.
2. ວາງຄຳສັ່ງໃສ່ການສົນທະນາໃໝ່ກັບ Claude ແລ້ວສົ່ງມັນ.

ຈາກນັ້ນ Claude ຈະຕິດຕັ້ງສ່ວນເສີມສຳລັບ Open Planner Studio ແລະ ອະທິບາຍວ່າມັນເຮັດຫຍັງໄປພ້ອມກັນ. ຖ້າທ່ານຕ້ອງເຮັດບາງຢ່າງດ້ວຍຕົນເອງ ເຊັ່ນ ກົດ *ຕິດຕັ້ງ* ໃນ Claude Desktop, Claude ຈະບອກທ່ານຢ່າງຊັດເຈນວ່າຕ້ອງກົດອັນໃດ. ທ່ານບໍ່ຕ້ອງການໂທເຄັນສຳລັບເລື່ອງນີ້.

```prompt
ຕິດຕັ້ງສ່ວນເສີມ Open Planner Studio ໃຫ້ຂ້າພະເຈົ້າ, ເພື່ອໃຫ້ທ່ານສາມາດອ່ານ ແລະ ປ່ຽນແປງແຜນງານກໍ່ສ້າງຂອງຂ້າພະເຈົ້າໃນ Open Planner Studio ໄດ້. ໃຫ້ທ່ານເຮັດໃຫ້ໄດ້ຫຼາຍທີ່ສຸດດ້ວຍຕົນເອງ. ກ່ອນແຕ່ລະຂັ້ນຕອນ ໃຫ້ບອກໃນປະໂຫຍກດຽວທີ່ງ່າຍວ່າທ່ານຈະເຮັດຫຍັງ ແລະ ເປັນຫຍັງ. ຖ້າທ່ານຕ້ອງການຂ້າພະເຈົ້າ, ໃຫ້ຖາມທີລະເລື່ອງ ແລະ ລໍຖ້າຄຳຕອບຂອງຂ້າພະເຈົ້າ. ຖ້າຂ້າພະເຈົ້າຕ້ອງເຮັດບາງຢ່າງດ້ວຍຕົນເອງ, ໃຫ້ບອກຂ້າພະເຈົ້າຢ່າງຊັດເຈນວ່າຕ້ອງກົດຄັ້ງດຽວ ຫຼື ເຮັດການໃດໜຶ່ງ ແລະ ຢູ່ບ່ອນໃດ.

ສິ່ງທີ່ທ່ານຕ້ອງຮູ້:
- ສ່ວນເສີມແມ່ນໄຟລ໌ດຽວ, open-planner-studio-<version>.mcpb, ໃນເວີຊັນໃໝ່ສຸດ: https://github.com/OpenAEC-Foundation/open-planner-studio/releases/latest. ທີ່ຢູ່ດາວໂຫຼດໂດຍກົງຢູ່ໃນ https://api.github.com/repos/OpenAEC-Foundation/open-planner-studio/releases/latest (ໄຟລ໌ທີ່ຊື່ລົງທ້າຍດ້ວຍ .mcpb). ໄຟລ໌ນີ້ເປັນໄຟລ໌ ZIP.
- ສ່ວນເສີມເຮັດວຽກໄດ້ກັບແອັບ Desktop ຂອງ Open Planner Studio ແລະ ໂດຍບໍ່ມີແອັບກໍ່ໄດ້. ເມື່ອແອັບເປີດຢູ່ ແລະ ຂົວເຊື່ອມຕໍ່ MCP ຂອງມັນກຳລັງເຮັດວຽກ ທ່ານເຮັດວຽກໃນແຜນງານທີ່ເປີດຢູ່ໃນແອັບ. ເມື່ອແອັບປິດ ທ່ານເຮັດວຽກກັບໄຟລ໌ແຜນງານໃນໂຟນເດີເຮັດວຽກທີ່ຂ້າພະເຈົ້າເລືອກ.
- ການຕິດຕັ້ງບໍ່ຕ້ອງການໂທເຄັນ ຫຼື ລະຫັດຜ່ານ. ຢ່າຂໍອັນໃດອັນໜຶ່ງຈາກຂ້າພະເຈົ້າ, ແລະ ຢ່າອ່ານ ຫຼື ສະແດງອັນໃດອັນໜຶ່ງ.

ຖ້າທ່ານໃຊ້ງານໃນ Claude Desktop:
1. ຖ້າທ່ານສາມາດດາວໂຫຼດໄຟລ໌ ແລະ ເປີດມັນໃນຄອມພິວເຕີຂອງຂ້າພະເຈົ້າໄດ້, ໃຫ້ເຮັດແບບນັ້ນກັບໄຟລ໌ .mcpb. ຖ້າບໍ່ໄດ້, ໃຫ້ສົ່ງທີ່ຢູ່ດາວໂຫຼດໂດຍກົງໃຫ້ຂ້າພະເຈົ້າ ແລະ ບອກຂ້າພະເຈົ້າໃຫ້ກົດສອງເທື່ອໃສ່ໄຟລ໌ ເມື່ອການດາວໂຫຼດສຳເລັດ.
2. ຈາກນັ້ນ Claude Desktop ຈະສະແດງສ່ວນເສີມ Open Planner Studio. ໃຫ້ບອກຂ້າພະເຈົ້າໃຫ້ກົດ ຕິດຕັ້ງ. ຈາກນັ້ນໃຫ້ບອກຂ້າພະເຈົ້າໃຫ້ເລືອກ, ຢູ່ Working folder, ໂຟນເດີທີ່ມີໄຟລ໌ແຜນງານຂອງຂ້າພະເຈົ້າ.
3. ໃຫ້ບອກຂ້າພະເຈົ້າໃຫ້ເລີ່ມການສົນທະນາໃໝ່ ແລະ ໃຫ້ຖາມທ່ານໃນນັ້ນວ່າທ່ານເຫັນເຄື່ອງມື Open Planner Studio ໃດແດ່.

ຖ້າທ່ານໃຊ້ງານໃນ Claude Code:
1. ກວດວ່າ Node.js 22 ຫຼື ໃໝ່ກວ່າໄດ້ຖືກຕິດຕັ້ງແລ້ວ. ຖ້າບໍ່ໄດ້ຖືກຕິດຕັ້ງ, ໃຫ້ບອກຂ້າພະເຈົ້າວ່າຈະຕິດຕັ້ງແນວໃດ ແລ້ວຢຸດ.
2. ຖາມຂ້າພະເຈົ້າວ່າໂຟນເດີໃດເກັບໄຟລ໌ແຜນງານຂອງຂ້າພະເຈົ້າ. ນັ້ນແມ່ນໂຟນເດີເຮັດວຽກ.
3. ດາວໂຫຼດໄຟລ໌ .mcpb ແລ້ວແຕກໄຟລ໌ອອກໃສ່ໂຟນເດີໃໝ່ຂອງມັນເອງ ໃນໂຟນເດີຜູ້ໃຊ້ຂອງຂ້າພະເຈົ້າ. ອ່ານ manifest.json ໃນນັ້ນ: server.mcp_config ບອກວ່າເຊີບເວີເລີ່ມເຮັດວຽກແນວໃດ. ປ່ຽນ ${__dirname} ເປັນໂຟນເດີທີ່ແຕກໄຟລ໌ແລ້ວ ແລະ ປ່ຽນ ${user_config.workdir} ເປັນໂຟນເດີເຮັດວຽກ.
4. ເອີ້ນຄຳສັ່ງ claude mcp list. ຖ້າມີເຊີບເວີທີ່ຊື່ open-planner-studio ຢູ່ແລ້ວ, ໃຫ້ຖາມຂ້າພະເຈົ້າວ່າທ່ານອະນຸຍາດໃຫ້ແທນທີ່ມັນໄດ້ບໍ່. ຢ່າສະແດງການຕັ້ງຄ່າຂອງມັນ ເພາະມັນອາດມີໂທເຄັນ.
5. ເພີ່ມເຊີບເວີໃຫ້ບັນຊີຜູ້ໃຊ້ຂອງຂ້າພະເຈົ້າ, ຕົວຢ່າງ: claude mcp add open-planner-studio --scope user -e OPS_MCP_ROOT=<working folder> -- node <unpacked folder>/server/index.mjs
6. ໃຫ້ບອກຂ້າພະເຈົ້າໃຫ້ເລີ່ມເຊດຊັນ Claude Code ໃໝ່, ແລະ ວ່າ /mcp ໃນນັ້ນສະແດງວ່າ open-planner-studio ເຊື່ອມຕໍ່ແລ້ວຫຼືບໍ່.

ຖ້າທ່ານໃຊ້ງານບ່ອນອື່ນ ເຊັ່ນ claude.ai ໃນບຣາວເຊີ, ໃຫ້ບອກຂ້າພະເຈົ້າວ່າອັນນີ້ຕ້ອງການ Claude Desktop ຫຼື Claude Code. ຖ້າທ່ານບໍ່ຮູ້ວ່າທ່ານໃຊ້ງານຢູ່ໃສ, ໃຫ້ຖາມຂ້າພະເຈົ້າ.

ເມື່ອການຕິດຕັ້ງສຳເລັດແລ້ວ, ໃຫ້ອະທິບາຍເປັນບໍ່ຫຼາຍປະໂຫຍກ:
- ວິທີທີ່ຂ້າພະເຈົ້າໃຫ້ທ່ານເຮັດວຽກໃນແອັບທີ່ເປີດຢູ່: ໃນ Open Planner Studio, ເລືອກ ການຕັ້ງຄ່າ › ໂຄງການ › ການຕັ້ງຄ່າແອັບ, ແຖບ ຂັ້ນສູງ, ແລ້ວເປີດ ອະນຸຍາດການເຊື່ອມຕໍ່ MCP. ຈາກນັ້ນກົດ ເລີ່ມຂົວເຊື່ອມຕໍ່ ຢູ່ແຖບ MCP.
- ວ່າໂດຍບໍ່ມີແອັບ ການປ່ຽນແປງຢູ່ໃນໄຟລ໌ພຽງແຕ່ຫຼັງຈາກທ່ານບັນທຶກແລ້ວ, ແລະ ວ່າທ່ານບໍ່ຂຽນທັບໄຟລ໌ທີ່ມີຢູ່ແລ້ວໃນຂະນະທີ່ແອັບເປີດຢູ່.
ຖ້າຂັ້ນຕອນໃດລົ້ມເຫຼວ, ໃຫ້ບອກຂ້າພະເຈົ້າໃນປະໂຫຍກດຽວວ່າຜິດພາດຫຍັງ ແລະ ຂ້າພະເຈົ້າເຮັດຫຍັງໄດ້. ຢ່າເດົາ.
```

ທ່ານຕ້ອງການເຮັດເອງ ຫຼື ທ່ານໃຊ້ໄຄລເອັນ MCP ອື່ນບໍ? ຖ້າແມ່ນ, ໃຫ້ເຮັດຕາມຂັ້ນຕອນຂ້າງລຸ່ມ.

## ເມື່ອທ່ານຕ້ອງການອັນນີ້

ທ່ານຕ້ອງການໃຫ້ໄຄລເອັນ MCP ອ່ານ, ວິເຄາະ ຫຼື ປ່ຽນແປງແຜນງານຂອງທ່ານ. ຕົວຢ່າງ ເພື່ອໃຫ້ມັນຮ່າງ WBS ເບື້ອງຕົ້ນ, ແກ້ໄຂໜ້າວຽກ ຫຼື ອະທິບາຍເສັ້ນທາງວິກິດ. ອັນນີ້ເຮັດວຽກຜ່ານ **Model Context Protocol** (MCP): ມາດຕະຖານທີ່ໃຫ້ໂປຣແກຣມ AI ທີ່ເປັນ **ໄຄລເອັນ MCP** ໃຊ້ເຄື່ອງມືຂອງໂປຣແກຣມອື່ນໄດ້. ເພື່ອອັນນີ້, Open Planner Studio ດຳເນີນເຊີບເວີນ້ອຍໆ ຢູ່ໃນຄອມພິວເຕີຂອງທ່ານເອງ, ຄື **ຂົວເຊື່ອມຕໍ່**. ເຊີບເວີນີ້ໃຫ້ຊຸດເຄື່ອງມື ທີ່ທຸກອັນມີຊື່ເລີ່ມດ້ວຍ `planner_`: ອ່ານ ແລະ ປ່ຽນແປງໜ້າວຽກ, ສາຍສຳພັນ, ຊັບພະຍາກອນ, ປະຕິທິນ, ແຜນຫຼັກ, ເອກະສານ ແລະ ໄຟລ໌. ເຄື່ອງມືໃດແດ່ທີ່ມີ ແລະ ສິ່ງໃດທີ່ມັນປະຕິເສດ ຢູ່ໃນ [ເຄື່ອງມື MCP](docs://ref-ai-tools). ໄຄລເອັນ MCP ເຮັດວຽກໃນໂຄງການທີ່ທ່ານເປີດຢູ່, ບໍ່ແມ່ນໃນສຳເນົາ: ໜ້າວຽກທີ່ມັນເພີ່ມຈະສະແດງຢູ່ໃນ Gantt ທັນທີ. ມັນໃຊ້ການຄິດໄລ່ດຽວກັນ ແລະ ປະຫວັດ *ກັບຄືນ* ດຽວກັນກັບທ່ານ.

ຂົວເຊື່ອມຕໍ່ໃຊ້ງານໄດ້ສະເພາະໃນແອັບ Desktop ເທົ່ານັ້ນ. ຖ້າທ່ານອະນຸຍາດການເຊື່ອມຕໍ່ MCP ໃນບຣາວເຊີ, ທ່ານຈະເຫັນແຖບ *MCP*, ແຕ່ປຸ່ມ *ເລີ່ມຂົວເຊື່ອມຕໍ່* ເປັນສີເທົາ ພ້ອມຂໍ້ຄວາມ *ຂົວເຊື່ອມຕໍ່ໃຊ້ງານໄດ້ສະເພາະໃນແອັບ Desktop ເທົ່ານັ້ນ*. ສ່ວນທີ່ເຫຼືອຂອງບົດຄວາມນີ້ແມ່ນກ່ຽວກັບແອັບ Desktop. ໃນບຣາວເຊີ, ປຸ່ມ *ສຳຮອງຂໍ້ມູນດຽວນີ້* ແລະ ປຸ່ມ *ເປີດໂຟນເດີສຳຮອງຂໍ້ມູນ* ກໍເປັນສີເທົາເຊັ່ນກັນ.

## ຂັ້ນຕອນ

### 1. ອະນຸຍາດການເຊື່ອມຕໍ່ MCP

1. ເລືອກ *ການຕັ້ງຄ່າ › ໂຄງການ › ການຕັ້ງຄ່າແອັບ*. ທ່ານຍັງສາມາດເລືອກ *ໄຟລ໌ › ການຕັ້ງຄ່າແອັບ* ໄດ້ ຫຼື ກົດໄອຄອນເກຍຢູ່ດ້ານເທິງ.
2. ເລືອກແຖບ *ຂັ້ນສູງ* ແລ້ວເປີດ *ອະນຸຍາດການເຊື່ອມຕໍ່ MCP*. ແຖບ *MCP* ຈະປາກົດຢູ່ໃນແຖບເຄື່ອງມື.
3. ຖ້າທ່ານຕ້ອງການໃຫ້ຂົວເຊື່ອມຕໍ່ພວມເຮັດວຽກທັນທີທີ່ແອັບເລີ່ມ ໃຫ້ເປີດ *ເລີ່ມຂົວເຊື່ອມຕໍ່ອັດຕະໂນມັດ* ນຳ. ຕົວເລືອກນີ້ເຮັດວຽກພຽງເວລາການເຊື່ອມຕໍ່ MCP ເປີດຢູ່ ແລະ ໃຊ້ໄດ້ສະເພາະໃນແອັບເດັສທັອບເທົ່ານັ້ນ. ຄ່າເລີ່ມຕົ້ນແມ່ນປິດ ເພາະການເປີດພອດເປັນການເລືອກທີ່ຕັ້ງໃຈ.

ຖ້າທ່ານປິດການເຊື່ອມຕໍ່ MCP ຂົວເຊື່ອມຕໍ່ຈະຢຸດ ແລະ ແຖບ *MCP* ຈະຫາຍໄປ.

### 2. ເລີ່ມຂົວເຊື່ອມຕໍ່

1. ໄປທີ່ແຖບ *MCP* ແລ້ວກົດ *ເລີ່ມຂົວເຊື່ອມຕໍ່* ພາຍໃຕ້ *ເຊີເວີ*.
2. ເບິ່ງສະຖານະຢູ່ຂ້າງປຸ່ມ. ມັນສະແດງ *ປິດ*, *ພວມເຮັດວຽກຢູ່ພອດ 3877*, *ພອດ 3877 ພວມຖືກໃຊ້ງານ* ຫຼື *ຂໍ້ຜິດພາດ*. ຖ້າການເລີ່ມສຳເລັດ ມັນສະແດງ *ພວມເຮັດວຽກຢູ່ພອດ 3877* ແລະ ປຸ່ມຊື່ວ່າ *ຢຸດຂົວເຊື່ອມຕໍ່*. ຖ້າມີ *ພອດ 3877 ພວມຖືກໃຊ້ງານ* ຫຼື *ຂໍ້ຜິດພາດ* ປຸ່ມຍັງເປັນ *ເລີ່ມຂົວເຊື່ອມຕໍ່*; ເບິ່ງຈຸດທີ່ຕ້ອງລະວັງ.

ຂົວເຊື່ອມຕໍ່ຟັງສະເພາະຢູ່ໃນຄອມພິວເຕີຂອງທ່ານເອງ ແລະ ໃຊ້ພອດດຽວເທົ່ານັ້ນ. ຄ່າເລີ່ມຕົ້ນແມ່ນ 3877. ໃນກຸ່ມ *ການເຊື່ອມຕໍ່* ທ່ານສາມາດເລືອກພອດອື່ນໄດ້ພາຍໃຕ້ *ພອດ* ແຕ່ພຽງເວລາທີ່ຂົວເຊື່ອມຕໍ່ຢຸດຢູ່ເທົ່ານັ້ນ. ການເຊື່ອມຕໍ່ເປັນ HTTP ທຳມະດາຢູ່ໃນຄອມພິວເຕີຂອງທ່ານເອງ. ແອັບເອງບໍ່ສົ່ງຂໍ້ມູນອອກໄປ. ສິ່ງທີ່ໄຄລເອັນ MCP ເຮັດກັບແຜນງານຂອງທ່ານ ເຊັ່ນ ສິ່ງທີ່ຜູ້ໃຫ້ບໍລິການຂອງມັນເຮັດ ຢູ່ນອກຂອບເຂດຂອງແອັບ.

### 3. ເຊື່ອມຕໍ່ໄຄລເອັນ MCP

1. ກົດ *ເຊື່ອມຕໍ່* ພາຍໃຕ້ *ການເຊື່ອມຕໍ່*. ໜ້າຕ່າງ *ລາຍລະອຽດການເຊື່ອມຕໍ່* ຈະເປີດ.
2. ເລືອກສິ່ງທີ່ໄຄລເອັນຂອງທ່ານຕ້ອງການ, ເບິ່ງຂ້າງລຸ່ມ.
3. ໂທເຄັນຖືກເຊື່ອງໄວ້. ກົດໄອຄອນຕາເພື່ອສະແດງມັນ. ປຸ່ມຄັດລອກຈະຄັດລອກຄ່າຈິງສະເໝີ ເຖິງແມ່ນວ່າໜ້າຈໍເຊື່ອງໂທເຄັນຢູ່ກໍຕາມ.
4. ໃຫ້ໄຄລເອັນ MCP ຂໍລາຍການເຄື່ອງມື. ການກວດນີ້ຢູ່ໃນຂໍ້ຄວາມຄຳສັ່ງເຊື່ອມຕໍ່ດ້ວຍ: ມັນຄວນເຫັນເຄື່ອງມືທີ່ມີຄຳນຳໜ້າ `planner_`; ຈຳນວນທີ່ຄາດໄວ້ຢູ່ໃນຂໍ້ຄວາມຄຳສັ່ງເຊື່ອມຕໍ່.

ໜ້າຕ່າງນີ້ມີສີ່ວິທີໃນການເຊື່ອມຕໍ່:

- *ໃຫ້ Claude ຈັດການໃຫ້*: ຂໍ້ຄວາມຄຳສັ່ງດຽວກັນກັບທີ່ຢູ່ດ້ານເທິງຂອງບົດຄວາມນີ້, ພ້ອມປຸ່ມ *ຄັດລອກຄຳສັ່ງ*. ອັນນີ້ໃຊ້ສຳລັບ Claude Desktop ແລະ Claude Code. ທ່ານບໍ່ຕ້ອງໃຊ້ໂທເຄັນສຳລັບອັນນີ້.
- *ໂຄດການຕັ້ງຄ່າ*: ສ່ວນໜຶ່ງຂອງການຕັ້ງຄ່າ ທີ່ທ່ານວາງລົງໃນການຕັ້ງຄ່າ MCP ຂອງໄຄລເອັນ.
- *ຂໍ້ຄວາມຄຳສັ່ງເຊື່ອມຕໍ່*: ຂໍ້ຄວາມທີ່ທ່ານວາງລົງໃນໄຄລເອັນ MCP ຂອງທ່ານ ຫຼັງຈາກນັ້ນມັນເຊື່ອມຕໍ່ດ້ວຍຕົນເອງ.
- *Endpoint* ແລະ *ການຢືນຢັນຕົວຕົນ*: ລາຍລະອຽດແຍກຕ່າງຫາກ. *Endpoint* ແມ່ນ `http://localhost:3877/mcp` ດ້ວຍການສົ່ງຂໍ້ມູນ *streamable HTTP*. ທຸກຄຳຂໍຕ້ອງມີສ່ວນຫົວ `Authorization: Bearer` ຕາມດ້ວຍໂທເຄັນຂອງທ່ານ. ໄຄລເອັນຂອງທ່ານຕ້ອງຮອງຮັບເຊດຊັນ MCP ນຳ: ເມື່ອມັນເຊື່ອມຕໍ່ ຂົວເຊື່ອມຕໍ່ຈະໃຫ້ລະຫັດເຊດຊັນໄວ້ໃນສ່ວນຫົວ `Mcp-Session-Id` ແລະ ມັນຈະປະຕິເສດທຸກຄຳຂໍຕໍ່ມາທີ່ບໍ່ມີລະຫັດນັ້ນ. Claude Code ແລະ `mcp-remote` ເຮັດອັນນີ້ດ້ວຍຕົນເອງ.

**ເຊື່ອມຕໍ່ໃໝ່ຫຼັງອັບເດດແອັບ.** ຖ້າໄຄລເອັນ MCP ຂອງທ່ານເຊື່ອມຕໍ່ກັບແອັບລຸ້ນເກົ່າຢູ່ແລ້ວ ມັນຍັງບໍ່ສົ່ງລະຫັດເຊດຊັນ ແລະ ຂົວເຊື່ອມຕໍ່ຈະປະຕິເສດທຸກຄຳຂໍ. ສະນັ້ນ ໃຫ້ເຊື່ອມຕໍ່ໃໝ່ຫຼັງຈາກອັບເດດ: ເລີ່ມເຊດຊັນໃໝ່ໃນ Claude Code ແລະ ປິດ Claude Desktop ໃຫ້ໝົດ ແລ້ວເປີດໃໝ່.

**Claude Code.** ໂຄດການຕັ້ງຄ່າເໝາະກັບ Claude Code ໂດຍກົງ. ປ້ອນຄຳສັ່ງນີ້ໃນເທີມິນໍ ໂດຍໃຊ້ໂທເຄັນຂອງທ່ານເອງແທນ `<token>`:

```
claude mcp add --transport http open-planner-studio http://localhost:3877/mcp --header "Authorization: Bearer <token>"
```

ທ່ານຍັງສາມາດໃສ່ໂຄດການຕັ້ງຄ່າໃນໄຟລ໌ `.mcp.json` ໃນໂຟນເດີໂຄງການຂອງທ່ານໄດ້. ສະນັ້ນ ຢ່າເອົາໄຟລ໌ນັ້ນເຂົ້າ git ເພາະໂທເຄັນໃຫ້ສິດເຂົ້າເຖິງແຜນງານຂອງທ່ານ. ເຊີເວີຈາກ `.mcp.json` ຕ້ອງໄດ້ຮັບການອະນຸມັດຄັ້ງທຳອິດໃນ Claude Code.

**Claude Desktop.** ສຳລັບ Claude Desktop ມີສ່ວນເສີມ, ຄື ໄຟລ໌ `open-planner-studio-<version>.mcpb`. Claude Desktop ຕິດຕັ້ງມັນດ້ວຍການດັບເບີ້ນຄລິກ. ທ່ານບໍ່ຕ້ອງໃຊ້ Node.js ສຳລັບອັນນີ້. ສ່ວນເສີມນີ້ໃຊ້ໄດ້ທັງກັບແອັບ ແລະ ໂດຍບໍ່ມີແອັບ. ມັນໄວກວ່າດ້ວຍຂໍ້ຄວາມຄຳສັ່ງດ້ານເທິງຂອງບົດຄວາມນີ້; ດ້ານລຸ່ມແມ່ນຂັ້ນຕອນດ້ວຍຕົນເອງ.

1. ດາວໂຫຼດໄຟລ໌ `.mcpb` ຈາກການປ່ອຍລຸ້ນຫຼ້າສຸດ: `https://github.com/OpenAEC-Foundation/open-planner-studio/releases/latest`.
2. ດັບເບີ້ນຄລິກໃສ່ໄຟລ໌. Claude Desktop ຈະເປີດ ແລະ ສະແດງສ່ວນເສີມ *Open Planner Studio*. ກົດ *Install*. ຖ້າການດັບເບີ້ນຄລິກບໍ່ເຮັດວຽກ ໃຫ້ເປີດ *ການຕັ້ງຄ່າ › Extensions* ໃນ Claude Desktop ແລ້ວຕິດຕັ້ງໄຟລ໌ຢູ່ບ່ອນນັ້ນ.
3. ໃນ *Working folder* ໃຫ້ເລືອກໂຟນເດີທີ່ມີໄຟລ໌ແຜນງານຂອງທ່ານ. Claude ໃຊ້ໂຟນເດີນີ້ພຽງເວລາແອັບປິດຢູ່ເທົ່ານັ້ນ. ຈາກນັ້ນ Claude ອ່ານ ແລະ ຂຽນໄດ້ສະເພາະໃນໂຟນເດີນັ້ນເທົ່ານັ້ນ.
4. ເປີດສ່ວນເສີມ ແລ້ວເລີ່ມການສົນທະນາໃໝ່. ຖາມ Claude ວ່າມັນເຫັນເຄື່ອງມືໃດຂອງ Open Planner Studio.

ທ່ານບໍ່ຕ້ອງປ້ອນໂທເຄັນ ຫຼື ພອດ: ໃນຂະນະທີ່ຂົວເຊື່ອມຕໍ່ເຮັດວຽກ ສ່ວນເສີມຊອກຫາແອັບດ້ວຍຕົນເອງ. ສຳລັບທຸກຄຳຖາມຈາກ Claude ສ່ວນເສີມຈະເລືອກໃໝ່ອີກຄັ້ງ:

- *ແອັບເປີດຢູ່ ແລະ ຂົວເຊື່ອມຕໍ່ເຮັດວຽກຢູ່*: Claude ເຮັດວຽກໃນແຜນງານທີ່ເປີດຢູ່ໃນແອັບ. ທ່ານເຫັນທຸກການປ່ຽນແປງໃນແອັບທັນທີ.
- *ແອັບປິດຢູ່, ຫຼື ຂົວເຊື່ອມຕໍ່ປິດຢູ່*: Claude ເຮັດວຽກກັບໄຟລ໌ແຜນງານໃນໂຟນເດີເຮັດວຽກ. ການປ່ຽນແປງຢູ່ໃນໄຟລ໌ພຽງເມື່ອ Claude ບັນທຶກໄຟລ໌ນັ້ນເທົ່ານັ້ນ. ບໍ່ມີການບັນທຶກອັດຕະໂນມັດ. ໃນຂະນະທີ່ແອັບເປີດຢູ່ Claude ບໍ່ຂຽນທັບໄຟລ໌ທີ່ມີຢູ່ແລ້ວ ແຕ່ບັນທຶກດ້ວຍຊື່ໃໝ່ແທນ.

ຖ້າແອັບເປີດ ຫຼື ປິດໃນຂະນະທີ່ Claude ເຮັດວຽກ ສ່ວນເສີມຈະສະຫຼັບ ແລະ ບອກ Claude. ຈາກນັ້ນ Claude ເລືອກ ຫຼື ເປີດແຜນງານອີກຄັ້ງກ່ອນ ແລະ ຈຶ່ງປ່ຽນແປງຫຍັງ. ຖ້າ Claude ຍັງມີການປ່ຽນແປງທີ່ບໍ່ໄດ້ບັນທຶກໂດຍບໍ່ມີແອັບ ສ່ວນເສີມຈະເຮັດວຽກຕໍ່ໂດຍບໍ່ມີແອັບ ຈົນກວ່າ Claude ຈະບັນທຶກມັນ. ດ້ວຍວິທີນີ້ ບໍ່ມີວຽກໃດສູນຫາຍ. ຖ້າສ່ວນເສີມເຂົ້າເຖິງແອັບບໍ່ໄດ້ ແລະ ບໍ່ມີໂຟນເດີເຮັດວຽກທີ່ໃຊ້ໄດ້, Claude ເຫັນພຽງເຄື່ອງມື `open_planner_studio_status` ພ້ອມຂໍ້ຄວາມທີ່ບອກທ່ານວ່າຕ້ອງເຮັດຫຍັງ.

**Claude Desktop ໂດຍບໍ່ມີສ່ວນເສີມ.** ຖ້າທ່ານໃຊ້ສ່ວນເສີມບໍ່ໄດ້ ໃຫ້ເຊື່ອມຕໍ່ Claude Desktop ດ້ວຍເຄື່ອງມືພາຍນອກ `mcp-remote`. ໂຄດການຕັ້ງຄ່າບໍ່ເໝາະກັບ Claude Desktop ໂດຍກົງ: ໃນໄຟລ໌ `claude_desktop_config.json` ທ່ານລະບຸໂປຣແກຣມທີ່ Claude Desktop ເລີ່ມເອງ ບໍ່ແມ່ນທີ່ຢູ່. `mcp-remote` ຕ້ອງການ Node.js. ໃນ Claude Desktop ໃຫ້ເລືອກ *ການຕັ້ງຄ່າ › Developer › Edit Config*, ວາງສິ່ງນີ້ລົງໃນໄຟລ໌ (ດ້ວຍໂທເຄັນຂອງທ່ານເອງ) ແລ້ວເປີດ Claude Desktop ໃໝ່:

```
{
  "mcpServers": {
    "open-planner-studio": {
      "command": "npx",
      "args": ["-y", "mcp-remote", "http://localhost:3877/mcp", "--header", "Authorization:${AUTH_HEADER}"],
      "env": { "AUTH_HEADER": "Bearer <token>" }
    }
  }
}
```

ໂທເຄັນຢູ່ໃນ `env` ແລະ ບໍ່ແມ່ນໃນ `args` ໂດຍຕັ້ງໃຈ: ໃນ Windows, Claude Desktop ຈະທຳລາຍຄ່າພາຣາມິເຕີທີ່ມີຊ່ອງຫວ່າງ. *custom connector* ໃນ Claude (*Customize › Connectors*) ໃຊ້ກັບຂົວເຊື່ອມຕໍ່ບໍ່ໄດ້. ຈາກນັ້ນ Claude ເຊື່ອມຕໍ່ຈາກຄລາວຂອງ Anthropic ແລະ ຄລາວນັ້ນເຂົ້າເຖິງຂົວເຊື່ອມຕໍ່ຢູ່ໃນຄອມພິວເຕີຂອງທ່ານເອງບໍ່ໄດ້.

ໃນກຸ່ມ *ການເຊື່ອມຕໍ່* ມີຊ່ອງ *ໂທເຄັນ* ນຳ. ມັນເປັນລະຫັດຍາວແບບສຸ່ມ ທີ່ແອັບສ້າງໃຫ້ທ່ານ ແລະ ເກັບໄວ້ໃນຄອມພິວເຕີນີ້. ໃນໜ້າຕ່າງມັນສະແດງວ່າ *ໂທເຄັນນີ້ອະນຸຍາດໃຫ້ເຂົ້າເຖິງແຜນງານທີ່ເປີດຢູ່. ຫ້າມແບ່ງປັນໃຫ້ຜູ້ອື່ນ.* ດ້ວຍໄອຄອນ *ສ້າງໂທເຄັນໃໝ່* ທ່ານສ້າງໂທເຄັນໃໝ່. ແອັບຖາມກ່ອນວ່າ *ການສ້າງໂທເຄັນໃໝ່ຈະຕັດການເຊື່ອມຕໍ່ທີ່ມີຢູ່ທັງໝົດ. ດຳເນີນການຕໍ່ຫຼືບໍ່?* ຖ້າຂົວເຊື່ອມຕໍ່ພວມເຮັດວຽກ ມັນຈະເລີ່ມໃໝ່ດ້ວຍໂທເຄັນໃໝ່ ແລະ ໂທເຄັນເກົ່າຈະໃຊ້ບໍ່ໄດ້ອີກ.

**ຊອກຫາແອັບແນວໃດ.** ໃນຂະນະທີ່ຂົວເຊື່ອມຕໍ່ເຮັດວຽກ ແອັບເດັສທັອບຈະຂຽນພອດ ແລະ ໂທເຄັນລົງໃນໄຟລ໌ `mcp/runtime.json` ໃນໂຟນເດີຂໍ້ມູນຂອງແອັບ. ສ່ວນເສີມສຳລັບ Claude Desktop ອ່ານໄຟລ໌ນັ້ນສຳລັບທຸກຄຳຖາມ. ໃນ Linux ແລະ macOS ມີພຽງບັນຊີຜູ້ໃຊ້ຂອງທ່ານເທົ່ານັ້ນທີ່ອ່ານໄຟລ໌ໄດ້. ໃນ Windows ການຕັ້ງຄ່າ ACL ເລີ່ມຕົ້ນຂອງໂຟນເດີໂປຣໄຟລ໌ຂອງທ່ານປົກປ້ອງໄຟລ໌ນັ້ນ; ແອັບບໍ່ກວດສອບອັນນີ້ແຍກຕ່າງຫາກ. ເມື່ອທ່ານຢຸດຂົວເຊື່ອມຕໍ່ ຫຼື ປິດການເຊື່ອມຕໍ່ MCP ແອັບຈະລຶບໄຟລ໌ນັ້ນ. ແອັບຍັງເກັບລາຍການໄຟລ໌ທີ່ເປີດຢູ່ໄວ້ໃນ `mcp/open-files.json` ເຖິງແມ່ນການເຊື່ອມຕໍ່ MCP ປິດຢູ່. ໃນຂະນະທີ່ໄຟລ໌ນັ້ນມີຢູ່ ສ່ວນເສີມ ແລະ ເຊີເວີ MCP ທີ່ບໍ່ມີໜ້າຈໍ ຈະບໍ່ຂຽນທັບໄຟລ໌ທີ່ມີຢູ່ແລ້ວ ແມ່ນແຕ່ໄຟລ໌ທີ່ທ່ານພຶ່ງເປີດ ແລະ ຍັງບໍ່ຢູ່ໃນລາຍການ. ການສ້າງໄຟລ໌ໃໝ່ແມ່ນອະນຸຍາດ. ການອ່ານກໍອະນຸຍາດເຊັ່ນກັນ: Claude ຈະເຫັນລຸ້ນທີ່ຢູ່ໃນດິສກ໌, ໂດຍບໍ່ມີການປ່ຽນແປງຂອງທ່ານທີ່ຍັງບໍ່ໄດ້ບັນທຶກ.

### 4. ເບິ່ງວ່າໄຄລເອັນ MCP ເຮັດຫຍັງ

1. ກົດ *ແຜງການເຄື່ອນໄຫວ* ພາຍໃຕ້ *ກິດຈະກຳ*. ແຜງ *ການເຄື່ອນໄຫວ MCP* ຈະເປີດຢູ່ດ້ານຂ້າງ.
2. ແຕ່ລະການເອີ້ນໃຊ້ຂອງຂົວເຊື່ອມຕໍ່ຢູ່ໃນແຖວຂອງມັນເອງ, ແຖວທີ່ໃໝ່ທີ່ສຸດຢູ່ດ້ານເທິງ: ເວລາ, ສິ່ງທີ່ເກີດຂຶ້ນ, ໃຊ້ເວລາດົນປານໃດ ແລະ ສຳເລັດຫຼືບໍ່. ກົດແຖວເພື່ອຂະຫຍາຍ *ຄ່າພາຣາມິເຕີ* ແລະ *ຜົນຕອບຮັບ*.
3. ດ້ວຍ *ລຶບລ້າງ* ທ່ານລຶບລາຍການທັງໝົດ. ແຜງເກັບ 500 ການເອີ້ນໃຊ້ສຸດທ້າຍ. ຕາບໃດທີ່ຍັງບໍ່ມີຫຍັງເກີດຂຶ້ນ ມັນສະແດງວ່າ *ຍັງບໍ່ມີການເຄື່ອນໄຫວ MCP. ການເອີ້ນໃຊ້ຂົວເຊື່ອມຕໍ່ຈະສະແດງຢູ່ບ່ອນນີ້.*

ເມື່ອການເຊື່ອມຕໍ່ MCP ເປີດຢູ່ ມີຈຸດທີ່ມີຂໍ້ຄວາມ *MCP* ຢູ່ມຸມຂວາລຸ່ມຂອງແຖບສະຖານະ. ສີຂອງມັນສະແດງສະຖານະຂອງຂົວເຊື່ອມຕໍ່ ແລະ ການກົດໃສ່ມັນນຳທ່ານໄປຫາແຖບ *MCP*.

### 5. ກຳນົດຂອບເຂດ

ພາຍໃຕ້ *ຄວາມປອດໄພ* ມີປຸ່ມທີ່ທ່ານໃຊ້ຈຳກັດໄຄລເອັນ MCP:

- *ພັກຊົ່ວຄາວ*: ໄຄລເອັນ MCP ປ່ຽນແປງຫຍັງບໍ່ໄດ້ຊົ່ວຄາວ ແຕ່ການອ່ານຍັງອະນຸຍາດຢູ່. ຂົວເຊື່ອມຕໍ່ຍັງເຮັດວຽກຢູ່. ປຸ່ມຈະປ່ຽນເປັນ *ສືບຕໍ່*.
- *ອ່ານຢ່າງດຽວ*: ເຄື່ອງມືທັງໝົດທີ່ປ່ຽນແປງຫຍັງຖືກປະຕິເສດ ໃນຂະນະທີ່ອັນນີ້ເປີດຢູ່.
- *ສຳຮອງຂໍ້ມູນອັດຕະໂນມັດ: ເປີດ*: ກ່ອນການປ່ຽນແປງຄັ້ງທຳອິດໂດຍໄຄລເອັນ MCP ໃນເອກະສານ ແອັບຈະຂຽນການສຳຮອງຂໍ້ມູນ IFC. ອັນນີ້ເປີດຢູ່ຕາມຄ່າເລີ່ມຕົ້ນ. ດ້ວຍປຸ່ມ ທ່ານປິດມັນໄດ້, ແລ້ວມັນຈະສະແດງ *ສຳຮອງຂໍ້ມູນອັດຕະໂນມັດ: ປິດ*. ເລື່ອງນີ້ເກີດຂຶ້ນຄັ້ງດຽວຕໍ່ເອກະສານທຸກຄັ້ງທີ່ທ່ານເລີ່ມຂົວເຊື່ອມຕໍ່.
- *ສຳຮອງຂໍ້ມູນດຽວນີ້*: ສ້າງການສຳຮອງຂໍ້ມູນຂອງເອກະສານທີ່ເປີດຢູ່ທັນທີ. ຫຼັງຈາກນັ້ນມັນສະແດງ *ສ້າງສຳຮອງຂໍ້ມູນແລ້ວ:* ພ້ອມຊື່ໄຟລ໌.
- *ເປີດໂຟນເດີສຳຮອງຂໍ້ມູນ*: ເປີດໂຟນເດີທີ່ມີການສຳຮອງຂໍ້ມູນ.

ການສຳຮອງຂໍ້ມູນຢູ່ໃນໂຟນເດີ `ai-backups` ໃນໂຟນເດີຂໍ້ມູນຂອງແອັບ. ແອັບເກັບການສຳຮອງຂໍ້ມູນຫຼ້າສຸດໄວ້ ແລະ ລຶບອັນເກົ່າອອກບາງສ່ວນ; ລາຍລະອຽດແນ່ນອນຢູ່ໃນ [ເຄື່ອງມື MCP](docs://ref-ai-tools).

### 6. ໃຫ້ໄຄລເອັນ MCP ວາງແຜນໄດ້ດີ

ໄຄລເອັນ MCP ຈະວາງແຜນໄດ້ດີກໍຕໍ່ເມື່ອມັນຮູ້ກົດການວາງແຜນ. ນີ້ແມ່ນສິ່ງທີ່ທ່ານເຮັດເອງ:

1. **ບໍ່ຕ້ອງເຮັດຫຍັງສຳລັບກົດຫຼັກ.** ກົດເຫຼົ່ານັ້ນມາພ້ອມການເຊື່ອມຕໍ່: ຂົວເຊື່ອມຕໍ່ສົ່ງພວກມັນໄປໃນຊ່ອງ `instructions` ຂອງການຈັບມື MCP. ວ່າໄຄລເອັນຂອງທ່ານໃສ່ພວກມັນໃນຂໍ້ຄວາມຄຳສັ່ງຂອງລະບົບຫຼືບໍ່ ແມ່ນຂຶ້ນກັບໄຄລເອັນນັ້ນ.
2. **ໃຫ້ອ່ານຄູ່ມືນຳ.** ຂໍ້ຄວາມຄຳສັ່ງເຊື່ອມຕໍ່ຈາກໜ້າຕ່າງ *ລາຍລະອຽດການເຊື່ອມຕໍ່* ຂໍໃຫ້ໄຄລເອັນ MCP ອ່ານຄູ່ມືດ້ວຍເຄື່ອງມື `planner_get_planning_guide`. ຖ້າທ່ານບໍ່ໃຊ້ຂໍ້ຄວາມຄຳສັ່ງ ໃຫ້ບອກໄຄລເອັນວ່າ: *ອ່ານຄູ່ມືການວາງແຜນດ້ວຍ planner_get_planning_guide ກ່ອນ, ກ່ອນທີ່ຈະປ່ຽນແປງຫຍັງ.* ທ່ານສາມາດອ່ານຄູ່ມືດ້ວຍຕົນເອງທີ່ `https://open-planner-studio.open-aec.com/agent/planning-guide.md`.
3. **ທາງເລືອກ: ຕິດຕັ້ງທັກສະ.** ອັນນີ້ໃຊ້ໄດ້ພຽງກັບໄຄລເອັນ MCP ທີ່ຮອງຮັບທັກສະເທົ່ານັ້ນ. ໃສ່ `SKILL.md` ຂອງ *goed-plannen* ແລະ *progress-update* ໄວ້ທີ່ `.claude/skills/goed-plannen/SKILL.md` ແລະ `.claude/skills/progress-update/SKILL.md` ໃນໂຟນເດີໂຄງການທີ່ໄຄລເອັນ MCP ເຮັດວຽກ ຫຼື ໄວ້ໃຕ້ `~/.claude/skills/` ສຳລັບທຸກໂຄງການ.

ທ່ານຮັບໄຟລ໌ໄດ້ສອງວິທີ. ໃຫ້ໄຄລເອັນ MCP ເອີ້ນເຄື່ອງມື `planner_get_planning_guide` ໂດຍຕັ້ງ `part` ເປັນ `skill`: ຜົນຕອບຮັບມີທັງສອງຂໍ້ຄວາມ ແລະ ສຳລັບແຕ່ລະທັກສະ ມີບ່ອນທີ່ມັນຄວນຢູ່. ຫຼື ດາວໂຫຼດຈາກ `https://open-planner-studio.open-aec.com/skills/goed-plannen/SKILL.md` ແລະ `https://open-planner-studio.open-aec.com/skills/progress-update/SKILL.md`. ຖ້າ *goed-plannen* ຍັງຢູ່ຈາກແອັບລຸ້ນເກົ່າ ໃຫ້ປ່ຽນແທນມັນ: ຂໍ້ຄວາມເກົ່ານັ້ນເປັນພາສາດັດ ແລະ ຊີ້ໄປທີ່ບົດຊ່ວຍເຫຼືອແທນທີ່ຈະເປັນຄູ່ມືສຳລັບໄຄລເອັນ MCP.

ທ່ານເຫັນໄດ້ວ່າໄຄລເອັນ MCP ອ່ານຄູ່ມືແທ້ຫຼືບໍ່ໃນ *ແຜງການເຄື່ອນໄຫວ*: ຈະມີການເອີ້ນ `planner_get_planning_guide`. ຄຳຕອບສຸດທ້າຍທີ່ມັນໃຫ້ຄວນມີລາຍການສົມມຸດຖານ: ໄລຍະເວລາທີ່ປະມານໄວ້, ການແບ່ງຍ່ອຍທີ່ເລືອກ, ສາຍສຳພັນທີ່ມັນສ້າງເອງ ແລະ ທຸກເງື່ອນໄຂທີ່ມັນຕັ້ງ. ຖ້າລາຍການນັ້ນຂາດ ໃຫ້ຂໍມັນ. ຫຼັງການອັບເດດຄວາມຄືບໜ້າຕາມ *progress-update* ຄຳຕອບຄວນລະບຸວັນທີສະຖານະ, ວັນທີສິ້ນສຸດໃໝ່ ແລະ ຄວາມແຕກຕ່າງກັບແຜນຫຼັກ.

## ຈຸດທີ່ຕ້ອງລະວັງ ແລະ ແອັບຈະເຮັດຫຍັງໃນກໍລະນີນັ້ນ

**ໄຄລເອັນ MCP ປ່ຽນແປງບາງຢ່າງທີ່ທ່ານຢາກຍົກເລີກ.** ທຸກການປ່ຽນແປງໂດຍໄຄລເອັນ MCP ແມ່ນໜຶ່ງຂັ້ນຕອນທີ່ທ່ານຍົກເລີກດ້ວຍ *ຍົກເລີກຄຳສັ່ງ* (Ctrl+Z). ຊຸດການປ່ຽນແປງທີ່ໄຄລເອັນ MCP ສົ່ງເປັນໜ່ວຍດຽວ ເປັນໜຶ່ງຂັ້ນຕອນ. ຫຼັງຈາກນັ້ນໂຄງການຈະສະແດງວ່າ ຍັງບໍ່ໄດ້ບັນທຶກ. ຫຼັງການປ່ຽນແປງ ແຜນງານຖືກຄິດໄລ່ຄືນໃໝ່, ດັ່ງນັ້ນທ່ານບໍ່ຕ້ອງກົດ F5 ເອງ.

**ແອັບປະຕິເສດການເອີ້ນໃຊ້ຈາກໄຄລເອັນ MCP.** ດ້ວຍ *ພັກຊົ່ວຄາວ* ແລະ *ອ່ານຢ່າງດຽວ* ແອັບປະຕິເສດທຸກການປ່ຽນແປງ ແລະ ການອ່ານຍັງເປັນໄປໄດ້, ລວມທັງການຄິດໄລ່ຄືນໃໝ່ຂອງແຜນງານທີ່ບໍ່ເປັນປັດຈຸບັນ. ຖ້າທ່ານກຳລັງແກ້ໄຂຢູ່ເອງ ເຊັ່ນ ລາກແຖບໜ້າວຽກ ຫຼື ພິມໃນຊ່ອງ, ໄຄລເອັນ MCP ຈະໄດ້ວັນທີກ່ອນການແກ້ໄຂຂອງທ່ານ ພ້ອມແຈ້ງເຕືອນວ່າວັນທີເຫຼົ່ານັ້ນບໍ່ເປັນປັດຈຸບັນ. ຖ້າມີກ່ອງໂຕ້ຕອບເປີດຢູ່ ເຊັ່ນ ການຕັ້ງຄ່າ, ກ່ອງໂຕ້ຕອບໜ້າວຽກ ຫຼື ໜ້າຕ້ອນຮັບ, ຫຼື ໂໝດນຳສະເໜີເປີດຢູ່, ແອັບຈະປະຕິເສດທຸກການເອີ້ນໃຊ້, ລວມທັງການອ່ານ, ຈົນກວ່າທ່ານຈະປິດກ່ອງໂຕ້ຕອບ. ຈາກນັ້ນໄຄລເອັນ MCP ຈະໄດ້ຂໍ້ຄວາມຜິດພາດພ້ອມຊື່ພາຍໃນຂອງສິ່ງທີ່ເປີດຢູ່, ເຊັ່ນ `showTaskDialog`. ມີພຽງ `planner_get_planning_guide` ເທົ່ານັ້ນທີ່ຍັງເຮັດວຽກ, ເພາະມັນບໍ່ອ່ານແຜນງານຂອງທ່ານ.

**ທ່ານປ່ຽນແຖບໃນຂະນະທີ່ໄຄລເອັນ MCP ກຳລັງເຮັດວຽກ.** ໄຄລເອັນ MCP ເຮັດວຽກໃນເອກະສານທີ່ການປ່ຽນແປງທຳອິດຂອງມັນເກີດຂຶ້ນ. ຖ້າທ່ານປ່ຽນແຖບໃນລະຫວ່າງນັ້ນ ແອັບຈະປະຕິເສດການປ່ຽນແປງຕໍ່ໄປຂອງມັນ ຈົນກວ່າມັນຢືນຢັນວ່າຢາກເຮັດວຽກໃນແຖບອື່ນ. ດ້ວຍວິທີນີ້ ບໍ່ມີຫຍັງໄປລົງໃນໂຄງການຜິດ. ຖ້າໄຄລເອັນ MCP ເປີດ ຫຼື ສຳເນົາເອກະສານດ້ວຍຕົນເອງ, ມັນຈະເຮັດວຽກໃນເອກະສານໃໝ່ນັ້ນຫຼັງຈາກນັ້ນ.

**ໄຄລເອັນ MCP ຂຽນ ຫຼື ເປີດໄຟລ໌.** ໄຄລເອັນ MCP ສາມາດຂຽນແຜນງານເປັນໄຟລ໌ IFC ແລະ ເປີດໄຟລ໌ແຜນງານເປັນແຖບໃໝ່ໄດ້. ມັນເຮັດໄດ້ພຽງໃນໂຟນເດີຜູ້ໃຊ້ຂອງທ່ານເທົ່ານັ້ນ. ມັນຂຽນທັບໄຟລ໌ທີ່ມີຢູ່ແລ້ວພຽງເມື່ອຂໍຢ່າງຊັດເຈນເທົ່ານັ້ນ.

**ສະຖານະແມ່ນ *ພອດ 3877 ພວມຖືກໃຊ້ງານ*.** ໂປຣແກຣມອື່ນກຳລັງໃຊ້ພອດນັ້ນຢູ່. ຂໍ້ຄວາມຂອງແອັບສະແດງຢູ່ດ້ານລຸ່ມ. ຊ່ອງພອດຈະຖືກລັອກຕໍ່ໄປ (*ແກ້ໄຂໄດ້ພຽງເວລາເຊີເວີຢຸດຢູ່ເທົ່ານັ້ນ.*), ເຖິງແມ່ນຂົວເຊື່ອມຕໍ່ບໍ່ໄດ້ເຮັດວຽກ, ແລະ ບໍ່ມີປຸ່ມຢຸດ. ນີ້ເປັນຂໍ້ບົກຜ່ອງທີ່ຮູ້ຈັກແລ້ວ. ຈົນກວ່າຈະແກ້ໄຂ: ປິດ *ອະນຸຍາດການເຊື່ອມຕໍ່ MCP* ແລ້ວເປີດໃໝ່. ຈາກນັ້ນສະຖານະຈະກັບຄືນເປັນ *ປິດ* ແລະ ທ່ານສາມາດເລືອກພອດອື່ນໄດ້. ຈາກນັ້ນຄັດລອກລາຍລະອຽດການເຊື່ອມຕໍ່ໃໝ່ອີກຄັ້ງ ເພາະ *Endpoint* ມີພອດຢູ່ໃນນັ້ນ.

**ໄຄລເອັນເຊື່ອມຕໍ່ບໍ່ໄດ້ຫຼັງຈາກໂທເຄັນໃໝ່.** ໂທເຄັນໃໝ່ຕັດການເຊື່ອມຕໍ່ທີ່ມີຢູ່ທັງໝົດ. ໃຫ້ໄຄລເອັນໂທເຄັນໃໝ່, ຫຼື ວາງໂຄດການຕັ້ງຄ່າອີກຄັ້ງ. ສ່ວນເສີມໃນ Claude Desktop ອ່ານໂທເຄັນໃໝ່ດ້ວຍຕົນເອງ; ທ່ານບໍ່ຕ້ອງເຮັດຫຍັງຢູ່ບ່ອນນັ້ນ.

**ທ່ານຢຸດຂົວເຊື່ອມຕໍ່ເອງ ແລະ ມັນບໍ່ເລີ່ມເອງ.** *ເລີ່ມຂົວເຊື່ອມຕໍ່ອັດຕະໂນມັດ* ເຮັດວຽກໄດ້ໜຶ່ງຄັ້ງທຸກຄັ້ງທີ່ແອັບເລີ່ມ. ຖ້າທ່ານຢຸດຂົວເຊື່ອມຕໍ່ເອງ ແອັບຈະບໍ່ເປີດມັນຄືນໂດຍບໍ່ແຈ້ງ.

**ແຖບ *MCP* ຫາຍໄປແລ້ວ.** ການເຊື່ອມຕໍ່ MCP ປິດຢູ່. ເປີດມັນໃນຂັ້ນຕອນ 1.

**ໜ້າເວັບໃນເບຣາວເຊີຂອງທ່ານບໍ່ສາມາດສື່ສານກັບຂົວເຊື່ອມຕໍ່ໄດ້.** ຂົວເຊື່ອມຕໍ່ປະຕິເສດທຸກຄຳຂໍທີ່ມາຈາກເບຣາວເຊີ ແລະ ທຸກຄຳຂໍທີ່ບໍ່ມີໂທເຄັນທີ່ຖືກຕ້ອງ.

## ໂດຍບໍ່ມີແອັບ

ນອກຈາກນີ້ ຍັງມີເຊີບເວີ MCP ທີ່ເຮັດວຽກໂດຍບໍ່ຕ້ອງມີແອັບເດັສທັອບ: **ເຊີບເວີ MCP ແບບບໍ່ມີໜ້າຈໍ**. ມັນໃຫ້ເຄື່ອງມື `planner_*` ແບບດຽວກັນ ແຕ່ມັນເຮັດວຽກກັບໄຟລ໌ແຜນງານໃນດິສກ໌ ແທນທີ່ຈະເຮັດວຽກກັບໂຄງການທີ່ທ່ານເປີດຢູ່. ດັ່ງນັ້ນ ທ່ານຈະບໍ່ເຫັນການປ່ຽນແປງໃນແຜນພາບ Gantt ແລະ *ຍົກເລີກຄຳສັ່ງ* ໃນແອັບຈະບໍ່ໃຊ້ກັບການປ່ຽນແປງເຫຼົ່ານັ້ນ. ໃຊ້ມັນເມື່ອທ່ານບໍ່ຕ້ອງການເປີດແອັບ ຫຼື ຢູ່ໃນຄອມພິວເຕີທີ່ບໍ່ມີໜ້າຈໍ.

ສ່ວນເສີມສຳລັບ Claude Desktop ຈະເລີ່ມເຊີບເວີນີ້ເອງເມື່ອແອັບປິດຢູ່ (ເບິ່ງຂັ້ນຕອນທີ 3). ຂັ້ນຕອນຂ້າງລຸ່ມນີ້ແມ່ນສຳລັບໄຄລເອັນ MCP ອື່ນ ເຊັ່ນ Claude Code.

ລຸ້ນນີ້ບໍ່ມີໄຟລ໌ເຊີບເວີສຳເລັດຮູບໃຫ້ດາວໂຫຼດ. ທ່ານສ້າງມັນຈາກຊອດສ໌ໂຄດດ້ວຍ `npm run build:mcp-server`; ສຳລັບອັນນັ້ນ ທ່ານຕ້ອງມີ Node.js 22 ຫຼື ໃໝ່ກວ່າ. ຜົນໄດ້ຮັບແມ່ນໄຟລ໌ດຽວ `server.mjs`.

1. ເລືອກໂຟລເດີເຮັດວຽກທີ່ມີໄຟລ໌ແຜນງານຂອງທ່ານ. ເຊີບເວີອ່ານ ແລະ ຂຽນໄດ້ສະເພາະໃນໂຟລເດີນັ້ນ.
2. ເຊື່ອມຕໍ່ໄຄລເອັນ MCP ຂອງທ່ານ. ສຳລັບ Claude Code ຄຳສັ່ງຢູ່ລຸ່ມຂັ້ນຕອນເຫຼົ່ານີ້.
3. ຂໍໃຫ້ໄຄລເອັນ MCP ເປີດແຜນງານ, ຕົວຢ່າງ `~/plan.ifc`. ໃນເຊີບເວີນີ້ `~` ໝາຍເຖິງໂຟລເດີເຮັດວຽກ.
4. ຂໍໃຫ້ໄຄລເອັນ MCP ບັນທຶກຜົນໄດ້ຮັບ. ບໍ່ມີການບັນທຶກອັດຕະໂນມັດ: ໄຄລເອັນ MCP ຂຽນໄຟລ໌ດ້ວຍ `planner_export_ifc`. ສິ່ງທີ່ມັນບໍ່ບັນທຶກຈະສູນຫາຍເມື່ອເຊີບເວີຢຸດ.

ສຳລັບຂັ້ນຕອນທີ 2 ໃນ Claude Code ໃຫ້ປ້ອນຄຳສັ່ງນີ້ໃນເທີມິນໍ, ດ້ວຍເສັ້ນທາງຂອງທ່ານເອງ:

```
claude mcp add open-planner -- node /path/to/server.mjs --root /path/to/working-folder
```

ກ່ອນການປ່ຽນແປງຄັ້ງທຳອິດຂອງແຕ່ລະເອກະສານ ເຊີບເວີຈະສ້າງສຳຮອງ MCP, ຄືກັບແອັບ. ໄຄລເອັນ MCP ທີ່ເລືອກເສັ້ນທາງນອກໂຟລເດີເຮັດວຽກ, ລວມທັງຜ່ານທາງລັດ (symbolic link), ຈະໄດ້ຮັບການປະຕິເສດ. ໃນຂະນະທີ່ແອັບເປີດຢູ່, ເຊີບເວີຈະບໍ່ຂຽນທັບໄຟລ໌ທີ່ມີຢູ່ແລ້ວ.
