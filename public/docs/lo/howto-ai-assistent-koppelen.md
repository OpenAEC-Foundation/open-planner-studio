# ເຊື່ອມຕໍ່ຕົວຊ່ວຍ AI (MCP)

ເປົ້າໝາຍ: ໃຫ້ຕົວຊ່ວຍ AI ອ່ານຕາມ ແລະ ເຮັດວຽກກັບແຜນງານຂອງທ່ານ. ທ່ານເຫັນໄດ້ວ່າມັນເຮັດຫຍັງ. ທ່ານກຳນົດຂີດຈຳກັດເອງ.

## ເມື່ອທ່ານຕ້ອງການ

ທ່ານຕ້ອງການໃຫ້ຕົວຊ່ວຍ AI ອ່ານ ວິເຄາະ ຫຼື ປ່ຽນແຜນງານຂອງທ່ານ. ຕົວຢ່າງ ໃຫ້ມັນຮ່າງ WBS ທຳອິດ ແກ້ໄຂໜ້າວຽກ ຫຼື ອະທິບາຍເສັ້ນທາງວິກິດ. ສິ່ງນີ້ເຮັດວຽກຜ່ານ **Model Context Protocol** (MCP): ມາດຕະຖານທີ່ໃຫ້ຕົວຊ່ວຍ AI ໃຊ້ເຄື່ອງມືຂອງໂປຣແກຣມໄດ້. ສຳລັບສິ່ງນີ້ Open Planner Studio ເປີດເຊີເວີນ້ອຍໆ ໃນຄອມພິວເຕີຂອງທ່ານເອງ ເອີ້ນວ່າ **ຂົວເຊື່ອມຕໍ່**. ມັນໃຫ້ຊຸດເຄື່ອງມື ທຸກອັນມີຊື່ເລີ່ມດ້ວຍ `planner_`: ອ່ານ ແລະ ປ່ຽນໜ້າວຽກ, ສາຍສຳພັນ, ຊັບພະຍາກອນ, ປະຕິທິນ, ແຜນຫຼັກ, ເອກະສານ ແລະ ໄຟລ໌. ມີເຄື່ອງມືໃດແດ່ ແລະ ອັນໃດຖືກປະຕິເສດ ຢູ່ໃນ [ເຄື່ອງມື AI](docs://ref-ai-tools). ເປັນຫຍັງການເຊື່ອມຕໍ່ເຮັດວຽກແບບນີ້ ຢູ່ໃນ [ວິທີການເຊື່ອມຕໍ່ AI ເຮັດວຽກ](docs://uitleg-ai-koppeling).

ຂົວເຊື່ອມຕໍ່ເຮັດວຽກສະເພາະໃນແອັບ Desktop ເທົ່ານັ້ນ. ຖ້າທ່ານເປີດໂໝດ AI ໃນບຣາວເຊີ ທ່ານຈະເຫັນແຖບ *AI*. ແຕ່ປຸ່ມ *ເລີ່ມຂົວເຊື່ອມຕໍ່* ຈະເປັນສີເທົາ ພ້ອມຂໍ້ຄວາມ *ຂົວເຊື່ອມຕໍ່ໃຊ້ງານໄດ້ສະເພາະໃນແອັບ Desktop ເທົ່ານັ້ນ*. ສ່ວນທີ່ເຫຼືອຂອງບົດຄວາມນີ້ ແມ່ນກ່ຽວກັບແອັບ Desktop. ໃນບຣາວເຊີ *ສຳຮອງຂໍ້ມູນດຽວນີ້* ແລະ *ເປີດໂຟນເດີສຳຮອງຂໍ້ມູນ* ກໍເປັນສີເທົາເຊັ່ນກັນ.

## ຂັ້ນຕອນ

### 1. ເປີດໂໝດ AI

1. ເລືອກ *ການຕັ້ງຄ່າ › ໂຄງການ › ການຕັ້ງຄ່າແອັບ*. ທ່ານສາມາດເລືອກ *ໄຟລ໌ › ການຕັ້ງຄ່າແອັບ* ກໍໄດ້, ຫຼື ໄອຄອນເຟືອງຢູ່ດ້ານເທິງ.
2. ເລືອກແຖບ *ຂັ້ນສູງ* ແລ້ວເປີດ *ເປີດໃຊ້ໂໝດ AI*. ແຖບ *AI* ປາກົດຢູ່ໃນແຖບເຄື່ອງມື.
3. ຖ້າທ່ານຕ້ອງການໃຫ້ຂົວເຊື່ອມຕໍ່ເຮັດວຽກທັນທີທີ່ແອັບເລີ່ມ ໃຫ້ເປີດ *ເລີ່ມຂົວເຊື່ອມຕໍ່ອັດຕະໂນມັດ* ນຳ. ການນີ້ປ່ຽນໄດ້ສະເພາະເມື່ອໂໝດ AI ເປີດຢູ່ ແລະ ເຮັດວຽກໄດ້ສະເພາະໃນແອັບ Desktop. ຄ່າເລີ່ມຕົ້ນແມ່ນປິດ ເພາະການເປີດພອດເປັນການເລືອກທີ່ຕັ້ງໃຈ.

ຖ້າທ່ານປິດໂໝດ AI ຂົວເຊື່ອມຕໍ່ຈະຢຸດ ແລະ ແຖບ *AI* ຈະຫາຍໄປ.

### 2. ເລີ່ມຂົວເຊື່ອມຕໍ່

1. ໄປທີ່ແຖບ *AI* ແລ້ວກົດ *ເລີ່ມຂົວເຊື່ອມຕໍ່* ໃຕ້ *ເຊີເວີ*.
2. ເບິ່ງສະຖານະຂ້າງປຸ່ມ. ມັນຂຽນວ່າ *ປິດ*, *ພວມເຮັດວຽກຢູ່ພອດ 3877*, *ພອດ 3877 ພວມຖືກໃຊ້ງານ* ຫຼື *ເກີດຂໍ້ຜິດພາດ*. ຖ້າການເລີ່ມສຳເລັດ ມັນຂຽນວ່າ *ພວມເຮັດວຽກຢູ່ພອດ 3877* ແລະ ປຸ່ມຊື່ວ່າ *ຢຸດຂົວເຊື່ອມຕໍ່*. ຖ້າຂຽນວ່າ *ພອດ 3877 ພວມຖືກໃຊ້ງານ* ຫຼື *ເກີດຂໍ້ຜິດພາດ* ປຸ່ມຈະຍັງເປັນ *ເລີ່ມຂົວເຊື່ອມຕໍ່*. ເບິ່ງ ຈຸດທີ່ຕ້ອງລະວັງ.

ຂົວເຊື່ອມຕໍ່ຟັງສະເພາະຄອມພິວເຕີຂອງທ່ານເອງ ໃນພອດດຽວ. ຄ່າເລີ່ມຕົ້ນແມ່ນ 3877. ໃນກຸ່ມ *ການເຊື່ອມຕໍ່* ທ່ານສາມາດເລືອກພອດອື່ນທີ່ຊ່ອງ *ພອດ* ໄດ້. ແຕ່ເລືອກໄດ້ພຽງຕອນທີ່ຂົວເຊື່ອມຕໍ່ຢຸດຢູ່ເທົ່ານັ້ນ.

### 3. ເຊື່ອມຕໍ່ຕົວຊ່ວຍ

1. ກົດ *ເຊື່ອມຕໍ່* ໃຕ້ *ການເຊື່ອມຕໍ່*. ໜ້າຕ່າງ *ລາຍລະອຽດການເຊື່ອມຕໍ່* ເປີດຂຶ້ນ.
2. ເລືອກສິ່ງທີ່ໄຄລເອັນຂອງທ່ານຕ້ອງການ ເບິ່ງຂ້າງລຸ່ມ.
3. ໂທເຄັນຖືກເຊື່ອງໄວ້. ດ້ວຍໄອຄອນຕາ ທ່ານສະແດງມັນໄດ້. ປຸ່ມຄັດລອກຈະຄັດລອກຄ່າຈິງສະເໝີ ເຖິງແມ່ນໜ້າຈໍຈະເຊື່ອງໂທເຄັນກໍຕາມ.
4. ໃຫ້ຕົວຊ່ວຍຂໍລາຍຊື່ເຄື່ອງມື. ການກວດນີ້ກໍຢູ່ໃນ *ຂໍ້ຄວາມຄຳສັ່ງເຊື່ອມຕໍ່* ເຊັ່ນກັນ: ມັນຄວນເຫັນເຄື່ອງມືທີ່ມີຄຳນຳໜ້າ `planner_`. ຈຳນວນທີ່ຄາດໄວ້ຢູ່ໃນ *ຂໍ້ຄວາມຄຳສັ່ງເຊື່ອມຕໍ່*.

ໜ້າຕ່າງນີ້ມີສາມວິທີເຊື່ອມຕໍ່:

- *ໂຄດການຕັ້ງຄ່າ*: ສ່ວນການຕັ້ງຄ່າທີ່ທ່ານວາງໃສ່ໃນການຕັ້ງຄ່າ MCP ຂອງໄຄລເອັນຂອງທ່ານ.
- *ຂໍ້ຄວາມຄຳສັ່ງເຊື່ອມຕໍ່*: ຂໍ້ຄວາມທີ່ທ່ານວາງໃສ່ຕົວຊ່ວຍ AI ຂອງທ່ານ ຫຼັງຈາກນັ້ນມັນເຊື່ອມຕໍ່ດ້ວຍຕົນເອງ.
- *Endpoint* ແລະ *ການຢືນຢັນຕົວຕົນ*: ລາຍລະອຽດແຍກຕ່າງຫາກ. Endpoint ແມ່ນ `http://localhost:3877/mcp` ດ້ວຍ transport *streamable HTTP*. ທຸກຄຳຮ້ອງຂໍຕ້ອງມີ header `Authorization: Bearer` ຕາມດ້ວຍໂທເຄັນຂອງທ່ານ. ໄຄລເອັນຂອງທ່ານຕ້ອງຮອງຮັບເຊດຊັນ MCP ນຳ. ເມື່ອມັນເຊື່ອມຕໍ່, ຂົວເຊື່ອມຕໍ່ຈະໃຫ້ລະຫັດເຊດຊັນໃນ header `Mcp-Session-Id`, ແລະ ມັນຈະປະຕິເສດທຸກຄຳຮ້ອງຂໍຕໍ່ມາທີ່ບໍ່ມີລະຫັດນັ້ນ. Claude Code ແລະ `mcp-remote` ເຮັດອັນນີ້ດ້ວຍຕົນເອງ.

**ເຊື່ອມຕໍ່ໃໝ່ຫຼັງອັບເດດແອັບ.** ຖ້າໄຄລເອັນ AI ຂອງທ່ານເຊື່ອມຕໍ່ກັບແອັບເວີຊັນເກົ່າແລ້ວ ມັນຍັງບໍ່ສົ່ງລະຫັດເຊດຊັນ ແລະ ຂົວເຊື່ອມຕໍ່ປະຕິເສດທຸກຄຳຮ້ອງຂໍ. ດັ່ງນັ້ນ ກະລຸນາເຊື່ອມຕໍ່ໃໝ່ຫຼັງການອັບເດດ: ເລີ່ມເຊດຊັນໃໝ່ໃນ Claude Code, ແລະ ປິດ Claude Desktop ໃຫ້ໝົດ ແລ້ວເປີດໃໝ່.

**Claude Code.** ໂຄດການຕັ້ງຄ່າເໝາະກັບ Claude Code ໂດຍກົງ. ກະລຸນາໃສ່ຄຳສັ່ງນີ້ໃນເທີມິນັນ ໂດຍໃຊ້ໂທເຄັນຂອງທ່ານແທນ `<token>`:

```
claude mcp add --transport http open-planner-studio http://localhost:3877/mcp --header "Authorization: Bearer <token>"
```

ທ່ານອາດໃສ່ໂຄດການຕັ້ງຄ່າໃນໄຟລ໌ `.mcp.json` ໃນໂຟນເດີໂຄງການຂອງທ່ານກໍໄດ້. ແຕ່ຢ່າເພີ່ມໄຟລ໌ນັ້ນເຂົ້າ git, ເພາະໂທເຄັນໃຫ້ສິດເຂົ້າເຖິງແຜນງານຂອງທ່ານ. ເຊີເວີຈາກ `.mcp.json` ຕ້ອງໄດ້ຮັບການອະນຸມັດຄັ້ງທຳອິດໃນ Claude Code.

**Claude Desktop.** ໂຄດການຕັ້ງຄ່າບໍ່ເໝາະກັບ Claude Desktop ໂດຍກົງ. ໃນໄຟລ໌ `claude_desktop_config.json` ທ່ານຕ້ອງລະບຸໂປຣແກຣມທີ່ Claude Desktop ເລີ່ມເອງ, ບໍ່ແມ່ນທີ່ຢູ່. ສະນັ້ນ ໃຫ້ໃຊ້ເຄື່ອງມືພາຍນອກ `mcp-remote` ເປັນຕົວກາງ; ມັນຕ້ອງການ Node.js. ໃນ Claude Desktop ໃຫ້ເລືອກ *ການຕັ້ງຄ່າ › ນັກພັດທະນາ › ແກ້ໄຂການຕັ້ງຄ່າ*, ໃສ່ອັນນີ້ໃນໄຟລ໌ (ດ້ວຍໂທເຄັນຂອງທ່ານ) ແລ້ວເປີດ Claude Desktop ໃໝ່:

```
{
  "mcpServers": {
    "open-planner-studio": {
      "command": "npx",
      "args": ["-y", "mcp-remote", "http://localhost:3877/mcp", "--header", "Authorization:${AUTH_HEADER}"],
      "env": { "AUTH_HEADER": "Bearer <token>" }
    }
  }
}
```

ໂທເຄັນຢູ່ໃນ `env` ແທນທີ່ຈະຢູ່ໃນ `args` ໂດຍຕັ້ງໃຈ: ໃນ Windows, Claude Desktop ຈະທຳລາຍ ຄ່າພາຣາມິເຕີ ທີ່ມີຊ່ອງຫວ່າງ. *ຕົວເຊື່ອມຕໍ່ແບບກຳນົດເອງ* ໃນ Claude (*ປັບແຕ່ງ › ຕົວເຊື່ອມຕໍ່*) ໃຊ້ງານກັບຂົວເຊື່ອມຕໍ່ບໍ່ໄດ້. Claude ຈະເຊື່ອມຕໍ່ຈາກຄລາວຂອງ Anthropic ແທນ, ແລະ ຄລາວນັ້ນເຂົ້າເຖິງຂົວເຊື່ອມຕໍ່ໃນຄອມພິວເຕີຂອງທ່ານເອງບໍ່ໄດ້.

ໃນກຸ່ມ *ການເຊື່ອມຕໍ່* ມີຊ່ອງ *ໂທເຄັນ* ນຳ. ມັນເປັນລະຫັດຍາວ ແບບສຸ່ມ ທີ່ແອັບສ້າງໃຫ້ທ່ານ ແລະ ເກັບໄວ້ໃນຄອມພິວເຕີເຄື່ອງນີ້. ໃນໜ້າຕ່າງມີຂໍ້ຄວາມ *ໂທເຄັນນີ້ອະນຸຍາດໃຫ້ເຂົ້າເຖິງແຜນງານທີ່ເປີດຢູ່. ຫ້າມແບ່ງປັນໃຫ້ຜູ້ອື່ນ*. ດ້ວຍໄອຄອນ *ສ້າງໂທເຄັນໃໝ່* ທ່ານສ້າງໂທເຄັນໃໝ່. ແອັບຈະຖາມກ່ອນວ່າ *ການສ້າງໂທເຄັນໃໝ່ຈະຕັດການເຊື່ອມຕໍ່ທີ່ມີຢູ່ທັງໝົດ. ດຳເນີນການຕໍ່ຫຼືບໍ່?* ຖ້າຂົວເຊື່ອມຕໍ່ກຳລັງເຮັດວຽກ ມັນຈະເລີ່ມໃໝ່ດ້ວຍໂທເຄັນໃໝ່ ແລະ ໂທເຄັນເກົ່າຈະໃຊ້ບໍ່ໄດ້ອີກ.

### 4. ເບິ່ງວ່າ AI ເຮັດຫຍັງ

1. ກົດ *ແຜງການເຄື່ອນໄຫວ* ໃຕ້ *ກິດຈະກຳ*. ໃນດ້ານຂ້າງ ແຜງ *ການເຄື່ອນໄຫວຂອງ AI* ຈະເປີດ.
2. ແຕ່ລະການຮຽກໃຊ້ຂອງຂົວເຊື່ອມຕໍ່ຢູ່ໃນແຖວຂອງມັນເອງ, ອັນໃໝ່ສຸດຢູ່ດ້ານເທິງ: ເວລາ, ສິ່ງທີ່ເກີດຂຶ້ນ, ໃຊ້ເວລາດົນປານໃດ ແລະ ສຳເລັດຫຼືບໍ່. ກົດແຖວໜຶ່ງເພື່ອຂະຫຍາຍ *ຄ່າພາຣາມິເຕີ* ແລະ *ຜົນຕອບຮັບ*.
3. ດ້ວຍ *ລຶບລ້າງ* ທ່ານລຶບລາຍຊື່ອອກ. ແຜງນີ້ເກັບ 500 ການຮຽກໃຊ້ຫຼ້າສຸດ. ຕາບໃດທີ່ຍັງບໍ່ມີຫຍັງເກີດຂຶ້ນ ມັນຂຽນວ່າ *ຍັງບໍ່ມີການເຄື່ອນໄຫວຂອງ AI. ການຮຽກໃຊ້ຂົວເຊື່ອມຕໍ່ຈະສະແດງຢູ່ນີ້*.

ເມື່ອໂໝດ AI ເປີດຢູ່ ມີຈຸດພ້ອມ *AI* ຢູ່ມຸມຂວາລຸ່ມຂອງແຖບສະຖານະ. ສີຂອງມັນບອກສະຖານະຂອງຂົວເຊື່ອມຕໍ່. ເມື່ອກົດໃສ່ມັນ ທ່ານຈະໄປທີ່ແຖບ *AI*.

### 5. ກຳນົດຂີດຈຳກັດ

ໃຕ້ *ຄວາມປອດໄພ* ມີປຸ່ມທີ່ທ່ານໃຊ້ຈຳກັດ AI:

- *ພັກຊົ່ວຄາວ*: AI ອາດຈະບໍ່ປ່ຽນຫຍັງຊົ່ວຄາວ ແຕ່ການອ່ານຍັງອະນຸຍາດຢູ່. ຂົວເຊື່ອມຕໍ່ຍັງເຮັດວຽກຢູ່. ປຸ່ມຈະປ່ຽນເປັນ *ສືບຕໍ່*.
- *ອ່ານຢ່າງດຽວ*: ເຄື່ອງມືທຸກອັນທີ່ປ່ຽນແປງຫຍັງຈະຖືກປະຕິເສດ ໃນຂະນະທີ່ອັນນີ້ເປີດຢູ່.
- *ສຳຮອງຂໍ້ມູນອັດຕະໂນມັດ: ເປີດ*: ກ່ອນການປ່ຽນແປງທຳອິດຂອງ AI ໃນເອກະສານ ແອັບຈະຂຽນສຳຮອງ IFC. ຄ່າເລີ່ມຕົ້ນແມ່ນເປີດ. ດ້ວຍປຸ່ມນີ້ທ່ານປິດມັນໄດ້ ແລະ ຫຼັງຈາກນັ້ນມັນຂຽນວ່າ *ສຳຮອງຂໍ້ມູນອັດຕະໂນມັດ: ປິດ*. ເລື່ອງນີ້ເກີດຂຶ້ນໜຶ່ງຄັ້ງຕໍ່ເອກະສານ ທຸກຄັ້ງທີ່ທ່ານເລີ່ມຂົວເຊື່ອມຕໍ່.
- *ສຳຮອງຂໍ້ມູນດຽວນີ້*: ສ້າງສຳຮອງຂອງເອກະສານທີ່ເປີດຢູ່ທັນທີ. ຫຼັງຈາກນັ້ນມັນຂຽນວ່າ *ສ້າງສຳຮອງຂໍ້ມູນແລ້ວ:* ພ້ອມຊື່ໄຟລ໌.
- *ເປີດໂຟນເດີສຳຮອງຂໍ້ມູນ*: ເປີດໂຟນເດີທີ່ມີການສຳຮອງຂໍ້ມູນ.

ການສຳຮອງຂໍ້ມູນຢູ່ໃນໂຟນເດີ `ai-backups` ໃນໂຟນເດີຂໍ້ມູນຂອງແອັບ. ແອັບເກັບການສຳຮອງຂໍ້ມູນຫຼ້າສຸດໄວ້ ແລະ ລຶບອັນເກົ່າອອກບາງສ່ວນ. ວິທີເຮັດຢ່າງລະອຽດຢູ່ໃນ [ເຄື່ອງມື AI](docs://ref-ai-tools).

### 6. ໃຫ້ຕົວຊ່ວຍວາງແຜນໃຫ້ດີ

ຕົວຊ່ວຍຈະວາງແຜນໄດ້ດີກໍຕໍ່ເມື່ອມັນຮູ້ກົດການວາງແຜນ. ເຫດຜົນວ່າເປັນຫຍັງສິ່ງນີ້ສຳຄັນ ແລະ ມີຫຍັງຢູ່ໃນນັ້ນ ທ່ານອ່ານໄດ້ໃນ [ວິທີການເຊື່ອມຕໍ່ AI ເຮັດວຽກ](docs://uitleg-ai-koppeling). ນີ້ແມ່ນສິ່ງທີ່ທ່ານເຮັດເອງ:

1. **ບໍ່ຕ້ອງເຮັດຫຍັງກັບກົດພື້ນຖານ.** ມັນມາພ້ອມກັບການເຊື່ອມຕໍ່. ໄຄລເອັນຂອງທ່ານໃສ່ມັນໃນ ຂໍ້ຄວາມຄຳສັ່ງລະບົບ ຫຼືບໍ່ ຂຶ້ນກັບໄຄລເອັນ.
2. **ໃຫ້ອ່ານຄູ່ມືກ່ອນ.** ຂໍ້ຄວາມຄຳສັ່ງເຊື່ອມຕໍ່ຈາກໜ້າຕ່າງ *ລາຍລະອຽດການເຊື່ອມຕໍ່* ຂໍໃຫ້ຕົວຊ່ວຍອ່ານຄູ່ມືດ້ວຍເຄື່ອງມື `planner_get_planning_guide`. ຖ້າທ່ານບໍ່ໃຊ້ຂໍ້ຄວາມນັ້ນ ໃຫ້ຖາມຕົວຊ່ວຍເອງ: *ອ່ານຄູ່ມືການວາງແຜນດ້ວຍ planner_get_planning_guide ກ່ອນ, ກ່ອນທ່ານຈະປ່ຽນຫຍັງ.* ທ່ານສາມາດອ່ານຄູ່ມືເອງໄດ້ທີ່ `https://open-planner-studio.open-aec.com/agent/planning-guide.md`.
3. **ທາງເລືອກ: ຕິດຕັ້ງທັກສະ.** ອັນນີ້ໃຊ້ໄດ້ສະເພາະກັບຕົວຊ່ວຍທີ່ຮອງຮັບທັກສະ. ໃສ່ໄຟລ໌ `SKILL.md` ຂອງ *goed-plannen* ແລະ *progress-update* ໃນ `.claude/skills/goed-plannen/SKILL.md` ແລະ `.claude/skills/progress-update/SKILL.md` ໃນໂຟນເດີໂຄງການທີ່ຕົວຊ່ວຍເຮັດວຽກ, ຫຼື ພາຍໃຕ້ `~/.claude/skills/` ສຳລັບທຸກໂຄງການ.

ທ່ານໄດ້ໄຟລ໌ໃນສອງວິທີ. ໃຫ້ຕົວຊ່ວຍເອີ້ນເຄື່ອງມື `planner_get_planning_guide` ໂດຍຕັ້ງ `part` ເປັນ `skill`: ຜົນຕອບຮັບມີທັງສອງຂໍ້ຄວາມ ແລະ ສຳລັບແຕ່ລະທັກສະ ບອກບ່ອນທີ່ມັນຄວນຢູ່. ຫຼື ດາວໂຫຼດຈາກ `https://open-planner-studio.open-aec.com/skills/goed-plannen/SKILL.md` ແລະ `https://open-planner-studio.open-aec.com/skills/progress-update/SKILL.md`. ຖ້າ *goed-plannen* ຍັງຢູ່ຈາກແອັບເວີຊັນເກົ່າ ໃຫ້ແທນທີ່ມັນ: ຂໍ້ຄວາມເກົ່ານັ້ນເປັນພາສາດັດ ແລະ ຊີ້ໄປຫາບົດຊ່ວຍເຫຼືອແທນຄູ່ມືສຳລັບຕົວຊ່ວຍ.

ທ່ານເຫັນໄດ້ໃນ *ແຜງການເຄື່ອນໄຫວ* ວ່າຕົວຊ່ວຍອ່ານຄູ່ມືແທ້ຫຼືບໍ່: ຈະມີການເອີ້ນ `planner_get_planning_guide`. ຄຳຕອບສຸດທ້າຍຄວນມີລາຍຊື່ການສົມມຸດ: ໄລຍະເວລາທີ່ປະມານໄວ້, ການແບ່ງຍ່ອຍທີ່ເລືອກ, ສາຍສຳພັນທີ່ມັນສ້າງເອງ ແລະ ເງື່ອນໄຂທຸກອັນທີ່ມັນຕັ້ງ. ຖ້າບໍ່ມີລາຍຊື່ນັ້ນ ໃຫ້ຂໍມັນ. ຫຼັງການອັບເດດຄວາມຄືບໜ້າຕາມ *progress-update*, ຄຳຕອບຄວນລະບຸ ວັນທີສະຖານະ, ວັນທີສິ້ນສຸດໃໝ່ ແລະ ຄວາມແຕກຕ່າງກັບແຜນຫຼັກ.

## ຈຸດທີ່ຕ້ອງລະວັງ ແລະ ແອັບເຮັດຫຍັງເມື່ອນັ້ນ

**AI ປ່ຽນບາງສິ່ງທີ່ທ່ານຢາກຖອນຄືນ.** ທຸກການປ່ຽນແປງໂດຍ AI ແມ່ນໜຶ່ງຂັ້ນຕອນ ທີ່ທ່ານຍົກເລີກດ້ວຍ *ຍົກເລີກຄຳສັ່ງ* (Ctrl+Z). ຊຸດການປ່ຽນແປງທີ່ AI ສົ່ງເປັນກ້ອນດຽວ ເປັນໜຶ່ງຂັ້ນຕອນ. ຫຼັງຈາກນັ້ນໂຄງການຖືກສະແດງວ່າຍັງບໍ່ໄດ້ບັນທຶກ. ຫຼັງການປ່ຽນແປງ ແຜນງານຖືກ*ຄິດໄລ່ຄືນໃໝ່* ອັດຕະໂນມັດ ດັ່ງນັ້ນທ່ານບໍ່ຕ້ອງກົດ F5 ເອງ.

**ແອັບປະຕິເສດການເອີ້ນໂດຍ AI.** ດ້ວຍ *ພັກຊົ່ວຄາວ* ແລະ *ອ່ານຢ່າງດຽວ* ແອັບປະຕິເສດການປ່ຽນແປງທັງໝົດ ແລະ ການອ່ານຍັງເປັນໄປໄດ້, ລວມທັງການ*ຄິດໄລ່ຄືນໃໝ່* ຂອງແຜນງານທີ່ລ້າສະໄໝ. ຖ້າທ່ານກຳລັງແກ້ໄຂເອງຢູ່, ເຊັ່ນລາກແຖບໜ້າວຽກ ຫຼື ພິມໃນຊ່ອງ, AI ຈະໄດ້ວັນທີກ່ອນການແກ້ໄຂຂອງທ່ານ ພ້ອມແຈ້ງເຕືອນວ່າມັນລ້າສະໄໝ. ຖ້າທ່ານມີກ່ອງໂຕ້ຕອບເປີດຢູ່ ຕົວຢ່າງ ການຕັ້ງຄ່າ, ກ່ອງໂຕ້ຕອບໜ້າວຽກ ຫຼື ໜ້າຕ່າງຕ້ອນຮັບ, ຫຼື ໂໝດນຳສະເໜີເປີດຢູ່, ແອັບຈະປະຕິເສດທຸກການເອີ້ນ ລວມທັງການອ່ານ ຈົນກວ່າທ່ານຈະປິດກ່ອງໂຕ້ຕອບ. ຫຼັງຈາກນັ້ນ AI ຈະໄດ້ຂໍ້ຄວາມຜິດພາດ ພ້ອມຊື່ພາຍໃນຂອງສິ່ງທີ່ເປີດຢູ່ ເຊັ່ນ `showTaskDialog`. ມີພຽງ `planner_get_planning_guide` ເທົ່ານັ້ນທີ່ຍັງເຮັດວຽກ ເພາະມັນບໍ່ອ່ານແຜນງານຂອງທ່ານ.

**ທ່ານສະຫຼັບແຖບໃນຂະນະທີ່ AI ກຳລັງເຮັດວຽກ.** AI ເຮັດວຽກກັບເອກະສານທີ່ການປ່ຽນແປງທຳອິດຂອງມັນໄດ້ເກີດຂຶ້ນ. ຖ້າທ່ານສະຫຼັບແຖບໃນລະຫວ່າງນັ້ນ ແອັບຈະປະຕິເສດການປ່ຽນແປງຕໍ່ໄປຂອງມັນ ຈົນກວ່າມັນຢືນຢັນວ່າມັນຢາກເຮັດວຽກໃນແຖບອື່ນ. ດ້ວຍວິທີນີ້ ບໍ່ມີສິ່ງໃດໄປຢູ່ໃນໂຄງການຜິດ.

**AI ຂຽນ ຫຼື ເປີດໄຟລ໌.** AI ສາມາດຂຽນແຜນງານເປັນໄຟລ໌ IFC ແລະ ເປີດໄຟລ໌ແຜນງານເປັນແຖບໃໝ່. ມັນເຮັດໄດ້ສະເພາະພາຍໃນໂຟນເດີຜູ້ໃຊ້ຂອງທ່ານ. ມັນຈະຂຽນທັບໄຟລ໌ທີ່ມີຢູ່ແລ້ວ ກໍຕໍ່ເມື່ອມັນຂໍຢ່າງຊັດເຈນເທົ່ານັ້ນ.

**ສະຖານະແມ່ນ *ພອດ 3877 ພວມຖືກໃຊ້ງານ*.** ໂປຣແກຣມອື່ນກຳລັງໃຊ້ພອດນັ້ນ. ຂໍ້ຄວາມຂອງແອັບສະແດງຢູ່ລຸ່ມມັນ. ຊ່ອງ *ພອດ* ຈະຖືກລັອກ (*ແກ້ໄຂໄດ້ສະເພາະຕອນເຊີເວີຢຸດຢູ່.*) ເຖິງແມ່ນຂົວເຊື່ອມຕໍ່ບໍ່ໄດ້ເຮັດວຽກ ແລະ ບໍ່ມີປຸ່ມຢຸດ. ນີ້ແມ່ນຂໍ້ບົກພ່ອງທີ່ຮູ້ຈັກ. ຈົນກວ່າມັນຈະຖືກແກ້ໄຂ: ປິດ *ເປີດໃຊ້ໂໝດ AI* ແລ້ວເປີດອີກຄັ້ງ. ສະຖານະຈະກັບໄປເປັນ *ປິດ* ແລະ ທ່ານສາມາດເລືອກພອດອື່ນ. ຈາກນັ້ນໃຫ້ຄັດລອກລາຍລະອຽດການເຊື່ອມຕໍ່ໃໝ່ອີກຄັ້ງ ເພາະ endpoint ມີພອດ.

**ໄຄລເອັນເຊື່ອມຕໍ່ບໍ່ໄດ້ຫຼັງໂທເຄັນໃໝ່.** ໂທເຄັນໃໝ່ຕັດການເຊື່ອມຕໍ່ທີ່ມີຢູ່ທັງໝົດ. ໃຫ້ໄຄລເອັນໂທເຄັນໃໝ່ ຫຼື ວາງ *ໂຄດການຕັ້ງຄ່າ* ອີກຄັ້ງ.

**ທ່ານຢຸດຂົວເຊື່ອມຕໍ່ເອງ ແລະ ມັນບໍ່ເລີ່ມເອງ.** *ເລີ່ມຂົວເຊື່ອມຕໍ່ອັດຕະໂນມັດ* ເຮັດວຽກໜຶ່ງຄັ້ງທຸກຄັ້ງທີ່ແອັບເລີ່ມ. ຖ້າທ່ານຢຸດຂົວເຊື່ອມຕໍ່ເອງ ແອັບຈະບໍ່ເປີດມັນຄືນໂດຍບໍ່ບອກ.

**ແຖບ *AI* ຫາຍໄປແລ້ວ.** ໂໝດ AI ປິດຢູ່. ເປີດມັນໃນຂັ້ນຕອນ 1.

**ໜ້າເວັບໃນບຣາວເຊີຂອງທ່ານບໍ່ສາມາດຕິດຕໍ່ກັບຂົວເຊື່ອມຕໍ່ໄດ້.** ຂົວເຊື່ອມຕໍ່ປະຕິເສດທຸກຄຳຮ້ອງຂໍທີ່ມາຈາກບຣາວເຊີ ແລະ ທຸກຄຳຮ້ອງຂໍທີ່ບໍ່ມີໂທເຄັນທີ່ຖືກຕ້ອງ.
