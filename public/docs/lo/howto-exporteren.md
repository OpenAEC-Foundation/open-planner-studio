# ການສົ່ງອອກ

ເປົ້າໝາຍ: ສົ່ງແຜນງານຂອງທ່ານເປັນໄຟລ໌ໃນຮູບແບບອື່ນ ສຳລັບຜູ້ທີ່ບໍ່ອ່ານ IFC ຫຼື ສຳລັບລະບົບອື່ນ.

## ເມື່ອທ່ານຕ້ອງການສິ່ງນີ້

ທີ່ປຶກສາເຮັດວຽກໃນ MS Project, ລູກຄ້າໃນ Primavera, ຜູ້ຮັບເໝົາຊ່ວງຕ້ອງການໜ້າວຽກໃນ Excel, ຫຼື ທ່ານສົ່ງແຜນງານໃຫ້ລະບົບທີ່ຈັດການ IFC ບໍ່ໄດ້. ການສົ່ງອອກແມ່ນສຳເນົາໃນຮູບແບບອື່ນ. ຖ້າທ່ານຕ້ອງການເກັບໂຄງການຂອງທ່ານເອງ ໃຫ້ບັນທຶກມັນ: ການນີ້ຂຽນເປັນ IFC ແລະ ລວມທຸກຢ່າງໄວ້. ແຕ່ລະຮູບແບບລວມຫຍັງ ແລະ ບໍ່ລວມຫຍັງ ຢູ່ໃນ [ໄຟລ໌ ແລະ ຮູບແບບ](docs://uitleg-bestanden).

## ຂັ້ນຕອນ

1. ເລືອກ *ໜ້າຫຼັກ › ໄຟລ໌ › ສົ່ງອອກ* ແລ້ວເລືອກຮູບແບບຈາກລາຍການ, ຫຼື ເລືອກ *ໄຟລ໌ › ສົ່ງອອກ*. ຢູ່ບ່ອນນັ້ນ ທຸກຮູບແບບເປັນກາດໜຶ່ງໃບ ພ້ອມຄຳອະທິບາຍສັ້ນ.
2. ໃນໜ້າຕ່າງ ເລືອກຊື່ ແລະ ບ່ອນເກັບ. ແອັບແນະນຳຊື່ໂຄງການ ພ້ອມນາມສະກຸນຂອງຮູບແບບ. ໃບຄວາມຄືບໜ້າຊື່ *projectname-voortgang* ແລະ ຖືກບັນທຶກໄວ້ໃນໂຟນເດີດາວໂຫຼດຂອງທ່ານ ເທົ່າທີ່ເປັນໄປໄດ້.
3. ຢືນຢັນ. ບໍ່ມີຂໍ້ຄວາມປາກົດ ຖ້າການສົ່ງອອກສຳເລັດ ຍົກເວັ້ນຂໍ້ຄວາມຂ້າງລຸ່ມ. ຈາກ *ໄຟລ໌ › ສົ່ງອອກ* ທ່ານຈະກັບໄປແຖບ *ໜ້າຫຼັກ* ພາຍຫຼັງ ເຖິງແມ່ນທ່ານຍົກເລີກໜ້າຕ່າງ. ຖ້າທ່ານຍົກເລີກໜ້າຕ່າງສຳລັບການສົ່ງອອກຈາກລາຍການໃນແຖບ *ໜ້າຫຼັກ* ຈະບໍ່ມີຫຍັງເກີດຂຶ້ນ.

ຖ້າບຣາວເຊີຂອງທ່ານບັນທຶກພຽງຜ່ານການດາວໂຫຼດ (ເຊັ່ນ Firefox) ໄຟລ໌ຢູ່ໃນໂຟນເດີດາວໂຫຼດຂອງທ່ານທັນທີຫຼັງຈາກຂັ້ນຕອນ 1. ທ່ານເຫັນຂໍ້ຄວາມ *ບັນທຶກເປັນໄຟລ໌ດາວໂຫຼດ: ຕອນນີ້ 'name.xml' ຢູ່ໃນໂຟນເດີດາວໂຫຼດຂອງທ່ານແລ້ວ. ລະບົບບໍ່ອະນຸຍາດໃຫ້ແອັບຂຽນທັບໃສ່ບ່ອນທີ່ທ່ານເລືອກໂດຍກົງ.*

### ເລືອກຮູບແບບໃດ?

ລາຍການໃນແຖບ *ໜ້າຫຼັກ* ແລະ ກາດໃນ *ໄຟລ໌ › ສົ່ງອອກ* ສະເໜີຮູບແບບດຽວກັນ:

- *ຄວາມຄືບໜ້າ (Excel)* ແລະ *ຄວາມຄືບໜ້າ (CSV)*, ໃນກາດ *ໃບຄວາມຄືບໜ້າ (Excel)* ແລະ *ໃບຄວາມຄືບໜ້າ (CSV)*: ແຜ່ນບາງໆທີ່ມີ id, WBS, ຊື່, ວັນທີ ແລະ ເປີເຊັນສຳເລັດ ສຳລັບສົ່ງໃຫ້ຜູ້ທີ່ປ້ອນຄວາມຄືບໜ້າ.
- *CSV (;)*, ໃນກາດ *CSV (ຂັ້ນດ້ວຍຈໍ້າຈຸດ ;)*: ຕາຕະລາງໜ້າວຽກທີ່ທ່ານເປີດໃນໂປຣແກຣມຕາຕະລາງຂໍ້ມູນ.
- *MS Project XML*: ເປີດໃນ Microsoft Project ໄດ້.
- *Primavera P6 XML*: ສຳລັບ Oracle Primavera P6.
- *IFC*: ຮູບແບບຂອງແອັບເອງ ມີທຸກຢ່າງຢູ່ໃນນັ້ນ, ຕາມ IFC schema ຂອງໂຄງການ (ຄ່າເລີ່ມຕົ້ນ IFC 4.3 ADD2).

### ການສົ່ງອອກ IFC ພ້ອມໄຟລ໌ຄັງຂໍ້ມູນ

ຖ້າໂຄງການຂອງທ່ານເຊື່ອມກັບຄັງຂໍ້ມູນ ຊ່ອງໝາຍ *ບັນທຶກໄຟລ໌ຄັງຂໍ້ມູນໄວ້ຄຽງຄູ່ກັນ* ຢູ່ລຸ່ມກາດໃນ *ໄຟລ໌ › ສົ່ງອອກ*. ຖ້າທ່ານຕິກມັນ ແລະ ເລືອກ *IFC* ແອັບຈະຖາມບ່ອນເກັບສອງເທື່ອ: ທຳອິດສຳລັບໂຄງການ, ຈາກນັ້ນສຳລັບ *projectname-bibliotheek.ifc*. ຊ່ອງໝາຍນີ້ມີພຽງໃນ *ໄຟລ໌ › ສົ່ງອອກ* ບໍ່ແມ່ນໃນລາຍການໃນແຖບ *ໜ້າຫຼັກ*.

### ການອ່ານໃບຄວາມຄືບໜ້າກັບເຂົ້າມາ

ທ່ານອ່ານໃບຄວາມຄືບໜ້າທີ່ປ້ອນແລ້ວກັບເຂົ້າມາຜ່ານ *ໄຟລ໌ › ນຳເຂົ້າ*. ເບິ່ງ [ການນຳເຂົ້າຄວາມຄືບໜ້າຈາກຕາຕະລາງຂໍ້ມູນ](docs://howto-voortgang-importeren).

## ຈຸດທີ່ຕ້ອງລະວັງ ແລະ ແອັບເຮັດຫຍັງໃນກໍລະນີນັ້ນ

**ໂຄງການຂອງທ່ານບໍ່ປ່ຽນ.** ໄຟລ໌ໂຄງການຂອງທ່ານຍັງຄືເກົ່າ ແລະ ເຄື່ອງໝາຍ *ຍັງບໍ່ໄດ້ບັນທຶກ* ຍັງຄົງຢູ່ ຖ້າມັນມີຢູ່ແລ້ວ.

**ແຜນງານທີ່ບໍ່ເປັນປັດຈຸບັນຈະຖືກຄິດໄລ່ຄືນໃໝ່ກ່ອນ.** ດັ່ງນັ້ນທ່ານໄດ້ວັນທີປັດຈຸບັນ ເຖິງແມ່ນທ່ານລືມກົດ *ຄິດໄລ່*.

**ການສົ່ງອອກກໍຢູ່ໃນລ່າສຸດດ້ວຍ.** ສິ່ງນີ້ບໍ່ໃຊ້ກັບໃບຄວາມຄືບໜ້າ. ຖ້າທ່ານເປີດການສົ່ງອອກຈາກບ່ອນນັ້ນ ມັນຈະເປີດເປັນການນຳເຂົ້າຂອງຮູບແບບນັ້ນ.

**ການສົ່ງອອກບໍ່ລວມທຸກຢ່າງ.** ໄຟລ໌ CSV ບໍ່ມີຊັບພະຍາກອນ ຫຼື ເງື່ອນໄຂ. P6 XML ບໍ່ມີແຜນຫຼັກ ແລະ ກຳນົດສົ່ງ. ໂປຣໄຟລ໌ການຄິດໄລ່ກໍບໍ່ໄປນຳເຊັ່ນກັນ: ເມື່ອເປີດການສົ່ງອອກຄືນ ມັນຈະຄິດໄລ່ເປັນ *Open Planner Studio*. ມີພຽງ IFC ເທົ່ານັ້ນທີ່ລວມທຸກຢ່າງ. ທ່ານຈະພົບຕົວຢ່າງທີ່ມີຕົວເລກໃນ [ໄຟລ໌ ແລະ ຮູບແບບ](docs://uitleg-bestanden).

**ສອງຮູບແບບທີ່ມີນາມສະກຸນດຽວກັນ.** MS Project XML ແລະ Primavera P6 XML ທັງສອງໄດ້ຊື່ *ຊື່ໂຄງການ.xml*. ຕັ້ງຊື່ທີ່ຕ່າງກັນເອງ ບໍ່ດັ່ງນັ້ນທ່ານຈະບໍ່ຮູ້ພາຍຫຼັງວ່າໄຟລ໌ໃດເປັນຮູບແບບໃດ.

**ແຜນງານທີ່ມີສາຍສຳພັນວົນລູບຈະບໍ່ຖືກສົ່ງອອກ.** ແອັບຄິດໄລ່ກ່ອນ ແລະ ຢຸດຖ້າມີວົນລູບ. ຢູ່ແຖບ *ໜ້າຫຼັກ* ທ່ານຈະເຫັນຂໍ້ຄວາມ *ບໍ່ສາມາດຄິດໄລ່ແຜນງານໄດ້* ພ້ອມດ້ານລຸ່ມ ຕົວຢ່າງ *ມີສາຍພົວພັນວົນລູບລະຫວ່າງໜ້າວຽກ: Set up site → Demolish existing extension → Set up site*. ໃນ *ໄຟລ໌ › ສົ່ງອອກ* ມີພຽງຂໍ້ຄວາມທີ່ສອງຢູ່ໜ້ານັ້ນ. ແກ້ວົນລູບ ແລ້ວສົ່ງອອກອີກເທື່ອ.

**ໂຄງການຈາກ Primavera ສູນເສຍຂໍ້ມູນຕົ້ນສະບັບ.** ຖ້າທ່ານສົ່ງອອກໂຄງການແບບນີ້ເປັນ CSV, MS Project XML ຫຼື P6 XML ແອັບຈະລາຍງານ: *ການສົ່ງອອກເປັນ CSV ຈະສູນເສຍຂໍ້ມູນຕົ້ນສະບັບຂອງ XER.* ສຳລັບ MS Project XML ມັນເວົ້າ *MSPDI*, ສຳລັບ P6 XML ມັນເວົ້າ *P6*. ເບິ່ງ [ການເປີດໄຟລ໌ Primavera P6 (.xer)](docs://howto-xer-openen).

**ແຍກວຽກຈະສູນເສຍການແຍກ.** MS Project ແລະ Primavera ຮູ້ຈັກການແຍກວຽກພຽງແຕ່ເປັນການກະຈາຍຊົ່ວໂມງ. ຖ້າໂຄງການຂອງທ່ານມີໜ້າວຽກທີ່ແຍກວຽກໂດຍບໍ່ມີການກະຈາຍຊົ່ວໂມງ ແອັບຈະລາຍງານຫຼັງການສົ່ງອອກເປັນ MS Project XML ຫຼື P6 XML: *2 ໜ້າວຽກທີ່ມີຊ່ວງພັກຖືກສົ່ງອອກໂດຍບໍ່ມີຊ່ວງພັກ: ເນື່ອງຈາກ MS Project/P6 ຮອງຮັບຊ່ວງພັກໃນຮູບແບບການກະຈາຍວຽກເທົ່ານັ້ນ.* ສຳລັບໜ້າວຽກດຽວ ມັນເວົ້າ *1 ໜ້າວຽກທີ່ມີຊ່ວງພັກຖືກສົ່ງອອກໂດຍບໍ່ມີຊ່ວງພັກ: ເນື່ອງຈາກ MS Project/P6 ຮອງຮັບຊ່ວງພັກໃນຮູບແບບການກະຈາຍວຽກເທົ່ານັ້ນ.* ເບິ່ງ [ການແຍກວຽກ](docs://howto-taak-splitsen).

**ແຜນງານໃນມຸມມອງ *ວັນທີຕາມທີ່ບັນທຶກໄວ້*.** ຖ້າທ່ານສົ່ງອອກເປັນ CSV ໃນຂະນະທີ່ທ່ານເຫັນວັນທີຈາກໄຟລ໌ຕົ້ນສະບັບ ແອັບຈະປ່ອຍ `Critical` ແລະ `Total Float` ໃຫ້ວ່າງສຳລັບໜ້າວຽກທີ່ໄຟລ໌ຕົ້ນສະບັບບໍ່ໄດ້ບັນທຶກສິ່ງນັ້ນໄວ້. ເບິ່ງ [ວັນທີຕາມທີ່ບັນທຶກໄວ້](docs://uitleg-datums-zoals-opgeslagen).
