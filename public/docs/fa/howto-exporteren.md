# خروجی گرفتن

هدف: برنامهٔ خود را به‌صورت یک فایل در قالب دیگر تحویل دهید، برای کسی که IFC نمی‌خواند یا برای یک بستهٔ نرم‌افزاری دیگر.

## زمانی که به این نیاز دارید

مشاور با MS Project کار می‌کند، کارفرما با Primavera کار می‌کند، پیمانکار فرعی وظیفه‌ها را در Excel می‌خواهد، یا شما برنامه را برای بسته‌ای می‌فرستید که IFC را پشتیبانی نمی‌کند. خروجی یک نسخه در قالب دیگر است. اگر می‌خواهید خود پروژه را نگه دارید، آن را ذخیره کنید: این کار IFC می‌نویسد و همه‌چیز را با خود حمل می‌کند. اینکه هر قالب چه چیزی را حمل می‌کند و چه چیزی را نه، در [فایل‌ها و قالب‌ها](docs://uitleg-bestanden) آمده است.

## گام‌ها

1. *خانه › فایل › خروجی* را انتخاب کنید و یک قالب را از فهرست برگزینید، یا *فایل › خروجی* را انتخاب کنید. آنجا هر قالب یک کارت با توضیح کوتاه است.
2. در پنجره یک نام و یک مکان انتخاب کنید. نرم‌افزار نام پروژه را با پسوند قالب پیشنهاد می‌دهد. صفحه‌های پیشرفت *projectname-voortgang* نام دارند و در صورت امکان در پوشهٔ دانلودهای شما باز می‌شوند.
3. تأیید کنید. اگر خروجی موفق باشد، پیامی نمایش داده نمی‌شود، به‌جز پیام‌های زیر. پس از *فایل › خروجی* به زبانهٔ *خانه* برمی‌گردید، حتی اگر پنجره را لغو کنید. اگر برای خروجی از فهرست زبانهٔ *خانه* پنجره را لغو کنید، هیچ اتفاقی نمی‌افتد.

اگر مرورگر شما فقط از راه دانلود ذخیره می‌کند (مانند Firefox)، فایل بلافاصله پس از گام 1 در پوشهٔ دانلودهای شما است. شما پیام *به‌صورت دانلود ذخیره شد: ‘name.xml’ اکنون در پوشهٔ دانلودهاست. این محیط به برنامه اجازه نمی‌دهد مستقیماً در محل انتخاب‌شده بنویسد.* را می‌بینید.

### کدام قالب را انتخاب می‌کنید؟

فهرست زبانهٔ *خانه* و کارت‌های *فایل › خروجی* همان قالب‌ها را ارائه می‌دهند:

- *پیشرفت (Excel)* و *پیشرفت (CSV)*، روی کارت‌های *صفحهٔ پیشرفت (Excel)* و *صفحهٔ پیشرفت (CSV)*: یک صفحهٔ کوچک با شناسه، WBS، نام، تاریخ‌ها و درصد تکمیل، برای فرستادن به کسی که پیشرفت را وارد می‌کند.
- *CSV (;)*، روی کارت *CSV (نقطه‌ویرگول‌جدا)*: فهرست وظیفه‌ها که آن را در یک صفحه‌گسترده باز می‌کنید.
- *MS Project XML*: می‌توان آن را در Microsoft Project باز کرد.
- *Primavera P6 XML*: برای Oracle Primavera P6.
- *IFC*: قالب اختصاصی نرم‌افزار، با همه‌چیز در آن، در طرح‌وارهٔ IFC پروژه (پیش‌فرض IFC 4.3 ADD2).

### خروجی IFC با فایل کتابخانه

اگر پروژهٔ شما به یک کتابخانهٔ منابع پیوند دارد، کادر انتخاب *فایل کتابخانه را هم ذخیره کن* زیر کارت‌های *فایل › خروجی* است. اگر آن را علامت بزنید و *IFC* را انتخاب کنید، نرم‌افزار دو بار محل ذخیره را می‌پرسد: اول برای پروژه، بعد برای *projectname-bibliotheek.ifc*. این کادر انتخاب فقط در *فایل › خروجی* است، نه در فهرست زبانهٔ *خانه*.

### بازگرداندن یک صفحهٔ پیشرفت

صفحهٔ پیشرفتِ پرشده را از طریق *فایل › درون‌ریزی* دوباره می‌خوانید. ببینید [درون‌ریزی پیشرفت از یک صفحه‌گسترده](docs://howto-voortgang-importeren).

## نکات احتیاطی و کاری که نرم‌افزار در آن صورت انجام می‌دهد

**پروژهٔ شما تغییر نمی‌کند.** فایل پروژهٔ شما همان می‌ماند، و نشانهٔ *ذخیره‌نشده* هم اگر بوده باشد، می‌ماند.

**اگر برنامه به‌روز نباشد، ابتدا محاسبهٔ دوباره انجام می‌شود.** بنابراین تاریخ‌های به‌روز را می‌گیرید، حتی اگر فراموش کرده باشید *محاسبه* را فشار دهید.

**خروجی در فهرست اخیر هم می‌آید.** این برای صفحه‌های پیشرفت صدق نمی‌کند. اگر خروجی را آن‌جا باز کنید، به‌عنوان درون‌ریزی همان قالب باز می‌شود.

**خروجی همه‌چیز را حمل نمی‌کند.** فایل CSV منابع یا محدودیت‌ها ندارد، و P6 XML خطوط مبنا و مهلت‌ها ندارد. پروفایل محاسبه هم همراه آن نمی‌رود: خروجی‌ای که دوباره باز شود، با *Open Planner Studio* محاسبه می‌شود. فقط IFC همه‌چیز را حمل می‌کند. یک مثال با عدد را در [فایل‌ها و قالب‌ها](docs://uitleg-bestanden) پیدا می‌کنید.

**دو قالب با پسوند یکسان.** MS Project XML و Primavera P6 XML هر دو نام *projectname.xml* می‌گیرند. خودتان به آن‌ها نام‌های متفاوت بدهید، وگرنه بعداً نمی‌دانید کدام فایل کدام قالب است.

**برنامه‌ای با رابطهٔ چرخشی خروجی گرفته نمی‌شود.** نرم‌افزار ابتدا محاسبه می‌کند و اگر حلقه‌ای باشد، متوقف می‌شود. در زبانهٔ *خانه* پیام *محاسبهٔ برنامه ممکن نشد* را می‌بینید و زیر آن، برای نمونه: *رابطه چرخشی بین وظایف: Set up site → Demolish existing extension → Set up site*. در *فایل › خروجی* فقط متن دوم روی صفحه است. حلقه را برطرف کنید و دوباره خروجی بگیرید.

**پروژه‌ای از Primavera اطلاعات منبع خود را از دست می‌دهد.** اگر چنین پروژه‌ای را به CSV، MS Project XML یا P6 XML خروجی بگیرید، نرم‌افزار این پیام را نشان می‌دهد: *خروجی به CSV باعث از دست رفتن اطلاعات منبع XER می‌شود.* برای MS Project XML پیام *MSPDI* و برای P6 XML پیام *P6* را نشان می‌دهد. ببینید [بازکردن یک فایل Primavera P6 (.xer)](docs://howto-xer-openen).

**تقسیم‌های وظیفه از بین می‌روند.** MS Project و Primavera تقسیم را فقط به‌صورت توزیع ساعت می‌شناسند. اگر پروژهٔ شما تقسیم‌های وظیفه بدون توزیع ساعت داشته باشد، نرم‌افزار پس از خروجی به MS Project XML یا P6 XML این پیام را نشان می‌دهد: *2 کار دارای وقفه بدون وقفه‌هایشان صادر شدند: MS Project/P6 وقفه‌ها را فقط به‌صورت توزیع کار می‌شناسند.* برای یک وظیفه پیام *1 کار دارای وقفه بدون وقفه‌هایش صادر شد: MS Project/P6 وقفه‌ها را فقط به‌صورت توزیع کار می‌شناسند.* را نشان می‌دهد. ببینید [تقسیم کردن یک وظیفه](docs://howto-taak-splitsen).

**برنامه در نمای *تاریخ‌های ثبت‌شده*.** وقتی تاریخ‌های فایل مبدأ را می‌بینید و به CSV خروجی می‌گیرید، نرم‌افزار مقدار `Critical` و `Total Float` را برای وظیفه‌هایی خالی می‌گذارد که فایل مبدأ این مقدارها را برای آن‌ها ثبت نکرده است. ببینید [تاریخ‌های ثبت‌شده](docs://uitleg-datums-zoals-opgeslagen).
