# وصل کردن یک دستیار هوش مصنوعی (MCP)

هدف: به یک دستیار هوش مصنوعی اجازه دهید برنامهٔ شما را دنبال کند و روی آن کار کند. شما دید روشنی از کارهایی که انجام می‌دهد داشته باشید، و محدودیت‌ها را خودتان تعیین کنید.

## وقتی این را لازم دارید

می‌خواهید یک دستیار هوش مصنوعی برنامهٔ شما را بخواند، تحلیل کند یا تغییر دهد. برای نمونه، تا یک WBS اولیه پیش‌نویس کند، وظیفه‌ها را اصلاح کند یا مسیر بحرانی را توضیح دهد. این کار از راه **Model Context Protocol** (MCP) انجام می‌شود: استانداردی که به یک دستیار هوش مصنوعی اجازه می‌دهد ابزارهای یک برنامه را به کار ببرد. برای این کار، Open Planner Studio یک سرور کوچک روی رایانهٔ خودتان اجرا می‌کند، به نام **پل**. این سرور مجموعه‌ای از ابزارها را ارائه می‌دهد. نام همهٔ آن‌ها با `planner_` شروع می‌شود: خواندن و تغییر وظیفه‌ها، رابطه‌ها، منابع، تقویم‌ها، خطوط مبنا، سندها و فایل‌ها. اینکه کدام ابزارها هستند و چه چیزهایی را رد می‌کنند، در [ابزارهای هوش مصنوعی](docs://ref-ai-tools) آمده است. اینکه چرا پیوند به این شکل کار می‌کند، در [نحوهٔ کار پیوند هوش مصنوعی](docs://uitleg-ai-koppeling) است.

پل فقط در نرم‌افزار دسکتاپ کار می‌کند. اگر حالت هوش مصنوعی را در مرورگر روشن کنید، زبانهٔ *هوش مصنوعی* را می‌بینید. اما دکمهٔ *شروع پل* خاکستری است، با متن *پل فقط در برنامهٔ دسکتاپ کار می‌کند*. بقیهٔ این مقاله دربارهٔ نرم‌افزار دسکتاپ است. در مرورگر، *پشتیبان‌گیری اکنون* و *باز کردن پوشهٔ پشتیبان* هم خاکستری هستند.

## مرحله‌ها

### 1. حالت هوش مصنوعی را روشن کنید

1. *تنظیمات › پروژه › تنظیمات* را انتخاب کنید. می‌توانید همچنین *فایل › تنظیمات* را انتخاب کنید، یا نماد چرخ‌دنده در بالا را.
2. زبانهٔ *پیشرفته* را انتخاب کنید و *فعال‌سازی حالت هوش مصنوعی* را روشن کنید. زبانهٔ *هوش مصنوعی* در نوار ظاهر می‌شود.
3. اگر می‌خواهید پل به محض شروع نرم‌افزار فعال باشد، *شروع خودکار پل* را هم روشن کنید. این فقط وقتی انجام می‌شود که حالت هوش مصنوعی روشن باشد، و فقط در نرم‌افزار دسکتاپ. به‌صورت پیش‌فرض خاموش است، چون باز کردن پورت یک تصمیم آگاهانه است.

اگر حالت هوش مصنوعی را خاموش کنید، پل متوقف می‌شود و زبانهٔ *هوش مصنوعی* ناپدید می‌شود.

### 2. پل را شروع کنید

1. به زبانهٔ *هوش مصنوعی* بروید و زیر *سرور* روی *شروع پل* کلیک کنید.
2. وضعیت کنار دکمه را بررسی کنید. آنجا *خاموش*، *فعال روی پورت 3877*، *پورت 3877 اشغال است* یا *خطا* نوشته می‌شود. اگر شروع موفق باشد، *فعال روی پورت 3877* نوشته می‌شود و نام دکمه *توقف پل* است. با *پورت 3877 اشغال است* یا *خطا*، دکمه همچنان *شروع پل* است؛ به بخش مشکل‌ها مراجعه کنید.

پل فقط روی رایانهٔ خودتان و روی یک پورت گوش می‌دهد. به‌صورت پیش‌فرض این پورت 3877 است. در گروه *اتصال* می‌توانید زیر *پورت* پورت دیگری انتخاب کنید، اما فقط وقتی پل متوقف است.

### 3. دستیار را وصل کنید

1. روی *اتصال* زیر *اتصال* کلیک کنید. پنجرهٔ *جزئیات اتصال* باز می‌شود.
2. آنچه کلاینت شما لازم دارد را انتخاب کنید. پایین‌تر را ببینید.
3. توکن پنهان است. با نماد چشم آن را نشان می‌دهید. دکمه‌های کپی همیشه مقدار واقعی را کپی می‌کنند، حتی اگر صفحه توکن را پنهان کند.
4. از دستیار بخواهید فهرست ابزارها را درخواست کند. این بررسی در پرامپت اتصال هم آمده است: دستیار باید ابزارهایی با پیشوند `planner_` ببیند. تعداد موردنظر در پرامپت اتصال آمده است.

این پنجره سه راه برای اتصال دارد:

- *قطعهٔ پیکربندی*: بخشی از پیکربندی که آن را در تنظیمات MCP کلاینت خود می‌چسبانید.
- *پرامپت اتصال*: متنی که آن را در دستیار هوش مصنوعی خود می‌چسبانید. بعد از آن دستیار خودش متصل می‌شود.
- *نقطهٔ پایانی* و *احراز هویت*: جزئیات جداگانه. نقطهٔ پایانی `http://localhost:3877/mcp` است، با انتقال *streamable HTTP*. هر درخواست به یک هدر `Authorization: Bearer` نیاز دارد، و بعد از آن توکن شما می‌آید. کلاینت شما باید هم از نشست‌های MCP پشتیبانی کند: وقتی متصل می‌شود، پل در هدر `Mcp-Session-Id` یک کد نشست می‌دهد و هر درخواست بعدی بدون این کد را رد می‌کند. Claude Code و `mcp-remote` این کار را خودشان انجام می‌دهند.

**بعد از به‌روزرسانی نرم‌افزار دوباره وصل شوید.** اگر کلاینت هوش مصنوعی شما قبلاً به نسخهٔ قدیمی‌تر نرم‌افزار وصل بود، هنوز کد نشست نمی‌فرستد و پل هر درخواست را رد می‌کند. پس بعد از به‌روزرسانی دوباره وصل شوید: یک نشست تازه در Claude Code شروع کنید، و Claude Desktop را کاملاً ببندید و دوباره شروع کنید.

**Claude Code.** قطعهٔ پیکربندی مستقیم با Claude Code کار می‌کند. این فرمان را در یک ترمینال بدهید، و به جای `<token>` توکن خودتان را بگذارید:

```
claude mcp add --transport http open-planner-studio http://localhost:3877/mcp --header "Authorization: Bearer <token>"
```

می‌توانید قطعه را هم در فایل `.mcp.json` در پوشهٔ پروژه‌تان بگذارید. آن‌وقت این فایل را در git نگذارید، چون توکن به برنامهٔ شما دسترسی می‌دهد. یک سرور از `.mcp.json` باید در بار اول در Claude Code تأیید شود.

**Claude Desktop.** قطعهٔ پیکربندی مستقیم با Claude Desktop کار نمی‌کند. در فایل `claude_desktop_config.json` باید نام برنامه‌ای را بنویسید که Claude Desktop خودش راه می‌اندازد، نه یک نشانی. پس ابزار بیرونی `mcp-remote` را میان این دو قرار دهید؛ به Node.js نیاز دارد. در Claude Desktop گزینهٔ *تنظیمات › Developer › Edit Config* را انتخاب کنید، این متن را در فایل بگذارید (با توکن خودتان) و Claude Desktop را دوباره شروع کنید:

```
{
  "mcpServers": {
    "open-planner-studio": {
      "command": "npx",
      "args": ["-y", "mcp-remote", "http://localhost:3877/mcp", "--header", "Authorization:${AUTH_HEADER}"],
      "env": { "AUTH_HEADER": "Bearer <token>" }
    }
  }
}
```

توکن در `env` است و نه در `args`، عمداً: در Windows، Claude Desktop یک آرگومان را که فاصله دارد می‌شکند. یک *کانکتور سفارشی* در Claude (*Customize › Connectors*) با پل کار نمی‌کند. Claude آنگاه از ابرِ Anthropic وصل می‌شود، و آن نمی‌تواند به پل روی رایانهٔ شما برسد.

در گروه *اتصال* فیلد *توکن* هم وجود دارد. این یک کد بلند و تصادفی است که نرم‌افزار برای شما می‌سازد و روی همین رایانه ذخیره می‌کند. در پنجره این پیام نوشته شده است: *این توکن به برنامهٔ باز دسترسی می‌دهد؛ آن را با دیگران به اشتراک نگذارید*. با نماد *توکن جدید* یک توکن تازه می‌سازید. نرم‌افزار ابتدا می‌پرسد: *ساخت توکن جدید همهٔ اتصال‌های موجود را قطع می‌کند. ادامه می‌دهید؟* اگر پل در حال اجراست، با توکن تازه دوباره راه می‌افتد و توکن قدیمی دیگر کار نمی‌کند.

### 4. ببینید هوش مصنوعی چه کاری می‌کند

1. زیر *فعالیت* روی *پنل فعالیت* کلیک کنید. در بخش کناری، پنل *فعالیت هوش مصنوعی* باز می‌شود.
2. هر فراخوانی پل روی یک خط نمایش داده می‌شود. جدیدترین خط در بالا است. هر خط زمان، آنچه رخ داده، مدت اجرا و موفق بودن یا نبودن را نشان می‌دهد. روی یک خط کلیک کنید تا *آرگومان‌ها* و *پاسخ* باز شوند.
3. با *پاک‌کردن* فهرست را خالی می‌کنید. پنل 500 فراخوانی آخر را نگه می‌دارد. تا وقتی اتفاقی نیفتاده باشد، این پیام نمایش داده می‌شود: *هنوز فعالیت هوش مصنوعی وجود ندارد. فراخوانی‌های پل اینجا نمایش داده می‌شوند*.

وقتی حالت هوش مصنوعی روشن است، یک نقطه با *هوش مصنوعی* در پایین سمت راست نوار وضعیت دیده می‌شود. رنگ آن وضعیت پل را نشان می‌دهد. با کلیک روی آن به زبانهٔ *هوش مصنوعی* می‌روید.

### 5. محدودیت‌ها را تنظیم کنید

زیر *ایمنی* دکمه‌هایی هستند که با آن‌ها هوش مصنوعی را محدود می‌کنید:

- *مکث*: هوش مصنوعی به‌طور موقت اجازه ندارد چیزی را تغییر دهد. خواندن همچنان مجاز است. پل فعال می‌ماند. دکمه به *ازسرگیری* تغییر می‌کند.
- *فقط خواندنی*: وقتی این حالت روشن است، همهٔ ابزارهایی که چیزی را تغییر می‌دهند رد می‌شوند.
- *پشتیبان‌گیری خودکار: روشن*: پیش از اولین تغییر هوش مصنوعی در یک سند، نرم‌افزار یک پشتیبان IFC می‌نویسد. این به‌طور پیش‌فرض روشن است. با دکمه آن را خاموش می‌کنید. بعد نوشته می‌شود *پشتیبان‌گیری خودکار: خاموش*. این کار برای هر سند یک بار انجام می‌شود، هر بار که پل را شروع می‌کنید.
- *پشتیبان‌گیری اکنون*: همان لحظه یک پشتیبان از سند فعال می‌سازد. بعد از آن نوشته می‌شود *پشتیبان ساخته شد:* همراه با نام فایل.
- *باز کردن پوشهٔ پشتیبان*: پوشهٔ پشتیبان‌ها را باز می‌کند.

پشتیبان‌ها در پوشهٔ `ai-backups` داخل پوشهٔ داده‌های نرم‌افزار قرار دارند. نرم‌افزار پشتیبان‌های اخیر را نگه می‌دارد و پشتیبان‌های قدیمی‌تر را کم می‌کند. دقیقاً چگونگی آن در [ابزارهای هوش مصنوعی](docs://ref-ai-tools) آمده است.

### 6. از دستیار بخواهید خوب برنامه‌ریزی کند

دستیار فقط وقتی خوب برنامه‌ریزی می‌کند که قواعد برنامه‌ریزی را بداند. چرایی اهمیت آن‌ها و آنچه در آن‌ها هست را در [نحوهٔ کار اتصال هوش مصنوعی](docs://uitleg-ai-koppeling) می‌خوانید. این کارهایی است که خودتان انجام می‌دهید:

1. **برای قواعد اصلی کاری نکنید.** آن‌ها هنگام اتصال می‌آیند. اینکه کلاینت شما آن‌ها را در پرامپت سیستمی‌اش می‌گذارد، به خود کلاینت بستگی دارد.
2. **راهنما را بخوانید.** پرامپت اتصال در پنجرهٔ *جزئیات اتصال* از دستیار می‌خواهد راهنمای برنامه‌ریزی را با ابزار `planner_get_planning_guide` بخواند. اگر از پرامپت استفاده نمی‌کنید، خودتان از دستیار بخواهید: *پیش از هر تغییری، ابتدا راهنمای برنامه‌ریزی را با planner_get_planning_guide بخوانید.* می‌توانید خودتان راهنما را در `https://open-planner-studio.open-aec.com/agent/planning-guide.md` بخوانید.
3. **اختیاری: مهارت‌ها را نصب کنید.** این فقط با دستیاری کار می‌کند که مهارت‌ها را پشتیبانی کند. `SKILL.md` مربوط به *goed-plannen* و *progress-update* را بگذارید در `.claude/skills/goed-plannen/SKILL.md` و `.claude/skills/progress-update/SKILL.md` در پوشهٔ پروژه‌ای که دستیار در آن کار می‌کند، یا زیر `~/.claude/skills/` برای هر پروژه.

فایل‌ها را به دو راه می‌گیرید. از دستیار بخواهید ابزار `planner_get_planning_guide` را با `part` برابر `skill` فراخوانی کند: پاسخ هر دو متن را دارد و برای هر مهارت، جایی که باید قرار بگیرد. یا آن‌ها را از `https://open-planner-studio.open-aec.com/skills/goed-plannen/SKILL.md` و `https://open-planner-studio.open-aec.com/skills/progress-update/SKILL.md` دانلود کنید. اگر *goed-plannen* هنوز از نسخهٔ قدیمی‌تر نرم‌افزار آنجاست، آن را جایگزین کنید: آن متن قدیمی به هلندی است و به مقالهٔ راهنما اشاره می‌کند، نه به راهنمای دستیارها.

اینکه دستیار راهنما را واقعاً خوانده است، در *پنل فعالیت* دیده می‌شود: آنجا فراخوانی `planner_get_planning_guide` دیده می‌شود. پاسخ نهایی باید فهرستی از فرض‌ها داشته باشد: مدت‌های برآوردی، تقسیم‌بندی‌ای که انتخاب شده، رابطه‌هایی که خودش ساخته و هر محدودیتی که گذاشته است. اگر آن فهرست نیست، آن را بخواهید. بعد از یک به‌روزرسانی پیشرفت با *progress-update*، پاسخ باید تاریخ وضعیت، تاریخ پایان تازه و انحراف نسبت به خط مبنا را نام ببرد.

## مشکل‌ها و کاری که نرم‌افزار آن‌وقت می‌کند

**هوش مصنوعی چیزی را تغییر می‌دهد که می‌خواهید برگردانید.** هر تغییر هوش مصنوعی یک مرحله است. آن را با *واگرد* (Ctrl+Z) برمی‌گردانید. مجموعه‌ای از تغییرات که هوش مصنوعی یکجا می‌فرستد، یک مرحله است. بعد از آن، پروژه ذخیره‌نشده نشان داده می‌شود. بعد از هر تغییر، محاسبهٔ دوبارهٔ برنامه انجام می‌شود، پس خودتان لازم نیست F5 را فشار دهید.

**نرم‌افزار یک فراخوانی هوش مصنوعی را رد می‌کند.** با *مکث* و *فقط خواندنی* نرم‌افزار همهٔ تغییرات را رد می‌کند. خواندن ممکن می‌ماند، از جمله محاسبهٔ دوبارهٔ یک برنامهٔ قدیمی. اگر خودتان وسط یک ویرایش هستید، مثلاً کشیدن یک نوار وظیفه یا تایپ در یک فیلد، هوش مصنوعی تاریخ‌های پیش از ویرایش شما را می‌گیرد. همراه با آن یک هشدار می‌گیرد که آن‌ها قدیمی‌اند. اگر یک کادر گفتگو باز است، برای نمونه تنظیمات، کادر گفتگوی وظیفه یا پنجرهٔ خوش‌آمد، یا حالت ارائه روشن است، نرم‌افزار همهٔ فراخوانی‌ها را رد می‌کند، حتی خواندن. این تا وقتی ادامه دارد که آن کادر گفتگو را ببندید. هوش مصنوعی آن‌وقت یک پیام خطا می‌گیرد با نام داخلی آنچه باز است، برای نمونه `showTaskDialog`. فقط `planner_get_planning_guide` کار می‌کند، چون برنامهٔ شما را نمی‌خواند.

**شما بین زبانه‌ها جابه‌جا می‌شوید وقتی هوش مصنوعی کار می‌کند.** هوش مصنوعی روی سندی کار می‌کند که اولین تغییرش در آن ثبت شد. اگر در این فاصله بین زبانه‌ها جابه‌جا شوید، نرم‌افزار تغییر بعدی آن را رد می‌کند. این کار را انجام می‌دهد تا وقتی که تأیید کند هوش مصنوعی می‌خواهد روی زبانهٔ دیگر کار کند. به این ترتیب هیچ چیز در پروژهٔ اشتباه قرار نمی‌گیرد.

**هوش مصنوعی یک فایل می‌نویسد یا باز می‌کند.** هوش مصنوعی می‌تواند یک برنامه را به‌صورت فایل IFC بنویسد، و یک فایل برنامه را در زبانهٔ تازه باز کند. این کار را فقط در پوشهٔ کاربری شما انجام می‌دهد. فایل موجود را فقط وقتی بازنویسی می‌کند که صریحاً بخواهد.

**وضعیت نشان می‌دهد *پورت 3877 اشغال است*.** برنامهٔ دیگری از پورت استفاده می‌کند. پیام نرم‌افزار زیر آن نشان داده می‌شود. فیلد پورت قفل می‌ماند، با پیام *فقط وقتی سرور متوقف است قابل ویرایش است*. این در حالی است که پل اجرا نمی‌شود، و دکمهٔ توقف هم وجود ندارد. این یک کمبود شناخته‌شده است. تا وقتی برطرف شود: *فعال‌سازی حالت هوش مصنوعی* را خاموش و دوباره روشن کنید. پس از آن وضعیت دوباره *خاموش* می‌شود و می‌توانید پورت دیگری انتخاب کنید. سپس جزئیات اتصال را دوباره کپی کنید، چون نقطهٔ پایانی شامل پورت است.

**کلاینت بعد از توکن جدید نمی‌تواند وصل شود.** توکن جدید همهٔ اتصال‌های موجود را قطع می‌کند. توکن جدید را به کلاینت بدهید، یا دوباره قطعهٔ پیکربندی را بچسبانید.

**شما پل را خودتان متوقف کرده‌اید و آن خودبه‌خود شروع نمی‌شود.** *شروع خودکار پل* هر بار که نرم‌افزار شروع می‌شود، یک بار کار می‌کند. اگر خودتان پل را متوقف کنید، نرم‌افزار آن را بی‌سروصدا دوباره روشن نمی‌کند.

**زبانهٔ *هوش مصنوعی* ناپدید شده است.** حالت هوش مصنوعی خاموش است. آن را در مرحلهٔ 1 روشن کنید.

**یک صفحهٔ وب در مرورگر نمی‌تواند با پل صحبت کند.** پل هر درخواستی را که از مرورگر بیاید رد می‌کند. هر درخواستی را که توکن درست نداشته باشد هم رد می‌کند.
