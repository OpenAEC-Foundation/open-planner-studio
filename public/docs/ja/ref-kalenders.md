# カレンダーウィンドウ

*カレンダー* ウィンドウは、プロジェクトのカレンダー一覧を管理します。稼働日、稼働時間、非稼働日を設定します。また、どのカレンダーがプロジェクトカレンダーかを設定します。一覧の横にあるフォームは、*リソースカレンダー* ウィンドウのフォームと同じです。この記事では、各フィールドの働き、既定値、そしてそのフィールドで何が起きるかを説明します。カレンダーを作成してタスクに割り当てる方法は [カレンダーの作成と割り当て](docs://howto-kalender-maken-en-toewijzen) に書かれています。アプリが稼働日をどのように数えるかは [カレンダーと稼働日](docs://uitleg-kalenders) に書かれています。

## 場所

- **カレンダー** — *計画 › カレンダー › カレンダー* または *設定 › カレンダー › カレンダー*。
- **タスクのカレンダー** — *タスクの編集* ウィンドウまたは *プロパティ* パネルにあるフィールド *カレンダー*。詳しくは [タスクダイアログとプロパティパネル](docs://ref-taak-eigenschappen) を参照してください。
- **リソースカレンダー** — *リソース* パネルの列 *カレンダー*。カレンダーを選ぶか、新しいカレンダーを作るには *+ リソースカレンダー* を選びます。選んだカレンダーを編集するには、鉛筆（*編集…*）をクリックします。詳しくは [リソースパネル](docs://ref-resourcepaneel) を参照してください。

## カレンダーウィンドウの一覧

左側にカレンダーの一覧、右側に選んだカレンダーのフォームがあります。プロジェクトカレンダーには星が付きます。入力が無効なカレンダーには赤い三角が付きます（*このカレンダーには無効な入力があります*）。

- **新規カレンダー**（プラス） — *新規カレンダー* という名前で、アプリの既定の内容を持つカレンダーを追加します。その内容は、月曜から金曜、07:00 から 16:00、標準稼働日は 8 時間です。*建設モードを有効にする* がオン（既定）なら、オランダの祝日も含まれます。建設業休暇は含まれません。オフなら、祝日の一覧は空です。その祝日が不要な場合は、*祝日を生成…* を選び、そのウィンドウで *祝日なし* を選びます。（名前 *Bouwkalender NL* と *Standaardkalender* は、どの言語でもオランダ語のままです。）
- **複製** — 選んだカレンダーを、*{name}（複製）* という名前でコピーします。
- **削除**（ごみ箱） — 選んだカレンダーを削除します。カレンダーが一つしか残っていない場合は、無効になります。削除したカレンダーがプロジェクトカレンダーだった場合は、残っている最初のカレンダーがプロジェクトカレンダーになります。そのカレンダーを使っていたタスクとリソースは、プロジェクトカレンダーに戻ります。
- **プロジェクトの既定に設定** — 選んだカレンダーをプロジェクトカレンダーにします。すでにプロジェクトカレンダーであるカレンダーには、星付きの *プロジェクトカレンダー* が表示されます。効果: 自分のカレンダーを持たないタスクは、すべてこのカレンダーで数えます。自分のカレンダーを持たないリソースも同じです。自分でカレンダーを設定したタスクは、そのカレンダーを維持します。
- **適用** — 一覧にあるすべての変更を、一度にプロジェクトに書き込み、スケジュールを再計算して、ウィンドウを閉じます。全体として何も変わっていない場合は、再計算しません。いずれかのカレンダーに無効な入力があると、*適用* は使えません。通常のテキストフィールドで Enter キーを押すと同じ動作になりますが、ウィンドウは開いたままです。
- **キャンセル** — ウィンドウを閉じ、開いてから（または最後の Enter から）行った変更をすべて破棄します。Esc キーと × ボタンは *キャンセル* と同じ働きをします。ウィンドウの外側をクリックしても何も起きないので、入力内容は失われません。

既定では、プロジェクトには *Bouwkalender NL*（建設モードがオン）または *Standaardkalender*（建設モードがオフ）があります。どちらも月曜から金曜、07:00 から 16:00 です。

## フォーム

### 基本

- **名前** — 一覧と、タスクおよびリソースのドロップダウンに表示される名前です。
- **稼働日** — 曜日ごとに 1 つのボタンがあり、*月* から *日* まで並びます。押されているボタンの曜日は稼働日です。並び順は *週の開始日*（*アプリ設定*、*計画* タブ）に従います。既定: *月* から *金*。クイックボタンは二つあります。*月〜金* は、月曜から金曜を 07:00 から 16:00、8 時間に設定します。設定した休憩は、もとの 12:00 から 60 分の暗黙の休憩に戻ります。時間帯がある場合は、土曜と日曜の時間帯を削除し、月曜から金曜の時間帯は残します。*常時（24/7）* は、すべての曜日を 00:00 から 24:00、24 時間に設定します。時間帯がある場合は、毎日 00:00 から 24:00 の一つの時間帯になります。曜日ボタンで曜日をオフにすると、その曜日の時間帯は消えます。もう一度有効にすると、ダイアログを開いたとき、または最後のプリセットの後にあった時間帯が戻ります。その曜日に時間帯がなかった場合は、最初の稼働日（日曜を先頭に数えます）の時間帯を受け取ります。どの曜日にも時間帯がなくなった場合（たとえば全曜日をオフにした場合）は、ダイアログを開いたとき、または最後のプリセットの後にあった最初の稼働日の時間帯を受け取ります。カレンダーにそれもなかった場合は、開始、終了と休憩から作った時間帯を受け取り、それもなければ 07:00 から 12:00 と 13:00 から 16:00 です。効果: タスクは稼働日にだけ作業します。稼働日がないカレンダーは計算できません（*カレンダーに稼働日が設定されていません*）。
- **開始（時）** と **終了（時）** — 稼働日の開始と終了です。設定の *時刻の表示形式*（24 時間または 12 時間）に従う時刻で入力します。既定: 07:00 と 16:00。矢印（または矢印キー）は 15 分単位で調整します。終了は 24:00（12 時間表記では *12:00 AM*）にできます。開始は終了より前でなければなりません。効果: 休憩と合わせて、標準稼働日を決めます。日数で数えるタスクの日付には影響しません。時間で数えるタスクには影響します。これらのフィールドは、稼働時間の帯がないカレンダーにだけあります。カレンダーに曜日ごとの稼働時間がある場合は、それが優先され、*稼働時間* ブロックで時刻を設定します。
- **休憩の開始** と **休憩時間（分）** — 休憩の開始と長さです。同じく 15 分単位で調整します。既定: 12:00 と 60 分。休憩時間を 0 にすると、稼働日は途切れなくなります。休憩は稼働日の中に完全に収まる必要があり、稼働日全体を占めることはできません。効果: 標準稼働日は、終了から開始と休憩を引いた時間です。時間で数えるタスクは、休憩中に作業しません。同じフィールドは、*開始（時）* と同じ条件で表示されなくなります。
- **稼働時間の帯があるカレンダー** — 曜日ごとの稼働時間の帯があるカレンダー（たとえば MS Project のカレンダー: 08:00 から 12:00 と 13:00 から 17:00）では、*時間計画を有効にする* がオフでも、ウィンドウは常に *稼働時間* ブロックを表示します。帯はそこで直接変更します。その場合、*開始（時）*、*終了（時）* と休憩は表示されません。効果: アプリは、帯を使って計算します。日数で数えるタスク（*標準稼働日*）も同じです。
- **標準稼働日** — 読み取り専用です。最も多く出現する稼働日の長さを、末尾の 0 を省いて示します。例: *8h* または *7.5h*。既定: 8。効果: これは、日と時間を変換するときや、時間で数えるタスクでの一日の長さです。カレンダーに稼働時間の帯がある場合、このフィールドは帯の一日の合計のうち最も多いものを示します。帯を変えると、数字はすぐに変わります。名前の横の情報アイコンにも、この説明があります。どの曜日にも稼働時間がない場合、フィールドにはダッシュ（—）が表示されます。カレンダーに独自の一日の時間数（たとえば Primavera P6 から）がある場合、その値はエクスポート用に保たれます。その値が数字と異なる場合、ウィンドウは、フィールドのすぐ下にオレンジ色のブロックを表示し、両方の数字を示します。詳しくは [日と時間](docs://uitleg-dagen-en-uren) を参照してください。

### 稼働時間

この部分は、*時間計画を有効にする*（*アプリ設定*、*計画* タブ）がオンのとき、そして稼働時間の帯があるカレンダーでは常に表示されます。ここで、曜日ごとの稼働時間とシフトを設定します。稼働時間の帯がないカレンダーは、時間計画がオンのときだけ、プリセットまたは *曜日ごとに設定…* で帯を受け取ります。詳しくは [稼働時間の設定](docs://howto-werktijden-instellen) を参照してください。

- **プリセット** — 稼働時間をまとめて設定するボタンです。*日勤*（月〜金、08:00 から 16:00。通常の日のカレンダー）、*2交代*（月〜金、06:00 から 22:00、16 時間）、*3交代*（月〜金、06:00 から翌日の 06:00、24 時間）、*夜勤*（月〜金、22:00 から 06:00、8 時間）、*24/7*（全曜日、00:00 から 24:00）があります。組み込みのボタンの後に、自分のプリセットが並びます。各プリセットには削除用の × があります。
- **プリセットとして保存…** — 現在の稼働時間を、このデバイスに自分のプリセットとして保存します。そうすると、どのプロジェクトでも再利用できます。名前（*プリセット名*）を入力し、*保存* または *キャンセル* をクリックします。
- **曜日ごとに設定…** — 日のカレンダーを時間のカレンダーに変えます。現在の時刻が、すべての稼働日の稼働時間の帯になります。休憩は、帯の間の空きになります。時間のカレンダーでは、ボタンの名前が *稼働時間を非表示* または *稼働時間を表示* になり、エディタを開閉します。時間のカレンダーでは、エディタは既定で開いています。
- **エディタ** — 曜日ごとに、開始時刻と終了時刻を持つ帯（*band*）のリストがあります。時刻は *開始（時）* と同じ表示形式です。*翌日* のチェックボックスを入れると、帯を真夜中を越えて続けられます（夜勤など）。終了時刻を 24:00（12 時間表記では *12:00 AM*）にすると、帯は真夜中ちょうどに終わります。その場合、*翌日* はオフのままです。開始時刻より前の終了時刻（たとえば 22:00 から始まる帯に 02:00）を入力すると、帯は翌日まで続き、*翌日* は自動的にオンになります。*帯を追加*（プラス）は 08:00 から 16:00 を追加します。*すべての稼働日にコピー*（月〜金だけ）は、その曜日の帯を月曜から金曜へコピーします。帯がない曜日は *非稼働* と呼ばれます。一日に帯が複数ある場合は、一番下に *2つの時間帯の間の空きは休憩です。必要に応じて時刻を調整してください。* というヒントが表示されます。効果: 帯が優先されます。帯がある曜日は稼働日になり、*開始（時）*、*終了（時）* と休憩のフィールドは表示されなくなります。

### 祝日

- **祝日を生成…** — 生成ツールを開きます。*国* では、*オランダ*、*ドイツ*、*ベルギー*、*フランス*、*イギリス*、*オーストリア*、*スイス*、または *祝日なし* を選べます。*地域* は、その国に地域がある場合だけ表示されます。既定は *全国* です。*建設業休暇* は、国がオランダで *建設モードを有効にする* がオンのときだけ表示されます。選択肢は *なし*（既定）、*北部*、*中部*、*南部* です。ヒント *目安の日付です — Bouwend Nederlandで確認してください* が表示されます。プレビュー行には、これから入る祝日の数が表示されます（*… 件の祝日、…–…*）。一覧は展開できます。*生成* を押すと、編集中のカレンダーに結果が入ります（有効になるのは *適用* の後です）。*キャンセル* は生成ツールを閉じます。効果: *祝日* の一覧全体が置き換えられます。自分で追加した祝日も、すべて置き換えられます。生成の対象となる年は、プロジェクト開始日の前年から、プロジェクト終了の翌年までです。プロジェクト終了がない場合は、開始から三年後までです。詳しくは [祝日の生成と建設業休暇](docs://howto-feestdagen-genereren) を参照してください。
- **再生成** — 生成した祝日が、プロジェクト期間をもうカバーしなくなると、ボタンの横に表示されます。テキストは *祝日は…–…をカバーしています。プロジェクトは…まで続きます。再生成しますか？* です。クリックすると、同じ選択（国、地域、建設業休暇）で、新しい期間を対象に再度生成します。これをしないと、生成した年の外の日は通常の稼働日になります。
- **祝日** — 非稼働日の一覧です。列は *説明*、*開始日*、*終了* で、各行に削除用のごみ箱があります。*祝日を追加* は、今日を *開始日* にした行を追加し、*終了* は空のままにします。*終了* が空の行は一日です。行がないときは、*祝日はまだありません。* と表示されます。効果: この期間のすべての日は、このカレンダーで非稼働日になります。これは、このカレンダーのタスクと、このカレンダーを使うリソースに適用されます。無効な行は赤い枠になり、文章が表示されます（*有効な開始日を入力してください。*、*有効な終了日を入力するか、1日だけの場合は空欄のままにしてください。*、または *終了日が開始日より前になっています。*）。その行があると、*適用* は使えなくなります。

### エラーメッセージと例外

稼働時間のエラーは、フィールドの下に表示され、*適用* を妨げます。次のメッセージがあります: *有効な開始時刻を HH:MM 形式で入力してください。*、*有効な終了時刻を HH:MM 形式で入力してください。*、*開始時刻は終了時刻より前である必要があります。*、*有効な休憩開始時刻を HH:MM で入力してください。*、*休憩時間は 0 以上の整数分でなければなりません。*、*休憩は設定した勤務日の範囲内でなければなりません。*、そして *休憩が勤務日全体を占めることはできません。*

カレンダーが例外として扱うのは、非稼働日だけです。MS Project または Primavera のファイルから来たカレンダーは、稼働日の例外、つまり余分な稼働日を持つこともあります。このウィンドウでは、それらを表示も編集もしません。

## リソースカレンダーウィンドウ

- **リソースカレンダー** — 上のフォームを、*適用* と *キャンセル* だけがあるウィンドウに入れたものです。Esc キーと × は *キャンセル* と同じ働きをします。ウィンドウの外側をクリックしても何も起きません。Enter キーも、ここでは何もしません。このウィンドウでは、一つのカレンダーを編集します。既存のカレンダーか、新しいカレンダーです。新しいカレンダーの既定名は *リソースカレンダー* です。*適用* の後で、そのカレンダーはリソースにリンクされます（*キャンセル* の場合は何も残りません）。リソースパネルの *ライブラリ* ビューで開くと、リソースライブラリのカレンダーを編集します。*プロジェクト* ビューで開くと、プロジェクトのカレンダーを編集します。そのカレンダーがリソースライブラリから来ていても同じです。効果: リソースカレンダーは、ヒストグラム、過剰割り当て、山崩しで、リソースがいつ利用可能かを決めます。タスクの日付は変わりません。*適用* は再計算しません。カレンダーがタスクにも付いている場合、またはプロジェクトカレンダーである場合は、スケジュールが変わります。その場合、スケジュールは最新ではないとマークされ、*計算* で再計算されます。詳しくは [リソースカレンダーの設定](docs://howto-resourcekalender-instellen) を参照してください。
