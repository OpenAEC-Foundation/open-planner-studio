# 関係を追加する

目的: タスクをリンクし、前の作業が終了したときにだけタスクが開始するようにします。必要な場合は、タスクの間に待ち時間（ラグ）を追加します。

## 必要になるとき

関係がないと、アプリはレンガ職人が基礎の打設後にしか作業できないことを認識しません。その場合、すべてのタスクがプロジェクト開始日に始まり、終了日は意味を持ちません。**関係**はその順序を記録します。最初のタスクが**先行タスク**、次のタスクが**後続タスク**です。

スケジュールを作成するとき、タスクを追加するとき、または二つのタスクが結局は互いに依存すると分かったときに、関係を追加します。**ラグ**は二つのタスクの間の待ち時間です。例えば、硬化させなければならないコンクリートや、乾燥させなければならない床の下地モルタルなどです。

既定の関係は **FS**（終了-開始）です。後続タスクは、先行タスクが終了した後にしか開始できません。アプリは SS、FF、SF も扱います。これらは開始または終了を、別の開始または終了に結び付けます。例えば SS（開始-開始）では、左官仕上げは設備工事が開始した後にしか開始できません。

どの種類が必要か分からないときは、種類の選択の下にある文を見てください。その文には実際のタスク名が入っており、例えば *Metselwerk は Fundering の完了後に開始します。* のように説明します。別の種類を選ぶと、文も変わります。この文は *関係の種類* ウィンドウ、*依存関係* ブロック、*先行タスク* 列または *後続タスク* 列で表示されます。

## 手順

関係を追加する方法は四つあります。どの方法でも同じ関係が作成されます。状況に合う方法を選んでください。

### 選択した二つのタスクをリンクする

タスクテーブルで作業するときに便利です。

1. タスクテーブルで、最初に来るタスク（先行タスク）をクリックします。
2. Ctrl（Mac では ⌘）を押したまま、次に来るタスク（後続タスク）をクリックします。
3. *ホーム › タスク › リンク ▾ › 選択したタスクをリンク* を選択します。同じボタンは *計画 › 関係* にもあります。

アプリは、ラグなしの終了-開始の関係を作成します。関係は、Gantt と *先行タスク* 列に矢印として表示されます。通知は、アプリが関係を拒否したときにだけ表示されます。このボタンは、ちょうど二つの選択したタスクがあるときにのみ機能します。

### Gantt で関係を描画する

関係を続けて多く追加するときに便利です。

1. *ホーム › タスク › リンク ▾ › 関係を描画* を選択します。スケジュールの上に、通知 *リンクモード: ガントチャートでバーから別のバーへドラッグすると関係を作成します。Esc で終了します。* が表示されます。
2. 先行タスクのバーを押したまま、後続タスクのバーまでドラッグします。矢印付きの破線がカーソルに追従します。
3. マウスボタンを離します。小さなウィンドウ *関係の種類* が表示されます。このウィンドウには種類（既定は FS）と、ラグを入力する欄があります。
4. 必要に応じて種類またはラグを変更し、Enter を押すか、ウィンドウの外をクリックします。関係が作成されます。
5. すぐに次の関係を追加してください。モードはオンのままです。終了するには、Esc を押すか、通知の *停止* ボタンを使うか、*関係を描画* をもう一度選択します。

*関係の種類* ウィンドウで Esc を押すと、何も記録されません。一つだけ関係を作成する場合は、モードをオンにする必要はありません。バーからバーへドラッグするあいだ Shift を押したままにしてください。バーの右クリックメニューにある *ここから関係を開始* は、リンクモードをオンにします。それでもドラッグは自分で行う必要があります。*テーブル* タブでは、Gantt がないため、*関係を描画* は無効です。

### プロパティパネルで関係を追加する

一つのタスクを見ていて、その先行タスクまたは後続タスクを追加したいときに便利です。

1. タスクを選択します。*プロパティ* パネルは右側にあります。表示されない場合は、*表示 › パネル › プロパティ* でオンにしてください。
2. *依存関係* ブロックで、*関係を追加* をクリックします。
3. もう一方のタスクが先に来る場合は、方向を *先行タスク* のままにします。後に来る場合は *後続タスク* を選択します。
4. もう一方のタスク名の一部を入力します。矢印キーと Enter で正しいタスクを選ぶか、クリックします。
5. 種類（既定は FS）を選択し、必要ならラグを入力します。
6. Enter を押すか、チェックマーク（*関係を作成*）をクリックします。

そのタスクの関係は、*依存関係* に一覧表示されます。各関係には、もう一方のタスクの WBS 番号、種類、ラグが表示されます。

### 先行タスク列に関係を入力する

キーボードで素早く作業し、WBS 番号が分かっているときに便利です。

1. タスクテーブルの見出し行の右にある **+** をクリックします（*列を追加*）。*関係* の下で、*先行タスク* 列を選択します。*後続タスク* 列も同じ方法で使えます。
2. *先行タスク* 列で、後続タスクのセルをクリックします。
3. 先行タスクの WBS 番号、空白、種類を入力します。例えば `2.6 FS` です。その直後にラグを付けます: `2.6 FS+1d`。複数の先行タスクは、セミコロンまたはカンマで区切ります: `3.1 FS; 3.2 SS+2d`。
4. Enter を押します。

入力した内容でセル全体が置き換わります。セルにすでに先行タスクがある場合は、それらも入力してください（「落とし穴とアプリの動作」を参照）。入力せずにセルで Enter または F2 を押すと、既存の関係を保持したまま入力欄が開きます。その欄で WBS 番号または名前でタスクを検索し、各関係の種類とラグを選択します。

### ラグを設定または変更する

上記のどの方法でも、種類の横の欄にラグを入力します。既存のラグは *依存関係* で変更します。ラグの欄をクリックし、新しい値を入力して Enter を押します。

- `3` または `3d`: 稼働日 3 日。週末は数えません。アプリは `+3d` と表示します。
- `3ed`: 暦日 3 日。週末も数えます。土曜日と日曜日にも硬化するコンクリートの場合と同じです。
- `-1`: 負のラグ（リード）。後続タスクは 1 日早く開始できます。そのため、タスクが重なります。
- `4h`: 稼働時間 4 時間。アプリは `+4h` と表示します。先行タスクが日タスクで、かつ、標準カレンダーのように独自の稼働時間の帯を持たないカレンダーの場合、アプリはこれを稼働日の単位に変換します。最も近い整数の日に丸めます。この場合、`4h` は 1 日、`2h` は 0 日として扱われます。独自の稼働時間の帯を持つカレンダーの場合、または時間タスクの後の場合、ラグは時間単位で正確に数えられます。
- `50%`: 先行タスクの期間の半分。

例: 基礎コンクリートは、煉瓦工が作業する前に硬化しなければなりません。そのため、*Pour foundation → Foundation brickwork* に、ラグ `3` の FS 関係を設定します。Pour foundation が 2027年6月18日（金曜日）に行われる場合、**計算** の後、Foundation brickwork は 6月24日（木曜日）に開始します。月曜日から水曜日までは待ち時間です。`3ed` の場合は週末も数えるため、Foundation brickwork は 6月22日（火曜日）に開始します。

### 最後に: 再計算する

新しい関係は、まだバーを動かしません。ステータスバーに *古くなっています — 再計算してください（F5）* と表示されます。**計算**（F5）を押します。例えば *ホーム › スケジュール › 計算* から実行できます。その後で初めて、後続タスクが新しい日付を受け取ります。アプリにこれを自動で行わせる場合は、*設定 › プロジェクト › アプリ設定* のタブ *計画* で *自動計算* をオンにします。

## 落とし穴とアプリの動作

**逆の順序。** *選択したタスクをリンク* では、クリックした順序が有効になります。一覧の順序ではありません。後のタスクを先にクリックすると、関係の向きが逆になります。*依存関係* で、ごみ箱アイコンを使って削除し、もう一度追加してください。

**列へ入力すると、既存の内容が消えます。** セルに `3.4 FS; 3.2 FS` が入っていて、`3.2 FS` だけを入力すると、3.4 との関係が消えます。メッセージは表示されません。先行タスクをすべて入力するか、Enter または F2 を使って既存の内容に追加するか、Ctrl+Z で元に戻してください。

**循環。** 関係を追加した結果、チェーン内の前のタスクに戻る場合、どのタスクも決して開始できません。アプリはこのような関係を拒否します: *この関係はスケジュールに循環を発生させるため（…）、作成されませんでした。* メッセージには、循環のタスクが括弧内に表示されます。まず、循環を閉じている関係を削除してください。

**タスクと自分のサマリータスク。** タスクと、そのタスクが属するサマリータスクとの間の関係はできません。アプリは *タスクとその自身の(祖先)サマリータスクとの間の関係は許可されません。* と表示します。

**重複。** 関係がすでに存在する場合、アプリは *この関係はすでに存在します* と表示し、何も変わりません。

**列の短いメッセージ。** *先行タスク* 列では、同じ拒否が、セルの下の短い文で表示されます: *この変更によりスケジュールに循環が発生します。*、*この関係はすでに存在します。*、または *タスクは自身のサマリータスクと関係を持てません。* `3.1` のように WBS 番号だけを入力すると、種類がありません。その場合、セルには *例: 1.2 FS+2d のように入力してください。* と表示されます。セルは開いたままです。入力を直すか、Esc を押して取り消してください。

**ラグに半日単位はありません。** 日単位のラグは必ず整数です。例えば `1.5` は `+2d` になります。独自の稼働時間の帯を持たないカレンダーの日タスクの後の時間ラグは、整数の稼働日に丸められます。読み取れない入力（例えば単語）は保存されません。欄は前の値に戻ります。
