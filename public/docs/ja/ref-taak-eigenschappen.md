# タスクダイアログとプロパティパネル

タスクは 2 つの場所で編集できます。*タスクの編集* ウィンドウと *プロパティ* パネルです。両方で、ほぼ同じ項目を使います。この記事では、項目ごとに働き、既定値、そして気づく点を説明します。タスクの作成と設定の方法は [タスクとマイルストーンを追加する](docs://howto-taken-en-mijlpalen-toevoegen) にあります。計算結果になる理由は [クリティカルパスとフロート](docs://uitleg-kritiek-pad) にあります。

## 2 つの場所

- **タスクの編集** — 最初に選択したタスク用のウィンドウです。F2 で開きます。Gantt のバーをダブルクリックしても開きます。または、Gantt かテーブルでタスクを右クリックし、*編集…* を選択します。変更は、*保存*（Enter）をクリックするまで下書きのままです。*キャンセル*（Esc）を押すと、変更は破棄されます。名前が空のあいだ、*保存* は使えません。保存は *元に戻す* で 1 つの操作として戻せます。これには、*タスク種類*、*依存関係*、*割り当て* および *コードとフィールド* のセクションでの操作も含まれます。これらは編集中にすでにプロジェクトへ反映されています。*キャンセル* は、それらも取り消します。
- **プロパティ** — 右側の列にあるパネルです。アクティブなタスク用です。変更は、すぐに反映されます。同じ項目への連続した変更は、*元に戻す* では 1 つの操作として数えられます。タスクがないと、*プロパティを表示するタスクを選択してください。* と表示されます。*表示 › パネル › プロパティ* でオンまたはオフにします。既定値はオンです。パネルは Gantt の横と、*テーブル* タブにあります。*IFC* と *レポート* では表示されず、リソースパネル全体の下にもありません。

ウィンドウにだけあるのは *親タスク* と、ボタンの *保存* および *キャンセル* です。パネルにだけあるのは、ごみ箱アイコンの *タスクを削除*、下部の *計算* ボタン、*中断* セクション、*タスク種類* の下にある 3 つのマーカー（長い非稼働期間、MS Project、記録された日付）です。また、*依存関係* での関係の追加と、リンク先タスクへの移動もパネルだけです。ほかのすべての項目は両方にあります。ウィンドウに *依存関係*、*割り当て* および *コードとフィールド* が表示されるのは、既存のタスクの場合だけです。

日付に影響する変更をした場合は、*計算* を押します。*自動計算* がオンでない限り、計算は自動では行われません。

## 一般

- **名前**（ウィンドウの *名前 \**）— Gantt、テーブルおよびレポートに表示される、タスクの名前です。必須です。空の名前は保持されません。新しいタスクの既定値は *新しいタスク* です。
- **WBS コード** — タスクの構造コードです。例: `RB-301`。必須です。*計画 › 構造 › WBS auto* がオンの場合、欄は無効になります（ツールチップ: *WBS コードは自動的に番号付けされます（計画 → 構造）*）。その場合、コードはアプリが管理します。
- **説明** — 自由なテキストです。計算には影響しません。テーブルの列 *説明* として表示できます。
- **作業区分** — タスクの作業区分です。一覧には、グループの *組み込みの作業区分*（*建設*、*設置*、*解体*、*物流*、*検査*、*移設*、*改修*、*保守*）、*自分の作業区分* および *このプロジェクトから* があります。*その他* は、タスクがすでにその作業区分を持つ場合にだけ表示されます。一番下には *+ 新しい作業区分…* と *作業区分を管理…* があります。既定値: 親タスクの作業区分。親タスクがない場合は、*建設*（建設モードがオンのとき。既定でオン）または *その他*。効果: 計算には影響しません。この作業区分でグループ化やフィルターができ、バーの色分けにも使えます。カスタムの作業区分は、お使いの端末に保存されます。選ぶと、そのコピーがプロジェクトに入ります（*このプロジェクトから*）。*+ 新しい作業区分…* で入力した名前が、大文字の違いがあっても *自分の作業区分* に既にある場合、アプリは 2 つ目の作業区分を作らず、既存のものを選びます。*作業区分を管理…* では、自分の作業区分だけを編集または削除できます。空の名前や既に存在する名前は保持されません。開いているプロジェクトが使っている作業区分を削除すると、アプリは先に確認します。プロジェクトのコピーは残ります。*このプロジェクトから* の作業区分（例: 他の人のファイル由来）は、*作業区分を管理…* で *自分の作業区分に追加* をクリックした場合にのみ、自分の一覧に入ります。
- **カレンダー** — タスクの期間、終了日およびフロートを数えるカレンダーです。既定値: *プロジェクトカレンダー: {name}*。効果: 独自のカレンダーを持つタスクは、プロジェクトカレンダーとは別の日に作業します。変更後は、*計算* で日付が再計算されます。詳細は [カレンダーと稼働日](docs://uitleg-kalenders) を参照してください。
- **親タスク**（ウィンドウのみ）— タスクを別のタスクの下に移動します。既定値: 現在の親。*－ なし（ルート）－* を選ぶと、最上位に置かれます。関係の循環を作る選択は、*保存* で拒否され、メッセージが表示されます。ウィンドウは開いたままです。

## メモ

- **メモ** — タスクにあるチェックリストです。*メモを追加* で行を追加します。チェックマーク（*完了*）を付けると、その行に取り消し線が付きます。ごみ箱（*削除*）で行を削除します。行がないと、*メモはまだありません。* と表示されます。計算には影響しません。テーブルの列 *メモ* には、先頭に ✓ または ○ を付けて表示されます。

## マイルストーン

- **マイルストーン** — タスクをマイルストーンにします。既定値: オフ。効果: 期間が 0 になります。サマリータスク（サブタスクを持つタスク）と、リソースの割り当てがあるタスクでは、アプリはメッセージを表示して拒否します。先に割り当てを削除してください。チェックを外すと、*マイルストーンの種類* と *必須（契約上）* は消えます。
- **マイルストーンの種類**（マイルストーンのみ）— *自動*、*開始マイルストーン* または *完了マイルストーン*。既定値: *自動*。効果: 開始マイルストーンは日の始まりに、完了マイルストーンは日の終わりに置かれます。*自動* の場合、マイルストーンが先行タスクになると、開始マイルストーンとして扱われ、日の始まりに置かれます。
- **必須（契約上）**（マイルストーンのみ）— 検査や引き渡しなど、契約上のマイルストーンに印を付けます。既定値: オフ。効果: Gantt とレポート用の印です。日付を守る機能はありません。それには制約または期限を使います。

## 時間

- **開始**（ウィンドウの *開始日*）— Gantt のバーや列 *開始* と同じ日付を表示します。計画の基準日ではありません。タスクがすでに開始している場合は、*実績開始日* が表示され、欄は読み取り専用です。その場合は代わりに *実績開始日* を変更してください。そうでない場合は、計算された開始日です。必須です。空の欄は元の値に戻ります。入力時の効果: 新しい日付が計画の基準日になります（列 *予定開始日*）。タスクに先行タスクがあり、まだ開始していない場合、アプリはその日付で新しい開始を制約 *指定日以降に開始 (SNET)* として記録します。既存の SNET があれば、それを移動します。メッセージが表示されます。そのため、*計算* の後もタスクはそれより早く開始しません。*ASAP* と SNET 以外の制約がある場合、アプリは開始を適用せず、どの制約が開始を決めているかを示します。
- **期間** — タスクが作業する時間です。日数は `5d`、時間は `12h` または `1h 30m` と入力します（`u`、`hour`、`hours` も使えます）。単位のない数字は、タスクの単位で数えられます。日数は常に整数です。時間には小数も使えます。無効な入力では *2d や 12h のように、日数または時間数を整数で入力してください。* と表示され、欄は元に戻ります。新しいタスクの既定値: 5 日（マイルストーンは 0）。サマリータスク、ハンモック、期間 0 のマイルストーンでは、欄は無効です。その期間は他のタスクから決まるか、0 です。時間単位のタスクは、*時間計画を有効にする* がオフのあいだ無効です。同じ名前のボタンがあります。効果: *計算* の後、期間がタスクのカレンダーでの終了日を決めます。タスクにリソースと *タスク種類* がある場合は、タスク種類が作業と単位数のどちらが動くかを決めます。タスクがすでに一部完了している場合、完了した作業より短い期間は拒否されます。詳細は [日と時間](docs://uitleg-dagen-en-uren) を参照してください。
- **期間の単位** — *日* または *時間* を選びます。横に情報ボタンがあります。*時間計画を有効にする* と *日単位と時間単位の混在計画を許可する* がオンのときだけ表示されます（時間計画がオンの場合、後者は既定でオンです）。効果: 別の単位を選ぶと、結果が正確な場合、アプリは期間をすぐに変換します。*元に戻す* で 1 回で元に戻せます。正確に合わない場合、単位は変わらず、アプリがその旨を表示します。有効な稼働時間がないカレンダーでは、切り替えは拒否されます。
- **タスク種類** — 期間 × 単位数 = 作業 の式のうち、3 つのどれかが変わるとき、どれを固定するかを決めます。選択肢: *プロジェクトの既定（固定期間・固定単位）*、*固定期間・固定単位*、*固定期間・固定作業*、*固定作業* および *固定単位*。既定値: *プロジェクトの既定（固定期間・固定単位）*。欄の横の i アイコンは、今適用されているタスク種類を説明します。開いた選択肢の一覧では、各項目に同じ i アイコンがあります。MS Project のタスクでは、この説明に保存された作業時間主導の設定も反映されます。*タスク種類を使用* がオンのとき（*アプリ設定*、タブ *計画*、見出し *計算*）、またはファイル自体にタスク種類や保存済みの作業がある場合にだけ表示されます。また、通常のタスクだけです。サマリータスク、マイルストーン、ハンモック、経過時間のタスクには表示されません。詳細は [タスク種類: 期間、単位数と作業](docs://uitleg-werkregels) を参照してください。

## ハンモック

- **ハンモック（導出された期間）** — 期間を自分では持たず、2 つの他のタスクから期間を導きます。既定値: オフ。通常のタスクだけで使えます。マイルストーンやサマリータスクでは使えません。オンの場合、*開始ドライバー* には 終了-開始 または 開始-開始 の関係を持つ先行タスクが表示されます。*終了ドライバー* には 終了-終了 または 開始-終了 の関係を持つタスクが表示されます。各タスクの後に、関係の種類が表示されます。終了ドライバーがない場合は、*終了ドライバーがありません（FF/SF）— 間隔はゼロ長に戻ります。* と表示され、期間は 0 になります。詳細は [ハンモックを作る](docs://howto-hammock) を参照してください。

## 制約と期限

サマリータスクでは、制約や期限は効果がありません。計算は末端のタスクだけを計算し、サマリータスクの日付はサブタスクから導きます。

- **制約** — タスクの日付の上限または下限です。選択肢: *できるだけ早く (ASAP)*、*できるだけ遅く (ALAP)*、*指定日以降に開始 (SNET)*、*指定日以前に開始 (SNLT)*、*指定日以降に終了 (FNET)*、*指定日以前に終了 (FNLT)*、*指定日に開始 (MSO)* および *指定日に終了 (MFO)*。既定値: *ASAP*。これは制約なしです。ASAP を選ぶと、タスクのすべての制約が消えます。ALAP を選ぶと、副制約が消えます。*計算* の後の効果: 制約はタスクを動かすか、フロートを負にします。詳細は [制約と期限](docs://uitleg-constraints) を参照してください。
- **制約日** — 制約に属する日付です。*ALAP* 以外のすべての制約で表示されます。必須です。新しい制約には、計画された開始日が日付として入ります。
- **必須（ピンロジック）** — *MSO* と *MFO* だけで使えます。既定値: オフ。オンの場合、日付は固定され、関係より優先されます。先行タスクの前であっても、バーを固定します。違反すると、上流で負のフロートになります。初めてオンにすると、説明が 1 回表示されます。
- **副制約** と **副日付** — 2 つ目の制約です。*SNET*、*FNET*、*SNLT*、*FNLT* のどれか 1 つだけ（または *(なし)*）を選べます。主制約が ASAP、ALAP または必須の固定ではない場合に表示されます。副制約は常にソフトです。禁止された組み合わせには、赤い枠と理由が表示されます。副制約は必須にできません。MSO/MFO や必須の固定とは組み合わせられません。ASAP/ALAP とも組み合わせられません。上限または下限でなければなりません。主制約と副制約が同じ側の境界を持つことはできません。有効な組み合わせは、例えば SNET と FNLT です。
- **期限** — 終了の目標日です。空欄 = 期限なし。効果: 期限があるためにタスクが動くことはありません。最早終了が期限より後になると、フロートは負になり、アプリは *期限 … 超過 — 最早終了 …* と報告します。

## 進捗

- **進捗 (%)** — 0 から 100 までのスライダーです。既定値: 0。効果: 0 より大きい値では、アプリは未入力の *実績開始日* を補います。100 では *実績終了日* を補います。状態は次のように変わります。*実績開始日* がない場合は *未開始*、*実績開始日* がある場合は *進行中*、*実績終了日* がある場合は *完了* です。残存期間（*残り*）は、期間 ×（1 − 進捗）です。日単位のタスクは整数の日に、時間単位のタスクは整数の分に丸められます。完了した作業は状態日までで計られます。状態日がまだない場合は、アプリが今日に設定し、その旨を表示します。サマリータスクでは、この欄は無効です。その進捗は *計算* の後にサブタスクから決まります（*サブタスクから算出されます。進捗はサブタスクで変更してください。計算（F5）後にサマリータスクへ反映されます。*）。
- **実績開始日** — タスクが実際に始まった日付です。状態日より後の日付は拒否されます。タスクテーブルと *実績開始日を入力* の質問では、実績終了日より後の日付も拒否されます。タスクが状態日より後に開始する予定で、今進捗が入る場合、ウィンドウは *実績開始日を入力* と表示します。マイルストーンでは、*実績開始日* と *実績終了日* の代わりに、1 つの欄 *実績日* があります。
- **実績終了日** — タスクが実際に終わった日付です。入力すると、進捗は 100 になり、状態は *完了* になります。消去すると、進捗は 0 に戻り、状態は *進行中* になります。状態日より後の日付は拒否されます。*実績開始日* と同様です。
- **残り** — 読み取り専用です（マイルストーンでは表示されません）。残っている期間を、タスクの単位で示します。

ウィンドウは、これらのルールを下書きに適用します。ルールは *保存* の後にのみ有効です。詳細は [進捗、状態日とベースライン](docs://uitleg-voortgang) を参照してください。

## CPM 結果

- **CPM 結果** — 直前の計算の読み取り専用の表示です。*最早開始日*、*最早終了日*、*最遅開始日*、*最遅終了日*、*トータルフロート*、*フリーフロート*、*干渉フロート* および *クリティカルパス*（*はい* または *いいえ*）を示します。フロートは稼働日で、小数点以下 2 桁で表示されます。結果が古い、または未計算ですか。*計算* を押してください。

## 依存関係

- **依存関係** — このタスクの関係です。1 つの関係につき 1 行です。各行には、リンク先のタスク（パネルでは WBS コード、なければ名前。ウィンドウでは名前）、関係が駆動している場合の稲妻アイコン（計算後に *駆動関係（駆動関係）*）、関係の種類（*FS*、*SS*、*FF* または *SF*）、ラグ、ごみ箱があります。パネルでは、WBS コードがボタンです。ポイントすると、タスクが表示されます。クリックすると、そのタスクへ移動します。コードの前の小さな印で役割がわかります。先行タスクは金色の丸、後続タスクは紫色の四角です。色は [パスの追跡](docs://howto-pad-traceren) と同じです。役割は、スクリーンリーダー向けにボタンの名前にも含まれます。ウィンドウでは、テキストとして表示されます。このセクションは、タスクに関係がある場合にだけ表示されます。
- **ラグ** — 単位付きの数字を入力します。例: `2d` は稼働日、`3ed` は暦日、`2u` または `2h` は稼働時間、`3eu` または `3eh` は暦時間、`50%` は先行タスクの期間の割合、`-25e%` は暦時間での割合です。マイナスを付けると、リードになります。単位がない場合は、稼働日として扱われます。無効な入力では、欄が赤くなり、元に戻ります。詳細は [関係とラグ](docs://uitleg-relaties) を参照してください。
- **関係を追加**（パネルのみ）— 下書きの行を開きます。*方向* で *先行タスク* または *後続タスク* を選びます。*タスクを検索…* で、WBS または名前からタスクを探します。種類とラグを選びます。*関係を作成*（または *キャンセル*）で確定します。重複した関係や、タスク自身の親との関係は、メッセージとともに拒否されます。行は残ります。

## 中断

パネルにのみ表示されます。マイルストーン、サマリータスク、ハンモック、経過時間のタスク、手動スケジュールのタスク、中断を入れるには短すぎるタスクには表示されません。

- **中断** — タスクの作業の休止です。休止ごとに 1 行あり、*後*（休止の前の作業量）、*休止*（長さ）、単位（*稼働日*。時間単位のタスクでは *時間*）を表示します。その下に、その後の区間の開始から終了までを表示します。*山崩し* で生じた休止には *山崩し* のバッジが付きます。長さ 0 の休止は削除されます。行ごとのゴミ箱（*中断を削除*）でも削除できます。効果：バーは途切れて描画され、*計算* の後に終了日が休止の分だけ移動します。
- **中断を追加** — タスクの最も長い区間の中央に、1 単位の休止を追加します。休止を入れる余地がない場合は無効です。
- **すべての中断を削除** — 中断が、ここでは編集できない形式の元ファイルに由来する場合にだけ表示されます（*これらの中断は元のファイルに由来し、ここでは編集できない形式です。*）。その場合は日付だけが表示されます。

詳しくは [タスクを分割する](docs://howto-taak-splitsen) を参照してください。

## 割り当て

- **割り当て** — このタスクのリソースです。各リソースは 1 行に表示されます。その行には、矢印、リソースの色の小さな四角、名前、*単位数*、*作業 (h)* およびゴミ箱（*削除*）があります。行の上の見出しで列の名前がわかります。名前をクリックすると、その下に *曲線*、*時間配分*…、*移動先*… が表示されます。もう一度クリックすると非表示になります。割り当てに *均等* 以外の曲線または独自の時間配分がある場合、折りたたんでいても名前の横に棒のアイコンが表示されます。一番下にあるリスト *リソースを割り当てる* は、そのリソースを 1 日あたり 1 単位で割り当てます。リソースがない場合は *先にリソースを作成してください（リソースタブ）。* と表示されます。すべてのリソースが割り当て済みの場合は *すべてのリソースはすでに割り当てられています。* と表示されます。マイルストーンまたはサマリータスクでは、割り当てできないと表示されます。
- **単位数** — タスクがリソースを 1 日あたりどれだけ使うかを示す数値です（1 日あたりの単位数）。0 より大きい数値です。欄には小数点以下 2 桁まで表示されます。正確な値はツールチップにあります。カンマまたはピリオドで入力できます。効果: ヒストグラムの負荷と過剰割り当てに影響します。タスク種類がある場合は、作業にも影響します。割り当てが Primavera P6（`.xer` または P6 XML）から来ていて、作業が残っている場合は、これは残りのレートです（P6 の *残り単位数/時間*）。計画されたレートは、テーブルの列 *1日あたりの計画された単位数* に保存されたままです。
- **作業 (h)** — このリソースの残作業を時間で示します。タスク種類が表示されていて、タスクにタスク種類がある場合にだけ表示されます。資材の場合はダッシュが表示されます。見出しの鍵アイコンは、タスク種類がどの項目を保護しているかを示します（*タスク種類で保護されています…*）。欄の警告の三角形（*単位 × 期間と一致しません*）は、保存された作業が単位 × 残存期間と等しくないことを意味します。その場合、ヒストグラムは保存された作業に従います。
- **曲線** — 作業が期間全体にどう広がるかを示します: *均等*、*前倒し*、*後ろ倒し*、*山型（ベル型）*、*早期ピーク*、*後期ピーク*、*二峰*、または *タートル*。既定値は *均等* です。割り当てに独自の時間配分がある場合は *輪郭* と表示され、リストは無効です。インポートされた曲線は *インポートされた曲線* と表示されます。
- **時間配分…** — この割り当ての稼働日ごとの時間配分を開きます。[時間配分の調整](docs://howto-urenverdeling-aanpassen) を参照してください。
- **移動先…** — 割り当てを、そのリソースをまだ持たない別の末端タスクへ移動します。そのようなタスクがある場合にだけ表示されます。

## コードとフィールド

- **コードとフィールド** — プロジェクトにアクティビティコードまたはカスタムフィールドがある場合にだけ表示されます。各アクティビティコードは、*(なし)* と値の一覧を持つリストです。値は `code — description` の形で表示されます。タイプごとに、値を 1 つまで選択できます。各カスタムフィールドには型に合う入力欄があります：*テキスト*、*数値*、*整数*、*コスト*、*日付*、*はい/いいえ*。効果：計算には影響しません。これらでグループ化やフィルターができ、列として表示できます。詳しくは [コードとカスタムフィールド](docs://howto-codes-en-velden) を参照してください。

## タスク種類の下のマーカー

パネルにのみ表示され、該当する場合だけ表示されます。

- **長い非稼働期間** — *このタスクは … 日間の非稼働期間にまたがっています（… 〜 …）。* と表示されます。祝日名または工事休止の名前が追加される場合もあります。祝日を少なくとも 1 日含む、8 日以上の連続期間をタスクがまたぐ場合に表示されます。これは拒否ではなく警告です。スケジュールがそのとおりに意図されているか確認してください。
- **MS Project のマーカー** — ブロック *MS Project の時間配分に従っています*、*編集後は MS Project の日付ウィンドウが適用されなくなりました — …*、または *独自の時間配分* が表示され、*詳細を見る* が付きます。MS Project ファイルの時間配分が今も日付を決めているかどうかを示します。
- **記録された日付** — *時間* の一番上、*開始* のすぐ上にあるブロックです。アプリがファイルの日付を表示しているあいだ表示されます。表示はオレンジ色です。*表示されているのは、ファイルに記録されていた日付です。アプリの計算結果ではありません。*（Primavera のファイルの場合は *表示されているのは Primavera が保存した日付です。アプリの計算結果ではありません。*）。その下に *再計算すると、このタスクは変わります。* または *再計算しても、このタスクは変わりません。* が表示されます。ファイルにこのタスクのすべての情報が含まれていない場合は、3 行目に不足している値が表示されます: *このタスクのすべての情報がファイルにはありません。不足: …*（Primavera の場合は *Primavera はこのタスクのすべての情報を保存していません。不足: …*）。ブロックはオレンジ色のままです。*詳細を見る* が付きます。詳しくは [記録された日付](docs://uitleg-datums-zoals-opgeslagen) を参照してください。

## パネルの上部と下部

- **タスクを削除** — 見出し *タスク* の横にあるゴミ箱です。このタスクをサブタスクと一緒に削除します。*元に戻す* の下で 1 つの操作として記録されます。その後、*計算* を押すまでスケジュールは最新ではなくなります。
- **計算** — 下部のボタンです。*ホーム › スケジュール › 計算* と同じ計算を実行します。

## ここにないもの

- **山崩し優先度** — ウィンドウにもパネルにもありません。右クリックして *優先度* を選ぶか（*低* = 100、*標準* = 500、*高* = 900）、列 *山崩し優先度* に 0 から 1000 までの数値を入力して設定します。既定値は 500 です。効果：山崩しでは、優先度の高いタスクが先に位置を保ちます。1000 にするとタスクが固定され、山崩しで動かなくなります。詳しくは [山崩し](docs://uitleg-nivelleren) を参照してください。
- **その他のタスクデータ** — タスクが持つ残りの情報、たとえば列 *手動スケジュール* と *色*、およびテクニカル列は、表にのみあります。詳しくは [表の列](docs://ref-tabelkolommen) を参照してください。
