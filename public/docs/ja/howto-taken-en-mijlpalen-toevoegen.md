# タスクとマイルストーンの追加

目標：新しいタスクまたはマイルストーンを、スケジュールの正しい場所に追加します。

## この操作が必要な場合

スケジュールを作成している場合、作業を追加する場合、または引き渡しや検査などの時点を記録したい場合です。

**タスク** は、時間がかかる仕事です。新しいタスクの期間は、既定で 5 稼働日です（時間計画では、プロジェクトの既定を時間にできます）。**マイルストーン** は、期間がない時点です。その期間は 0 日です。サブタスクを持つタスクを **サマリータスク** と呼びます。建設工事では、多くの場合フェーズです。**計算**（F5）を使うとすぐに、そのサマリータスクの期間と日付は、そのサブタスクから決まります。

## 手順

### タスクを追加する

1. *ホーム › タスク › タスク* を選択します。同じボタンは *テーブル* タブにもあります。
2. *プロパティ*パネルが開き、*名前*フィールドが選択されます。名前を入力して Enter を押します。

新しいタスクは、最初は *新しいタスク* という名前で、プロジェクト開始日に始まります。

タスクを選択している場合、新しいタスクはその直下に、同じレベルで追加されます。選択したタスクがサマリータスクの場合、新しいタスクはそのフェーズ全体の下に、つまりサブタスクの後に追加されます。何も選択していない場合は、リストの末尾に追加されます。ボタンのツールチップに、どちらになるかが表示されます：*選択したタスクのすぐ下に新しいタスクを追加します* または *リストの末尾に新しいタスクを追加します*。複数のタスクを選択すると、画面に表示されている順で最も下のタスクの下に、新しいタスクが 1 つ作成されます。

### タスクテーブルで続けて追加する

タスクテーブルの最後のタスクの下には、常に灰色の *新しいタスク* 行があります。これはまだタスクではありません。Gantt にもファイルにもありません。

1. その行のセルをクリックするか、下矢印キーで移動します。
2. 名前を入力して Enter を押します。これで実際のタスクになります。上のタスクと同じレベルです。カーソルは、すぐ下の新しい灰色の行に移ります。
3. 次の名前を入力します。以下同様に続けます。

灰色の行に期間や日付だけを入力した場合、タスクの名前は *新しいタスク* になります。何も入力せずに離れた場合は、何も起こりません。タスクも *元に戻す* の手順もありません。タスクの作成と最初の値の入力は、*元に戻す* では 1 つの手順としてまとめられます。灰色の行は、タスクテーブルがフィルター、グループ化、並べ替えされていないときだけ表示されます。

### 空いている場所で右クリックする

空いている場所を右クリックします。タスクテーブルでは最後のタスクの下、Gantt ではバーの横またはバーの下です。*新しいタスク* または *マイルストーンを追加* を選択します。タスクはリストの末尾に追加されます。Gantt では、クリックした日付から始まります。タスクテーブルでは、名前のセルがすぐに開き、入力できます。

### 特定のタスクの上または下に追加する

タスクを右クリックして、*上に挿入* または *下に挿入* を選択します。キーボードでも操作できます。Insert で選択したタスクの上に追加し、Ctrl+I（Mac では ⌘+I）で下に追加します。タスクテーブルでは、Insert の後に名前のセルがすぐに開き、入力できます。

複数のタスクを選択している場合は、新しいタスクが 1 つ作成されます。*上に挿入* は、選択したタスクのうち最も上のタスクの上に、*下に挿入* は最も下のタスクの下に追加します。

### サブタスクを追加する

タスクを右クリックして、*サブタスクを追加* を選択します。新しいタスクは、そのタスクのサブタスクの末尾に追加されます。Gantt の隣にあるタスクテーブルでは、サマリータスクの名前の後ろにも小さな **+** があります。これも同じことをします。

### マイルストーンを追加する

1. *ホーム › タスク › マイルストーン ▾* を選択し、次に *開始マイルストーン*、*完了マイルストーン*、または *検査ポイント（必須）* を選択します。
2. 名前を入力して Enter を押します。配置は *タスク* と同じルールに従います。

三つの種類の違いは次のとおりです：

- *開始マイルストーン* は、その日の始まりに置きます。*完了マイルストーン* は、その日の終わりに置きます。Gantt では、ひし形がそれぞれ日付の区間の左または右に表示されます。後続タスクにも影響します。たとえば、2026年9月29日（火曜日）のマイルストーンのあとに、終了-開始の関係でタスクが続くとします。開始マイルストーンの後では、そのタスクは同じ火曜日に始まります。完了マイルストーンの後では、9月30日（水曜日）に始まります。
- *検査ポイント（必須）* は、作業区分 *検査* の完了マイルストーンで、*必須（契約上）* にチェックが付いています。

### 既存のタスクをマイルストーンにする

タスクを右クリックして *マイルストーンを切り替え* を選択するか、*プロパティ*パネルで *マイルストーン* にチェックを付けます。メニュー項目は、選択したすべてに使えます。期間は 0 になります。

マイルストーンの設定を外すと、期間 0 の通常のタスクのままになります。期間は自分で入力します。

### その他の方法

- Ctrl+M（Mac では ⌘+M）を押すと、タスクが選択されていても、リストの末尾に新しいマイルストーンが追加されます。*プロパティ*パネルは開きません。
- Ctrl+M か右クリックメニューで作成したマイルストーンは、作業区分 *検査* になります。*マイルストーン ▾* の *開始マイルストーン* または *完了マイルストーン* は、作業区分 *その他* になります。必要な場合は、*プロパティ*パネルで作業区分を変更してください。
- タスクの右クリックメニューにある *マイルストーンを追加* は、マイルストーンをそのタスクのサブタスクにします。同じ階層のタスクにはなりません。

### タスクまたはブランチ全体をコピーする

1. Gantt で、タスクのバーをクリックします。Ctrl を押しながらクリックすると、ほかのタスクも選択できます。
2. Ctrl+C（Mac では ⌘+C）を押します。アプリは、タスクをそのサブタスク、コピーしたタスク同士の関係、リソースの割り当てと一緒にコピーします。
3. 必要に応じて、コピーを置きたいタスクのバーをクリックし、Ctrl+V（Mac では ⌘+V）を押します。

コピーは、同じ名前、同じ日付、同じ進捗になります。選択したタスクと同じ階層に入ります。複数選択時は、最初にクリックしたタスクと同じ階層に入ります。その同じ階層の中では、末尾に置かれます。何も選択していない場合は、リストの末尾に入ります。コピーしたタスクは、そのあと選択されます。WBS の番号（ツリー内の各タスクの番号。例：1.2。詳しくは [構造の調整](docs://howto-structuur-aanpassen) を参照）が再び決まり、スケジュールは古くなります。

クリップボードはアプリ全体で共有されるため、別のドキュメントに貼り付けることもできます。そこに存在しないもの（たとえば、タスクのカレンダー、カスタムの作業区分、アクティビティコード、カスタムフィールド）は、アプリが消去して、そのことを知らせます。

### その後

新しいタスクは、まだほかの日付を変更しません。ステータスバーには *古くなっています — 再計算してください（F5）* と表示されます。**計算**（F5）を押します。たとえば *ホーム › スケジュール › 計算* から実行できます。

## 注意点と、アプリの動作

**すべての新しいタスクは、プロジェクト開始日から始まります。** 関係がなければ、タスクは何も待ちません。関係を追加します。詳しくは [関係の追加](docs://howto-relaties-leggen) を参照してください。

**フィルター、グループ化、または並べ替えが有効です。** その場合、画面に見えている順序は、スケジュールの順序ではありません。タスクを選択している場合、*タスク* と *マイルストーン ▾* は新しいタスクを末尾に追加します。赤い通知に *新しいタスクは末尾に追加されました。フィルター、グループ化、並べ替えの間は、アプリは選択中の項目の下に配置できません。* と表示されます。*上に挿入* と *下に挿入* は拒否され、*フィルター/グループ化/並べ替え中は使用できません* の帯が表示されます。通知または帯の *クリア* ボタンは、フィルター、グループ化、並べ替えを一度に解除します。これは *元に戻す* には含まれません。Ctrl+Z では戻りません。

**リソースの割り当てがあるタスクの下のサブタスク。** そのタスクはサマリータスクになります。サマリータスクは、自分では割り当てを持ちません。アプリは割り当てを新しいサブタスクに移し、そのことを知らせます。それができない場合、たとえば *マイルストーンを追加* を選んだときは、マイルストーンは割り当てを持てないため、アプリは何も追加せず、理由を説明します。

**マイルストーンの下のサブタスク。** マイルストーンはサマリータスクになり、アプリはマイルストーンのフラグを外します。その旨のメッセージが表示されます。

**サマリータスク、または割り当てのあるタスクにマイルストーンを設定する場合。** アプリは拒否し、理由を説明します。割り当てがある場合は、先に割り当てを削除してください。

**タスクテーブルでのコピー。** タスクテーブル（および *テーブル* タブ）では、Ctrl+C は、表計算ソフトのように、選択したセルの値だけをコピーします。Ctrl+V はセルに貼り付けます。そのため、タスクをコピーできるのは Gantt を使う場合だけです。先にバーをクリックしてください。
