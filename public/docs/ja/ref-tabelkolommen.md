# 表の列

タスクテーブルには 86 の固定列があります。さらに、プロジェクトのアクティビティコードとカスタムフィールドごとに 1 列、ベースラインごとに 8 列があります。この記事では、各列が何を表示するか、編集できるかどうか、値がどの形式で書かれるかを説明します。列の選び方と並べ方は、[表の列を変更する](docs://howto-tabelkolommen-aanpassen) に書かれています。

## 列を選ぶ場所

Gantt の横にあるタスクテーブルと、*テーブル* タブの表には、それぞれ独自の列の選択があります。ヘッダーの右側にある + を押すと、列の選択ウィンドウ（ウィンドウのタイトル *列を選択*）が開きます。*テーブル* では *テーブル › 列 › 列…* も使えます。列の選択ウィンドウには、列がカテゴリごとに並びます。カテゴリは *タスク*、*計画*、*制約*、*依存関係*、*リソース*、*進捗*、*計算値*、*ベースライン*、*カスタム* と *技術情報* です。名前で検索できます。*最近使用した列* は一番上にあります。*既定値に戻す* を選ぶと、既定の列に戻ります。

既定では、Gantt の横のタスクテーブルに *WBS*、*タスク名* と *期間* が表示されます。*テーブル* タブの表には、*WBS*、*タスク名*、*期間*、*開始*、*終了*、*作業区分*、*クリティカル*、*トータルフロート* と *進捗* が表示されます。さらに、プロジェクトのアクティビティコードとカスタムフィールドごとに 1 列が表示されます。

## 値の読み方と編集

- **計算列** — カテゴリ *計算値* の列と、そのほかいくつかの列は読み取り専用です。これらの値は計算から得られます。読み取り専用のセルを編集しようとすると、アプリに *この計算列は編集できません。* と表示されます。このメッセージは、列が計算列でない場合も含め、読み取り専用のすべてのセルに共通です。何かを変更して値が古くなった場合、値の横に *古い* が表示されます。*計算* を選ぶまで表示されたままです。
- **日付** — *アプリ設定* の *外観* タブ、見出し *日付形式* で選んだ形式で表示されます。
- **期間とフロート** — 期間は、タスクの単位（`5d`、`12h`）で表示されます。または、同じタブの *期間の表示* に従って表示されます（*自動（タスクごとの単位）*、*常に日* または *常に時間*）。フロートは、小数点以下 2 桁の稼働日で表示されます。小数点の記号は、お使いの言語に従います。
- **はい/いいえ** — はい/いいえの値は *はい* または *いいえ* で表示されます。空の値は、ダッシュ（—）で表示されます。
- **編集** — 値を入力するか、選択します。無効な値は拒否され、セルの下に理由が表示されます。例: *5d や 8h のような有効な期間を入力してください。* または *0〜100 のパーセントを入力してください。* セルのブロックを貼り付けると、セルごとに処理されます。読み取り専用のセルは飛ばされ、アプリは飛ばした数を表示します。

## タスク

- **タスク名** — タスクの名前。編集できます。必須です。サマリータスクは太字で表示され、名前のセルはうすい背景色になります。マイルストーンは、マイルストーンの色で太字で表示されます（Gantt のマイルストーンと同じ色の系統です）。通常のタスクは変わりません。これは書式だけです。選択、ドラッグ、編集は同じように動作します。
- **説明** — 説明文。編集できます。自由な文章です。
- **WBS** — WBS コードです。編集できて、必須です。ただし *WBS auto* がオンの間は読み取り専用です。
- **作業区分** — 作業区分（*建設*、*設置*、*解体*、*物流*、*検査*、*移設*、*改修*、*保守* または *その他*）。一覧から編集できます。
- **カスタム作業区分** — プロジェクトのカスタム作業区分、またはダッシュ（—）。プロジェクトのカスタム作業区分の一覧から編集できます。
- **色** — タスクに保存されている色で、色コード（例: `#1a73e8`）で表示されます。色の選択ツールで編集できます。色は IFC ファイルに保存されますが、バーもレポートも使いません。バーの色は、*表示 › ベースラインと進捗 › バーの色* で設定します。
- **メモ** — メモは `✓ text; ○ text` の形式で表示されます。メモが 1 件以下の間は編集できます（その場合はメモの本文を編集します）。メモが 2 件以上の場合は読み取り専用です。

## 計画

- **マイルストーン** — タスクがマイルストーンかどうか。編集できます。オンにすると期間は 0 になります。サマリータスクと割り当てのあるタスクでは、アプリはこれを拒否します。
- **マイルストーンの種類** — *開始マイルストーン* または *完了マイルストーン*、または自動の場合はダッシュ（—）。マイルストーンでのみ編集できます。
- **必須マイルストーン** — フラグ *必須（契約上）*。マイルストーンでのみ編集できます。
- **山崩しの優先度** — 0 から 1000 までの整数。既定値は 500 です。編集できます。1000 にすると、山崩しでタスクが固定されます。
- **分割の間隔** — 休憩の数を `Split gaps: 2` の形で表示します。ダッシュ（—）の場合もあります。読み取り専用です。編集は *プロパティ* パネルで行います。
- **タスク種類** — タスクに設定されているタスク種類。空の場合は、プロジェクトの既定値です。一覧から編集できます。ただし、マイルストーン、サマリータスク、ハンモックでは、空で読み取り専用です。タスク種類が表示されているときだけ、列の選択ウィンドウに表示されます（*タスク種類を使用*、またはファイルにタスク種類が含まれる場合）。
- **ハンモック（計算された期間）** — タスクがハンモックかどうか。マイルストーンとサマリータスクを除き、編集できます。
- **カレンダー** — タスク独自のカレンダーの ID。空（—）の場合は、プロジェクトのカレンダーです。ID を入力するか、候補から選びます。不明な ID は拒否されます。注: このセルには、現在、名前ではなく内部の ID が表示されます。*プロパティ* パネルでカレンダーを選ぶ方が適切です。
- **期間の種類** — *稼働時間*（期間は、カレンダーの稼働日または稼働時間で数えます）または *経過時間*（期間は、カレンダーを使わず、連続した時計の時間で数えます）。編集できます。
- **期間の単位** — *日* または *時間*。サマリータスク、ハンモック、マイルストーンを除き、編集できます。変換が正確で、*時間計画を有効にする* がオンの場合にだけ切り替えが動作します。
- **期間** — タスクの期間。タスクの単位、または *期間の表示* に従って表示されます。編集できます。`5d`、`12h`、`1h 30m` と入力します。タスクの単位の数値も入力できます。サマリータスク、ハンモック、期間が 0 のマイルストーンでは読み取り専用です。
- **開始** — 表示されている開始日です。Gantt のバーと同じ日付です。開始したタスクでは、実績開始日です。編集できます。先行タスクがあるタスクに新しい開始日を入れると、その日付に制約 *指定日以降に開始 (SNET)* が付きます。サマリータスクまたはハンモックでは、手動スケジュールでない限り読み取り専用です。開始したタスクも読み取り専用です。その場合は *このタスクは開始しています。開始は実績開始です。進捗から変更してください。* と表示されます。
- **終了** — 表示されている終了日です。完了したタスクでは、実績終了日です。編集できます。新しい終了日を入れると、新しい期間になります。マイルストーン、経過時間のタスク、休憩があるタスクでは、アプリは拒否します。開始より前の終了日も拒否します（*終了が開始より前です。*）。サマリータスクまたはハンモックでは、手動スケジュールでない限り読み取り専用です。完了したタスクも読み取り専用です。その場合は *このタスクは完了しています。終了は実績終了です。進捗から変更してください。* と表示されます。
- **予定開始日** — 計算の起点となるスケジュール上の基準日（表示されている開始日と同じとは限りません）。編集できます。*開始* に入力するのと同じ効果があります。
- **予定終了日** — 入力された終了日。手動スケジュールのタスクでのみ編集できます。それ以外の場合、アプリは *予定終了日は手動スケジュールのタスクにのみ適用されます。終了は「終了」列または期間で変更してください。* と表示します。

## 制約

- **制約の種類** — 制約の種類。*できるだけ早く (ASAP)* から *指定日に終了 (MFO)* までです。編集できます。制約がないタスクには *ASAP* と表示されます。
- **制約日** — 制約の日付。編集できます。
- **ハード制約** — フラグ *必須（ピン留めロジック）*。*MSO* と *MFO* でのみ編集できます。
- **副制約の種類** — 2 つ目の境界の種類、またはダッシュ（—）。編集できます。この列の一覧にはすべての種類が表示されますが、許可されない組み合わせは拒否されます。副制約は *SNET*、*FNET*、*SNLT* または *FNLT* でなければなりません。主制約は境界でなければならず（*ASAP*、*ALAP*、*MSO*、*MFO*、またはハード制約ではない）、2 つの制約は反対側の境界でなければなりません（下限の *SNET*/*FNET* と上限の *SNLT*/*FNLT*、またはその逆）。
- **副制約日** — 2 つ目の境界の日付。編集できます。
- **期限** — 終了の目標日。編集できます。

## 依存関係

- **先行タスク** — 先行タスクを `WBS type±lag` の形で、`; ` で区切って表示します。例: `1.2 FS+2d`。同じ形式で入力すると編集できます。ここでは外部関係を追加しません。外部関係は *計画 › 依存関係 › リンク › 外部関係を追加…* で追加します。
- **後続タスク** — 後続タスクを同じ形式で表示します。編集できます。
- **駆動関係** — このタスクの日付を決める関係を、`← 1.2`（先行タスク）または `→ 1.4`（後続タスク）で表示します。読み取り専用です。*計算* を実行するまで、古い状態です。
- **フリーフロート**（カテゴリ *依存関係* の列） — 関係ごとのフリーフロートを `← 1.2: 3d` の形で表示します。*計算値* の下の *フリーフロート* 列とは別の列です。その列はタスク自身のフロートを表示します。読み取り専用です。
- **警告** — 関係ごとの警告。例: *順序どおりではありません* または *計算に含まれていません*。読み取り専用です。詳しくは [通知と警告](docs://ref-meldingen) を参照してください。

## リソース

- **割り当てられたリソース** — 割り当てられたリソースの名前を、カンマで区切って表示します。編集できます。名前を追加すると、そのリソースが 1 日あたり 1 単位で割り当てられます。名前を削除すると、割り当てが削除されます。マイルストーンまたはサマリータスクでは、読み取り専用です。
- **1日あたりの割り当て単位** — リソースごとの単位数を `Name: 1; Name: 0.5` の形で、小数点以下 2 桁までで表示します。保存されている値は正確なままです。割り当てのあるタスクで編集できます。
- **計画された1日あたりの割り当て単位** — リソースごとの計画された割合を `Name: 1.11` の形で、小数点以下 2 桁までで表示します。*1日あたりの割り当て単位* と同じ形式です。Primavera P6 からの割り当てで、残りの割合が異なる場合にだけ表示されます。その場合、*1日あたりの割り当て単位* には残りの割合が表示されます。読み取り専用です。
- **割り当て曲線** — リソースごとの曲線を `Name: Uniform` の形で表示します。割り当てのあるタスクで編集できます。
- **作業ウィンドウの開始** と **作業ウィンドウの終了** — 取り込んだファイルのリソースごとの作業ウィンドウを、`Name: date` の形で表示します。読み取り専用です。
- **計画作業（時間）** と **実績作業（時間）** — 取り込んだファイルのリソースごとの計画作業と実績作業を、時間で `Name: 617.14` の形で、小数点以下 2 桁までで表示します。読み取り専用です。
- **残作業（時間）** — リソースごとの残作業を、時間で `Name: 6` または `Name: 26.67` の形で表示します。保存されている作業を表示します。保存されていない場合は、残存期間 × 単位数です。小数点の区切りには、カンマまたはピリオドを使えます。タスク種類が適用される、割り当てのあるタスクで編集できます。タスク種類が表示されているときだけ、列の選択ウィンドウに表示されます。黄色の ⚠ がセルに表示されると、保存されている作業が単位数 × 残存期間と異なることを示します。タスクパネルの *作業（残）* の ⚠ と同じです。

## 進捗

- **ステータス** — *未開始*、*進行中* または *完了*。サマリータスクを除き、編集できます。
- **進捗** — 割合を `40%` の形で表示します。0 から 100 までの数値で編集できます。ただし、サマリータスクでは編集できません。
- **実績開始日** — タスクが始まった日付。サマリータスクを除き、編集できます。
- **実績終了日** — タスクが終わった日付。サマリータスクを除き、編集できます。
- **実績期間** — 実績期間を数値で表示します。サマリータスクを除き、編集できます。
- **残存期間** — タスクの単位での残存期間。サマリータスクを除き、編集できます。
- **再開日** と **停止日** — MS Project または Primavera のファイルから取り込んだ、進行中タスクの再開と停止。読み取り専用です。

進捗の列は、アプリの進捗のルールに従います。状態日より後の実績日は拒否されます。サマリータスクでは、アプリは *サマリータスクの進捗はサブタスクから算出されるため、ここでは変更できません。* と表示します。

## 計算値

このカテゴリのすべての列は読み取り専用です。

- **山崩し遅延** — 山崩しによって、タスクが何稼働日遅れたか。山崩しが適用されていない場合は、ダッシュ（—）。
- **最早開始** と **最早終了** — 計算から得られる、最も早い日付。開始したタスクでは、最早開始と最早終了が *開始* と *終了* と異なる場合があります。計算プロファイル *Primavera P6* は、進行中または完了したタスクの最早開始を状態日に置きます。
- **最遅開始** と **最遅終了** — プロジェクトを遅らせずに、タスクを開始または終了できる最も遅い日付。
- **フリーフロート** — タスクが後続タスクを遅らせずに遅れられる稼働日数。
- **トータルフロート** — プロジェクト終了日を遅らせずに、タスクが遅れられる稼働日数。制約または期限を満たせない場合は、マイナスになります。
- **クリティカル** — タスクがクリティカルパス上にある場合は *はい*。
- **干渉フロート** — トータルフロートからフリーフロートを引いた値。
- **準クリティカル** — 準クリティカルのタスクでは *はい*。*準クリティカルとしてマーク* がオンの場合にだけ値が入ります（*プロジェクト設定*、ブロック *計算プロファイルとオプション*）。それ以外の場合は、ダッシュ（—）。
- **フロートパス** — フロートパスの番号。最もクリティカルなものが 1 です。*複数フロートパス* がオンの場合にだけ値が入ります。それ以外の場合は、ダッシュ（—）。
- **記録済み日付のソース** — アプリがファイルの日付を表示している間は、ファイルにすべてが含まれないタスクに *一部未記録* が表示されます。この列は、その表示のときだけ列の選択ウィンドウに表示されます。記録されていない軸では、遅い日付とフロートの列に *未記録* が表示されます。

詳しくは [クリティカルパスとフロート](docs://uitleg-kritiek-pad) を参照してください。

## ベースライン

プロジェクトのベースラインごとに列が追加されます。列名の前に、ベースラインの名前が付きます（`<baseline> — Scheduled start`）。これらの列は読み取り専用です。ベースラインに含まれないタスクには、ダッシュ（—）が表示されます。ツールチップには *このベースラインには存在しません* と表示されます。

- **予定開始日**、**予定終了日** と **期間** — ベースラインが記録した開始日、終了日、期間です。
- **開始差異** と **終了差異** — ベースラインと、表示されている開始日または終了日との間の稼働日数。プロジェクトのカレンダーで数えます。タスクが遅い場合はプラスです。
- **期間の差異** — 現在の期間から、ベースラインの期間を引いた値（稼働日単位）。

## カスタム

- **アクティビティコード** — アクティビティコードごとに 1 列。列名はコードの名前です。選んだ値のコードを表示します。編集できます。コードを入力するか、候補から選びます。不明なコードは拒否されます。同じコードが複数ある場合、アプリは一覧から選ぶように求めます。
- **カスタムフィールド** — カスタムフィールドごとに 1 列。列名はフィールドの名前です。入力は種類に合わせます。種類は、テキスト、数値、整数、コスト、日付、はい/いいえ です。編集できます。

これらの列は、そのコードまたはフィールドが属するプロジェクトのものです。詳しくは [コードとカスタムフィールド](docs://howto-codes-en-velden) を参照してください。

## 技術情報

このカテゴリのすべての列は読み取り専用です。これらの列は、アプリが保存しているデータを表示します。通常の列には表示されないデータです。たとえば、取り込みを確認するために使います。

- **タスク ID** — タスクの内部 ID。
- **親タスク ID** と **子タスク ID** — 親タスクと子タスクの ID。
- **リソース ID** — タスクにあるリソースの ID。
- **割り当て ID**、**割り当てタスク ID** と **割り当てリソース ID** — このタスクの割り当て、タスク、リソースの ID。
- **期間（分）** と **残存期間（分）** — 期間と残存期間を分で表示します。時間単位のタスクにだけ値が入ります。
- **山崩し遅延（分）** と **経過時間の山崩し遅延** — MS Project からの山崩し遅延を分で表示します。また、その遅延が時計の時間で数えられるかどうかを示します。
- **手動スケジュール** — タスクが手動スケジュールかどうか。
- **MS Project のタスク種類（取り込み）** と **作業時間主導** — MS Project が持っていた、タスク種類と作業時間主導のフラグ。
- **Primavera P6 の由来** — Primavera ファイルの元のフィールドを、`key: value` の形で表示します。
- **明示的なサマリータスク** — タスクが、サブタスクのない明示的なサマリーかどうか（Primavera ファイルから）。
- **時間分布の終了下限**、**時間分布の開始基準**、**時間分布の期間区間** と **時間分布の輪郭** — MS Project ファイルの時間の分布を、日付と件数で表示します。
- **アクティビティコードのデータ**、**カスタムフィールドのデータ** と **メモのデータ** — コードの割り当て、カスタムフィールド、メモの件数。
