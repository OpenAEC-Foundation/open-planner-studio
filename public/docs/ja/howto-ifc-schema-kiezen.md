# IFC スキーマの選び方

目的：統合したい建物モデルと同じ IFC スキーマで、スケジュールを保存します。

## 必要な場合

既定では、アプリはプロジェクトを IFC 4.3 ADD2 として保存します。これは、IfcOpenShell や Bonsai が作成するファイルでの IFC 4.3 の名前です。スケジュールと建物モデルを 1 つの 4D ファイルに統合したい場合（たとえば IfcOpenShell（ifcpatch）の *MergeProjects* レシピを使う場合）、両方のファイルは同じスキーマである必要があります。建物モデルが IFC4 ファイルの場合、IfcOpenShell は IFC 4.3 のスケジュールとの統合を拒否します。その場合は、ここで建物モデルのスキーマを選びます。

## 手順

1. *プロジェクト設定* を開きます：*設定 › プロジェクト › プロジェクト設定*、または *ファイル › プロジェクト設定*。
2. *保存時のIFCスキーマ* の欄で、建物モデルのスキーマを選びます。
3. *適用* をクリックします。プロジェクトは *未保存* になります。
4. *保存*（Ctrl+S）、または *名前を付けて保存* で保存します。

選択肢は 3 つです：

- *IFC 4.3 ADD2 (既定)* は、ファイルのヘッダーに `IFC4X3_ADD2` を書き込みます。
- *IFC 4.3* は `IFC4X3` を書き込みます。これは、古いバージョンのアプリが IFC 4.3 を書き込んでいた方法です。
- *IFC4* は `IFC4` を書き込みます。IFC4 の建物モデル向けです。

## 注意点と、アプリの動作

**統合は最後の手順にします。** 統合済みの 4D ファイル（建物モデルとスケジュール）を、再び保存するためにアプリで開かないでください。アプリに残るのはスケジュールだけです。壁など建物モデルのほかの部分は失われます。スキーマを保持していても同じです。スケジュールの変更は自分のファイルで行い、あとで再度統合してください。

**アプリは、開いたファイルのスキーマが異なる場合に、最初に確認します。** 例えば IFC4 ファイル、または古いバージョンのアプリの IFC 4.3 ファイルを開いても、アプリはファイルの種類を単純に変更しません。*保存* または *名前を付けて保存* を初めて使うと、アプリはまず、ファイルのスキーマを保持するか、IFC 4.3 ADD2 にするかを尋ねます。*IFC4 を保持*（または *IFC 4.3 を保持*）は、Enter キーで選ばれるボタンです。Esc キーまたは閉じるボタン（×）で確認を閉じると、アプリは何も保存しません。

**確認するのは、ファイルごとに 1 回だけです。** 選んだスキーマは、ファイル自体に保存されます。あとでファイルを開き直しても、アプリは再び尋ねません。*プロジェクト設定* でスキーマを自分で選び、*適用* をクリックした場合も、アプリは尋ねません。

**アプリが書き込めないスキーマ** （IFC2X3 など）のファイルも、アプリで開けます。初めて保存すると、確認でその旨が示されます。上の 3 つのスキーマのうちから 1 つを選んでください。

**自動保存とクラッシュ復元は、何も尋ねません。** これらはファイルのスキーマのまま書き込み、確認は、自分で初めて保存するときまで残します。アプリが書き込めないスキーマの場合、確認に答えるまで *自動保存* はファイルに書き込みません。

**新しいプロジェクトでは、確認は出ません。** 新しいプロジェクトと、XER、MPP、CSV などほかの形式のプロジェクトは、*IFC 4.3 ADD2 (既定)* で始まります。

**ファイルの内容は変わりません。** 3 つのスキーマは、アプリが書き込むスケジュールのデータを同じ方法で扱います。違うのは、ヘッダーの `FILE_SCHEMA` 行だけです。そのため、別のスキーマを選んでも何も失われません。

**IfcOpenShell や Bonsai の IFC 4.3 モデル** は、通常ヘッダーに `IFC4X3_ADD2` があります。これはアプリの既定と同じです。IfcOpenShell は、`IFC4X3` のスケジュールをそのモデルに統合しません。迷ったら、モデルファイルの先頭にある `FILE_SCHEMA` 行を確認してください。

**スキーマは *元に戻す* では変わりません。** スキーマはファイルに属します。保存先と同じです。そのため、*プロジェクト設定* での選択や、保存時の確認への答えは、*元に戻す* の操作ではありません。元に戻すには、*プロジェクト設定* で別のスキーマを選びます。そうすれば、編集を取り消したあとに *自動保存* が別のスキーマで黙って保存することはありません。
