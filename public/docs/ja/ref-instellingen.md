# 設定

**設定** ウィンドウには、アプリの設定が入っています。プロジェクトファイルとは無関係な、この端末に適用される好みの設定です。すべての変更は即座に適用・保存されます — OK ボタンはありません。計算されるスケジュールを変更するスケジューリングオプションは、代わりにプロジェクトに属します — [プロジェクト情報](docs://ref-projectgegevens) を参照してください。

## 開く — 3つの入口、同じ内容

- タイトルバーの **歯車**（⚙）。
- **設定**（リボンタブ）→ **プロジェクト** リボングループ → **設定**。
- **ファイル** → **設定**（Backstage）。

3つとも、まったく同じ設定を表示します。バージョンによっては3つまたは4つのタブに分かれています — 4つ目の **アプリケーション** タブは、最近になって最初のタブの後半部分が独立してできたものです — が、設定そのものとその働きはどちらの場合でも同一です。この記事では、それらを **一般**、**言語**、**タイムライン／ズーム** としてまとめて扱います。

## 一般タブ

**外観：**

- **テーマ** — **ダーク**、**ライト**、**ハイコントラスト**。カードをクリックして切り替えます。
- **フォント** — **標準**、**システム**、**セリフ**、**等幅**。インターフェースの書体を上書きします。ウェブアプリはシステムのフォント設定に自動的に従わないため、この項目と次の項目で自分で選びます。
- **文字サイズ** — 90%、100%、110%、125%。インターフェースのテキストとレイアウトをスケーリングします。
- **ドキュメント切り替えスタイル** — 開いているドキュメント間をどう切り替えるか：**横タブ**、**縦タブ**、**ピル**。
- **日付形式** — **dd-mm-yyyy**、**mm-dd-yyyy**、**yyyy-mm-dd**。表示のみに影響し、ファイルや計算には影響しません。
- **建設モード** — **建設モードを有効にする** は、*新規* プロジェクトの既定値を、建設向け（オランダの祝日を含む建設カレンダー、建設休暇、フェーズテンプレート）と、中立的で建設に依存しない構成との間で切り替えます。既存のプロジェクトはどちらの場合も影響を受けません。

**アプリケーション：**

- **バージョン** — アプリのバージョン番号（読み取り専用）と、アップデートウィンドウを開く **アップデートを確認** リンク。アップデートのインストールはデスクトップアプリでのみ機能します。Snap と AppImage のインストールは、それぞれ独自のチャンネルで更新されます。それとは別に、自動更新後に初めてアプリを開くと、「アップデートしました」という一度限りのダイアログが自動的に表示されます。バージョンの変化、インストーラーのサイズ差、前回のリリースからの日数、そして取得できた場合は GitHub のリリースノートが示されます。これは、ここにある手動の **アップデートを確認** リンクとは別の、自動的なタイミングで起こるものです。
- **プロジェクト情報...** — [プロジェクト情報](docs://ref-projectgegevens) ウィンドウへのショートカット。
- **ツアー** — **ツアーを開始** で紹介ツアーをもう一度再生します。同じ再開ボタンは、**表示** リボンタブの **ツアー** と、Backstage（**ファイル** → **ツアーを開始**）にもあります。
- **ベンチマーク** — 組み込みのベンチマークツールを開きます。この端末のスケジューリング／描画性能を測定します。
- **AI モード** — **AI モードを有効にする** で、MCP ブリッジを備えた **AI** リボンタブが表示され、AI アシスタントが Model Context Protocol 経由でスケジュールを操作できるようになります。オフにすると、実行中のブリッジは即座に停止します。**ブリッジを自動的に開始**（AI モードがオンのときのみ表示）は、AI タブを開かなくても、アプリの起動と同時にブリッジを有効にします — デスクトップアプリのみ。全体像については、アプリ内の AI アシスタントガイドを参照してください。
- **デバッグターミナル** — **デバッグターミナルを有効にする** で、トラブルシューティング用のログパネルを表示します。

## 言語タブ

- **言語** — アプリの表示言語。即座に適用されます。

## タイムライン／ズームタブ

- **時間計画** — **時間計画を有効にする** で時間軸と具体的な稼働時間帯を使えます。オフでは新しいタスクは日単位で始まり、既存の時間タスクの正確な値は保持されます。オンでは日タスクと時間タスクが共存できます。[カレンダーと時間計画](docs://gids-kalenders-uren) を参照してください。
- **期間の表示** — **自動（タスクごとの単位）**、**常に日**、**常に時間**。
- **中断時のタスクバー** — **分割しない**、**選択時に分割**、**常に分割**：非稼働日の周りでバーを視覚的に分割するかどうか。
- **タイムライン軸** — **稼働日のみ表示** はタイムラインを圧縮します。プロジェクトカレンダーの週末と祝日は省略されるため、その間のカレンダーがどうであれ、5稼働日のタスクはちょうど5列分の幅になります。
- **週の開始日** — **月曜日** または **日曜日**（タイムスケールの週のレイアウト）。
- **拡大時に15分単位を表示する** — 時間のタイムスケールに、追加の15分刻みの目盛りを表示します。
- **計算** — **自動計算** は、F5 を待たずに、スケジュールが古くなった時点で自動的に再計算します。
- **スクロールとズーム** — **モード**：
- **ズーム＋ドラッグ**（既定） — スクロールホイールでズーム（カーソル基点）。チャート背景をドラッグして表示をパンします。Shift＋スクロールホイールで行をスクロールします。Ctrl/⌘＋ドラッグで選択ボックスを描画します。
- **位置** — カーソルの位置がスクロール方向を決めます。**画面分割**（**左右**、**上下**、**右上隅**）付き。Ctrl＋スクロール＝ズーム、Shift＋スクロール＝水平。
- **キー** — チップをドラッグして、どの操作（**スクロール**、**Ctrl＋スクロール**、**Shift＋スクロール**）にどの機能（**垂直**、**水平**、**ズーム**）を割り当てるかを設定します。すでに使われているスロットにドロップすると、操作が入れ替わります。
