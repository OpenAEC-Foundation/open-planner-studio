# 通知と警告

アプリは次の四か所で状況を知らせます。下部のステータスバー、右側の列にある *警告* パネル、画面下部に短時間表示される通知、そしてリボンの下の帯です。この記事では、各場所に何が表示されるか、いつ表示されるか、そして何ができるかを説明します。スケジュールがクリティカルである理由や過剰割り当ての理由は[クリティカルパスとフロート](docs://uitleg-kritiek-pad)に記載されています。過剰割り当ての解消は[過剰割り当ての解消](docs://howto-overbezetting-oplossen)に、関係の作成は[関係の作成](docs://howto-relaties-leggen)に記載されています。

## 四つの違い

- **ステータスバー** — カウンターを表示する固定の行です。カウンターは前回の計算から得られ、次に計算するまで表示されたままです。
- **警告パネル** — カウンターの元になる一覧です。前回の計算で見つかったすべての項目を表示します。項目をクリックすると、そのタスク、関係、またはリソースへ移動します。前回の計算から導き出されるため、何も保存されません。
- **通知** — 直前の操作に関する短いメッセージです（保存の失敗、関係の拒否、インポートの読み込み完了など）。情報の通知は自動的に消えます。エラーの通知は閉じるまで残ります。通知は警告パネルには表示されません。
- **リボンの下の帯** — 文書またはモードの状態を示す、色付きの帯です。説明とボタンが一つあります。帯は、その状態が続くあいだ表示されます。*リボンの下の帯* を参照してください。

## ステータスバー

下部のバーには、左から右へ次の項目が表示されます：

- **タスク:** — リーフタスクの数です（サマリータスクは数えません）。
- **マイルストーン:** — マイルストーンの数です。
- **クリティカルパス: N 件のタスク、N 稼働日** — クリティカルタスクの数とプロジェクトの期間です。計算後にのみ表示されます。
- **終了:** — 計算によるプロジェクト終了日です。計算後にのみ表示されます。空のプロジェクトには終了日がありません。
- **N 件の期限超過**、**N 件の制約違反**、**N 件の順序外進捗の関係** および **N 件の過剰割り当てのリソース** — 警告マーク付きのボタンです。カウンターが 0 より大きく、計算がある場合にのみ表示されます。クリックすると *警告* パネルが開きます（ツールチップ: *警告パネルを開く（詳細とナビゲーション）*）。*IFC* または *レポート* タブを表示している場合、右側の列はそこにないため、アプリは同時に *ホーム* へ切り替わります。*過剰割り当てのリソース* のカウンターは、リソースと割り当ての変更後にも更新されます。ほかのカウンターは *計算* の後にのみ変わります。ステータスバーに表示されるのは四つのカウンターだけです。パネルに追加で表示される項目（切り詰められたリード、無視された関係、終了ドライバーのないハンモック、打ち切られた終了日、スケジュールエラー）は、ステータスバーには含まれません。
- **古くなっています — 再計算 (F5)** — 警告マーク付きの表示です（ツールチップ: *スケジュールが古くなっています — 再計算してください（F5）*）。スケジュールに影響する変更をして、まだ再計算していない場合にすぐ表示されます。*自動計算* がオンの場合は表示されません。ただし、計算でエラーが出た場合は表示されたままです。
- **選択: N 件のタスク** — 選択されているタスクの数です。選択がある場合にのみ表示されます。
- **スケール:** と **ズーム: Npx/日** — タイムラインのタイムスケールとズームレベルです。スケールはズームから決まります。
- **未保存** — ドキュメントに、ファイルに保存されていない変更がある間、表示されます。
- **AI** — 色付きの点と文字 AI です。AI モードがオンの場合にのみ表示されます。ツールチップには *AI ブリッジ:* と、*オフ*、*ポート N で稼働中*、*ポート N は使用中です*、または *エラー* が表示されます。クリックすると *AI* タブが開きます。
- **デバッグターミナル** — ターミナルのボタンです。デバッグターミナルが有効な場合にのみ表示されます。ボタンでターミナルを表示または非表示にします（*デバッグターミナルを表示* / *デバッグターミナルを非表示*）。

## 警告パネル

- **開く** — *計画 › スケジュール › 警告*、*表示 › パネル › 警告*、またはステータスバーのカウンターです。パネルは右側の列にあり、*プロパティ* とリソースドックの下に表示されます。折りたたまれた列は展開されます。既定では閉じており、セッションをまたいで記憶されません。ほかのパネルの下にある場合は、端をドラッグして高さを変えられます。その高さは記憶されます。右上の×ボタン（*警告を閉じる*）で閉じます。
- **見出し行** — *エラー N 件、警告 N 件*。まだ何も計算されていない場合は、*まだ計算されていません — 計算 (F5) を押してチェックを実行してください。* と表示されます。
- **計算** — 見出し行にあるボタンです。スケジュールが古い場合、またはまだ計算されていない場合に表示されます。リボンの *計算* と同じ動作をします。
- **見出し行の警告マーク** — スケジュールが古い場合に表示されます。ツールチップは *スケジュールが古くなっています — この一覧は前回の計算結果です。再計算 (F5) してください。* です。一覧は隠れず、古いとマークされるだけです。
- **空の一覧** — *警告はありません。スケジュールはすべてのチェックに合格しています。*
- **一行** — 上に場所（タスク、関係、リソース、またはプロジェクト）、その下に説明が表示されます。エラーには八角形の記号、警告には三角形の記号が付きます。タスクは `WBS名` と表示されます。関係は `先行タスク → 後続タスク (FS+2d)` と表示され、種類とラグも含まれます。場所をクリックすると、その場所へ移動します（ツールチップ: *移動先: …*）。下記も参照してください。アクティブなタスクの行（関係の場合は後続タスク）、またはヒストグラムで選んだリソースの行は強調表示されます。
- **順序** — エラーが先に表示されます。その後、下記の一覧の順に種類ごとに並びます。種類の中では、プロジェクト内の順です（関係の場合は後続タスクの順、リソースの場合はリソース一覧の順）。前回の計算後に削除されたタスク、関係、またはリソースは一覧から消えます。

### 警告の種類

- **スケジュールエラー** — *スケジュールを計算できませんでした: …* 理由は後ろに続きます。下記を参照してください。クリックすると、循環の場合はアプリが循環内のすべてのタスクを選択し、最初のタスクへ移動します。ほかのエラーでは移動先がないため、その行はボタンではありません。
- **期限超過** — *期限 {date} を超過 — 最早終了 {date}*。タスクには期限がありますが、計算結果がそれを満たしていません。クリックするとタスクへ移動します。修正するには、ロジックまたは期間を調整するか、期限を変更します。
- **制約違反** — *制約 {type and date} がロジックによって上書きされています（負のフロート）*。制約は、ロジックを壊さずに満たせません。フロートは負の値です。クリックするとタスクへ移動します。[制約](docs://uitleg-constraints)も参照してください。
- **順序外進捗** — *順序違反: 後続タスクの進捗が関係と矛盾しています*。後続タスクの進捗が関係の種類に合いません。たとえば、終了-開始の関係で、先行タスクがまだ終わっていないのに後続タスクがすでに進行中の場合です。クリックすると両方のタスクが選択され、後続タスクがアクティブになります。実績日または関係を確認してください。
- **リード切り詰め** — *リードがプロジェクト開始で切り詰められました — 関係が完全には守られていません*。関係のリード（負のラグ）が、プロジェクト開始日より前に及んでいます。クリックすると両方のタスクが選択されます。
- **関係の無視** — *関係を無視: 先行または後続が存在しないか、リーフタスクではありません*。計算はこの関係を使いません。クリックすると、まだ存在するタスクが選択されます。[関係](docs://uitleg-relaties)も参照してください。
- **終了ドライバーのないハンモック** — *終了ドライバーのないハンモック（FF/SF の先行なし）: 期間はゼロになります*。クリックするとタスクへ移動します。[ハンモックタスク](docs://howto-hammock)も参照してください。
- **終了日の打ち切り** — *終了日が打ち切られました: カレンダーにこのタスクの作業可能な期間がありません*。計算が、検索できる日数の上限に達しました。たとえば、カレンダーに非稼働日が非常に長く続いている場合です。クリックするとタスクへ移動します。[カレンダーと稼働日](docs://uitleg-kalenders)も参照してください。
- **過剰割り当て** — *N 日間過剰割り当て（first – last）*。すべての日が非稼働日の場合は *リソースはカレンダーによりこれらの日には作業しません* が追加されます。一部の日だけの場合は、*そのうち N 日はリソースがカレンダーにより作業しません* と表示されます。クリックすると、そのリソースに割り当てられたタスクが選択され、ヒストグラムがオンになり、そのリソースが選択されます。*テーブル*、*IFC*、または *レポート* から開いた場合は、アプリは *リソース* へ移動します。[リソースパネル](docs://ref-resourcepaneel)も参照してください。

### スケジュールエラーの理由

- *タスク間に循環依存があります: {path}* — 関係が循環を作っています。タスクはこのパスに含まれます。関係を一つ逆にするか、削除します。
- *カレンダーに稼働日が設定されていません* — カレンダーに稼働日を少なくとも一つ設定します。[カレンダーの時間帯](docs://ref-kalenders)を参照してください。
- *タスク「{task}」の日単位の期間が無効です* および *タスク「{task}」の時間単位の期間が無効です* — タスクの期間が有効な数値ではありません。
- *時間タスク「{task}」のカレンダーに有効な稼働時間がありません* — 時間単位のタスクが、稼働時間のないカレンダーにあります。
- *タスク「{task}」の開始日が無効です* — タスクの開始日が有効ではありません。

## リボンの下の帯

帯は、リボンのすぐ下、作業領域の上に表示されます。帯には文章が一つと、ボタンが一つあります。モード用の帯には × がありません。ほかの帯は × で閉じます。帯は次の五種類があります。

- **リンクモード** — *リンクモード: ガントチャートでバーから別のバーへドラッグすると関係を作成します。Esc で終了します。* Gantt でリンクモードがオンの間は、帯が表示されたままです。ボタン: *停止*。[関係の作成](docs://howto-relaties-leggen)を参照してください。
- **分割モード** — *中断が始まる日のバーをクリックし、右へドラッグして長さを決めます。Esc で終了します。* *タスクを分割* がオンの間は、帯が表示されたままです。ボタン: *停止*。
- **ファイル内の時間計画** — *このファイルには時間単位の計画が含まれています。* 開いたファイルに時間計画が含まれていて、*時間計画を有効にする* がオフのときに表示されます。ボタン: *時間計画を有効にする*。[時間計画をオンにする](docs://howto-urenplanning-aanzetten)を参照してください。
- **構造がロックされている** — タスクテーブルがフィルター、グループ化、または並べ替えされているため、インデントまたはインデント解除が拒否されると表示されます。文章は *フィルター/グループ化/並べ替え中は使用できません* です。ボタン: *クリア*。これでフィルター、グループ化、並べ替えが解除されます。
- **記録された日付** — 再計算によって日付が移動したファイルを開いた後に表示されます: *再計算により、M 件中 N 件のタスクがファイル内の日付から移動しました。* ボタン: *記録された日付を表示*。表示モードがオンの間は、次の文と *再計算* ボタンが表示されます: *ファイルに記録された日付を表示しています …*。[記録された日付](docs://uitleg-datums-zoals-opgeslagen)を参照してください。

## 通知

通知は画面の下部に表示されます。表、バックステージ、プレゼンテーションモードでも表示されます。通知は *エラー* または *情報* です。エラーは赤く表示され、× をクリックするまで残ります。情報は 5 秒後に消えます（説明が多い通知は、もっと長く表示されます）。通知の一覧が変わると、この時間は最初から数え直されます。各通知の右上には × があります（ツールチップ *通知を閉じる*）。これをクリックすると、通知はすぐに閉じます。通知の文章をクリックしても、何も起こりません。拒否は、必ずエラーです。拒否とは、行った操作をアプリが実行しなかった、という通知です。たとえば、拒否された関係、期間、開始日、マイルストーンなどです。少しの間、画面から目を離しても見逃しません。拒否の通知は、Ctrl+Z または Ctrl+Y を押したとき、および別の文書に移動したときに消えます。その時点で、通知はもう正しくないためです。*保存できませんでした* などの別のエラーは残ります。同じ操作の残りが成功していた場合も同じです（たとえば、複数のセルに貼り付けたとき）。複数のタスクが関係する場合は、その下の行で、変更されなかったタスクを示します。たとえば *変更されていません: Foundation, Masonry。* です。5 件を超えると、最後は *ほか N 件のタスク* で終わります。同じ拒否が繰り返されると、カウンター付きの 1 行にまとめられます。同時に表示されるのは最大 3 件です。4 件目が来ると、最も古い情報が先に消えます。情報がなければ、最も古い拒否が消えます。次に、最も古い開いたときの通知（× をクリックするまで残るもの）が消えます。最後に、最も古いエラーが消えます。つまり、情報や拒否が *保存できませんでした* などの別のエラーを押し出すことは、決してありません。通知の一覧は、開いているダイアログのボタンや、固定されたアクションバーから離れて表示されます。ファイルを開くときに、アプリがデータを補完、置換、修復、または除外した場合も、ファイルを開いたときの通知は × をクリックするまで残ります。これには次の内容に関する行が含まれます。パーサーやカレンダーの検出事項、数値形式の問題、列挙値のフォールバック、安全なフォールバックを使った P6 計画設定、保護的なベースラインのフォールバック、無視したベースライン参照、計画された開始日がないため開始日が設定されたタスク、取り込まれなかったプロジェクト間の関係（P6 XML）、プロジェクトに属さないタスク、取り込まれなかった MS Project ファイルの内容（MS Project XML と `.mpp`）、使用できない XER ソースアーカイブ、そして計算されない重複 ID と関係についての通知です。このような変更がなく、情報だけが含まれる場合（プロジェクト数、ドキュメント数、テキストエンコーディングなど）は、通知は 5 秒後に消えます。

- **カウンター ×N** — 固定のキーを持つ通知は、繰り返しを 1 行にまとめ、カウンターを付けます。たとえば、何度も戻ってくる保存エラーや、繰り返した拒否された関係などです。すべての通知がこれを行うわけではありません。
- **詳細を見る** — 一部の通知には、*詳細を見る* リンク、または独自のトピック（たとえば *タスク種類の説明*）があります。これらは、バックステージ › ヘルプのガイドへのリンクです。
- **操作ボタン** — 計算プロファイルの通知には、*計算プロファイルを開く* ボタンがあります。これでプロジェクト設定を開けます。

以下の一覧は、通知の一部をトピックごとにまとめたものです。別の記載がない場合、その通知は情報です。

### 保存、開く、復元

- **保存に失敗** （エラー） — *保存できませんでした* と、その下に理由を表示します。保存、名前を付けて保存、およびレポートのエクスポート時に表示されます。
- **ダウンロードとして保存** （情報） — *ダウンロードとして保存: '{name}' がダウンロードフォルダーに保存されました。…* *名前を付けて保存* およびエクスポート時に表示されます。環境によってアプリが選んだ場所へ直接書き込めない場合です。続けて 2 回ダウンロードした場合は、1 つにまとめられます。
- **ダウンロードとして保存（説明）** （情報、15 秒） — *ダウンロードとして保存: '{name}' がダウンロードフォルダーにあります。このブラウザーでは、アプリが独自の場所に書き込めません。…* ダウンロードによってのみ保存するブラウザーで *保存* を使ったときに表示されます。セッションごとに 1 回で、ファイルの説明へのリンクが付きます。
- **ブラウザーが書き戻さない** （情報、15 秒） — *このブラウザーでは、アプリが '{name}' に書き戻せません。…* ファイルのあるプロジェクトを *保存* したとき、ブラウザーが保存先を再び尋ねる必要がある場合に表示されます。セッションごとに 1 回で、ファイルの説明へのリンクが付きます。
- **自動保存に失敗** （エラー） — *自動保存に失敗しました* と理由を表示します。ファイルへの自動保存とクラッシュ復元に当てはまります。
- **ライブラリを保存できない** （エラー） — *ライブラリを保存できませんでした*。リソースライブラリを保存するときに表示されます。
- **ファイルを開けない** （エラー） — *ファイルを開けませんでした* と理由を表示します。たとえば、最近使ったファイルや取り込んだファイルを開くときです。
- **古いまたは保護された .mpp** （エラー） — *この .mpp ファイルは古い形式です（Project 2007 以前）…* または *この .mpp ファイルはパスワードで保護されています…* です。どちらの場合も、MS Project で XML としてエクスポートし、そのファイルを開くように案内します。
- **無効な XER ファイル** （エラー） — *XER…* で始まる文のいずれか、たとえば *これは有効または対応済みの XER ファイルではありません。* や *XER ファイルに重複したテーブルがあります。* を、理由を付け加えて表示します。
- **IFC を読み込めない** （エラー） — *IFC を読み込めませんでした* と理由を、IFC ビューに表示します。
- **復元** （エラー） — *復元したファイルを読み込めませんでした*、*復元に失敗しました*、*N 件の復旧ファイルを読み込めなかったため、スキップされました。* を表示します。予期しない終了の後に復元するときに表示されます。
- **ブランチをテンプレートとして保存** （情報） — *ブランチをテンプレート「{name}」として保存しました*。
- **拡張機能からのメッセージ** （情報。拡張機能がエラーを報告した場合はエラー） — *拡張機能 {name}: {message}*。拡張機能は 10 秒間に最大 3 件まで新しいメッセージを表示できます。そのため、通知の一覧がいっぱいになりません。拡張機能のガイドのステップが失敗した場合は、*拡張機能 {name} のステップでエラーが発生しました。ガイドは続行します。* と表示されます。拡張機能のプロジェクトファイルを開けない場合は、*拡張機能 {name} のプロジェクトファイル {file} を開けませんでした。* と表示されます。どちらもエラーです。
- **途中で変更が入った** （エラー） — *AI アシスタントまたは拡張機能による変更が途中で入りました。…* タスクダイアログをキャンセルしたときに表示されます。その間に AI または拡張機能が何かを変更していた場合です。その変更の前のタスクの編集は元に戻されず、*元に戻す* の下に通常の操作として残ります。

### 計算

- **スケジュールを計算できない** （エラー） — *スケジュールを計算できませんでした* と、その下に理由を表示します（*スケジュールエラーの理由* を参照）。*計算* 時、文書を切り替えたとき、およびファイルを開いたときに表示されます。
- **状態日を今日に設定** （情報） — *状態日を今日（{date}）に設定しました。* 状態日のないプロジェクトで進捗を入力したときに表示されます。アプリは状態日までの進捗を計算するため、状態日がないと進捗を処理できません。別の日付は、*計画 › ベースラインと進捗 › ステータス日付* で設定します。*詳細を見る* のリンクから [進捗、状態日、ベースライン](docs://uitleg-voortgang) を開けます。
- **期間が完了済みの作業より短い** （エラー） — 「{name}」はすでに {N}% 完了しています。完了済みの作業より短い期間にはできません。期間は変更されていません。

### 関係と階層

- **関係の拒否** （エラー） — *この関係はすでに存在します*、*タスクとその自身の(祖先)サマリータスクとの間の関係は許可されません。*、または *この関係はスケジュールに循環を発生させるため（{cycle}）、作成されませんでした。* を表示します。循環にはタスク名が示されるため、先にどの関係を削除または反転すればよいかがわかります。
- **移動の拒否** （エラー） — *この移動はスケジュールに循環を発生させます（{cycle}）。サマリータスクの関係はそのサブタスクにも適用されます。何も移動されませんでした。*
- **移動後に関係が計算から外れる** （情報） — *移動後、N 件の関係がタスクをその自身の上位サマリータスクに結び付けています。これらは計算に含まれなくなりました。*
- **挿入時に関係をスキップ** （エラー） — *N 件の関係は作成されませんでした: 無効なリンク…* を、ブランチを貼り付けたとき、または挿入したときに表示します。その下の行に、どの関係かを示します。たとえば *作成されていません: Foundation → Masonry。* です。
- **取り込み後に計算されない関係** （情報） — *N 件の関係が計算に含められませんでした。先行タスク列と後続タスク列を確認してください。*
- **取り込み後の重複 ID** （情報） — *このファイル内で重複 ID を持つオブジェクト: N 件。それらには独自の ID が割り当てられました…*

### タスクの編集

- **開始日を制約として記録** （情報） — 「{name}」は {date} より前に開始しません (SNET)。先行タスクがあるタスクの開始日を変更したときに表示されます。先行タスクが開始日を決めるため、アプリは入力した日付を *指定日以降に開始 (SNET)* の制約として記録します。再計算（F5）の後、タスクはその日付より前には開始しません。タスクにすでにそのような制約があった場合は、「{name}」は今後 {date} より前に開始しません (SNET)。と表示されます。複数のタスクを同時に変更した場合は、件数で表示されます。*詳細を見る* のリンクから [制約と期限](docs://uitleg-constraints) を開けます。
- **開始日が適用されない** （エラー） — *'{name}' の新しい開始日は適用されませんでした。タスクには先行タスクと制約 {type} {date} があり、それらが開始日を決めています。開始日を移動するには、その制約を変更してください。*
- **マイルストーンの拒否** （エラー） — *リソースの割り当てがあるタスク N 件はマイルストーンにできません。先に割り当てを削除してください。* または *サブタスクを持つサマリータスク N 件はマイルストーンにできません。* タスクダイアログ、プロパティパネル、コンテキストメニュー、表で変換したときに表示されます。
- **割り当てをサブタスクに移動** （情報） — *割り当てをサブタスク「{child}」に移動しました。* または *N 件の割り当てをサブタスク「{child}」に移動しました。* 割り当てのあるタスクに、拡張機能がサブタスクを与えたときに表示されます。そのタスクはサマリータスクになり、サマリータスク自体は割り当てを持てません。そのため、割り当ては最初の新しいサブタスクに移動します。アプリ自体では、*タスクがサマリータスクになります* ウィンドウでこれを選択します。その場合、このメッセージは表示されません。*詳細を見る* のリンクから [構造の調整](docs://howto-structuur-aanpassen) を開けます。
- **マイルストーンの印を削除** （情報） — *N 件のタスクがマイルストーンではなくなりました。* マイルストーンにサブタスクが追加されたときに表示されます。マイルストーンは、サブタスクのない時点です。サブタスクがあると、サマリータスクになります。*詳細を見る* のリンクから [構造の調整](docs://howto-structuur-aanpassen) を開けます。
- **質問が古くなった** （エラー） — *タスクまたは割り当てが、質問が開いている間に変更されました。何も変更されていません。もう一度お試しください。* *タスクがサマリータスクになります* ウィンドウで選択したときに、質問がもう合わない場合に表示されます。
- **サマリータスクの拒否** （エラー） — *'{phase}' はサマリータスクになれません: …* と理由を表示し、*何も変更されていません。* と続きます。割り当てのあるタスクに拡張機能がサブタスクを与え、割り当てを最初の新しいサブタスクに移せない場合に表示されます。アプリ自体では、このメッセージは表示されません。そこでは *タスクがサマリータスクになります* ウィンドウが何をするかを尋ね、*移動* は無効になります。
- **貼り付け時にセルをスキップ** （エラー） — *N 件の読み取り専用セルをスキップしました（例：自動採番の WBS コードや計算列など）。*
- **貼り付け時に参照をクリア** （情報） — *N 件の参照はこの文書に存在しなかったため、クリアしました（元の文書のタスクカレンダー、カスタムの作業区分、アクティビティコード、カスタムフィールド）。*
- **構造がロックされている** （エラー、リボンの下の赤い帯） — *フィルター/グループ化/並べ替え中は使用できません* と *クリア* ボタンを表示します。一覧がフィルター、グループ化、または並べ替えされている間に、インデント、インデント解除、ドラッグを行ったとき、および *上に挿入* と *下に挿入*（右クリックメニューまたはショートカット）を使ったときに表示されます。赤い帯は、× をクリックするか、Ctrl+Z または Ctrl+Y を使うか、別の文書に移動するまで残ります。[構造の調整](docs://howto-structuur-aanpassen) を参照してください。
- **タスクが末尾に追加された** （エラー） — *新しいタスクは末尾に追加されました。フィルター、グループ化、並べ替えの間は、アプリは選択中の項目の下に配置できません。* *クリア* ボタン付きで表示されます。タスクが選択されていて、一覧がフィルター、グループ化、または並べ替えされている状態で、*タスク* と *マイルストーン ▾* を使ったときに表示されます。タスクは追加されますが、一番下に配置されます。*クリア* を押すと、フィルター、グループ化、並べ替えが解除され、通知が閉じます。[タスクとマイルストーンの追加](docs://howto-taken-en-mijlpalen-toevoegen) を参照してください。
- **タスク種類が期間を調整** （情報） — *カレンダー変更後、タスク種類により N 件のタスクの期間が調整されました（作業は変わらず、1日の時間数が変わりました）。* *タスク種類の説明* のリンク付きで表示されます。

### Primavera P6 XML

- **P6 XML ファイルを開いた** （情報） — *P6 XML ファイルを開きました: N 件のプロジェクトドキュメント。* P6 XML ファイルを開いた後に表示されます。
- **取り込まれなかった** （消えません） — *プロジェクト間の N 件の関係は、関係として取り込まれませんでした。* と *プロジェクトに属さない N 件のタスクは読み込まれませんでした。* スケジュールが完全かどうかを確認してください。
- **空または使用できない** （エラー） — 何も開きません。理由は 3 つあります。*このファイルには、アプリが読み取れるタスクがありません。*、*タスクに ObjectId がありません。…*、*このファイルは XER の列名を使っています … .xer ファイル自体を開いてください。*

### Primavera (XER)

- **XER ファイルを開いた** （情報） — *XER ファイルを開きました: プロジェクト文書 N 件。* ファイルごとに 1 件の通知です。ファイルが複数のプロジェクトを開く場合でも同じです。*詳細を見る* のリンクと、その下に詳細行が表示されます。常に *検出したプロジェクト: N* を表示します。数が 0 より大きい場合のみ、*空のプロジェクトをスキップ: N*、*除外したベースラインプロジェクト: N*、*具体化したベースライン: N*、*無効なベースライン参照を無視: N*、*保護的なベースラインのフォールバックを使用しました。*、*外部関係を保持: N* を表示します。UTF-8 以外のエンコーディングの場合のみ、*選択したテキストエンコーディング: {encoding}。* を表示します。さらに、数が 0 より大きい場合は、*パーサーの検出事項: N*、*カレンダーの検出事項: N*、*数値形式の問題: N*、*列挙値のフォールバック: N*、*安全なフォールバックを使った P6 計画設定: N* を表示します。
- **Primavera が記録した日付** （同じ通知の詳細行） — *Primavera が記録した日付をそのまま表示しているタスク: N 件（再計算していません）* N は、ファイルに日付が記録されているすべてのタスクを数えます。違いがないタスクも含みます。モードがオンにならなかった場合は、*N 件のタスクはファイルの日付と異なります。表示できます。* と表示されます。
- **XER ソースアーカイブが使用できない** （情報） — *このファイルの XER ソースアーカイブは使用できないため除外しました。プロジェクト自体はすべて開かれています。* 理由（たとえば *理由: チェックサムがソースバイトと一致しません。アーカイブが破損しています。*）と、その結果（*スケジュール、計算プロファイル、および IFC のすべてのプロジェクトデータは完全です。…*）も表示されます。以前に保存された XER ソースアーカイブを使えない IFC ファイルを開いたときに表示されます。また、予期しない終了の後に復元するときも、復元ストレージがソースアーカイブを保持していなければ表示されます。
- **エクスポートで XER 情報が失われる** （情報） — *{format} へのエクスポートでは XER のソース情報が失われます。* XER ファイルにしか存在しないデータを持つプロジェクトを、IFC 以外の形式へ正常にエクスポートした後に表示されます。*詳細を見る* のリンク付きです。

### 取り込み、エクスポート、計算プロファイル

- **ファイルどおりの日付** （情報） — *ファイルに記録された日付をそのまま表示しているタスク: N 件（再計算していません）*（N は、記録された日付を持つすべてのタスクを数えます）、または *N 件のタスクはファイルの日付と異なります。表示できます。* 記録された日付を持つファイルを開いたときに表示されます。
- **作業とタスク種類が表示される** （情報） — *このファイルには保存された作業またはタスク種類が含まれています。このプロジェクトでは、タスク種類と残作業が表示されます。*
- **MS Project のスケジュールを読み込んだ** （情報） — *この MS Project ファイルには、分割・山崩し・リソース主導で計画されたタスクが N 件含まれています。そのまま読み込まれ、表示されます。*
- **休憩がエクスポートされない** （情報） — *中断のあるタスク N 件は中断なしでエクスポートされました。MS Project/P6 では中断を作業配分としてしか扱えません。* MS Project または Primavera へエクスポートするときに表示されます。
- **プロジェクト開始日の移動** （情報） — *N 件のタスクがプロジェクト開始日に合わせて移動しました。* プロジェクト開始日を後の日付に設定したときに表示されます。先行タスクがなく、新しい開始日より前になる制約もないタスクだけが、その日付へ移動します。*詳細を見る* のリンクから [新規プロジェクトとプロジェクト設定](docs://ref-projectinfo) を開けます。
- **日付ウィンドウが制御しなくなった** （情報） — *この編集の後、MS Project の日付ウィンドウは N 件のタスクを制御しなくなりました。…* 文書ごとに 1 回表示されます。
- **山崩し遅延を丸めた** （情報） — *山崩しは、MS Project の分単位の山崩し遅延（タスク N 件分）を整数の稼働日に丸めます。* 文書ごとに 1 回表示されます。
- **計算プロファイルを適用** （情報） — *このプロジェクトは {profile} として計算されます。変更は ファイル → プロジェクト情報 → 計算プロファイルとオプション で行えます。* *計算プロファイルを開く* ボタン付きで表示されます。プロファイルを適用した後、必要な場合は *適用後に N 件のタスクが移動しました。* が続きます。
