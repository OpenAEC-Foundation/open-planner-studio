# 進捗の更新

目標: 作業の実際の状態をスケジュールに反映し、スケジュールを再計算することです。どのタスクが完了したか、どのタスクが進行中か、残りの作業がどれだけあるかを反映します。

## この作業が必要なとき

進捗は決まったタイミングで更新します。たとえば、現場監督が状況を報告する毎週金曜日に更新します。こうすると、スケジュールは実際に起きたことを把握し、状態日から残作業を計算します。アプリがこの方法を使う理由は、[進捗、状態日、ベースライン](docs://uitleg-voortgang)で説明しています。

## 手順

### 1. 状態日を設定する

状態日は、状況を確認する日です。進捗を入力する前に設定します。

1. *計画 › ベースラインと進捗 › 状態日* に移動します。
2. 日、月、年の三つの欄に日付を入力します（お使いの日付表記の順番で）。たとえば 28、06、2027 と入力して Enter を押します。アプリは自動で次の欄に移動します。
3. プロジェクトカレンダーに稼働時間の帯がありますか（*カレンダー* ウィンドウの *稼働時間*）？ その場合、アプリは時間単位で計算し、右側に時刻欄が表示されます。たとえば 17:00 です。別の時刻（たとえば 12:00）を入力して Enter を押します。時刻欄を空にすると、日付だけが残ります。日付だけを変更すると、時刻はそのままです。時刻の表記は、お使いの表記（24時間または12時間）に従います。稼働時間の帯がない場合、アプリは日単位で計算します。その場合、時刻欄はなく、状態日の線は日の始まりに置かれます。
4. 欄の横にある小さな×印を押すと、状態日を空にします。

金曜日の稼働時間の終了後に状況を確認する場合は、状態日を次の稼働日である月曜日に設定します。アプリは、状態日の開始時点から残作業を計画します。

状態日がまだないときに進捗を入力すると、アプリは状態日を今日に設定し、次のメッセージを表示します。 *状態日を今日（…）に設定しました。* そのため、先に自分で設定するほうがよいです。

### 2. 進捗を入力する

状況に合う方法を選びます。どの方法でも結果は同じです。

**プロパティパネルで一つのタスクを入力します。** 一つのタスクだけを更新するときに便利です。

1. タスクをクリックします。*プロパティ* パネルが表示されていない場合は、*表示 › パネル › プロパティ* で表示します。
2. *進捗（%）* のスライダーを、完了している割合までドラッグします。
3. 必要な場合は、状態日と同じ方法で *実績開始日* と *実績終了日* を入力します。*残り* 欄はアプリが自動で計算するため、ここでは変更できません。

マイルストーンには、*実績日* という欄が一つだけあります。

**メニューで割合を選択します。** 状態をすばやく入力するときに便利です。

1. Gantt のタスクバーを右クリックします。
2. *進捗* を選び、次に 0%、25%、50%、75% または 100% を選びます。

**タスクテーブルで複数のタスクを入力します。** 一覧全体を更新するときに便利です。

1. タスクテーブルの見出しの右にある **+** をクリックします（*列を追加*）。カテゴリ *進捗* を開き、列 *実績開始日*、*実績終了日*、*残り* と *状態* を追加します。列 *進捗* は、*テーブル* タブにすでにあります。
2. セルをダブルクリックし、値を入力して Enter を押します。割合は `50` または `50%` と入力します。日付は `25-06-2027` と入力します。残存期間は `1` と入力します。
3. *状態* は、ダブルクリックしてから Enter を押し、*未開始*、*進行中* または *完了* を選びます。

残存期間を入力すると、アプリは割合を逆算します。たとえば期間 2 稼働日のタスクで残りが 1 の場合、割合は 50 になります。残りが 0 の場合、タスクは完了します。列 *実績期間*（カテゴリ *進捗* にもあります）では、計算の方向が逆になります。実績期間に、すでに行った作業量を入力します。アプリが割合を計算します。期間 4 稼働日のタスクで実績期間が 1 の場合、割合は 25% になります。*状態* で *未開始* を選ぶと、割合は 0 になり、実績日は消えます。

**一つのタスクのすべての項目を、タスクの編集ウィンドウで入力します。** タスクを右クリックし、*編集...* を選びます。進捗の欄もここにあります。これらは *保存* をクリックして初めて適用されます。

**スプレッドシートから多くのタスクを一度に入力します。** [スプレッドシートからの進捗の取り込み](docs://howto-voortgang-importeren)を参照してください。

### 3. スケジュールを再計算する

進捗または状態日を変更するたびに、スケジュールは古くなります。ステータスバーに *古くなっています — 再計算してください（F5）* と表示されます。**計算**（F5）を押します。たとえば *計画 › スケジュール › 計算* を選びます。*自動計算* がオンになっている場合（*設定 › プロジェクト › アプリ設定*、タブ *計画*）、アプリが自動で計算します。

## 結果を確認する

- 状態日には、Gantt に破線が表示され、ヘッダーに日付が表示されます。進行中のタスクでは、線がバー内の完了率まで膨らみます。これらの表示は *表示 › ベースラインと進捗 › 進捗ライン* と *状態日ライン* で、オンまたはオフにできます。
- バーの完了した部分は灰色になります。残りの部分は元の色のままです。完全に完了したタスクは、バー全体が灰色になります。名前の前にチェックマークが付き、フロートの表示はありません。フェーズのバーも、算出された完了率まで灰色になります。そのため、フェーズごとに作業がどこまで進んでいるかがわかります。あるタスクの先行タスクまたは後続タスクを表示する場合、それらのバーは、完了していても強調色のままです。
- 完了したタスクは、決して赤くなりません。状態日がある場合、完了したタスクはクリティカルではありません。
- フェーズには算出された完了率が表示され、スケジュールの終了日が変わっている場合があります。
- ベースラインを保存した場合、各バーの下に元のスケジュールが表示されます。レポートの種類 *差異* では差異が表示されます。

## 注意点とアプリの動作

**状態日より後の日付。** アプリは、状態日より後の実績開始日または実績終了日を受け付けません。パネルでは欄の下に *実績日は状態日より後にできません* と表示されます。タスクテーブルでは、セルに *実績日がステータス日より後です。* と表示されます。先に状態日を後の日付に設定するか、日付を修正してください。

**状態日より後に開始するはずのタスク。** スケジュール上まだ開始していないはずのタスクに進捗を入力すると、ウィンドウ *実績開始日を入力* が開きます。このウィンドウでは、タスクが実際にいつ開始したかを尋ねます。候補は状態日です。*進捗を適用* で記録し、*キャンセル* では何も変わりません。

**日付なしで 100%。** 実績終了日を入力せずにタスクを 100% にすると、タスクが以前に終わっていても、実績終了日は状態日になります。その場合は、実績終了日を自分で入力してください。

**100% 未満の割合。** 完了したタスクを 100% 未満に戻すと、実績終了日は削除されます。実績終了日だけを消すと、割合は 0 になり、タスクは *進行中* のままです。タスクを再び未開始として扱いたい場合は、実績開始日も消すか、タスクテーブルの *状態* で *未開始* を選びます。

**進行中のタスクの期間を変更する場合。** 完了済みの作業はそのまま残り、割合が調整されます。5 稼働日のタスクが 60% のときに、期間を 10 稼働日に設定すると、割合は 30% になります。アプリは、完了済みの作業より短い期間を受け付けません。*「Build inner cavity leaf」はすでに 60% 完了しています。完了済みの作業より短い期間にはできません。期間は変更されていません。* タスクテーブルでは、セルに *この期間は完了済みの作業より短いです。* と表示されます。

**残存期間は丸められます。** アプリは残存期間を整数の稼働日に丸めます。期間 2 稼働日のタスクでは、50% と 75% のどちらでも残りは 1 稼働日になります。

**フェーズ。** フェーズには独自の進捗がありません。パネルには *サブタスクから算出されます。進捗はサブタスクで変更してください。計算（F5）後にサマリータスクへ反映されます。* と表示されます。タスクテーブルでは、セルに *サマリータスクの進捗はサブタスクから算出されるため、ここでは変更できません。* と表示されます。

**状態日を後ろに移動する。** 進行中のタスクの残作業は、新しい状態日から始まります。まだ開始していない作業は、その日付より前には置けません。そのため、状態日は進捗の更新と合わせてのみ変更してください。進捗を入力せずに状態日だけを設定すると、まだ開始していない作業はすべてその日付に移動します（Microsoft Project のプロファイルを除く）。

**間違えた場合。** 進捗の変更は、それぞれ Ctrl+Z 一回で元に戻せます。
