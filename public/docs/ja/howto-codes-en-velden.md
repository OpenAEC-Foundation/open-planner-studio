# コードとカスタムフィールド

目標：タスクに、独自の分類（*場所* などのアクティビティコード）と、独自のフィールド（*施工業者* など）を追加します。

## 必要な場合

タスクの固定データ（名前、期間、関係、…）のほかに、独自のデータを追加できます。タスクを北棟と南棟で分類したい場合、分野で分類したい場合、またはタスクをどの施工業者が担当するかを記録したい場合は、自分で記録します。方法は二つあります。その違いが重要です。

**アクティビティコード** は、決まった選択リストを持つ分類です。**コードタイプ**（例：*場所*）を作成し、その中に**値**（北棟は *N*、南棟は *Z*）を追加します。タスクは、コードタイプごとに最大一つの値を持てます。

**カスタムフィールド**（ウィンドウ内の *カスタムフィールド* の下）は、型を持つ自由入力欄です。型は *テキスト*、*数値*、*整数*、*コスト*、*日付*、*はい/いいえ* のいずれかです。フィールドには、タスクごとに異なる値を入力できます。

## 手順

### コードとフィールドの定義

1. *計画 › 構造 › コードとフィールド* を選択します。
2. **コードタイプの作成。** *新しいコードタイプ（例：場所）* の下に名前を入力し、Enter キーを押します。または *コードタイプを追加* をクリックします。
3. **値の追加。** コードタイプの下で *値を追加* をクリックします。アプリは仮のコード（例：*V1*）を追加します。*コード* の欄で、短いコードに変更します（入力する形で、例：*N*）。必要な場合は *説明* を入力します（例：*北棟*）。*色* を選択します。欄から離れるか Enter キーを押すと、変更が有効になります。
4. **カスタムフィールドの作成。** *新しいフィールド（例：施工業者）* の下に名前を入力し、型を選択して *フィールドを追加* をクリックします（または Enter キーを押します）。

このウィンドウには OK ボタンがありません。すべての変更がすぐに適用されます。後から変更できるのは、フィールドの名前だけです。型は変更できません。別の型が必要な場合は、新しいフィールドを作成してください。

### タスクにコードまたはフィールドを入力する

入力できる場所は 2 つあります。

- ***プロパティ*** パネル（または F2 キーで開くウィンドウ）。下部に *コードとフィールド* ブロックがあります。コードタイプごとに選択リスト、フィールドごとに入力欄があります。このブロックは、コードタイプまたはフィールドが 一つ以上ある場合にだけ表示されます。
- **タスクテーブルの列として。** テーブルヘッダーの右側にある **+**（*列を追加*）をクリックし、*カスタム* の下で、コードタイプまたはフィールドを選択します。コードタイプのセルには、コード（例：`N`）を入力するか、一覧から選びます。存在しないコードを入力すると、*このアクティビティコードから値を選んでください。* と表示されます。

### 使い方

コードタイプまたはカスタムフィールドで、フィルター、グループ化、並べ替えができます。これはレイアウトで設定します：*表示 › レイアウト › 新規レイアウト*。ウィンドウで、保存したい部分にチェックを入れます。*保存* を選ぶと、*表示 › レイアウト* に、後で再びクリックできるボタンが表示されます。*保存せずに適用* を選ぶと、そのレイアウトは今だけ画面に表示されます。グループ化すると、値のないタスクは *（なし）* の下に入ります。

バーの色を設定するには、*表示 › ベースラインと進捗 › バーの色* を選び、次に *カテゴリ別* とコードタイプを選びます。各バーは、その値の *色* になります。

## 注意点とアプリの動作

**削除すると、タスク上の値も消えます。** コードタイプ、値、またはフィールドをごみ箱で削除すると、アプリは確認を求めません。すべてのタスクに設定された値も一緒に消えます。そのコードタイプまたはフィールドによるグループ化や並べ替えも無効になります。*元に戻す*（Ctrl+Z。先にウィンドウを閉じてください）を使うと、コードタイプ、値、フィールド、入力済みの値が戻ります。ただし、グループ化と並べ替えは戻りません。それらは、もう一度設定してください。

**同じコードを持つ二つの値。** *値を追加* は、既存の値の数から連番を振ります。値を一つ削除して一つ追加すると、同じコードが二回現れることがあります。そのコードを列のセルに入力すると、アプリは入力を拒否し、*このアクティビティコードの値は複数あります。一覧から選んでください。* と表示します。各値に、それぞれ別のコードを付けてください。

**テンプレートには、コードとフィールドは含まれません。** 詳しくは [WBS テンプレートの保存と挿入](docs://howto-wbs-sjablonen) を参照してください。タスクを別のドキュメントに貼り付けると、アプリは、そこにないコードとフィールドを消去し、その旨を通知します。

**日付フィールドは、一緒に移動しません。** プロジェクト全体を移動すると、型が *日付* の入力済みカスタムフィールドは、元の日付のままです。アプリはプレビューで警告します。
