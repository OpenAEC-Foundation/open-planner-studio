# 祝日と建設業休暇を生成する

目的: 国の祝日を、必要な場合は建設業休暇も、カレンダーに入れることです。必要な場合は、独自の休みの日または期間を追加します。

## この機能が必要な場合

祝日がないと、アプリはクリスマスやキングスデーにも作業を計画します。新しいプロジェクトには、*建設モード* がオンの場合、オランダの祝日がすでに入ります。別の国または地域が必要な場合、建設業休暇を含めたい場合、またはプロジェクトが祝日を作成した年の範囲外にある場合は、もう一度生成します。年の範囲は重要です。アプリにとって、その範囲外の日は単に稼働日です。アプリが数えるときに祝日をどう扱うかは、[カレンダーと稼働日](docs://uitleg-kalenders)で読めます。

**建設業休暇**（*bouwvak*）は、オランダの建設業界で全体が取る休暇です。夏の 3 週間です。アプリでは、既定では含まれていません。

## 手順

### 祝日を生成する

1. *計画 › カレンダー › カレンダー* を選択し、左で祝日を入れるカレンダーを選びます。
2. *祝日を生成…* をクリックします。ボタンの下に、選択肢のブロックが開きます。
3. *国* を選びます: オランダ、ドイツ、ベルギー、フランス、イギリス、オーストリア、スイス、または *祝日なし*。一部の国では、*地域* の一覧も表示されます。例: ドイツの連邦州。*全国* を選ぶと、全国で適用される祝日だけが残ります。
4. オランダの場合は、*建設業休暇* を選びます: *なし*（既定）、*北部*、*中部* または *南部*。建設業休暇は、一覧に 1 つの期間として表示されます。例: *Bouwvak (Noord)*、月曜日から金曜日までの 3 週間。この選択肢は、*建設モード* がオンの場合にだけ表示されます。
5. 選択肢の下に概要が表示されます。例: *21 件の祝日、2026〜2028*。概要をクリックすると、日付が表示されます。
6. *生成* をクリックします。*祝日* の一覧に項目が入ります。
7. *適用* をクリックします。アプリはすぐにスケジュールを再計算します。

オランダでは、アプリは毎年次の祝日を一覧に入れます: Nieuwjaar（元日）、Goede Vrijdag（聖金曜日）、Pasen（復活祭、2 日間）、Koningsdag（キングスデー）、Hemelvaart（昇天祭）、Pinksteren（聖霊降臨祭、2 日間）、Kerst（12月25日と26日のクリスマス）。キングスデーが日曜日に当たる場合は、4月26日です。Bevrijdingsdag（解放記念日）は、5 年ごとの年、例: 2025年と2030年にだけ一覧に入ります。

年の範囲は、プロジェクトの期間に従います: 開始日の前年から、終了日の翌年までです。プロジェクトに終了日がない場合は、開始の年から 3 年後までです。開始日と終了日は、*設定 › プロジェクト › プロジェクト設定* で調整します。

### プロジェクトの期間を変えた後に再生成する

プロジェクトの期間が移動する場合、または終了日が後ろにずれる場合、祝日は新しい年をもうカバーしません。アプリは、*カレンダー* ウィンドウでそのことを伝えます。例: *祝日は2025〜2028をカバーしています。2030まで再生成しますか？* 次に *再生成* をクリックします。アプリは、前回と同じ選択（国、地域、建設業休暇）を、プロジェクトの年に使います。次に *適用* をクリックします。このメッセージが表示されるのは、祝日が以前に生成されたカレンダーだけです。

### 独自の休みの日または期間を追加する

1. *カレンダー* ウィンドウで *祝日を追加* をクリックします。一覧の一番下に新しい行が表示されます。*開始日* の下に今日の日付が入っています。
2. *説明* を入力します。例: *社員旅行*。
3. *開始日* を調整します。1 日だけの場合は *終了* を空のままにします。期間の場合は、休みの最終日を入力します。例: 冬季の休暇。
4. *適用* をクリックします。

行の後ろにあるゴミ箱のアイコンで、祝日を削除します。

### すべての祝日を削除する

*国* の下で *祝日なし* を選び、*生成* をクリックします。その後、一覧は空になります。

## 注意点と、その場合にアプリが行うこと

**祝日を生成すると、一覧全体が置き換わります。** 自分で追加した日も消えます。その後、もう一度追加してください。

**Goede Vrijdag（聖金曜日）も含まれています。** 会社が聖金曜日または5年ごとの年の解放記念日に働く場合は、その行をゴミ箱のアイコンで削除します。

**建設業休暇の日付は目安です。** アプリは2025年から2028年まで（この年を含む）の日付を把握しています。ほかの年では、大まかな見積もりを使います。そのため、建設業休暇を選ぶと、アプリは *目安の日付です — Bouwend Nederlandで確認してください* と表示します。必要な場合は、一覧で期間を調整します。

**無効な行。** 有効な *開始日* がない行、*開始日* より前の *終了* がある行、または読み取れない日付がある行には、赤いメッセージが表示されます。例: *終了日が開始日より前になっています。* 修正するまで *適用* は無効です。

**新しいプロジェクトの場合。** *新しいプロジェクト* ウィンドウには、*祝日セット* の下に同じ選択肢があります。*カスタム…* を選ぶと、祝日なしで始まります。作成後、*カレンダー* ウィンドウが開くので、自分で祝日を入れられます。
