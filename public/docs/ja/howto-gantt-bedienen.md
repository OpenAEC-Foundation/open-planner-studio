# Gantt でのドラッグ、移動、ズーム

目標：マウスでタイムラインを操作します。バーを移動するか、期間を調整します。タイムラインをずらし、ボックスでタスクを選択し、拡大と縮小をします。

## いつ必要か

Gantt で、れんが積み工事を 2 日後に開始する必要があると分かります。または、コンクリート打設が予定より 1 日長くかかると分かります。その変更は、バー上で直接行いたいと思います。または、数か月のプロジェクトがあり、建設の祝日まですばやくスクロールしたいと思います。そのためのマウス操作がいくつかあります。どの操作が何をするかは、ドラッグを開始する場所と、スクロール設定によって決まります。

## 手順

### バーを移動する

1. タスクバーの中央を押し、水平方向にドラッグします。開始と終了は一緒に、日単位で移動します。期間は変わりません。
2. マウスを離します。バーは新しい位置に留まります。スケジュールは最新ではなくなります。*計算*（F5）を選択します。*自動計算* がオンの場合は、アプリが自動で行います。

タスクに先行タスクがある場合、アプリは新しい開始を制約 *指定日以降に開始 (SNET)* として記録します。マウスを離した後に、その旨を表示します。その理由と、別の制約の場合の動作は、[制約と期限](docs://uitleg-constraints) にあります。元の開始日までドラッグし直すと、元の制約も戻ります。

横ではなく主に上または下にドラッグすると、タスクは別の行に移動します。日付は変わりません。最初の数ピクセルで選んだ方向が、ドラッグ全体に適用されます。そのため、一回の操作で日付と構造が同時に変わることはありません。[構造の調整](docs://howto-structuur-aanpassen) を参照してください。

### 期間を調整する

1. バーの右端にマウスを合わせます。カーソルは左右を指す矢印になります。
2. 端をドラッグします。ドラッグ中、テーマのアクセントカラー（既定ではオレンジ）の小さな枠に、タスクが今得る期間が表示されます。例えば *4d* のように表示されます。値はリアルタイムに更新されるので、マウスを離す前に新しい期間を確認できます。右端では、小さな枠はバーの内側に表示されます。左端では、バーのすぐ左に表示されます。小さな枠には、期間列と同じ形式で期間が表示されます。
3. マウスを離します。期間は、小さな枠に表示されていた値になります。

左端は開始を移動し、終了はそのままにします。そのため、タスクは前側が短くなるか長くなります。移動の場合と同じ SNET の規則が適用されます。バーの中央をドラッグすると、小さな枠は表示されません。期間は変わらないからです。

期間は、タスクのカレンダーの稼働日で数えます。週末と休業日は数えません。日単位のタスクは、一稼働日より短くできません。時間単位のタスクの場合、アプリはマウスの下にあるタイムラインの刻みに合わせて丸めます。最小は一時間です。十分に拡大していて *拡大時に15分単位を表示する* がオンの場合は、15分になります。

ドラッグ一回は、どれだけ長くドラッグしても、*元に戻す* の一回分です。分割されたバーでは、端の動作が異なります。[タスクを分割](docs://howto-taak-splitsen) を参照してください。

### タイムラインをずらす

Gantt の背景の空白部分をドラッグした時の動作は、スクロールモードによって異なります。モードは *アプリ設定* で選びます。*外観* タブで *ガント › スクロールとズーム* の *モード* を選択します。

- **ズーム＋ドラッグ**（既定）: 背景の空白部分を左マウスボタンでドラッグすると、タイムラインがマウスと一緒に動きます。地図のような動きです。カーソルは手の形になります。バーの上では、ドラッグは単にバー操作の開始になります。
- **位置** と **キー**: 同じドラッグで選択ボックスを作ります。タイムラインは、ホイール（[アプリ設定](docs://ref-instellingen) を参照）または中ボタンでずらします。

**マウスの中ボタン**（ホイールを押す）は、どのモードでもタイムラインをずらします。バー上から開始した場合も同じです。別の操作の途中では機能しません。例えば、バーのドラッグ中です。

### ボックスでタスクを選択する

ボックスは、触れた行にあるタスクをすべて選択します。ボックスの高さだけが影響します。時間軸は影響しません。

1. 背景の空白部分から開始します。*ズーム＋ドラッグ* では、Ctrl（Mac では ⌘）を押したままにします。*位置* と *キー* では、その必要はありません。
2. 選択したい行の上でドラッグします。選択範囲に枠が付きます。
3. マウスを離します。ドラッグ中に Esc を押すと、ボックスを取り消します。その場合、選択は元のままです。

選択について詳しくは、[タスクの選択、削除、取り消し](docs://howto-taken-selecteren-verwijderen) を参照してください。タスクテーブル内の空白部分では、ドラッグしても何も起きません。

### ズームで拡大と縮小

1. *ズーム＋* と *ズーム－*（*開始 › ズーム*）、または + キーと - キーを使います。ホイールでもズームできます。ホイールの動作は、スクロールモードによって異なります（[アプリ設定](docs://ref-instellingen) を参照）。
2. プロジェクト全体を表示するには、*表示 › タイムスケール › プロジェクトに合わせる* を選ぶか、Ctrl+0 を押します。*表示* タブの *リセット*、または 0 キーで、ズームを既定値に戻します。
3. ステータスバーの右下には、一日あたりのピクセル数でズームが表示されます。例えば *ズーム：15px/日* です。

縮小するほど、グリッド線は少なくなります。一日あたり 8 ピクセル以上では、日ごとに線があり、週の境界には太い線があります。一日あたり 2〜8 ピクセルでは、週の境界だけが残ります。一日あたり 2 ピクセル未満、年の表示では、月の境界だけが残ります。そうしないと、キャンバスが一様な縞模様になり、バーが見えなくなります。グレーの週末と休業日、および交互に色を付けた週の背景は、どの表示レベルでも残ります。線が消えても、週の構造が分かるようにするためです。タイムラインのヘッダーでは、週番号と日番号は、表示する余白がある場合にだけ現れます。一日あたり 40 ピクセル以上では、日番号の前に曜日も表示されます。

タスク名は、バーに完全に収まる場合はバーの中に表示されます。収まらない場合（例えば縮小したとき）は、バーの右側に名前全体が表示されます。

### タスクの詳細を見る

マウスを動かさずに、バーの上に置きます。小さなカードが表示されます。カードには、タスクの名前と、*WBS*、*期間*、*開始*、*終了*、*状態*、*クリティカル*、*トータルフロート* が表示されます。ドラッグ中、タイムラインのずらし中、選択ボックスの操作中、または右クリックメニューの表示中は、カードは表示されません。

## 注意点と、アプリの動作

**開始は移動しません。** タスクに先行タスクがあり、SNET 以外の制約、例えば *できるだけ遅く (ALAP)* がある場合、アプリはドラッグした開始を適用しません。マウスを離すと、アプリは開始を止めている制約を表示します。開始を移動するには、その制約を変更します。右端は機能します。期間だけを変更するからです。

**操作が別の動きをします。** 関係モードとタスクを分割モードでは、バーの操作は異なる動きをします。Esc で、これらのモードを終了します。バーからドラッグするときに Shift を押したままにすると、バーを移動する代わりに関係を作成します。[関係の追加](docs://howto-relaties-leggen) を参照してください。

**位置** または **キー** モードでは、左マウスボタンでタイムラインは移動しません。その場合、手の形ではなく通常のカーソルが表示されます。ホイールまたは中ボタンを使うか、モードを *ズーム＋ドラッグ* に設定します。

**分割バーの間隔部分をクリックすると**、タスクは選択されます。ドラッグもボックスも開始されません。
