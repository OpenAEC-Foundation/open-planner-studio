# 右クリックメニュー

Gantt とタスクテーブルで右マウスボタンを押したときに開くメニュー、各項目の動作、および項目が適用されるタスクを説明します。ボタンやショートカットとしても使える項目は、[リボン、タブごと](docs://ref-lint) と [キーボードショートカット](docs://ref-sneltoetsen) にあります。

## どのメニューがどこにあるか

メニューは四種類あります。どのメニューが開くかは、クリックした場所によって決まります:

- **Gantt のタスクバー上** — タスクメニューです。先頭に *ここから関係を開始* があります。
- **タスクテーブル内のタスク上** — 同じタスクメニューですが、先頭のその項目はありません。これは、Gantt の左にあるタスクテーブルと、*テーブル* タブに当てはまります。
- **タスクテーブルのグループヘッダー上** — グループを展開と折りたたみするための小さなメニューです。グループヘッダーは、グループ化したときだけ表示されます。たとえば *リソース図* レイアウトを使うときです。
- **空いている場所上** — Gantt のバーの横やバーの下、およびタスクテーブルで最後のタスクの下、または灰色の *新しいタスク* 行の上です。メニューには *新しいタスク*、*マイルストーンを追加* と *貼り付け* があります。Gantt では、*ズームをリセット* と *プロジェクトに合わせる* もあります。新しいタスクまたはマイルストーンは、リストの一番下に追加されます。Gantt では、クリックした日付から始まります。タスクテーブルでは、名前のセルがすぐに開くので、そのまま入力できます。

Gantt のグループヘッダーの帯の上では、右マウスボタンで空いている場所のメニューが開きます。グループヘッダー自体にメニューがあるのは、タスクテーブルだけです。タイムラインのヘッダーで右クリックしても、何も起こりません。タスクテーブルの列見出しには専用のメニューがあります。それは [テーブル列の調整](docs://howto-tabelkolommen-aanpassen) で説明しています。

**項目はどのタスクに適用されますか？** タスクを一つクリックしますが、選択範囲が適用範囲を決めます。クリックしたタスクが選択範囲に含まれている場合、項目は選択範囲全体に適用されます。含まれていない場合は、そのタスク一つだけに適用されます。Gantt のバー上またはタスクテーブルの行上で右クリックしたとき、そのタスクが選択範囲に含まれていなければ、そのタスクが選択を置き換えます。何かを変更する項目はすべて、選択範囲全体の場合でも *元に戻す* の一ステップになります。

## タスクメニュー

項目は次の順に並んでいます。グループの間の線は、メニューの区切りです。

**ここから関係を開始** — Gantt のバー上でのみ表示されます。このタスクを選択した状態で関係モードをオンにします。その後、後続タスクまでドラッグします。[関係の追加](docs://howto-relaties-leggen) を参照してください。

**中断を解除** と **すべての中断を解除** — 中断があるバー上の Gantt でのみ表示されます。*中断を解除* は、中断部分、またはその後ろの部分をクリックし、その中断を編集できる場合にのみ表示されます。その一つの中断部分を削除します。*すべての中断を解除* は、すべての中断を削除します。編集できないソースファイルの中断も含みます。[タスクの分割](docs://howto-taak-splitsen) を参照してください。

**編集...** — このタスクの *タスクの編集* ウィンドウを開きます。[タスクダイアログとプロパティパネル](docs://ref-taak-eigenschappen) を参照してください。

**上に挿入** と **下に挿入** — 適用範囲の一番上のタスクの上、または一番下のタスクの下に、同じレベルで新しいタスクを一つ挿入します。これは、フィルターもグループ化も並べ替えもしていない、純粋なツリー表示でのみ動作します。そうでない場合、アプリはメッセージを出して実行を拒否します。[タスクとマイルストーンの追加](docs://howto-taken-en-mijlpalen-toevoegen) を参照してください。

**サブタスクを追加** — クリックしたタスクのサブタスクとして、新しいタスクを追加します。サブタスクの一番下に追加されます。このタスク一つだけに適用され、選択範囲全体には適用されません。

**マイルストーンを追加** — クリックしたタスクのサブタスクとして、マイルストーンを追加します。このタスク一つだけに適用されます。

**関係を追加** — *ここから関係を開始* と同じことをします。このタスクを選択した状態で関係モードをオンにします。タスクテーブルでは、Gantt が表示されていない場合、この項目は無効になります。ツールチップに *ガントチャートが表示されているときのみ使用できます* と表示されます。

**インデント** と **インデント解除** — 適用範囲のタスクを、WBS で一レベル下または一レベル上に移動します。この二つは、純粋なツリー表示でのみ表示されます。[構造の調整](docs://howto-structuur-aanpassen) を参照してください。

**マイルストーンを切り替え** — タスクをマイルストーンに変えます。または元に戻します。新しい状態は、クリックしたタスクから決まり、適用範囲全体に適用されます。そのタスクが通常のタスクの場合、適用範囲内のすべてのタスクがマイルストーンになります。サマリータスクと、割り当てがあるタスクはマイルストーンになりません。残りのタスクはマイルストーンになります。理由ごとにメッセージが表示されます。

**カレンダーを割り当て ▸** — サブメニューです。*プロジェクトカレンダー* があります。このタスクは、その場合は独自のカレンダーを持ちません。その下に、使用できるカレンダーが並びます。現在の選択にはチェックマークが付きます。すでにそのカレンダーに設定されているタスクは対象に含まれず、*元に戻す* の手順も追加されません。[カレンダーの作成と割り当て](docs://howto-kalender-maken-en-toewijzen) を参照してください。

**進捗 ▸** — サブメニューです。0%、25%、50%、75%、100% があります。現在の値にはチェックマークが付きます。サマリータスクには独自の進捗がありません。適用範囲にサマリータスクがある場合、その末端タスクにパーセンテージが設定されます。状態日がない場合、アプリは今日の日付を設定し、メッセージを表示します。状態日の後に計画された開始日を持ち、まだ実績開始日がないタスクは、まず実績開始日について確認されます。キャンセルすると、何も変わりません。[進捗の更新](docs://howto-voortgang-bijwerken) を参照してください。

**優先度 ▸** — サブメニューです。*低*（100）、*標準*（500）、*高*（900）があります。これはタスクの山崩しの優先度です。現在の値にはチェックマークが付きます。[リソースの山崩し](docs://uitleg-nivelleren) を参照してください。

**パスをトレース** — このタスクの先行タスクと後続タスクを表示します。トレースがすでにオンの場合、項目名は *パスのトレースを停止* になります。[パストレース](docs://howto-pad-traceren) を参照してください。

**折りたたむ**、**展開** と **ブランチをテンプレートとして保存** — サマリータスクでのみ表示されます。*折りたたむ* と *展開* は、タスクがすでに折りたたまれている、または展開されている場合でも、どちらも常に表示されます。適用範囲全体に適用されます。*ブランチをテンプレートとして保存* は、そのタスクをサブタスクと、サブタスク同士の関係も含めて、WBS テンプレートとして保存します。[WBS テンプレートの保存と挿入](docs://howto-wbs-sjablonen) を参照してください。

**削除** — 適用範囲のタスクを、そのサブタスクとともに削除します。確認はありません。Ctrl+Z で元に戻せます。適用範囲全体で一ステップです。[タスクの選択、削除、元に戻す](docs://howto-taken-selecteren-verwijderen) を参照してください。

## グループヘッダーのメニュー

このメニューは、タスクテーブルのグループヘッダー上にのみあります:

**グループを折りたたむ** または **グループを展開** — このグループだけを折りたたむか展開します。項目には、実行できる操作が表示されます。

**すべて展開** と **すべて折りたたむ** — すべてのグループを一度に展開または折りたたみます。

グループ化は、レイアウトで設定します。[レイアウトの作成と使用](docs://howto-layouts-gebruiken) を参照してください。
