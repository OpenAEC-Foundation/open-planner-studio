# 列の選択

**テーブル**（**テーブル** タブ）と、ガントの横にあるタスクリストには、それぞれ独自の列があります。列はテーブルそのもので変更します。テーブルのヘッダーにあるプラスで列の選択を開き、列ヘッダーでは列の移動、幅の変更、固定、削除ができます。変更はすぐに反映され、OK の手順はありません。

既定では、ガントの横にあるタスクリストは **作業分解構成（WBS）**、**タスク名**、**期間** を表示します。テーブルはさらに **開始**、**終了**、**タスクタイプ**、**クリティカル**、**総余裕**、**進捗** と、プロジェクトのアクティビティコードおよびカスタムフィールドを表示します。

## 列の選択を開く

- テーブルのヘッダー右端のプラス。テーブルとガントの横にあるタスクリストにはそれぞれ専用のプラスがあり、自分のテーブルだけを変更します。
- **テーブル** タブ → **列…** で、テーブルの列の選択が開きます。
- 従来の表示ボタンがオンのとき（**設定** → **詳細設定** タブ → **レガシー機能** → **従来の表示ボタンを表示**）は、**表示** → **表示** リボングループ → **列…** も同じ働きをします。ボタンはテーブル タブに切り替え、そこで列の選択を開きます。

**Esc**、列の選択の外側のクリック、またはもう一度プラスをクリックすると閉じます。

## 列を追加する

**列を選択** には、上から順に次のものがあります。

- **最近使用した列** — 列の選択で最近追加したフィールド。列を一度追加すると、このブロックが表示されます。
- **検索** 欄 — フィールド名の一部を入力します。**検索結果** はすべてのグループから集められます。
- グループ別のフィールド：**タスク**、**計画**、**制約**、**依存関係**、**リソース**、**進捗**、**計算値**、**ベースライン**、**カスタム**、**技術情報**。グループをクリックすると展開し、横の数字はそのグループのフィールド数です。
- 一番下に **既定値に戻す** ボタン（後述）。

フィールドをクリックすると最後の列として追加され、列の選択は閉じます。すでに列になっているフィールドにはチェックが付いており、もう一度選ぶことはできません。プロジェクトのアクティビティコードとカスタムフィールドは **カスタム** に、ベースラインのフィールドは **ベースライン** にあります。

**計算値** には、分析フィールドの **自由余裕**、**干渉余裕**、**準クリティカル**、**余裕パス** などがあります。これらは計算（**F5**）の後にだけ値を持ち、**準クリティカル** と **余裕パス** は対応するスケジューリングオプションがオンの場合に限られます — [クリティカルパスと高度な分析](docs://gids-kritiek-pad-analyse) を参照してください。

## 列ヘッダーで列を調整する

- **移動** — 列ヘッダーを別の位置へドラッグします。固定した列は先頭にまとまったままで、固定していない列は固定していない列の間でだけ移動できます。
- **幅** — 列ヘッダーの右端をドラッグします（40～480 ピクセル）。その端をダブルクリックすると、ヘッダーと最も長い値に合わせて列幅を調整します。キーボードでは、端にフォーカスを置いて左右の矢印キーを使います。**Shift** を併用すると大きく変わります。
- **削除** — 列ヘッダーにポインターを重ねると現れるマイナス記号。フィールドは列の選択で引き続き選べます。
- 列ヘッダーを **右クリック** すると **固定**（または **固定を解除**）、**自動調整**、**削除** が表示されます。固定した列は先頭の、ほかの固定した列の隣へ移り、テーブルを横にスクロールしても表示されたままです（固定した列がまとめてテーブルに収まる限り）。

## 開始、終了と予定日

**開始** と **終了**（テーブルの既定のレイアウトにある列）は、ガントのバーと同じ日付を表示します。計算済みのスケジュール、最初の計算の前は入力した日付です。開始に別の日付を入力すると、それが予定開始日になります。別の終了を入力すると、自動スケジュールのタスクでは期間が変わり、手動スケジュールのタスクでは予定終了日になります。その後 **F5** を押して再計算します。同じ日付を入力し直しても何も変わりません。

**予定開始日** と **予定終了日** のフィールドは、計算でタスクが移動しても、入力した日付そのものを表示します。予定終了日を編集できるのは手動スケジュールのタスクだけです。その他のタスクでは開始と期間が終了を決めます。自動スケジュールのサマリータスクの開始と終了はサブタスクから決まり、編集できません。

## 既定値に戻す

**既定値に戻す** は列の選択の一番下にあります。1 回クリックすると、そのテーブルの列が既定のレイアウトに戻ります。対象は表示する列、その順序と幅、固定した列です。追加したフィールドはテーブルから外れ、列の選択から引き続き選べます。更新後に新しい既定レイアウトを使うのもこの方法です。たとえば **予定開始日** と **予定終了日** の代わりに **開始** と **終了** になります。以前に保存した自分のレイアウトは自動では変わりません。テーブルがすでに既定のレイアウトの場合、ボタンは無効です。

## 保存、元に戻す、レイアウト

列のレイアウトはこのデバイス上の個人設定です。すべてのプロジェクトに適用され、プロジェクトファイルには保存されません。列の操作（追加、削除、移動、幅の変更、固定、**既定値に戻す**）はそれぞれ 1 ステップで、**Ctrl+Z** で元に戻せます。

レイアウトに列を記録することもできます。レイアウトを作成するときに表示しているテーブルの列レイアウトを取り込み、レイアウトボタンをクリックすると、そのとき表示されているテーブルに適用します。テーブル タブではテーブル、ほかのタブではガントの横にあるタスクリストです。[レイアウトの保存と読み込み](docs://ref-layouts) を参照してください。
