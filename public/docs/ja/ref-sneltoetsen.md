# キーボードショートカット

このアプリのキーの組み合わせをすべて示します。グループは *キーボードショートカット* ウィンドウと同じです。キーは固定されています。割り当てを変更できません。マウスとメニューの操作は、ハウツーに記載されています。ここでは、キーを調べられます。

## この一覧の読み方

**Mac。** この記事で Ctrl とある場合は、Mac では Cmd（⌘）を使います。Alt は Option（⌥）です。Mac では、*キーボードショートカット* ウィンドウに Alt、Shift、Ctrl の代わりに記号 ⌥、⇧、⌘ が表示されます。Mac のアプリでも Ctrl が使えます。

**完全一致の組み合わせ。** アプリは Ctrl、Shift、Alt を正確に比較します。そのため、Ctrl+Alt+S は何もしません。キーは一覧と正確に一致している必要があります。

**ウィンドウを開く。** Ctrl+/ を押すか、*設定 › キーボードショートカット › キーボードショートカット* を選択します。Ctrl+/ でウィンドウを再び閉じられます。このウィンドウは読み取り専用です。ここに記載されているすべてのキーは表示されません。テーブルのキーは最初の六項目のみ表示されます。この記事の下部にあるダイアログのキーも表示されません。

**キーが機能しない場合。** 各項目に制限が書かれています。次の三つのルールは、ほぼすべての場合に当てはまります：

- 入力欄、ドロップダウンリスト、テキストボックスでは、アプリはキーを処理しません。そのため、そのまま入力できます。例外として、F5、Ctrl+S、F11、プレゼンテーション中の Esc は入力欄でも機能します。閉じたドロップダウンリストにフォーカスがある場合は、Ctrl を使うキーも機能します。例えば、選択後の Ctrl+Z です（Ctrl+Delete と Ctrl+Backspace は除きます）。開いたリストやダイアログ内では、これは当てはまりません。ビルド済みのアプリ（デスクトップ版とサイト上のウェブ版）では、Ctrl+Shift+S、Ctrl+O、Ctrl+N も入力欄で機能します。
- ダイアログや別のウィンドウが開いている間は、下に *ダイアログ内では使えません* と書かれたキーは機能しません。ツアー、ようこそダイアログ、回答を待つ質問（例：変更を保存するかどうかの質問や、拡張機能のインストール時の同意）にも同じことが当てはまります。これらのキーのほとんどは、プレゼンテーションモードでも機能しません。例外は編集キーです。Ctrl+C、Ctrl+V、Ctrl+Z、Ctrl+Y、Delete/Backspace は、プレゼンテーション中も機能します。
- ドキュメントの切り替え（Ctrl+1 から 9、Ctrl+N、Ctrl+O）も、*ファイル › プロジェクト設定* で *適用* を選択して確定していない変更がある間は機能しません。先に変更を破棄するか、適用してください。

## ファイル

**F5** — *計算*: スケジュールを再計算します。*計算* ボタンと同じです（*ホーム › スケジュール › 計算*）。入力欄でも機能します。

**Ctrl+S** — *保存*: プロジェクトを保存します。入力欄でも機能します。

**Ctrl+Shift+S** — *名前を付けて保存*: ファイルの保存先を尋ねます。開発ビルドでは、入力欄では機能しません。

**Ctrl+O** — *開く*: ファイルを開きます。通常は新しいタブで開きます。ダイアログ内では使えません。未適用のプロジェクト設定がある場合も使えません。

**Ctrl+N** — *新しいプロジェクト*: *新しいプロジェクト* ウィンドウを開きます。ダイアログ内では使えません。未適用のプロジェクト設定がある場合も使えません。

ビルド済みのアプリ（デスクトップ版とサイト上のウェブ版）は、作業の邪魔にならないように、一部のブラウザーキーもブロックします。Ctrl+R と Ctrl+Shift+R（再読み込み）、F12、Ctrl+Shift+I と Ctrl+Shift+J（開発者ツール）、Ctrl+U（ソースの表示）、Ctrl+G、Ctrl+F、Ctrl+L（検索とアドレスバー）です。Ctrl+S、Ctrl+Shift+S、Ctrl+O、Ctrl+N、F5 は、アプリ自体に渡されます。

## 編集

**Ctrl+C** — *コピー*: 選択したタスクをコピーします。選択がある場合にのみ機能します。ダイアログ内では使えません。*ファイル* では使えません。*レポート* と *IFC* のタブでも使えません。全画面のリソースパネルを開いている間も使えません。タスクテーブルでは、Ctrl+C は選択したセルをコピーします。これはタスクテーブル自体が処理します。

**Ctrl+V** — *貼り付け*: コピーしたタスクを貼り付けます。ダイアログ内では使えません。*ファイル* では使えません。*レポート* と *IFC* のタブでも使えません。全画面のリソースパネルを開いている間も使えません。タスクテーブルがそこでは表示されていないためです。タスクテーブルでは、セルを貼り付けます。

**Ctrl+Z** — *元に戻す*。ダイアログ内では使えません。先にウィンドウを閉じてください。

**Ctrl+Y** または **Ctrl+Shift+Z** — *やり直し*: 元に戻した操作をやり直します。ダイアログ内では使えません。

**Delete** または **Backspace** — *削除*: 選択したタスクを削除します。選択がある場合にのみ機能します。ダイアログ内では使えません。*ファイル* では使えません。*レポート* と *IFC* のタブでも使えません。全画面のリソースパネルを開いている間も使えません。タスクテーブルがそこでは表示されていないためです。タスクテーブルのセル内では、Delete と Backspace はセルの内容を消去するだけです（*テーブル* を参照）。

**F2** — *編集...*: 最初に選択したタスクのタスクダイアログを開きます。選択がある場合にのみ機能します。ダイアログ内では使えません。タスクテーブルのセル内では、F2 でそのセルの編集を開始します。

**Ctrl+A** — *すべて選択*: すべてのタスクを選択します。ダイアログ内では使えません。

**Esc** — *選択を解除*: 選択を解除します。同時に、関係モード、タスクを分割するモード、パストレースをオフにします。さらに、タスクダイアログとプロジェクトの概要を閉じます。プレゼンテーション中は、Esc はプレゼンテーションを閉じるだけです（*表示* を参照）。入力欄では、Esc はこれらのどれも行いません。

## 構造

**Alt+Shift+→** または **Alt+→** — *インデント*: 選択したタスクを WBS で一段階深くします。選択がある場合にのみ機能します。ダイアログ内では使えません。

**Alt+Shift+←** または **Alt+←** — *インデント解除*: 選択したタスクを一段階上げます。選択がある場合にのみ機能します。ダイアログ内では使えません。

インデント、インデント解除、および選択したタスクの上または下への挿入は、通常のツリー表示でのみ機能します。つまり、フィルター、グループ化、並べ替えがない表示です。それ以外の表示では、アプリはメッセージを表示してこれらを拒否します。表示される順序がプロジェクトの順序ではなくなるためです。選択がない状態での挿入は、どの表示でも機能します。

**Insert** — *上に挿入*: 最も上に選択したタスクの上に、同じレベルで新しいタスクを挿入します。選択がない場合、タスクはどの表示でも一番下に入ります。ダイアログ内では使えません。

**Ctrl+I** — *下に挿入*: 最も下に選択したタスクの下に、同じレベルで新しいタスクを挿入します。選択がない場合、タスクは一番下に入ります。ダイアログ内では使えません。

**Ctrl+M** — *マイルストーンを追加*: タスクを選択していても、リストの一番下に新しいマイルストーンを追加します。ダイアログ内では使えません。

**Alt+↑** — *タスクを上に移動*: 最初に選択したタスクを、同じレベル内で一つ上に移動します。選択がある場合にのみ機能します。ダイアログ内では使えません。

**Alt+↓** — *タスクを下に移動*: 同じ動作を、一つ下に行います。

## 表示

**F11** — *プレゼンテーション*: プレゼンテーションモードのオン/オフを切り替えます。アプリは、ウィンドウに全画面表示も要求します。入力欄でも機能します。ブラウザーでは、F11 でプレゼンテーションは開始されません。ブラウザーがウィンドウを自分で全画面にし、アプリは変わりません。ブラウザーでも、F11 で実行中のプレゼンテーションを停止できます。

**Esc**（プレゼンテーション中）— *プレゼンテーションを終了*。入力欄でも機能します。これは *選択を解除* より優先されます。

**Ctrl+=** — *拡大*: タイムラインを一定の段階で拡大します。入力欄では使えません。

**Ctrl+-** — *縮小*: タイムラインを一定の段階で縮小します。

**+** または **=** — *拡大*: Gantt エリアの中央を基準に、10% 拡大します。入力欄では使えません。Gantt のタイムラインが表示されている場合にのみ機能します（つまり、*テーブル*、*IFC*、*レポート* タブでは機能しません）。

**-** — *縮小*: 10% 縮小します。制限は同じです。

**0** — *ズームをリセット*: ズームを既定値に戻し、先頭までスクロールします。制限は同じです。

**Ctrl+0** — *プロジェクトに合わせる*: プロジェクト全体が表示に収まるように拡大縮小します。制限は同じです。

**Ctrl+/** — *ショートカットを表示*: *キーボードショートカット* ウィンドウを開いたり閉じたりします。別のダイアログが開いている場合でも機能しますが、ツアーとようこそダイアログ中は機能しません。

**Ctrl+Shift+H** — *ヒストグラム*: ヒストグラムのオン/オフを切り替えます。*ヒストグラム* ボタンと同じです（*リソース › ヒストグラム › ヒストグラム* または *表示 › パネル › ヒストグラム*）。アプリは選択内容を記憶します。

**Ctrl+Shift+L** — *警告*: 警告パネルのオン/オフを切り替えます。*警告* ボタンと同じです（*表示 › パネル › 警告* または *計画 › スケジュール › 警告*）。

## ナビゲーション

**Ctrl+P** — *レポートタブへ移動*: *レポート* タブに移動します。そのため、印刷コマンドではありません。ダイアログ内では使えません。

**F1** — *ヘルプを開く*: *ファイル › ヘルプ* を開きます。入力欄とダイアログでは使えません。ウィンドウでは、右上の疑問符を使います。その場合、そのウィンドウに関する記事のヘルプが開きます（[リボン、タブごとの説明](docs://ref-lint) の *ヘルプ* の項目を参照）。

**Ctrl+1** から **Ctrl+9** — *ドキュメントを切り替え*: 一番目から九番目に開いているドキュメントに移動します。そのドキュメントがない場合、何も起こりません。ダイアログ内では使えません。未適用のプロジェクト設定がある場合も使えません。

**Ctrl+Home** — *今日にジャンプ*: タイムラインをスクロールして、ある日付を表示の左端に置きます。その日付は、状態日を設定している場合は状態日、設定していない場合は今日です。そのため、タイムラインが状態日へ移動する場合でも、ラベルには「今日」と書かれています。ズームとタイムラインの開始位置は変わりません。タスクテーブルのセルにフォーカスがある場合、Ctrl+Home は代わりにタスクテーブルの最初のセルへ移動します（*テーブル* を参照）。

## テーブル

これらのキーは、セルにフォーカスがあるとき、タスクテーブル（*テーブル* タブ、および Gantt の左側）で機能します。*キーボードショートカット* ウィンドウには、最初の六項目が表示されます。残りは表示されません。

**Tab** および **Shift+Tab** — *次/前のセル*: 次または前のセルに移動します。行の末尾では次の行に移動します。最後のセル（Tab）または最初のセル（Shift+Tab）では、フォーカスがタスクテーブルから外れます。

**Enter** または **F2** — *セルを編集*: セルの編集欄を開きます。セルが読み取り専用の場合、タスクテーブルがメッセージを表示します。

**文字、数字、またはその他の文字** — *入力するとセルの内容が置き換わります*: 編集を開始し、入力した内容でセルの内容を置き換えます。

**Insert** — *上に挿入*: 現在の行の上にタスクを挿入します。

**Delete** または **Backspace** — *セルの内容を消去*: 選択したセルの内容を消去します。タスク自体は消去しません。*キーボードショートカット* ウィンドウには Delete のみ表示されます。

**Esc** — *選択を解除*: フォーカスをタスクテーブル全体に移動します。そのため、次の Tab でタスクテーブルから外れます。上で説明したとおり、選択も解除します。

**矢印キー** — 上、下、左、右のセルに移動します。Shift を加えると、選択範囲を広げます。

**Home** および **End** — 行の最初または最後の列に移動します。Ctrl を加えると、最初の行の最初のセル、または最後の行の最後のセルに移動します。Shift を加えると、選択範囲を広げます。

**Page Up** および **Page Down** — 画面一つ分の高さだけ上または下に移動します。Shift を加えると、選択範囲を広げます。

**Enter**（編集中）— 入力を確定し、次の行の同じ列に移動します。Shift+Enter で前の行に移動します。

**Esc**（編集中）— 編集をキャンセルし、入力内容は保持しません。

リソーステーブルには、入力欄の間で独自のキー操作があります。それはこの一覧には含まれません。

## ダイアログとその他のウィンドウ

これらのキーは *キーボードショートカット* ウィンドウには含まれません。

**Esc** — 最前面のダイアログを閉じます（キャンセルします）。*ファイル*（バックステージ）でも Esc は画面を閉じます。ただし、ダイアログまたは開いているドロップダウンリストが最前面にある場合は除きます。

**Enter** — 対応しているダイアログで、最前面のダイアログを確定します。主要ボタンと同じ動作です。複数行のテキストボックス、開いているドロップダウンリスト、IME の入力中には、この動作はありません。

**Esc**（Gantt でのジェスチャー中）— 選択範囲の枠をキャンセルします（選択は変わりません）。また、タスクを分割するジェスチャーをキャンセルします（すでに行った分割は元に戻ります）。

**Enter** および **Esc**（関係の種類の選択ツール）— Enter で確定し、Esc でキャンセルします。

**左矢印** および **右矢印**（タスクテーブルとタイムラインの間の仕切り線で）— 仕切り線を一度に 10 ピクセルずつ動かします。Shift を押すと 40 ピクセル動かします。仕切り線にキーボードのフォーカスが必要です。

**上矢印** および **下矢印**（ヒストグラムのリソース一覧で）— 前または次のリソースを選択します。ヒストグラムの欄にフォーカスが必要です。
