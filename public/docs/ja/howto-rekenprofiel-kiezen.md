# 計算プロファイルの選択と作成

目的: プロジェクトがどの計算規則を使うかを決めます。組み込みのプロファイルを選ぶか、独自の規則を持つカスタムプロファイルを作成します。

## 必要になる場面

Primavera P6 または Microsoft Project として計算する必要があるプロジェクトを開く場合、またはプロファイルの動作とは違う規則を一つ設定したい場合に使います。プロファイルとは何か、また日付が変わることがある理由は [計算プロファイルと規則](docs://uitleg-rekenprofielen) に書かれています。

## 手順

### 新しいプロジェクトの計算プロファイルを選ぶ

1. *ホーム › ファイル › 新規* を選択します。*新しいプロジェクト* ウィンドウが開きます。
2. ドロップダウンリスト *計算プロファイル* で、次のプロファイルのいずれかを選択します: *Open Planner Studio*、*Primavera P6*、*Microsoft Project*。
3. プロジェクトを作成します。アプリは、すでに入力されていた計算オプションを、プロファイルの既定値に置き換えます。

### 既存のプロジェクトの計算プロファイルを切り替える

1. *設定 › プロジェクト › プロジェクト設定* を選択します。*ファイル › プロジェクト設定* を選択することもできます。
2. ブロック *計算プロファイルとオプション* で、ドロップダウンリスト *計算プロファイル* を開き、別のプロファイルを選択します。
3. **適用** をクリックします。*自動計算* がオフの場合でも、アプリはすぐにスケジュールを再計算します。タスクが移動した場合、アプリはその数を通知します。

*適用* をクリックするまで、変更はフォーム内だけに存在します。切り替え全体は、*元に戻す* を一回実行するだけで取り消せます。切り替えで変わるのは規則だけです。計算オプションはそのまま残ります。

### カスタムプロファイルを作成する

1. ブロック *計算プロファイルとオプション* で、ドロップダウンリストの横にある *新しいプロファイル* をクリックします。
2. 名前を入力します。アプリは、選んだプロファイルに *Copy of* を付けた名前を提案します。例: *Copy of Open Planner Studio*。
3. *作成* をクリックします。セクション *このプロファイルの規則* が展開されます。
4. チェックボックスで規則をオンまたはオフにします。行の後ろの i アイコンに、その規則の説明が表示されます。基準と異なる規則には、ラベル *基準に戻す* が付きます。
5. **適用** をクリックします。そのときに初めて、プロジェクトは新しいプロファイルで計算します。

組み込みの三つのプロファイルは変更できません。それらの規則は参考情報としてのみ表示されます。

### カスタムプロファイルをテンプレートとして保管する

1. 必要に応じて、欄 *このカスタムプロファイルの名前* に別の名前を入力します。
2. *テンプレートとして保存* をクリックします。アプリは、テンプレートが保存されたこと、または保存できなかった理由を通知します。
3. 同じアプリ内の別のプロジェクトでは、テンプレートはドロップダウンリスト *計算プロファイル* に表示されます。

後でプロファイルがテンプレートと異なる場合、黄色いブロックにその旨が表示されます。その場合は *このプロジェクトからテンプレートを更新* または *テンプレートから更新* を選択します。

テンプレートを削除するには *テンプレートを削除* を使います。アプリは先に確認を求めます。

## 結果の確認

- ブロック *計算プロファイルとオプション* に、選んだプロファイルが表示されます。
- *適用* の後、アプリは移動したタスクを通知します。例: *適用後に 4 件のタスクが移動しました。*
- 計算オプションの上にあるオレンジのブロックには、計算オプションがプロファイルの既定値と異なると表示されます。これは多くの場合、意図的なものです。それでも既定値を使いたい場合は、*… の既定の設定を使う* をクリックします。

## 注意点とアプリの動作

**日付が変わります。** 別のプロファイルでは、実際の日付が変わることがあります。結果を確認してください。気に入らない場合は *元に戻す* を選択します。プロファイルと日付は一緒に元に戻ります。

**元に戻した後の黄色いブロック。** プロジェクト設定が開いている間に *元に戻す* または *やり直し* を押すと、ブロックはプロジェクトの状態に追従します。ブロック内で自分がすでに何かを変更していた場合は、その選択が残ります。そのとき黄色いブロックには、*適用* でその選択が戻ることが表示されます。

**テンプレートは最大 100 件までです。** すでに 100 件ある場合、アプリはテンプレートを保存せず、その旨を通知します。先にテンプレートを一つ削除してください。アプリの保存領域がいっぱいである場合、または見つからない場合も、アプリはメッセージを表示します。

**テンプレートはアプリに属し、プロファイルはプロジェクトに属します。** プロジェクトは常に自分のプロファイルのコピーを持ちます。後からテンプレートを変更しても、プロジェクトは一緒には変わりません。

**元のファイルの設定。** 別のファイルから作られたプロジェクトに *Primavera P6* または *Microsoft Project* を選ぶと、元のファイルの設定が残ります。ここでは変更できません。
