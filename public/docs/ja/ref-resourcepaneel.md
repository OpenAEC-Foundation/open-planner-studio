# リソースパネル

リソースパネルでは、リソースを管理します。どのリソースが利用できるか、どのくらいのキャパシティがあるか、どのカレンダーを使うかを設定します。Gantt の下にあるヒストグラムと過剰割り当ても、このパネルに属します。この記事では、各項目とボタンの働き、既定値、そして画面でどう見えるかを説明します。リソースの作成と割り当ての方法は [リソースの管理](docs://howto-resources-beheren) と [曲線を使ったリソースの割り当て](docs://howto-resource-toewijzen) にあります。過剰割り当ての解消は [過剰割り当ての解消](docs://howto-overbezetting-oplossen) で説明しています。

## 場所

- **フルパネル** — *リソース › 管理 › リソース* または *表示 › パネル › リソース*。作業領域全体を使います。右上の「×」で閉じます。
- **リソースドック** — *リソース › 管理 › リソースドック* または *表示 › パネル › リソースドック*：Gantt の横、右側の列にあるコンパクトな一覧です。詳しくは下を参照してください。
- **ヒストグラム** — *リソース › ヒストグラム › ヒストグラム* または *表示 › パネル › ヒストグラム*：Gantt の下にある帯です。詳しくは下を参照してください。
- **ビュー** — プロジェクトがリソースライブラリに属している場合、パネルの右上に *ライブラリ*、*プロジェクト*、*稼働状況* から選ぶ項目があります。ライブラリがない場合は、プロジェクトの表だけがあります。パネルを開くたびに *プロジェクト* から始まります。そのため、共有ライブラリに知らないうちに入ることはありません。

## 新規リソース

- **プロジェクトに新規リソース**（*ライブラリ* ビューの *ライブラリに新規リソース*）— 右上のボタンです。表の一番下に下書き行を開きます。名前を入力して行から離れる（または Enter を押す）まで、リソースは作成されません。空のまま行から離れるか Esc を押すと、何も残りません。リソースも、*元に戻す* の手順も残りません。項目は任意の順で入力できます。すべてが同時に登録されます。Enter または下矢印で行を確定し、新しい下書き行を開きます。Shift+Enter または上矢印で行を確定し、表に戻ります。下書き行には、キャパシティの展開ボタン、カレンダーの鉛筆、ごみ箱はありません。これらは、まだ存在しないリソースを対象とするためです。*リソース › 管理* の *新規リソース* ボタンも同じ動作をします。
- **表の移動** — 表では、Enter と Shift+Enter、および上矢印と下矢印で、行の間をカーソルが移動します。最後の行で Enter を押すと、新しい下書き行を開きます。

## プロジェクトビュー

プロジェクトが使うリソースの表です。一行が一つのリソースです。名前と単価の変更は、欄から離れた時点で反映されます。それぞれが *元に戻す* の一手順になります。

- **色** — 色を選ぶ入力欄です。既定値: パレットにある最初の空いている色。効果: Gantt のバーの下にあるリソースアクセントの色（*表示 › ベースラインと進捗 › リソースアクセント*）と、ドックの色見本に使われます。
- **名前** — リソースの名前です。空の名前は保存されません。その場合、欄は元の名前に戻ります。
- **種類** — *労務*、*機材*、*資材*、*下請業者* または *班*。新規リソースの既定値: *労務*。効果: *資材* には *単位* があり、ヒストグラムの *すべてのリソース* の合計には含まれません。山崩しは資材を対象外にします。*班* は、ほかのリソースの *班* として選べます。ほかの種類は同じように計算されます。
- **最大単位数** — 一日に利用できるリソースの量です。0 より大きい数字を入力します（小数も入力できます）。既定値: 1。効果: 一日あたりのキャパシティです。負荷がこれより高い場合、リソースは過剰割り当てになります。横の矢印で *時期別キャパシティ* を展開します。矢印の横の数字は、ステップの数です。
- **時期別キャパシティ** — *開始日*（日付）と *最大単位数* を持つステップです。*ステップを追加* は、今日の日付と 1 のステップを追加します。ステップがない場合は、*ステップがありません — 常に固定の最大単位数が適用されます。* と表示されます。効果: ステップの日付から、そのステップの *最大単位数* が固定値の代わりに適用されます。ある日以前の日付を持つ最後のステップが優先されます。
- **カレンダー** — 一覧です。*プロジェクトカレンダー*（既定値）、プロジェクトのカレンダー、および新規作成用の *+ リソースカレンダー* があります。鉛筆（*編集*）は、選んだカレンダーを開きます。*プロジェクトカレンダー* では無効です。効果: リソースが稼働する日です。休日はキャパシティが 0 になります。その日に作業が予定されている場合、リソースは過剰割り当てになり、理由として *カレンダー「…」によりこの日は稼働しません* が表示されます。リソースカレンダーは、タスクの日付を変更しません。詳しくは [カレンダーの画面](docs://ref-kalenders) を参照してください。
- **単価/時間** — 一時間あたりのコストです。空欄は、単価なしを意味します。無効な数字の場合は、前の値に戻ります。効果: スケジュールや負荷には影響しません。単価で *合計* 列が決まります。単価は IFC ファイルに保存されます。MS Project へのエクスポートでは標準単価として、Primavera P6 XML では単価（単位あたりの価格）として書き出されます。
- **合計** — 読み取り専用です。負荷の時間 × 単価を、小数点以下二桁で表示します。単価や負荷がない場合は *—* と表示されます。表の一番下の *合計* の行は、すべてのリソースを合計します。時間は前回の計算から取得されます。単位数 × タスクのカレンダーにおける一日の時間で数えます。古い場合は、*計算* を押してください。
- **単位** — 資材の計量単位です。例: `m³`。入力できるのは種類 *資材* だけです（ヒントに *「資材」タイプのリソースにのみ入力できます。* と表示されます）。効果: ラベルだけです。計算には使われません。
- **班** — リソースが属する班です。班は、種類 *班* のリソースから選びます。既定値: *なし*。効果: グループ化のみです。班のキャパシティと負荷は、メンバーの合計ではありません。
- **削除**（ごみ箱）— リソースを削除します。割り当てがある場合、アプリは最初に *「…」には … 件の割り当てがあります — 削除しますか？* と確認します。チェックマークで確定し、× で取り消します。
- **ライブラリへ** — プロジェクトがリソースライブラリに属している場合にのみ表示されます。ライブラリに由来しない名前のリソースに対してです。リソースをライブラリに追加するか、同じ名前の既存の項目に関連付けます。結果も表示されます（*追加しました。*、*既存のライブラリ項目に関連付けました — 値が異なります。マーカーを確認してください。* または *ライブラリに既に存在していました — 関連付けました。*）。
- **ライブラリから切り離す** — ライブラリ由来のリソースにある切り離しアイコンです。由来を削除します。その後、すべての欄は再び自由に編集できます。

リソースがない場合は *リソースがまだありません。追加して始めましょう。* と表示されます。プロジェクトがライブラリに属している場合は、*このプロジェクトはまだライブラリのリソースを使用していません。* とヒントが表示されます。

### ライブラリ由来のリソース

ライブラリ由来のリソースには、小さなライブラリアイコン（*ライブラリ由来*）が付いています。その *名前*、*種類*、*単価/時間* および *単位* は、通常の文字で表示されます（*ライブラリの値です。ライブラリビューで編集するか、このリソースをライブラリから切り離してください。*）。リソースが何であるかは、ライブラリが決めるためです。*色*、*最大単位数*、キャパシティのステップ、*カレンダー* および *班* は編集できます。どれだけ、いつ使うかは、プロジェクトが決めるためです。バッジが二つ表示されることがあります。*相違あり — 決定が必要*（クリックすると *リソースライブラリにリンク* の画面が開きます）と、*ライブラリにはもう存在しません*（ボタン *プロジェクトから削除* 付き）です。

## ライブラリビュー

プロジェクトがリソースライブラリに属している場合にのみ表示されます。[リソースライブラリの使い方](docs://howto-resourcebibliotheek-gebruiken) と [リソースライブラリの管理と共有](docs://howto-bibliotheken-beheren) を参照してください。上部には色付きの通知があります: *これはライブラリデータを編集し、すべてのプロジェクトに適用されます — 元に戻す操作の対象外です。* 表の項目は *プロジェクト* ビューと同じです。ただし、次の点が異なります:

- *合計* 列はありません。これは一つのプロジェクトの計算だからです。
- *班* 列は、ライブラリにリソースが登録されるとすぐに表示されます。
- *カレンダー* 列には、ライブラリのカレンダーが並びます。既定値は *カレンダーなし* です。
- **プロジェクトに割り当て** — リソースをプロジェクトに入れます。カレンダーのコピーも入ります。結果として *追加しました。* または *すでにプロジェクトに含まれています。* と表示されます。
- **削除** — *ライブラリから「…」を削除しますか？これはすべてのプロジェクトに適用され、元に戻せません。* と確認します。
- リソースがない場合は *プールにはまだリソースがありません。* と表示されます。

## 稼働状況ビュー

開いているすべてのドキュメントを対象にする、読み取り専用のビューです。どのライブラリリソースが、どこで予約されているかを示します。新規リソースのボタンはありません。[稼働状況の概要の使い方](docs://howto-bezettingsoverzicht-gebruiken) を参照してください。

- **表** — ライブラリリソースごとに、*名前*、*ドキュメント*（リソースが含まれるドキュメントの数）、*期間* および *ピーク / キャパシティ*（その日の合計負荷のうち、キャパシティに対して最も高い値）を表示します。赤い *N 日が二重予約* は、複数のドキュメントをまたいで、リソースがキャパシティを超えていることを意味します。名前の横の矢印を押すと、ドキュメントが展開されます。それぞれに期間とピークがあります。行をクリックすると、そのリソースのヒストグラムが表示されます（*ヒストグラムを表示するにはリソースを選択してください。*）。
- **集計対象** — このアプリで開いているドキュメントだけが対象です（*この概要には、このアプリで開いているドキュメントのみが表示されます。*）。まだ計算されていないドキュメントには、その行にメッセージが表示されます。アクティブなドキュメントは、最後に計算された数値で集計されます（*古い状態: これは前回計算された数値です — このドキュメントで F5 を押してください。*）。ほかのドキュメントは、この概要のために事前に計算されます（*この概要のために事前に計算されています — ドキュメント自体は、そこで F5 を押すか「自動計算」をオンにするまで古い日付を表示したままです。*）。*自動計算* がオンの場合、概要は実際にそれらのドキュメントを計算します。計算に失敗すると、そのドキュメントは集計されません（*集計対象外: スケジュールが未計算です — このドキュメントをアクティブにして F5 を押してください。*）。予約されたリソースがない場合は *開いているドキュメントで予約されているライブラリリソースはありません。* と表示されます。
- **並び順** — 二重予約があるリソースが上に並びます。衝突日の多い順に並び、その後は名前順です。

## リソースドック

右側の列にあるコンパクトな一覧です。*プロパティ* パネルの横にあります。リソースごとに、色見本、名前（読み取り専用）、過剰割り当ての日が一日でもあるリソースに表示される赤い三角（*過剰割り当て*）、および編集できる *最大単位数* があります。タスクを選択している場合は、そのタスクのリソースだけが表示されます。ヘッダーには *フルパネル*（フルパネルを開きます）と *ドッキングを閉じる* があります。リソースがない場合は *リソースがまだありません。追加して始めましょう。* と表示されます。

## ヒストグラム

Gantt の下にある帯です。リソースの一日あたりの負荷を示します。オンとオフは *リソース › ヒストグラム › ヒストグラム* または *表示 › パネル › ヒストグラム* で切り替えます。既定値: オフ。選んだ設定は保存されます。高さは既定で 160 ピクセルです。Gantt とヒストグラムの間の端をドラッグして変更できます。

- **選択一覧** — 左側、タスクテーブルの下に一覧があります。一番上に *すべてのリソース* が固定され、その下に 一リソースにつき一行あります。行をクリックすると、その行を選びます。矢印キーで行を移動できます。*リソース › ヒストグラム › 前へ* と *次へ* も同じ動作をします。行の横の赤い点は、そのリソースに過剰割り当ての日が一日以上あることを意味します。*すべてのリソース* の場合、点は資材以外のリソースだけを見ます。タスクを選択している場合、一覧にはそれらのタスクのリソースだけが含まれます。選んだリソースがその外にある場合、帯は一時的に、選択中のタスクの *すべてのリソース* を表示します。
- **バー** — 一日に一本のバーです。負荷を *単位* で示します。線はキャパシティを示します。キャパシティより上にあるバーの部分は赤くなります。左上には、*単位* とともに最大値が表示されます。*すべてのリソース* は、資材を除くすべてのリソースの負荷とキャパシティを合計します。
- **ツールチップ** — 日の上でマウスを少しの間止めます。*{date} に N 件のタスクが関与* と、最大八件のタスク名が表示されます。選んだリソースで、そのカレンダーが稼働しない日の場合は、*カレンダー「…」によりこの日は稼働しません* も表示されます。
- **メッセージ** — 負荷がないときは *再計算 (F5) して負荷を表示* と表示されます。リソースがないときは *リソースがまだありません* と表示されます。スケジュールが古いときは、右上に *⚠ スケジュールは古い状態です — 再計算 (F5)* と表示されます。
- **集計対象** — すべての割り当ての一日あたりの単位を数えます。その単位は、*曲線*（または *時間配分*）に従って、タスクの稼働日に配分されます。集計されるのは末端タスクのみです。マイルストーンは含まれません。負荷は、*計算* の後、およびリソースと割り当ての変更後に更新されます。タスクの日付を変更した場合は、*計算* の後にだけ反映されます。

## 過剰割り当て

リソースは、負荷がキャパシティより高い日に過剰割り当てになります。キャパシティは、カレンダーの稼働日では *最大単位数*（キャパシティのステップを含む）です。休日では 0 です。ここでは資材も含まれます。理由は、キャパシティが少なすぎるか、カレンダーによりリソースが稼働しない日であるかのどちらかです。

次の場所で確認できます:

- **リソース › 過剰割り当て** — 過剰割り当てのリソース数。ない場合は *なし*。
- **ステータスバー** — *N 件のリソースが過剰割り当て*。クリックすると *警告* パネルを開きます。
- **警告** — リソースごとに一行、*N 日間過剰割り当て（最初 – 最後）* が表示されます。すべての日が休日の場合は、*リソースはこれらの日、カレンダーにより稼働しません* が追加されます。一部が休日の場合は、*そのうち N 日は、カレンダーによりリソースが稼働しません* が追加されます。[通知と警告](docs://ref-meldingen) を参照してください。
- **ヒストグラム** — 棒の赤い部分と、選択一覧の赤い点。
- **ドック** — 三角 *過剰割り当て*。

山崩しは、タスクを後の日に開始させることで過剰割り当てを解消できます。既定では、プロジェクト終了日が動くことがあります。*平滑化* を使うと、プロジェクト終了日はフロートの範囲内にとどまります。山崩しは、休日に稼働する必要があるリソースを解消しません。[山崩し](docs://uitleg-nivelleren) を参照してください。
