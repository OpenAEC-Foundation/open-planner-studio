# 拡張機能の権限

拡張機能がマニフェストに記載できるすべての権限です。各権限が許可する内容、権限がない場合の動作、拡張機能をインストールするときに表示される内容を説明します。拡張機能の管理とインストールの方法は、[拡張機能のインストールと管理](docs://howto-extensie-installeren) にあります。

## 権限とは何か、何ではないか

権限とは、**作成者による申告**です。拡張機能がアプリのインターフェースのどの部分を使いたいかを示します。権限は制限ではありません。拡張機能のコードは、アプリ本体と同じ環境で動作します。そのため、権限で示した以上のことができます。サンドボックスはありません。アプリもインストール時のウィンドウでこれを伝えます。信頼できる作成者の拡張機能だけをインストールしてください。

アプリは権限を次のいずれかの方法で適用します。その違いは重要です。

**厳格に適用。** 権限がないと、該当するメソッドは何かを実行する前にエラーになります（オランダ語では、たとえば *Extensie "…" mist permissie: ribbon* と表示されます）。

**警告。** 権限がなくても、メソッドは動作します。ただし、アプリはログに警告を書き込みます。将来のバージョンでは、拒否されるようになります。

**情報のみ。** 権限はインターフェースのどの部分にも結び付いていません。アプリはインストール時にこの権限を表示しますが、ほかには何もしません。

権限が不要なものが、拡張機能のインターフェースの基本です。プロジェクト、カレンダー、タスク、関係、リソース、割り当てを読むこと。タスクと関係を追加し、タスクを変更すること。プロジェクトを読み込み、再計算し、複数の変更をまとめて行うこと。独自の設定を保持し、独自の同梱ファイルを読み、通知を表示すること。

**マニフェスト。** 権限は、マニフェストに一覧として記載されます。このアプリのバージョンが知らない権限を持つ拡張機能は、今インストールしようとすると拒否されます。すでに保存されている古い拡張機能の場合、アプリは未知の権限を取り除き、その内容をログに報告します。

## アプリが確認する方法

カタログから（*ファイル › 拡張機能 › 参照 › インストール*）、またはファイルから（*ZIP* または *JS*）インストールすると、アプリは *拡張機能をインストールしますか？* ウィンドウを表示します。この確認は、インストール時に一度だけ行われます。拡張機能を有効にするたびには行われません。

ウィンドウには、名前、バージョン、説明、作成者が表示されます。リポジトリがある場合は、それも表示されます。*入手元* の欄には、拡張機能の入手先が表示されます（*オンライン拡張機能カタログから*、*このコンピューター上の ZIP ファイルから*、または *このコンピューター上の JavaScript ファイルから*）。また、ダウンロードが検証済みかどうかも表示されます。カタログのチェックサムで検証済み、カタログにチェックサムがないため未検証、またはご自身で選んだファイル、のいずれかです。*同意する内容* の欄には、拡張機能はアプリと同じ権利で動作するプログラムコードであることが書かれています。また、実際には何を意味するかも書かれています。デスクトップアプリでは、特に、ユーザーフォルダー内のどこでもファイルを読み書きできること、そしてプロジェクト、設定、クリップボードへのアクセスです。ブラウザーでは、保存されたプロジェクトと設定へのアクセス、許可したファイルへのアクセス、そしてネットワークへのアクセスです。

*この拡張機能が使用すると申告している項目* の欄には、マニフェストの権限が、下と同じ名前の短いラベルとして表示されます。*これは作成者による申告であり、制限ではありません。コードはそれ以上のことも実行できます。* と表示されます。拡張機能に権限がない場合は、*申告なし。* と表示されます。二つの権限には説明が付きます。*importSource* と *help* です。残りの六つには、ラベルだけが付きます。

*インストール* を選ぶと、同意したことになります。*インストールしない*、Esc キー、ウィンドウの外側をクリックすると、インストールは拒否されます。

## 権限の一覧

**ribbon** — リボンにボタンを配置します。効果：拡張機能は、リボンタブのグループにボタンを追加できます。この権限がない拡張機能は、追加しようとするとエラーになります。ボタンは、選んだタブの末尾に、拡張機能のグループラベルの下で表示されます。拡張機能を無効にするか削除すると、ボタンは消えます。既定：付与されません。マニフェストに記載されたものだけです。適用方法：厳格。場所：拡張機能が選んだタブ上。

**events** — アプリのイベントを追跡し、イベントも自分で送信します。効果：拡張機能は、イベントを購読したり購読を解除したりできます。また、自分でイベントを送信することもできます。アプリ自体は四つのイベントを送信します。プロジェクトが読み込まれたとき（インポート、開く、または拡張機能による読み込みの後）、空のプロジェクトが作成されたとき、スケジュールが計算されたとき（再計算を含む）、そしてユーザーがチュートリアルを要求したときです。最後のイベントは、チュートリアル拡張機能だけに送られます。既定：付与されません。マニフェストに記載されたものだけです。適用方法：厳格。場所：どこでもありません。拡張機能がイベントに反応します。

**backstage** — インポート形式を提供します。効果：拡張機能はインポート機能を登録できます。その形式は *ファイル › インポート* に表示されます。そこで形式をクリックし、ファイルを選びます。組み込みの形式は、これとは別です（[インポートとエクスポートの形式](docs://ref-import-exportformaten) を参照）。既定：付与されません。マニフェストに記載されたものだけです。適用方法：警告。権限がなくても登録は動作しますが、ログに警告が書き込まれます。これは移行期の措置です。既存の拡張機能は、この権限を必ず記載しているとは限らないためです。場所：*ファイル › インポート*。

**pdf-fonts** — PDF エクスポート用のフォントを提供します。効果：拡張機能はフォントプロバイダーを登録できます。PDF エクスポートは、組み込みフォントに含まれない文字に、そのフォントを使います。たとえば、中国語、日本語、韓国語の文字です。既定：付与されません。マニフェストに記載されたものだけです。適用方法：厳格。場所：レポートの PDF 内。インストール時のウィンドウには、ラベルだけが表示されます。

**importSource** — インポートしたファイルの元のバイトを読み取ります。効果：拡張機能は、インポートしたプロジェクトのソースファイルの完全な内容を要求できます。現時点では、Primavera ファイルのみです。その内容には、アプリがプロジェクトに意図的に取り込まないフィールドも含まれます。たとえば、監査フィールドと来歴フィールド、コスト、レビューとロケーションのフィールドです。これは、インターフェースの他の部分よりずっと広い範囲です。そのため、別の権限になっています。この権限がないと、アプリはソースファイルのバイトを一つも読み取りません。その場合、すべてのメソッドは、何かを取得する前にエラーになります。既定：付与されません。マニフェストに記載されたものだけです。適用方法：厳格。既定では拒否されます。場所：インストール時のウィンドウに、次の説明が付きます：*importSource — インポートした各ファイルの完全な元のソースバイト (例: 生の Primavera ファイル)。プロジェクトに取り込まれないフィールドも含みます。*

**help** — ヘルプ記事とガイドを追加します。効果：拡張機能は、ヘルプ記事（チュートリアル）を登録したり取り下げたりできます。同梱の `.ifc` ファイルを新しいドキュメントとして開くこともできます。また、アプリの一部を示すガイドを開始したり停止したりできます。同梱プロジェクトが、編集中のドキュメントを上書きすることはありません。同梱プロジェクトは、新しいドキュメントとして開くか、空で変更されていないタブだけを引き継ぎます。契約バージョン 1.4.0 以降で利用できます。既定：付与されません。マニフェストに記載されたものだけです。適用方法：厳格。場所：*ヘルプ* ウィンドウ（記事）、新しいタブ（プロジェクト）、ボタンを示すガイドです。インストール時のウィンドウには、次の説明が付きます：*help — ヘルプ記事の追加、同梱プロジェクトを新しいドキュメントとして開くこと、アプリの各部分を示すガイドの表示ができます。*

**filesystem** — 拡張機能がファイルを使用すると申告します。効果：なし。インターフェースのどの部分にも結び付いていないため、アプリはこれを適用できません。既定：付与されません。マニフェストに記載されたものだけです。適用方法：情報のみ。場所：インストール時のウィンドウのラベルとして。

**network** — 拡張機能がネットワークを使用すると申告します。効果：なし。*filesystem* と同じです。既定：付与されません。マニフェストに記載されたものだけです。適用方法：情報のみ。場所：インストール時のウィンドウのラベルとして。
