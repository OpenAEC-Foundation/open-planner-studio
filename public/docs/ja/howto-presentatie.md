# 大型画面でのプレゼンテーション

目的: リボンとパネルを表示せずに、Gantt を全画面で表示します。たとえば、現場の打ち合わせでプロジェクターやテレビに表示する場合です。

## いつ必要か

現場事務所で十人が一つの画面を見ています。リボン、ステータスバー、プロパティパネルはスケジュールに必要な場所を取り、気が散ります。**プレゼンテーションモード**では、アプリは画面全体にタスクテーブルと Gantt だけを表示します。

## 手順

### 表示を準備する

プレゼンテーションモードではリボンが表示されないため、表示したい内容を事前に設定します。

1. **計算**（F5）を押して、表示される日付を正しくします。
2. 表示したい内容を設定します。たとえば、クリティカルタスクだけを表示するレイアウトを使います（[レイアウトの作成と使用](docs://howto-layouts-gebruiken) を参照）。
3. 遠くからでもタスク名が読めるタイムスケールとズームを選びます。また、*表示* タブの *アウトライン* グループにある *折りたたむ* と *展開* を使い、フェーズを折りたたむか展開します。
4. 使いたい場合は、*分割ビュー* と *ミニマップ* を有効にします（[分割ビューとミニマップの使用](docs://howto-split-view-en-mini-map) を参照）。

### プレゼンテーションを開始する

*表示 › プレゼンテーション › プレゼンテーション* を選びます。デスクトップアプリでは F11 も押せます。ブラウザでは F11 はブラウザ自体の機能です。ブラウザのウィンドウを全画面表示にしますが、アプリの表示は変わりません。リボン、タブ、ステータスバー、右側のパネルが消えます。表示されるのは、タスクテーブルと Gantt、そして有効にした場合はヒストグラムとミニマップです。画面下に数秒間、*Esc または F11 を押して全画面表示を終了します。* と表示されます。

デスクトップアプリでは、どのタブからでも F11 でプレゼンテーションを開始できます。*テーブル* や *レポート* からも開始できます。ブラウザでは *表示 › プレゼンテーション › プレゼンテーション* からのみ開始できます。常に表示されるのは、開いているプロジェクトの Gantt です。終了すると、開始したタブに戻ります。ブラウザでは、戻り先のタブは *表示* です。

### プレゼンテーションを終了する

Esc または F11 を押します。リボンとパネルは、開始したタブで再び表示されます。

## 注意点とアプリの動作

**プレゼンテーションモードでも編集できます。** クリック、ドラッグ、セルの編集、Delete は引き続き使えます。バーを誤ってドラッグすると、バーが移動し、スケジュールは最新ではなくなります。誤って削除したタスクは、プレゼンテーションモードでも Ctrl+Z で元に戻せます。そのため、複数の人と一緒に操作するときは慎重にクリックしてください。

**通知は表示されたままです。** アプリからのメッセージ（例: 保存エラー）も、プレゼンテーションモードで表示されます。このモードではリボンもステータスバーもないため、このメッセージが問題の唯一のしるしです。

**分割ビュー、ミニマップ、レイアウトは事前に設定してください。** これらにはリボンが必要で、このモードではリボンが表示されません。ズームは機能します。マウスホイール、または Ctrl+= と Ctrl+- で操作できます。+ と - も機能しますが、フォーカスが Gantt にあるときだけです。プレゼンテーションを開始した後は、フォーカスがタスクテーブルにあることが多いため、先に Gantt をクリックしてください。

**全画面表示が機能しません。** アプリはリボンを隠すだけでなく、実際に全画面表示を要求します。ブラウザやウィンドウがそれを拒否すると、リボンとパネルだけが消えます。プレゼンテーションは引き続き機能します。Esc または F11 以外の方法で全画面表示を終了すると（たとえばオペレーティングシステムのキー）、プレゼンテーションモードも終了します。

**プレゼンテーションモードは記憶されません。** アプリを閉じて再び開くと、オフになっています。
