# レポートの作成と印刷

目標：スケジュールのレポートを選び、プレビューで確認して PDF として保存します。そうすると、配布したり自分で印刷したりできます。

## 必要になる場面

金曜日は現場会議です。発注者は紙のスケジュールを求めています。現場監督は、今後数週間に何が始まるかを知りたいと考えています。職長は自分のタスクだけのシートを求めています。このような一覧は *レポート* タブで作成します。アプリはスケジュールから一覧を計算し、まずプレビューに表示します。その後、一覧を PDF にエクスポートします。

アプリはレポートをプリンターに直接送りません。最終的な出力先は常に PDF です。その PDF を PDF リーダーで印刷するか、メールで送ります。

## 手順

### 1. レポートタブを開く

リボンで *レポート* を選択するか、Ctrl+P を押します。Ctrl+P を押すと、このタブに移動します。フィールドに入力中、ダイアログが開いている、またはプレゼンテーションモードがオンの場合、Ctrl+P は機能しません。ブラウザーでは、ブラウザーの印刷ダイアログが開きます。その場合は画面が印刷され、レポートは印刷されません。

左側には *レポート* 欄があります。この欄には *レポートの種類* の一覧、概要、設定があります。右側にはプレビューがあります。

### 2. レポートの種類を選ぶ

*レポートの種類* の一覧には 十一種類のレポートがあります。質問に合うレポートを選択します。

- *ガントチャート*: 通常の配布用スケジュールとして、スケジュールを棒グラフで表示します。
- *リソース図*: 同じバーを表示しますが、リソースごとに段を表示します。「班 X は何をしていますか？」を知りたい場合に使います。必要に応じて、班ごとのシートで出力できます。
- *マイルストーン一覧*: すべてのマイルストーンを、日付と状態とともに表示します。
- *差異*: 現在のスケジュールを、アクティブなベースラインと並べて表示します。「どのくらい遅れているか？」を知りたい場合に使います。
- *先行計画*: 今後の期間に実行または開始されるもの。毎週の会議用の一覧です。
- *クリティカル／準クリティカル*: フロートがないか、ほとんどないタスクを表示します。
- *進捗レポート*: 状態日時点でのプロジェクトの状況を示します。状態日は、進捗を測定する日です。
- *スケジュール健全性*: スケジュール自体にエラーや異常な値がないかを確認します。
- *リソース負荷*: リソースごとに、週または月ごとの必要量と利用可能量を比較します。
- *リソース割当*: リソースごとに、そのリソースが割り当てられたタスクを表示します。
- *WBS サマリー*: 管理者向けに、WBS の階層ごとにスケジュールを集計します。

### 3. スケジュールが最新であることを確認する

アプリは自動では計算しません。前回の計算以降にタスク、関係、カレンダーを変更した場合は、**計算**（F5）を押します。表形式のレポートは、レポートの上部で自動的に警告します。前回の計算以降にスケジュールが変更された場合は、*前回の計算以降にスケジュールが変更されました — 最新の値を得るには「計算」(F5) を押してください。* と表示されます。一度も計算していない場合は、*未計算です — 日付とフロートを得るには「計算」(F5) を押してください。* と表示されます。

*レポート* タブのリボンには **計算** ボタンがありません。ただし、ここでも F5 は問題なく機能します。スケジュールが最新でない場合は、*PDF エクスポート* を選んだときも、アプリが先に自動で計算します。そのため、PDF がスケジュールより古くなることはありません。

### 4. レポートを調整する

*設定* には、ガントチャート（Gantt）とリソース図の選択項目があります。先行計画、クリティカル／準クリティカル、進捗レポート、スケジュール健全性、リソース負荷、リソース割当、WBS サマリーには、*用紙：* と *向き：* だけがあります。さらに、そのレポートの選択項目を含む *レポート設定* ブロックがあります。マイルストーン一覧と差異には、独自の選択項目がありません。レポートの期間については、[レポート期間の選択](docs://howto-rapportageperiode-kiezen)を参照してください。

- *用紙：* と *向き：* で用紙を決めます。既定では、A3 横向きです。建設スケジュールには便利ですが、すべてのプリンターが A3 を印刷できるわけではありません。A4 プリンターをお使いの場合は、今 A4 を選択します。そうすると、アプリはページを A4 用に配置します。後から縮小する必要はありません。
- リソース図では、チェックボックスの *リソースごとに改ページ* を選ぶと、班ごとのシートになります。
- *文字サイズ：*（90% から 125%）で、テキストと表の大きさを変えます。文字を大きくすると、タイムラインに使える場所が減ります。
- *ビューに追従（フィルター・グループ化・並べ替え）* は、ガントチャートでのみ表示されます。既定では、タスクツリー全体が用紙に出力されます。このチェックボックスを選ぶと、レポートは画面で見ている行をそのまま描きます。折りたたんだフェーズも含まれます。たとえば、レイアウトからクリティカルタスクだけを描くこともできます。そのようなビューの作り方は、[レイアウトの作成と利用](docs://howto-layouts-gebruiken) にあります。
- *ベースライン オーバーレイを表示* は、現在のバーの横にアクティブなベースラインを表示します。*ステータス線*：では、*ステータス日付線* または *進捗線* を選びます。
- *用紙に自動調整* は既定でオンです。タイムラインはページ幅に合わせて縮尺されます。ページ数は高さから決まります。オフにすると、レポートは固定の倍率を使い、幅方向にもページを分割します。そのため、ページ数がすぐに増えます。*タイムライン：* を使うと、自動調整のまま、タイムラインを横に 2 から 8 ページへ広げられます。読みやすい大きさで印刷したい長いスケジュールに向いています。

### 5. プレビューを確認する

ガントチャートとリソース図では、用紙、ページヘッダー、表、タイムライン、凡例が表示されます。ページをスクロールして確認します。*プレビュー品質* は、画面上のプレビューの鮮明さだけを変えます。PDF はこの設定によって変わりません。ページの下に *… 他 1 ページ — 完全な文書はエクスポートしてください* と表示される場合（ページ数が多い場合は *… 他 2 ページ — 完全な文書はエクスポートしてください*）、プレビューにはまだすべてのページが準備されていません。PDF にはすべてのページが含まれます。

そのほかのレポートは、画面に表として表示されます。表示されている内容が、そのまま PDF に含まれます。

### 6. PDF にエクスポートする

左の欄の下部で、**PDF エクスポート** をクリックします。提案されるファイル名は、プロジェクト名とレポートの種類を続けたものです。ガントチャートの場合は、たとえば *Extension house-planning.pdf* です。

- デスクトップアプリと、ファイルの保存ダイアログがあるブラウザーでは、PDF の保存先を選びます。保存せずにダイアログを閉じると、何も起こりません。
- 保存ダイアログがないブラウザーでは、ブラウザーが PDF をダウンロードフォルダーに保存します。

### 7. PDF を印刷する

PDF リーダーで PDF を開き、そこで印刷します。A3 の PDF を A4 プリンターで印刷すると、印刷ダイアログでページを縮小する必要があります。そのため、手順 4 で先に用紙サイズを設定してください。

## 注意点とアプリの動作

**印刷ボタンと Ctrl+P では印刷されません。** *レポート* グループの *印刷* ボタンは、レポートタブ自体にあり、ほかには何もしません。Ctrl+P を押すと、このタブに移動します。アプリには別の印刷コマンドがありません。用紙への出力は PDF を経由します。Ctrl+P が機能しない場合（手順 1 を参照）は、ブラウザーの印刷ダイアログが開きます。その場合は画面が印刷され、レポートは印刷されません。

**会社：上書きした内容は保持されません。** ガントチャート（Gantt）の *会社：* フィールドには、最初にプロジェクト設定の会社が入っています。ここに入力した内容は保持されません。ここでは *作成者：* を入力できません。両方を変更するには、*設定 › プロジェクト › プロジェクト設定* を開き、*発注者/組織* と *作成者* のフィールドに入力して、*適用* で確定します。

**バーの色：画面にも適用されます。** レポートの *バーの色：* の選択は、表示タブの *バーの色* と同じ設定です。レポートでこれを変更すると、画面のガントチャートも変わります。

**ベースラインがない場合の差異。** ベースラインとは、後で比較するために保存したスケジュールのスナップショットです。保存方法は、[ベースラインの保存と管理](docs://howto-baseline-opslaan-en-beheren) にあります。アクティブなベースラインがない場合、比較の代わりに *アクティブなベースラインがありません — ベースラインを保存するか、いずれかをアクティブに設定してください。* と表示されます。

**ステータス線：状態日がない場合。** プロジェクトに状態日がない状態で *ステータス線*：を選ぶと、レポートは *先にステータス日付を設定してください* と警告し、何も描きません。状態日は、*計画 › ベースラインと進捗 › ステータス日付* で設定します。

**スケジュールにループがあります。** スケジュールにループが含まれる場合、*PDF エクスポート* はファイルを作成せず、エラーを表示します。

**用紙は現在すべてのレポートに適用されます。** *用紙：* と *向き：* の選択は一つだけで、すべてのレポートで共有されます。マイルストーン一覧と差異には、独自の用紙の選択がありません。そのため、ほかのレポートで設定された値を使います。既定では A3 横向きです。そこで、先に用紙を選択できるレポート（たとえばガントチャート）で用紙を選び、その後で元のレポートに戻ります。

**設定は、すべてのプロジェクトに適用されます。** 用紙、文字サイズ、期間、そのほかの選択は、このデバイス上でアプリに記憶され、すべてのプロジェクトで使われます。これらはプロジェクトファイルには含まれません。
