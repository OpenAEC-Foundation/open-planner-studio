# Primavera P6 ファイル (.xer) を開く

目的：Primavera P6 のスケジュールを、先に XML へエクスポートせずに、アプリで直接開きます。

## この機能が必要な場合

顧客または元請け業者は Primavera で作業し、スケジュールを `.xer` ファイルとして提供します。それを表示したり、計算したり、追加したりしたくなります。アプリは `.xer` ファイルを読み取るだけです。`.xer` への書き込みは行わず、お使いのファイルを変更することもありません。ファイルからは、WBS の構造と、期間、日付、制約、進捗を持つタスク、ラグ付きの関係、カレンダー、割り当て付きのリソースを読み取ります。さらに、アクティビティコード、カスタムフィールド（UDF）、メモ、P6 のスケジュール設定も読み取ります。タイプが *工数量ベース* のタスクは、ハンモックになります。

## 手順

1. *ホーム › ファイル › 開く* を選択するか、Ctrl+O キーを押します。`.xer` ファイルを選択します。
2. アプリは、タスクを持つプロジェクトごとに一つのタブを開きます。タスクが最も多いプロジェクトが、アクティブなタブになります。P6 のプロジェクト ID が名前と異なる場合、タブ名は *プロジェクト名（プロジェクト ID）* になります。*プロジェクト設定* に表示されるのは名前だけです。プロジェクト名を変更しても、プロジェクト ID はその後ろに残ります。その後、アプリがファイルから引き継いだ内容と保存の仕組みを簡単に説明するウィンドウが表示されます。詳しくは [ファイルを開いて保存する](docs://howto-bestand-openen-en-opslaan) を参照してください。
3. 下部のメッセージを読みます。プロジェクトが三つあるファイルの場合、次のように表示されることがあります：*XER ファイルを開きました: プロジェクト文書 3 件。* その下には、アプリが行ったことを説明する行があります。詳しくは下の見出しを参照してください。
4. リボンの下に帯状のメッセージがあるか確認します：*Primavera が記録したスケジュールを表示しています。再計算すると 1 件のタスクがずれます。* Primavera は、自身が計算した日付をファイルに記録します。アプリの計算がそれらと異なる場合、変更しなければ、アプリは Primavera の日付を表示します。着手済みまたは完了したタスクは、Primavera と同じく必ず実績日に固定されます。その意味と、アプリ自身の計算への切り替え方は [記録どおりの日付](docs://uitleg-datums-zoals-opgeslagen) に記載されています。メッセージ *このファイルには時間単位の計画が含まれています。* が、ボタン *時間計画を有効にする* と一緒に表示されることもあります。詳しくは [時間計画を有効にする](docs://howto-urenplanning-aanzetten) を参照してください。
5. Ctrl+S でプロジェクトを保存します。`.xer` は上書きされないため、アプリは新しい IFC ファイルの保存先を尋ねます。ファイル名として *プロジェクト名（プロジェクト ID）* を提案します。

### メッセージの下の行

メッセージの最初の行には、開いたタブの数が示されます。その下には、該当する行だけが表示されます。特に注意が必要な行は次のとおりです：

- *このプロジェクトは Primavera P6 として計算されます。変更は ファイル → プロジェクト情報 → 計算プロファイルとオプション で行えます。* アプリは、このプロジェクトを Primavera の計算ルールで計算します。*計算プロファイルを開く* を選ぶと、その設定に移動します。
- *除外したベースラインプロジェクト: 1* と *具体化したベースライン: 1*。P6 のプロジェクトが別のプロジェクトをベースラインとして指定すると、指定されたプロジェクトは独自のタブとしては開きません。それは、それを参照しているプロジェクトの有効なベースラインになります。
- *保護的なベースラインのフォールバックを使用しました。* ベースラインを指定すると、どのプロジェクトも開けなくなる場合、プロジェクトが自分自身を参照する場合、またはプロジェクト同士が循環して参照し合う場合は、アプリは単にすべてのプロジェクトを開き、ベースラインを作成しません。
- *外部関係を保持: 1*。二つのプロジェクト間の関係です。アプリはそれをソースデータとして保持しますが、スケジュールの関係にはしません。
- *Primavera が記録した日付をそのまま表示しているタスク: 12 件（再計算していません）*。*記録どおりの日付* ビューで Primavera の日付が表示されているタスクの数です。ファイルに日付が記録されているタスクは、差があるものだけでなく、すべて対象です。

それ以外の行は、読み取り自体の診断です。これらの行で操作は必要ありません：

- 見つかったプロジェクトの数
- スキップした空のプロジェクト
- 無視した、参照先のないベースライン参照
- プレーンな UTF-8 以外のテキストエンコーディング（通知には、どのエンコーディングかが書かれています。アラビア語、キリル文字、ギリシャ語のテキストでは、アプリは対応する Windows のコードページを選び、それ以外では Windows-1252 を選びます）
- 計画された開始日のないタスク（ファイルの状態日またはプロジェクト開始日から開始されます）
- テーブル、カレンダー、数値で見つかった件数、不明なフィールド値、アプリが安全な選択肢に置き換えた P6 の計画設定の件数

*詳細を見る* を選択すると、Primavera ファイルを開くことに関するヘルプが開きます。

## 注意点と、その場合にアプリが行うこと

**すべてがタブや関係になるわけではありません。** タスクのないプロジェクトは開かず、ベースラインのプロジェクトは独自のタブとしては開かず、二つのプロジェクト間の関係はスケジュールの関係にはなりません。アプリは、その内容をメッセージの下の行で知らせます。

**どのタブも、それぞれ独立したプロジェクトです。** 一つ保存すると、IFC ファイルには元の `.xer` が完全な形で残ります。後でその IFC ファイルを開き直しても、アプリは Primavera の日付をまだ把握しています。そのソースアーカイブが壊れている場合、または別の IFC プログラムがファイルを書き換えた場合、アプリは次のように知らせます：*このファイルの XER ソースアーカイブは使用できないため除外しました。プロジェクト自体はすべて開かれています。* スケジュール、計算プロファイル、すべてのプロジェクトデータは揃っています。不足しているのは、Primavera が保存していた日付と、AI および拡張機能向けのソースの出所情報です。アーカイブを取り戻すには、元の `.xer` をもう一度開いてください。

**IFC ファイルは大きくなります。** IFC ファイルには元の `.xer` 全体が含まれるため、アーカイブのない IFC ファイルより大きくなります。大きな `.xer` の場合は、ファイルサイズと保存にかかる時間でそれが分かります。一つの `.xer` から複数のプロジェクトが開かれた場合、保存したタブはそれぞれ、自分のプロジェクトだけでなく `.xer` 全体を持ちます。

**CSV、MS Project XML、P6 XML へのエクスポートでは、データが失われます。** アプリは次のように警告します：*CSV へのエクスポートでは XER のソース情報が失われます。* IFC では何も失われません。

**ファイルにない、作業のない土曜日または日曜日。** アプリは、その週末の日を自動的に作業のない日にできます。その場合、その日はカレンダーで *カレンダーの例外（週末の再構成）* と呼ばれます。そのパターンは [インポートとエクスポートの形式](docs://ref-import-exportformaten) に記載されています。

**終了日がないときのプロジェクト終了日までのフロート。** ファイルに終了日がない場合、アプリはオプション *プロジェクト終了日までのフロートを計算* をオフにします。これは、*安全なフォールバックを使った P6 計画設定: N* の行で数えられます。詳細は [インポートとエクスポートの形式](docs://ref-import-exportformaten) に記載されています。

**状態日にある完了済みのタスク。** 完了したタスクは、*記録どおりの日付* ビューで、状態日に細いバーとして表示されることがあります。これはファイルの誤りではありません。説明と関連する規則は [インポートとエクスポートの形式](docs://ref-import-exportformaten) に記載されています。

**小数点にカンマを使う数値。** アプリが小数点の記号を確実に判定できない場合、ファイルは開きません。そうすることで、誤って読み取られた数値を含むスケジュールが開かれることはありません。送り主に新しいエクスポートを依頼してください。

**アプリが読み取れないファイル。** 理由を示すエラーメッセージが表示されます。次に例を示します：

- *これは有効または対応済みの XER ファイルではありません。*
- *XER テーブルに必須列がありません。*
- *この XER ファイルの P6 プロジェクトにはアクティビティがありません。*
- *この XER ファイルの小数表記を確実に判定できません。*

その場合、何も開きません。P6 でファイルを確認するか、送り主に新しいエクスポートを依頼してください。
