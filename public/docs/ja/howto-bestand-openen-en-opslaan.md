# ファイルを開いて保存する

目的：ファイルからプロジェクトを開き、変更を保持します。

## 必要になるとき

前日のプロジェクトで一日を始めるとき、同僚や別のパッケージからファイルを受け取ったとき、または大きな変更の前に途中の状態を残したいときに必要です。アプリがファイルに保持する内容と、IFC だけがプロジェクト全体を保持する理由は、[ファイルと形式](docs://uitleg-bestanden) で説明しています。

## 手順

### ファイルを開く

1. *ホーム › ファイル › 開く*、*ファイル › 開く*、または Ctrl+O を押します（Mac では ⌘+O）。*ファイル* グループは *テーブル* タブにもあります。
2. ファイルを選択します。一度に開くのは 1 つのファイルだけです。デスクトップアプリと、Chrome や Edge などのように、ファイルへのアクセスに対応しているブラウザーでは、ウィンドウにファイルの種類の一覧が表示されます：*対応形式すべて*、*IFC ファイル*、*CSV ファイル*、*XML ファイル*、*MS Project ファイル*、*Primavera XER ファイル*。
3. プロジェクトは新しいタブで開きます。現在のタブがまだ空で、変更されていない場合は、プロジェクトはそのタブで開きます。
4. ファイルが IFC ではない場合、そのファイル形式の簡単な説明を含むウィンドウが表示されます。緑のブロックには、アプリが引き継いだ内容が、オレンジのブロックには、含まれなかった内容または一部だけ含まれた内容が、青のブロックには、保存と書き戻しの動作が示されます。*詳細を見る* を選ぶと、その形式のガイドが開きます。*了解* をクリックして、ウィンドウを閉じます。この説明を今後表示したくない場合は、先に *… について今後表示しない* にチェックを入れます。表示を再びオンにするには、[アプリの設定](docs://ref-instellingen) の *詳細設定* タブで設定します。

IFC ファイルの場合、タブにはそのファイル名が付きます。ほかの形式のプロジェクトの場合、タブにはプロジェクト名が付きます。

アプリは `.ifc`、`.csv`、`.xml`（MS Project XML または Primavera P6 XML）、`.mpp`、`.xer` を開きます。最後の 2 つには、別々の手順があります：[MS Project ファイル (.mpp) を開く](docs://howto-mpp-openen) と [Primavera P6 ファイル (.xer) を開く](docs://howto-xer-openen)。

### 最近のプロジェクトを開く

*ホーム › ファイル › 最近* を選び、一覧のファイルをクリックします。または、*ファイル › 最近* を選びます。一覧には、最後に開いた、保存した、またはエクスポートした 10 件のファイルが残ります。ここでも、IFC ではないファイルの場合は、その形式の説明が続きます。デスクトップアプリでは、各ファイルのパスが表示されます。ブラウザーでは、ファイル名だけが表示されます。

アプリが一覧のファイルをもう読めない場合（たとえばファイルを移動した場合）、そのファイルはメッセージなしで一覧から消えます。ファイルへのアクセスに対応しないブラウザー（Firefox など）では、*最近* は空のままです。

### サンプルを開く

*ファイル › サンプル* を選び、サンプルプロジェクトをクリックします。プロジェクトは、ファイルなしでタブに開きます。そのため、*保存* を選ぶと、アプリは保存先を尋ねます。

### 保存

*ホーム › ファイル › 保存* または *ファイル › 保存* を選ぶか、Ctrl+S を押します。その後の動作は、プロジェクトの状態によって決まります：

1. プロジェクトにすでにファイルがある場合（IFC ファイルを開いた場合、または以前に保存した場合）、アプリはそのファイルに書き込みます。ウィンドウは表示されません。例外は、IFC 4.3 ADD2 以外の IFC スキーマを持つファイルを初めて保存する場合です。その場合、アプリは先に *どの IFC スキーマで保存しますか？* と尋ねます。詳細は [IFC スキーマの選択](docs://howto-ifc-schema-kiezen) を参照してください。
2. プロジェクトにまだファイルがない場合、アプリは保存先を尋ねます。プロジェクト名に `.ifc` を付けた名前が提案されます。その後、そのファイルがプロジェクトのファイルになります。
3. ブラウザーがダウンロードとしてだけ保存できる場合（Firefox など）、ファイルはダウンロードフォルダーに保存され、保存のたびに新しいダウンロードが作られます。セッションで初めて、次のメッセージが表示されます：*ダウンロードとして保存しました：'name.ifc' はダウンロードフォルダーにあります。このブラウザーでは、アプリが独自の場所に書き込めないため、保存のたびに新しいダウンロードが作られます。Chrome、Edge、またはデスクトップアプリでは、保存は同じファイルを更新するだけです。*
4. ブラウザーがプロジェクトのファイルに書き戻せない場合、アプリは保存のたびに、ファイルの置き場所を改めて尋ねます。これは *名前を付けて保存* に似ていますが、ブラウザーの制限によるものです。セッションで初めて、メッセージ *このブラウザーでは、アプリが 'name.ifc' に書き戻せません。* がこの点を説明します。説明には [ファイル](docs://uitleg-bestanden) へのリンクがあります。

保存後、*未保存* の印が消えます：タブの点、画面上部のプロジェクト名の前にあるアスタリスク、およびステータスバーの右下にある *未保存* という文字です。

### 別の名前で保存

*ホーム › ファイル › 名前を付けて保存* または *ファイル › 名前を付けて保存* を選ぶか、Ctrl+Shift+S を押します。名前と場所を選びます（Firefox では、アプリは代わりに新しいファイルをダウンロードします）。その後、プロジェクトはこの新しいファイルで動作します。次の *保存* は、そのファイルに書き込みます。以前のファイルは、前回保存したときの状態のまま残ります。

### プロジェクトを閉じる

タブの × をクリックするか、*ファイル › プロジェクトを閉じる* を選びます。保存していない変更があるプロジェクトの場合、アプリは次のメッセージで確認します：*未保存の変更：'name' に、まだ保存されていない変更があります。* 次のいずれかを選びます：*キャンセル*（プロジェクトは開いたままになります）、*保存しない*（プロジェクトは閉じられ、変更は失われます）、または *保存*（先に保存してから閉じます）。デスクトップでアプリ全体を閉じる場合（閉じるボタン、Alt+F4、またはオペレーティングシステムのメニューを使う場合）、アプリは変更のあるプロジェクトごとにこの確認を行います。*キャンセル*、または保存が失敗した場合は、閉じる操作が止まります。このような通常の終了のあと、アプリはそのセッションの復旧用コピーを削除します。そのため、復旧ウィンドウは本当のクラッシュのあとにだけ表示されます。変更のあるプロジェクトがあるときに、ブラウザーのタブまたはウィンドウを閉じると、ブラウザーが確認を求めます。

## 問題が起きた場合と、アプリの動作

**開いた IFC ファイルは、すぐにプロジェクトのファイルになります。** *保存* は、別のプログラムから来たファイルでも、そのファイルを上書きします。元のファイルを残したい場合は、先に *名前を付けて保存* を選びます。

**ほかの形式のファイルは、決して上書きされません。** `.csv`、`.xml`、`.mpp`、`.xer` は、開いたあとはファイルとの紐づけがありません。*保存* は新しい IFC ファイルを書き込み、元のファイルはそのままにします。

**Firefox では、保存のたびに新しいファイルができます。** このブラウザーでは、アプリは開いたファイルに書き込めません。そのため、保存のたびに新しいファイルをダウンロードします。ファイル名は、開いたファイルの名前ではなく、プロジェクト名になります。

**Chrome と Edge では、許可を求められます。** 開いたファイルを初めて *保存* するとき、ブラウザーは、アプリがそのファイルに書き込んでよいかを尋ねます。拒否すると、アプリは新しいファイルを選ぶためのウィンドウを開きます。Chrome と Edge では、既存のファイルへの書き込みに失敗した場合（たとえば、ファイルが消えた場合やロックされている場合）にも、このウィンドウが開きます。

**重複した ID や、計算に入らない関係についてのメッセージ。** 開いたあと、メッセージが画面に残ることがあります。*このファイル内で ID が重複しているオブジェクト* と表示される場合、重複したオブジェクトにはそれぞれ新しい ID が付けられ、参照は最初に出現したものを指します。その場合は、関係と割り当てを確認します。*計算に含めることができない関係* と表示される場合、その関係はサマリータスクに置かれていて、効果がありません。たとえば、タスクを自身のサマリータスクにリンクしている場合です。ファイル自体は変更されません。サマリータスクに置いた関係の動作については、[関係](docs://uitleg-relaties) を参照してください。

**保存に失敗することがあります。** 保存自体がエラーを返すと、アプリは理由とともに *保存できませんでした* と表示します。プロジェクトは開いたままで、まだ *未保存* の印が付いています。
