# レイアウトの作成と使用

目的：ワンクリックでスケジュールの表示を切り替えます。たとえば、クリティカルタスクだけ、班ごとのタスク、別の並べ替え順などです。

## 必要になる場面

現場会議で、発注者はクリティカルタスクだけを見たいと考えています。次に現場監督は、班ごとに誰がいつ必要かを確認したいと考えています。その後、スケジュール全体をもう一度表示したくなります。フィルター、グループ化、並べ替えを何度も設定し直すのは手間がかかります。**レイアウト**は、このような表示をリボンのボタンとして保存します。

レイアウトには六つの項目を保存できます。フィルター、グループ化、並べ替え、Gantt の横にあるタスクテーブルの列、タイムスケール、関係線とオーバーレイ（ベースライン、進捗ライン、状態日の線、リソースの強調表示、フロートの帯、バーの色）です。ボタンをクリックすると、チェックを入れた項目だけが変わります。表示のそれ以外の部分はそのまま残ります。

フィルター、グループ化、並べ替えは、レイアウトで行います。個別のボタン *フィルター…*、*グループ化…*、*並べ替え…* は、今は非表示の設定の裏にだけ残っています（後述の注意点を参照）。

## 手順

### 既存のレイアウトを使う

1. *表示* タブを選択します。*レイアウト* グループに、レイアウトごとに一つのボタンがあります。既定では *リソース図* です。
2. クリックします。*リソース図* は、タスクをリソースごとにグループ化し、各グループ内を開始日順に並べ替え、関係線をオフにします。リソースを二つ持つタスクは、両方のグループに表示されます。
3. もう一度クリックすると、レイアウトがオフになります。表示は、クリックする前の状態に戻ります。

一回のクリックが、*元に戻す*（Ctrl+Z）の一手順として扱われます。オンにする操作もオフにする操作も同様です。

### 独自のレイアウトを作る

1. *レイアウト* グループで、*新規レイアウト* をクリックします。*新規レイアウト* ウィンドウが開きます。
2. *名前* を入力し、*アイコン* を選択します。
3. *このレイアウトは何を保存しますか？* の下に、チェックボックス付きの六つの項目があります。新しいウィンドウでは、すべての項目にチェックが入った状態で始まり、今の画面の内容が入ります。レイアウトで変えてはいけない項目は、すべてチェックを外します。フィルターだけが必要な場合は、*フィルター* だけにチェックを入れたままにします。*現在の表示を取り込む* を押すと、すべての項目が今の画面の内容で再び埋められます。
4. 項目を設定します。
5. *保存* をクリックします。

レイアウトはリボンのボタンになりましたが、まだ適用されていません。ボタンをクリックして、オンにします。

### フィルターを設定する

*フィルター* の下で、ルールを作成します。*+ ルール* をクリックし、*フィールド*、*演算子* と値を選択します。クリティカルタスクだけを表示したい場合は、フィールド *クリティカル*、演算子 *次と等しい*、値 *はい* を選びます。フィールドには、*タスク名*、*開始*、*終了*、*トータルフロート*、*進捗*、*マイルストーン* のほか、独自のアクティビティコードやフィールド、そして *リソース* があります。演算子はフィールドの種類によって変わります。テキストの場合は *次を含む* を選べます。数値と日付の場合は *次の範囲内* を選べます。

表示される演算子は、フィールドの種類によって異なります：

- テキスト（*タスク名*、*WBS*）：*次と等しい*、*次と等しくない*、*次を含む*、*次で始まる*、*空である*。
- 数値と日付（*トータルフロート*、*開始*、*進捗*）：*次と等しい*、*次と等しくない*、*次より小さい*、*次以下*、*次より大きい*、*次以上*、*次の範囲内*、*空である*。*次の範囲内* を選ぶと、二つのフィールドが表示されます。数値の場合、ヒントとして *開始日* と *終了* が表示されます。日付の場合はヒントがありません。一つ目の日付が開始、二つ目の日付が終了です。
- はい/いいえ（*クリティカル*、*マイルストーン*、*準クリティカル*）：*次と等しい* と *次と等しくない*。値は *はい* または *いいえ*。
- 選択肢（*作業区分*、アクティビティコード）：*次と等しい*、*次と等しくない*、*次のいずれか*（チェックボックスで値を選ぶ）、*空である*。
- *リソース*：*次のいずれか* と *空である*。
- *進行中*：*次の範囲内* のみ。二つの日付（開始と終了）を入力します。

フィールド *進行中*、演算子 *次の範囲内*、二つの日付を指定すると、その期間のいずれかの時点で進行中のすべてのタスクが表示されます。たとえば、六月に進行中のすべてのタスクです。

複数のルールは、上の一覧で組み合わせます。*すべて一致 (AND)* は、すべてのルールを満たすタスクを表示します。*いずれかに一致 (OR)* は、少なくとも一つのルールを満たすタスクを表示します。*+ グループ* を選ぶと、独自のルールを持つサブグループを追加できます。

フィルターは、タスクそのものを判定します。そのタスクが属するフェーズ（サマリータスク）は、グレーで表示されたままなので、タスクの所属先がわかります。グループ化も設定している場合、そのグレーのフェーズは表示されなくなります。

### グループ化と並べ替え

*グループ化* の下で、*+ レベル* を使ってフィールドを追加します。グループ化のレベルは最大二つです。グループ化しない場合は、WBS ツリーが表示されます。*並べ替え* の下で、*+ レベル* を使ってフィールドを追加し、*昇順* または *降順* を選びます。二つのレベルがある場合、一つ目の値が同じときは二つ目で順序が決まります。

### ボタンなしで素早く試す

ウィンドウで *保存せずに適用* をクリックします。チェックを入れた項目が画面に適用されますが、ボタンは追加されません。一回だけ必要なフィルターに便利です。Ctrl+Z で取り消せます。

### レイアウトの変更、複製、削除

レイアウトのボタンを右クリックします。*編集…*、*複製*、または *削除* を選択します。*削除* を選ぶと、先に確認が表示されます。コピーの名前は、元の名前に *（コピー）* を付けたものになります。組み込みのレイアウト（たとえば *リソース図*）は、編集も削除もできません。独自のバージョンを作るには、複製します。

### 複数のレイアウトを同時に使う

同じ項目を保存していないレイアウトは、同時にオンにできます。フィールド *クリティカル*、演算子 *次と等しい*、値 *はい* のフィルターだけを保存するレイアウトがあるとします（例：*クリティカルのみ*）。それを *リソース図*（グループ化、並べ替え、関係線）と同時にオンにすると、リソースごとのクリティカルタスクが表示されます。同じ項目、たとえば両方ともフィルターを保存している場合は、二つ目のレイアウトが引き継ぎ、一つ目はオフになります。その二つ目のレイアウトをもう一度オフにすると、最初のクリックの前の表示に戻ります。一つ目のレイアウトには戻りません。

## 注意点と、アプリの動作

**チェックを外し忘れることがあります。** 列、タイムスケール、オーバーレイも保存しているレイアウトは、クリックするたびに、それらを保存時の状態に戻します。フィルターだけを使いたいのに、ズームが急に変わってしまいます。ウィンドウで、意図した項目だけにチェックが入っているか確認してください。

**未設定のルールは何も表示しません。** はい/いいえのフィールドで値を選ばなかった場合（まだ *—* と表示されている）、または *進行中* の日付を空欄のままにした場合、一致するタスクはなく、一覧は空のままです。ルールの設定を終えてください。

**手動で変更すると、レイアウトはオフになります。** レイアウトが保存している項目を自分で変えると、そのレイアウトはオフになります。たとえば *リソース図* がオンのときに *関係線* を変えると、そのレイアウトは外れ、ほかの項目はレイアウト適用前の表示に戻ります。タイムスケールを保存しているレイアウトは、ズームするとオフになります。列の幅を広げると、列を保存しているレイアウトがオフになります。表示のほかの部分はそのままです。*リソース図* はタイムスケールを保存しないため、ズームしても影響を受けません。

**列は Gantt の横にあるタスクテーブルに適用されます。** *列* の項目には、タイムラインの左にある表の列が保存されます。*テーブル* タブの表は、独自の列を保持します。列の選び方は [列の調整](docs://howto-tabelkolommen-aanpassen) に説明があります。

**インデントとインデント解除は無効になります。** フィルター、グループ化、並べ替えのいずれかがオンの間は、表示されている順序はスケジュールの順序ではありません。そのため、*インデント* と *インデント解除* は無効になり、ツールチップに *フィルター/グループ化/並べ替え中は使用できません* と表示されます。構造を再び調整するには、レイアウトをオフにします。詳しくは [構造の調整](docs://howto-structuur-aanpassen) を参照してください。

**ステータスバーは追従しません。** ステータスバーの *タスク：* は、フィルターで一部のみ表示されている場合でも、プロジェクト全体のタスク数を表示します。

**レイアウトはプロジェクトではなく、お使いの端末に保存されます。** アプリは、お使いの端末で、すべてのプロジェクトのレイアウトと列を保存します。レイアウトのオーバーレイ（ベースライン、進捗ライン、その他）は、すべてのプロジェクトに適用されます。今オンになっているフィルター、グループ化、並べ替えは開いているプロジェクトに属しますが、プロジェクトファイルには保存されません。保存して開き直すと、表示はまた何も設定されていない状態に戻ります。これらはプロジェクトを「変更済み」にもしません。

**個別のボタンは非表示になっています。** *列…*、*フィルター…*、*グループ化…*、*並べ替え…* は、*表示* タブの個別のボタンで、古い表示方式です。*アプリ設定* ウィンドウ（タイトルバーの ⚙）の *詳細設定* タブ、*レガシー機能* の下にある *従来の表示ボタンを表示* で、これらを再び表示できます。レイアウトを使うことをお勧めします。
