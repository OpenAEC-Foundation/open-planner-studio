# タスク種類の選び方

目標：タスクごとに、期間、単位数、または作業を変更したときに、アプリが何を調整するかを設定します。調整するのは、期間、単位数、作業のいずれかです。

## 必要になる場合

タスクにリソースを割り当てました。アプリに、自分の計算方法どおりに計算させたいとします。例：クレーンを一日借りていて、その日は固定です。もう一つの例：れんが積みに 160 時間かかることがわかっています。二人の代わりに三人で、どのくらいの期間がかかるかを見たいとします。この二つの状況には、異なるタスク種類が必要です。

タスク種類は、別の量を変更したときに、期間、単位数、作業のどれが一緒に動くかを決めます。背景と作業例は [タスク種類：期間、単位数、作業](docs://uitleg-werkregels) にあります。

## 手順

### タスク種類を表示する

タスク種類は既定では表示されません。一度だけオンにします：

1. *設定 › プロジェクト › アプリ設定* を選びます。タブ *計画* を選びます。
2. 見出し *計算* の下で、*タスク種類を使用* にチェックを入れます。
3. *閉じる* で、ウィンドウを閉じます。

これはアプリの設定です。プロジェクトファイルの設定ではありません。ファイルにすでにタスク種類や保存された作業がある場合（たとえば MS Project または Primavera P6 のファイル）、この設定がなくても、アプリはそのファイルのタスク種類を表示します。ファイルでタスク種類を自分で選んだ場合も同じです。その場合、設定をオフにしても、そのファイルでは表示がオンのままになります。表示は、ファイルを開いている間はオンのままです。再度開いたあとも、ファイルにタスク種類または保存された作業がある限りオンのままです。

### タスクのタスク種類を設定する

1. タスクを選択します。*プロパティ* パネルは右側にあります。見えない場合は、*表示 › パネル › プロパティ* でオンにします。
2. *タスク種類* で、五つの選択肢のいずれかを選びます：*プロジェクトの既定（固定期間・固定単位）*、*固定期間・固定単位*、*固定期間・固定作業*、*固定作業*、または *固定単位*。*プロジェクトの既定* を選ぶと、タスクはプロジェクトの既定に従います。
3. 選択肢の働きを知りたい場合は、開いたドロップダウンで各選択肢に i アイコンがあります。それにポイントするか、クリックまたはタップすると説明が表示されます。i アイコンをクリックしても、そのタスク種類はまだ選ばれません。
4. 閉じた欄の横にも i アイコンがあります。これは今適用されているタスク種類を説明します。例：*期間は作業と単位数から決まります。* *プロジェクトの既定* の場合は、かっこ内のタスク種類が説明されます。

*プロジェクトの既定* は最初の選択肢で、タスクが既定で持つ値です。かっこ内のタスク種類は、プロジェクトに現在設定されている既定です。アプリには、この既定を変更するボタンはありません。既定は、インポート（たとえば MS Project または Primavera P6 からのインポート）か、MCP 接続で決まります。一つのタスクだけ別のタスク種類にしたい場合は、ここで選びます。

テーブルでもタスク種類を選べます。タスクテーブルのヘッダーの右にある **+** をクリックします（*列を追加*）。*計画* の下で、*タスク種類* 列を選びます。

割り当てのないタスクでは、まとめるものがないため、タスク種類は何もしません。先にリソースを割り当ててください（[曲線を使ったリソースの割り当て](docs://howto-resource-toewijzen) を参照）。

### 作業を確認して変更する

割り当てのあるタスクでは、*プロパティ* パネルの *割り当て* ブロックに、*単位数* の隣に *作業 (h)* 列が表示されます。これは、そのリソースの残作業を時間で示します。列の上の小さな南京錠は、タスク種類が何を固定しているかを示します。*固定期間・固定単位* と *固定単位* では *単位数* に、*固定期間・固定作業* と *固定作業* では *作業 (h)* に南京錠が付きます。

作業を自分で変更する場合は、欄に時間を入力して Enter を押します。アプリは 0 以下の値を受け付けません。その場合、欄は前の値に戻ります。

### 結果を確認する

タスク種類を選んでも、まだ数値は変わりません。作業を保護するタスク種類では、アプリは現在の作業を固定するだけなので、*作業 (h)* に保存された値があります。次の変更で初めて、タスク種類がどの値を一緒に動かすかを決めます。たとえば *単位数* を変更して、期間と作業にどう影響するかを確認します。

この変更でタスクの期間が変わると、ステータスバーに *古くなっています — 再計算してください（F5）* と表示されます。**計算**（F5）を押します。たとえば *ホーム › スケジュール › 計算* から実行できます。新しい日付が表示されます。*自動計算* がオンの場合（同じ *計画* タブ、見出し *計算*）、アプリが自動で実行します。

## どのタスク種類が合うか

- **固定期間・固定単位** は、期間が取り決めで、単位数を自分が入力する場合に合います。作業は、この二つから決まります。これが既定です。一日だけ借りたクレーンはここに当てはまります。日は固定で、その日に何台のクレーンを置くかは自分で決めます。
- **固定期間・固定作業** は、タスクを固定期間内に終える必要があり、作業量がわかっている場合に合います。期間が変わると、アプリが単位数を調整します。
- **固定作業** は、作業時間がわかっていて、人数によって期間がどう変わるかを見たい場合に合います。二人の代わりに三人で行う 160 時間のれんが積みは、ここに当てはまります。練習用プロジェクトの plastering には、このタスク種類が設定されています。
- **固定単位** は、単位数が固定で（たとえばクレーン一台）、作業量によって期間が決まる場合に合います。

## 落とし穴とアプリの動作

***タスク種類* 欄が表示されません。** この場合、*タスク種類を使用* の設定がオフで、ファイルにまだタスク種類がないか、マイルストーン、フェーズ、ハンモック、または期間の種類が *経過時間* のタスクを選択しています。そこにはタスク種類はありません。通常のタスクを選択してください。

**自分が変えていないのに期間が変わります。** *固定作業* と *固定単位* では、期間は単位数と作業から決まります。どちらか、またはリソースの人数を変えると、アプリは期間を調整します。その際、期間は稼働日単位で切り上げられます。時間単位のタスクでは、アプリは分単位で切り上げます。

**作業が単位数 × 期間と正確に一致しません。** 丸めが原因で起こることがあります。*作業 (h)* の横に警告マークが表示されます：*単位 × 期間と一致しません*。ヒストグラムは保存された作業に従います。

**資材は数えられません。** 資材リソースの場合、*作業 (h)* にはダッシュが表示されます。資材が期間を決めることはありません。

**進捗のあるタスク。** タスク種類は残りの部分に対して働きます。そのため *作業 (h)* には、まだ行う必要がある分だけが表示されます。

**元に戻す。** タスク種類を選ぶこと、およびタスク種類が計算する変更はすべて、*元に戻す*（Ctrl+Z）で一回で戻せます。そのあとタスク種類は解除されますが、*タスク種類* 欄は表示されたままです。
