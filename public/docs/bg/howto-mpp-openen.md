# Отваряне на файл от Microsoft Project (.mpp)

Цел: отворете график от MS Project директно в приложението, без да го експортирате първо.

## Кога ви е нужно

Изпълнител, консултант или клиент Ви изпраща графика си като `.mpp` файл. Искате да го прегледате, да го изчислите или да го разработвате по-нататък. Приложението чете `.mpp` файлове от MS Project 2010 до 2021 включително. То само чете: не записва `.mpp` и никога не променя файла Ви. От файла то взема самия график: задачи със структура, продължителност и ограничения, зависимости с време на отстъп, календари, ресурси, назначения и напредък. То чете и датите и резервите, които MS Project е изчислил сам, но ги използва само за изгледа *Дати, както са записани*, никога като вход.

## Стъпки

1. Изберете *Начало › Файл › Отвори* или натиснете Ctrl+O. Изберете файла `.mpp`.
2. Проектът се отваря в нов раздел или в текущия раздел, ако той още е празен и не е променян. Проектът няма свързан файл: *Запиши* по-късно записва нов IFC файл.
3. Прочетете съобщението долу: *Този проект се изчислява като Microsoft Project. Променете го чрез Файл → Информация за проекта → Профил на изчисление и опции за изчисление.* Приложението изчислява този проект с правилата за изчисление на MS Project: профилът на изчисление *Microsoft Project*. С *Отвори профил на изчисление* отивате към настройката, *Прочетете повече* отваря помощта за профилите на изчисление.
4. Проверете дали под лентата с команди има съобщение: *Виждате датите така, както са в файла; при преизчисляване 4 задачи ще се изместят.* Тогава при тези задачи резултатът на приложението се различава от датите, които MS Project е записал. Под съобщението от стъпка 3 се показва и ред: *4 задачи показват датите, както са записани във файла (не са преизчислени).* Какво значи това и как превключвате към собственото изчисление на приложението, е описано в [Дати, както са записани](docs://uitleg-datums-zoals-opgeslagen).
5. Ако там пише *Този файл съдържа планиране по часове.* и има бутон *Включи планиране по часове*, файлът съдържа данни в часове. Вижте [Включване на планиране по часове](docs://howto-urenplanning-aanzetten).

Ако файлът съдържа задачи с прекъсване, нивелиране или график, управляван от ресурси, се добавя още едно съобщение, например *Този файл на MS Project съдържа 3 задачи с прекъснат, нивелиран или ресурсно управляван график. Те се импортират и показват като такива.* За една задача съобщението е в единствено число.

## Капани и какво прави приложението тогава

**Не всичко се прехвърля.** Приложението не поема базовите линии, разходите и стандартни цени на единица, бележките и потребителски полета от MS Project. Код WBS, който сте попълнили сами в MS Project, се поема; иначе приложението номерира задачите според структурата.

**Файл от MS Project 2007 или по-стар.** Приложението го отказва и показва: *Този .mpp файл е в по-стар формат (Project 2007 или по-ранен). Експортирайте го от MS Project като XML (Файл → Запиши като → XML) и отворете този файл.* Под съобщението приложението добавя техническа причина на английски.

**Файл с парола.** Приложението показва: *Този .mpp файл е защитен с парола. Експортирайте го от MS Project като XML (Файл → Запиши като → XML) и отворете този файл.* И тук съобщението идва с техническа причина на английски.

**Файл, който не е `.mpp`.** Получавате *Файлът не можа да се отвори*, с техническа причина.

**Пътят през XML изчислява по друг начин.** Ако отворите XML експорта от MS Project вместо `.mpp`, приложението изчислява с профила на изчисление *Open Planner Studio* и не виждате съобщението за *Microsoft Project*. Датите могат тогава да излязат различно, отколкото при файла `.mpp`.

**Редактирането освобождава управлението от MS Project.** Ако редактирате задача, чийто график се управляваше от прозореца с дати на MS Project, приложението показва веднъж за проект: *Прозорецът с дати от MS Project вече не управлява 2 задачи след това редактиране; самото разпределение на часовете остава в сила и се запазва във файла.* За една задача съобщението е в единствено число.

**Записването никога не презаписва вашия `.mpp`.** Проектът няма файл. *Запиши* пита къде трябва да се запише новият IFC файл.
