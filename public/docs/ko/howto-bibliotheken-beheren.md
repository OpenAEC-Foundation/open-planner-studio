# 리소스 라이브러리 관리 및 공유

목표: 리소스 라이브러리를 만들고 삭제하며, 라이브러리에 달력을 넣고, 백업용으로 또는 다른 컴퓨터에서 쓰기 위해 라이브러리를 내보내거나 가져옵니다.

## 이것이 필요한 경우

리소스 라이브러리는 프로젝트 파일이 아니라 앱 안에 있습니다. 데스크톱 앱에서는 이 컴퓨터의 파일에, 브라우저에서는 그 브라우저의 저장 공간에 있습니다. 동기화되지 않습니다. 브라우저의 사이트 데이터를 지우면 리소스 라이브러리가 사라집니다. 그러므로 백업으로 내보내세요. 동료가 같은 작업팀과 단가로 작업하려면 리소스 라이브러리를 파일로 함께 전달하세요. 조직에 자체 작업팀을 둔 운영 회사가 여러 곳 있으면 회사마다 별도의 리소스 라이브러리를 만드세요. 새 프로젝트에서는 사용할 리소스 라이브러리를 직접 선택하세요.

리소스 라이브러리가 무엇인지는 [리소스 라이브러리 설명](docs://uitleg-resourcebibliotheek)에서 확인하세요. 리소스 자체는 여기서 편집하지 않고 리소스 패널에서 편집합니다. 자세한 내용은 [리소스 라이브러리 사용하기](docs://howto-resourcebibliotheek-gebruiken)를 참조하세요.

## 단계

### 관리 화면 열기

*파일 › 라이브러리*를 선택합니다. 왼쪽에는 *리소스 라이브러리* 목록이 있습니다. 오른쪽에는 클릭한 리소스 라이브러리의 세부 정보가 있습니다. 이름, 버튼, 그리고 *달력* 목록입니다. 맨 위에는 리소스를 *자원* 탭에서 관리한다는 안내가 있습니다.

### 리소스 라이브러리 만들기, 이름 바꾸기 및 기본값 선택

1. 목록 위의 더하기 기호(*리소스 라이브러리 추가*)를 클릭합니다. *새 리소스 라이브러리*가 추가되고 바로 선택됩니다.
2. 오른쪽 부분 맨 위의 이름 칸에 새 이름을 입력하고 Enter를 누르거나, 칸 밖을 클릭합니다. 앱은 빈 이름을 허용하지 않습니다.
3. *기본값으로 설정*을 클릭하면 이 리소스 라이브러리가 이후 새 프로젝트에서 미리 선택됩니다. 기본 리소스 라이브러리에는 목록에 별표가 있습니다.

### 리소스 라이브러리에 달력 넣기

1. *달력* 아래에서 *프로젝트에서*를 클릭합니다. 활성 프로젝트의 달력이 있는 목록이 열립니다.
2. 가져오려는 달력 뒤의 작은 화살표를 클릭합니다. 목록 위에 *추가되었습니다*라고 나옵니다. 이 리소스 라이브러리에 이미 연결된 달력에는 이름 뒤에 *이미 연결됨*이 나옵니다.
3. 달력은 이제 리소스 라이브러리의 *달력* 목록에 있습니다. 연필(*편집*) 아이콘으로 이름을 바꾸고 체크 표시로 저장합니다. 휴지통을 누르면 확인 없이 달력이 바로 삭제됩니다. 프로젝트에 있는 사본은 그대로 남습니다.

*달력* 다음에 버전 번호가 있습니다(예: *v2*). 리소스 라이브러리를 변경할 때마다 번호가 올라갑니다. 리소스 라이브러리의 달력은 이를 사용하는 리소스를 할당하면 프로젝트로 함께 넘어갑니다. 달력은 리소스에 연결합니다. *자원*, *라이브러리* 보기에서 *달력* 열을 사용합니다.

### 라이브러리 내보내기

1. 목록에서 리소스 라이브러리를 선택합니다.
2. *내보내기*를 클릭합니다.
3. 데스크톱 앱과 Chrome, Edge에서는 저장 위치를 직접 선택합니다. 다른 브라우저에서는 파일이 바로 다운로드 폴더에 저장되며, 앱이 이를 알려 줍니다. 파일 이름은 `bibliotheek-` 뒤에 리소스 라이브러리 이름을 붙이고, 확장자는 `.ifc`입니다.

버튼 아래에는 다음 안내가 있습니다: *내보내기는 백업 역할도 합니다. 파일을 안전한 곳에 보관하세요.*

### 라이브러리 가져오기

1. *가져오기*를 클릭합니다. 목록에서 선택한 리소스 라이브러리를 대상으로 *라이브러리 가져오기* 창이 열립니다.
2. *파일 선택…*을 클릭하고 내보내기로 만든 `.ifc` 파일을 고릅니다. 파일에 리소스 라이브러리가 없으면 *이 IFC 파일에는 리소스 라이브러리가 포함되어 있지 않습니다.*라는 안내가 나옵니다.
3. 앱에 파일 내용이 표시됩니다. 예를 들면 *달력 2개, 자원 5개(버전 3).*
4. 원하는 작업을 선택합니다. 아래를 참조하세요.
5. *추가* 또는 *교체*를 클릭합니다. 중단하려면 *취소*를 클릭합니다.

선택지는 두 가지입니다:

- *새 리소스 라이브러리로 추가*: 파일이 기존 리소스 라이브러리 옆에 별도의 리소스 라이브러리가 됩니다. 아래에 어떤 이름으로 추가되는지 표시됩니다. 예: *"Mijn resourcebibliotheek (2)"(으)로 추가됩니다.* 아무것도 잃지 않으며, 활성 프로젝트는 자신의 리소스 라이브러리에 계속 연결됩니다.
- *기존 리소스 라이브러리 교체*: 선택한 리소스 라이브러리의 전체 내용이 파일의 내용으로 교체됩니다. 앱도 이를 알려 줍니다: *가져오기를 실행하면 선택한 리소스 라이브러리의 풀 전체가 교체됩니다.* 리소스 라이브러리가 두 개 이상이면 *리소스 라이브러리로 가져오기*에서 어느 것을 바꿀지 고릅니다. 리소스 라이브러리가 파일보다 최신이면 앱이 경고합니다: *로컬 라이브러리가 더 최신입니다 — 가져오면 변경 사항이 덮어써질 수 있습니다.*

앱이 선택지를 스스로 미리 제안합니다. 파일에 기본 리소스 라이브러리가 들어 있었다면 *새 리소스 라이브러리로 추가*가 미리 선택됩니다. 파일의 리소스 라이브러리가 이 컴퓨터에 이미 있고 기본 리소스 라이브러리가 아니면 *기존 리소스 라이브러리 교체*가 미리 선택되며, 그 리소스 라이브러리도 함께 선택됩니다. 확신이 없으면 추가를 선택하세요. 추가는 아무것도 덮어쓰지 않습니다.

### 리소스 라이브러리 삭제

1. 목록에서 리소스 라이브러리를 선택하고 *리소스 라이브러리 삭제*를 클릭합니다. 마지막 리소스 라이브러리의 버튼은 회색으로 표시됩니다. 리소스 라이브러리는 항상 하나 남아 있어야 하기 때문입니다.
2. *삭제*로 확인합니다. 질문은 *이 리소스 라이브러리를 삭제하시겠습니까?*입니다. 열려 있는 프로젝트가 연결되어 있으면 *이 리소스 라이브러리는 열려 있는 1개의 프로젝트와 연결되어 있습니다. 삭제하면 해당 프로젝트와의 연결이 해제됩니다. 계속하시겠습니까?*라고 나옵니다. 프로젝트가 더 많으면 같은 내용이 개수와 함께 나옵니다. 예: *열려 있는 프로젝트 2개와 연결되어 있습니다.*

그러면 리소스 라이브러리가 사라지며, 그 안의 모든 리소스와 달력도 함께 사라집니다. 이 리소스 라이브러리를 사용하던 열린 프로젝트는 연결이 해제됩니다. 해당 프로젝트의 리소스는 일반 프로젝트 리소스로 남습니다. 내용을 보관하려면 먼저 내보내세요.

### 라이브러리와 함께 프로젝트 전달하기

프로젝트 파일에는 리소스의 사본이 들어 있습니다. 리소스 라이브러리 전체도 함께 전달하려면 다음 단계를 따르세요. 내보내기 자체는 [내보내기](docs://howto-exporteren)에서도 설명합니다.

1. 리소스 라이브러리에 연결된 프로젝트를 열고 *파일 › 내보내기*를 선택합니다.
2. *라이브러리 파일도 함께 저장*을 체크합니다. 이 체크 박스는 연결된 프로젝트에만 나타납니다.
3. *IFC* 카드를 선택하고 파일을 저장합니다. 그러면 앱이 두 번째 파일도 요청합니다. 이 파일은 프로젝트 이름 뒤에 `-bibliotheek`이 붙은 이름이며, 리소스 라이브러리를 담고 있습니다.

이 체크 박스는 IFC 내보내기에서만 작동하며, 다른 내보내기 형식에서는 작동하지 않습니다. 동료는 위에서 설명한 대로 두 번째 파일을 가져옵니다.

## 주의할 점과 그때 앱이 하는 일

**계획자 두 명, 리소스 라이브러리 두 개.** 앱은 컴퓨터 사이에서 리소스 라이브러리를 동기화하지 않습니다. 가져오기 창에는 이에 대한 경고가 항상 표시됩니다: *참고: 리소스 라이브러리는 컴퓨터 간에 동기화되지 않습니다. 계획자 두 명이 같은 리소스 라이브러리로 작업하면 리소스 라이브러리 내용이 서로 달라질 수 있습니다. 조직에서 여러 운영 회사가 작업팀을 공유한다면 공유 리소스 라이브러리 하나를 의도적으로 선택하세요.*

**교체하면 모든 내용이 덮어써집니다.** 선택한 리소스 라이브러리에 있던 내용은 모두 사라지며, 리소스 라이브러리 변경은 *실행 취소* 대상에 포함되지 않습니다. 확실하지 않으면 먼저 내보내세요. 프로젝트는 자신의 사본을 그대로 유지합니다. 앱은 새 파일에 여전히 있는 사본을 업데이트합니다. 새 파일에 더 이상 없는 사본에는 *더 이상 라이브러리에 없음* 표시가 붙고, 계속 작동합니다. 사본이 다르면 *리소스 라이브러리와 연결* 창이 열립니다([리소스 라이브러리 사용하기](docs://howto-resourcebibliotheek-gebruiken)를 참조하세요).

**목록에서 달력을 삭제하면 바로 실행됩니다.** 앱은 달력 삭제를 확인하지 않지만, 리소스 삭제는 확인합니다. 이는 결함처럼 보일 수 있습니다. 리소스 라이브러리 변경은 *실행 취소* 대상에 포함되지 않습니다.
