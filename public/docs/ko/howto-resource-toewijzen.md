# 곡선으로 리소스 할당하기

목표: 작업에 리소스를 할당합니다. 일별 단위와, 그 단위를 작업의 날짜에 어떻게 나눌지 정하는 곡선을 함께 설정합니다.

## 이 기능이 필요한 경우

누가 언제 어디서 일하는지 보고 싶으면 바로 필요합니다. 예: 바깥쪽 벽의 중공층을 쌓는 벽돌공, 중공 슬래브를 설치하는 크레인. 할당이 없으면 부하가 없으므로 히스토그램이나 과다 할당도 없습니다.

용어 두 가지입니다. **단위**(패널에서는 열 *단위*, *할당* 창에서는 필드 *단위/일*)는 근무일마다 작업에 리소스가 얼마나 일하는지를 뜻합니다. 1은 벽돌공 한 명, 2는 두 명, 0.5는 반나절입니다. **곡선**은 총량(단위 × 기간)을 작업의 근무일에 어떻게 나눌지 정합니다. 작업량은 보통 고르게 나뉘지 않습니다. 벽은 시작은 한산하고, 중간은 바쁘고, 끝은 다시 한산합니다.

바깥쪽 벽의 중공층 쌓기는 근무일 6일이 걸립니다. 벽돌공 한 명과 *균등* 곡선이면 6일 각각 1단위, 합계 6입니다. *종형* 곡선이면 합계는 여전히 6단위이지만 분배는 0, 1, 2, 2, 1, 0이 됩니다.

## 단계

리소스를 할당하는 방법은 두 가지입니다. 리소스가 이미 있어야 합니다([리소스 관리](docs://howto-resources-beheren) 참조).

### 리본으로

1. 작업 표에서 작업 하나를 선택합니다. 일반 작업이어야 합니다. 마일스톤이나 요약 작업은 안 됩니다.
2. *자원 › 할당 › 할당 ▾*를 선택합니다.
3. 창에서 *단위/일*(기본값 1)을 입력하고 *곡선*(기본값 *균등*)을 선택합니다. 이 값은 지금 선택하는 리소스에 적용됩니다.
4. 리소스를 클릭합니다. 창이 닫히고 할당이 추가됩니다.

두 번째 리소스를 할당하려면 창을 다시 엽니다. 작업에 이미 있는 리소스는 목록에 나오지 않습니다.

### 속성 패널로

1. 작업을 선택합니다. *속성* 패널은 오른쪽에 있습니다. 보이지 않으면 *보기 › 패널 › 속성*에서 켭니다.
2. *할당* 블록 맨 아래의 *자원 할당*에서 리소스를 선택합니다. 할당은 단위 1과 *균등* 곡선으로 시작합니다.
3. 각 할당에서 *단위*를 바꿉니다. 리소스 이름을 클릭하면 *곡선*이 나타납니다. 거기서 다른 곡선을 선택합니다.

기존 할당을 바꿀 때도 같은 방법입니다. 줄 끝의 휴지통(*제거*)으로 할당을 작업에서 뺍니다. 리소스 자체는 남습니다. 리소스 이름을 클릭하면 나타나는 *이동…*으로 할당을 다른 작업으로 옮깁니다.

### 곡선 종류

- *균등*: 매일 같습니다. 기본값이며, 매일 같은 강도의 작업에 맞습니다.
- *초반 집중*: 시작이 끝보다 무겁습니다. 시작부터 힘이 많이 드는 작업에 맞습니다. 예: 규준 잡기.
- *후반 집중*: 끝이 시작보다 무겁습니다. 완료에 가까워질수록 바빠지는 작업에 맞습니다.
- *종형*: 가운데에 피크가 있고 시작과 끝은 한산합니다. 시작은 한산하고, 가운데는 한창이고, 끝에 줄어드는 벽에 맞습니다.
- *초기 피크*: 가운데 이전에 피크가 있습니다. 빨리 속도가 붙는 작업에 맞습니다.
- *후기 피크*: 가운데 이후에 피크가 있습니다. 바쁜 시기가 늦게야 오는 작업에 맞습니다.
- *이중 피크*: 피크가 두 개 있습니다. 바쁜 시점이 두 번 있는 작업에 맞습니다.
- *거북이*: 시작과 끝은 한산하고 가운데에 넓은 피크가 있습니다. 천천히 올라갔다가 천천히 내려가는 긴 작업에 맞습니다.

곡선은 분배만 바꿉니다. 기간, 날짜, 합계는 그대로입니다. 그 후에 다시 계산할 필요는 없습니다. 히스토그램은 즉시 바뀝니다. 보려면 *자원 › 히스토그램 › 히스토그램*을 선택합니다. 작업을 선택하면 히스토그램은 그 작업의 부하만 보여줍니다.

## 주의할 점과 앱의 동작

**곡선 때문에 피크가 단위보다 높아질 수 있습니다.** 단위를 정수로 입력하면 앱은 일별 값을 정수 단위로 반올림합니다. 합계는 그대로입니다. 바깥쪽 벽의 중공층에 단위 1인 벽돌공과 *종형* 곡선을 쓰면 0, 1, 2, 2, 1, 0이 됩니다. 가운데 두 날은 2단위가 되는데, *최대 단위*는 1입니다. 히스토그램은 그 날을 빨간색으로 표시하고, 리소스는 과다 할당된 것으로 집계됩니다. 다른 곡선을 선택하거나, 시간을 직접 나누세요([시간 분배 조정](docs://howto-urenverdeling-aanpassen) 참조). 0.5 같은 단위에서는 앱이 소수점 둘째 자리까지 반올림합니다. 그래서 정수 단위의 짧은 작업에서는 모양이 거칠어집니다. 10일 동안 단위 1인 *거북이* 곡선은 0, 1, 1, 2, 2, 1, 1, 1, 1, 0 분배가 되며, 이는 *초기 피크*와 정확히 같습니다.

**마일스톤이나 요약 작업은 안 됩니다.** 그러면 *할당* 버튼이 비활성화되고, *속성* 패널에 *마일스톤에는 할당할 수 없습니다* 또는 *요약 작업에는 할당할 수 없습니다*가 표시됩니다.

**리소스는 작업당 한 번만 할당됩니다.** 리소스가 이미 작업에 있으면 목록에 더 이상 나오지 않습니다. 모든 리소스가 이미 작업에 있으면 앱은 *모든 자원이 이미 할당되었습니다*라고 표시합니다. 리소스가 아직 없으면 *먼저 자원을 만드세요 (자원 탭)*이라고 표시합니다.

**단위는 0보다 커야 합니다.** 앱은 0 이하의 값을 받지 않습니다.

**자재.** 자재 리소스의 단위는 리소스 단위로 된 일별 수량입니다. 예: m³. 자재는 작업 기간에 포함되지 않습니다.

**작업 유형이 기간을 조정할 수 있습니다.** 작업이 *고정 작업량* 또는 *고정 단위*이면, 두 번째 리소스가 작업의 기간을 바꿉니다. 그러면 일정이 더 이상 최신 상태가 아닙니다. **계산**(F5)을 누르세요. [작업 유형: 기간, 단위 및 작업량](docs://uitleg-werkregels) 참조.

**자체 분배.** 할당에 이미 자체 시간 분배가 있으면 곡선은 비활성화되고 *윤곽*이 표시됩니다. 먼저 *시간 분배…*에서 그 분배를 해제하세요.

**실행 취소.** 할당을 만들기, 바꾸기, 제거하기는 *실행 취소*(Ctrl+Z)로 되돌릴 수 있습니다.
