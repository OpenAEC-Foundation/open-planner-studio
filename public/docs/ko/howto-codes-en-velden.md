# 코드 및 사용자 지정 필드

목표: 직접 정의한 분류(*위치* 같은 활동 코드)와 직접 정의한 필드(*시공사* 같은 필드)를 작업에 연결합니다.

## 이 기능이 필요한 경우

작업의 고정 데이터(이름, 기간, 관계 등) 외에 직접 만든 데이터를 추가할 수 있습니다. 작업을 북측 동과 남측 동으로 나누거나, 분야별로 분류하거나, 어느 시공사가 작업을 수행하는지 기록하려면 직접 입력해야 합니다. 방법은 두 가지이며, 둘의 차이가 중요합니다.

**활동 코드**는 고정된 선택 목록이 있는 분류입니다. **코드 유형**(예: *위치*)을 만들고, 그 안에 **값**(북측 동은 *N*, 남측 동은 *Z*)을 추가합니다. 작업은 코드 유형마다 최대 하나의 값을 받습니다.

**사용자 지정 필드**(창의 *사용자 지정 필드* 아래에 있습니다)는 유형이 있는 자유 입력 필드입니다. 유형은 *텍스트*, *숫자*, *정수*, *비용*, *날짜* 또는 *예/아니오*입니다. 필드는 작업마다 다른 값을 가질 수 있습니다.

## 단계

### 코드 및 필드 정의하기

1. *계획 › 구조 › 코드 및 필드*를 선택합니다.
2. **코드 유형 만들기.** *새 코드 유형 (예: 위치)* 아래에 이름을 입력하고 Enter 키를 누르거나 *코드 유형 추가*를 클릭합니다.
3. **값 추가하기.** 코드 유형 아래에서 *값 추가*를 클릭합니다. 앱은 그 자리에 *V1* 같은 임시 코드를 넣습니다. *코드* 상자에서 코드를 바꾸세요. 직접 입력하듯이 짧게 씁니다(예: *N*). 필요하면 *설명*을 입력하세요(예: *북측 동*). 그다음 *색상*을 고르세요. 상자를 벗어나거나 Enter 키를 누르는 순간 변경이 적용됩니다.
4. **사용자 지정 필드 만들기.** *새 필드 (예: 시공사)* 아래에 이름을 입력하고 유형을 고른 다음 *필드 추가*를 클릭합니다(또는 Enter 키를 누릅니다).

이 창에는 확인 버튼이 없습니다. 모든 변경은 즉시 적용됩니다. 나중에 필드의 유형은 바꿀 수 없고, 이름만 바꿀 수 있습니다. 다른 유형이 필요하면 새 필드를 만드세요.

### 작업에 코드 또는 필드 입력하기

입력할 곳은 두 군데입니다.

- **패널 *속성*에서**(또는 F2로 여는 창에서). 아래쪽에는 *코드 및 필드* 블록이 있습니다. 코드 유형마다 선택 목록이, 필드마다 입력란이 있습니다. 이 블록은 코드 유형이나 필드가 하나 이상 있을 때만 나타납니다.
- **작업 표의 열로 추가.** 표 머리글 오른쪽에 있는 **+**(*열 추가*)를 클릭하고, *사용자 지정* 아래에서 코드 유형이나 필드를 고르세요. 코드 유형의 셀에는 코드를 입력하거나(예: `N`) 목록에서 고릅니다. 없는 코드를 입력하면 *이 활동 코드에서 값을 선택하세요.* 메시지가 나타납니다.

### 사용 방법

코드 유형이나 사용자 지정 필드로 필터링, 그룹화, 정렬할 수 있습니다. 이를 레이아웃으로 설정합니다: *보기 › 레이아웃 › 새 레이아웃*. 창에서 레이아웃에 담을 항목을 체크하세요. *저장*을 선택하면 *보기 › 레이아웃*에 나중에 다시 클릭할 수 있는 버튼이 생깁니다. *저장하지 않고 적용*을 선택하면 지금 화면에만 적용됩니다. 그룹화할 때 값이 없는 작업은 *(없음)* 아래에 놓입니다.

막대 색상을 바꾸려면 *보기 › 기준선 및 진행 › 막대 색상*을 선택한 다음 *범주별*과 코드 유형을 고르세요. 그러면 각 막대가 자신의 값에 지정된 *색상*을 받습니다.

## 주의 사항과 앱의 동작

**삭제하면 작업에 있는 값이 사라집니다.** 휴지통 아이콘으로 코드 유형, 값 또는 필드를 삭제하면 앱은 확인을 묻지 않습니다. 그러면 모든 작업에 입력된 값도 함께 사라집니다. 그 코드 유형이나 필드에 대한 그룹화나 정렬도 함께 해제됩니다. 창을 먼저 닫은 다음 *실행 취소*(Ctrl+Z)를 누르면 코드 유형, 값 또는 필드와 입력된 값은 돌아옵니다. 그러나 그룹화와 정렬은 돌아오지 않습니다. 그룹화와 정렬은 다시 설정해야 합니다.

**같은 코드를 가진 두 값.** *값 추가*는 현재 값의 개수에서 이어서 번호를 매깁니다. 값을 하나 삭제하고 하나 추가하면 같은 코드가 두 번 나타날 수 있습니다. 그 코드를 열의 셀에 입력하면 앱은 *이 활동 코드 값이 여러 번 나타납니다. 목록에서 선택하세요* 메시지를 띄우고 입력을 거부합니다. 모든 값에 서로 다른 코드를 부여하세요.

**템플릿은 코드와 필드를 함께 가져가지 않습니다.** [WBS 템플릿 저장 및 삽입](docs://howto-wbs-sjablonen)을 참조하세요. 작업을 다른 문서에 붙여 넣으면, 앱은 그 문서에 없는 코드와 필드를 지우고 알려 줍니다.

**날짜 필드는 함께 이동하지 않습니다.** 전체 프로젝트를 이동하면, 유형이 *날짜*인 사용자 지정 필드에 입력된 값은 원래 날짜에 그대로 남습니다. 앱은 미리 보기에서 이를 경고합니다.
