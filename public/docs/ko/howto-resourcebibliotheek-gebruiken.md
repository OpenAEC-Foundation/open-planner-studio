# 리소스 라이브러리 사용하기

목표: 프로젝트에서 리소스 라이브러리의 리소스를 사용하고, 프로젝트에서 만든 리소스를 라이브러리에 넣어 모든 프로젝트가 같은 데이터를 사용하도록 합니다.

## 이 작업이 필요할 때

여러 프로젝트에 나오는 고정 조적 팀, 크레인, 미장공이 있습니다. 라이브러리가 없으면 프로젝트마다 다시 입력해야 합니다. 이름과 단가가 달라질 위험이 있습니다. 또한 어떤 프로젝트도 다른 프로젝트가 같은 팀을 요청하는지 알 수 없습니다. 라이브러리에서는 한 번만 기록합니다.

라이브러리가 무엇인지, 프로젝트가 라이브러리에서 무엇을 가져오는지는 [리소스 라이브러리](docs://uitleg-resourcebibliotheek)에서 읽을 수 있습니다. 이 문서는 작업 방법을 다룹니다. 라이브러리 만들기, 내보내기, 삭제는 [리소스 라이브러리 관리 및 공유](docs://howto-bibliotheken-beheren)에 있습니다.

## 단계

### 1. 프로젝트를 라이브러리에 연결하기

프로젝트가 라이브러리에 연결된 경우에만 라이브러리를 사용할 수 있습니다. 연결이 없으면 *리소스* 패널에 *라이브러리*, *프로젝트*, *점유 현황* 전환 버튼이 표시되지 않습니다.

새 프로젝트의 경우:

1. *파일 › 새로 만들기*를 선택합니다. *새 프로젝트* 창이 열립니다.
2. *리소스 라이브러리* 필드를 확인합니다. 필드는 기본 라이브러리로 설정되어 있습니다. 다른 라이브러리, *없음(독립 프로젝트)* 또는 *+ 새 리소스 라이브러리…*를 선택할 수 있습니다.
3. *만들기*를 클릭합니다.

기존 프로젝트의 경우:

1. *파일 › 프로젝트 설정*을 선택합니다.
2. *리소스 라이브러리*에서 라이브러리를 선택합니다.
3. *적용*을 클릭합니다. 그때까지 하단에 *변경 사항이 적용되지 않았습니다. 유지하려면 적용을(를) 클릭하세요.*라고 표시됩니다.

프로젝트에 라이브러리 항목과 이름이 같은 리소스가 이미 있으면 *리소스 라이브러리와 연결* 창이 열리고 *인식* 구역이 표시됩니다. 일치하는 각 리소스에는 *제안: Bricklayer*라고 표시됩니다. 하나만 연결하려면 *연결*을 클릭합니다. 제안이 여러 개이면 *모든 제안 연결*을 클릭합니다. 앱은 대문자와 이중 공백을 구분하지 않고 이름을 비교합니다. 연결하면 리소스는 라이브러리 항목에서 이름, 유형, 단가, 단위와 설명을 가져옵니다. *최대 단위*는 프로젝트에 있던 값이 그대로 유지됩니다. 이 창에는 라이브러리 달력과 이름이 같은 프로젝트 달력도 표시됩니다. *나중에 결정*을 선택하면 연결하지 않고 창을 닫습니다.

### 2. 리소스를 라이브러리에 넣기

1. *자원 › 관리 › 리소스*를 선택합니다. 리소스 패널이 작업 영역 전체를 차지합니다. 연결된 프로젝트에서도 항상 *프로젝트* 보기로 열립니다.
2. 오른쪽 위에서 *라이브러리*를 선택합니다. 표 위에 *이 작업은 라이브러리 데이터를 편집하며 모든 프로젝트에 적용됩니다 — 실행 취소 대상이 아닙니다.*라고 표시됩니다.
3. *라이브러리에 새 리소스*를 클릭합니다. 표 맨 아래에 빈 행이 나타납니다.
4. 이름을 입력합니다. 예를 들어 *Bricklayer*를 입력하고 Enter를 누릅니다. 이제 리소스가 라이브러리에 있으며, 다음 리소스를 위한 빈 행이 바로 열립니다. 작업이 끝나면 Esc를 누릅니다. 이름이 없으면 앱은 아무것도 만들지 않습니다.
5. 행의 나머지 값을 입력합니다. *유형*은 기본적으로 *인력*입니다. *최대 단위*에는 이 리소스가 전체 몇 개인지 입력합니다. 예를 들어 조적공이 세 명이면 3을 입력합니다. 점유 현황 개요는 이 숫자를 용량으로 사용합니다. *단가/시간*은 선택 사항입니다. *단위*는 유형이 *자재*인 경우에만 입력할 수 있습니다. *달력*에서 라이브러리의 달력을 선택하거나, 새로 만들려면 *+ 리소스 달력*을 선택합니다. 자세한 내용은 [리소스 달력 설정](docs://howto-resourcekalender-instellen)을 참조하세요. 앱은 필드를 떠날 때 이름, 단가와 단위를 저장합니다. 나머지 필드는 바로 저장합니다.

라이브러리의 모든 변경은 열려 있는 프로젝트의 편집되지 않은 복사본에 즉시 반영됩니다.

### 3. 리소스를 프로젝트에 할당하기

1. *라이브러리* 보기에서 리소스의 *프로젝트에 할당*을 선택합니다. 표 위에 *추가되었습니다.*라고 표시됩니다. 다시 클릭하면 *이미 프로젝트에 있습니다.*라고 표시되며 두 번째 복사본은 나타나지 않습니다.
2. *프로젝트*를 선택합니다. 복사본이 표에 있으며 이름 옆에 *라이브러리에서 가져옴*이라는 작은 라이브러리 아이콘이 있습니다. 이름, 유형, 단가와 단위는 일반 텍스트입니다. 마우스를 올리면 *라이브러리 값입니다 — 라이브러리 보기에서 편집하거나 이 리소스를 라이브러리에서 분리하세요.*가 표시됩니다.
3. 이 프로젝트의 *최대 단위*를 설정합니다. 필드는 라이브러리 값으로 시작하며 프로젝트에서 계속 편집할 수 있습니다.
4. 이제 다른 리소스와 같은 방법으로 작업에 리소스를 할당합니다. 자세한 내용은 [곡선으로 리소스 할당](docs://howto-resource-toewijzen)을 참조하세요. *자원 › 할당 › 할당*에는 프로젝트에 이미 있는 리소스만 표시됩니다. 따라서 먼저 이 방법으로 라이브러리 리소스를 프로젝트에 할당하세요.

*프로젝트에 할당*은 해당 라이브러리에 연결된 프로젝트의 *라이브러리* 보기에만 있습니다.

### 4. 프로젝트의 리소스를 라이브러리로 가져오기

프로젝트에서 만들었고 더 자주 사용하는 리소스에 이 작업을 합니다. 예를 들어 임대 크레인이 있습니다.

1. 연결된 프로젝트의 *프로젝트* 보기에서 리소스의 *라이브러리로*를 선택합니다. 이 버튼은 이름이 있고 아직 라이브러리에서 가져오지 않은 리소스에만 나타납니다.
2. 표 위의 메시지를 읽습니다.

메시지에는 세 가지 내용이 나올 수 있습니다.

- *추가되었습니다*. 라이브러리에 그 이름의 항목이 없었습니다. 새 항목이 만들어졌고 리소스가 그 항목에 연결되었습니다.
- *라이브러리에 이미 있었습니다 — 이제 연결되었습니다*. 같은 이름과 같은 데이터의 항목이 있었습니다. 리소스가 그 항목에 연결되었습니다.
- *기존 라이브러리 항목과 연결되었습니다 — 값이 다릅니다. 표시를 확인하세요*. 같은 이름이지만 데이터가 다른 항목이 있었습니다. 리소스는 연결되고 바로 *차이 있음 — 결정 필요*로 표시됩니다. 6단계로 계속하세요.

### 5. 복사본을 라이브러리에서 분리하기

한 프로젝트에서만 라이브러리와 다르게 하려면, 예를 들어 다른 단가를 사용하려면 복사본을 분리합니다.

1. *프로젝트* 보기에서 행 끝에 있는 *라이브러리에서 분리* 아이콘을 클릭합니다.
2. 리소스는 이제 일반 프로젝트 리소스입니다. 모든 필드를 편집할 수 있으며 더 이상 라이브러리를 따르지 않습니다. 리소스와 함께 들어온 달력도 분리됩니다. 단, 이 프로젝트의 다른 리소스가 아직 그 달력을 따르고 있으면 예외입니다.

*실행 취소* (Ctrl+Z)를 사용하면 분리를 되돌릴 수 있습니다.

### 6. 차이 해결하기

*차이 있음 — 결정 필요*라고 표시된 복사본은 라이브러리 항목과 다릅니다. 앱은 어느 쪽이 맞는지 선택하지 않습니다.

1. 리소스의 *차이 있음 — 결정 필요* 표시를 클릭합니다. *리소스 라이브러리와 연결* 창이 열립니다. 이런 복사본이 있는 파일을 열 때도 이 창이 저절로 열립니다.
2. *차이점* 구역에서 항목에 대해 원하는 것을 선택합니다. 아래를 참조하세요.
3. 아직 선택하지 않으려면 *나중에 결정*을 클릭합니다. 창이 닫히고 표시는 그대로 남습니다.

차이가 있으면 두 가지 중에서 선택할 수 있습니다:

- *라이브러리 값 사용*: 복사본이 라이브러리의 데이터를 가져옵니다.
- *파일 값을 라이브러리에 반영*: 라이브러리가 복사본의 데이터를 가져옵니다. 아래에 *주의: 이는 라이브러리 데이터를 변경하며 모든 프로젝트에 적용됩니다.*라고 표시됩니다. 열려 있는 다른 프로젝트의 복사본도 따라갑니다.

## 주의할 점과 그때 앱의 동작

**예제 프로젝트에는 자체 라이브러리가 있습니다.** 세 가지 예제 중 하나를 열면 (*파일 › 예제*, 또는 도움말의 링크를 통해) 앱은 *데모 리소스 라이브러리*를 한 번 만들고 프로젝트를 그 라이브러리에 연결합니다. 라이브러리 항목과 이름이 같은 프로젝트 리소스는 바로 연결됩니다. 달력은 연결되지 않습니다. 직접 만든 라이브러리는 그대로 남습니다. 예제 두 개를 나란히 열면 함께 [점유 현황 개요 사용하기](docs://howto-bezettingsoverzicht-gebruiken)에서 충돌이 보입니다. 예를 들어 조적 팀(*Masonry crew*)에서 *Refurbishment & Extension of a Family Home*과 *6 New Terraced Houses, De Akkers* 사이에 충돌이 있습니다.

**전환 버튼이 보이지 않습니다.** 프로젝트가 라이브러리에 연결되어 있지 않습니다. 1단계를 수행하세요.

**라이브러리를 실수로 편집합니다.** 이를 막기 위해 패널은 항상 *프로젝트*에서 열립니다. *라이브러리* 보기에서 한 변경은 모든 프로젝트에 적용되며 *실행 취소* 대상이 아닙니다.

**라이브러리에서 리소스를 삭제합니다.** 앱은 먼저 *라이브러리에서 'Bricklayer'을(를) 삭제하시겠습니까? 이는 모든 프로젝트에 적용되며 실행 취소할 수 없습니다*라고 묻습니다. 프로젝트의 복사본은 그대로 남아 계속 작동합니다. 복사본에는 *더 이상 라이브러리에 없음* 표시가 붙으며 모든 필드를 편집할 수 있습니다. *프로젝트에서 제거*를 선택하면 복사본을 프로젝트에서 뺍니다.

**리소스 라이브러리에서 다른 라이브러리나 *없음(독립 프로젝트)*을 선택합니다.** 이전 라이브러리의 출처 표시가 사라집니다. 리소스는 일반 프로젝트 리소스로 프로젝트에 남습니다. 다른 라이브러리를 선택하면 앱은 같은 이름의 리소스를 다시 찾습니다.

**리소스에 *인식* 구역의 제안이 없습니다.** 이 리소스에는 *제안 없음 — 직접 선택*이라고 표시되지만 이 창에는 이 선택을 위한 버튼이 없습니다. 이는 결함으로 보입니다. 이런 리소스는 4단계에 따라 *라이브러리로* 버튼으로 라이브러리에 넣으세요.
