# 설정

**설정** 창에는 앱 설정이 있습니다: 프로젝트 파일과 무관하게 이 기기에 적용되는 환경설정입니다. 모든 변경 사항은 즉시 적용되고 저장됩니다 — 확인 버튼이 없습니다. 계산된 일정을 바꾸는 스케줄링 옵션은 대신 프로젝트에 속합니다 — [프로젝트 정보](docs://ref-projectgegevens)를 참조하세요.

## 열기 — 세 가지 입구, 같은 내용

- 제목 표시줄의 **톱니바퀴**(⚙).
- **설정**(리본 탭) → 리본 그룹 **프로젝트** → **설정**.
- **파일** → **설정**(백스테이지).

세 곳 모두 정확히 같은 설정을 보여 줍니다. 버전에 따라 세 개 또는 네 개의 탭에 나뉘어 있습니다 —
네 번째 탭인 **애플리케이션**은 최근에 첫 번째 탭의 뒷부분에서 분리되었습니다 — 하지만 설정
자체와 그 동작은 어느 경우든 동일합니다; 이 문서는 이를 **일반**, **언어**, **타임라인 / 확대/축소**로
묶어서 설명합니다.

## 일반 탭

**모양:**

- **테마** — **어두운 테마**, **밝은 테마** 또는 **고대비**; 카드를 클릭하여 전환합니다.
- **글꼴** — **기본**, **시스템**, **세리프** 또는 **고정 폭**; 인터페이스의 서체를 재정의합니다. 웹 앱은 시스템 글꼴 설정을 자동으로 따르지 않으므로, 이 항목과 다음 항목이 직접 선택하는 방법입니다.
- **텍스트 크기** — 90%, 100%, 110% 또는 125%; 인터페이스 텍스트와 레이아웃을 조정합니다.
- **문서 전환 스타일** — 열린 문서 간 전환 방법: **가로 탭**, **세로 탭** 또는 **알약**.
- **날짜 형식** — **dd-mm-yyyy**, **mm-dd-yyyy** 또는 **yyyy-mm-dd**. 표시 전용이며, 파일과 계산에는 영향을 주지 않습니다.
- **건설 모드** — **건설 모드 사용**은 *새* 프로젝트의 기본값을 건설 지향(네덜란드 공휴일이 포함된 건설 달력, 건설 휴가, 단계 템플릿)과 중립적이고 건설에 종속되지 않은 구성 사이에서 전환합니다. 기존 프로젝트는 어느 경우든 영향을 받지 않습니다.

**애플리케이션:**

- **버전** — 앱의 버전 번호(읽기 전용)와, 업데이트 창을 여는 링크 **업데이트 확인**. 업데이트 설치는 데스크톱 앱에서만 작동합니다; Snap과 AppImage 설치는 자체 채널로 업데이트됩니다. 별도로, 앱이 스스로 자동 업데이트된 후 처음 열 때는 일회성 "방금 업데이트되었습니다" 대화상자가 자동으로 나타납니다 — 버전 변화, 설치 파일 크기 차이, 이전 릴리스 이후 경과일, 그리고 가져올 수 있었던 GitHub 릴리스 노트까지요. 이는 위의 수동 **업데이트 확인** 링크와는 다른, 자동으로 일어나는 순간입니다.
- **투어** — **투어 시작**은 소개 투어를 다시 재생합니다. 같은 재시작 버튼은 **보기** 리본 탭 → **투어**와 백스테이지(**파일** → **투어 시작**)에도 있습니다.
- **벤치마크** — 이 기기의 스케줄링/렌더링 성능을 측정하기 위한 내장 벤치마크 도구를 엽니다.
- **AI 모드** — **AI 모드 사용**은 MCP 브리지가 포함된 **AI** 리본 탭을 표시하여, AI 어시스턴트가 Model Context Protocol을 통해 여러분의 일정에서 작업할 수 있게 합니다; 끄면 실행 중인 브리지가 즉시 중지됩니다. **브리지 자동 시작**(AI 모드가 켜져 있을 때만 사용 가능)은 AI 탭을 먼저 열지 않아도 앱이 시작되는 즉시 브리지를 실행합니다 — 데스크톱 앱 전용입니다. 전체 내용은 앱 내 AI 어시스턴트 가이드를 참조하세요.
- **디버그 터미널** — **디버그 터미널 활성화**는 문제 해결을 위한 로그 패널을 표시합니다.

## 통계 (응용 프로그램 탭의 버튼)

**설정** → **응용 프로그램** 탭 → **통계…** 로 엽니다. 의도적으로 별도 탭이 아니라 버튼 뒤의 별도 창입니다.

Open Planner Studio가 운영체제별, 릴리스별로 다운로드된 횟수입니다. 수치는 GitHub Releases의 공개 다운로드 카운터에서 가져오며 매주 갱신됩니다. 앱은 읽기만 하며, 사용자에 대한 정보는 수집하거나 전송하지 않습니다.

- **운영체제별 다운로드** — 시스템별 다운로드 수를 설치 파일(사람이 직접 받는 것)과 업데이트(앱 내 업데이터가 받는 것)로 나누어 표시합니다. Linux는 둘이 하나의 수치입니다. 업데이터가 수동 다운로드와 같은 `.deb`/`.rpm`/`.AppImage`를 받기 때문입니다. Linux에서는 snap 파일만 설치 파일로 집계합니다.
- **앱에서의 업데이트 확인** — 데스크톱 설치본이 시작할 때 새 버전을 확인한 횟수입니다. 활성 사용의 대략적인 지표이며 다운로드가 아닙니다.
- **릴리스별** — 같은 수치를 버전별로 표시합니다. 기본은 최신 6개이며 나머지는 **전체 …개 릴리스 표시**로 펼칩니다.
- **출처** — 수치의 기준일과 **지금 새로 고침**. 탭은 마지막으로 가져온 수치를 30분 동안 기억하며, 새로 고침이 실패하면 그 수치를 알림과 함께 계속 표시합니다.

Snap Store를 통한 설치는 GitHub를 거치지 않으므로 여기에 포함되지 않습니다.

## 타임라인 / 확대/축소 탭

- **시간 단위 계획** — **시간 단위 계획 사용**은 시간축과 구체적인 근무 시간대를 켭니다. 끄면 새 작업은 일 단위로 시작하고 기존 시간 작업의 정확한 값은 유지됩니다. 켜면 일 작업과 시간 작업이 함께 존재할 수 있습니다. [달력 및 시간 단위 계획](docs://gids-kalenders-uren)을 참조하세요.
- **기간 표시** — **자동 (작업별 고유 단위)**, **항상 일** 또는 **항상 시간**.
- **중단 시 작업 막대** — **분할 안 함**, **선택 시 분할** 또는 **항상 분할**: 비근무일 주변에서 막대가 시각적으로 분할되는지 여부.
- **타임라인 축** — **근무일만 표시**는 타임라인을 압축합니다: 프로젝트 달력의 주말과 공휴일을 건너뛰므로, 그 사이의 달력이 어떻든 5 근무일짜리 작업은 정확히 5개 열 너비가 됩니다.
- **주 시작 요일** — **월요일** 또는 **일요일**(시간축의 주 레이아웃).
- **최대 확대 시 15분 단위 표시** — 시간 시간축에 추가적인 15분 단위 눈금.
- **계산** — **자동 계산**은 F5를 기다리지 않고 일정이 오래되는 즉시 다시 계산합니다.
- **스크롤 및 확대/축소** — **모드**:
- **확대/축소 + 드래그**(기본값) — 스크롤 휠로 확대/축소(커서 기준); 차트 배경을 드래그하여 보기를 이동합니다; Shift+스크롤 휠은 행 사이를 스크롤합니다; Ctrl/⌘+드래그는 선택 상자를 그립니다.
- **위치** — 커서 위치가 스크롤 방향을 결정합니다; **화면 분할**(**좌/우**, **상/하** 또는 **우상단 모서리**) 포함. Ctrl+스크롤 = 확대/축소, Shift+스크롤 = 가로.
- **키** — 어떤 조작(**스크롤**, **Ctrl + 스크롤**, **Shift + 스크롤**)이 어떤 기능(**세로**, **가로**, **확대/축소**)을 수행하는지 칩을 드래그하여 지정합니다; 이미 사용 중인 슬롯에 놓으면 조작이 서로 바뀝니다.
