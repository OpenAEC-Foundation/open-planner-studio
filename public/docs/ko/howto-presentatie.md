# 큰 화면에서 발표하기

목표: 리본과 패널 없이 Gantt 차트를 전체 화면으로 보여 줍니다. 예를 들어 현장 회의에서 프로젝터나 TV에 보여 줄 때입니다.

## 이런 때 필요합니다

현장 사무실에서 열 명이 화면 하나를 봅니다. 그러면 리본, 상태 표시줄과 속성 패널이 일정에 필요한 공간을 차지하고, 주의를 흩뜨립니다. **프레젠테이션 모드**에서는 앱이 작업 표와 Gantt 차트만 전체 화면에 남깁니다.

## 단계

### 보기 준비하기

프레젠테이션 모드에서는 리본이 없으므로, 보여 줄 내용을 미리 설정하세요.

1. **계산** (F5)를 누르세요. 그래야 표시되는 날짜가 맞습니다.
2. 보여 주려는 보기를 설정하세요. 예를 들어 주공정 작업만 보여 주는 레이아웃을 사용할 수 있습니다(참조: [레이아웃 만들기 및 사용](docs://howto-layouts-gebruiken)).
3. 멀리서도 작업 이름을 읽을 수 있는 시간 척도와 확대 수준을 선택하세요. 그리고 *보기* 탭의 *개요* 그룹에 있는 *접기*와 *펼치기*로 단계를 접거나 펼치세요.
4. 원하면 *분할 보기*와 *미니맵*을 켜세요(참조: [분할 보기와 미니맵 사용](docs://howto-split-view-en-mini-map)).

### 프레젠테이션 시작하기

*보기 › 프레젠테이션 › 프레젠테이션*을 선택하세요. 데스크톱 앱에서는 F11 키를 누를 수도 있습니다. 브라우저에서 F11은 브라우저 자체의 기능입니다. 브라우저 창을 전체 화면으로 바꾸고, 앱은 그대로 둡니다. 리본, 탭, 상태 표시줄과 오른쪽 패널이 사라집니다. 작업 표와 Gantt 차트가 보입니다. 켜 두었다면 히스토그램과 미니맵도 보입니다. 화면 아래쪽에 몇 초 동안 *Esc 또는 F11 키를 눌러 전체 화면을 종료하세요.* 메시지가 표시됩니다.

데스크톱 앱에서는 어느 탭에서든 F11 키로 프레젠테이션을 시작할 수 있습니다. *테이블*이나 *보고서*에서도 가능합니다. 브라우저에서는 *보기 › 프레젠테이션 › 프레젠테이션*으로만 시작합니다. 열린 프로젝트의 Gantt 차트가 항상 보입니다. 프레젠테이션을 끝내면 시작했던 탭으로 돌아갑니다. 그러므로 브라우저에서는 그 탭이 *보기*입니다.

### 프레젠테이션 끝내기

Esc 또는 F11을 누르세요. 리본과 패널이 시작했던 탭에 다시 나타납니다.

## 주의할 점과 앱의 동작

**프레젠테이션 모드에서도 편집할 수 있습니다.** 클릭, 끌기, 셀 편집과 Delete 키가 그대로 작동합니다. 막대를 실수로 끌면 막대가 이동하고 일정이 더 이상 최신 상태가 아닙니다. 실수로 삭제한 작업은 Ctrl+Z로 되돌릴 수 있습니다. 프레젠테이션 모드에서도 가능합니다. 그러므로 여러 사람과 작업할 때는 클릭에 주의하세요.

**알림은 계속 표시됩니다.** 저장 오류 같은 앱 메시지도 프레젠테이션 모드에 표시됩니다. 그 밖에는 리본과 상태 표시줄이 없으므로, 이런 메시지가 문제를 알려 주는 유일한 신호입니다.

**분할 보기, 미니맵과 레이아웃은 미리 설정하세요.** 이 설정에는 리본이 필요하지만 이 모드에서는 리본이 없습니다. 확대와 축소는 작동합니다. 마우스 휠이나 Ctrl+= 및 Ctrl+-를 사용하세요. +와 -도 작동하지만 포커스가 Gantt 차트에 있을 때만 작동합니다. 시작한 뒤에는 포커스가 자주 작업 표에 있으므로 먼저 Gantt 차트를 클릭하세요.

**전체 화면이 작동하지 않습니다.** 앱은 리본을 숨기는 것 외에 실제로 전체 화면도 요청합니다. 브라우저나 창이 이를 거부하면 리본과 패널만 사라집니다. 프레젠테이션은 그래도 작동합니다. Esc 또는 F11이 아닌 다른 방법으로 전체 화면을 나가면, 예를 들어 운영 체제의 키를 사용하면, 프레젠테이션 모드도 함께 종료됩니다.

**프레젠테이션 모드는 기억되지 않습니다.** 앱을 닫았다가 다시 열면 꺼져 있습니다.
