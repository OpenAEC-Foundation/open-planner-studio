# IFC 스키마 선택하기

목표: 합치려는 건물 모델의 IFC 스키마로 일정을 저장합니다.

## 이 기능이 필요한 경우

기본적으로 앱은 프로젝트를 IFC 4.3 ADD2로 저장합니다. 이는 IfcOpenShell과 Bonsai가 만드는 파일에서 쓰는 IFC 4.3의 이름입니다. 예를 들어 IfcOpenShell(ifcpatch)의 *MergeProjects* 레시피로 일정을 건물 모델과 합쳐 하나의 4D 파일로 만들려면, 두 파일의 스키마가 같아야 합니다. 건물 모델이 IFC4 파일이면 IfcOpenShell은 이를 IFC 4.3 일정과 합치지 않습니다. 이때는 여기에서 모델의 스키마를 선택하세요.

## 단계

1. *프로젝트 설정*을 엽니다: *설정 › 프로젝트 › 프로젝트 설정*, 또는 *파일 › 프로젝트 설정*.
2. *저장 시 IFC 스키마*에서 건물 모델의 스키마를 선택하세요.
3. *적용*을 클릭하세요. 프로젝트 상태가 *저장되지 않음*이 됩니다.
4. *저장*(Ctrl+S) 또는 *다른 이름으로 저장*으로 저장하세요.

세 가지 선택지는 다음과 같습니다:

- *IFC 4.3 ADD2 (기본)*은 파일 헤더에 `IFC4X3_ADD2`를 씁니다.
- *IFC 4.3*은 `IFC4X3`를 씁니다. 이전 버전의 앱이 IFC 4.3을 쓰던 방식입니다.
- *IFC4*는 `IFC4`를 씁니다. IFC4 건물 모델에 사용합니다.

## 주의 사항과 앱의 동작

**합치기는 마지막 단계로 하세요.** 합쳐진 4D 파일(건물 모델과 일정)을 앱에서 열고 다시 저장하지 마세요. 앱은 일정만 보관합니다. 벽과 건물 모델의 다른 부분은 스키마를 유지하더라도 사라집니다. 일정은 자신의 파일에서 변경한 뒤 다시 합치세요.

**열린 파일에 다른 스키마가 있으면 앱이 먼저 묻습니다.** 예를 들어 IFC4 파일 또는 이전 버전의 앱이 만든 IFC 4.3 파일을 열면, 앱은 파일 형식을 그냥 바꾸지 않습니다. *저장* 또는 *다른 이름으로 저장*을 처음 사용하면, 앱이 먼저 파일의 스키마를 유지할지 아니면 IFC 4.3 ADD2로 바꿀지 묻습니다. *IFC4 유지*(또는 *IFC 4.3 유지*)는 엔터로 선택하는 버튼입니다. Esc 키나 닫기(X) 버튼으로 질문을 닫으면 앱은 아무것도 저장하지 않습니다.

**앱은 파일마다 한 번만 묻습니다.** 선택한 내용은 파일 자체에 저장됩니다. 나중에 파일을 다시 열어도 앱은 다시 묻지 않습니다. *프로젝트 설정*에서 스키마를 직접 선택하고 *적용*을 클릭하면 앱은 묻지 않습니다.

**앱이 쓸 수 없는 스키마**(예: IFC2X3)도 앱에서 열립니다. 처음 저장할 때 질문에서 이를 알려 주며, 위의 세 가지 스키마 중 하나를 선택하세요.

**자동 저장과 충돌 복구는 묻지 않습니다.** 두 기능은 파일의 스키마로 기록하며, 직접 처음 저장할 때까지 질문을 남겨 둡니다. 앱이 쓸 수 없는 스키마의 경우, 질문에 답하기 전까지 *자동 저장*은 파일에 기록하지 않습니다.

**새 프로젝트는 묻지 않습니다.** 새 프로젝트와 XER, MPP, CSV 같은 다른 형식의 프로젝트는 *IFC 4.3 ADD2 (기본)*으로 시작합니다.

**파일 내용은 바뀌지 않습니다.** 세 스키마는 앱이 같은 방식으로 기록하는 일정 데이터를 모두 지원합니다. 헤더의 `FILE_SCHEMA` 줄만 다릅니다. 따라서 다른 스키마를 선택해도 잃는 것은 없습니다.

**IfcOpenShell 또는 Bonsai의 IFC 4.3 모델**은 보통 앱의 기본값과 같이 헤더에 `IFC4X3_ADD2`가 있습니다. IfcOpenShell은 `IFC4X3` 일정을 이 모델과 합치지 않습니다. 확실하지 않으면 모델 파일 맨 위의 `FILE_SCHEMA` 줄을 확인하세요.

**실행 취소는 스키마를 바꾸지 않습니다.** 스키마는 파일에 속하며, 파일이 저장된 위치와 같습니다. 따라서 *프로젝트 설정*에서 고른 내용과 저장할 때 질문에 답한 내용은 *실행 취소*의 한 단계가 아닙니다. 되돌리려면 *프로젝트 설정*에서 다른 스키마를 선택하세요. 이렇게 하면 편집을 실행 취소한 뒤 *자동 저장*이 다른 스키마를 몰래 기록하는 일이 없습니다.
