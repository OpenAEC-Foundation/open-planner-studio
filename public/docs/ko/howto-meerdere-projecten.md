# 여러 프로젝트를 동시에 작업하기

목표: 일정을 둘 이상 열고, 그 사이를 전환하고, 각각 따로 닫습니다.

## 이 기능이 필요한 경우

동네의 주택 개발 사업을 진행하는 중입니다. 그런데 현장 회의에서는 클럽하우스 개조도 다룹니다. 또는 원래 일정 옆에 변형안을 보관하려고 합니다. 각 프로젝트는 자체 탭에 있으며, 고유한 작업, 계산 및 시간 범위를 가집니다. 전환은 한 번의 클릭으로 되며 아무것도 잃지 않습니다.

## 단계

### 두 번째 프로젝트 열기

1. 탭 오른쪽의 더하기 기호를 클릭합니다(*프로젝트 시작*). *프로젝트 시작* 창이 열립니다.
2. 빈 일정을 만들려면 *새 프로젝트*를 선택합니다. 파일을 고르려면 *기존 프로젝트 열기*를 선택합니다. *취소*를 누르면 창이 닫힙니다.
3. *새 프로젝트*를 선택한 경우 *새 프로젝트* 창에 정보를 입력하고 *만들기*를 클릭합니다.

프로젝트는 자체 탭에 나타나며 바로 활성 상태가 됩니다. 리본의 *새로 만들기*와 *열기*, Ctrl+O, 그리고 *파일 › 예제*의 예제도 새 탭에서 프로젝트를 엽니다. 아직 건드리지 않은 새 빈 일정만 탭을 추가하는 대신 재사용됩니다.

### 프로젝트 사이 전환하기

- 프로젝트의 탭을 클릭합니다.
- Ctrl+1부터 Ctrl+9까지(macOS에서는 Ctrl 대신 ⌘)를 누르면 탭 줄에서 왼쪽에서 오른쪽으로 센 위치의 프로젝트로 이동합니다.
- 탭 왼쪽의 메뉴 아이콘을 클릭합니다(*모든 프로젝트*). *열린 프로젝트* 개요에는 프로젝트마다 카드가 표시됩니다. 카드에는 이름, 파일 이름(프로젝트에 파일이 있는 경우), 일정의 미리 보기, 작업 수, 주공정 작업 수, 종료일이 나타납니다. 카드를 클릭하면 해당 프로젝트로 이동합니다. Esc를 누르면 개요가 닫힙니다.

각 탭에는 해당 프로젝트에 속한 색 점이 있습니다. 탭 이름 뒤에 작은 점이 있는 탭에는 저장되지 않은 변경 사항이 있습니다.

탭이 너비에 모두 들어가지 않으면 탭과 더하기 기호 사이에 화살표 두 개가 나타납니다(*탭을 처음으로 스크롤*과 *탭을 끝으로 스크롤*). 클릭할 때마다 탭이 두 칸씩 이동합니다. 탭이 이미 처음이나 끝까지 스크롤되어 있으면 화살표가 회색으로 표시됩니다. 탭 위에서 마우스 휠로도 스크롤할 수 있습니다. 선택한 탭은 항상 자동으로 화면에 나타납니다.

### 프로젝트 닫기

탭의 이름 옆에 있는 ×를 클릭하거나(*닫기*), 개요의 카드에 있는 ×를 클릭합니다. 변경 사항이 없는 프로젝트는 바로 닫힙니다. 저장되지 않은 변경 사항이 있으면 앱이 세 가지 선택지와 함께 *저장되지 않은 변경 사항* 대화 상자를 표시합니다:

- *저장*은 프로젝트를 저장한 다음 닫습니다.
- *저장 안 함*은 프로젝트를 닫고 변경 사항을 버립니다.
- *취소*는 프로젝트를 열린 상태로 둡니다.

저장을 취소하면(예: 저장 대화 상자를 닫는 경우) 프로젝트는 열린 상태로 남습니다.

마지막 프로젝트를 닫으면 이름이 *새 계획*인 빈 일정이 남습니다.

### 전환 방식 고르기

탭 방식은 선택할 수 있습니다. 제목 표시줄의 톱니바퀴 아이콘으로 *앱 설정* 창을 엽니다. *모양* 탭으로 이동하여 *문서 전환 스타일*에서 선택합니다:

- *가로 탭*: 기본값입니다. 리본 아래에 있는 탭 한 줄입니다.
- *세로 탭*: 왼쪽의 좁은 막대입니다. 프로젝트마다 버튼이 하나씩 있고(이름의 첫 글자), 더하기 버튼도 있습니다. 버튼 위에 마우스를 올리면 이름, 파일 이름, 작업 수, 주공정 작업 수, 종료일이 표시됩니다. 맨 위 버튼은 개요를 엽니다.
- *알약*: 제목 표시줄에 있는 알약 모양 버튼 하나입니다. 활성 프로젝트의 이름과 *2 open* 같은 개수 표시가 들어 있습니다. 클릭하면 개요가 열리고 거기서 전환할 수 있습니다.

세 가지 방식 모두 같은 개요를 열며, Ctrl+1부터 Ctrl+9까지는 모든 방식에서 작동합니다.

## 주의할 점과 앱의 동작

**무엇이 프로젝트에 속하고 무엇이 공유되는지.** 각 프로젝트에는 고유한 보기가 있습니다. 여기에는 확대/축소 수준과 위치, 필터, 그룹화 또는 정렬이 적용된 활성 레이아웃, 분할 보기, 관계선, 접힌 단계가 포함됩니다. 다른 프로젝트로 전환하면 그 프로젝트의 보기가 나타납니다. 모든 프로젝트가 공유하는 항목은 리본에서 선택한 탭, 미니맵, 오버레이(기준선 오버레이, 진행선 등), 열 선택, 레이아웃, 보고서 선택입니다.

**대화 상자가 열려 있으면 전환할 수 없습니다.** *앱 설정* 창이나 작업 창처럼 대화 상자가 열려 있는 동안에는 Ctrl+1부터 Ctrl+9까지가 앱에서 아무 동작도 하지 않습니다. 브라우저에서는 이 키로 브라우저 탭이 전환됩니다. 먼저 대화 상자를 닫습니다. 백스테이지의 *프로젝트 설정*에서 적용되지 않은 변경 사항이 있으면 전환도 막힙니다.

**Ctrl+1부터 Ctrl+9까지는 순서대로 셉니다.** 단축키는 줄에서 그 위치에 있는 프로젝트로 이동합니다. 프로젝트를 닫으면 나머지 위치가 한 칸씩 앞으로 당겨집니다. 아홉 개보다 많은 프로젝트를 열면 나머지 프로젝트로는 탭이나 개요를 통해서만 이동할 수 있습니다.

**계산과 보고서 기능은 활성 프로젝트에서 작동합니다.** 계산(F5), *PDF 내보내기*, 보고서는 지금 활성 상태인 프로젝트를 대상으로 합니다.
