# 작업과 마일스톤 추가하기

목표: 새 작업이나 마일스톤을 일정의 알맞은 위치에 넣는 것입니다.

## 이 기능이 필요한 경우

일정을 만드는 중이거나, 새 공사 범위가 추가되거나, 인계나 검사 같은 시점을 기록하려는 경우입니다.

**작업**은 시간이 걸리는 일입니다. 새 작업은 기본적으로 5 근무일 동안 지속됩니다. 시간 단위 계획을 사용하면 프로젝트 기본값이 시간일 수 있습니다. **마일스톤**은 기간이 없는 시점입니다. 기간은 0일입니다. 하위 작업이 있는 작업을 **요약 작업**이라고 합니다. 건설에서는 보통 단계입니다. **계산** (F5)를 사용하는 즉시 요약 작업의 기간과 날짜가 하위 작업에서 정해집니다.

## 단계

### 작업 추가하기

1. *홈 › 작업 › 작업*을 선택합니다. 같은 버튼이 *테이블* 탭에도 있습니다.
2. *속성* 패널이 열리고 *이름* 필드가 선택됩니다. 이름을 입력하고 Enter를 누릅니다.

새 작업의 처음 이름은 *새 작업*이며, 프로젝트 시작일에 시작합니다.

작업이 선택되어 있으면 새 작업은 그 바로 아래, 같은 수준에 추가됩니다. 선택한 작업이 요약 작업이면 새 작업은 그 단계 전체 아래, 즉 하위 작업 뒤에 추가됩니다. 아무것도 선택되어 있지 않으면 목록 맨 아래에 추가됩니다. 버튼의 도구 설명에 어떤 동작이 일어날지 나옵니다. 그 두 문구는 *선택한 작업 바로 아래에 새 작업 추가* 또는 *목록 맨 아래에 새 작업 추가*입니다. 작업을 여러 개 선택하면 새 작업이 하나만 만들어집니다. 새 작업은 화면에 보이는 순서에서 선택한 작업 중 가장 아래 작업 아래에 추가됩니다.

### 작업 표에서 연달아 추가하기

작업 표에서 마지막 작업 아래에는 항상 회색 *새 작업* 행이 있습니다. 이 행은 아직 작업이 아닙니다. Gantt 차트에도 없고 파일에도 없습니다.

1. 그 행의 셀을 클릭하거나 아래쪽 화살표로 그 행으로 이동합니다.
2. 이름을 입력하고 Enter를 누릅니다. 이제 실제 작업이 되며, 위에 있는 작업과 같은 수준입니다. 커서는 바로 아래의 새 회색 행에 놓입니다.
3. 다음 이름을 입력하고, 같은 방식으로 계속합니다.

회색 행에 기간이나 날짜만 입력하면 작업 이름은 *새 작업*이 됩니다. 아무것도 입력하지 않고 나가면 아무 일도 일어나지 않습니다. 작업도 없고 *실행 취소*에 단계도 추가되지 않습니다. 작업 생성과 첫 값 입력은 *실행 취소*에서 한 단계로 함께 묶입니다. 회색 행은 필터, 그룹화 또는 정렬이 없는 작업 표에만 있습니다.

### 빈 공간에서 마우스 오른쪽 버튼 사용하기

빈 공간을 마우스 오른쪽 버튼으로 클릭합니다. 마지막 작업 아래의 작업 표에서 클릭하거나, 막대 옆이나 아래의 Gantt 차트에서 클릭합니다. *새 작업* 또는 *마일스톤 추가*를 선택합니다. 작업은 목록 맨 아래에 추가됩니다. Gantt 차트에서는 클릭한 날짜에서 시작합니다. 작업 표에서는 이름 셀이 바로 열리므로 바로 입력할 수 있습니다.

### 특정 작업 위 또는 아래에 추가하기

작업을 마우스 오른쪽 버튼으로 클릭하고 *위에 삽입* 또는 *아래에 삽입*을 선택합니다. 키보드로도 할 수 있습니다. Insert 키는 선택한 작업 위에 추가하고, Ctrl+I(Mac에서는 ⌘+I)는 그 아래에 추가합니다. 작업 표에서는 Insert 키를 누르면 이름 셀이 바로 열리므로 바로 입력할 수 있습니다.

작업을 여러 개 선택하면 새 작업이 하나만 만들어집니다. *위에 삽입*은 가장 위에 선택한 작업 위에, *아래에 삽입*은 가장 아래에 선택한 작업 아래에 추가합니다.

### 하위 작업 추가하기

작업을 마우스 오른쪽 버튼으로 클릭하고 *하위 작업 추가*를 선택합니다. 새 작업은 그 작업의 하위 작업 맨 아래에 추가됩니다. Gantt 차트 옆의 작업 표에서는 요약 작업 이름 뒤에 작은 **+**가 있습니다. 이 **+**도 같은 동작을 합니다.

### 마일스톤 추가하기

1. *홈 › 작업 › 마일스톤 ▾*을 선택합니다. 그다음 *시작 마일스톤*, *완료 마일스톤* 또는 *검사 지점(필수)*를 선택합니다.
2. 이름을 입력하고 Enter를 누릅니다. 위치는 *작업*과 같은 규칙을 따릅니다.

세 종류는 다음과 같이 다릅니다.

- *시작 마일스톤*은 날의 시작에, *완료 마일스톤*은 날의 끝에 놓입니다. Gantt 차트에서 다이아몬드는 각각 날짜 열의 왼쪽 또는 오른쪽에 놓입니다. 후속 작업에도 영향을 줍니다. 예를 들어 마일스톤이 2026년 9월 29일 화요일에 있고, 그 뒤에 완료-시작 관계로 작업이 연결되어 있다고 하겠습니다. 시작 마일스톤 뒤에서는 그 작업이 같은 화요일에 시작합니다. 완료 마일스톤 뒤에서는 2026년 9월 30일 수요일에 시작합니다.
- *검사 지점(필수)*는 공종이 *검사*이고 *필수(계약상)*에 체크한 완료 마일스톤입니다.

### 기존 작업을 마일스톤으로 바꾸기

작업을 마우스 오른쪽 버튼으로 클릭하고 *마일스톤 전환*을 선택합니다. 또는 *속성* 패널에서 *마일스톤*에 체크 표시를 합니다. 이 메뉴 항목은 선택 전체에 적용됩니다. 기간은 0이 됩니다.

마일스톤을 다시 끄면 기간이 0인 일반 작업으로 남습니다. 기간은 직접 입력하세요.

### 다른 방법

- Ctrl+M(Mac에서는 ⌘+M)은 작업이 선택되어 있어도 목록 맨 아래에 새 마일스톤을 추가합니다. *속성* 패널은 열리지 않습니다.
- Ctrl+M 또는 마우스 오른쪽 버튼 메뉴로 만든 마일스톤은 공종 *검사*를 받습니다. *마일스톤 ▾*의 *시작 마일스톤* 또는 *완료 마일스톤*은 공종 *기타*를 받습니다. 필요하면 *속성*에서 공종을 바꾸세요.
- 작업의 마우스 오른쪽 버튼 메뉴에 있는 *마일스톤 추가*는 마일스톤을 그 작업의 하위 작업으로 만듭니다. 같은 수준의 작업으로 만들지 않습니다.

### 작업 또는 전체 하위 구조 복사하기

1. Gantt 차트에서 작업의 막대를 클릭합니다. Ctrl+클릭으로 작업을 더 선택합니다.
2. Ctrl+C(Mac에서는 ⌘+C)를 누릅니다. 앱은 작업을 모든 하위 작업, 복사된 작업 사이의 관계, 그리고 리소스 할당과 함께 복사합니다.
3. 원하는 경우 복사본을 넣을 위치의 작업 막대를 클릭하고 Ctrl+V(⌘+V)를 누릅니다.

복사본은 이름, 날짜, 진행률이 원본과 같습니다. 복사본은 선택한 작업과 같은 수준의 작업으로 들어갑니다. 여러 개를 선택했다면 먼저 클릭한 작업을 기준으로 합니다. 같은 수준의 작업 중 맨 아래에 놓입니다. 아무것도 선택하지 않았다면 목록 맨 아래에 놓입니다. 복사한 작업은 그 뒤에 선택됩니다. WBS 코드(트리에서 각 작업의 번호, 예: 1.2; 참고: [구조 조정하기](docs://howto-structuur-aanpassen))는 다시 정해지며, 일정은 더 이상 최신 상태가 아닙니다.

클립보드는 앱 전체가 공유하므로 다른 문서에도 붙여 넣을 수 있습니다. 그곳에 없는 항목(예: 작업 달력, 사용자 지정 공종, 활동 코드, 사용자 지정 필드)은 앱이 지우고 알려 줍니다.

### 그 후

새 작업을 추가해도 다른 날짜는 아직 바뀌지 않습니다. 상태 표시줄에 *오래됨 — 다시 계산하세요 (F5)*가 표시됩니다. **계산** (F5)를 누릅니다. 예를 들어 *홈 › 일정 › 계산*에서 선택할 수 있습니다.

## 문제 상황과 앱의 동작

**모든 새 작업은 프로젝트 시작일에 시작합니다.** 관계가 없으면 작업은 아무것도 기다리지 않습니다. 관계를 추가하세요. [관계 추가하기](docs://howto-relaties-leggen)를 참고하세요.

**필터, 그룹화 또는 정렬이 켜져 있습니다.** 이때 보이는 순서는 일정의 순서가 아닙니다. 작업을 선택한 상태에서 *작업*과 *마일스톤 ▾*은 새 작업을 목록 맨 아래에 추가합니다. 그러면 빨간 알림이 나타나며 *새 작업이 맨 끝에 추가되었습니다. 필터, 그룹화 또는 정렬 중에는 앱이 선택 항목 아래에 넣을 수 없습니다*라고 알려 줍니다. *위에 삽입*과 *아래에 삽입*은 거부되며, *필터링/그룹화/정렬 중에는 사용할 수 없습니다* 띠가 나타납니다. 알림이나 띠의 *지우기* 버튼은 필터, 그룹화, 정렬을 한 번에 제거합니다. 이 동작은 *실행 취소*에 포함되지 않습니다. Ctrl+Z는 이를 되돌리지 않습니다.

**리소스 할당이 있는 작업 아래에 하위 작업을 추가하는 경우.** 그 작업은 요약 작업이 됩니다. 요약 작업은 할당을 직접 가질 수 없습니다. 앱은 할당을 새 하위 작업으로 옮기고 알려 줍니다. 옮길 수 없으면 앱은 아무것도 추가하지 않고 그 이유를 알려 줍니다. 예를 들어 *마일스톤 추가*를 선택했다면 마일스톤은 할당을 가질 수 없습니다.

**마일스톤 아래에 하위 작업을 추가하는 경우.** 마일스톤은 요약 작업이 되고, 앱은 마일스톤 표시를 제거하며 메시지를 보여 줍니다.

**요약 작업이나 리소스 할당이 있는 작업에 마일스톤을 켜는 경우.** 앱은 실행을 거부하고 그 이유를 알려 줍니다. 할당이 있다면 먼저 할당을 제거하세요.

**작업 표에서 복사하는 경우.** 작업 표(및 *테이블* 탭)에서 Ctrl+C는 스프레드시트처럼 선택한 셀의 값만 복사합니다. Ctrl+V는 값을 셀에 붙여 넣습니다. 따라서 작업은 Gantt 차트를 사용할 때만 복사할 수 있습니다. 먼저 막대를 클릭하세요.
