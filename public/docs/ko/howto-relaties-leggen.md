# 관계 추가

목표: 작업을 서로 연결합니다. 그러면 작업은 앞선 일이 끝나야만 시작합니다. 필요한 곳에서는 작업 사이에 대기 시간(지연)을 추가합니다.

## 이 기능이 필요한 경우

관계가 없으면 앱은 벽돌공이 기초를 타설한 뒤에야 시작할 수 있다는 것을 알지 못합니다. 그러면 모든 작업이 프로젝트 시작일에 시작하고, 완료 날짜는 의미가 없습니다. **관계**는 이 순서를 기록합니다. 첫 번째 작업은 **선행 작업**이고, 두 번째 작업은 **후속 작업**입니다.

일정을 만들 때, 작업을 추가할 때, 또는 두 작업이 나중에 서로 의존한다는 것이 드러날 때 관계를 추가합니다. **지연**은 두 작업 사이의 대기 시간입니다. 예를 들면 양생해야 하는 콘크리트나 건조해야 하는 바닥 모르타르 미장이 있습니다.

기본 관계는 **FS**(완료-시작)입니다. 이 경우 선행 작업이 끝나야 후속 작업을 시작할 수 있습니다. 앱은 SS, FF, SF 유형도 지원합니다. 이들은 시작이나 완료를 다른 시작이나 완료에 연결합니다. 예를 들어 SS(시작-시작)에서는 설비 공사가 시작한 뒤에야 미장을 시작할 수 있습니다.

어떤 유형이 필요한지 모르겠다면 유형을 고르는 곳 아래에는 실제 작업 이름이 들어간 문장이 나와 그 뜻을 설명합니다. 예를 들면 *Metselwerk은(는) Fundering이(가) 끝난 뒤에 시작합니다.* 다른 유형을 고르면 문장도 바뀝니다. 이 문장은 *관계 유형* 창, *관계* 블록, 그리고 *선행 작업* 또는 *후속 작업* 열에서 볼 수 있습니다.

## 단계

관계를 추가하는 방법은 네 가지입니다. 모두 같은 관계를 만듭니다. 상황에 가장 맞는 방법을 고르세요.

### 선택한 두 작업 연결

작업 표에서 작업할 때 유용합니다.

1. 작업 표에서 먼저 오는 작업, 즉 선행 작업을 클릭합니다.
2. Ctrl 키(Mac에서는 ⌘)를 누른 채 다음 작업, 즉 후속 작업을 클릭합니다.
3. *홈 › 작업 › 연결 ▾ › 선택한 작업 연결*을 선택합니다. 같은 버튼이 *계획 › 관계*에도 있습니다.

앱은 지연 없이 완료-시작 관계를 만듭니다. 관계는 Gantt 차트와 *선행 작업* 열에 화살표로 나타납니다. 알림은 앱이 관계를 거부할 때만 나타납니다. 이 버튼은 작업이 정확히 두 개 선택되었을 때만 작동합니다.

### Gantt 차트에서 관계 그리기

많은 관계를 연달아 추가할 때 유용합니다.

1. *홈 › 작업 › 연결 ▾ › 관계 그리기*를 선택합니다. 일정 위에 안내 문구 *링크 모드: 간트 차트에서 막대에서 다른 막대로 끌어 관계를 만듭니다. Esc를 누르면 종료됩니다.*가 나타납니다.
2. 선행 작업의 막대를 누른 채 후속 작업의 막대까지 끄세요. 화살표가 있는 점선이 마우스를 따라갑니다.
3. 손을 떼세요. 작은 *관계 유형* 창이 나타나고, 유형(기본값은 FS)과 지연 입력 칸이 있습니다.
4. 필요하면 유형이나 지연을 바꾸고 Enter를 누르거나 창 밖을 클릭하세요. 관계가 만들어집니다.
5. 바로 다음 관계를 추가하세요. 모드는 계속 켜져 있습니다. Esc를 누르거나, 안내 문구의 *중지* 버튼을 누르거나, *관계 그리기*를 다시 선택해 종료합니다.

*관계 유형* 창에서 Esc를 누르면 아무것도 기록되지 않습니다. 관계 하나만 만들 때는 모드를 켤 필요가 없습니다. 막대에서 막대로 끄는 동안 Shift 키를 누르고 계세요. 막대의 오른쪽 클릭 메뉴에 있는 *여기서 관계 시작*은 링크 모드를 켭니다. 끄는 작업은 직접 해야 합니다. *테이블* 탭에는 Gantt 차트가 없으므로 *관계 그리기*를 사용할 수 없습니다.

### 속성 패널에서 관계 추가

한 작업을 보면서 그 선행 작업이나 후속 작업을 추가할 때 유용합니다.

1. 작업을 선택하세요. *속성* 패널은 오른쪽에 있습니다. 보이지 않으면 *보기 › 패널 › 속성*에서 켜세요.
2. *관계* 블록에서 *관계 추가*를 누르세요.
3. 다른 작업이 먼저 오면 방향을 *선행 작업*으로 두세요. 아니면 *후속 작업*을 고르세요.
4. 다른 작업 이름의 일부를 입력하세요. 방향키와 Enter로 맞는 작업을 고르거나, 작업을 클릭하세요.
5. 유형(기본값은 FS)을 고르고, 필요하면 지연을 입력하세요.
6. Enter를 누르거나 체크 표시(*관계 만들기*)를 누르세요.

작업의 관계는 *관계* 블록에 나열됩니다. 각 관계에는 다른 작업의 WBS 번호, 유형, 지연이 표시됩니다.

### 선행 작업 열에 관계 입력하기

키보드로 빠르게 작업하고 WBS 번호를 알 때 유용합니다.

1. 작업 표 머리글 오른쪽의 **+**(*열 추가*)를 누르고, *관계* 아래에서 *선행 작업* 열을 고르세요. *후속 작업* 열도 같은 방법으로 추가합니다.
2. *선행 작업* 열에서 후속 작업의 칸을 누르세요.
3. 선행 작업의 WBS 번호, 띄어쓰기, 유형을 입력하세요. 예: `2.6 FS`. 유형 바로 뒤에 지연을 붙이세요. 예: `2.6 FS+1d`. 여러 선행 작업은 세미콜론이나 쉼표로 구분하세요. 예: `3.1 FS; 3.2 SS+2d`.
4. Enter를 누르세요.

입력한 내용이 칸 전체를 바꿉니다. 칸에 선행 작업이 이미 있으면 그것도 함께 입력하세요(주의할 점 참고). 입력하지 않고 칸에서 Enter 또는 F2를 누르면, 기존 관계를 유지하는 입력창이 열립니다. 이 입력창에서 WBS 번호나 이름으로 작업을 찾고, 각 관계의 유형과 지연을 고릅니다.

### 지연 설정 또는 변경

지연은 위의 각 방법에서 유형 옆 칸에 입력합니다. 기존 지연을 바꾸려면 *관계* 블록에서 지연 칸을 누르고, 새 값을 입력한 뒤 Enter를 누르세요.

- `3` 또는 `3d`: 근무일 3일. 주말은 포함되지 않습니다. 앱은 `+3d`로 표시합니다.
- `3ed`: 달력 기준 3일. 주말도 포함됩니다. 토요일과 일요일에도 양생되는 콘크리트처럼 쓰세요.
- `-1`: 음수 지연(리드). 후속 작업이 하루 먼저 시작할 수 있으므로 작업이 겹칩니다.
- `4h`: 근무 시간 4시간. 앱은 `+4h`로 표시합니다. 선행 작업이 일 단위 작업이고 달력에 자체 근무 구간이 없을 때(예: 표준 달력), 앱은 이 지연을 가장 가까운 온전한 근무일로 반올림합니다. 그래서 `4h`는 1일이 되고, `2h`는 0일이 됩니다. 자체 근무 구간이 있는 달력이나 시간 작업 뒤에서는 지연이 정확히 시간 단위로 계산됩니다.
- `50%`: 선행 작업 기간의 절반.

예: 기초 콘크리트는 양생된 뒤에야 벽돌공이 작업할 수 있습니다. 그래서 *Pour foundation → Foundation brickwork*에 지연 `3`의 FS 관계를 설정합니다. 타설이 2027년 6월 18일 금요일이면, 벽돌 쌓기는 2027년 6월 24일 목요일 **계산** 후에 시작합니다. 월요일부터 수요일까지는 대기 시간입니다. `3ed`를 쓰면 주말도 포함되어, 벽돌 쌓기는 2027년 6월 22일 화요일에 시작합니다.

### 마지막으로 다시 계산

새 관계는 아직 막대를 움직이지 않습니다. 상태 표시줄에 *오래됨 — 다시 계산하세요 (F5)*가 표시됩니다. **계산**(F5)을 누르세요. 예를 들어 *홈 › 일정 › 계산*을 선택합니다. 그 후에야 후속 작업이 새 날짜를 받습니다. 앱이 이것을 자동으로 하게 하려면 *설정 › 프로젝트 › 앱 설정*의 *계획* 탭에서 *자동 계산*을 켜세요.

## 주의할 점과 앱의 동작

**순서가 거꾸로 됨.** *선택한 작업 연결*에서는 목록의 순서가 아니라 클릭한 순서가 중요합니다. 나중 작업을 먼저 클릭하면 관계 방향이 틀립니다. *관계* 블록에서 휴지통 아이콘으로 지우고 다시 추가하세요.

**열에 입력하면 기존 내용이 지워집니다.** 칸에 `3.4 FS; 3.2 FS`가 있는데 `3.2 FS`만 입력하면, 3.4와의 관계는 알림 없이 사라집니다. 모든 선행 작업을 입력하거나, Enter 또는 F2를 써서 추가하거나, Ctrl+Z로 되돌리세요.

**순환 관계.** 관계가 사슬 안의 앞선 작업으로 되돌아가면 일정은 시작할 수 없게 됩니다. 앱은 이런 관계를 거부합니다: *이 관계는 일정에 순환 관계를 만들기 때문에(…) 생성되지 않았습니다*. 괄호 안에는 순환에 속한 작업이 표시됩니다. 먼저 순환을 닫는 관계를 지우세요.

**작업과 자신의 요약 작업.** 작업과 그 작업이 속한 요약 작업 사이에는 관계를 만들 수 없습니다. 앱은 *작업과 자신의 (조상) 요약 작업 간의 관계는 허용되지 않습니다.*라고 말합니다.

**중복.** 관계가 이미 있으면 앱은 *이 관계는 이미 있습니다*라고 말하고, 아무것도 바뀌지 않습니다.

**열의 짧은 메시지.** *선행 작업* 열에서도 같은 거부 사유가 나오지만, 칸 아래에 더 짧은 문구로 표시됩니다. *이 변경으로 일정에 순환 관계가 생깁니다.*, *이 관계는 이미 존재합니다.* 또는 *작업은 자신의 요약 작업과 관계를 가질 수 없습니다.* WBS 번호만 입력하고(예: `3.1`) 유형을 빼면, 칸에 *예: 1.2 FS+2d 형식으로 입력하세요.*가 표시됩니다. 칸은 열린 채로 남습니다. 입력을 고치거나 Esc를 눌러 취소하세요.

**지연에 반일은 없습니다.** 일 단위 지연은 항상 정수입니다. `1.5`는 `+2d`가 됩니다. 근무 구간이 없는 달력에서 일 단위 작업 뒤의 시간 지연은 정수 근무일로 반올림됩니다. 해석할 수 없는 입력, 예를 들어 단어는 저장되지 않습니다. 칸은 이전 값으로 돌아갑니다.
