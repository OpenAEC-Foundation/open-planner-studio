# 열 선택

**테이블**(**테이블** 탭)과 간트 옆의 작업 목록은 각각 자체 열을 가집니다. 열은 테이블 안에서 직접 바꿉니다. 테이블 머리글의 더하기가 열 선택기를 열고, 열 머리글에서는 열을 옮기거나 넓히거나 고정하거나 제거합니다. 모든 변경은 즉시 적용되며 확인 단계는 없습니다.

기본적으로 간트 옆의 작업 목록은 **작업 분류 체계(WBS)**, **작업 이름**, **기간**을 표시합니다. 테이블은 여기에 더해 **시작**, **종료**, **작업 유형**, **주공정**, **총 여유**, **진행률**과 프로젝트의 작업 코드 및 사용자 정의 필드를 표시합니다.

## 열 선택기 열기

- 테이블 머리글 오른쪽의 더하기. 테이블과 간트 옆의 작업 목록은 각자 더하기를 가지며, 그 더하기는 자기 테이블만 바꿉니다.
- **테이블** 탭 → **열…**은 테이블의 열 선택기를 엽니다.
- 기존 보기 버튼이 켜져 있으면(**설정** → **고급** 탭 → **레거시 기능** → **기존 보기 버튼 표시**) **보기** → 리본 그룹 **표시** → **열…**도 같은 일을 합니다. 이 버튼은 테이블 탭으로 전환한 뒤 그곳에서 열 선택기를 엽니다.

**Esc**, 선택기 바깥 클릭 또는 더하기를 한 번 더 클릭하면 선택기가 닫힙니다.

## 열 추가

**열 선택** 선택기에는 위에서 아래로 다음이 있습니다.

- **최근 사용한 열** — 선택기로 최근에 추가한 필드. 열을 하나 추가하면 이 블록이 나타납니다.
- **검색** 필드 — 필드 이름의 일부를 입력합니다. **검색 결과**는 모든 그룹에서 찾습니다.
- 그룹별 필드: **작업**, **계획**, **제약 조건**, **관계**, **리소스**, **진행률**, **계산됨**, **기준선**, **사용자 지정**, **기술 정보**. 그룹을 클릭하면 펼쳐지고, 옆의 숫자는 그 그룹의 필드 수입니다.
- 맨 아래의 **기본값으로 재설정** 버튼(아래 참조).

필드를 클릭하면 마지막 열로 추가되고 선택기가 닫힙니다. 이미 열인 필드는 체크 표시가 되어 있어 다시 고를 수 없습니다. 프로젝트의 작업 코드와 사용자 정의 필드는 **사용자 지정**에, 기준선의 필드는 **기준선**에 있습니다.

**계산됨**에는 분석 필드인 **자유 여유**, **간섭 여유**, **준주공정**, **여유 경로** 등이 있습니다. 이 필드들은 계산(**F5**) 후에만 값을 가지며, **준주공정**과 **여유 경로**는 해당 일정 계산 옵션이 켜져 있을 때만 값을 가집니다 — [크리티컬 패스 및 고급 분석](docs://gids-kritiek-pad-analyse)을 참조하세요.

## 열 머리글에서 열 조정

- **이동** — 열 머리글을 다른 위치로 끕니다. 고정된 열은 앞쪽에 함께 모여 있고, 고정되지 않은 열은 고정되지 않은 열 사이에서만 옮길 수 있습니다.
- **너비** — 열 머리글의 오른쪽 가장자리를 끕니다(40~480픽셀). 그 가장자리를 두 번 클릭하면 머리글과 가장 긴 값에 맞게 열 너비가 조정됩니다. 키보드: 가장자리에 포커스를 두고 왼쪽·오른쪽 화살표 키를 사용하며, **Shift**를 함께 누르면 더 크게 바뀝니다.
- **제거** — 포인터를 열 머리글 위에 올리면 나타나는 빼기 기호. 필드는 열 선택기에서 계속 고를 수 있습니다.
- 열 머리글을 **마우스 오른쪽 단추로 클릭**하면 **고정**(또는 **고정 해제**), **자동 맞춤**, **제거**가 나옵니다. 고정된 열은 앞쪽의 다른 고정된 열 옆으로 옮겨지고, 테이블을 가로로 스크롤해도 계속 보입니다(고정된 열이 함께 테이블에 들어가는 한).

## 시작, 종료와 예정 날짜

**시작**과 **종료**(테이블의 기본 레이아웃에 있는 열)는 간트의 막대와 같은 날짜를 표시합니다. 계산된 일정이며, 첫 계산 전에는 입력한 날짜입니다. 시작에 다른 날짜를 입력하면 그 날짜가 예정 시작이 됩니다. 다른 종료를 입력하면 자동 예약 작업은 기간이 바뀌고, 수동 예약 작업은 그 날짜가 예정 완료가 됩니다. 그런 다음 **F5**를 눌러 다시 계산합니다. 같은 날짜를 다시 입력하면 아무것도 바뀌지 않습니다.

**예정 시작**과 **예정 완료** 필드는 계산으로 작업이 이동해도 입력한 날짜 자체를 표시합니다. 예정 완료는 수동 예약 작업에서만 편집할 수 있습니다. 다른 작업에서는 시작과 기간이 종료를 정합니다. 자동 예약 요약 작업의 시작과 종료는 하위 작업에서 정해지며 편집할 수 없습니다.

## 기본값으로 재설정

**기본값으로 재설정**은 열 선택기 맨 아래에 있습니다. 한 번 클릭하면 해당 테이블의 열이 기본 레이아웃으로 돌아갑니다. 표시할 열, 열의 순서와 너비, 고정된 열이 모두 포함됩니다. 추가로 더한 필드는 테이블에서 빠지지만 선택기에서 계속 고를 수 있습니다. 업데이트 후 새 기본 레이아웃을 받는 방법도 이것입니다. 예를 들어 **예정 시작**과 **예정 완료** 대신 **시작**과 **종료**가 표시됩니다. 이전에 저장한 자신의 레이아웃은 저절로 바뀌지 않습니다. 테이블이 이미 기본 레이아웃이면 버튼이 비활성화됩니다.

## 저장, 실행 취소와 레이아웃

열 레이아웃은 이 기기의 개인 설정입니다. 모든 프로젝트에 적용되며 프로젝트 파일에는 저장되지 않습니다. 열 작업(추가, 제거, 이동, 너비 변경, 고정, **기본값으로 재설정**)은 각각 한 단계이며 **Ctrl+Z**로 실행 취소할 수 있습니다.

레이아웃에 열을 저장할 수도 있습니다. 레이아웃을 만들 때 보고 있는 테이블의 열 레이아웃을 가져오고, 레이아웃 버튼을 클릭하면 그때 보이는 테이블에 적용합니다. 테이블 탭에서는 테이블, 다른 탭에서는 간트 옆의 작업 목록입니다. [레이아웃 저장 및 불러오기](docs://ref-layouts)를 참조하세요.
