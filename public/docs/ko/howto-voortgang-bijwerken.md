# 진행률 업데이트

목표: 작업의 실제 상태를 일정에 입력하고 일정을 다시 계산하는 것입니다: 어떤 작업이 완료되었는지, 어떤 작업이 진행 중인지, 그리고 남은 작업량이 얼마인지 확인합니다.

## 이런 때 필요합니다

정해진 시점에 진행률을 업데이트합니다. 예를 들어 현장 감독이 상태를 보고하는 매주 금요일에 업데이트합니다. 그러면 일정에 실제로 일어난 일이 반영되고, 앱은 상태 날짜부터 남은 작업량을 계산합니다. 앱이 이렇게 동작하는 이유는 [진행률, 상태 날짜 및 기준선](docs://uitleg-voortgang)에서 설명합니다.

## 단계

### 1. 상태 날짜 설정

상태 날짜는 상황을 점검하는 날입니다. 진행률을 입력하기 전에 설정하세요.

1. *계획 › 기준선 및 진행 › 상태 날짜*로 이동합니다.
2. 일, 월, 연도 칸에 날짜를 입력합니다(날짜 표기 순서에 따라). 예를 들어 28, 06, 2027을 입력하고 Enter를 누릅니다. 앱이 다음 칸으로 자동으로 이동합니다.
3. 프로젝트 달력에 근무 시간 구간이 있습니까(*달력* 창의 *근무 시간* 구간)? 그러면 앱은 시간 단위로 계산하고 오른쪽에 시간 칸이 표시됩니다. 예를 들어 17:00입니다. 다른 시간, 예를 들어 12:00을 입력하고 Enter를 누릅니다. 시간 칸을 비우면 날짜만 남습니다. 날짜만 바꾸면 시간은 그대로 남습니다. 시간은 시간 표기 방식(24시간 또는 12시간)을 따릅니다. 근무 시간 구간이 없으면 앱은 정수 일 단위로 계산합니다. 이 경우 시간 칸이 없고 상태 날짜 줄은 그날의 시작에 놓입니다.
4. 필드 옆의 작은 ×를 누르면 상태 날짜를 다시 비웁니다.

금요일 근무 시간이 끝난 뒤에 상황을 점검하면 상태 날짜를 다음 근무일인 월요일로 설정하세요. 앱은 상태 날짜의 시작일부터 남은 작업량을 계획합니다.

상태 날짜가 아직 없는데 진행률을 입력하면, 앱은 상태 날짜를 오늘로 설정하고 다음 메시지를 표시합니다: *상태 날짜를 오늘(…)로 설정했습니다.* 그러므로 먼저 직접 설정하는 편이 좋습니다.

### 2. 진행률 입력

상황에 맞는 방법을 선택하세요. 모든 방법의 결과는 같습니다.

**속성 패널에서 작업 하나 입력.** 작업 하나만 업데이트할 때 유용합니다.

1. 작업을 클릭합니다. *속성* 패널이 보이지 않으면 *보기 › 패널 › 속성*에서 켭니다.
2. 슬라이더 *진행률 (%)*를 완료율까지 드래그합니다.
3. 필요하면 상태 날짜와 같은 방법으로 *실제 시작*과 *실제 완료*를 입력합니다. 앱이 *남음* 필드를 직접 계산합니다. 이 필드는 여기에서 변경할 수 없습니다.

마일스톤에는 *실제 날짜* 필드가 하나 있습니다.

**메뉴에서 비율 선택.** 빠르게 상태를 입력할 때 유용합니다.

1. Gantt 차트에서 작업 막대를 마우스 오른쪽 버튼으로 클릭합니다.
2. *진행률*을 선택한 다음 0%, 25%, 50%, 75% 또는 100%를 선택합니다.

**작업 표에서 여러 작업 입력.** 전체 목록을 업데이트할 때 유용합니다.

1. 작업 표 머리글 오른쪽의 **+**를 클릭하고(*열 추가*) 범주 *진행률*을 엽니다. *실제 시작*, *실제 완료*, *남음*, *상태* 열을 추가합니다. *진행률* 열은 *테이블* 탭에 이미 있습니다.
2. 셀을 두 번 클릭하고 값을 입력한 다음 Enter를 누릅니다. 비율은 `50` 또는 `50%`로, 날짜는 `25-06-2027`로, 남은 기간은 `1`로 입력합니다.
3. *상태*는 두 번 클릭한 다음 Enter를 누르고 *시작 안 함*, *진행 중* 또는 *완료*를 선택합니다.

남은 기간을 입력하면 앱이 비율을 역으로 계산합니다. 기간이 2 근무일인 작업에서 남은 기간을 1로 입력하면 비율은 50이 됩니다. 남은 기간이 0이면 작업이 완료됩니다. *실제 기간* 열(역시 *진행률* 범주에 있습니다)은 반대로 작동합니다. 이미 수행한 작업량을 입력하면 앱이 비율을 계산합니다. 기간이 4 근무일인 작업에서 실제 기간을 1로 입력하면 비율은 25%가 됩니다. *상태*에서 *시작 안 함*을 선택하면 비율은 0으로 바뀌고 실제 날짜가 사라집니다.

**작업 하나의 모든 항목은 작업 편집 창에서 입력합니다.** 작업을 마우스 오른쪽 버튼으로 클릭하고 *편집*...을 선택합니다. 진행률 필드도 거기에 있습니다. 이 필드는 *저장*을 클릭한 후에만 적용됩니다.

**스프레드시트에서 여러 작업을 한 번에 가져오기.** [스프레드시트에서 진행률 가져오기](docs://howto-voortgang-importeren)를 참조하세요.

### 3. 일정 다시 계산

진행률이나 상태 날짜를 바꿀 때마다 일정은 오래된 상태가 됩니다. 상태 표시줄에 *오래됨 — 다시 계산하세요 (F5)*가 표시됩니다. **계산**(F5)을 누릅니다. 예를 들어 *계획 › 일정 › 계산*에서 선택할 수 있습니다. *자동 계산*이 켜져 있으면(*설정 › 프로젝트 › 앱 설정*, 탭 *계획*에서) 앱이 계산을 직접 수행합니다.

## 결과 확인

- 상태 날짜에 Gantt 차트에 점선이 표시되고 머리글에 날짜가 나타납니다. 진행 중인 작업에서는 선이 막대 안의 비율까지 튀어나옵니다. *보기 › 기준선 및 진행 › 진행선*과 *상태 날짜선*에서 이 선을 켜거나 끌 수 있습니다.
- 작업 막대의 완료된 부분은 회색으로 바뀝니다. 나머지 부분은 원래 색을 유지합니다. 완전히 끝난 작업은 막대 전체가 회색이고, 이름 앞에 체크 표시가 있으며 여유 띠가 없습니다. 단계의 막대도 파생된 비율까지 회색으로 바뀌므로, 단계별로 진행 정도를 볼 수 있습니다. 작업의 선행 작업 또는 후속 작업을 표시하면, 그 막대는 완료되어도 강조 색을 유지합니다.
- 완료된 작업은 빨간색으로 표시되지 않습니다. 상태 날짜가 있으면 완료된 작업은 주공정이 아닙니다.
- 단계는 파생된 비율을 표시하며, 일정의 완료일이 바뀌었을 수 있습니다.
- 기준선을 저장했다면 각 막대 아래에 원래 일정이 표시됩니다. 보고서 유형 *차이*에서 그 차이가 표시됩니다.

## 주의할 점과 앱의 동작

**상태 날짜 이후의 날짜.** 앱은 상태 날짜 이후의 실제 시작일이나 실제 완료일을 받지 않습니다. 속성 패널에서는 필드 아래에 *실제 날짜는 상태 날짜 이후일 수 없습니다*라고 표시됩니다. 작업 표에서는 셀에 *실제 날짜가 상태 날짜 이후입니다.*라고 표시됩니다. 먼저 상태 날짜를 나중으로 설정하거나 날짜를 바로잡으세요.

**상태 날짜 이후에야 시작할 작업.** 일정상 아직 시작하지 않았어야 하는 작업의 진행률을 입력하면 *실제 시작 입력* 창이 열립니다. 이 창은 작업이 실제로 언제 시작했는지 묻습니다. 제안 값은 상태 날짜입니다. *진행률 적용*을 선택하면 기록됩니다. *취소*를 선택하면 아무것도 바뀌지 않습니다.

**날짜 없이 100%.** 실제 완료일 없이 작업을 100%로 설정하면, 작업이 그보다 일찍 끝났더라도 실제 완료일이 상태 날짜가 됩니다. 그런 다음 실제 완료일을 직접 입력하세요.

**100% 미만의 완료율.** 완료된 작업을 다시 100% 미만으로 설정하면 실제 완료일이 삭제됩니다. 실제 완료일만 지우면 비율은 0이 되고 작업은 *진행 중* 상태로 남습니다. 작업을 다시 *시작 안 함* 상태로 되돌리려면 실제 시작일도 지우거나, 작업 표의 *상태*에서 *시작 안 함*을 선택하세요.

**진행 중인 작업의 기간 변경.** 이미 수행한 작업은 그대로 유지되고 비율이 조정됩니다. 60%인 5 근무일 작업을 10 근무일로 설정하면 비율은 30%가 됩니다. 앱은 이미 수행한 작업보다 짧은 기간을 거부합니다: *“Build inner cavity leaf”은(는) 이미 60% 완료되었습니다. 이미 수행한 작업보다 짧은 기간은 불가능합니다. 기간을 변경하지 않았습니다.* 작업 표에서는 셀에 *이 기간은 이미 수행한 작업보다 짧습니다*라고 표시됩니다.

**남은 기간은 반올림됩니다.** 앱은 남은 기간을 정수 근무일 단위로 반올림합니다. 기간이 2 근무일인 작업에서는 50%와 75% 모두 남은 기간이 1 근무일이 됩니다.

**단계.** 단계에는 자체 진행률이 없습니다. 패널에는 *하위 작업에서 산출됩니다. 진행률은 하위 작업에서 변경하세요. 계산(F5) 후 요약 작업에 반영됩니다*라고 표시됩니다. 작업 표에서는 셀에 *요약 작업의 진행률은 하위 작업에서 산출되므로 여기에서 변경할 수 없습니다*라고 표시됩니다.

**상태 날짜를 나중으로 옮기기.** 진행 중인 작업의 남은 작업량은 새 상태 날짜부터 시작합니다. 아직 시작하지 않은 작업은 그 날짜 이전에 놓일 수 없습니다. 따라서 상태 날짜는 진행률을 함께 업데이트할 때에만 옮기세요. 진행률을 입력하지 않고 상태 날짜만 설정하면, 아직 시작하지 않은 모든 작업이 그 날짜로 옮겨집니다(Microsoft Project 프로필 제외).

**실수한 경우.** 진행률 변경 하나는 Ctrl+Z 한 번으로 되돌릴 수 있습니다.
