# 내보내기

목표: 일정을 다른 형식의 파일로 전달합니다. IFC 형식을 읽지 않는 사람이나 다른 패키지에 보낼 때 사용합니다.

## 이 기능이 필요한 경우

컨설턴트는 MS Project에서, 발주자는 Primavera에서 작업합니다. 하도급업체는 작업을 Excel로 받고 싶어 합니다. 또는 IFC 형식을 처리할 수 없는 패키지에 일정을 보내야 합니다. 내보내기는 다른 형식의 사본입니다. 프로젝트 자체를 보관하려면 저장하세요. 저장하면 IFC 형식으로 기록되고 모든 내용이 함께 저장됩니다. 각 형식이 담는 내용과 담지 않는 내용은 [파일과 형식](docs://uitleg-bestanden)에 있습니다.

## 단계

1. *홈 › 파일 › 내보내기* 메뉴에서 목록의 형식을 고르거나 *파일 › 내보내기*를 선택합니다. 그곳에서는 각 형식이 짧은 설명이 있는 카드로 표시됩니다.
2. 창에서 이름과 위치를 고릅니다. 앱은 형식의 확장자를 붙인 프로젝트 이름을 제안합니다. 진행률 시트는 *projectname-voortgang*이라는 이름이 붙고, 가능하면 다운로드 폴더에 저장됩니다.
3. 확인합니다. 내보내기가 성공하면 아래 메시지 외에는 아무 메시지도 나타나지 않습니다. *파일 › 내보내기*에서 내보낸 뒤에는, 창을 취소하더라도 *홈* 탭으로 돌아갑니다. *홈* 탭 목록에서 내보내기를 시작한 뒤 창을 취소하면 아무 일도 일어나지 않습니다.

브라우저가 다운로드로만 저장하는 경우(예: Firefox), 파일은 1단계 직후 다운로드 폴더에 있습니다. 다음 메시지가 나타납니다. *다운로드로 저장했습니다. 'name.xml' 파일이 다운로드 폴더에 있습니다. 이 환경에서는 앱이 선택한 위치에 직접 쓸 수 없습니다.*

### 어떤 형식을 선택하나요?

*홈* 탭의 목록과 *파일 › 내보내기*의 카드에는 같은 형식이 있습니다:

- *진행률(Excel)*과 *진행률(CSV)*, 카드 *진행률 시트(Excel)*과 *진행률 시트(CSV)*: ID, WBS, 이름, 날짜 및 완료율이 있는 간단한 시트입니다. 진행률을 입력할 담당자에게 보내는 용도입니다.
- *CSV (;)*, 카드 *CSV (세미콜론 구분)*: 스프레드시트에서 열 수 있는 작업 표입니다.
- *MS Project XML*: Microsoft Project 프로그램에서 열 수 있습니다.
- *Primavera P6 XML*: Oracle Primavera P6용입니다.
- *IFC*: 앱 고유의 형식이며 모든 내용이 들어 있습니다. 프로젝트의 IFC 스키마(기본값: IFC 4.3 ADD2)를 사용합니다.

### 라이브러리 파일과 함께하는 IFC 내보내기

프로젝트가 리소스 라이브러리에 연결되어 있으면, *라이브러리 파일도 함께 저장* 확인란이 *파일 › 내보내기*의 카드 아래에 있습니다. 확인란을 선택하고 *IFC*를 고르면 앱은 위치를 두 번 묻습니다. 먼저 프로젝트 위치를, 그다음 *projectname-bibliotheek.ifc* 위치를 묻습니다. 이 확인란은 *파일 › 내보내기*에만 있으며 *홈* 탭의 목록에는 없습니다.

### 진행률 시트 다시 불러오기

입력된 진행률 시트는 *파일 › 가져오기*로 다시 읽습니다. [스프레드시트에서 진행률 가져오기](docs://howto-voortgang-importeren)를 참조하세요.

## 주의 사항과 그때 앱이 하는 일

**프로젝트는 바뀌지 않습니다.** 프로젝트 파일은 그대로 유지됩니다. 있었다면 *저장되지 않음* 표시도 그대로 남습니다.

**최신 상태가 아닌 일정은 먼저 다시 계산됩니다.** 따라서 *계산*을 누르지 않았더라도 현재 날짜를 얻습니다.

**내보내기 파일도 최근 파일에 나타납니다.** 진행률 시트에는 해당하지 않습니다. 최근 파일에서 내보내기 파일을 열면 그 형식의 가져오기로 열립니다.

**내보내기는 모든 내용을 담지 않습니다.** CSV 파일에는 리소스와 제약 조건이 없고, P6 XML에는 기준선과 기한이 없습니다. 계산 프로필도 함께 넘어가지 않습니다. 다시 여는 내보내기는 *Open Planner Studio*로 계산됩니다. 모든 내용을 담는 것은 IFC 형식뿐입니다. 숫자가 있는 예는 [파일과 형식](docs://uitleg-bestanden)에서 찾을 수 있습니다.

**확장자가 같은 두 형식.** MS Project XML과 Primavera P6 XML은 모두 *projectname.xml* 이름이 붙습니다. 직접 다른 이름을 붙이세요. 그렇지 않으면 나중에 어느 파일이 어떤 형식인지 알 수 없습니다.

**순환 관계가 있는 일정은 내보내지 않습니다.** 앱은 먼저 계산하고, 순환이 있으면 멈춥니다. *홈* 탭에 *일정을 계산할 수 없습니다* 메시지가 나타나며, 그 아래에 예를 들어 *작업 간 순환 관계: Set up site → Demolish existing extension → Set up site* 문구가 표시됩니다. *파일 › 내보내기*에서는 페이지에 두 번째 문구만 나타납니다. 순환을 해결하고 다시 내보내세요.

**Primavera에서 가져온 프로젝트는 원본 정보를 잃습니다.** 이런 프로젝트를 CSV, MS Project XML 또는 P6 XML로 내보내면 앱이 다음 메시지를 표시합니다. *CSV 형식으로 내보내면 XER 원본 정보가 손실됩니다.* MS Project XML에서는 *MSPDI*, P6 XML에서는 *P6*라고 표시됩니다. [Primavera P6 파일(.xer) 열기](docs://howto-xer-openen)를 참조하세요.

**분할된 작업은 분할 정보를 잃습니다.** MS Project와 Primavera는 분할을 시간 분배로만 인식합니다. 프로젝트에 시간 분배가 없는 분할 작업이 있으면, MS Project XML 또는 P6 XML로 내보낸 뒤 앱이 다음 메시지를 표시합니다: *중단이 있는 작업 2개가 중단 없이 내보내졌습니다. MS Project/P6은 중단을 작업 분배로만 인식합니다.* 작업이 하나인 경우에는 *중단이 있는 작업 1개가 중단 없이 내보내졌습니다. MS Project/P6은 중단을 작업 분배로만 인식합니다.*라고 표시됩니다. [작업 분할하기](docs://howto-taak-splitsen)를 참조하세요.

**보기 *기록된 날짜*에서의 일정.** 원본 파일의 날짜가 보이는 상태에서 CSV로 내보내면, 원본 파일에 기록되지 않은 작업에서는 앱이 `Critical`과 `Total Float`을 비워 둡니다. [기록된 날짜](docs://uitleg-datums-zoals-opgeslagen)를 참조하세요.
