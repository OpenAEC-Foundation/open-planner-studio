# Отварање MS Project датотеке (.mpp)

Циљ: отворити распоред из Microsoft Project-а директно у апликацији, без претходног извоза.

## Кад вам ово треба

Извођач, консултант или наручилац вам шаље свој распоред као `.mpp` датотеку. Желите да га прегледате, израчунате или даље развијате. Апликација чита `.mpp` датотеке из MS Project-а 2010 до и укључујући 2021. Она само чита: не пише `.mpp` и никада не мења вашу датотеку. Из датотеке узима сам распоред: задатке са структуром, трајањем и ограничењима, зависности са кашњењем, календаре, ресурсе, доделе и напредак. Она чита и датуме и временске резерве које је MS Project сам израчунао, али их користи само за приказ *Датуми онако како су записани*, никада као улаз.

## Кораци

1. Изаберите *Почетна › Датотека › Отвори* или притисните Ctrl+O. Изаберите `.mpp` датотеку.
2. Пројекат се отвара у новој картици, или у текућој картици ако је још био празан и непромењен. Пројекат нема датотеку: *Сачувај* касније записује нову IFC датотеку. Затим се кратко појављује прозор који објашњава шта је апликација преузела из датотеке и како функционише чување; погледајте [Отварање и чување датотеке](docs://howto-bestand-openen-en-opslaan).
3. Прочитајте поруку на дну: *Овај пројекат се израчунава као Microsoft Project. Прилагодите га преко: Датотека → Подаци о пројекту → Профил израчунавања и опције израчунавања.* Апликација израчунава овај пројекат по правилима MS Project-а: профил израчунавања *Microsoft Project*. Дугметом *Отвори профил израчунавања* идете на поставку; *Прочитај више* отвара помоћ о профилима израчунавања.
4. Проверите да ли се испод траке приказује порука: *Видите датуме онако како стоје у датотеци; при поновном израчунавању одступају 4 задатка.* Тада се на тим задацима резултат апликације разликује од датума које је сачувао MS Project. Испод поруке из корака 3 тада се појављује и ред: *4 задатка приказују датуме онако како су записани у датотеци (није поново израчунато).* Шта то значи и како прелазите на сопствено израчунавање апликације, описано је у [Датуми онако како су записани](docs://uitleg-datums-zoals-opgeslagen).
5. Ако се прикаже *Ова датотека садржи планирање по сатима.* са дугметом *Укључи планирање по сатима*, датотека садржи податке у сатима. Погледајте [Укључивање планирања по сатима](docs://howto-urenplanning-aanzetten).

Ако датотека садржи задатке са прекидом, нивелисањем или распоредом вођеним ресурсима, додаје се још једна порука, на пример *Ова MS Project датотека садржи 3 задатка са прекидом, нивелисаним или распоредом вођеним ресурсима. Они се тако учитавају и приказују.* За један задатак порука је у једнини.

## Замке и шта апликација тада ради

**Није све преузето.** Након отварања апликација једном поруком јавља шта није преузела: *Није све из ове MS Project датотеке преузето.* Испод ње је по један ред за сваку ставку, с бројем, на пример *2 основне линије нису преузете.* За `.mpp` датотеку је први ред ове поруке реченица о профилу израчунавања из корака 3. Порука остаје док не кликнете на крстић. Ако ништа није изгубљено, ова порука се не приказује. Сваки ред може да се односи на:

- уметнути пројекти (подпројекти): апликација их чита као обичан задатак, без везе са другом датотеком;
- спољни задаци из другог пројекта: апликација их чита као обичан задатак;
- основне линије: из `.mpp` датотеке апликација не преузима ниједну основну линију, из MS Project XML-а само основну линију 0 задатака, и то само датуме и трајање (за задатак у сатима и време; не посао и трошак, и не основне линије за ресурсе и доделе);
- уз MS Project XML: додела чија основна линија има друге датуме од свог задатка. Апликација задржава само основну линију задатка; ако су датуми исти, ништа се не губи и апликација ништа не јавља. Другачије време истог дана такође се рачуна као разлика;
- прилагођена поља с вредностима, на пример прилагођена поља, вредности из табеле за претрагу и кодови структуре (апликација у `.mpp` датотеци не рачуна поља да/не);
- белешке (и белешка која садржи само слику) на ресурсима и доделама, а из `.mpp` датотеке и на задацима (из MS Project XML-а белешка задатка долази као његов опис);
- хипервезе;
- фиксни трошкови задатака;
- цене ресурса (стандардна цена): из `.mpp` датотеке се не преузима ниједна, из MS Project XML-а само стандардна цена;
- само уз MS Project XML: ручно планирани задаци (апликација их планира сама), неактивни задаци (укључени су у израчунавање) и одлагање због нивелисања;
- само уз `.mpp` датотеку: гранична вредност за критичност из MS Project-а; апликација користи граничну вредност 0.

Шифра САП коју сте сами унели у MS Project се преузима; у супротном апликација задатке нумерише према структури.

**Датотека из MS Project-а 2007 или старијег издања.** Апликација је одбија и јавља: *Ова .mpp датотека користи стар формат (Project 2007 или старији). Извезите је у MS Project као XML (Датотека → Сачувај као → XML) и отворите ту датотеку.* Испод поруке апликација додаје технички разлог на енглеском.

**Датотека са лозинком.** Апликација јавља: *Ова .mpp датотека је заштићена лозинком. Извезите је у MS Project као XML (Датотека → Сачувај као → XML) и отворите ту датотеку.* И ова порука долази са техничким разлогом на енглеском.

**Датотека која се испостави да није `.mpp`.** Добијате поруку *Отварање датотеке није успело*, са техничким разлогом.

**Пут преко XML-а израчунава другачије.** Ако отворите XML извоз из MS Project-а уместо `.mpp`, апликација израчунава са профилом израчунавања *Open Planner Studio* и не видите поруку о *Microsoft Project*. Датуми тада могу испасти другачије него са `.mpp` датотеком. И уз XML извоз апликација јавља шта не преузима; погледајте *Није све преузето*.

**Измена укида утицај MS Project-а.** Ако измените задатак чији је распоред вођен прозором датума из MS Project-а, апликација то јавља једном по пројекту: *Прозор датума из MS Project-а више не утиче на 2 задатка после ове измене; сама расподела сати и даље важи и остаје сачувана у датотеци.* За један задатак порука је у једнини.

**Чување никада не преписује ваш `.mpp`.** Пројекат нема датотеку. *Сачувај* пита где треба да буде нова IFC датотека.
