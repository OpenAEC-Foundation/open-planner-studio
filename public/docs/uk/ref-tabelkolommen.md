# Стовпці таблиці

Таблиця завдань має 86 фіксованих стовпців, плюс по одному стовпцю для кожного коду операції та настроюваного поля проєкту і по вісім стовпців для кожного базового плану. У цій статті для кожного стовпця вказано, що він показує, чи можна його редагувати і в якій формі записується значення. Як вибрати й упорядкувати стовпці, описано в [Налаштування стовпців таблиці](docs://howto-tabelkolommen-aanpassen).

## Де вибирати стовпці

Таблиця завдань поруч із діаграмою Gantt і таблиця на вкладці *Таблиця* мають кожна свій вибір стовпців. Знак плюс праворуч від заголовка відкриває вибирач стовпців (заголовок вікна *Вибрати стовпець*). На вкладці *Таблиця* можна також скористатися командою *Таблиця › Колонки › Колонки…*. Вибирач показує стовпці за категоріями: *Завдання*, *Графік*, *Обмеження*, *Залежності*, *Ресурси*, *Прогрес*, *Обчислені*, *Базовий план*, *Настроювані* і *Технічні*. Ви шукаєте за назвою, а *Нещодавні стовпці* стоять нагорі. *Відновити стандартні* відновлює стандартні стовпці.

За замовчуванням таблиця поруч із діаграмою Gantt показує *WBS*, *Назва завдання* і *Тривалість*. Таблиця на вкладці *Таблиця* показує *WBS*, *Назва завдання*, *Тривалість*, *Початок*, *Завершення*, *Тип завдання*, *Критичний*, *Загальний часовий резерв* і *Прогрес*, а також по одному стовпцю для кожного коду операції та настроюваного поля проєкту.

## Як читаються і редагуються значення

- **Обчислені стовпці** — стовпці категорії *Обчислені* та низка інших лише для читання: їхні значення походять з обчислення. Якщо ви спробуєте змінити комірку лише для читання, застосунок покаже *Цей обчислений стовпець не можна редагувати.* Цей текст — загальне повідомлення для кожної комірки лише для читання, також коли стовпець не обчислюється. Якщо вони застаріли, бо ви щось змінили, поруч із ними з'являється *застаріле*, доки ви не натиснете *Обчислити*.
- **Дати** — відображаються у форматі, який ви вибрали на сторінці *Налаштування*, на вкладці *Вигляд*, під заголовком *Формат дати*.
- **Тривалості й резерви часу** — тривалість відображається в одиниці завдання (`5d`, `12h`) або відповідно до *Відображення тривалості* на тій самій вкладці (*Автоматично (власна одиниця для кожного завдання)*, *Завжди дні* або *Завжди години*). Резерв часу відображається в робочих днях, з двома десятковими знаками та з роздільником десяткових знаків вашої мови.
- **Так/ні** — значення так або ні відображається як *Так* або *Ні*; порожнє значення як тире (—).
- **Редагування** — введіть або виберіть значення. Недійсне значення відхиляється з поясненням під коміркою, наприклад *Введіть дійсну тривалість, наприклад 5d або 8h.* або *Введіть відсоток від 0 до 100.* Вставлення блоку комірок виконується комірка за коміркою; комірки лише для читання пропускаються, а застосунок повідомляє, скільки їх було.

## Завдання

- **Назва завдання** — назва завдання. Можна редагувати; поле обов'язкове. Зведене завдання показано жирним шрифтом, з легким фоновим відтінком у комірці назви; віха показана жирним шрифтом кольором віхи (тієї самої колірної групи, що й віха в діаграмі Gantt). Звичайне завдання залишається без змін. Це лише оформлення: вибір, перетягування й редагування працюють так само.
- **Опис** — опис завдання. Можна редагувати; вільний текст.
- **WBS** — код WBS. Можна редагувати, поле обов'язкове, але лише для читання, поки ввімкнено *Авто WBS*.
- **Тип завдання** — тип завдання (*Будівництво*, *Монтаж*, *Знесення*, *Логістика*, *Огляд/інспекція*, *Переміщення*, *Реновація*, *Обслуговування* або *Інше*). Можна редагувати зі списку.
- **Настроюваний тип завдання** — настроюваний тип завдання з проєкту або тире. Можна редагувати зі списку настроюваних типів проєкту.
- **Колір** — збережений колір завдання у вигляді коду кольору, наприклад `#1a73e8`. Можна редагувати за допомогою вибирача кольорів. Колір зберігається у файлі IFC, але жодна смуга чи звіт його не використовує; кольори смуг задаються в *Вигляд › Базові плани та прогрес › Кольори смужок*.
- **Примітки** — примітки у вигляді `✓ text; ○ text`. Можна редагувати, якщо є не більше однієї примітки (тоді ви редагуєте її текст). Якщо приміток більше, поле лише для читання.

## Графік

- **Віха** — чи є завдання віхою. Можна редагувати. Коли її ввімкнено, тривалість стає 0; застосунок відхиляє це для зведеного завдання та для завдання з призначеннями.
- **Тип віхи** — *Віха початку* або *Віха завершення*, або тире для автоматичного визначення. Можна редагувати лише для віхи.
- **Обов'язкова віха** — прапорець *Обов'язкова (за контрактом)*. Можна редагувати лише для віхи.
- **Пріоритет вирівнювання** — ціле число від 0 до 1000, за замовчуванням 500. Можна редагувати. Значення 1000 закріплює завдання для вирівнювання.
- **Проміжки розщеплення** — кількість перерв у вигляді `Split gaps: 2` або тире. Лише для читання; редагуйте їх на панелі *Властивості*.
- **Правило роботи** — правило роботи завдання; порожнє значення означає, що для проєкту діє правило за замовчуванням. Можна редагувати зі списку, але для віхи, зведеного завдання або завдання-гамака поле порожнє й лише для читання. Видно у вибирачі лише тоді, коли правила роботи видимі (*Правила роботи й трудовитрати* або файл містить правила роботи).
- **Завдання-гамак (похідна тривалість)** — чи є завдання завданням-гамаком. Можна редагувати, крім віхи або зведеного завдання.
- **Календар** — ідентифікатор власного календаря завдання; порожнє значення (—) означає календар проєкту. Ви вводите ідентифікатор або вибираєте його з підказок; невідомий ідентифікатор відхиляється. Примітка: комірка наразі показує внутрішній ідентифікатор замість назви; краще виберіть календар на панелі *Властивості*.
- **Тип тривалості** — *Робочий час* (тривалість рахується в робочих днях або робочих годинах календаря) або *Астрономічна тривалість* (тривалість рахується в безперервному часі, без календаря). Можна редагувати.
- **Одиниця тривалості** — *Дні* або *Години*. Можна редагувати, крім зведеного завдання, завдання-гамака або віхи; перемикання працює лише тоді, коли перетворення точне і ввімкнено *Увімкнути планування за годинами*.
- **Тривалість** — тривалість завдання в одиниці завдання або відповідно до *Відображення тривалості*. Можна редагувати: введіть `5d`, `12h` або `1h 30m`; також число в одиниці завдання. Лише для читання для зведеного завдання, завдання-гамака і віхи з тривалістю 0.
- **Початок** — відображуваний початок, та сама дата, що й смуга в діаграмі Gantt. Можна редагувати. Завдання з попередником, для якого ви задаєте новий початок, отримує обмеження *Початок не раніше (SNET)* на цю дату. Лише для читання для зведеного завдання або завдання-гамака, якщо вони не заплановані вручну.
- **Завершення** — відображуване завершення. Можна редагувати: нове завершення стає новою тривалістю. Застосунок відхиляє його для завершеного завдання, віхи, завдання з астрономічною тривалістю і завдання з перервами, а також для завершення раніше за початок (*Завершення раніше за початок.*). Лише для читання для зведеного завдання або завдання-гамака, якщо вони не заплановані вручну.
- **Запланований початок** — точка прив'язки, з якої починається обчислення (не обов'язково відображуваний початок). Можна редагувати; дає той самий результат, що й введення в *Початок*.
- **Заплановане завершення** — введене завершення. Можна редагувати лише для завдання, яке заплановано вручну; інакше застосунок показує *Заплановане завершення діє лише для завдання, яке заплановано вручну. Змініть завершення в стовпці Завершення або через тривалість.*

## Обмеження

- **Тип обмеження** — тип обмеження, від *Якомога раніше (ASAP)* до *Має завершитися в (MFO)*. Можна редагувати; завдання без обмеження показує *ASAP*.
- **Дата обмеження** — дата обмеження. Можна редагувати.
- **Жорстке обмеження** — прапорець *Обов'язкове закріплення (логіка)*. Можна редагувати лише для *MSO* і *MFO*.
- **Тип додаткового обмеження** — тип другої межі або тире. Можна редагувати. Таблиця пропонує всі типи, але недозволену комбінацію застосунок відхиляє: має бути *SNET*, *FNET*, *SNLT* або *FNLT*, основне обмеження має бути межею (не *ASAP*, *ALAP*, *MSO*, *MFO* і не жорстке обмеження), а дві межі мають бути з протилежних боків (нижня межа *SNET*/*FNET* з верхньою межею *SNLT*/*FNLT* або навпаки).
- **Дата додаткового обмеження** — дата другої межі. Можна редагувати.
- **Крайній термін** — цільова дата завершення. Можна редагувати.

## Залежності

- **Попередники** — попередники у вигляді `WBS type±lag`, розділені `; `, наприклад `1.2 FS+2d`. Можна редагувати, вводячи той самий вигляд. Зовнішню залежність тут не додають, а через *Графік › Залежності › Пов'язати › Додати зовнішню залежність…*.
- **Наступники** — наступники в тому самому вигляді. Можна редагувати.
- **Визначальна залежність** — залежності, що визначають дату цього завдання, у вигляді `← 1.2` (попередник) або `→ 1.4` (наступник). Лише для читання; позначається як *застаріле*, доки ви не натиснете *Обчислити*.
- **Вільний резерв часу** (у категорії *Залежності*) — вільний резерв часу для кожної залежності у вигляді `← 1.2: 3d`. Це не той самий стовпець, що *Вільний резерв часу* в категорії *Обчислені*, який показує резерв самого завдання. Лише для читання.
- **Попередження** — попередження для кожної залежності, наприклад *Поза послідовністю* або *Не враховано в розрахунку*. Лише для читання. Див. [Сповіщення та попередження](docs://ref-meldingen).

## Ресурси

- **Призначені ресурси** — назви призначених ресурсів, розділені комами. Можна редагувати: додавання назви призначає ресурс з 1 одиницею на день, видалення назви знімає призначення. Лише для читання для віхи або зведеного завдання.
- **Одиниці призначення на день** — одиниці на ресурс у вигляді `Name: 1; Name: 0.5`. Можна редагувати для завдання з призначеннями.
- **Контур призначення** — контур для кожного ресурсу у вигляді `Name: Uniform`. Можна редагувати для завдання з призначеннями.
- **Початок вікна трудовитрат** і **Завершення вікна трудовитрат** — вікно трудовитрат для кожного ресурсу з імпортованого файлу у вигляді `Name: date`. Лише для читання.
- **Плановий обсяг роботи (години)** і **Фактичні трудовитрати (години)** — заплановані та фактичні трудовитрати для кожного ресурсу в годинах, у вигляді `Name: 12`, з імпортованого файлу. Лише для читання.
- **Залишковий обсяг роботи (години)** — залишковий обсяг роботи для кожного ресурсу в годинах, у вигляді `Name: 6`: збережені трудовитрати, інакше залишкова тривалість × одиниці. Можна редагувати для завдання з призначеннями, до яких застосовується правило роботи. Видно у вибирачі лише тоді, коли правила роботи видимі.

## Прогрес

- **Статус** — *Не розпочато*, *Виконується* або *Завершено*. Можна редагувати, крім зведеного завдання.
- **Прогрес** — відсоток у вигляді `40%`. Можна редагувати числом від 0 до 100, крім зведеного завдання.
- **Фактичний початок** — дата, коли завдання почалося. Можна редагувати, крім зведеного завдання.
- **Фактичне завершення** — дата, коли завдання було виконано. Можна редагувати, крім зведеного завдання.
- **Фактична тривалість** — фактична тривалість, як число. Можна редагувати, крім зведеного завдання.
- **Залишкова тривалість** — залишкова тривалість в одиниці завдання. Можна редагувати, крім зведеного завдання.
- **Дата відновлення** і **Дата зупинки** — відновлення й зупинка завдання, що виконується, з файлу MS Project або Primavera. Лише для читання.

Стовпці прогресу дотримуються правил прогресу застосунку: фактична дата після дати звітування про стан відхиляється. Для зведеного завдання застосунок показує *Прогрес зведеного завдання обчислюється з його підзавдань і тут не можна його змінити.*

## Обчислені

Усі стовпці цієї категорії лише для читання.

- **Затримка через вирівнювання** — на скільки робочих днів вирівнювання затримало завдання; тире, якщо вирівнювання не застосовувалося.
- **Ранній початок** і **Раннє завершення** — найраніші дати з обчислення.
- **Пізній початок** і **Пізнє завершення** — найпізніші дати, коли завдання ще може початися або завершитися, не затримуючи проєкт.
- **Вільний резерв часу** — робочі дні, на які завдання може зсунутися, не затримуючи наступника.
- **Загальний часовий резерв** — робочі дні, на які завдання може зсунутися, не затримуючи дату завершення проєкту. Від'ємний, якщо не можна дотриматися обмеження або крайнього терміну.
- **Критичний** — *Так*, якщо завдання лежить на критичному шляху.
- **Перешкоджаючий резерв часу** — загальний часовий резерв мінус вільний резерв часу.
- **Майже критичне** — *Так* для майже критичного завдання. Заповнюється, лише якщо ввімкнено *Позначати майже критичні* (*Відомості проєкту*, блок *Профіль обчислень і параметри обчислень*); інакше тире.
- **Шлях резерву** — номер шляху резерву, 1 для найбільш критичного. Заповнюється, лише якщо ввімкнено *Кілька шляхів резерву*; інакше тире.
- **Джерело зафіксованих дат** — для файлу із зафіксованими датами: *Відхиляється* або *Частково не зафіксовано*. Видно у вибирачі лише для такого файлу. Для незафіксованої осі в стовпцях пізніх дат і резервів часу з'являється *Не зафіксовано*.

Див. [Критичний шлях і резерв часу](docs://uitleg-kritiek-pad).

## Базовий план

Для кожного базового плану проєкту додаються стовпці, а перед назвою стовпця стоїть назва базового плану (`<baseline> — Scheduled start`). Вони лише для читання. Завдання, якого немає в базовому плані, показує тире з підказкою *Відсутній в цьому базовому плані*.

- **Запланований початок**, **Заплановане завершення** і **Тривалість** — початок, завершення й тривалість, як їх зафіксував базовий план.
- **Відхилення початку** і **Відхилення завершення** — кількість робочих днів між базовим планом і відображуваним початком або завершенням, за календарем проєкту; додатне, якщо завдання пізніше.
- **Відхилення тривалості** — поточна тривалість мінус тривалість у базовому плані, в робочих днях.

## Настроювані

- **Код операції** — один стовпець для кожного коду операції, з назвою коду. Показує код вибраного значення. Можна редагувати: ви вводите код або вибираєте його з підказок; невідомий код відхиляється, а якщо код трапляється більше одного разу, застосунок просить вибрати його зі списку.
- **Настроюване поле** — один стовпець для кожного настроюваного поля, з його назвою. Введення відповідає типу: текст, число, ціле число, витрати, дата або так/ні. Можна редагувати.

Ці стовпці належать до проєкту, в якому є код або поле. Див. [Коди та настроювані поля](docs://howto-codes-en-velden).

## Технічні

Усі стовпці цієї категорії лише для читання. Вони показують дані, які застосунок зберігає, але не показує у звичайному стовпці, наприклад для перевірки імпорту.

- **Ідентифікатор завдання** — внутрішній ідентифікатор завдання.
- **Ідентифікатор батьківського завдання** і **Ідентифікатори дочірніх завдань** — ідентифікатори батьківського та дочірніх завдань.
- **Ідентифікатори ресурсів** — ідентифікатори ресурсів у завданні.
- **Ідентифікатор призначення**, **Ідентифікатор завдання призначення** і **Ідентифікатор ресурсу призначення** — ідентифікатори призначення, завдання і ресурсу для цього завдання.
- **Тривалість (хвилини)** і **Залишкова тривалість (хвилини)** — тривалість і залишкова тривалість у хвилинах; заповнюється лише для завдання в годинах.
- **Затримка через вирівнювання (хвилини)** і **Астрономічна затримка через вирівнювання** — затримка через вирівнювання з MS Project у хвилинах, і чи рахується вона в астрономічному часі.
- **Заплановано вручну** — чи заплановано завдання вручну.
- **Тип завдання MS Project (імпорт)** і **Фіксований обсяг роботи** — тип завдання та прапорець фіксованого обсягу роботи, як вони були в MS Project.
- **Походження Primavera P6** — вихідні поля з файлу Primavera, у вигляді `key: value`.
- **Явне зведене завдання** — чи є завдання явним зведеним завданням без підзавдань (з файлу Primavera).
- **Поетапний нижній поріг завершення**, **Поетапна прив'язка початку**, **Поетапні сегменти тривалості** і **Поетапні контури** — розподіл годин з файлу MS Project, у вигляді дат і кількостей.
- **Дані кодів операцій**, **Дані настроюваних полів** і **Дані приміток** — кількість призначень кодів, настроюваних полів і приміток.
- **Дані внутрішніх залежностей** і **Дані зовнішніх залежностей** — кількість внутрішніх і зовнішніх залежностей.
- Для кожного базового плану тут також є **Віха** і **Тип віхи**, як їх зафіксував базовий план.
