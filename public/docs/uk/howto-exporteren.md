# Експорт

Мета: передати ваш графік у файлі іншого формату для того, хто не читає IFC, або для іншої програми.

## Коли це потрібно

Консультант працює в MS Project, замовник у Primavera, субпідрядник хоче отримати завдання в Excel, або ви надсилаєте графік в іншу програму, яка не працює з IFC. Експорт — це копія в іншому форматі. Якщо ви хочете зберегти сам проєкт, збережіть його: так записується IFC, і все переноситься разом із ним. Що переноситься в кожному форматі, а що ні, описано в [Файли і формати](docs://uitleg-bestanden).

## Кроки

1. Виберіть *Початок › Файл › Експорт* і оберіть формат зі списку, або виберіть *Файл › Експорт*. Там кожен формат є карткою з коротким описом.
2. У вікні виберіть назву і місце. Застосунок пропонує назву проєкту з розширенням формату. Аркуші прогресу називаються *projectname-voortgang* і, де це можливо, зберігаються у вашій папці завантажень.
3. Підтвердьте. Повідомлення не з'являється, якщо експорт успішний, крім повідомлень нижче. Із *Файл › Експорт* ви потім повертаєтеся на вкладку *Початок*, навіть якщо скасуєте вікно. Якщо ви скасуєте вікно для експорту зі списку на вкладці *Початок*, нічого не станеться.

Якщо ваш браузер зберігає файли лише через завантаження (наприклад, Firefox), файл одразу після кроку 1 з'являється у вашій папці завантажень. Ви бачите повідомлення *Збережено як завантаження: «name.xml» тепер у вашій папці завантажень. Це середовище не дозволяє програмі записувати безпосередньо в обране вами місце.*

### Який формат ви обираєте?

Список на вкладці *Початок* і картки в *Файл › Експорт* пропонують однакові формати:

- *Прогрес (Excel)* і *Прогрес (CSV)*, на картках *Аркуш прогресу (Excel)* і *Аркуш прогресу (CSV)*: компактний аркуш з ідентифікатором, WBS, назвою, датами і відсотком виконання, який надсилають тому, хто вносить прогрес.
- *CSV (;)*, на картці *CSV (розділений крапкою з комою)*: список завдань, який ви відкриваєте в електронній таблиці.
- *MS Project XML*: можна відкрити в Microsoft Project.
- *Primavera P6 XML*: для Oracle Primavera P6.
- *IFC 4x3*: власний формат застосунку, у якому є все.

### Експорт IFC з файлом бібліотеки

Якщо ваш проєкт пов'язаний з бібліотекою ресурсів, прапорець *Зберегти файл бібліотеки поруч* розташований під картками в *Файл › Експорт*. Якщо ви його відмітите і виберете *IFC 4x3*, застосунок двічі запитає місце: спершу для проєкту, потім для *projectname-bibliotheek.ifc*. Цей прапорець є лише в *Файл › Експорт*, а не в списку на вкладці *Початок*.

### Відновлення аркуша прогресу

Заповнений аркуш прогресу ви повертаєте в застосунок через *Файл › Імпортувати*. Див. [Імпорт прогресу з електронної таблиці](docs://howto-voortgang-importeren).

## Підводні камені та що застосунок робить тоді

**Ваш проєкт не змінюється.** Файл вашого проєкту лишається таким самим, а позначка *Не збережено* лишається, якщо вона була.

**Застарілий графік спочатку проходить перерахунок.** Тому ви отримуєте актуальні дати, навіть якщо забули натиснути *Обчислити*.

**Експорт також є в розділі Нещодавні.** Це не стосується аркушів прогресу. Якщо ви відкриваєте там експорт, він відкривається як імпорт цього формату.

**Експорт переносить не все.** У файлі CSV немає ресурсів і обмежень, а P6 XML не має базових планів і крайніх термінів. Профіль обчислень також не переноситься: повторно відкритий експорт обчислюється як *Open Planner Studio*. Лише IFC переносить усе. Приклад із числами є в [Файли і формати](docs://uitleg-bestanden).

**Два формати з однаковим розширенням.** MS Project XML і Primavera P6 XML обидва отримують назву *projectname.xml*. Дайте їм різні назви самі, інакше пізніше не зрозумієте, який файл має який формат.

**Графік із циклічною залежністю не експортується.** Застосунок спершу обчислює графік і зупиняється, якщо є цикл. На вкладці *Початок* ви отримуєте повідомлення *Не вдалося розрахувати графік*, а під ним, наприклад, *Циклічна залежність між завданнями: Set up site → Demolish existing extension → Set up site*. У *Файл › Експорт* на сторінці є лише цей другий текст. Усуньте цикл і експортуйте знову.

**Проєкт з Primavera втрачає початкову інформацію.** Якщо ви експортуєте такий проєкт у CSV, MS Project XML або P6 XML, застосунок повідомляє: *Експорт у CSV втрачає початкову інформацію XER.* Для MS Project XML він каже *MSPDI*, для P6 XML — *P6*. Див. [Відкриття файлу Primavera P6 (.xer)](docs://howto-xer-openen).

**Розподілені завдання втрачають свій поділ.** MS Project і Primavera знають поділ лише як розподіл трудовитрат за годинами. Якщо ваш проєкт містить розподілені завдання без розподілу трудовитрат за годинами, застосунок після експорту в MS Project XML або P6 XML повідомляє: *2 завдання з перервами експортовано без них: MS Project і P6 знають перерви лише як розподіл трудовитрат.* Для одного завдання він каже *1 завдання з перервами експортовано без них: MS Project і P6 знають перерви лише як розподіл трудовитрат.* Див. [Розділення завдання](docs://howto-taak-splitsen).

**Графік у поданні *Дати, як їх записано*.** Якщо ви експортуєте в CSV, поки бачите дати з початкового файлу, застосунок залишає порожніми `Critical` і `Total Float` для завдань, для яких початковий файл цього не записав. Див. [Дати, як їх записано](docs://uitleg-datums-zoals-opgeslagen).
