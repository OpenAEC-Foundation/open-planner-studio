# Відкриття файлу MS Project (.mpp)

Мета: відкрити графік із Microsoft Project безпосередньо в застосунку, без попереднього експорту.

## Коли це потрібно

Підрядник, консультант або замовник надсилає вам свій графік як файл `.mpp`. Ви хочете переглянути його, обчислити або далі опрацювати. Застосунок читає файли `.mpp` від MS Project 2010 до 2021 включно. Він лише читає: він не записує `.mpp` і ніколи не змінює ваш файл. З файлу він бере сам графік: завдання зі структурою, тривалістю та обмеженнями, залежності із затримкою, календарі, ресурси, призначення та прогрес. Він також читає дати й резерв часу, які MS Project обчислив сам, але використовує їх лише для вигляду *Дати, як їх записано*, ніколи як вхідні дані.

## Кроки

1. Виберіть *Початок › Файл › Відкрити* або натисніть Ctrl+O. Виберіть файл `.mpp`.
2. Проєкт відкривається на новій вкладці або в поточній вкладці, якщо вона ще була порожньою й без змін. Проєкт не має файлу: пізніше *Зберегти* записує новий файл IFC. Потім з'являється вікно, яке коротко пояснює, що застосунок переняв із файлу і як працює збереження; див. [Відкриття і збереження файлу](docs://howto-bestand-openen-en-opslaan).
3. Прочитайте повідомлення внизу: *Цей проєкт обчислюється як Microsoft Project. Змініть це через Файл → «Інформація про проєкт» → «Профіль обчислень і параметри обчислень».* Застосунок обчислює цей проєкт за правилами обчислень MS Project: профіль обчислень *Microsoft Project*. Через *Відкрити профіль обчислень* ви переходите до цього параметра. *Докладніше* відкриває довідку про профілі обчислень.
4. Перевірте, чи є під стрічкою рядок повідомлення: *Ви бачите дати так, як вони записані у файлі; перерахунок змінить дати у 4 завданнях.* Тоді на цих завданнях результат застосунку відрізняється від дат, які зберіг MS Project. Під повідомленням із кроку 3 є ще один рядок: *4 завдання показують дати так, як вони є у файлі (не перераховано).* Що це означає і як перейти на власне обчислення застосунку, описано в [Дати, як їх записано](docs://uitleg-datums-zoals-opgeslagen).
5. Якщо там написано *Цей файл містить планування за годинами.* і є кнопка *Увімкнути планування за годинами*, файл містить дані в годинах. Див. [Увімкнення планування за годинами](docs://howto-urenplanning-aanzetten).

Якщо файл містить завдання з розділеним, вирівняним або залежним від ресурсів графіком, додається ще одне повідомлення, наприклад: *Цей файл MS Project містить 3 завдання з розділеним, вирівняним або залежним від ресурсів графіком. Їх імпортовано та показано саме так.* Для одного завдання повідомлення подано в однині.

## Підводні камені і що тоді робить застосунок

**Не все переноситься.** Після відкриття застосунок в одному повідомленні каже, що він не переняв: *Не все з цього файлу MS Project перенесено.* Під ним є по одному рядку на кожен пункт із числом, наприклад *2 базові плани не перенесено.* Для файлу `.mpp` речення про профіль обчислень із кроку 3 тоді є першим рядком цього повідомлення. Повідомлення лишається, доки ви не натиснете хрестик. Якщо нічого не втрачено, це повідомлення не з'являється. Рядок може стосуватися:

- вставлених проєктів (підпроєктів): застосунок читає їх як звичайне завдання, без зв'язку з іншим файлом;
- зовнішніх завдань з іншого проєкту: застосунок читає їх як звичайне завдання;
- базових планів: з файлу `.mpp` застосунок не переймає жодного базового плану, з XML MS Project лише базовий план 0 завдань, і з нього лише дати та тривалість (для завдання в годинах також час; не трудовитрати та витрати, і не базові плани ресурсів і призначень);
- з XML MS Project: призначення, чий базовий план має інші дати, ніж його завдання. Застосунок переймає лише базовий план завдання; якщо дати однакові, нічого не втрачається і застосунок нічого не повідомляє. Інший час того самого дня теж вважається відмінністю;
- настроюваних полів зі значеннями, як-от настроювані поля, значення з таблиці пошуку та коди структури (у файлі `.mpp` застосунок не враховує поля так/ні);
- нотаток (також нотатка лише з малюнком) до ресурсів і призначень, а з файлу `.mpp` також до завдань (з XML MS Project нотатка завдання переходить як його опис);
- гіперпосилань;
- фіксованих витрат завдань;
- ставок ресурсів: з файлу `.mpp` жодної ставки, з XML MS Project лише стандартну ставку;
- лише з XML MS Project: завдань, запланованих вручну (застосунок планує їх автоматично), неактивних завдань (вони входять до обчислення) і затримки через вирівнювання;
- лише з файлу `.mpp`: граничного значення для критичності з MS Project; застосунок використовує граничне значення 0.

Код робочої структури проєкту (WBS), який ви самі заповнили в MS Project, переноситься. Інакше застосунок нумерує завдання за структурою.

**Файл із MS Project 2007 або старішого.** Застосунок відмовляє у відкритті й повідомляє: *Цей файл .mpp має старий формат (Project 2007 або старіший). У MS Project експортуйте його як XML (Файл → Зберегти як → XML) і відкрийте цей файл.* Під повідомленням застосунок додає технічну причину англійською мовою.

**Файл із паролем.** Застосунок повідомляє: *Цей файл .mpp захищено паролем. У MS Project експортуйте його як XML (Файл → Зберегти як → XML) і відкрийте цей файл.* Тут повідомлення теж супроводжується технічною причиною англійською мовою.

**Файл, що виявився не `.mpp`.** Ви бачите *Не вдалося відкрити файл* з технічною причиною.

**Маршрут через XML обчислює інакше.** Якщо ви відкриваєте експорт MS Project у форматі XML замість `.mpp`, застосунок обчислює з профілем обчислень *Open Planner Studio*, і ви не бачите повідомлення про *Microsoft Project*. Дати тоді можуть вийти інакшими, ніж у файлі `.mpp`. Також і з експортом XML застосунок повідомляє, що він не переймає; див. *Не все переноситься*.

**Редагування знімає керування з MS Project.** Якщо ви редагуєте завдання, графік якого керувався вікном дат MS Project, застосунок один раз на проєкт повідомляє: *Вікно дат з MS Project після цієї зміни більше не визначає дати для 2 завдання. Розподіл трудовитрат і далі діє та зберігається у файлі.* Для одного завдання повідомлення подано в однині.

**Збереження ніколи не перезаписує ваш `.mpp`.** Проєкт не має файлу. *Зберегти* запитує, де зберегти новий файл IFC.
