# Коды и настраиваемые поля

Цель: привязать к задачам собственные классификации (коды задач, например *Местоположение*) и собственные поля (например, *Подрядчик*).

## Когда это нужно

Кроме постоянных данных задачи (название, длительность, связи, …) вы можете добавить собственные данные. Если вы хотите классифицировать задачи по северному и южному крылу, по дисциплине или отслеживать, какой подрядчик выполняет задачу, вы записываете это сами. Есть два способа, и разница важна.

**Код задачи** — это классификация с фиксированным списком выбора. Вы создаете **тип кода** (например, *Местоположение*) со **значениями** (*N* для северного крыла, *Z* для южного крыла). Задача получает не более одного значения для каждого типа кода.

**Настраиваемое поле** (в окне под заголовком *Настраиваемые поля*) — это свободное поле ввода с типом: *Текст*, *Число*, *Целое число*, *Затраты*, *Дата* или *Да/нет*. Поле может хранить разное значение у каждой задачи.

## Шаги

### Определение кодов и полей

1. Выберите *График › Макет › Коды и поля*.
2. **Создание типа кода.** В поле *Новый тип кода (например, Местоположение)* введите название и нажмите Enter или щелкните *Добавить тип кода*.
3. **Добавление значений.** Под типом кода щелкните *Добавить значение*. Приложение поставит туда предварительный код, например *V1*. Измените его в поле *Код*: укажите короткое обозначение, как вы бы его ввели, например *N*. При необходимости заполните поле *Описание* (*Северное крыло*) и выберите *Цвет*. Изменение применяется, как только вы выйдете из поля или нажмете Enter.
4. **Создание настраиваемого поля.** В поле *Новое поле (например, Подрядчик)* введите название, выберите тип и щелкните *Добавить поле* (или нажмите Enter).

В окне нет кнопки OK: каждое изменение применяется сразу. Тип поля потом изменить нельзя, только его название. Если нужен другой тип, создайте новое поле.

### Заполнение кода или поля у задачи

Есть два места.

- **В панели *Свойства*** (или в окне, которое открывается по F2). Внизу находится блок *Коды и поля*: список выбора для каждого типа кода и поле ввода для каждого поля. Блок появляется, только когда есть хотя бы один тип кода или поле.
- **Как столбец в таблице задач.** Щелкните **+** справа от заголовка таблицы (*Добавить столбец*) и в разделе *Настраиваемые* выберите тип кода или поле. В ячейке типа кода введите код, например `N`, или выберите его из списка. Код, которого нет, дает сообщение *Выберите значение из этого кода задачи.*

### Использование

Тип кода или настраиваемое поле можно использовать для фильтрации, группировки и сортировки. Настройте это с помощью макета: *Вид › Макет › Новый макет*. В окне отметьте части, которые нужно включить в макет. Если нажать *Сохранить*, в меню *Вид › Макет* появится кнопка, на которую можно щелкнуть позже. Если нажать *Применить без сохранения*, макет только показывается на экране сейчас. При группировке задачи без значения попадают в группу *(нет)*.

Чтобы задать цвет полос, выберите *Вид › Базовые планы и ход выполнения › Цвета полос*, затем *По категории* и тип кода. Затем каждая полоса получает *Цвет* своего значения.

## Подводные камни и что делает приложение

**Удаление убирает значения у задач.** Если вы удалите тип кода, значение или поле через корзину, приложение не спрашивает подтверждения, и значения у всех задач исчезают вместе с ним. Группировка или сортировка по этому типу кода или полю тоже перестает действовать. *Отменить* (Ctrl+Z) возвращает тип кода, значение или поле и заполненные значения, но не группировку и сортировку: их придется настроить заново.

**Два значения с одним кодом.** *Добавить значение* нумерует новые значения, продолжая от числа уже существующих. Если вы удалите одно значение и добавите другое, код может повториться. Если вы введете такой код в ячейку столбца, приложение отказывает и выдает сообщение *Это значение кода задачи встречается несколько раз. Выберите его из списка.* Дайте каждому значению свой код.

**Шаблоны не переносят коды и поля.** См. [Сохранение и вставка шаблонов СДР](docs://howto-wbs-sjablonen). Если вы вставите задачи в другой документ, приложение очистит коды и поля, которых там нет, и сообщит вам об этом.

**Поле даты не сдвигается вместе с проектом.** Если вы переместите весь проект, заполненные настраиваемые поля типа *Дата* останутся на своих датах. Приложение предупреждает об этом в предварительном просмотре.
