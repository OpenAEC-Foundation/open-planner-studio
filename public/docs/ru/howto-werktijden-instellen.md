# Настройка рабочих часов

Цель: для каждого дня недели указать, в какое время по часам работает календарь. Тогда задачи в часах выполняются в нужное время.

## Когда это нужно

Вторая половина пятницы не рабочая. Бригада работает с 06:00 до 22:00 в две смены. Есть ночная бригада. Перерыв короче часа. Пока вы планируете только в днях, достаточно полей *Начало (час)*, *Окончание (час)* и перерыва ([Создание и назначение календаря](docs://howto-kalender-maken-en-toewijzen)). Если вы планируете задачи в часах, приложение считает рабочие минуты внутри **блоков рабочего времени** календаря. В интерфейсе для этих блоков используется название *блок*. Блок — это непрерывный отрезок рабочего времени в один день недели. Промежуток между двумя блоками — это перерыв. Что это значит для вашего графика, описано в разделе [Дни и часы](docs://uitleg-dagen-en-uren).

Для этого нужна настройка *Включить почасовое планирование* ([Включение почасового планирования](docs://howto-urenplanning-aanzetten)). Без почасового планирования вы не видите панель *Рабочие часы*.

## Шаги

### Выбор пресета смены

1. Выберите *График › Календарь › Календарь* и слева укажите календарь.
2. На панели *Рабочие часы* нажмите пресет. Он заменяет рабочие дни и рабочие часы календаря.
3. Нажмите *Применить*.

Каждый пресет задает следующее:

- *Дневная смена*: с понедельника по пятницу с 08:00 до 16:00 без перерыва. Календарь снова становится обычным, без блоков рабочего времени.
- *2 смены*: с понедельника по пятницу с 06:00 до 14:00 и с 14:00 до 22:00, всего 16 часов.
- *3 смены*: с понедельника по пятницу три смены: с 06:00 до 14:00, с 14:00 до 22:00 и с 22:00 до 06:00 следующего дня, всего 24 часа.
- *Ночная смена*: с понедельника по пятницу с 22:00 до 06:00 следующего дня, 8 часов.
- *24/7*: все семь дней с 00:00 до 24:00.

### Задание рабочих часов по дням недели

1. На панели *Рабочие часы* нажмите *Задать по дням недели…*. Под кнопками появится строка для каждого дня недели с рабочим временем этого дня. У календаря теперь есть блоки рабочего времени по дням недели. Если они уже есть, этот обзор сразу открыт. Тогда кнопка называется *Скрыть рабочие часы* и сворачивает обзор.
2. Измените время начала и окончания каждого блока в двух полях времени.
3. Если вы хотите добавить перерыв, нажмите **+** (*Добавить блок*) для этого дня и измените время блоков так, чтобы между ними был промежуток. Новый блок начинается в 08:00 и заканчивается в 16:00.
4. Блок, который идет через полночь, отметьте *на следующий день*. Блок учитывается в том дне, в котором он начинается.
5. Нажмите значок корзины рядом с блоком, чтобы удалить его. День без блоков отображается как *Нерабочий день*.
6. Для дня с понедельника по пятницу нажмите значок копирования (*Копировать на все рабочие дни*), чтобы блоки этого дня появились с понедельника по пятницу.
7. Внизу находится *Расчетные часы/день:* с чистым количеством часов в день, которое приложение вычисляет по этим данным. Нажмите *Применить*.

**Пример: свободная вторая половина пятницы.** Нажмите *Задать по дням недели…*. Удалите второй блок (с 13:00 до 16:00) для *Пт*. Теперь в пятнице 5 часов, в остальные дни 8. Расчетные часы в день остаются 8.

### Сохранение собственного пресета

1. Нажмите *Сохранить как пресет…* и введите название в поле *Название своего пресета*.
2. Нажмите *Сохранить*. Пресет появится среди других пресетов, и вы сможете использовать его в любом проекте. Чтобы удалить его, нажмите крестик рядом с ним.

Собственный пресет хранится на этом устройстве, а не в файле проекта.

## Типичные ошибки и что делает приложение

**Пресет заменяет все.** Если вы выбираете пресет, рабочие дни и рабочие часы, которые вы задали раньше, исчезают. Праздничные дни остаются.

**Кнопки дней и блоки — это разные вещи.** Кнопки под *Рабочие дни* не меняют блоки. День получает рабочее время, нажав *Добавить блок* для этого дня. Если вы включаете день только кнопкой, он учитывается для задач в днях, но не для задач в часах. Если у календаря есть рабочие часы, пользуйтесь строками по дням недели.

**Изменение рабочих часов при выключенном почасовом планировании.** Если вы снова выключите почасовое планирование, появятся поля *Начало (час)*, *Окончание (час)* и перерыв. В календаре с блоками рабочего времени эти поля не меняют блоки. Поэтому всегда меняйте рабочие часы, когда почасовое планирование включено.

**Нет допустимых рабочих часов.** Календарь без блоков или без рабочих дней не может учитывать задачу в часах. Тогда приложение выдает сообщение *У этого календаря нет допустимых рабочих часов. Проверьте рабочие дни и рабочие часы.*
