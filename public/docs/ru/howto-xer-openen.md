# Открытие файла Primavera P6 (.xer)

Цель: открыть график из Primavera P6 прямо в приложении, без предварительного экспорта в XML.

## Когда это нужно

Заказчик или генеральный подрядчик работает в Primavera и передает свой график в виде файла `.xer`. Вы хотите его посмотреть, рассчитать или дополнить. Приложение только читает файлы `.xer`: оно не записывает `.xer` и никогда не меняет ваш файл. Из файла оно берет структуру СДР и задачи с длительностью, датами, ограничениями и ходом выполнения, связи с задержками, календари и ресурсы с их назначениями, а также коды задач, настраиваемые поля (UDF), примечания и настройки расчета P6. Задача типа *Уровень усилий* становится гамаком.

## Шаги

1. Выберите *Главная › Файл › Открыть* или нажмите Ctrl+O. Выберите файл `.xer`.
2. Приложение открывает по одной вкладке для каждого проекта, в котором есть задачи. Проект с наибольшим числом задач становится активной вкладкой. Вкладка называется *Название проекта (Project ID)*, если ID проекта в P6 отличается от названия. *Настройки проекта* показывает только название. Если вы переименуете проект, после названия остается ID проекта. Затем окно коротко объясняет, что приложение перенесло из файла и как работает сохранение; см. [Открытие и сохранение файла](docs://howto-bestand-openen-en-opslaan).
3. Прочитайте сообщение внизу. Для файла с тремя проектами оно может выглядеть так: *Файл XER открыт: 3 документа проекта.* Ниже находятся строки, в которых объясняется, что сделало приложение. См. раздел ниже.
4. Проверьте, есть ли под лентой строка сообщения: *Вы видите график так, как его сохранила Primavera; при пересчете сместится 1 задача.* Primavera сохраняет в файле свои рассчитанные даты. Если расчет приложения отличается от них, приложение показывает даты Primavera, пока вы ничего не меняете. Задача, которая уже начата или завершена, всегда использует свои фактические даты, как и в Primavera. Что это значит и как перейти к собственному расчету приложения, описано в разделе [Даты, как их сохранила Primavera](docs://uitleg-datums-zoals-opgeslagen). Также может появиться сообщение *Этот файл содержит почасовое планирование.* с кнопкой *Включить почасовое планирование*. См. [Включение почасового планирования](docs://howto-urenplanning-aanzetten).
5. Сохраните проект с помощью Ctrl+S. Поскольку файл `.xer` никогда не перезаписывается, приложение спрашивает, где сохранить новый файл IFC. Оно предлагает *Название проекта (Project ID)* в качестве имени файла.

### Строки под сообщением

Первая строка сообщения называет количество открытых вкладок. Ниже находятся только строки, которые относятся к вашему файлу. На них стоит обратить внимание:

- *Этот проект рассчитывается как Primavera P6. Изменить можно в разделе «Файл → Информация о проекте → Профиль расчета и параметры расчета».* Приложение рассчитывает этот проект по правилам расчета Primavera. С помощью *Открыть профиль расчета* вы переходите к настройке.
- *Исключён 1 проект базового плана* и *Создан 1 базовый план*. Если в P6 один проект назначает другой проект своим базовым планом, этот другой проект не открывается как отдельная вкладка. Он становится активным базовым планом того проекта, который на него ссылается.
- *Применён защитный запасной вариант для базового плана.* Если назначение базовых планов означало бы, что не откроется ни один проект, если проект ссылается сам на себя или если проекты ссылаются друг на друга по кругу, приложение просто открывает все проекты и не создает базовых планов.
- *Сохранена 1 внешняя зависимость.* Связь между двумя проектами. Приложение сохраняет ее как исходные данные, но не превращает в связь в вашем графике.
- *12 задач показывают даты так, как их сохранила Primavera (без пересчёта).* Это число задач, для которых представление *Даты, как их сохранила Primavera* показывает даты Primavera: все задачи, для которых файл содержит даты, а не только те, которые отличаются.

Остальные строки — это диагностика самого чтения файла. От вас они ничего не требуют:

- количество найденных проектов;
- пропущенный пустой проект;
- проигнорированная ссылка на базовый план, которого нет;
- кодировка текста, отличная от обычной UTF-8 (в сообщении указано, какая именно: для арабского, кириллического или греческого текста приложение выбирает подходящую кодовую страницу Windows, в остальных случаях — Windows-1252);
- задачи без плановой даты начала (они начинаются с даты отчета о состоянии или с начала проекта из файла);
- счетчики замечаний в таблицах, календарях и числовых значениях, неизвестных значениях полей и настройках графика P6, которые приложение заменило безопасным выбором.

*Подробнее* открывает справку об открытии файлов Primavera.

## Возможные проблемы и что делает приложение в этом случае

**Не все становится вкладкой или связью.** Проект без задач не открывается, проект базового плана не открывается как отдельная вкладка, а связь между двумя проектами не становится связью в вашем графике. Приложение сообщает об этом в строках под сообщением.

**Каждая вкладка — это отдельный проект.** Если вы сохраните вкладку, файл IFC сохранит и полный исходный файл `.xer`. Если вы позже снова откроете этот файл IFC, приложение по-прежнему будет знать даты Primavera. Если исходный архив поврежден или другая программа для IFC переписала файл, приложение сообщает: *Исходный архив XER в этом файле непригоден и пропущен; сам проект открыт полностью.* График, профиль расчета и все данные проекта полные. Не хватает двух вещей: дат, которые сохранила Primavera, и сведений о происхождении данных для ИИ и расширений. Чтобы вернуть архив, снова откройте исходный файл `.xer`.

**Файл IFC становится больше.** Поскольку файл IFC содержит весь исходный файл `.xer`, он больше файла IFC без архива. С большим `.xer` это заметно по размеру файла и по времени сохранения. Если `.xer` открывает несколько проектов, каждая сохраненная вкладка содержит весь исходный файл `.xer`, а не только свой проект.

**Экспорт в CSV, MS Project XML или P6 XML приводит к потере данных.** Приложение предупреждает: *При экспорте в CSV теряются сведения об исходном файле XER.* IFC ничего не теряет.

**Свободная суббота или воскресенье, которых нет в файле.** Приложение может само сделать такой выходной день свободным. Тогда в календаре он называется *Исключение календаря (восстановление выходных)*. Шаблон описан в [Форматы импорта и экспорта](docs://ref-import-exportformaten).

**Резерв времени до окончания проекта без даты окончания.** Если в файле нет даты окончания, приложение выключает параметр *Рассчитывать резерв времени до окончания проекта*. Это отражается в строке *N настроек графика P6 заменены безопасными значениями по умолчанию.* Подробности описаны в [Форматы импорта и экспорта](docs://ref-import-exportformaten).

**Завершенные задачи на дате отчета о состоянии.** Завершенная задача может выглядеть как узкая полоса на дате отчета о состоянии в представлении *Даты, как их сохранила Primavera*. Это не ошибка в вашем файле. Объяснение и связанное правило расчета описаны в [Форматы импорта и экспорта](docs://ref-import-exportformaten).

**Числа с запятой в качестве десятичного разделителя.** Если приложение не может надежно определить десятичный разделитель, оно не открывает файл. Так никогда не открывается график с неверно прочитанными числами. Попросите отправителя прислать новый экспорт.

**Файл, который приложение не может прочитать.** Вы получаете сообщение об ошибке с причиной. Несколько примеров:

- *Это некорректный или неподдерживаемый файл XER.*
- *В таблице XER не хватает обязательных столбцов.*
- *Проект P6 в этом файле XER не содержит задач.*
- *Формат десятичных знаков в этом файле XER нельзя надёжно определить.*

Тогда ничего не открывается. Проверьте файл в P6 или попросите отправителя прислать новый экспорт.
