# Подключение MCP-клиента

Цель: дать MCP-клиенту возможность читать ваш график и работать с ним, при этом вы видите, что он делает, и сами задаете ему ограничения.

## Быстро: пусть Claude сделает это сам

Вы работаете в Claude Desktop или Claude Code? Тогда Claude может сам установить подключение:

1. Нажмите *Копировать промпт* ниже.
2. Вставьте промпт в новый чат с Claude и отправьте его.

Затем Claude установит расширение для Open Planner Studio и по ходу объяснит, что оно делает. Если вам нужно сделать что-то самому, например нажать *Установить* в Claude Desktop, Claude точно скажет, что именно нажать. Токен для этого не нужен.

```prompt
Установите для меня расширение Open Planner Studio, чтобы вы могли читать и менять мои строительные графики в Open Planner Studio. Делайте как можно больше сами. Перед каждым шагом скажите одним простым предложением, что вы собираетесь сделать и зачем. Если вам нужна моя помощь, спрашивайте по одному вопросу и ждите моего ответа. Если я должен что-то сделать сам, скажите мне точно, какой один щелчок или шаг нужен и где.

Что вам нужно знать:
- Расширение — это один файл open-planner-studio-<version>.mcpb из последнего релиза: https://github.com/OpenAEC-Foundation/open-planner-studio/releases/latest. Прямая ссылка указана в https://api.github.com/repos/OpenAEC-Foundation/open-planner-studio/releases/latest (файл, имя которого заканчивается на .mcpb). Файл представляет собой ZIP-архив.
- Расширение работает с настольным приложением Open Planner Studio и без него. Когда приложение открыто и его мост MCP запущен, вы работаете с планом, открытым в приложении. Когда приложение закрыто, вы читаете и меняете файлы графиков в рабочей папке, которую выбираю я.
- Для установки не нужны ни токен, ни пароль. Не просите меня ни о токене, ни о пароле, и не читайте и не показывайте их.

Если вы работаете в Claude Desktop:
1. Если вы можете скачать файл и открыть его на моем компьютере, сделайте это с файлом .mcpb. Если не можете, дайте мне прямую ссылку для скачивания и скажите мне дважды щелкнуть по файлу, когда загрузка завершится.
2. Затем Claude Desktop покажет расширение Open Planner Studio. Скажите мне нажать Установить. Затем скажите мне выбрать в поле «Рабочая папка» папку, в которой лежат мои файлы графиков.
3. Скажите мне начать новый чат и спросить вас там, какие инструменты Open Planner Studio вы видите.

Если вы работаете в Claude Code:
1. Проверьте, что установлен Node.js 22 или новее. Если нет, скажите мне, как его установить, и остановитесь.
2. Спросите меня, в какой папке лежат мои файлы графиков. Это и есть рабочая папка.
3. Скачайте файл .mcpb и распакуйте его в новую отдельную папку в моей пользовательской папке. Прочитайте там manifest.json: server.mcp_config показывает, как запускается сервер. Замените ${__dirname} на распакованную папку, а ${user_config.workdir} на рабочую папку.
4. Выполните claude mcp list. Если сервер с именем open-planner-studio уже есть, спросите меня, можно ли его заменить. Не показывайте его настройки, потому что в них может быть токен.
5. Добавьте сервер для моей учетной записи пользователя, например: claude mcp add open-planner-studio --scope user -e OPS_MCP_ROOT=<рабочая папка> -- node <распакованная папка>/server/index.mjs
6. Скажите мне начать новую сессию Claude Code, а также что /mcp там показывает, подключен ли open-planner-studio.

Если вы работаете в другом месте, например в claude.ai в браузере, скажите мне, что для этого нужны Claude Desktop или Claude Code. Если вы не знаете, где работаете, спросите меня.

Когда установка завершена, объясните в нескольких предложениях:
- как я разрешаю вам работать в открытом приложении: в Open Planner Studio выберите Настройки › Проект › Настройки приложения, вкладка Дополнительно, и включите Разрешить подключение MCP. Затем нажмите Запустить мост на вкладке MCP.
- что без приложения изменение попадает в файл только после того, как вы его сохраните, и что вы не перезаписываете существующий файл, пока приложение открыто.
Если шаг не удался, скажите мне одним предложением, что пошло не так и что я могу сделать. Не угадывайте.
```

Вы предпочитаете сделать это сами или используете другой MCP-клиент? Тогда следуйте шагам ниже.

## Когда это нужно

Вы хотите, чтобы MCP-клиент читал, анализировал или менял ваш график. Например, чтобы он составил черновой СДР, исправил задачи или объяснил критический путь. Это работает через **Model Context Protocol** (MCP): стандарт, который позволяет программе с ИИ, то есть **MCP-клиенту**, использовать инструменты другой программы. Для этого Open Planner Studio запускает на вашем компьютере небольшой сервер, **мост**. Он предлагает набор инструментов; все их имена начинаются с `planner_`: чтение и изменение задач, связей, ресурсов, календарей, базовых планов, документов и файлов. Какие инструменты есть и что им запрещено, описано в [инструменты MCP](docs://ref-ai-tools). MCP-клиент работает в открытом проекте, а не в копии: задача, которую он добавит, сразу появляется в диаграмме Ганта. Он использует тот же расчет и ту же историю команды *Отменить*, что и вы.

Мост работает только в настольном приложении. Если вы разрешили подключение MCP в браузере, вы видите вкладку *MCP*, но кнопка *Запустить мост* серая и с текстом *Мост доступен только в настольном приложении.* Остальная часть этой статьи посвящена настольному приложению. В браузере кнопки *Создать копию сейчас* и *Открыть папку копий* тоже серые.

## Шаги

### 1. Разрешение подключения MCP

1. Выберите *Настройки › Проект › Настройки приложения*. Также можно выбрать *Файл › Настройки приложения* или шестеренку вверху.
2. Выберите вкладку *Дополнительно* и включите *Разрешить подключение MCP*. На ленте появляется вкладка *MCP*.
3. Если вы хотите, чтобы мост был активен сразу после запуска приложения, включите также *Автоматически запускать мост*. Это срабатывает, только когда подключение MCP включено, и работает только в настольном приложении. По умолчанию эта функция выключена, потому что открытие порта — осознанное решение.

Если выключить подключение MCP, мост останавливается и вкладка *MCP* исчезает.

### 2. Запуск моста

1. Перейдите на вкладку *MCP* и нажмите *Запустить мост* в группе *Сервер*.
2. Посмотрите на статус рядом с кнопкой. Там написано *Выкл*, *Активен на порту 3877*, *Порт 3877 занят* или *Ошибка*. Если запуск удался, там написано *Активен на порту 3877*, а кнопка называется *Остановить мост*. При статусе *Порт 3877 занят* или *Ошибка* кнопка остается *Запустить мост*; см. подводные камни.

Мост принимает подключения только на вашем компьютере, на одном порту. По умолчанию это порт 3877. В группе *Подключение* можно задать другой *Порт*, но только пока мост остановлен. Подключение идет по обычному HTTP на вашем компьютере. Само приложение ничего никуда не отправляет. Что клиент MCP делает с вашим графиком, например что с ним делает его поставщик, выходит за пределы приложения.

### 3. Подключение клиента MCP

1. Нажмите *Подключить* в группе *Подключение*. Откроется окно *Данные подключения*.
2. Выберите, что нужно вашему клиенту, см. ниже.
3. Токен скрыт. Значком глаза его можно показать. Кнопки копирования всегда копируют настоящее значение, даже если на экране токен скрыт.
4. Попросите клиент MCP запросить список инструментов. Эта проверка также есть в промпте подключения: клиент должен видеть инструменты с префиксом `planner_`; ожидаемое число указано в промпте подключения.

В окне есть четыре способа подключения:

- *Поручить Claude настройку*: тот же промпт, что в начале этой статьи, с кнопкой *Копировать промпт*. Это для Claude Desktop и Claude Code. Токен для этого не нужен.
- *Фрагмент конфигурации*: часть конфигурации, которую вы вставляете в настройки MCP вашего клиента.
- *Промпт подключения*: текст, который вы вставляете в клиент MCP, после чего клиент подключается сам.
- *Конечная точка* и *Аутентификация*: отдельные данные. Конечная точка — `http://localhost:3877/mcp`, транспорт — *потоковый HTTP*. Каждый запрос должен содержать заголовок `Authorization: Bearer`, за которым идет ваш токен. Клиент также должен поддерживать сеансы MCP: при подключении мост выдает код сеанса в заголовке `Mcp-Session-Id` и отклоняет каждый следующий запрос без этого кода. Claude Code и `mcp-remote` делают это сами.

**Подключитесь снова после обновления приложения.** Если клиент MCP уже был подключен к более старой версии приложения, он еще не отправляет код сеанса, и мост отклоняет каждый запрос. Поэтому подключитесь снова после обновления: начните новый сеанс в Claude Code и полностью закройте Claude Desktop, а затем запустите его снова.

**Claude Code.** Фрагмент конфигурации подходит для Claude Code напрямую. Выполните эту команду в терминале, подставив свой токен вместо `<token>`:

```
claude mcp add --transport http open-planner-studio http://localhost:3877/mcp --header "Authorization: Bearer <token>"
```

Фрагмент можно также поместить в файл `.mcp.json` в папке вашего проекта. Тогда не добавляйте этот файл в git, потому что токен дает доступ к вашему графику. Сервер из `.mcp.json` в Claude Code нужно подтвердить при первом использовании.

**Claude Desktop.** Для Claude Desktop есть расширение: файл `open-planner-studio-<version>.mcpb`. Claude Desktop устанавливает его двойным щелчком. Node.js для этого не нужен. Расширение работает и с приложением, и без него. Быстрее использовать промпт в начале этой статьи; ниже описаны шаги вручную.

1. Скачайте файл `.mcpb` из последнего выпуска: `https://github.com/OpenAEC-Foundation/open-planner-studio/releases/latest`.
2. Дважды щелкните файл. Claude Desktop откроется и покажет расширение *Open Planner Studio*. Установите его. Если двойной щелчок не работает, откройте в Claude Desktop *Настройки › Расширения* и установите файл там.
3. В поле *Рабочая папка* выберите папку с файлами графика. Claude использует эту папку, только когда приложение закрыто. Затем Claude читает и записывает файлы только в этой папке.
4. Включите расширение и начните новый чат. Спросите Claude, какие инструменты Open Planner Studio он видит.

Токен и порт вводить не нужно: пока мост работает, расширение само находит приложение. Для каждого запроса от Claude расширение выбирает заново:

- *Приложение открыто и мост работает*: Claude работает с графиком, который открыт в приложении. Каждое изменение вы сразу видите в приложении.
- *Приложение закрыто или мост выключен*: Claude работает с файлом графика в рабочей папке. Изменение попадает в файл, только когда Claude сохраняет файл. Автоматического сохранения нет. Пока приложение открыто, Claude не перезаписывает существующий файл, а сохраняет его под новым именем.

Если приложение открывается или закрывается, пока Claude работает, расширение переключается и сообщает об этом Claude. Затем Claude сначала снова выбирает или открывает график и только потом что-то меняет. Если у Claude еще есть несохраненные изменения без приложения, расширение продолжает работать без приложения, пока Claude их не сохранит. Так ничего не теряется. Если расширение не может связаться с приложением и нет подходящей рабочей папки, Claude видит только инструмент `open_planner_studio_status` с сообщением, которое объясняет, что делать.

**Claude Desktop без расширения.** Если расширение использовать нельзя, подключите Claude Desktop через внешний инструмент `mcp-remote`. Фрагмент конфигурации не подходит для Claude Desktop напрямую: в файле `claude_desktop_config.json` вы указываете программу, которую Claude Desktop запускает сам, а не адрес. Для `mcp-remote` нужен Node.js. В Claude Desktop выберите *Настройки › Разработчик › Редактировать конфигурацию*, вставьте в файл следующее (с вашим токеном) и снова запустите Claude Desktop:

```
{
  "mcpServers": {
    "open-planner-studio": {
      "command": "npx",
      "args": ["-y", "mcp-remote", "http://localhost:3877/mcp", "--header", "Authorization:${AUTH_HEADER}"],
      "env": { "AUTH_HEADER": "Bearer <token>" }
    }
  }
}
```

Токен указан в `env`, а не в `args`, намеренно: в Windows Claude Desktop ломает аргумент, в котором есть пробел. *Пользовательский коннектор* в Claude (*Настроить › Коннекторы*) с мостом не работает. Тогда Claude подключается из облака Anthropic, а оно не может связаться с мостом на вашем компьютере.

В группе *Подключение* есть также поле *Токен*. Это длинный случайный код, который приложение создает за вас и хранит на этом компьютере. В окне написано *Этот токен дает доступ к открытому графику. Не передавайте его другим.* С помощью значка *Создать новый токен* вы создаете новый токен. Сначала приложение спрашивает *Создание нового токена разорвет все текущие подключения. Продолжить?* Если мост работает, он перезапускается с новым токеном, и старый токен больше не работает.

**Как расширение находит приложение.** Пока мост работает, настольное приложение записывает порт и токен в файл `mcp/runtime.json` в папке данных приложения. Расширение для Claude Desktop читает этот файл при каждом запросе. В Linux и macOS читать файл может только ваша учетная запись пользователя. В Windows файл защищает стандартный ACL папки вашего профиля; приложение это отдельно не проверяет. Когда вы останавливаете мост или выключаете подключение MCP, приложение удаляет файл. Приложение также ведет список открытых файлов в `mcp/open-files.json`, даже когда подключение MCP выключено. Пока этот файл существует, расширение и MCP-сервер без интерфейса не перезаписывают ни один существующий файл, в том числе файл, который вы только что открыли и которого еще нет в списке. Создавать новый файл можно. Читать тоже можно: Claude тогда видит версию на диске, без ваших несохраненных изменений.

### 4. Просмотр действий клиента MCP

1. Нажмите *Панель активности* в группе *Задача*. В боковой части окна откроется панель *Активность MCP*.
2. Каждый вызов моста занимает одну строку, самые новые сверху: время, что произошло, сколько он занял и успешно ли выполнен. Нажмите строку, чтобы развернуть *Аргументы* и *Ответ*.
3. Кнопкой *Очистить* вы очищаете список. Панель хранит последние 500 вызовов. Пока ничего не произошло, там написано *Пока нет активности MCP. Вызовы моста появятся здесь.*

Когда подключение MCP включено, в правом нижнем углу строки состояния есть точка с *MCP*. Ее цвет показывает состояние моста, а щелчок по ней переводит вас на вкладку *MCP*.

### 5. Установка ограничений

В группе *Безопасность* находятся кнопки, с помощью которых вы ограничиваете клиент MCP:

- *Приостановить*: клиенту MCP временно нельзя ничего менять, чтение по-прежнему разрешено. Мост остается активным. Кнопка становится *Возобновить*.
- *Только для чтения*: все инструменты, которые что-то меняют, отклоняются, пока это включено.
- *Автокопия: вкл*: перед первым изменением клиентом MCP в документе приложение записывает копию IFC. По умолчанию это включено. Кнопкой вы ее выключаете, и тогда там написано *Автокопия: выкл*. Это происходит один раз для каждого документа при каждом запуске моста.
- *Создать копию сейчас*: сразу создает копию активного документа. После этого там написано *Копия создана:* и имя файла.
- *Открыть папку копий*: открывает папку с копиями.

Копии находятся в папке `ai-backups` в папке данных приложения. Приложение хранит последние копии и прореживает старые; точно, как это устроено, описано в [инструменты MCP](docs://ref-ai-tools).

### 6. Обеспечение хорошего планирования клиентом MCP

Клиент MCP хорошо планирует, только если знает правила составления графика. Это вы делаете сами:

1. **Для основных правил ничего делать не нужно.** Они передаются при подключении: мост отправляет их в поле `instructions` при рукопожатии MCP. Попадут ли они в системный промпт вашего клиента, зависит от клиента.
2. **Дайте клиенту прочитать руководство.** Промпт подключения из окна *Данные подключения* просит клиент MCP прочитать руководство с помощью инструмента `planner_get_planning_guide`. Если вы не используете промпт, скажите клиенту MCP следующее: *Сначала прочитайте руководство по составлению графика с помощью planner_get_planning_guide, прежде чем что-либо менять.* Руководство можно прочитать самостоятельно по адресу `https://open-planner-studio.open-aec.com/agent/planning-guide.md`.
3. **Необязательно: установите навыки.** Это работает только с клиентом MCP, который поддерживает навыки. Поместите `SKILL.md` навыков *goed-plannen* и *progress-update* в `.claude/skills/goed-plannen/SKILL.md` и `.claude/skills/progress-update/SKILL.md` в папке проекта, в которой работает клиент MCP, или в `~/.claude/skills/` для всех проектов.

Файлы можно получить двумя способами. Попросите клиент MCP вызвать инструмент `planner_get_planning_guide` с параметром `part`, равным `skill`: ответ содержит оба текста и для каждого навыка место, где он должен лежать. Или скачайте их по адресам `https://open-planner-studio.open-aec.com/skills/goed-plannen/SKILL.md` и `https://open-planner-studio.open-aec.com/skills/progress-update/SKILL.md`. Если *goed-plannen* остался от старой версии приложения, замените его: старый текст написан на нидерландском языке и ведет к статье справки, а не к руководству для клиентов MCP.

Действительно ли клиент MCP прочитал руководство, видно на панели *Панель активности*: там есть вызов `planner_get_planning_guide`. Итоговый ответ клиента должен содержать список допущений: оцененные длительности, выбранную разбивку, связи, которые клиент создал сам, и каждое заданное им ограничение. Если такого списка нет, попросите его. После обновления хода выполнения по *progress-update* в ответе должны быть указаны дата отчета о состоянии, новая дата окончания и отклонение от базового плана.

## Подводные камни и реакция приложения

**Клиент MCP меняет то, что вы хотите отменить.** Каждое изменение клиента MCP — это шаг, который вы отменяете кнопкой *Отменить* (Ctrl+Z). Серия изменений, которую клиент MCP передает как одно целое, — это один шаг. После этого проект отображается как несохраненный. После изменения график пересчитывается заново, поэтому F5 нажимать не нужно.

**Приложение отклоняет вызов клиента MCP.** Если включены *Приостановить* и *Только для чтения*, приложение отклоняет все изменения, а чтение остается возможным, в том числе пересчет устаревшего графика. Если вы сами находитесь в середине правки, например перетаскиваете полосу или вводите текст в поле, клиент MCP получает даты, которые были до вашей правки, с уведомлением, что они устарели. Если у вас открыто диалоговое окно, например настройки, диалог задачи или окно приветствия, или включен режим презентации, приложение отклоняет все вызовы, в том числе чтение, пока вы не закроете диалог. Тогда клиент MCP получает сообщение об ошибке с внутренним именем открытого окна, например `showTaskDialog`. Работает только `planner_get_planning_guide`, потому что он не читает ваш график.

**Вы переключаетесь между вкладками, пока клиент MCP работает.** Клиент MCP работает с документом, в котором было сделано его первое изменение. Если вы тем временем переключаете вкладки, приложение отклоняет его следующее изменение, пока клиент не подтвердит, что хочет работать с другой вкладкой. Так ничего не попадает в неправильный проект. Если клиент MCP сам открывает или дублирует документ, дальше он работает в этом новом документе.

**Клиент MCP записывает или открывает файл.** Клиент MCP может записать график как файл IFC и открыть файл графика в новой вкладке. Он может делать это только в вашей папке пользователя. Он перезаписывает существующий файл, только если явно запросил это.

**Статус — *Порт 3877 занят*.** Другая программа использует порт. Сообщение приложения показано под ним. Поле порта тогда остается заблокированным (*Изменить можно только при остановленном сервере.*), хотя мост не работает, и кнопки остановки нет. Это известный недостаток. Пока его не исправили, выключите и снова включите *Разрешить подключение MCP*. Тогда статус снова *Выкл*, и можно выбрать другой порт. Затем заново скопируйте данные подключения, потому что конечная точка содержит порт.

**Клиент не может подключиться после создания нового токена.** Новый токен разрывает все текущие подключения. Передайте клиенту новый токен или снова вставьте фрагмент конфигурации. Расширение в Claude Desktop само читает новый токен; там ничего делать не нужно.

**Вы сами остановили мост, и он сам не запускается.** *Автоматически запускать мост* срабатывает один раз при каждом запуске приложения. Если вы сами остановили мост, приложение его тихо снова не включает.

**Вкладка *MCP* исчезла.** Подключение MCP выключено. Включите его в шаге 1.

**Веб-страница в браузере не может обращаться к мосту.** Мост отклоняет каждый запрос, который пришел из браузера, и каждый запрос без правильного токена.

## Без приложения

Есть также MCP-сервер, который работает без настольного приложения: **MCP-сервер без графического интерфейса**. Он предоставляет те же инструменты `planner_*`, но работает с файлом графика на диске, а не с открытым проектом. Поэтому вы не видите изменений на диаграмме Ганта, а *Отменить* в приложении на них не действует. Используйте его, когда не хотите открывать приложение или работаете на компьютере без экрана.

Расширение для Claude Desktop само запускает этот сервер, когда приложение закрыто (см. шаг 3). Шаги ниже относятся к другому клиенту MCP, например к Claude Code.

Выпуск не содержит готового файла сервера для загрузки. Вы собираете его из исходного кода командой `npm run build:mcp-server`; для этого нужен Node.js 22 или новее. Результат — один файл `server.mjs`.

1. Выберите рабочую папку с файлами графиков. Сервер читает и записывает файлы только в этой папке.
2. Подключите свой клиент MCP. Для Claude Code команда указана ниже этих шагов.
3. Попросите клиент MCP открыть график, например `~/plan.ifc`. В этом сервере `~` означает рабочую папку.
4. Попросите клиент MCP сохранить результат. Автоматического сохранения нет: клиент MCP записывает файл с помощью `planner_export_ifc`. Все, что не сохранено, теряется при остановке сервера.

Для шага 2 в Claude Code выполните в терминале эту команду, подставив свои пути:

```
claude mcp add open-planner -- node /path/to/server.mjs --root /path/to/working-folder
```

Перед первым изменением каждого документа сервер создает резервную копию MCP, как и приложение. Клиент MCP, который выбирает путь за пределами рабочей папки, в том числе через ярлык (символическую ссылку), получает отказ. Пока приложение открыто, сервер не перезаписывает существующий файл.
