# Подключение ИИ-помощника (MCP)

Цель: позволить ИИ-помощнику читать и менять ваш график. Вы видите, что он делает, и сами задаете ему ограничения.

## Когда это нужно

Вам нужно, чтобы ИИ-помощник читал, анализировал или менял ваш график. Например, чтобы он набросал первую СДР, исправил задачи или объяснил критический путь. Это работает через **Model Context Protocol** (MCP): стандарт, который позволяет ИИ-помощнику использовать инструменты программы. Для этого Open Planner Studio запускает на вашем компьютере небольшой сервер, **мост**. Он предлагает набор инструментов. Все их имена начинаются с `planner_`: чтение и изменение задач, связей, ресурсов, календарей, базовых планов, документов и файлов. Какие инструменты есть и что они отклоняют, описано в [Инструменты ИИ](docs://ref-ai-tools). Почему связь работает именно так, описано в [Как работает связь с ИИ](docs://uitleg-ai-koppeling).

Мост работает только в настольном приложении. Если включить ИИ-режим в браузере, вы видите вкладку *ИИ*. Но кнопка *Запустить мост* серая, с текстом *Мост доступен только в настольном приложении.* Остальная часть статьи относится к настольному приложению. В браузере кнопки *Создать копию сейчас* и *Открыть папку копий* тоже серые.

## Шаги

### 1. Включите ИИ-режим

1. Выберите *Настройки › Проект › Настройки приложения*. Также можно выбрать *Файл › Настройки приложения* или шестеренку вверху.
2. Выберите вкладку *Дополнительно* и включите опцию *Включить ИИ-режим*. Вкладка *ИИ* появится на ленте.
3. Если вы хотите, чтобы мост был активен сразу после запуска приложения, включите также *Автоматически запускать мост*. Эту опцию можно включить только при включенном ИИ-режиме, и она работает только в настольном приложении. По умолчанию она выключена, потому что открытие порта — осознанный выбор.

Если вы выключите ИИ-режим, мост остановится, а вкладка *ИИ* исчезнет.

### 2. Запустите мост

1. Перейдите на вкладку *ИИ* и нажмите *Запустить мост* в группе *Сервер*.
2. Посмотрите статус рядом с кнопкой. Там написано *Выкл*, *Активен на порту 3877*, *Порт 3877 занят* или *Ошибка*. Если запуск прошел успешно, там написано *Активен на порту 3877*, а кнопка называется *Остановить мост*. При статусе *Порт 3877 занят* или *Ошибка* кнопка остается *Запустить мост*; см. возможные проблемы.

Мост принимает подключения только с вашего компьютера, на одном порту. По умолчанию это порт 3877. В группе *Подключение* можно выбрать другой порт в поле *Порт*, но только пока мост остановлен.

### 3. Подключите ИИ-помощника

1. Нажмите *Подключить* в группе *Подключение*. Откроется окно *Данные подключения*.
2. Выберите то, что нужно вашему клиенту. См. ниже.
3. Токен скрыт. Значком глаза вы его показываете. Кнопки копирования всегда копируют настоящее значение, даже если токен на экране скрыт.
4. Попросите ИИ-помощника запросить список инструментов. Эта проверка также есть в промпте подключения: помощник должен увидеть инструменты с префиксом `planner_`. Ожидаемое количество указано в промпте подключения.

В окне есть три способа подключения:

- *Фрагмент конфигурации*: фрагмент настройки, который вы вставляете в настройки MCP вашего клиента.
- *Промпт подключения*: текст, который вы вставляете в ИИ-помощника. После этого он подключается сам.
- *Конечная точка* и *Аутентификация*: отдельные данные. Конечная точка — `http://localhost:3877/mcp`, транспорт *потоковый HTTP*. Каждому запросу нужен заголовок `Authorization: Bearer`, после которого указывается ваш токен. Ваш клиент тоже должен поддерживать сеансы MCP: при подключении мост выдает код сеанса в заголовке `Mcp-Session-Id` и отклоняет каждый следующий запрос без этого кода. Claude Code и `mcp-remote` делают это сами.

**Подключитесь снова после обновления приложения.** Если ваш ИИ-клиент уже был подключен к старой версии приложения, он еще не отправляет код сеанса, и мост отклоняет каждый запрос. Поэтому подключитесь снова после обновления: начните новый сеанс в Claude Code, а Claude Desktop полностью закройте и запустите снова.

**Claude Code.** Фрагмент конфигурации подходит для Claude Code напрямую. Введите в терминале эту команду и вместо `<token>` укажите свой токен:

```
claude mcp add --transport http open-planner-studio http://localhost:3877/mcp --header "Authorization: Bearer <token>"
```

Вы также можете поместить фрагмент в файл `.mcp.json` в папке проекта. Тогда не добавляйте этот файл в git, потому что токен дает доступ к вашему графику. Сервер из `.mcp.json` нужно один раз подтвердить в Claude Code.

**Claude Desktop.** Фрагмент конфигурации не подходит для Claude Desktop напрямую. В файле `claude_desktop_config.json` указывается программа, которую Claude Desktop запускает сам, а не адрес. Поэтому используйте внешний инструмент `mcp-remote`; для него нужен Node.js. В Claude Desktop выберите *Настройки › Разработчик › Изменить конфигурацию*, вставьте в файл следующее (со своим токеном) и снова запустите Claude Desktop:

```
{
  "mcpServers": {
    "open-planner-studio": {
      "command": "npx",
      "args": ["-y", "mcp-remote", "http://localhost:3877/mcp", "--header", "Authorization:${AUTH_HEADER}"],
      "env": { "AUTH_HEADER": "Bearer <token>" }
    }
  }
}
```

Токен указан в `env`, а не в `args`, намеренно: в Windows Claude Desktop ломает аргумент, в котором есть пробел. *Пользовательский коннектор* в Claude (*Настроить › Коннекторы*) с мостом не работает. Тогда Claude подключается из облака Anthropic, и это облако не может достучаться до моста на вашем компьютере.

В группе *Подключение* есть еще поле *Токен*. Это длинный случайный код, который приложение создает для вас и хранит на этом компьютере. В окне написано: *Этот токен дает доступ к открытому графику. Не передавайте его другим.* Кнопкой *Создать новый токен* вы создаете новый токен. Приложение сначала спрашивает: *Создание нового токена разорвет все текущие подключения. Продолжить?* Если мост работает, он перезапускается с новым токеном, и старый токен перестает работать.

### 4. Посмотрите, что делает ИИ

1. Нажмите *Панель активности* в группе *Задача*. В боковой части окна откроется панель *Журнал ИИ*.
2. Каждый вызов моста — отдельная строка, новые строки сверху: время, что произошло, сколько времени это заняло и успешно ли это. Нажмите строку, чтобы развернуть *Аргументы* и *Ответ*.
3. Кнопкой *Очистить* вы очищаете список. Панель хранит последние 500 вызовов. Пока ничего не произошло, там написано: *Активности ИИ пока нет. Вызовы моста появятся здесь.*

Если ИИ-режим включен, в правом нижнем углу строки состояния есть точка с подписью *ИИ*. Ее цвет показывает статус моста. Щелчок по ней переводит вас на вкладку *ИИ*.

### 5. Задайте ограничения

В группе *Безопасность* находятся кнопки, с помощью которых вы ограничиваете ИИ:

- *Приостановить*: ИИ временно ничего не может менять, чтение по-прежнему разрешено. Мост остается активным. Кнопка становится *Возобновить*.
- *Только для чтения*: пока эта опция включена, все инструменты, которые что-то меняют, отклоняются.
- *Автокопия: вкл*: перед первым изменением документа ИИ приложение записывает резервную копию IFC. Эта опция включена по умолчанию. Кнопкой вы ее выключаете, и тогда там написано *Автокопия: выкл*. Это происходит один раз для каждого документа при каждом запуске моста.
- *Создать копию сейчас*: сразу создает копию активного документа. После этого появляется *Копия создана:* и имя файла.
- *Открыть папку копий*: открывает папку с копиями.

Копии лежат в папке `ai-backups` в папке данных приложения. Приложение хранит последние копии и удаляет часть более старых. Как именно это работает, описано в [Инструменты ИИ](docs://ref-ai-tools).

### 6. Пусть ИИ-помощник хорошо планирует

ИИ-помощник хорошо планирует, только если знает правила планирования. Почему это важно и что в них входит, описано в [Как работает подключение к ИИ](docs://uitleg-ai-koppeling). Вот что вы делаете сами:

1. **Для основных правил ничего делать не нужно.** Они передаются при подключении. Помещает ли их ваш клиент в системный промпт, зависит от самого клиента.
2. **Пусть помощник прочитает руководство.** Промпт подключения из окна *Данные подключения* просит помощника прочитать руководство по планированию с помощью инструмента `planner_get_planning_guide`. Если вы не используете промпт, спросите помощника сами: *Перед любыми изменениями сначала прочитайте руководство по планированию с помощью planner_get_planning_guide.* Вы можете прочитать руководство сами по адресу `https://open-planner-studio.open-aec.com/agent/planning-guide.md`.
3. **По желанию: установите навыки.** Это работает только с помощником, который поддерживает навыки. Положите `SKILL.md` навыков *goed-plannen* и *progress-update* в `.claude/skills/goed-plannen/SKILL.md` и `.claude/skills/progress-update/SKILL.md` в папку проекта, в которой работает помощник, или в `~/.claude/skills/`, чтобы навыки действовали для каждого проекта.

Файлы можно получить двумя способами. Попросите помощника вызвать инструмент `planner_get_planning_guide` с параметром `part`, равным `skill`: ответ содержит оба текста и для каждого навыка место, где он должен лежать. Или скачайте их по адресам `https://open-planner-studio.open-aec.com/skills/goed-plannen/SKILL.md` и `https://open-planner-studio.open-aec.com/skills/progress-update/SKILL.md`. Если навык *goed-plannen* остался от старой версии приложения, замените его: старый текст на нидерландском языке и ссылается на статью справки, а не на руководство для помощников.

Чтобы проверить, действительно ли помощник прочитал руководство, посмотрите в окне *Панель активности*: тогда там есть вызов `planner_get_planning_guide`. Итоговый ответ помощника должен содержать список допущений: оценки длительности, выбранную декомпозицию, связи, которые он создал сам, и каждое ограничение, которое он задал. Если этого списка нет, попросите его. После обновления хода выполнения по *progress-update* ответ должен называть дату отчета о состоянии, новую дату окончания и отклонение от базового плана.

## Возможные проблемы и что делает приложение

**ИИ меняет то, что вы хотите отменить.** Каждое изменение ИИ — это шаг, который вы отменяете кнопкой *Отменить* (Ctrl+Z). Серия изменений, которую ИИ передает как одно целое, — это один шаг. После этого проект помечается как несохраненный. После изменения приложение заново рассчитывает график, поэтому F5 нажимать не нужно.

**Приложение отклоняет вызов ИИ.** Если включена опция *Приостановить* или опция *Только для чтения*, приложение отклоняет все изменения. Чтение остается возможным, включая пересчет устаревшего графика. Если вы сами что-то правите, например перетаскиваете полосу или вводите текст в поле, ИИ получает даты, которые были до вашей правки, и уведомление, что они устарели. Если открыто окно, например настройки, окно задачи или стартовое окно, либо включен режим презентации, приложение отклоняет все вызовы, включая чтение, пока вы не закроете окно. ИИ тогда получает сообщение об ошибке с внутренним названием того, что открыто, например `showTaskDialog`. Работает только `planner_get_planning_guide`, потому что он не читает ваш график.

**Вы переключаете вкладки, пока ИИ работает.** ИИ работает с документом, в котором сделано его первое изменение. Если вы в это время переключите вкладки, приложение отклоняет его следующее изменение, пока ИИ не подтвердит, что хочет работать с другой вкладкой. Так ничего не попадает в другой проект.

**ИИ записывает или открывает файл.** ИИ может записать график в файл IFC и открыть файл с графиком как новую вкладку. Он может делать это только в вашей папке пользователя. Существующий файл он перезаписывает, только если явно просит об этом.

**Статус *Порт 3877 занят*.** Порт использует другая программа. Сообщение приложения показано под ним. Поле порта тогда остается заблокированным (*Можно изменить, только пока сервер остановлен.*), хотя мост не работает, и кнопки остановки нет. Это известный недостаток. Пока его не исправили: выключите *Включить ИИ-режим* и включите снова. Статус тогда снова *Выкл*, и вы можете выбрать другой порт. Потом скопируйте данные подключения заново, потому что конечная точка содержит порт.

**Клиент не может подключиться после нового токена.** Новый токен разрывает все текущие подключения. Передайте клиенту новый токен или вставьте фрагмент конфигурации заново.

**Вы остановили мост сами, и он не запускается сам.** *Автоматически запускать мост* работает один раз при каждом запуске приложения. Если вы остановили мост сами, приложение не включает его тихо снова.

**Вкладка *ИИ* пропала.** ИИ-режим выключен. Включите его в шаге 1.

**Веб-страница в браузере не может обратиться к мосту.** Мост отклоняет каждый запрос из браузера и каждый запрос без правильного токена.
