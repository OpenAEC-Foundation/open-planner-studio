# Открытие файла MS Project (.mpp)

Цель: открыть график из Microsoft Project прямо в приложении, без предварительного экспорта.

## Когда это нужно

Подрядчик, консультант или заказчик присылает вам свой график в виде файла `.mpp`. Вы хотите его просмотреть, рассчитать или доработать. Приложение читает файлы `.mpp` из MS Project 2010 вплоть до версии 2021 включительно. Оно только читает: файл `.mpp` оно не записывает и ваш файл никогда не меняет. Из файла оно берет сам график: задачи со структурой, длительностью и ограничениями, связи с задержкой, календари, ресурсы, назначения и ход выполнения. Оно также читает даты и резерв времени, которые MS Project рассчитал сам, но использует их только для вида *Даты как записаны*, никогда как исходные данные.

## Шаги

1. Выберите *Главная › Файл › Открыть* или нажмите Ctrl+O. Выберите файл `.mpp`.
2. Проект открывается в новой вкладке или в текущей, если она была еще пустой и без изменений. У проекта нет файла: команда *Сохранить* позже создает новый файл IFC. Затем ненадолго появляется окно, в котором объясняется, что приложение взяло из файла и как работает сохранение; см. [Открытие и сохранение файла](docs://howto-bestand-openen-en-opslaan).
3. Прочитайте сообщение внизу: *Этот проект рассчитывается как Microsoft Project. Изменить можно в разделе «Файл → Информация о проекте → Профиль расчета и параметры расчета».* Приложение рассчитывает этот проект по правилам расчета MS Project: профиль расчета *Microsoft Project*. Кнопка *Открыть профиль расчета* переводит вас к настройке, а *Подробнее* открывает справку о профилях расчета.
4. Проверьте, есть ли под лентой сообщение: *Вы видите даты так, как они записаны в файле; при пересчете сместятся 4 задачи.* Тогда для этих задач результат приложения отличается от дат, которые сохранил MS Project. Под сообщением из шага 3 есть также строка: *4 задачи показывают даты так, как они записаны в файле (без пересчёта).* Что это значит и как перейти на собственный расчет приложения, описано в статье [Даты как записаны](docs://uitleg-datums-zoals-opgeslagen).
5. Если появляется сообщение *Этот файл содержит почасовое планирование.* с кнопкой *Включить почасовое планирование*, файл содержит данные в часах. См. [Включение почасового планирования](docs://howto-urenplanning-aanzetten).

Если в файле есть задачи с разделением, выравниванием или графиком, управляемым ресурсами, появляется еще одно сообщение, например: *Этот файл MS Project содержит 3 задачи с разделённым, выровненным или управляемым ресурсами графиком. Они импортируются и показываются так же.* Для одной задачи сообщение выводится в единственном числе.

## Возможные проблемы и что делает приложение

**Не все переносится.** После открытия приложение в одном сообщении сообщает, что оно не перенесло: *Из этого файла MS Project импортировано не все.* Под ним есть по одной строке на каждый пункт с количеством, например *2 базовых плана не импортированы.* Для файла `.mpp` предложение о профиле расчета из шага 3 тогда становится первой строкой этого сообщения. Сообщение остается, пока вы не нажмете крестик. Если ничего не потеряно, это сообщение не появляется. Строка может касаться:

- вставленные проекты (подпроекты): приложение читает их как обычную задачу, без связи с другим файлом;
- внешние задачи из другого проекта: приложение читает их как обычную задачу;
- базовые планы: из файла `.mpp` приложение не переносит ни одного базового плана, из XML MS Project только базовый план 0 задач, и из него только даты и длительность (для задачи в часах также время; не трудозатраты и затраты, и не базовые планы ресурсов и назначений);
- в XML MS Project: назначение, чей базовый план имеет другие даты, чем его задача. Приложение сохраняет только базовый план задачи; если даты совпадают, ничего не теряется и приложение ничего не сообщает. Другое время в тот же день тоже считается отличием;
- настраиваемые поля со значениями, например настраиваемые поля, значения из таблицы подстановки и коды структуры (приложение не учитывает поля «да/нет» в файле `.mpp`);
- заметки (также заметка, в которой только рисунок) к ресурсам и назначениям, а из файла `.mpp` также к задачам (из XML MS Project заметка задачи переносится как ее описание);
- гиперссылки;
- фиксированные затраты задач;
- ставки ресурсов: из файла `.mpp` ставки не переносятся вообще, из XML MS Project только стандартная ставка;
- только в XML MS Project: задачи, планируемые вручную (приложение планирует их автоматически), неактивные задачи (они входят в расчет) и выравнивающая задержка;
- только для `.mpp`: критическое пороговое значение из MS Project; приложение использует пороговое значение 0.

Код СДР, который вы сами заполнили в MS Project, переносится; в остальных случаях приложение нумерует задачи по структуре.

**Файл из MS Project 2007 или более старой версии.** Приложение его не открывает и выводит сообщение: *Этот файл .mpp имеет старый формат (Project 2007 или более ранний). Экспортируйте его из MS Project в XML (Файл → Сохранить как → XML) и откройте этот файл.* Под сообщением приложение добавляет техническую причину на английском языке.

**Файл с паролем.** Приложение выводит сообщение: *Этот файл .mpp защищён паролем. Экспортируйте его из MS Project в XML (Файл → Сохранить как → XML) и откройте этот файл.* Здесь сообщение тоже сопровождается технической причиной на английском языке.

**Файл, который оказался не `.mpp`.** Вы получаете сообщение *Не удалось открыть файл* с технической причиной.

**Путь через XML рассчитывает иначе.** Если вы откроете экспорт MS Project в XML вместо файла `.mpp`, приложение рассчитает проект с профилем расчета *Open Planner Studio*, и сообщения о *Microsoft Project* вы не увидите. Даты тогда могут получиться другими, чем при открытии файла `.mpp`. В экспорте XML приложение тоже сообщает, что не переносит; см. *Не все переносится*.

**Изменение снимает управление MS Project.** Если вы измените задачу, планирование которой управлялось окном дат MS Project, приложение выводит сообщение один раз на проект: *2 задачи перестают управляться окном дат из MS Project после этого изменения; распределение трудозатрат по часам остаётся в силе и сохраняется в файле.* Для одной задачи сообщение выводится в единственном числе.

**Сохранение никогда не перезаписывает ваш файл `.mpp`.** У проекта нет файла. Команда *Сохранить* спрашивает, куда записать новый файл IFC.
