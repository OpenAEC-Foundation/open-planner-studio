# Открытие файла MS Project (.mpp)

Цель: открыть график из Microsoft Project прямо в приложении, без предварительного экспорта.

## Когда это нужно

Подрядчик, консультант или заказчик присылает вам свой график в виде файла `.mpp`. Вы хотите его просмотреть, рассчитать или доработать. Приложение читает файлы `.mpp` из MS Project 2010 вплоть до версии 2021 включительно. Оно только читает: файл `.mpp` оно не записывает и ваш файл никогда не меняет. Из файла оно берет сам график: задачи со структурой, длительностью и ограничениями, связи с задержкой, календари, ресурсы, назначения и ход выполнения. Оно также читает даты и резерв времени, которые MS Project рассчитал сам, но использует их только для вида *Даты как записаны*, никогда как исходные данные.

## Шаги

1. Выберите *Главная › Файл › Открыть* или нажмите Ctrl+O. Выберите файл `.mpp`.
2. Проект открывается в новой вкладке или в текущей, если она была еще пустой и без изменений. У проекта нет файла. Команда *Сохранить* позже создает новый файл IFC.
3. Прочитайте сообщение внизу: *Этот проект рассчитывается как Microsoft Project. Изменить можно в разделе «Файл → Информация о проекте → Профиль расчета и параметры расчета».* Приложение рассчитывает этот проект по правилам расчета MS Project: профиль расчета *Microsoft Project*. Кнопка *Открыть профиль расчета* переводит вас к настройке, а *Подробнее* открывает справку о профилях расчета.
4. Проверьте, есть ли под лентой сообщение: *Вы видите даты так, как они записаны в файле; при пересчете сместятся 4 задачи.* Тогда для этих задач результат приложения отличается от дат, которые сохранил MS Project. Под сообщением из шага 3 есть также строка: *4 задачи показывают даты так, как они записаны в файле (без пересчёта).* Что это значит и как перейти на собственный расчет приложения, описано в статье [Даты как записаны](docs://uitleg-datums-zoals-opgeslagen).
5. Если появляется сообщение *Этот файл содержит почасовое планирование.* с кнопкой *Включить почасовое планирование*, файл содержит данные в часах. См. [Включение почасового планирования](docs://howto-urenplanning-aanzetten).

Если в файле есть задачи с разделением, выравниванием или графиком, управляемым ресурсами, добавляется еще одно сообщение, например: *Этот файл MS Project содержит 3 задачи с разделённым, выровненным или управляемым ресурсами графиком. Они импортируются и показываются так же.* Для одной задачи сообщение выводится в единственном числе.

## Возможные проблемы и что делает приложение

**Не все переносится.** Приложение не переносит базовые планы, затраты и ставки, заметки и настраиваемые поля MS Project. Код СДР, который вы сами заполнили в MS Project, сохраняется; в остальных случаях приложение нумерует задачи по структуре.

**Файл из MS Project 2007 или более старой версии.** Приложение отказывается его открывать и выводит сообщение: *Этот файл .mpp имеет старый формат (Project 2007 или более ранний). Экспортируйте его из MS Project в XML (Файл → Сохранить как → XML) и откройте этот файл.* Под сообщением приложение добавляет техническую причину на английском языке.

**Файл с паролем.** Приложение выводит сообщение: *Этот файл .mpp защищён паролем. Экспортируйте его из MS Project в XML (Файл → Сохранить как → XML) и откройте этот файл.* Здесь сообщение тоже сопровождается технической причиной на английском языке.

**Файл, который оказался не `.mpp`.** Вы получите сообщение *Не удалось открыть файл* с технической причиной.

**Путь через XML рассчитывает иначе.** Если вы откроете экспорт MS Project в XML вместо файла `.mpp`, приложение рассчитает проект с профилем расчета *Open Planner Studio*, и сообщения о *Microsoft Project* вы не увидите. Тогда даты могут получиться другими, чем при открытии файла `.mpp`.

**Изменение прекращает управление со стороны MS Project.** Если вы измените задачу, планирование которой управлялось окном дат MS Project, приложение выводит сообщение один раз на проект: *2 задачи перестают управляться окном дат из MS Project после этого изменения; распределение трудозатрат по часам остаётся в силе и сохраняется в файле.* Для одной задачи сообщение выводится в единственном числе.

**Сохранение никогда не перезаписывает ваш файл `.mpp`.** У проекта нет файла. Команда *Сохранить* спрашивает, куда записать новый файл IFC.
