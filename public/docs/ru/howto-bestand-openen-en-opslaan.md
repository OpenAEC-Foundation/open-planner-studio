# Открытие и сохранение файла

Цель: открыть проект из файла и сохранить внесенные изменения.

## Когда это нужно

Вы начинаете день с вчерашнего проекта, вы получаете файл от коллеги или из другой программы, или вы хотите сохранить промежуточное состояние проекта, прежде чем изменить что-то крупное. Что приложение хранит в файле и почему весь проект сохраняется только в IFC, описано в разделе [Файлы и форматы](docs://uitleg-bestanden).

## Шаги

### Открытие файла

1. Выберите *Главная › Файл › Открыть*, или *Файл › Открыть*, или нажмите Ctrl+O (⌘+O на Mac). *Открыть* также есть на верхней панели. Группа *Файл* есть также на вкладке *Таблица*.
2. Выберите файл. Вы открываете один файл за раз. В настольном приложении и в браузерах с доступом к файлам, например Chrome и Edge, окно показывает список типов файлов: *Все поддерживаемые*, *Файлы IFC*, *Файлы CSV*, *Файлы XML*, *Файлы MS Project* и *Файлы Primavera XER*.
3. Проект открывается на новой вкладке. Если текущая вкладка еще пустая и без изменений, проект открывается в ней.

Вкладка получает имя файла IFC. Проект из другого формата получает имя проекта.

Приложение открывает `.ifc`, `.csv`, `.xml` (MS Project XML или Primavera P6 XML), `.mpp` и `.xer`. Для последних двух форматов есть отдельные шаги: [Открытие файла MS Project (.mpp)](docs://howto-mpp-openen) и [Открытие файла Primavera P6 (.xer)](docs://howto-xer-openen).

### Открытие недавнего проекта

Выберите *Главная › Файл › Недавние* и щелкните файл в списке, или выберите *Файл › Недавние*. Список хранит последние десять файлов, которые вы открывали, сохраняли или экспортировали. Настольное приложение показывает путь к каждому файлу, браузер только имя.

Если приложение больше не может прочитать файл из списка, например потому что вы его переместили, он исчезает из списка без сообщения. В браузерах без доступа к файлам, например Firefox, *Недавние* остается пустым.

### Открытие примера

Выберите *Файл › Примеры* и щелкните пример проекта. Он открывается на вкладке без файла, поэтому *Сохранить* спрашивает, где вы хотите сохранить проект.

### Сохранение

Выберите *Главная › Файл › Сохранить* или *Файл › Сохранить*, или нажмите Ctrl+S. Что происходит дальше, зависит от вашего проекта:

1. Если у проекта уже есть файл, потому что вы открыли файл IFC или сохраняли его раньше, приложение записывает в этот файл. Окно не появляется.
2. Если у проекта еще нет файла, приложение спрашивает, куда его сохранить. Оно предлагает имя проекта с `.ifc`. После этого этот файл и есть файл проекта.
3. Если ваш браузер сохраняет только через загрузку (например Firefox), файл попадает в папку загрузок, и каждое сохранение создает новую загрузку. В первый раз за сеанс вы видите сообщение *Сохранено как загрузка: «name.ifc» находится в папке загрузок. Этот браузер не позволяет приложению писать в собственное место, поэтому каждое сохранение создает новую загрузку. В Chrome, Edge или настольном приложении команда Сохранить просто обновляет тот же файл.*
4. Если ваш браузер не может записать изменения обратно в файл проекта, приложение каждый раз при сохранении снова спрашивает, куда поместить файл. Это похоже на *Сохранить как*, но это ограничение браузера. В первый раз за сеанс сообщение *Этот браузер не позволяет приложению записывать обратно в «name.ifc».* объясняет это, со ссылкой на [Файлы](docs://uitleg-bestanden).

После сохранения маркер *Не сохранено* исчезает: точка на вкладке, звездочка перед именем проекта вверху и текст *Не сохранено* справа внизу строки состояния.

### Сохранение под другим именем

Выберите *Главная › Файл › Сохранить как* или *Файл › Сохранить как*, или нажмите Ctrl+Shift+S. Выберите имя и место (в Firefox приложение вместо этого загружает новый файл). После этого проект работает с этим новым файлом: следующее *Сохранить* записывает в него. Старый файл остается таким, каким был при последнем сохранении.

### Закрытие проекта

Щелкните крестик на вкладке или выберите *Файл › Закрыть проект*. Если в проекте есть несохраненные изменения, приложение спрашивает: *Несохраненные изменения: в «name» есть изменения, которые еще не сохранены.* Вы выбираете *Отменить* (проект остается открытым), *Не сохранять* (проект закрывается, и ваши изменения пропадают) или *Сохранить* (сначала сохранить, затем закрыть). Если вы закрываете все приложение на компьютере (кнопкой закрытия, Alt+F4 или меню операционной системы), приложение задает этот вопрос для каждого проекта с изменениями. *Отменить* или сохранение, которое не удалось, останавливает закрытие. После такого обычного закрытия приложение удаляет копии для восстановления этого сеанса, поэтому окно восстановления появляется только после настоящего сбоя. Если в проекте есть изменения и вы закрываете вкладку или окно браузера, браузер запрашивает подтверждение.

## Подводные камни и что тогда делает приложение

**Открытый файл IFC сразу становится файлом вашего проекта.** *Сохранить* перезаписывает этот файл, даже если он создан в другой программе. Если вы хотите сохранить оригинал, сначала выберите *Сохранить как*.

**Другие форматы никогда не перезаписываются.** У проекта, открытого из `.csv`, `.xml`, `.mpp` или `.xer`, нет файла. *Сохранить* записывает новый файл IFC и не трогает оригинал.

**В Firefox каждое сохранение создает новый файл.** Приложение не может записывать в ваш файл там. Оно каждый раз загружает новый файл с именем проекта, а не с именем открытого вами файла.

**Chrome и Edge запрашивают разрешение.** При первом нажатии *Сохранить* для открытого файла браузер спрашивает, может ли приложение в него записывать. Если вы откажете, приложение откроет окно, в котором вы выберете новый файл. В Chrome и Edge это окно появляется также, если запись в существующий файл не удалась, например потому что файл исчез или заблокирован.

**Сохранение может не удаться.** Если при самом сохранении появляется ошибка, приложение показывает *Не удалось сохранить* с указанием причины. Ваш проект остается открытым и по-прежнему помечен как *Не сохранено*.
