# Назначение ресурсов с контуром

Цель: назначить ресурс на задачу с единицами назначения в день и контуром. Контур определяет, как эти единицы распределяются по дням задачи.

## Когда это нужно

Как только вы хотите видеть, кто где и когда работает: каменщик на наружном слое двойной стены, кран на пустотных плитах перекрытия. Без назначения нет нагрузки, и поэтому нет гистограммы и превышения доступности.

Два термина. **Единицы назначения** (в приложении *Ед./день*) — это доля ресурса, которая работает над задачей в рабочий день: 1 — один каменщик, 2 — два, 0,5 — половина дня. **Контур** определяет, как общий объем, единицы назначения, умноженные на длительность, распределяется по рабочим дням задачи. Трудозатраты редко распределены равномерно: начало стены спокойное, середина напряженная, конец снова спокойный.

Наружный слой двойной стены занимает 6 рабочих дней. При одном каменщике и контуре *Равномерно* это 1 единица на каждый из 6 дней, всего 6. При контуре *Колоколообразная* общее значение по-прежнему 6 единиц, но распределение трудозатрат становится 0, 1, 2, 2, 1 и 0.

## Шаги

Назначить ресурс можно двумя способами. Ресурс должен уже существовать (см. [Управление ресурсами](docs://howto-resources-beheren)).

### Через ленту

1. Выберите одну задачу в таблице задач. Это должна быть обычная задача, не веха и не фаза.
2. Выберите *Ресурсы › Назначение › Назначить ▾*.
3. В окне заполните *Ед./день* (по умолчанию 1) и выберите *Контур* (по умолчанию *Равномерно*). Они применяются к ресурсу, который вы выбираете сейчас.
4. Щелкните ресурс. Окно закроется, и назначение появится.

Для второго ресурса откройте окно снова. Ресурсы, которые уже назначены на задачу, в списке отсутствуют.

### Через панель свойств

1. Выберите задачу. Панель *Свойства* находится справа. Если вы ее не видите, включите ее через *Вид › Панели › Свойства*.
2. В блоке *Назначения*, в самом низу, выберите ресурс в поле *Назначить ресурс*. Назначение начинается с единиц назначения, равных 1, и контура *Равномерно*.
3. Для каждого назначения измените *Ед./день* и выберите другой *Контур*.

Так же вы меняете существующее назначение. С помощью значка корзины (*Удалить*) рядом с именем вы снимаете назначение с задачи. Сам ресурс остается. С помощью *Переместить в…* вы переносите назначение на другую задачу.

### Контуры

- *Равномерно*: одинаково каждый день. Это значение по умолчанию; подходит для работы, которая каждый день одинаково тяжелая.
- *Нагрузка в начале*: начало тяжелее конца. Подходит для работы, которая начинается с интенсивных усилий, например с разметки.
- *Нагрузка в конце*: конец тяжелее начала. Подходит для работы, которая к завершению становится интенсивнее.
- *Колоколообразная*: пик в середине, спокойные начало и конец. Подходит для стены, которая начинается спокойно, в середине идет полным ходом и затем затихает.
- *Ранний пик*: пик до середины. Подходит для работы, которая быстро набирает темп.
- *Поздний пик*: пик после середины. Подходит для работы, у которой напряженный период наступает только поздно.
- *Двойной пик*: два пика. Подходит для работы с двумя напряженными моментами.
- *Черепаха*: спокойные начало и конец и широкий пик в середине. Подходит для длинной работы, которая постепенно набирает обороты и постепенно затихает.

Контур меняет только распределение трудозатрат. Длительность, даты и итог остаются прежними. Пересчитывать после этого не нужно. Гистограмма сразу меняется. Выберите *Ресурсы › Гистограмма › Гистограмма*, чтобы ее увидеть. Если вы выбрали задачу, гистограмма показывает только нагрузку этой задачи.

## Возможные проблемы и что делает приложение

**Контур может поднять пик выше ваших единиц.** При целом числе единиц приложение округляет значение за день до целых единиц, а итог остается прежним. Каменщик с 1 единицей на наружном слое двойной стены и контуром *Колоколообразная* дает 0, 1, 2, 2, 1, 0. В двух средних днях это 2 единицы при значении *Макс. доступность* 1. Гистограмма окрашивает эти дни красным, и у ресурса возникает превышение доступности. Выберите другой контур или распределите часы сами (см. [Изменение распределения часов](docs://howto-urenverdeling-aanpassen)). При таких единицах, как 0,5, приложение округляет до сотых. На короткой задаче с целыми единицами форма поэтому становится грубой: за 10 дней *Черепаха* с 1 единицей дает распределение трудозатрат 0, 1, 1, 2, 2, 1, 1, 1, 1, 0, точно такое же, как *Ранний пик*.

**Не веха и не фаза.** Кнопка *Назначить* тогда неактивна, а в панели *Свойства* написано *Назначения на вехах невозможны.* или *Назначения на суммарных задачах невозможны.*

**Ресурс назначается на задачу только один раз.** Если ресурс уже назначен на задачу, его нет в списке. Если все ресурсы уже назначены на задачу, приложение пишет *Все ресурсы уже назначены.* Если ресурсов еще нет, оно пишет *Сначала создайте ресурсы (вкладка «Ресурсы»).*

**Единицы назначения должны быть больше 0.** Приложение не принимает значение 0 или меньше.

**Материал.** Для материального ресурса единицы назначения — это количество в день в единице измерения ресурса, например м³. Материал не учитывается в длительности задачи.

**Правило работы может изменить длительность.** Если задача имеет тип *Фиксированные трудозатраты* или *Фиксированные единицы*, второй ресурс меняет длительность задачи. График тогда уже не актуален: нажмите **Рассчитать** (F5). См. [Правила работы: длительность, единицы назначения и трудозатраты](docs://uitleg-werkregels).

**Собственное распределение.** Если у назначения уже есть собственное распределение часов, контур отключен и показывает *Контур*. Сначала снимите это распределение через *Задать распределение часов…*.

**Отмена.** Создание, изменение и удаление назначения можно отменить командой *Отменить* (Ctrl+Z).
