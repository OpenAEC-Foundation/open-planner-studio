# Импорт хода выполнения из таблицы

Цель: за один раз внести в график ход выполнения, который сотрудники площадки записывают в таблицу, без ручного изменения каждой задачи.

## Когда это нужно

У субподрядчика или руководителя работ на площадке нет приложения, но он каждую неделю сообщает свое состояние: сколько процентов сделано, когда начали и когда закончили. Вы отправляете ему таблицу со своими задачами. Он заполняет три столбца и отправляет ее обратно. Из нее приложение читает только три значения для каждой задачи: процент завершения, фактическое начало и фактическое окончание. Остальная часть графика не меняется. Что приложение делает с этим ходом выполнения, описано в статье [Ход выполнения, дата отчета о состоянии и базовый план](docs://uitleg-voortgang).

## Шаги

### 1. Задайте дату отчета о состоянии и рассчитайте график

Задайте дату отчета о состоянии, как описано в статье [Обновление хода выполнения](docs://howto-voortgang-bijwerken). Руководитель работ на площадке вносит фактические даты до этого дня включительно. Если график устарел, приложение пересчитывает его до создания таблицы.

### 2. Создайте таблицу

Выберите *График › Ход выполнения › Экспортировать таблицу хода выполнения*. Та же кнопка есть на вкладках *Таблица* и *Отчет*. Приложение создает файл Excel и предлагает имя *(название проекта)-ход-выполнения.xlsx*. В браузере файл попадает в папку загрузок. Предпочитаете CSV? Выберите *Файл › Экспорт › Лист хода выполнения (CSV)*. Таблица Excel тоже есть, как *Лист хода выполнения (Excel)*.

В таблице восемь столбцов. Имена столбцов остаются на английском языке, с короткой инструкцией на языке приложения после них:

- `OPS Task ID`, `WBS` и `Name` нужны только для распознавания задачи. Не меняйте их.
- `Start` и `Finish` — плановые даты, для справки. Приложение никогда не записывает их обратно.
- `Completion (%)`, `Actual Start` и `Actual Finish` — это столбцы, которые вы заполняете.

Таблица Excel защищена без пароля: изменять можно только три столбца для заполнения. Excel проверяет, что процент находится между 0 и 100, а фактическая дата является датой. Фаза (суммарная задача) отмечена серым цветом с надписью *— суммарная задача: не заполнять*.

### 3. Попросите заполнить таблицу

Для каждой задачи руководитель работ на площадке заполняет:

- `Completion (%)`: от 0 до 100 включительно. В таблице Excel допускаются десятичные числа (например, 33,3); в CSV инструкция просит целые числа.
- `Actual Start` и `Actual Finish`: в Excel как дата в ваших региональных настройках; в CSV в формате dd-mm-yyyy.

Пустые ячейки ничего не меняют. Поэтому пустая ячейка также не удаляет уже внесенный ход выполнения; это можно сделать только в приложении. Задачу, которая еще не началась, он оставляет полностью пустой.

### 4. Загрузите заполненную таблицу

1. Выберите *График › Ход выполнения › Обновить ход выполнения из таблицы* (также на вкладках *Таблица* и *Отчет*) или *Файл › Импорт › Обновить ход выполнения из таблицы*. Открывается окно *Обновить ход выполнения из таблицы*.
2. Нажмите *Выбрать файл…* и выберите заполненный файл `.xlsx` или `.csv`.
3. Если даты в CSV неоднозначны, приложение спрашивает *День или месяц первым?* и показывает дату из вашего файла, прочитанную двумя способами. Нажмите правильную дату.
4. Теперь вы видите предварительный просмотр. Сверху четыре счетчика: *Применено*, *Без изменений*, *Ожидает связывания* и *Отклонено*. Ниже для каждой задачи показано, что меняется, например *Процент завершения: 0% → 100%*.
5. Проверьте предварительный просмотр и нажмите *Применить*. Окно показывает *Результат* со счетчиками и строками, которые были отклонены, с причинами. Завершите, нажав *Закрыть*.

Пропустить предварительный просмотр нельзя. Кнопка *Применить* неактивна, пока нечего применять.

### 5. Пересчитайте график

Загрузка таблицы сама по себе не пересчитывает график. Нажмите **Рассчитать** (F5), например через *График › График › Рассчитать*, если *Автоматический расчет* не включен.

## Строки, которые не всегда подходят сразу

Приложение связывает каждую строку с задачей: сначала по `OPS Task ID`, а если его нет, то по номеру СДР.

**Связывание под вопросом.** Если приложение нашло задачу только по номеру СДР, строка стоит в списке *Связывание под вопросом* с кнопками *Подтвердить* и *Изменить*. Строка тоже применяется, если ничего не делать. Поэтому проверьте, что задача правильная. *Подтвердить* убирает строку из этого списка; это ничего не меняет в том, что применяется. *Изменить* позволяет выбрать другую задачу. С помощью *Удалить связывание* вы удаляете связывание, которое создали сами. Примечание: таблица из другого проекта с теми же номерами СДР все равно связывается, стоит в списке *Связывание под вопросом* и применяется, когда вы нажимаете *Применить*.

**Ожидает связывания.** Если приложение не нашло ни одной задачи или нашло несколько с одним номером СДР, строка стоит в списке *Ожидает связывания*. Нажмите *Выберите задачу…* и выберите нужную задачу; ищите по номеру СДР или по имени. Если не связать строку, она отклоняется.

## Подводные камни и что делает приложение

Строка, которая не подходит, отклоняется с причиной. Остальная часть таблицы продолжает обрабатываться. Вот основные сообщения:

- *Фактическая дата позже даты отчета о состоянии.* Задайте дату отчета о состоянии позже или исправьте таблицу.
- *По графику эта задача начинается только после даты отчета о состоянии: сначала укажите ее фактическое начало в таблице.* Приложение не придумывает начало; укажите его в таблице.
- *Процент вне диапазона 0–100. Проверьте десятичный разделитель: 8,38 в таблице с другими региональными настройками может быть прочитано как 838.*
- *Суммарные задачи не могут получать ход выполнения из таблицы.* Ход выполнения фазы определяется задачами, которые входят в нее.
- *Фактическое окончание раньше фактического начала.*
- *Нечитаемая дата.* и *Нечитаемый процент.*
- *Введенные значения противоречат друг другу.* Например, фактическое окончание указано, а процент ниже 100.
- *Для этой строки задача не найдена.* В таблице указаны идентификатор задачи и номер СДР, которых нет в этом проекте.
- *Этот код СДР есть у нескольких задач — свяжите строку вручную.*
- *Эту задачу уже занимает другая строка.* Две строки указывают на одну и ту же задачу.
- *Отклонено планировщиком.* Отказ со стороны самого планирования, без собственного сообщения.

Если отклоняется весь файл, в окне появляется одно из этих сообщений: *В этом файле нет столбца «OPS Task ID» или «WBS», по которым строки связываются с задачами.*, *В этом файле нет ни одного из столбцов: Процент завершения, Фактическое начало или Фактическое окончание.*, *Этот файл слишком большой, чтобы читать его как таблицу хода выполнения.* (более 16 МБ), *В этом файле слишком много строк, чтобы читать его как таблицу хода выполнения.* (более 50 000 строк) или *Этот файл защищен паролем и не может быть прочитан.* или *Не удалось прочитать этот файл как таблицу хода выполнения.*

**Нет даты отчета о состоянии.** Если дата отчета о состоянии еще не задана, а импорт применяет ход выполнения, приложение ставит сегодняшнюю дату и сообщает вам об этом. Поэтому задайте ее сами заранее.

**Все можно отменить сразу.** Вся таблица считается одним шагом для Ctrl+Z.

**Только то, что вы заполняете.** Строка без отличий от графика считается как *Без изменений*. Задача без строки в таблице остается такой, как была.
