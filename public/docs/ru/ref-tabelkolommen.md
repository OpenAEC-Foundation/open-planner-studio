# Столбцы таблицы

Таблица задач содержит 86 фиксированных столбцов, а также по одному столбцу на каждый код задачи и настраиваемое поле проекта и по восемь столбцов на каждый базовый план. В этой статье для каждого столбца указано, что он показывает, можно ли его редактировать и в каком виде записывается значение. Как выбирать и располагать столбцы, описано в статье [Настройка столбцов таблицы](docs://howto-tabelkolommen-aanpassen).

## Где выбирать столбцы

Таблица задач рядом с диаграммой Ганта и таблица на вкладке *Таблица* имеют каждая свой выбор столбцов. Плюс справа в заголовке открывает окно *Выбрать столбец*. На вкладке *Таблица* можно также использовать *Таблица › Столбцы › Настроить столбцы…*. Окно перечисляет столбцы по категориям: *Задача*, *График*, *Ограничения*, *Связи*, *Ресурсы*, *Ход выполнения*, *Вычисляемые*, *Базовый план*, *Настраиваемые* и *Технические*. Столбец можно найти по названию. Сверху стоит *Недавно использованные*. Кнопка *Вернуть по умолчанию* восстанавливает столбцы по умолчанию.

По умолчанию таблица рядом с диаграммой Ганта показывает *СДР*, *Название задачи* и *Длительность*. Таблица на вкладке *Таблица* показывает *СДР*, *Название задачи*, *Длительность*, *Начало*, *Окончание*, *Тип задачи*, *Критическая*, *Общий резерв времени* и *Ход выполнения*, а также по одному столбцу на каждый код задачи и настраиваемое поле проекта.

## Как читаются и редактируются значения

- **Вычисляемые столбцы** — столбцы категории *Вычисляемые* и ряд других доступны только для чтения: их значения берутся из расчета. Если вы попытаетесь изменить ячейку только для чтения, приложение покажет сообщение *Этот вычисляемый столбец нельзя редактировать.* Этот текст общий для каждой ячейки только для чтения, также когда столбец не вычисляемый. Если значения устарели после вашего изменения, рядом с ними появляется *устарело*, пока вы не нажмете *Рассчитать*.
- **Даты** — отображаются в формате, который вы выбрали в окне *Настройки*, вкладка *Вид*, раздел *Формат даты*.
- **Длительности и резерв времени** — длительность отображается в единице задачи (`5d`, `12h`) или по настройке *Отображение длительности* на той же вкладке (*Автоматически (собственная единица каждой задачи)*, *Всегда в днях* или *Всегда в часах*). Резерв времени отображается в рабочих днях с двумя знаками после запятой и с десятичным разделителем вашего языка.
- **Да/Нет** — значение да или нет отображается как *Да* или *Нет*; пустое значение — как тире (—).
- **Редактирование** — введите значение или выберите его. Недопустимое значение отклоняется; причина появляется под ячейкой, например *Введите допустимую длительность, например 5d или 8h.* или *Введите процент от 0 до 100.* Вставка блока ячеек выполняется по каждой ячейке отдельно. Ячейки только для чтения пропускаются, а приложение сообщает, сколько их было.

## Задача

- **Название задачи** — название задачи. Редактируется; обязательно. Суммарная задача выделяется жирным шрифтом, а ячейка названия получает светлый оттенок фона. Веха выделяется жирным шрифтом цветом вехи (той же цветовой гаммы, что и веха на диаграмме Ганта). Обычная задача не меняется. Это только оформление: выбор, перетаскивание и редактирование работают одинаково.
- **Описание** — описание задачи. Редактируется; свободный текст.
- **СДР** — код СДР. Редактируется и обязателен, но только для чтения, пока включен *СДР авто*.
- **Тип задачи** — тип задачи (*Строительство*, *Монтаж*, *Снос*, *Логистика*, *Проверка/инспекция*, *Перемещение*, *Ремонт*, *Техобслуживание* или *Прочее*). Редактируется со списком.
- **Настраиваемый тип задачи** — настраиваемый тип задачи из проекта или тире. Редактируется со списком настраиваемых типов проекта.
- **Цвет** — сохраненный цвет задачи в виде кода цвета, например `#1a73e8`. Редактируется с помощью палитры цветов. Он сохраняется в файле IFC, но ни одна полоса и ни один отчет его не использует. Цвета полос задаются в *Вид › Базовые планы и ход выполнения › Цвета полос*.
- **Примечания** — примечания в виде `✓ text; ○ text`. Редактируются, пока есть не более одного примечания (тогда вы редактируете его текст). При большем количестве примечаний только для чтения.

## График

- **Веха** — является ли задача вехой. Редактируется. Если включить, длительность становится 0. Приложение отклоняет это для суммарной задачи и для задачи с назначениями.
- **Тип вехи** — *Веха начала* или *Веха окончания*, или тире для автоматического выбора. Редактируется только у вехи.
- **Обязательная веха** — признак *Обязательная (по контракту)*. Редактируется только у вехи.
- **Приоритет выравнивания** — целое число от 0 до 1000, по умолчанию 500. Редактируется. Значение 1000 закрепляет задачу для выравнивания.
- **Разрывы** — число разрывов в виде `Разрывы: 2` или тире. Только для чтения; редактируются на панели *Свойства*.
- **Правило работы** — правило работы задачи; пустое значение означает значение по умолчанию для проекта. Редактируется со списком. Пусто и только для чтения у вехи, суммарной задачи или гамака. Появляется в окне выбора, только когда видны правила работы (*Правила работы и трудозатраты*, или файл содержит правила работы).
- **Гамак (производная длительность)** — является ли задача гамаком. Редактируется, кроме вехи и суммарной задачи.
- **Календарь** — идентификатор собственного календаря задачи; пусто (—) означает календарь проекта. Введите идентификатор или выберите его из подсказок; неизвестный идентификатор отклоняется. Примечание: сейчас ячейка показывает внутренний идентификатор вместо названия. Лучше выберите календарь на панели *Свойства*.
- **Тип длительности** — *Рабочее время* (длительность считается в рабочих днях или рабочих часах календаря) или *Астрономическая длительность* (длительность считается в непрерывном времени по часам, без календаря). Редактируется.
- **Единица длительности** — *Дни* или *Часы*. Редактируется, кроме суммарной задачи, гамака и вехи. Переключение работает, только если пересчет точный и включена опция *Включить почасовое планирование*.
- **Длительность** — длительность задачи в единице задачи или по настройке *Отображение длительности*. Редактируется: введите `5d`, `12h` или `1h 30m`; также число в единице задачи. Только для чтения у суммарной задачи, гамака и вехи с длительностью 0.
- **Начало** — отображаемое начало, та же дата, что у полосы в диаграмме Ганта. Редактируется. Если вы задаете задаче с предшественником новое начало, на эту дату действует ограничение *Начало не ранее (SNET)*. Только для чтения у суммарной задачи или гамака, если задача не планируется вручную.
- **Окончание** — отображаемое окончание. Редактируется: новое окончание дает новую длительность. Приложение отклоняет его для завершенной задачи, вехи, задачи с астрономической длительностью и задачи с перерывами, а также если окончание раньше начала (*Окончание находится раньше начала.*). Только для чтения у суммарной задачи или гамака, если задача не планируется вручную.
- **Плановое начало** — опорная дата, с которой начинается расчет (не обязательно отображаемое начало). Редактируется; действует так же, как ввод даты в столбце *Начало*.
- **Плановое окончание** — введенное окончание. Редактируется только у задачи, планируемой вручную. Иначе приложение пишет: *Плановое окончание действует только для задачи, планируемой вручную. Измените окончание в столбце «Окончание» или измените длительность.*

## Ограничения

- **Тип ограничения** — тип ограничения, от *Как можно раньше (ASAP)* до *Фиксированное окончание (MFO)*. Редактируется; у задачи без ограничения отображается *ASAP*.
- **Дата ограничения** — дата ограничения. Редактируется.
- **Жесткое ограничение** — признак *Обязательная (жёсткая привязка)*. Редактируется только для *MSO* и *MFO*.
- **Тип вторичного ограничения** — тип второй границы или тире. Редактируется. Таблица предлагает все типы, но недопустимое сочетание отклоняется: вторичное ограничение должно быть *SNET*, *FNET*, *SNLT* или *FNLT*, основное ограничение должно задавать границу (не *ASAP*, *ALAP*, *MSO*, *MFO* или жесткое ограничение), а обе границы должны задавать противоположные стороны (нижняя граница *SNET* или *FNET* с верхней границей *SNLT* или *FNLT*, или наоборот).
- **Дата вторичного ограничения** — дата второй границы. Редактируется.
- **Крайний срок** — целевая дата окончания. Редактируется.

## Связи

- **Предшественники** — предшественники в виде `СДР тип±задержка`, разделенные `; `, например `1.2 FS+2d`. Редактируется вводом в том же виде. Внешнюю зависимость добавляют не здесь, а через *График › Связи › Связать › Добавить внешнюю зависимость…*.
- **Последователи** — последователи в том же виде. Редактируется.
- **Определяющие связи** — связи, которые задают дату этой задачи, в виде `← 1.2` (предшественник) или `→ 1.4` (последователь). Только для чтения. Значение устаревает, пока вы не нажмете *Рассчитать*.
- **Свободный резерв времени** (в категории *Связи*) — свободный резерв времени для каждой связи, в виде `← 1.2: 3d`. Это не тот же столбец, что *Свободный резерв времени* в категории *Вычисляемые*, который показывает резерв времени самой задачи. Только для чтения.
- **Предупреждения** — предупреждения по каждой связи, например *Нарушен порядок* или *Не учитывается в расчете*. Только для чтения. См. [Уведомления и предупреждения](docs://ref-meldingen).

## Ресурсы

- **Назначенные ресурсы** — названия назначенных ресурсов, через запятую. Редактируется: добавление названия назначает ресурс с 1 единицей назначения в день, удаление названия удаляет назначение. Только для чтения у вехи или суммарной задачи.
- **Единицы назначения в день** — единицы на каждый ресурс, в виде `Name: 1; Name: 0.5`. Редактируется у задачи с назначениями.
- **Контур назначения** — контур на каждый ресурс, в виде `Name: Uniform`. Редактируется у задачи с назначениями.
- **Начало окна работ** и **Окончание окна работ** — окно работ на каждый ресурс из импортированного файла, в виде `Name: date`. Только для чтения.
- **Плановые трудозатраты (часы)** и **Фактические трудозатраты (часы)** — плановые и фактические трудозатраты на каждый ресурс в часах, в виде `Name: 12`, из импортированного файла. Только для чтения.
- **Оставшиеся трудозатраты (часы)** — оставшиеся трудозатраты на каждый ресурс в часах, в виде `Name: 6`: сохраненные трудозатраты, иначе оставшаяся длительность × единицы назначения. Редактируется у задачи с назначениями, к которым применяется правило работы. Появляется в окне выбора, только когда видны правила работы.

## Ход выполнения

- **Статус** — *Не начата*, *В работе* или *Завершена*. Редактируется, кроме суммарной задачи.
- **Ход выполнения** — процент завершения, в виде `40%`. Редактируется: число от 0 до 100, кроме суммарной задачи.
- **Фактическое начало** — дата, когда задача началась. Редактируется, кроме суммарной задачи.
- **Фактическое окончание** — дата, когда задача была выполнена. Редактируется, кроме суммарной задачи.
- **Фактическая длительность** — фактическая длительность в виде числа. Редактируется, кроме суммарной задачи.
- **Оставшаяся длительность** — оставшаяся длительность в единице задачи. Редактируется, кроме суммарной задачи.
- **Дата возобновления** и **Дата остановки** — возобновление и остановка выполняющейся задачи из файла MS Project или Primavera. Только для чтения.

Столбцы хода выполнения следуют правилам хода выполнения приложения: приложение отклоняет фактическую дату, которая позже даты отчета о состоянии. У суммарной задачи приложение показывает сообщение *Ход выполнения суммарной задачи определяется по подзадачам и здесь не может быть изменен.*

## Вычисляемые

Все столбцы этой категории доступны только для чтения.

- **Выравнивающая задержка** — на сколько рабочих дней выравнивание сдвинуло задачу; тире, если выравнивание не применялось.
- **Раннее начало** и **Раннее окончание** — самые ранние даты из расчета.
- **Позднее начало** и **Позднее окончание** — самые поздние даты, на которые задача еще может начаться или закончиться, не задерживая проект.
- **Свободный резерв времени** — рабочие дни, на которые задача может сдвинуться, не задерживая последователя.
- **Общий резерв времени** — рабочие дни, на которые задача может сдвинуться, не задерживая окончание проекта. Отрицательный, если ограничение или крайний срок нельзя выполнить.
- **Критическая** — *Да*, если задача лежит на критическом пути.
- **Мешающий резерв времени** — общий резерв времени минус свободный резерв времени.
- **Почти критическая** — *Да* для почти критической задачи. Заполняется, только если включена опция *Отмечать почти критические* (*Сведения о проекте*, блок *Профиль расчета и параметры расчета*); иначе тире.
- **Путь резерва времени** — номер пути резерва времени, 1 для самого критического. Заполняется, только если включена опция *Несколько путей резерва времени*; иначе тире.
- **Источник зафиксированных дат** — для файла с зафиксированными датами: *Отклоняется* или *Частично не зафиксировано*. Появляется в окне выбора только у такого файла. Для незафиксированной шкалы в столбцах поздних дат и резервов времени появляется *Не зафиксировано*.

См. [Критический путь и резерв времени](docs://uitleg-kritiek-pad).

## Базовый план

Для каждого базового плана проекта добавляются столбцы. Перед названием столбца стоит название базового плана (`<базовый план> — Плановое начало`). Они доступны только для чтения. Задача, которой нет в базовом плане, показывает тире с подсказкой *Отсутствует в этом базовом плане*.

- **Плановое начало**, **Плановое окончание** и **Длительность** — начало, окончание и длительность так, как их записал базовый план.
- **Отклонение начала** и **Отклонение окончания** — число рабочих дней между базовым планом и отображаемым началом или окончанием по календарю проекта; положительное, если задача позже.
- **Отклонение длительности** — текущая длительность минус длительность в базовом плане, в рабочих днях.

## Настраиваемые

- **Код задачи** — один столбец на каждый код задачи, с названием кода. Показывает код выбранного значения. Редактируется: введите код или выберите его из подсказок. Неизвестный код отклоняется; если код встречается несколько раз, приложение просит выбрать его из списка.
- **Настраиваемое поле** — один столбец на каждое настраиваемое поле, с его названием. Ввод соответствует типу: текст, число, целое число, затраты, дата или да/нет. Редактируется.

Эти столбцы относятся к проекту, в котором находится код или поле. См. [Коды и настраиваемые поля](docs://howto-codes-en-velden).

## Технические

Все столбцы этой категории доступны только для чтения. Они показывают данные, которые приложение хранит, но не показывает в обычном столбце, например для проверки импорта.

- **Идентификатор задачи** — внутренний идентификатор задачи.
- **Идентификатор родительской задачи** и **Идентификаторы дочерних задач** — идентификаторы родительской и дочерних задач.
- **Идентификаторы ресурсов** — идентификаторы ресурсов задачи.
- **Идентификатор назначения**, **Идентификатор задачи назначения** и **Идентификатор ресурса назначения** — идентификаторы назначения, задачи и ресурса этой задачи.
- **Длительность (минуты)** и **Оставшаяся длительность (минуты)** — длительность и оставшаяся длительность в минутах; заполняется только у задачи в часах.
- **Выравнивающая задержка (минуты)** и **Выравнивающая задержка по астрономическому времени** — выравнивающая задержка из MS Project в минутах и то, учитывается ли она в астрономическом времени.
- **Планируемая вручную** — планируется ли задача вручную.
- **Тип задачи MS Project (импорт)** и **Фиксированный объем работ** — тип задачи и признак фиксированного объема работ, как они были в MS Project.
- **Происхождение Primavera P6** — исходные поля из файла Primavera, в виде `key: value`.
- **Явная суммарная задача** — является ли задача явной суммарной без подзадач (из файла Primavera).
- **Пол окончания по времени**, **Опорная точка начала по времени**, **Отрезки длительности по времени** и **Контуры по времени** — распределение трудозатрат по часам из файла MS Project, в виде дат и количеств.
- **Данные кодов задач**, **Данные настраиваемых полей** и **Данные примечаний** — число назначений кодов, настраиваемых полей и примечаний.
- **Данные внутренних связей** и **Данные внешних зависимостей** — число внутренних связей и внешних зависимостей.
- Для каждого базового плана здесь также есть **Веха** и **Тип вехи**, как их записал базовый план.
