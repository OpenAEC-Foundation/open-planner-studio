# Экспорт

Цель: передать ваш график в виде файла в другом формате тому, кто не работает с IFC, или другой программе.

## Когда это нужно

Консультант работает в MS Project, заказчик в Primavera, субподрядчик хочет получить задачи в Excel, или вы отправляете график программе, которая не работает с IFC. Экспорт — это копия в другом формате. Если вы хотите сохранить сам проект, сохраните его: так записывается IFC, и он переносит все данные. Что переносит каждый формат и что не переносит, описано в [Файлы и форматы](docs://uitleg-bestanden).

## Шаги

1. Выберите *Главная › Файл › Экспорт* и формат из списка, или выберите *Файл › Экспорт*. Там каждый формат — это карточка с коротким описанием.
2. В окне выберите имя и место. Приложение предлагает имя проекта с расширением формата. Листы хода выполнения называются *имяпроекта-ход-выполнения* и по возможности открываются в папке загрузок.
3. Подтвердите. Если экспорт прошел успешно, сообщение не появляется, кроме сообщений ниже. Из раздела *Файл › Экспорт* вы потом возвращаетесь на вкладку *Главная*, даже если отменили окно. Если вы отмените окно для экспорта из списка на вкладке *Главная*, ничего не произойдет.

Если ваш браузер сохраняет файлы только через загрузку (например, Firefox), файл находится в папке загрузок сразу после шага 1. Вы видите сообщение *Сохранено как загрузка: «name.xml» теперь находится в папке загрузок. Эта среда не позволяет приложению писать напрямую в выбранное место.*

### Какой формат выбрать?

Список на вкладке *Главная* и карточки в *Файл › Экспорт* предлагают одни и те же форматы:

- *Ход выполнения (Excel)* и *Ход выполнения (CSV)*, на карточках *Лист хода выполнения (Excel)* и *Лист хода выполнения (CSV)*: компактный лист с идентификатором, СДР, названием, датами и процентом завершения, чтобы разослать его тем, кто вносит данные о ходе выполнения.
- *CSV (;)*, на карточке *CSV (разделитель «;»)*: список задач, который вы открываете в электронной таблице.
- *MS Project XML*: его можно открыть в Microsoft Project.
- *Primavera P6 XML*: для Oracle Primavera P6.
- *IFC 4x3*: собственный формат приложения, со всеми данными.

### Экспорт IFC с файлом библиотеки

Если ваш проект связан с библиотекой ресурсов, флажок *Сохранить файл библиотеки рядом* находится под карточками в разделе *Файл › Экспорт*. Если вы установите флажок и выберете *IFC 4x3*, приложение дважды запрашивает место: сначала для проекта, затем для *имяпроекта-библиотека.ifc*. Этот флажок есть только в разделе *Файл › Экспорт*, но не в списке на вкладке *Главная*.

### Восстановление листа хода выполнения

Вы загружаете заполненный лист хода выполнения обратно через раздел *Файл › Импорт*. См. [Импорт хода выполнения из таблицы](docs://howto-voortgang-importeren).

## Подводные камни и что тогда делает приложение

**Ваш проект не меняется.** Файл проекта остается прежним. Если была метка *Не сохранено*, она остается.

**Устаревший график сначала пересчитывается.** Так вы получаете актуальные даты, даже если забыли нажать *Рассчитать*.

**Экспорт также попадает в Недавние.** Это не относится к листам хода выполнения. Если вы откроете там экспорт, он откроется как импорт в этом формате.

**Экспорт переносит не все данные.** В файле CSV нет ресурсов и ограничений, в P6 XML нет базовых планов и крайних сроков. Профиль расчета тоже не переносится: повторно открытый экспорт рассчитывается как *Open Planner Studio*. Только IFC переносит все данные. Пример с числами вы найдете в [Файлы и форматы](docs://uitleg-bestanden).

**Два формата с одинаковым расширением.** MS Project XML и Primavera P6 XML получают одно имя *имяпроекта.xml*. Дайте им разные имена сами, иначе позже не поймете, какой файл в каком формате.

**График с циклической связью не экспортируется.** Приложение сначала рассчитывает график и останавливается, если есть цикл. На вкладке *Главная* вы получите сообщение *Не удалось рассчитать график*, а под ним, например, *Циклическая связь между задачами: Set up site → Demolish existing extension → Set up site*. В разделе *Файл › Экспорт* на странице есть только второй текст. Устраните цикл и экспортируйте снова.

**Проект из Primavera теряет сведения об источнике.** Если вы экспортируете такой проект в CSV, MS Project XML или P6 XML, приложение выводит сообщение: *При экспорте в CSV теряются сведения об исходном файле XER.* Для MS Project XML оно говорит *MSPDI*, для P6 XML — *P6*. См. [Открытие файла Primavera P6 (.xer)](docs://howto-xer-openen).

**Разделенные задачи теряют разделение.** MS Project и Primavera поддерживают разделение только как распределение трудозатрат по часам. Если в вашем проекте есть разделенные задачи без распределения трудозатрат по часам, приложение после экспорта в MS Project XML или P6 XML выводит сообщение: *2 задачи с перерывами экспортированы без перерывов: MS Project и P6 поддерживают перерывы только как распределение трудозатрат.* Для одной задачи оно говорит *1 задача с перерывами экспортирована без перерывов: MS Project и P6 поддерживают перерывы только как распределение трудозатрат.* См. [Разделение задачи](docs://howto-taak-splitsen).

**График в представлении *Даты в исходном виде*.** Если вы экспортируете в CSV, пока видите даты из исходного файла, приложение оставляет поля `Critical` и `Total Float` пустыми у задач, для которых исходный файл этого не записал. См. [Даты в исходном виде](docs://uitleg-datums-zoals-opgeslagen).
