# Выбор типа задачи

Цель: задать для каждой задачи, что приложение корректирует при изменении длительности, единиц назначения или трудозатрат: саму длительность, единицы назначения или трудозатраты.

## Когда это нужно

Вы назначили ресурсы на задачу, и вы хотите, чтобы приложение рассчитывало так, как рассчитываете вы. Пример: кран арендован на один день, и этот день фиксирован. Другой пример: в кладке 160 часов трудозатрат, и вы хотите узнать, сколько времени займет кладка тремя людьми вместо двух. Для этих двух ситуаций нужны разные типы задач.

Тип задачи определяет, какая из трех величин (длительность, единицы назначения или трудозатраты) меняется, когда вы меняете другую. Общие сведения и примеры расчетов описаны в [Типы задач: длительность, единицы и трудозатраты](docs://uitleg-werkregels).

## Шаги

### Отображение типа задачи

Тип задачи по умолчанию не показывается. Включите его один раз:

1. Выберите *Настройки › Проект › Настройки приложения*, вкладка *График*.
2. В разделе *Расчет* поставьте галочку напротив *Типы задач*.
3. Закройте окно кнопкой *Закрыть*.

Это настройка приложения, а не файла проекта. Если файл уже содержит типы задач или сохраненные трудозатраты, например файл из MS Project или Primavera P6, приложение показывает тип задачи для этого файла, даже без этой настройки. То же происходит, как только вы сами выберете тип задачи в файле: тогда отображение остается включенным для этого файла, даже если вы снова выключите настройку. Оно остается включенным, пока файл открыт, а после повторного открытия — пока файл содержит тип задачи или сохраненные трудозатраты.

### Установка типа задачи

1. Выберите задачу. Панель *Свойства* находится справа. Если вы ее не видите, включите ее командой *Вид › Панели › Свойства*.
2. В поле *Тип задачи* выберите один из пяти вариантов: *Стандарт проекта (Фиксированная длительность и единицы)*, *Фиксированная длительность и единицы*, *Фиксированная длительность и трудозатраты*, *Фиксированные трудозатраты* или *Фиксированные единицы*. При выборе *Стандарт проекта* задача использует стандарт проекта.
3. Хотите узнать, что делает вариант? В открытом списке у каждого варианта есть значок i. Наведите на него указатель, щелкните его или коснитесь его, чтобы увидеть объяснение. Нажатие на значок i пока не выбирает этот тип задачи.
4. Рядом с закрытым полем тоже есть значок i. Он объясняет тип задачи, который действует сейчас, например *Длительность следует из трудозатрат и единиц назначения.* Если выбран *Стандарт проекта*, это тип задачи в скобках.

*Стандарт проекта* — первый вариант, и он стоит у задачи по умолчанию. Тип задачи в скобках — это тип, который сейчас задан для проекта по умолчанию. В приложении нет кнопки, с помощью которой можно изменить стандарт проекта: он берется из импорта (например, из MS Project или Primavera P6) или из подключения MCP. Если вы хотите другой тип задачи для одной задачи, выберите его здесь.

Тип задачи можно выбрать и в таблице. Щелкните **+** справа от заголовка таблицы задач (*Добавить столбец*) и в группе *График* выберите столбец *Тип задачи*.

Задача без назначения не имеет ничего, что можно связать, поэтому тип задачи там не действует. Сначала назначьте ресурс (см. [Назначение ресурсов с кривой](docs://howto-resource-toewijzen)).

### Просмотр и изменение трудозатрат

Для задачи с назначениями в разделе *Назначения* панели *Свойства* рядом со столбцом *Единицы назначения* появляется столбец *Трудозатраты (ч)*. Это оставшиеся трудозатраты этого ресурса в часах. Над столбцом небольшой замок показывает, что удерживает тип задачи: *Единицы назначения* при типах *Фиксированная длительность и единицы* и *Фиксированные единицы*, *Трудозатраты (ч)* при типах *Фиксированная длительность и трудозатраты* и *Фиксированные трудозатраты*.

Если вы хотите изменить трудозатраты вручную, введите часы в поле и нажмите Enter. Приложение не принимает значение 0 или меньше: поле возвращается к предыдущему значению.

### Что происходит

Если вы выбираете тип задачи, пока ни одно число не меняется. При типе задачи, который защищает трудозатраты, приложение только фиксирует текущие трудозатраты, поэтому в столбце *Трудозатраты (ч)* появляется сохраненное значение. Тип задачи решает, что меняется, только при следующем изменении. Например, измените *Единицы назначения* и посмотрите, что произойдет с длительностью и трудозатратами.

Если это меняет длительность задачи, строка состояния показывает *Устарело — пересчитайте (F5)*. Нажмите **Рассчитать** (F5), например через *Главная › График › Рассчитать*, чтобы увидеть новые даты. Если включен *Автоматический расчет* (на той же вкладке *График*, в разделе *Расчет*), приложение делает это само.

## Какой тип задачи подходит

- **Фиксированная длительность и единицы** подходит, когда длительность задана по договоренности, а единицы назначения вводите вы. Трудозатраты следуют из этих двух величин. Это значение по умолчанию. Кран, арендованный на один день, относится сюда: день фиксирован, а вы решаете, сколько кранов работает в этот день.
- **Фиксированная длительность и трудозатраты** подходит, когда задача должна быть закончена в фиксированный срок и вы знаете, сколько в ней трудозатрат. Если длительность меняется, приложение корректирует единицы назначения.
- **Фиксированные трудозатраты** подходят, когда вы знаете, сколько часов трудозатрат в задаче, и хотите увидеть, как меняется длительность при разном числе людей. 160 часов кладки при трех людях вместо двух относятся сюда. Штукатурка в учебном проекте получает этот тип задачи.
- **Фиксированные единицы** подходят, когда единицы назначения фиксированы, например один кран, а трудозатраты определяют длительность.

## Возможные проблемы и что делает приложение

**Поле *Тип задачи* отсутствует.** Тогда настройка *Типы задач* выключена и в файле пока нет типов задач, или вы выбрали веху, фазу, гамак или задачу с типом длительности *астрономическая длительность*. Для них типа задачи нет. Выберите обычную задачу.

**Длительность меняется, хотя вы ее не меняли.** При типах *Фиксированные трудозатраты* и *Фиксированные единицы* длительность следует из единиц назначения и трудозатрат. Если вы измените одно из них или число ресурсов, приложение корректирует длительность, округляя ее вверх до целых рабочих дней. Для задачи в часах приложение округляет вверх до целых минут.

**Трудозатраты не совпадают точно с единицами назначения × длительность.** Причиной может быть округление. В столбце *Трудозатраты (ч)* тогда появляется предупреждающий знак *Отличается от единиц назначения × длительность*. Гистограмма следует за сохраненными трудозатратами.

**Материал не учитывается.** Для материального ресурса *Трудозатраты (ч)* показывает прочерк. Материал никогда не определяет длительность.

**Задача с ходом выполнения.** Тип задачи работает с оставшейся частью. Поэтому *Трудозатраты (ч)* показывает только то, что еще предстоит.

**Отмена.** Выбор типа задачи и каждое изменение, которое рассчитывает тип задачи, отменяются одним шагом командой *Отменить* (Ctrl+Z). После этого выбранный тип задачи снова пропадает, но поле *Тип задачи* остается на виду.
