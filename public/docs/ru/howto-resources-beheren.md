# Управление ресурсами

Цель: создавать, изменять и удалять ресурсы (людей, машины и материалы) в вашем проекте, чтобы назначать их на задачи.

## Когда это нужно

Прежде чем назначить каменщика или кран на задачу, этот человек или эта машина должны существовать как ресурс. В ресурсе указано, сколько их есть и в какие дни они работают. Так приложение проверяет, не назначаете ли вы на один день больше, чем ресурс может выполнить. Вы изменяете ресурс, когда меняется состав бригады, например когда в нее приходит второй каменщик.

Два термина. **Максимальная доступность** — это емкость за один рабочий день: 1 — один человек или одна машина, 2 — две из них. **Назначение** — это ресурс, назначенный на задачу (см. [Назначение ресурсов с помощью кривой](docs://howto-resource-toewijzen)).

## Шаги

### Создание ресурса

1. Выберите *Ресурсы › Управление › Новый ресурс*. Панель ресурсов занимает рабочую область, и внизу таблицы появляется пустая строка. Панель также можно открыть через *Ресурсы › Управление › Ресурсы*, а затем выбрать *Создать ресурс в проекте*.
2. Введите имя, например *Bricklayer*.
3. Выберите *Тип*: *Труд* (по умолчанию), *Оборудование*, *Материал*, *Субподрядчик* или *Смена*.
4. Заполните при необходимости другие поля. У всех полей есть значение по умолчанию: *Макс. доступность* равна 1, а *Календарь* — *Календарь проекта*. *Ст. ставка/час* остается пустым. Поле *Единица* можно заполнить только для типа *Материал*, например м³.
5. Нажмите Enter или щелкните за пределами строки. Ресурс добавлен в таблицу. При нажатии Enter под ней сразу открывается пустая строка для следующего ресурса. Когда закончите, нажмите Esc.

Строка становится ресурсом, только когда у нее есть имя. При нажатии Esc или щелчке мимо строки без имени приложение ничего не создает. Порядок заполнения не важен: можно сначала выбрать тип, а затем ввести имя.

### Изменение ресурса

Измените поля в строке. Приложение сохраняет имя, стандартную ставку и единицу, когда вы выходите из поля, а остальные поля — сразу.

- *Макс. доступность* принимается приложением, только если значение больше 0. При 0 или меньше поле получает красную рамку и возвращается к предыдущему значению.
- *Календарь* определяет, в какие дни работает ресурс. Выберите *Календарь проекта* или собственный календарь. С помощью *+ Календарь ресурса* вы создаете новый календарь, а карандаш (*Изменить…*) открывает выбранный календарь. Если задача идет в день, когда ресурс не работает по своему календарю, этот день считается превышением доступности. Как создать календарь ресурса, описано в [Настройка календаря ресурса](docs://howto-resourcekalender-instellen).
- *Ст. ставка/час* и *Итого*: *Итого* — это загруженные часы ресурса, умноженные на ставку. Штукатур, загруженный на 32 часа при ставке 50 в час, составляет 1 600,00. Внизу таблицы стоит сумма по всем ресурсам.
- *Смена* группирует ресурс под ресурсом типа *Смена*. Это только группировка: приложение не суммирует емкость или загрузку участников смены.
- Цветной квадрат слева — это цвет ресурса. Он только для показа и не влияет на график.

### Емкость, которая меняется со временем

Ваш второй каменщик появляется только 19 июля? Щелкните стрелку рядом с *Макс. доступность*. Под *Поэтапная емкость* выберите *Добавить шаг*. У каждого шага есть дата (*С*) и число (*Макс. доступность*). С этой даты действует это число. Без шагов всегда действует постоянное значение.

Новый шаг начинается с сегодняшней даты и значения 1. Измените оба, иначе с сегодняшнего дня действует емкость 1.

### Удаление ресурса

1. Щелкните корзину в строке.
2. Если у ресурса есть назначения, приложение запрашивает подтверждение, например *«Bricklayer» связан с назначениями (4) — удалить?* Нажмите галочку, чтобы удалить, или крестик, чтобы отменить. Без назначений ресурс сразу исчезает.

Назначения ресурса удаляются вместе с ним. Если у задачи есть правило работы, отличное от *Фиксированная длительность и единицы*, приложение распределяет трудозатраты удаленного ресурса между оставшимися ресурсами. В зависимости от правила меняются единицы назначения или длительность задачи. Если длительность меняется, график уже не актуален.

Создание, изменение и удаление ресурса можно отменить командой *Отменить* (Ctrl+Z).

### Краткий обзор в боковой колонке

*Ресурсы › Управление › Панель ресурсов* выводит краткий обзор в правую колонку, рядом с *Свойства*. Там видны имя и цвет каждого ресурса. Рядом с ресурсом, у которого есть превышение доступности, стоит предупреждающий знак (*Превышение доступности*). В этом обзоре можно изменить только *Макс. доступность*. Если выбрать одну или несколько задач, обзор показывает только ресурсы этих задач.

## Типичные ошибки и что тогда делает приложение

**Только тип *Материал* влияет на расчет.** Труд, Оборудование, Субподрядчик и Смена обрабатываются одинаково. Материал не учитывается в длительности задачи и не выравнивается. В гистограмме строка *Все ресурсы* тоже не учитывает материал.

**Нет имени — нет ресурса.** Пустая строка исчезает без следа.

**Новый шаг емкости.** Если вы забудете изменить дату и число, с сегодняшнего дня емкость будет равна 1.

**Удаление ресурса, который еще нужен.** Если вы удалили его по ошибке, сразу нажмите Ctrl+Z. Назначения тоже вернутся.
