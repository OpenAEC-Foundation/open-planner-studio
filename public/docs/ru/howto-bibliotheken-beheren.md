# Управление библиотеками ресурсов и их передача

Цель: создавать и удалять библиотеки ресурсов, помещать в них календари, а также экспортировать и импортировать библиотеку — как резервную копию или чтобы использовать ее на другом компьютере.

## Когда это нужно

Библиотека ресурсов не находится в файлах проекта, а хранится в приложении: в настольном приложении — в файле на этом компьютере, в браузере — в хранилище этого браузера. Она не синхронизируется. Если вы очистите данные сайта в браузере, библиотека пропадет. Поэтому экспортируйте ее как резервную копию. Если коллега хочет работать с теми же бригадами и ставками, передайте ему библиотеку ресурсов тоже в виде файла. Если в вашей организации несколько операционных компаний с собственными бригадами, сделайте отдельную библиотеку ресурсов для каждой. Для нового проекта вы выбираете, какую библиотеку ресурсов он использует.

Что такое библиотека ресурсов, вы узнаете в [Библиотека ресурсов](docs://uitleg-resourcebibliotheek). Сами ресурсы здесь вы не редактируете, а на панели ресурсов. См. [Использование библиотеки ресурсов](docs://howto-resourcebibliotheek-gebruiken).

## Шаги

### Открытие экрана управления

Выберите *Файл › Библиотека*. Слева находится список *Библиотеки ресурсов*. Справа находятся подробности выбранной библиотеки: имя, кнопки и список *Календари*. Вверху написано, что ресурсами управляют на вкладке *Ресурсы*.

### Создание, переименование и выбор библиотеки по умолчанию

1. Нажмите на значок «+» над списком (*Добавить библиотеку ресурсов*). Добавится библиотека *Новая библиотека ресурсов*, и она сразу выбирается.
2. Введите новое имя в поле имени вверху правой части и нажмите Enter или щелкните вне поля. Приложение не принимает пустое имя.
3. Нажмите *Сделать по умолчанию*, чтобы для новых проектов эта библиотека выбиралась заранее. У библиотеки по умолчанию в списке есть звездочка.

### Помещение календаря в библиотеку

1. В разделе *Календари* нажмите *Добавить из проекта*. Откроется список календарей активного проекта.
2. Нажмите на маленькую стрелку после календаря, который хотите взять. Над списком появится *Добавлено*. У календаря, который уже связан с этой библиотекой ресурсов, после имени стоит *уже связано*.
3. Календарь теперь находится в списке *Календари* библиотеки ресурсов. Карандашом (*Изменить*) вы меняете имя и сохраняете галочкой. Значок корзины удаляет календарь сразу, без запроса подтверждения. Копии в проектах остаются.

Рядом с *Календари* стоит номер версии, например *v2*. Он увеличивается при каждом изменении библиотеки ресурсов. Календарь библиотеки переходит в проект вместе с ресурсом, когда вы назначаете ресурс, который его использует. Вы подключаете его к ресурсу на вкладке *Ресурсы*, в виде *Библиотека*, в столбце *Календарь*.

### Экспорт библиотеки

1. Выберите библиотеку в списке.
2. Нажмите *Экспортировать*.
3. В настольном приложении, а также в Chrome и Edge вы выбираете, куда сохранить файл. В других браузерах файл сразу попадает в папку загрузок, и приложение сообщает вам об этом. Файл называется `bibliotheek-`, после него идет имя библиотеки ресурсов, с расширением `.ifc`.

Под кнопками написано *Экспорт также служит резервной копией: храните файл в надежном месте*.

### Импорт библиотеки

1. Нажмите *Импортировать*. Откроется окно *Импорт библиотеки* для библиотеки, которую вы выбрали в списке.
2. Нажмите *Выбрать файл…* и выберите файл `.ifc` экспорта. Если файл не содержит библиотеку, приложение покажет: *Этот IFC-файл не содержит библиотеку ресурсов*.
3. Приложение показывает, что в файле есть, например: *Календарей: 2, ресурсов: 5 (версия 3)*.
4. Выберите, что вы хотите с ним сделать, см. ниже.
5. Нажмите *Добавить* или *Заменить*, либо *Отменить*, чтобы остановить импорт.

У вас два варианта:

- *Добавить как новую библиотеку ресурсов*: файл становится отдельной библиотекой рядом с вашими существующими. Под ним написано, под каким именем, например: *Будет добавлена как «Mijn resourcebibliotheek (2)»*. Ничего не теряется, и ваш активный проект остается связан со своей библиотекой.
- *Заменить существующую библиотеку ресурсов*: все содержимое выбранной библиотеки ресурсов заменяется содержимым файла. Приложение также говорит об этом: *Импорт заменяет ВЕСЬ набор выбранной библиотеки ресурсов*. Если у вас две или больше библиотек ресурсов, вы выбираете нужную в поле *Импортировать в библиотеку ресурсов*. Если ваша библиотека новее файла, приложение предупреждает: *Ваша локальная библиотека новее — импорт может перезаписать ваши изменения*.

Приложение само предлагает вариант. Для файла, в котором была библиотека по умолчанию, заранее выбран вариант *Добавить как новую библиотеку ресурсов*. Если библиотека из файла уже есть на вашем компьютере и не является библиотекой по умолчанию, заранее выбран вариант *Заменить существующую библиотеку ресурсов*, и именно эта библиотека выбрана. Если сомневаетесь, выберите вариант добавления: он ничего не перезаписывает.

### Удаление библиотеки

1. Выберите библиотеку в списке и нажмите *Удалить библиотеку ресурсов*. Кнопка серая у последней библиотеки, потому что одна библиотека всегда остается.
2. Подтвердите, нажав *Удалить*. Вопрос: *Удалить эту библиотеку ресурсов?* Если к ней подключены открытые проекты, появится: *Эта библиотека ресурсов связана с открытым проектом (1). При удалении он будет отвязан. Продолжить?* Для нескольких проектов текст такой же, с числом, например: *связана с 2 открытыми проектами*.

После этого библиотека ресурсов исчезает вместе со всеми ресурсами и календарями в ней. Открытые проекты, которые ее использовали, отвязываются: их ресурсы остаются обычными ресурсами проекта. Экспортируйте библиотеку заранее, если хотите сохранить ее содержимое.

### Передача проекта вместе с его библиотекой

Файл проекта содержит собственные копии ресурсов. Если вы также хотите передать всю библиотеку, сделайте следующее. Сам экспорт описан в разделе [Экспорт](docs://howto-exporteren).

1. Откройте проект, который связан с библиотекой, и выберите *Файл › Экспорт*.
2. Отметьте флажок *Сохранить файл библиотеки рядом*. Он появляется только у связанного проекта.
3. Выберите карточку *IFC 4x3* и сохраните файл. Затем приложение также запрашивает второй файл. Он называется как проект, с суффиксом `-bibliotheek`, и содержит библиотеку ресурсов.

Флажок работает только для экспорта IFC, но не для других форматов экспорта. Ваш коллега импортирует второй файл, как описано выше.

## Типичные ошибки и что делает приложение

**Два планировщика, две библиотеки.** Приложение не синхронизирует библиотеки между компьютерами. Окно импорта всегда показывает предупреждение об этом: *Примечание: библиотеки не синхронизируются между компьютерами. Если два планировщика работают с одной библиотекой ресурсов, библиотеки могут разойтись. Если ваша организация делит бригады между операционными компаниями, сознательно выберите один общий набор.*

**Замена перезаписывает все.** Все, что было в выбранной библиотеке ресурсов, пропадает. Изменение библиотеки нельзя отменить командой *Отменить*. Если сомневаетесь, экспортируйте библиотеку заранее.

**Удаление календаря из списка происходит сразу.** Приложение не запрашивает подтверждения, в отличие от удаления ресурса. Это похоже на недостаток. Изменения библиотеки нельзя отменить командой *Отменить*.
