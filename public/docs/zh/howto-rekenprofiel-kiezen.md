# 选择或创建计算配置文件

目标：决定项目使用哪些计算规则。你可以选择内置配置文件，或者用你自己的约定创建自定义配置文件。

## 何时需要此操作

你打开的项目必须按 Primavera P6 或 Microsoft Project 计算，或者你想让某个约定与配置文件的设置不同。配置文件是什么，以及日期为什么会变化，请见 [计算配置文件和约定](docs://uitleg-rekenprofielen)。

## 步骤

### 为新项目选择配置文件

1. 选择 *首页 › 文件 › 新建*。*新建项目* 窗口会打开。
2. 在下拉列表 *计算配置文件* 中选择配置文件：*Open Planner Studio*、*Primavera P6* 或 *Microsoft Project*。
3. 创建项目。应用会用配置文件的默认值替换你已经填写的计算选项。

### 更改现有项目的配置文件

1. 选择 *设置 › 项目 › 项目设置*。你也可以选择 *文件 › 项目设置*。
2. 在 *计算配置文件和选项* 区块中，打开下拉列表 *计算配置文件*，然后选择另一个配置文件。
3. 点击 **应用**。即使 *自动计算* 已关闭，应用也会立即重新计算计划。如果有任务移动，应用会告诉你移动了多少个。

在你点击 *应用* 之前，更改只存在于表单中。整个切换可以用 *撤销* 一步撤回。切换只会更改约定；你的计算选项保持不变。

### 创建自定义配置文件

1. 在 *计算配置文件和选项* 区块中，点击下拉列表旁边的 *新建配置文件*。
2. 输入名称。应用会建议使用所选配置文件的名称，前面加上 *副本* 字样，例如 *副本 Open Planner Studio*。
3. 点击 *创建*。*此配置文件的约定* 部分会展开。
4. 用复选框开启或关闭约定。约定行后面的 i 图标会显示该约定的说明。与基准不同的约定会带有 *恢复基准* 标签。
5. 点击 **应用**。只有这样，项目才会按新配置文件计算。

内置的三个配置文件无法更改。它们的约定仅供参考显示。

### 将自定义配置文件保存为模板

1. 如有需要，在 *此自定义配置文件的名称* 字段中为配置文件另取一个名称。
2. 点击 *另存为模板*。应用会报告模板已保存，或者说明保存失败的原因。
3. 在同一应用中的另一个项目里，该模板会出现在下拉列表 *计算配置文件* 中。

如果之后配置文件与模板不同，黄色区块会提示。然后选择 *从此项目更新模板* 或 *从模板更新*。

你可以用 *删除模板* 删除模板。应用会先要求你确认。

## 检查结果

- *计算配置文件和选项* 区块会显示所选的配置文件。
- 点击 *应用* 后，应用会报告移动的任务，例如 *应用后移动了 4 个任务。*
- 计算选项上方的橙色区块表示你的计算选项与配置文件的默认值不同。这通常是有意为之。如果你仍想使用默认值，请点击 *使用 … 的默认设置*。

## 注意事项和应用的行为

**日期会变化。** 另一个配置文件可能会改变实际日期。请检查结果。如果你不满意，请选择 *撤销*：配置文件和日期会一起恢复。

**撤销后出现黄色区块。** 如果在项目设置打开时按下 *撤销* 或 *重做*，该区块会跟随项目的状态。如果你已经自己更改过该区块中的某项，你的选择会保留。此时黄色区块会说明，*应用* 会恢复该选择。

**最多可以有 100 个模板。** 如果已经有 100 个，应用不会保存模板，并会给出提示。请先删除一个模板。应用存储空间已满或不可用时，也会显示提示。

**模板属于应用，配置文件属于项目。** 项目始终保存自己的配置文件副本。如果之后更改模板，项目不会随之改变。

**来自源文件的设置。** 如果为来自其他文件的项目选择 *Primavera P6* 或 *Microsoft Project*，源文件中的设置会保留。你不能在这里更改这些设置。
