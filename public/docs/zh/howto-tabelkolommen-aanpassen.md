# 调整表格列

目标：选择你在任务表中看到哪些列、列的顺序和列的宽度。

## 何时需要此功能

在会议中，你想在每个任务旁边看到 *截止日期* 和 *总浮时*。现场经理只想在名称旁边看到 *开始* 和 *完成*。或者某一列太窄，列标题被截断。任务表由你自己选择的列组成：有几十种，从 *任务名称* 和 *工期* 到 *截止日期*、*自由浮时* 和 *已分配资源*。

任务表有两种，每种都有自己的列：

- **Gantt 旁边的任务表** 位于时间线左侧，例如在 *首页*、*计划* 和 *视图* 选项卡上。默认情况下它有 *WBS*、*任务名称* 和 *工期*，因此时间线仍有空间。
- **表格选项卡上的表格** 占用整个工作区。默认情况下它有 *WBS*、*任务名称*、*工期*、*开始*、*完成*、*工作类别*、*关键*、*总浮时* 和 *进度*，另外还有项目中每个活动代码和自定义字段各一列。

对一个表格的更改不会改变另一个表格。

## 步骤

### 添加列

1. 点击表格标题右侧的加号（**+**）。在 *表格* 选项卡上，你也可以使用 *表格 › 列 › 列…*。随后会打开 *选择列* 窗口。
2. 找到该列。如果你之前选过列，顶部会显示 *最近使用*。在 *搜索* 中输入名称的一部分，例如输入 *截止* 查找 *截止日期*，或者打开一个类别：*任务*、*计划*、*约束*、*关系*、*资源*、*进度*、*已计算*、*基线*、*自定义* 或 *技术信息*。
3. 点击该列。它会加到表格末尾，窗口随即关闭。

表格中已有的列显示为灰色，无法选择。

### 删除列

点击列标题中的减号（*删除：截止日期*）。或者右键单击标题并选择 *删除：截止日期*。按 Ctrl+Z 可以恢复该列，或者再次用加号选择它。

### 调整宽度

拖动列标题右侧的边缘，向左或向右移动。双击该边缘，或在标题的菜单中（鼠标右键）选择 *自动调整*，使列宽足以容纳其内容，最大为 480 像素。如果该边缘有焦点，方向键会逐步加宽或缩窄它。

### 固定列

右键单击标题并选择 *固定*。被固定的列会移到最前面，在水平滚动时保持在左侧。只要这些列的总宽度不超过窗口，这一功能就有效。*取消固定* 会把它们放回原来的行中。

### 更改顺序

将列标题拖到另一个位置。被固定的列只能在固定列之间移动，普通列只能在普通列之间移动。

### 恢复默认值

打开 *选择列* 窗口，然后点击底部的 *恢复默认*。如果这些列已经是默认值，该按钮显示为灰色。对于 *表格* 选项卡上的表格，还会为项目的每个活动代码和自定义字段添加一列，即使你之前删除过这些列。这些列属于该代码或字段所在的项目。你可以在 [代码和自定义字段](docs://howto-codes-en-velden) 中阅读这些代码和字段。

## 易错点及应用的行为

**标题被截断。** 窄列会截断其名称，例如 *总浮时* 被截断为 *总浮…*。双击标题的边缘，让列自动适应内容宽度。

**你调整了错误的表格。** Gantt 旁边任务表的列与 *表格* 选项卡的列是分开的。如果你位于 *视图* 或 *首页*，你调整的是 Gantt 旁边的任务表。*表格* 选项卡上的加号调整的是大表格。

**布局会恢复列。** 如果布局勾选了 *列* 部分，点击布局按钮会把 Gantt 旁边任务表的列恢复为已保存的状态。*表格* 选项卡上的表格不受影响。参见 [创建和使用布局](docs://howto-layouts-gebruiken)。

**列设置保存在你的设备上，不在项目中。** 应用会为此设备上的所有项目保存你的列选择，而不会把它保存在项目文件中。它也不会把项目标记为“已修改”。你可以用 *撤销*（Ctrl+Z）撤销每一次列更改；这些步骤的名称例如为 *添加列 截止日期* 和 *调整列 任务名称 的宽度*。
