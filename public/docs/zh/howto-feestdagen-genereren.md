# 生成假日和建筑业假期

目标：将某个国家的假日填入日历，并可选择加入建筑业假期。需要时，你也可以添加自己的休假日或一段休假。

## 何时需要此操作

没有假日时，应用会把工作排在圣诞节或国王日。只要*施工模式*开启，新项目就已包含荷兰假日。如果你需要其他国家或地区、想加入建筑业假期，或项目超出了已生成假日的年份，就需要重新生成。那些年份很重要：对应用来说，这些年份之外的日子只是工作日。应用在计算时如何考虑假日，请阅读[日历与工作日](docs://uitleg-kalenders)。

**建筑业假期**（*bouwvak*）是荷兰建筑业的集体休假，夏季三周。在应用中，它默认关闭。

## 步骤

### 生成假日

1. 选择*计划 › 日历 › 日历*，然后在左侧选择要放入假日的日历。
2. 点击*生成假日…*。按钮下方会打开一个包含各选项的区域。
3. 在*国家*中选择：荷兰、德国、比利时、法国、英国、奥地利、瑞士，或*无假日*。对于部分国家，还会出现*地区*列表，例如德国的联邦州。选择*全国*时，只保留适用于全国的假日。
4. 对于荷兰，在*建筑业假期*中选择：*无*（默认）、*北部*、*中部*或*南部*。建筑业假期会在列表中显示为一段时间，例如 *Bouwvak (Noord)*（建筑业假期，北部），从周一到周五，共三周。只有*施工模式*开启时，你才会看到此选项。
5. 选项下方有一个摘要，例如 *21 个假日，2026–2028*。点击它可查看日期。
6. 点击*生成*。现在*假日*列表已填入内容。
7. 点击*应用*。应用会立即重新计算计划。

对于荷兰，应用每年都会在列表中加入以下假日：Nieuwjaar（元旦）、Goede Vrijdag（耶稣受难日）、Pasen（复活节，两天）、Koningsdag（国王日）、Hemelvaart（耶稣升天节）、Pinksteren（圣灵降临节，两天）以及 Kerst（圣诞节，12月25日和26日）。如果国王日是星期日，则为4月26日。Bevrijdingsdag（解放日）只在五年一次的纪念年出现，例如 2025年和 2030年。

年份跟随项目的起止时间：从开始日期的前一年到结束日期的后一年。如果项目没有结束日期，则为开始年份之后最多三年。你可以在*设置 › 项目 › 项目设置*中调整开始和结束日期。

### 项目起止时间变更后重新生成

如果你的项目时间有变动，或结束日期延后，假日就不再覆盖新的年份。应用会在*日历*窗口中提示，例如 *假日覆盖 2025–2028；是否重新生成至 2030（含）？* 然后点击*重新生成*。应用会沿用上次的选择（国家、地区、建筑业假期），为项目所在的年份生成假日。然后点击*应用*。只有之前生成过假日的日历才会显示此提示。

### 添加你自己的休假日或一段休假

1. 在*日历*窗口中，点击*添加假日*。列表底部会出现一个新行，*起始于*下方显示今天的日期。
2. 填写*描述*，例如 *公司团建*。
3. 调整*起始于*。若只是一天，将*至*留空；若是一段时间，填写最后一个休息日，例如冬季休假。
4. 点击*应用*。

点击某一行末尾的垃圾桶图标，即可删除该假日。

### 删除所有假日

在*国家*下选择*无假日*，然后点击*生成*。列表随即为空。

## 注意事项及应用的处理方式

**生成会替换整个列表。** 你自己添加的假日也会消失。之后请重新添加。

**列表中包含耶稣受难日。** 如果你的公司在耶稣受难日或五年一次纪念年的解放日工作，请用垃圾桶图标删除该行。

**建筑业假期的日期仅供参考。** 应用只掌握2025年至2028年（含）的日期；其他年份为粗略估算。因此，选择建筑业假期后，应用会显示 *仅供参考的日期 — 请与 Bouwend Nederland 核实*。如有需要，请在列表中调整这段时间。

**无效的行。** 没有有效*起始于*的行、*至*早于*起始于*的行，或无法识别的日期，都会显示红色提示，例如 *结束日期早于开始日期。* 在你修正之前，*应用*按钮不可用。

**新建项目时。** *新建项目*窗口在*假日集*下提供相同的选项。选择*自定义…*时，你一开始不设假日；创建后会打开*日历*窗口，供你自行填写。
