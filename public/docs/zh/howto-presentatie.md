# 在大屏幕上演示

目标：全屏显示 Gantt 图，不显示功能区和面板。例如，在现场会议中用投影仪或电视显示。

## 何时需要

十个人同时看工地办公室里的同一块屏幕。这时，功能区、状态栏和属性面板会占用计划所需的空间，并且会分散注意力。在 **演示模式** 中，应用只保留任务表和 Gantt 图，并占满整个屏幕。

## 步骤

### 准备视图

在演示模式中没有功能区，所以请事先设置好要显示的内容。

1. 按 **计算**（F5），确保显示的日期正确。
2. 设置要显示的视图，例如只显示关键任务的布局（参见 [创建和使用布局](docs://howto-layouts-gebruiken)）。
3. 选择合适的时间刻度和缩放级别，使任务名称从远处也能看清。然后使用 *视图* 选项卡的 *大纲* 组中的 *折叠* 和 *展开*，折叠或展开各个阶段。
4. 如果要使用，请打开 *拆分视图* 和 *小地图*（参见 [使用拆分视图和小地图](docs://howto-split-view-en-mini-map)）。

### 启动演示

选择 *视图 › 演示 › 演示*。在桌面应用中，你也可以按 F11。在浏览器中，F11 属于浏览器本身：它会让浏览器窗口进入全屏，应用本身保持不变。功能区、选项卡、状态栏和右侧面板会消失。你会看到任务表和 Gantt 图，如果你已打开它们，还会看到直方图和小地图。底部会在几秒钟内显示 *按 Esc 或 F11 退出全屏模式。*

在桌面应用中，你可以在任何选项卡上按 F11 启动演示，也可以从 *表格* 或 *报告* 启动。在浏览器中，你只能通过 *视图 › 演示 › 演示* 启动演示。你始终会看到当前打开项目的 Gantt 图。停止演示后，会回到开始时所在的选项卡。在浏览器中，这个选项卡因此是 *视图*。

### 停止演示

按 Esc 或 F11。功能区和面板会在你开始时所在的选项卡上重新显示。

## 注意事项与应用的行为

**在演示模式中仍然可以编辑。** 点击、拖动、编辑单元格和 Delete 键仍然有效。如果你不小心拖动了一个任务条，它会移动，计划就不再是最新的。你误删的任务可以用 Ctrl+Z 恢复，在演示模式中同样可以。因此，与一组人一起工作时，请仔细点击。

**通知会保持可见。** 应用的消息（例如保存错误）同样会在演示模式中显示。演示模式中没有功能区或状态栏，因此这类消息是唯一能提示出错的迹象。

**请事先设置拆分视图、小地图和布局。** 设置这些需要功能区，而演示模式中没有功能区。也可以缩放，用鼠标滚轮或按 Ctrl+= 和 Ctrl+-。+ 和 - 也可以用，但只有在焦点位于 Gantt 图中时才有效。启动后，焦点通常位于任务表中，所以请先在 Gantt 图中点击。

**全屏可能无法生效。** 除了隐藏功能区，应用还会真正请求进入全屏。如果你的浏览器或窗口拒绝该请求，则只会隐藏功能区和面板。演示仍然可以正常使用。如果你不是用 Esc 或 F11 退出全屏，例如用操作系统的某个按键退出，演示模式也会随之停止。

**演示模式不会被记住。** 关闭并重新打开应用后，演示模式为关闭状态。
