# 崩溃后恢复

目标：应用或浏览器意外停止，而你尚未保存时，取回你的工作。

## 何时需要本文

笔记本电脑死机、应用冻结，或浏览器标签页崩溃，而你尚未保存最近的更改。只要任何地方有更改，应用就会在后台为你所有打开的项目保留恢复副本，最多每十秒一次。该副本与项目文件是分开的。保存与自动保存的区别，请阅读[文件和格式](docs://uitleg-bestanden)。

## 步骤

1. 再次启动应用。在浏览器中，重新加载同一个标签页：恢复副本属于这一个标签页。
2. 如果应用找到了副本，会出现 *恢复未保存的工作* 窗口。窗口内容为：*Open Planner Studio 未正常关闭。以下文档存在可恢复的未保存更改：* 对每个项目，窗口显示名称；如果项目有文件，则显示文件路径（在浏览器中只显示文件名）；还显示任务数量和副本的时间，例如 *21 个任务* 和 *已保存：Sep 29, 2026 9:41 AM*。时间按你的 *时间格式* 设置显示。窗口也可能显示你未更改过的项目。
3. 选择 *恢复*。应用会打开列表中的所有项目，每个项目在一个标签页中，并带有最后一个副本的状态。按 Enter 键的效果相同。
4. 检查你的项目，并立即用 Ctrl+S 保存。

如果你不想恢复，有两个选项。*不恢复* 会删除这些副本，而且你无法撤销此操作。如果你按 Esc 键、点击叉号，或点击窗口外部关闭窗口，副本会保留，应用会在下次启动时再次询问。

窗口右上角的问号会打开本文，但不做任何选择。在你阅读帮助时，窗口会等待。你返回后，窗口会再次出现，你仍可以恢复。

## 注意事项及应用随后的处理

**你获得的是最后一个副本的状态。** 崩溃前最后几秒所做的操作可能会丢失。有更改的项目会再次标记为 *未保存*。*撤销* 历史为空：你无法撤销崩溃前的步骤。缩放、滚动位置和选择会重新建立。

**在桌面端，恢复的项目保留其文件；在浏览器中则不保留。** 在桌面端，*保存* 会将恢复后的状态写入原始文件。在浏览器中，恢复的项目不再关联其文件：*保存* 会询问文件应存放的位置。在你至少保存过该项目一次之前，*自动保存* 开关也是灰色的。

**处于 *按记录的日期* 视图中的项目会保持在该视图中。** 请参阅 [按记录的日期](docs://uitleg-datums-zoals-opgeslagen)。

**在桌面端，并非每次启动后都会出现该窗口。** 恢复副本位于应用的数据文件夹中，为 IFC 文件，文件名以 *recovery* 开头。如果你以正常方式关闭应用，它会清除自己的副本。因此，窗口会在以下情况出现：应用意外结束后；为应用更新而重新启动后；或你在上一次启动时推迟了恢复。

**在浏览器中，副本按标签页保存。** 副本保存在浏览器的存储中。新标签页或新窗口不会提供另一个标签页的副本。不再存在的标签页的副本，会在应用再次写入副本时，于七天后清除。

**在浏览器中，普通重新加载后，窗口也会出现。** 即使你已保存所有内容，也会出现。如果你在重新加载前刚保存，之后没有做任何更改，可以放心选择 *不恢复*：你的文件是最新的。

**窗口没有出现。** 这表示应用没有找到副本。原因可能是：你还没有做任何更改；你在浏览器中使用了新标签页；你之前已用 *不恢复* 丢弃了恢复副本；或崩溃发生在应用保存第一个副本之前。保存第一个副本最多可能需要约十秒，从你的第一次更改开始计算。

**副本已损坏。** 应用会报告 *无法读取恢复的文件*，并附上原因，同时仍可恢复其他项目。如果你选择 *恢复*，应用之后会删除所有副本，包括无法读取的那个。如果没有任何副本可读，窗口不会出现，副本会保留。

**恢复失败。** 应用会报告 *恢复失败* 并附上原因。副本会保留，下次启动时会再次询问。

**部分项目无法加载。** 应用会报告：*有 2 个恢复文件无法加载，已被跳过。* 如果只有一个文件，它会显示 *有 1 个恢复文件无法加载，已被跳过。* 其他项目会被恢复。由于有内容被跳过，所有副本都会保留，窗口会在下次启动时以相同列表再次出现。如果你已取回所有能取回的内容，请选择 *不恢复*。
