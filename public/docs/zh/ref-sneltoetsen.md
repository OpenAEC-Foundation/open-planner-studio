# 键盘快捷键

应用的所有组合键，按 *键盘快捷键* 窗口中的分组列出。按键是固定的：你无法重新绑定。如何使用鼠标和菜单，请见操作指南；在这里，你可以查找某个按键。

## 如何阅读此列表

**Mac。** 本文中凡是写 Ctrl 的地方，在 Mac 上请使用 Cmd (⌘)。Alt 即 Option (⌥)。在 Mac 上，*键盘快捷键* 窗口会显示符号 ⌥、⇧ 和 ⌘，而不是 Alt、Shift 和 Ctrl。在 Mac 上，应用中 Ctrl 同样有效。

**完全相同的组合。** 应用会精确比较 Ctrl、Shift 和 Alt。因此 Ctrl+Alt+S 不会有任何作用：按键必须与列表完全一致。

**打开窗口。** 按 Ctrl+/，或选择 *设置 › 键盘快捷键 › 键盘快捷键*。Ctrl+/ 也可以再次关闭窗口。该窗口为只读。它不显示这里列出的所有按键：表格按键中只显示前六项，不显示本文末尾的对话框按键。

**按键不起作用时。** 每一项都写明了其限制。以下三条规则几乎适用于所有情况：

- 在输入字段、下拉列表或文本框中，应用不会拦截按键，因此你可以直接输入。例外：F5、Ctrl+S、F11 和演示期间的 Esc 在字段中同样有效。如果焦点在关闭的下拉列表上，带 Ctrl 的按键同样有效，例如选择后按 Ctrl+Z（但不包括 Ctrl+Delete 和 Ctrl+Backspace）。在展开的列表或对话框中则不然。在正式版应用中（桌面版和网站上的网页版），Ctrl+Shift+S、Ctrl+O 和 Ctrl+N 同样如此。
- 当对话框或其他窗口打开时，下文标有 *对话框中不可用* 的按键无效。导览、欢迎对话框以及等待回答的问题（例如是否保存更改的询问，或安装扩展时的同意确认）同样如此。在演示模式下，这些按键大多也无效。例外：编辑按键 Ctrl+C、Ctrl+V、Ctrl+Z、Ctrl+Y 和 Delete/Backspace 在演示期间仍然有效。
- 在 *文件 › 项目设置* 中有尚未用 *应用* 确认的更改时，文档切换（Ctrl+1 至 9、Ctrl+N、Ctrl+O）同样无效。请先放弃或应用这些更改。

## 文件

**F5** — *计算*：重新计算计划，效果与 *计算* 按钮相同（*首页 › 进度 › 计算*）。在输入字段中同样有效。

**Ctrl+S** — *保存*：保存项目。在输入字段中同样有效。

**Ctrl+Shift+S** — *另存为*：询问文件应保存到何处。在开发版本中，它在输入字段中无效。

**Ctrl+O** — *打开*：打开文件，通常在新选项卡中打开。对话框中不可用，且有未应用的项目设置时也不可用。

**Ctrl+N** — *新建项目*：打开 *新建项目* 窗口。对话框中不可用，且有未应用的项目设置时也不可用。

正式版应用（桌面版和网站上的网页版）也会屏蔽一些浏览器按键，使它们不会造成干扰：Ctrl+R 和 Ctrl+Shift+R（重新加载）、F12、Ctrl+Shift+I 和 Ctrl+Shift+J（开发者工具）、Ctrl+U（查看源代码），以及 Ctrl+G、Ctrl+F 和 Ctrl+L（查找和地址栏）。Ctrl+S、Ctrl+Shift+S、Ctrl+O、Ctrl+N 和 F5 由应用本身处理。

## 编辑

**Ctrl+C** — *复制*：复制所选任务。仅在有选择时可用。对话框中不可用。在 *文件* 中、在 *报告* 和 *IFC* 选项卡上，以及完整资源面板打开时不可用。在任务表中，Ctrl+C 复制所选单元格；这由任务表自行处理。

**Ctrl+V** — *粘贴*：粘贴已复制的任务。对话框中不可用。在 *文件* 中、在 *报告* 和 *IFC* 选项卡上，以及完整资源面板打开时不可用，因为那里看不到任务表。在任务表中，它粘贴单元格。

**Ctrl+Z** — *撤销*。对话框中不可用：请先关闭窗口。

**Ctrl+Y** 或 **Ctrl+Shift+Z** — *重做*：重复你撤销的操作。对话框中不可用。

**Delete** 或 **Backspace** — *删除*：删除所选任务。仅在有选择时可用。对话框中不可用。在 *文件* 中、在 *报告* 和 *IFC* 选项卡上，以及完整资源面板打开时不可用，因为那里看不到任务表。在任务表的单元格中，Delete 和 Backspace 只清除单元格内容（见 *表格*）。

**F2** — *编辑...*：为第一个所选任务打开任务对话框。仅在有选择时可用。对话框中不可用。在任务表的单元格中，F2 开始编辑该单元格。

**Ctrl+A** — *全选*：选择所有任务。对话框中不可用。

**Esc** — *取消选择*：取消选择，同时关闭关系模式、拆分任务模式和路径追踪，并关闭任务对话框和项目概览。在演示期间，Esc 只关闭演示（见 *视图*）。在输入字段中，Esc 不执行以上任何操作。

## 结构

**Alt+Shift+→** 或 **Alt+→** — *降级*：使所选任务在 WBS 中降低一级。仅在有选择时可用，对话框中不可用。

**Alt+Shift+←** 或 **Alt+←** — *升级*：将所选任务提升一级。仅在有选择时可用，对话框中不可用。

降级、升级以及在所选任务上方或下方插入，只在普通树形视图中有效：没有筛选、分组或排序。在其他视图中，应用会用消息拒绝这些操作，因为此时显示的顺序不是项目的顺序。没有选择时插入，在每个视图中都有效。

**Insert** — *在上方插入*：在最上方的所选任务上方插入新任务，且与其同级。没有选择时，任务会放在底部，在每个视图中都是如此。对话框中不可用。

**Ctrl+I** — *在下方插入*：在最下方的所选任务下方插入新任务，且与其同级。没有选择时，任务会放在底部。对话框中不可用。

**Ctrl+M** — *添加里程碑*：即使已选中任务，也会在列表底部添加新的里程碑。对话框中不可用。

**Alt+↑** — *上移任务*：在所在级别内，将第一个所选任务上移一位。仅在有选择时可用，对话框中不可用。

**Alt+↓** — *下移任务*：相同操作，下移一位。

## 视图

**F11** — *演示*：开启或关闭演示模式。应用还会请求窗口进入全屏。在输入字段中同样有效。在浏览器中，F11 不会启动演示：浏览器会自行将窗口切换为全屏，应用保持不变。在浏览器中，F11 会停止正在进行的演示。

**Esc**（演示期间）— *退出演示*。在输入字段中同样有效。此操作优先于 *取消选择*。

**Ctrl+=** — *放大*：以固定步长放大时间轴。在输入字段中不可用。

**Ctrl+-** — *缩小*：以固定步长缩小。

**+** 或 **=** — *放大*：以 Gantt 区域的中间为中心放大 10%。在输入字段中不可用，且只有 Gantt 时间轴可见时才有效（因此在 *表格*、*IFC* 和 *报告* 选项卡上无效）。

**-** — *缩小*：缩小 10%。限制相同。

**0** — *重置缩放*：将缩放恢复为默认值，并滚动到起点。限制相同。

**Ctrl+0** — *适应项目*：缩放至整个项目都在视野内。限制相同。

**Ctrl+/** — *显示快捷键*：打开或关闭 *键盘快捷键* 窗口。在其他对话框打开时也有效，但在导览和欢迎对话框期间无效。

**Ctrl+Shift+H** — *直方图*：开启或关闭直方图，效果与 *直方图* 按钮相同（*资源 › 直方图 › 直方图* 或 *视图 › 面板 › 直方图*）。应用会记住你的选择。

**Ctrl+Shift+L** — *警告*：开启或关闭警告面板，效果与 *警告* 按钮相同（*视图 › 面板 › 警告* 或 *计划 › 进度 › 警告*）。

## 导航

**Ctrl+P** — *转到报告选项卡*：带你到 *报告* 选项卡。因此它不是打印命令。对话框中不可用。

**F1** — *打开帮助*：打开 *文件 › 帮助*。在输入字段和对话框中不可用。在窗口中，使用右上角的问号：它会打开关于该窗口的帮助文章（见 [功能区，按选项卡分列](docs://ref-lint)，在 *帮助* 下）。

**Ctrl+1** 至 **Ctrl+9** — *切换文档*：切换到第一至第九个已打开的文档。如果该文档不存在，则不会发生任何变化。对话框中不可用，且有未应用的项目设置时也不可用。

**Ctrl+Home** — *跳转到今天*：滚动时间轴，使某个日期位于视图左侧。若你设置了状态日期，则该日期为状态日期，否则为今天。因此，即使时间轴跳到状态日期，标签仍写着“今天”。缩放和时间轴起点保持不变。若任务表的某个单元格有焦点，Ctrl+Home 则会改为跳到任务表的第一个单元格（见 *表格*）。

## 表格

当单元格有焦点时，这些按键可用于任务表（在 *表格* 选项卡上，以及 Gantt 左侧的表格中）。*键盘快捷键* 窗口显示前六项，其余项不在其中。

**Tab** 和 **Shift+Tab** — *下一个/上一个单元格*：移到下一个或上一个单元格；在行末则移到下一行。在最后一个单元格（Tab）或第一个单元格（Shift+Tab）上，焦点会离开任务表。

**Enter** 或 **F2** — *编辑单元格*：打开单元格的编辑器。若单元格为只读，任务表会显示一条消息。

**字母、数字或其他字符** — *输入将替换单元格内容*：开始编辑，并用你输入的内容替换原有内容。

**Insert** — *在上方插入*：在当前行上方插入任务。

**Delete** 或 **Backspace** — *清除单元格内容*：清除所选单元格的内容，而不是任务本身。*键盘快捷键* 窗口只列出 Delete。

**Esc** — *取消选择*：将焦点移到整个任务表，使下一次 Tab 离开任务表，并且如上所述同时清除选择。

**方向键** — 移到上方、下方、左侧或右侧的单元格。加上 Shift 可扩展选择。

**Home** 和 **End** — 移到该行的第一列或最后一列。加上 Ctrl 时，移到第一行的第一个单元格和最后一行的最后一个单元格。加上 Shift 可扩展选择。

**Page Up** 和 **Page Down** — 向上或向下移动一个屏幕高度。加上 Shift 可扩展选择。

**Enter**（编辑时）— 确认输入，并移到下一行的同一列。Shift+Enter 移到上一行。

**Esc**（编辑时）— 取消编辑，不保留输入的内容。

资源表在输入字段之间有自己的按键处理；本列表不包含这些按键。

## 对话框和其他窗口

这些按键不在 *键盘快捷键* 窗口中。

**Esc** — 关闭最上层的对话框（取消）。在 *文件*（后台）中同样如此：Esc 会关闭该界面，除非最上层是对话框或已展开的下拉列表。

**Enter** — 确认最上层的对话框，效果与主按钮相同（支持该功能的对话框）。在多行文本框、已展开的下拉列表中或输入法输入期间，Enter 不会这样做。

在 Gantt 中做手势时按 **Esc** — 取消框选（选择保持原状）和拆分手势（应用会撤销已完成的拆分）。

关系类型选择器中的 **Enter** 和 **Esc** — Enter 确认，Esc 取消。

在任务表与时间轴之间的分隔线上，**左方向键**和**右方向键** — 每次移动分隔线 10 像素，加上 Shift 则移动 40 像素。分隔线必须有键盘焦点。

直方图的资源列表中，**上方向键**和**下方向键** — 选择上一个或下一个资源。直方图区域必须有焦点。
