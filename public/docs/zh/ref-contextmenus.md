# 右键菜单

本页说明在 Gantt 和任务表中按下鼠标右键会打开哪些菜单、每个菜单项的作用，以及它作用于哪些任务。同时也有按钮或快捷键的菜单项，见 [功能区，按选项卡](docs://ref-lint) 和 [键盘快捷键](docs://ref-sneltoetsen)。

## 在哪里出现哪个菜单

共有四种菜单。出现哪一种取决于你点击的位置：

- **在 Gantt 中的任务条上** — 任务菜单，顶部有 *从此处开始建立关系*。
- **在任务表中的任务上** — 同一个任务菜单，但顶部没有该项。这适用于 Gantt 左侧的任务表，以及 *表格* 选项卡。
- **在任务表中的分组标题上** — 一个小菜单，用于展开和折叠分组。只有分组时才会出现分组标题，例如使用 *资源图* 布局时。
- **在空白处** — 在 Gantt 中，任务条旁边或下方；在任务表中，最后一个任务下方，或灰色的 *新任务* 行上。菜单中有 *新建任务*、*添加里程碑* 和 *粘贴*；在 Gantt 中还有 *重置缩放* 和 *适应项目*。新任务或里程碑会加到列表底部。在 Gantt 中，它从你点击的日期开始；在任务表中，名称单元格会立即打开，方便你直接输入。

在 Gantt 中分组标题的条带上，右键会打开空白处的菜单。分组标题本身只在任务表中有菜单。在时间轴标题上右键没有任何作用。任务表的列标题有自己的菜单，见 [调整表格列](docs://howto-tabelkolommen-aanpassen)。

**菜单项作用于哪些任务？** 你点击一个任务，但选择范围由选中的任务决定。如果你点击的任务属于选择范围，该项作用于整个选择。如果不属于，则只作用于该任务。在 Gantt 中右键点击任务条，或在任务表中右键点击一行时，如果该任务不在选择范围内，它会替换原来的选择。每个会更改内容的菜单项都是 *撤销* 中的一步，整个选择也是如此。

## 任务菜单

菜单项按以下顺序排列。组与组之间的横线是菜单中的分隔线。

**从此处开始建立关系** — 只在 Gantt 中的任务条上可用。选中该任务并开启关系模式；然后拖动到后续任务。见 [添加关系](docs://howto-relaties-leggen)。

**取消中断** 和 **取消所有中断** — 只在 Gantt 中、带有中断的任务条上可用。*取消中断* 只在你点击某个暂停或其后的部分，并且该中断可编辑时出现；它只删除该处暂停。*取消所有中断* 会删除全部中断，包括来自你无法编辑的源文件中的中断。见 [拆分任务](docs://howto-taak-splitsen)。

**编辑...** — 打开该任务的 *编辑任务* 窗口。见 [任务对话框和属性面板](docs://ref-taak-eigenschappen)。

**在上方插入** 和 **在下方插入** — 在作用范围最上面的任务上方，或最下面的任务下方，插入一个新任务，层级相同。只在纯树形视图中有效，不能有筛选、分组或排序；否则应用会拒绝并显示一条消息。见 [添加任务和里程碑](docs://howto-taken-en-mijlpalen-toevoegen)。

**添加子任务** — 将新任务添加为你点击的任务的子任务，放在其子任务的最下面。只作用于该任务，不作用于整个选择。

**添加里程碑** — 将里程碑添加为你点击的任务的子任务。只作用于该任务。

**添加关系** — 与 *从此处开始建立关系* 相同：选中该任务并开启关系模式。在任务表中，如果 Gantt 不可见，该项会被禁用，提示为 *仅在显示甘特图时可用*。

**降级** 和 **升级** — 在 WBS 中将作用范围内的任务降低一级或升高一级。这两项只在纯树形视图中出现。见 [调整结构](docs://howto-structuur-aanpassen)。

**切换里程碑** — 将任务变为里程碑，或再变回来。新状态由你点击的任务决定，并作用于整个范围：如果该任务是普通任务，范围内的所有任务都会变为里程碑。摘要任务和带有分配的任务不会变为里程碑；范围内的其他任务会变，并且每种原因都会显示一条消息。

**分配日历 ▸** — 子菜单，包含 *项目日历*（任务随后没有自己的日历），其下列出可用的日历。当前选择带有对勾标记。已经使用该日历的任务不计入，也不会产生额外的 *撤销* 步骤。见 [创建并分配日历](docs://howto-kalender-maken-en-toewijzen)。

**进度 ▸** — 子菜单，包含 0%、25%、50%、75% 和 100%。当前值带有对勾标记。摘要任务没有自己的进度：如果范围内有摘要任务，则其末级任务会获得该百分比。没有状态日期时，应用会将其设为今天，并显示一条消息。如果某任务的计划的开始日期晚于状态日期，并且尚无实际开始日期，则会先询问实际开始日期；如果你取消，则不会有任何更改。见 [更新进度](docs://howto-voortgang-bijwerken)。

**优先级 ▸** — 子菜单，包含 *低*（100）、*普通*（500）和 *高*（900），即任务的资源平衡优先级。当前值带有对勾标记。见 [资源平衡](docs://uitleg-nivelleren)。

**路径追踪** — 显示该任务的前置任务和后续任务。如果追踪已经开启，该项会显示为 *停止路径追踪*。见 [追踪路径](docs://howto-pad-traceren)。

**折叠**、**展开** 和 **将分支保存为模板** — 只用于摘要任务。*折叠* 和 *展开* 总是两者都显示，即使该任务已经折叠或展开，并且作用于整个范围。*将分支保存为模板* 会将任务及其子任务，以及它们之间的关系，保存为 WBS 模板。见 [保存和插入 WBS 模板](docs://howto-wbs-sjablonen)。

**删除** — 删除范围内的任务及其子任务。没有确认提示；你可以用 Ctrl+Z 恢复它们，整个范围算作一步。见 [选择、删除和撤销任务](docs://howto-taken-selecteren-verwijderen)。

## 分组标题的菜单

此菜单只在任务表中的分组标题上出现：

**折叠分组** 或 **展开分组** — 只折叠或展开该分组。该项会显示你可以执行的操作。

**全部展开** 和 **全部折叠** — 一次展开或折叠所有分组。

你使用布局设置分组，见 [创建和使用布局](docs://howto-layouts-gebruiken)。
