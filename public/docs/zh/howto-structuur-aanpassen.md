# 调整结构

目标：将任务安排为阶段和子任务，更改它们的顺序，并保持 WBS 编号正确。

## 何时需要这样做

你的计划是一棵树：阶段（摘要任务）下方有子任务，例如 *Foundation* 下有 *Groundwork*、*Reinforcement* 和 *Pouring*。当你想把任务挂到某个阶段下、把任务移出某个阶段，或者顺序有误时，你就需要调整这棵树。**WBS 编码**（1, 1.1, 1.2, 2, …）是任务在这棵树中的编号。

## 操作步骤

### 降级任务

1. 选择任务。选择多个任务也可以。
2. 选择 *计划 › 结构 › 降级*。你也可以使用 Alt+→（或 Alt+Shift+→），或使用右键菜单中的 *缩进*。

任务会成为同一级上一个任务的最后一个子任务。因此，上一个任务会变成摘要任务。如果你选择一组连续任务，整组任务会一起降级。如果该任务在同一级没有上一个任务，则不会发生任何变化，也不会显示任何消息。

### 升级任务

选择 *计划 › 结构 › 升级*，按 Alt+←（或 Alt+Shift+←），或在右键菜单中选择 *取消缩进*。

任务会成为它原来所属阶段之后紧邻的同级任务。它自己的子任务会随之移动。该阶段中排在它后面的任务仍留在该阶段内。顶层任务不能再升级。

### 移动任务

有三种方法。

- **用键盘。** Alt+↑ 和 Alt+↓ 会将任务与同一级的相邻任务交换位置。摘要任务会带着其子任务一起移动。在该级的顶部或底部，不会发生任何变化。选择了多个任务时，只移动你先点击的那个任务。
- **在任务表中拖动。** 在某一行上按下并垂直拖动。行的上四分之一表示 *之前*，下四分之一表示 *之后*。摘要任务的中间部分会将任务挂在它下面，作为其最后一个子任务。普通任务的中间部分会归到离它最近的那一边。如果你拖动的行属于多选的一部分，则整个选择都会移动。
- **在 Gantt 中拖动。** 将任务条垂直拖到另一行。这与在任务表中拖动的效果相同，不会更改任何日期。如果你水平拖动，则会改为移动日期。

每次移动都是 *撤销*（Ctrl+Z）的一步。

### 保持 WBS 编号为最新

查看 *计划 › 结构* 中的 *WBS auto* 按钮。

- **开（新项目中的默认值）。** 打开一个没有此设置的文件后，若所有 WBS 编码已与树的编号一致（1、1.1、1.2 …），该设置也会变为 *开*。编码不会更改。没有此设置的空文件同样会变为 *开*，与新项目一样。应用会在每次添加、删除和移动后为整棵树重新编号。此时 WBS 编码为只读：你无法在任务表或 *属性* 面板中输入它。*重新编号 WBS* 已禁用。
- **关。** 在带有自己编码的文件中（例如编码为 *A1000* 的文件），或在某个编码与树不一致的文件中，默认值为 *关*。编码保持原样，移动和降级之后也一样。你自己输入编码：在 *WBS* 列中，或在 *属性* 中的 *WBS 编码* 字段中。也可以使用 *重新编号 WBS*，让编码重新编号一次。这也会覆盖你自己输入的编码。

如果你将 *WBS auto* 开启，应用会立即为整棵树编号。*WBS auto* 和 *重新编号 WBS* 都可以用 *撤销* 撤回。

## 注意事项与应用的行为

**筛选、分组或排序已开启。** 此时你看到的顺序不是计划中的顺序，因此应用会锁定结构。*降级* 和 *升级* 已禁用，提示文字为 *筛选/分组/排序时不可用*。Alt+→ 和拖动会在一个红色提示条中显示同样的文字，并带有 *清除* 按钮。该按钮会一次性移除筛选、分组和排序，Ctrl+Z 无法将它们恢复。该提示条会一直显示，直到你点击叉号、按 Ctrl+Z 或 Ctrl+Y，或切换到另一个文档。此时右键菜单中没有 *缩进* 和 *取消缩进*。

在这种视图中，Alt+↑ 和 Alt+↓ 仍然可以使用，且不会显示任何消息。只有筛选时，你会立即看到新的顺序。使用排序时，计划中的顺序确实会改变，但只有在 *清除* 之后你才能看到。

**WBS auto 为关。** 这种情况发生在带有自己编码的文件中，或在将该设置保存为 *关* 的文件中。新任务会得到符合其在树中位置的编码，即使另一个任务已有该编码。这样可能出现重复编号。降级之后，编码也会与树不再相符。*重新编号 WBS* 可以同时修正这两种情况。

**里程碑获得了子任务。** 里程碑是一个时间点，没有子任务。应用会移除里程碑标记，并通知你。

**带有资源分配的任务获得了子任务。** 摘要任务本身不携带分配。因此，应用会先在 *任务变为摘要任务* 窗口中询问如何处理这些分配。这发生在以下情况：降级任务、在任务上使用 *添加子任务* 或 *添加里程碑*、插入模板，以及在 *编辑任务* 中为任务选择新的 *父任务* 时（适用于现有任务和新任务）。在 *编辑任务* 中，询问会在保存之前出现。如果你在此处选择 *取消*，*编辑任务* 会保持打开，并保留你的更改。你可以选择：

- *取消*：什么都不会更改，结构也保持原样。
- *删除分配*：任务获得子任务，其分配会被删除。这些分配的实际工时也会一并删除。
- *移动到 '…'*：分配会连同其实际工时移到第一个能承载它们的新子任务上。里程碑或摘要任务不能承载分配。

如果该子任务已有相同的资源，或没有合适的子任务，*移动* 会被禁用。橙色区块会说明原因。

如果某个分配已有实际工时，橙色区块会按每个资源列出工时数，例如 *Metselaar 的分配已记录 8 小时的实际工时。删除会丢弃这些工时。* 此时 *取消* 是默认按钮：按回车键不会更改任何内容。如果你仍要删除该分配，请自己点击 *删除分配*。

窗口打开时，窗口外的快捷键都不起作用，包括 *撤销*、*粘贴*、删除键、F5 和 Ctrl+S。如果一个操作同时创建了多个摘要任务，窗口会按任务列出资源，你的选择适用于所有这些任务。一次 *撤销*（Ctrl+Z）会撤回整个操作。

**关系会形成循环。** 摘要任务的关系同样适用于其子任务。如果移动因此会形成循环，应用会拒绝该移动，并显示消息 *此移动会在计划中形成循环（…）*。不会发生任何变化。

**任务与其所属阶段之间的关系。** 如果你将任务放到一个它已与之存在关系的阶段下，该关系会保留，但不再计入计算。应用会通知你。你可以在 [关系与延隔](docs://uitleg-relaties) 中阅读更多关于摘要任务上关系的内容。

**计划已过时。** 移到另一个阶段可能会改变日期。请按 **计算**（F5）。仅在同一阶段内交换顺序，则不需要这样做。
