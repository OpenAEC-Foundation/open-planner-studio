# 更新应用

目标：确认你是否使用最新版本，更新应用，并阅读某个版本的新内容。

## 何时需要这些内容

Open Planner Studio 会定期发布新版本。你可能想确认自己是否已经有新版本，例如在报告错误之前，或者因为某个扩展需要更新的版本。也可能你刚刚完成更新，想看看有哪些变化。

只有桌面应用才能更新。浏览器版没有更新程序。

## 步骤

### 当应用本身提示有新版本时更新

1. 启动桌面应用。启动时，应用会在后台检查是否有新版本。如果没有新版本，或检查失败（例如没有网络连接），你不会注意到任何变化。
2. 如果有新版本，会打开 *软件更新* 窗口。窗口会显示 *当前版本*、*新版本*、消息 *有新版本可用*，以及 *更新内容* 下与此次更新相关的文字。
3. 保存你打开的项目。
4. 点击 *下载并安装*。进度条会显示 *正在下载…*，然后开始安装。下载期间不能关闭窗口。
5. 等待应用自动重启。这就是新版本。

在安装更新之前，应用还会为你打开的工作内容创建一份恢复快照（用于崩溃恢复），详见 [从崩溃中恢复](docs://howto-herstellen-na-een-crash)。

### 自行检查新版本

1. 选择 *设置 › 项目 › 应用设置*。你也可以选择 *文件 › 应用设置*，或顶部的齿轮图标。
2. 选择 *高级* 标签页。在 *版本* 下方显示你当前使用的版本号。
3. 点击 *检查更新*。会打开 *软件更新* 窗口，并显示 *正在检查…*。之后会显示 *您正在使用最新版本*，或显示有新版本的消息，同时还有相同的 *下载并安装* 按钮。

在浏览器中，这个按钮没有特别作用：窗口会立即显示 *您正在使用最新版本*，而应用不会检查任何内容。

### 阅读更新内容

1. 如果你第一次以不同于上次的版本启动桌面应用，窗口会自动打开，标题为 *已更新到最新版本！*。全新安装后的第一次启动不会打开此窗口，因为那不是更新。如果你仍想查看它，请使用 *更新内容* 按钮（见下文）。
2. 顶部显示从上一个版本到新版本的变化。使用 *更新内容* 按钮时，只显示新版本。
3. 如果应用为该版本内置了概要，你会看到一个主要要点和四个较小的要点。主要要点可能带有 *阅读指南* 按钮。否则你只会看到版本变化以及下方的内容。
4. 点击 *查看完整发行说明*，在 GitHub 上打开更新日志。如果无法打开，会显示 *无法打开发行说明。*
5. 在 *本次更新数据* 下显示：距离上一次发布的天数、提交次数，以及新增代码行数。如果应用能查到安装包大小的变化，也会显示。每项数字只在可用时显示。
6. 点击 *知道了* 关闭窗口。

如果你以后想再次查看此窗口，请选择 *设置 › 项目 › 应用设置*，进入 *高级* 标签页，然后在 *版本* 下点击 *更新内容* 按钮。窗口会显示你当前版本的内容，不显示上一版本。

## 可能遇到的问题及应用的处理方式

**更新失败。** 窗口会显示 *更新时出现问题*，下方是技术原因，还有 *重试* 按钮。

**你通过 .deb 软件包安装了应用，而且安装失败。** 窗口会说明：*在终端中运行此命令以手动更新，或下载最新的软件包。* 在 *安装命令* 下方是该命令，并有 *复制命令* 按钮（之后会显示 *已复制*）。点击 *打开下载页面*，即可前往最新版本的下载页面。

**你通过 Snap Store 安装了应用。** 此时应用不会自行更新，启动时也不会检查。这些由 Snap Store 完成。窗口中会显示 *此版本通过 Snap Store 自动更新 — 您无需执行任何操作。*

**启动时没有显示任何内容。** 如果你已经是最新版本，这是正常的。启动检查不会报告错误。如果你想确认自己是最新版本，请按上文所述自行检查。
