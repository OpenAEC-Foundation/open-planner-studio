# Resourcekalender

**资源日历**窗口编辑单个资源的自有日历——例如每周工作四天的班组。该表单与[日历对话框](docs://ref-kalenderdialoog)相同；本文只描述其中的差异。

## 打开方式

- 打开资源面板：**资源** → **管理**功能区组 → **资源**（完整面板）或**资源停靠栏**（停靠在甘特图旁边）。
- 在资源的**日历**列中，选择一个日历并点击旁边的铅笔图标（**编辑…**）进行编辑；通过同一个下拉菜单创建新日历。

## 与日历对话框的区别

- **一次一个日历** — 左侧没有库列表，也没有项目默认星标；只有表单。
- **应用**保存日历；**取消**、**Esc**、关闭图标或点击窗口外部会放弃更改。通过下拉列表中的 **+ 资源日历** 新建的日历只有在**应用**之后才会存在，并随即关联到该资源（合起来是一步撤销）；**取消**之后不会留下任何东西。它的初始设置与日历对话框中的 **+** 相同。
- **没有自动重新计算** — **应用**不会重新计算计划。作为资源日历，日历不会改变 CPM 日期；它计入负荷（直方图）和平衡，您需要分别通过 F5 或**平衡…**自行重新运行。不过下拉列表提供项目中的所有日历：如果您在这里编辑的日历同时也是项目日历或某个任务的日历，计划确实会改变。此时计划会被标记为已过期，按 F5 重新计算。

## 字段

完整字段参考请参见[日历对话框](docs://ref-kalenderdialoog)：**名称**、**工作日**（带有周一至周五和连续（24/7）预设）、**开始（时）** / **结束（时）** / **每日工时**、**工作时间**部分（小时计划开启时）、**生成假日…**和**假日**列表。
