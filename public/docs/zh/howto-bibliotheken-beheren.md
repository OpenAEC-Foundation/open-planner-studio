# 管理和共享资源库

目标：创建和删除资源库，将日历放入资源库，并导出或导入资源库，用作备份或在另一台电脑上使用。

## 何时需要

资源库不在你的项目文件中，而是在应用里：在桌面应用中保存为本机上的一个文件，在浏览器中保存在该浏览器的存储空间里。资源库不会同步。如果你清除浏览器中的网站数据，资源库就没有了，因此请将其导出作为备份。如果同事想使用相同的班组和费率，你也要以文件形式把资源库交给他。如果你的组织有多个运营公司，各自有自己的班组，请为每个公司建立单独的资源库。新建项目时，你选择它使用哪个资源库。

资源库是什么，请阅读[资源库](docs://uitleg-resourcebibliotheek)。你不在这里编辑资源本身，而是在资源面板中编辑，参见[使用资源库](docs://howto-resourcebibliotheek-gebruiken)。

## 步骤

### 打开管理界面

选择 *文件 › 资源库*。左侧是列表 *资源库*。右侧是你点击的资源库的详细信息：名称、按钮，以及列表 *日历*。顶部提示你可以在 *资源* 选项卡中管理资源。

### 创建、重命名并选择默认资源库

1. 点击列表上方的加号（*添加资源库*）。随即添加资源库 *新建资源库*，并立即选中它。
2. 在右侧顶部的名称框中输入新名称，然后按 Enter，或点击框外任意处。应用不接受空名称。
3. 点击 *设为默认*，之后新项目会预先选择此资源库。默认资源库在列表中带有星标。

### 将日历放入资源库

1. 在 *日历* 下方，点击 *从项目*。随即打开一个列表，其中显示当前活动项目的日历。
2. 点击要添加的日历后面的小箭头。列表上方会显示 *已添加。* 已经关联到此资源库的日历，名称后面会显示 *已关联*。
3. 该日历现在位于资源库的 *日历* 列表中。点击铅笔（*编辑*）可以更改名称，点击勾号保存。点击垃圾桶会立即删除该日历，不会要求确认。项目中的副本保留。

在 *日历* 下方有一个版本号，例如 *v2*。每次更改资源库，版本号都会增加。当你分配使用该日历的资源时，资源库日历会随之进入项目。你在 *资源* 的 *资源库* 视图中，在 *日历* 列里将它关联到资源。

### 导出资源库

1. 在列表中选择资源库。
2. 点击 *导出*。
3. 在桌面应用以及 Chrome 和 Edge 中，你选择文件的保存位置。在其他浏览器中，文件会直接保存到下载文件夹，应用会告诉你。文件名为 `bibliotheek-` 加上资源库的名称，后缀为 `.ifc`。

按钮下方会显示 *导出同时也是备份：请将文件妥善保存。*

### 导入资源库

1. 点击 *导入*。窗口 *导入资料库* 会针对你在列表中选中的资源库打开。
2. 点击 *选择文件*…，然后选择导出的 `.ifc` 文件。如果该文件不包含资源库，会显示 *该 IFC 文件不包含资源库。*
3. 应用会显示文件内容，例如 *2 个日历，5 个资源（版本 3）。*
4. 选择你要对文件执行的操作，见下文。
5. 点击 *添加* 或 *替换*，或点击 *取消* 停止操作。

你有两种选择：

- *添加为新的资源库*：该文件成为与现有资源库并列的单独资源库。下方会显示将使用的名称，例如 *将添加为“Mijn resourcebibliotheek (2)”。* 不会丢失任何内容，你当前的项目仍关联其自身的资源库。
- *替换现有资源库*：所选资源库的全部内容会被文件中的内容替换。窗口中也有说明：*导入将替换所选资源库的整个资源池。* 如果你有两个或更多资源库，请在 *导入到资源库* 下选择要替换的资源库。如果你的资源库比文件新，应用会发出警告：*你的本地资料库版本较新——导入可能会覆盖你的更改。*

应用会自动推荐一个选项。如果文件包含默认资源库，则会预先选择 *添加为新的资源库*。如果文件中的资源库已存在于你的电脑上，且不是默认资源库，则会预先选择 *替换现有资源库*，并选中该资源库。如有疑问，请选择添加：这样不会覆盖任何内容。

### 删除资源库

1. 在列表中选择资源库，然后点击 *删除资源库*。最后一个资源库的按钮呈灰色，因为始终会保留一个资源库。
2. 点击 *删除* 确认。对话框会询问 *删除此资源库？* 如果有已打开的项目与其关联，会显示 *此资源库已与 1 个已打开的项目关联。删除将取消这些项目的关联。是否继续？* 如果项目更多，会显示相同内容，但数字不同，例如 *已与 2 个已打开的项目关联*。

之后该资源库就没有了，其中的所有资源和日历也一并删除。使用该资源库的已打开项目会取消关联：它们的资源会作为普通项目资源保留。如果你想保留内容，请先导出。

### 连同资源库一起交付项目

项目文件包含其资源的副本。如果你还想交出整个资源库，请执行以下操作。导出本身也在[导出](docs://howto-exporteren)中有说明。

1. 打开已关联资源库的项目，然后选择 *文件 › 导出*。
2. 勾选 *同时保存资料库文件*。该复选框仅在已关联的项目中显示。
3. 选择卡片 *IFC*，然后保存文件。随后应用还会要求保存第二个文件。该文件名与项目名相同，后面加上 `-bibliotheek`，并且包含资源库。

该复选框只对 IFC 导出有效，对其他导出格式无效。你的同事按上文所述导入第二个文件。

## 注意事项及应用的处理方式

**两名计划人员，两个资源库。** 应用不会在不同电脑之间同步资源库。导入窗口始终会就此显示警告：*注意：资源库不会在不同电脑之间同步。如果两名计划人员使用同一个资源库，资源库可能会出现差异。如果你的组织在多个运营公司之间共享班组，请有意选择一个共享的资源库。*

**替换会覆盖全部内容。** 所选资源库中的所有内容都会消失，而且资源库的更改不在 *撤销* 范围内。如果不确定，请先导出。你的项目保留其副本。应用会更新新文件中仍然存在的副本。新文件中已不存在的副本会带上标记 *资源库中已不存在*，并继续正常工作。如果某个副本与之不同，会打开窗口 *关联资源库*（见[使用资源库](docs://howto-resourcebibliotheek-gebruiken)）。

**从列表中删除日历会立即生效。** 应用不会要求确认，而删除资源时会要求确认。这看起来像是一个不足之处。资源库的更改不在 *撤销* 范围内。
