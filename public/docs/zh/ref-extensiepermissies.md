# 扩展权限

这里列出扩展清单中可以声明的每项权限：它允许什么，缺少时会发生什么，以及你在安装扩展时会看到什么。扩展的管理和安装方法见 [安装和管理扩展](docs://howto-extensie-installeren)。

## 权限是什么，不是什么

权限是**作者的声明**：扩展想使用应用界面的哪些部分。它不是屏障。扩展的代码与应用本身在同一环境中运行，因此它能做的事可能超过其权限所列的内容：没有沙盒。安装窗口中也会这样说明。只安装你信任的作者所提供的扩展。

应用以三种方式之一执行权限。这三种方式的区别很重要：

**严格执行。** 如果缺少该权限，对应的方法会在任何操作发生之前抛出错误（错误文字为荷兰语，例如 *Extensie "…" mist permissie: ribbon*）。

**警告。** 如果缺少该权限，该方法仍然可以运行，但应用会在日志中写入警告。在未来的版本中，它会变为拒绝。

**仅供参考。** 该权限没有关联任何界面部分。应用只在安装时显示它，不会对它做其他处理。

无需权限的操作是扩展界面的基础：读取项目、日历、任务、关系、资源和分配；添加和更改任务及关系；加载项目、重新计算并批量执行多项更改；保存扩展自己的设置、读取自己附带的文件并显示通知。

**清单。** 权限以列表形式写在清单中。如果你现在安装的扩展含有本应用版本不认识的权限，该扩展会被拒绝安装。对于已保存的较旧扩展，应用会去掉不认识的权限，并在日志中报告。

## 应用如何询问

安装时，无论是从扩展目录（*文件 › 扩展 › 浏览 › 安装*）还是从文件（*ZIP* 或 *JS*）安装，应用都会显示 *安装扩展？* 窗口。该问题只在安装时出现一次，而不是每次启用扩展时都出现。

该窗口显示名称、版本、说明、作者，以及（如果有）代码仓库。在 *来源* 下，它说明扩展的来源（*来自在线扩展目录*、*来自本机的 ZIP 文件* 或 *来自本机的 JavaScript 文件*），以及下载是否已验证：使用目录提供的校验和验证、因目录未提供校验和而未验证，或者是你自己选择的文件。在 *你同意的内容* 下，它说明扩展是以与应用相同权限运行的程序代码，并说明实际含义：在桌面应用中，除其他外，可以读写用户文件夹中的任何文件，并可访问你的项目、设置和剪贴板；在浏览器中，则可访问你保存的项目和设置、你授予访问权限的文件，以及网络。

在 *此扩展声明会使用的功能* 下，列出清单中的权限，以简短标签显示，名称与下文一致。窗口中还会显示：*这是作者的声明，而非限制——代码无论如何都能做得更多。* 如果扩展没有权限，窗口会显示 *未声明任何内容。* 两项权限有说明：*importSource* 和 *help*。其余六项只显示标签。

点击 *安装* 即表示你同意。点击 *不安装*、按 Esc 或点击窗口外部，都会拒绝安装。

## 各项权限

**ribbon** — 在功能区中放置按钮。作用：扩展可以在功能区标签上的某个组中添加按钮。没有此权限的扩展在尝试时会出错。按钮会出现在所选标签的末尾，位于扩展的组标签之下，并在你停用或删除扩展时消失。默认：未授予；仅限清单中列出的内容。执行方式：严格。位置：扩展所选的标签上。

**events** — 监听应用的事件，并自行发送事件。作用：扩展可以订阅和取消订阅事件，并自行发送事件。应用本身发送四种事件：项目已加载（导入、打开或由扩展加载之后）、已创建空项目、计划已（重新）计算，以及用户请求了教程。最后一种事件只发送给教程扩展。默认：未授予；仅限清单中列出的内容。执行方式：严格。位置：无；扩展对事件作出反应。

**backstage** — 提供导入格式。作用：扩展可以注册一个导入器；它会出现在 *文件 › 导入* 中，你可以在其中点击一种格式，然后选择文件。内置格式不属于此项（见 [导入和导出格式](docs://ref-import-exportformaten)）。默认：未授予；仅限清单中列出的内容。执行方式：警告。如果缺少此权限，注册仍然有效，但日志中会有警告。这是过渡性安排，因为现有扩展并不总是列出此权限。位置：*文件 › 导入*。

**pdf-fonts** — 为 PDF 导出提供字体。作用：扩展可以注册一个字体提供者。PDF 导出会用它来显示内置字体未覆盖的字符，例如中文、日文和韩文字符。默认：未授予；仅限清单中列出的内容。执行方式：严格。位置：报表的 PDF 中；在安装窗口中只显示标签。

**importSource** — 读取导入文件的原始字节。作用：扩展可以请求导入项目的源文件的完整内容（目前仅限 Primavera 文件），包括应用特意不纳入项目的字段，例如审计和来源字段、成本、审查字段和位置字段。这比界面其余部分的权限广泛得多，因此是单独的权限。没有此权限时，应用不会读取源文件的任何字节：每个方法都会在获取任何内容之前抛出错误。默认：未授予；仅限清单中列出的内容。执行方式：严格，默认拒绝。位置：安装窗口中会附带以下说明：*importSource — 每个导入文件的完整原始源字节（例如原始 Primavera 文件），包括从未进入项目的字段。*

**help** — 添加帮助文章和引导。作用：扩展可以注册和撤回帮助文章（教程），将附带的 `.ifc` 文件作为新文档打开，并启动和停止一个指向应用各部分的引导。附带的项目绝不会覆盖你正在编辑的文档：它会作为新文档打开，或者只会接管一个空白且未更改的标签页。自契约版本 1.4.0 起。默认：未授予；仅限清单中列出的内容。执行方式：严格。位置：在 *帮助* 窗口中（文章）、作为新标签页（项目），以及作为指向按钮的引导。安装窗口中附带以下说明：*help — 可以添加帮助文章、将附带的项目作为新文档打开，并显示指向应用各部分的引导。*

**filesystem** — 扩展声明它会使用文件。作用：无；没有任何界面部分与之关联，应用也无法执行它。默认：未授予；仅限清单中列出的内容。执行方式：仅供参考。位置：作为安装窗口中的标签。

**network** — 扩展声明它会使用网络。作用：无；与 *filesystem* 相同。默认：未授予；仅限清单中列出的内容。执行方式：仅供参考。位置：作为安装窗口中的标签。
