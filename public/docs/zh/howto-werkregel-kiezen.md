# 选择任务类型

目标：为每个任务设置，当你更改工期、单位或工时时，应用会调整的内容：工期、单位或工时本身。

## 何时需要

你已为任务分配资源，并希望应用按你的方式计算。例如：起重机租用一天，且这一天是固定的。另一个例子：你知道其中有 160 小时的砌砖工作，并想看看三个人而不是两个人需要多长时间。这两种情况需要不同的任务类型。

任务类型决定，当你更改其中一项时，工期、单位和工时中的哪一项随之变化。背景知识和示例见 [任务类型：工期、单位和工时](docs://uitleg-werkregels)。

## 步骤

### 显示任务类型

默认不显示任务类型。请将其开启一次：

1. 选择 *设置 › 项目 › 应用设置*，选项卡 *计划*。
2. 在标题 *计算* 下，勾选 *使用任务类型*。
3. 使用 *关闭* 关闭窗口。

这是应用的设置，而不是项目文件的设置。如果文件已包含任务类型或已存储的工时，例如来自 MS Project 或 Primavera P6 的文件，即使未开启此设置，应用也会显示该文件的任务类型。你亲自在文件中选择任务类型后，情况也一样：即使之后关闭此设置，该文件仍会显示任务类型。只要文件保持打开，它就保持显示；重新打开后，只要文件仍包含任务类型或已存储的工时，它也会保持显示。

### 设置任务的任务类型

1. 选择任务。*属性* 面板位于右侧；如果看不到它，请使用 *视图 › 面板 › 属性* 将其开启。
2. 在 *任务类型* 处，从五个选项中选择一个：*项目默认（固定工期和单位）*、*固定工期和单位*、*固定工期和工时*、*固定工时* 或 *固定单位*。选择 *项目默认* 时，任务会跟随项目的默认值。
3. 想了解某个选项的作用？在打开的下拉列表中，每个选项旁都有一个 i 图标。将光标移到它上面，然后点击或轻触以查看说明。点击 i 图标还不会选择该任务类型。
4. 关闭的字段旁也有一个 i 图标。它说明当前生效的任务类型，例如 *工期由工时和单位得出。* 选择 *项目默认* 时，它说明的是括号中的任务类型。

*项目默认* 是第一个选项，也是任务默认具有的选项。括号中的任务类型是项目当前的默认值。应用没有按钮可更改项目默认值：它来自导入（例如 MS Project 或 Primavera P6），或来自 MCP 连接。如果你想为某个任务使用另一种任务类型，请在此处选择。

你也可以在任务表中选择任务类型。点击任务表标题右侧的 **+**（*添加列*），然后在 *计划* 下选择 *任务类型* 列。

没有分配的任务没有可关联的内容，因此任务类型在此不起作用。请先为该任务分配资源（见 [用曲线分配资源](docs://howto-resource-toewijzen)）。

### 查看和更改工时

对于有分配的任务，在 *属性* 面板的 *分配* 区块中，*单位* 旁会显示 *工时（小时）* 列。这是该资源的剩余工时，单位为小时。列上方有一个小挂锁图标，表示任务类型保持不变的内容：*固定工期和单位* 与 *固定单位* 时为 *单位*；*固定工期和工时* 与 *固定工时* 时为 *工时（小时）*。

如果你想自己更改工时，请在字段中输入小时数，然后按 Enter 键。应用不接受 0 或小于 0 的值：字段会跳回上一个值。

### 查看会发生什么

如果你选择任务类型，数字还不会变化。在保护工时的任务类型下，应用只固定当前工时，因此 *工时（小时）* 有一个已存储的值。只有在下一次更改时，任务类型才会决定哪一项随之变化。例如，更改 *单位*，然后查看工期和工时的变化。

如果这会改变任务的工期，状态栏会显示 *已过期 — 请重新计算（F5）*。按 **计算**（F5），例如通过 *首页 › 进度 › 计算*，即可查看新日期。如果已开启 *自动计算*（同一个 *计划* 选项卡，标题 *计算* 下），应用会自动执行此操作。

## 哪种任务类型适用

- **固定工期和单位** 适用于工期是约定好的、而单位由你输入的情况。工时由这两项决定。这是默认设置。租用一天的起重机属于这种情况：这一天是固定的，而你决定这一天有多少台起重机。
- **固定工期和工时** 适用于任务必须在固定时间内完成，并且你知道其中有多少工时的情况。如果工期发生变化，应用会调整单位。
- **固定工时** 适用于你知道其中有多少小时工时，并想查看工期如何随人数变化的情况。三个人而不是两个人完成 160 小时的砌砖工作，属于这种情况。练习项目中的抹灰工作采用此任务类型。
- **固定单位** 适用于单位固定的情况，例如一台起重机，而工时决定工期。

## 易错点及应用随后的处理方式

**缺少 *任务类型* 字段。** 这时，*使用任务类型* 设置处于关闭状态，且文件中还没有任务类型；或者你选择了里程碑、阶段、吊床任务，或工期类型为 *已用时间* 的任务。这些对象没有任务类型。请选择普通任务。

**你没有更改工期，工期却发生了变化。** 在 *固定工时* 和 *固定单位* 下，工期由单位和工时决定。如果你更改其中一项或资源数量，应用会调整工期，并向上取整到整个工作日。对于以小时计的任务，应用会向上取整到整分钟。

**工时与单位 × 工期不完全一致。** 取整可能造成这种情况。此时，*工时（小时）* 字段中会出现一个警告标志，*与单位 × 工期不一致*。直方图会按已存储的工时显示。

**材料不计入。** 对于材料类资源，*工时（小时）* 显示一个短横线。材料从不决定工期。

**有进度的任务。** 任务类型只作用于剩余部分。因此 *工时（小时）* 只显示仍需完成的部分。

**撤销。** 选择任务类型，以及任务类型计算出的每次更改，都可以用 *撤销*（Ctrl+Z）一步撤回。之后，所选的任务类型会消失，但 *任务类型* 字段仍保持显示。
