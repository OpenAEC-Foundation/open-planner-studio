# 导出

目标：把你的计划以另一种格式的文件交出，供不读 IFC 的人或其他软件使用。

## 何时需要

顾问使用 MS Project，客户使用 Primavera，分包商想要 Excel 格式的任务，或者你要把计划发给无法处理 IFC 的软件。导出是另一种格式的副本。如果你想保留项目本身，请保存它：保存会写入 IFC，并保留全部内容。每种格式保留什么、不保留什么，见 [文件和格式](docs://uitleg-bestanden)。

## 步骤

1. 选择 *首页 › 文件 › 导出*，然后从列表中选择一种格式；或者选择 *文件 › 导出*。在那里，每种格式都是一张附有简短说明的卡片。
2. 在窗口中选择名称和位置。应用会建议项目名称，并加上该格式的文件后缀。进度表的名称为 *projectname-voortgang*，并在可能的情况下在你的下载文件夹中打开。
3. 确认。除下面的消息外，导出成功时不会出现任何消息。通过 *文件 › 导出* 导出后，即使你取消窗口，之后也会回到 *首页* 选项卡。如果你在 *首页* 选项卡的列表中导出时取消窗口，什么也不会发生。

如果你的浏览器只能通过下载保存（例如 Firefox），文件会在第 1 步之后立即出现在你的下载文件夹中。你会看到消息 *已保存为下载文件：“name.xml”现在位于您的下载文件夹中。当前环境不允许应用直接写入您选择的位置。*

### 你选择哪种格式？

*首页* 选项卡上的列表与 *文件 › 导出* 中的卡片提供相同的格式：

- *进度（Excel）* 和 *进度（CSV）*，对应卡片 *进度表（Excel）* 和 *进度表（CSV）*：一份精简的表格，包含编号、WBS、名称、日期和完成度，用于发给填写进度的人。
- *CSV (;)*，对应卡片 *CSV（分号分隔）*：一个任务表，你可以在电子表格中打开。
- *MS Project XML*：可以在 Microsoft Project 中打开。
- *Primavera P6 XML*：用于 Oracle Primavera P6。
- *IFC*：应用自己的格式，包含全部内容，使用项目的 IFC 模式（默认为 IFC 4.3 ADD2）。

### 带资料库文件的 IFC 导出

如果你的项目已链接到资源库，复选框 *同时保存资料库文件* 位于 *文件 › 导出* 中卡片的下方。如果你勾选它并选择 *IFC*，应用会两次要求选择位置：先是项目，然后是 *projectname-bibliotheek.ifc*。该复选框只在 *文件 › 导出* 中出现，不在 *首页* 选项卡的列表中。

### 恢复进度表

你通过 *文件 › 导入* 读回已填写的进度表。见 [从电子表格导入进度](docs://howto-voortgang-importeren)。

## 易错点及应用随后的做法

**你的项目不会改变。** 项目文件保持不变。如果原来有 *未保存* 标记，它仍然保留。

**过期的计划会先重新计算。** 因此，即使你忘记按 *计算*，你也会得到当前的日期。

**导出的文件也会列在最近使用中。** 这不适用于进度表。如果你在那里打开导出的文件，它会以该格式的导入方式打开。

**导出不会保留全部内容。** CSV 文件没有资源和约束，P6 XML 没有基线和截止日期。计算配置文件也不会一起导出：重新打开的导出文件会按 *Open Planner Studio* 计算。只有 IFC 会保留全部内容。带数字的示例见 [文件和格式](docs://uitleg-bestanden)。

**两种格式使用相同的文件后缀。** MS Project XML 和 Primavera P6 XML 都会得到名称 *projectname.xml*。请自行为它们取不同的名称，否则以后你将不知道哪个文件是哪种格式。

**含关系循环的计划不会被导出。** 应用会先计算，如果有循环就会停止。在 *首页* 选项卡上，你会看到消息 *无法计算计划*，其下方例如显示 *任务之间存在循环依赖：Set up site → Demolish existing extension → Set up site*。在 *文件 › 导出* 中，页面上只显示第二条消息。请解决循环后再次导出。

**来自 Primavera 的项目会丢失源信息。** 如果你把这样的项目导出为 CSV、MS Project XML 或 P6 XML，应用会报告：*导出为 CSV 会丢失 XER 源信息。* 对于 MS Project XML，它显示 *MSPDI*；对于 P6 XML，它显示 *P6*。见 [打开 Primavera P6 文件（.xer）](docs://howto-xer-openen)。

**拆分任务会丢失其拆分。** MS Project 和 Primavera 只能把拆分识别为工时分布。如果你的项目包含没有工时分布的拆分任务，导出为 MS Project XML 或 P6 XML 后，应用会报告：*2 个带中断的任务在导出时未包含中断：MS Project/P6 只能以工时分布的形式识别中断。* 如果只有一个任务，应用会显示：*1 个带中断的任务在导出时未包含中断：MS Project/P6 只能以工时分布的形式识别中断。* 见 [拆分任务](docs://howto-taak-splitsen)。

**在 *按记录的日期* 视图中的计划。** 如果你在看到源文件中的日期时导出为 CSV，对于源文件没有记录这些值的任务，应用会将 `Critical` 和 `Total Float` 留空。见 [按记录的日期](docs://uitleg-datums-zoals-opgeslagen)。
