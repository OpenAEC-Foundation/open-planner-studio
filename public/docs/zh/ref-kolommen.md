# 选择列

**表格**（**表格**选项卡）和甘特图旁边的任务列表各有自己的列。你直接在表格中修改它们：表头中的加号打开列选择器，在列标题中可以移动、加宽、固定或移除一列。每次更改立即生效，没有单独的确定步骤。

默认情况下，甘特图旁边的任务列表显示 **工作分解结构（WBS）**、**任务名称** 和 **工期**。表格另外显示 **开始**、**完成**、**任务类型**、**关键**、**总浮时** 和 **进度**，以及项目的活动代码和自定义字段。

## 打开列选择器

- 表头右侧的加号。表格和甘特图旁边的任务列表各有自己的加号，只修改所属的表格。
- **表格** 选项卡 → **列…** 打开表格的列选择器。
- 开启经典视图按钮后（**设置** → **高级** 选项卡 → **旧版功能** → **显示经典视图按钮**），**视图** → **显示** 功能区组 → **列…** 的作用相同：该按钮切换到表格选项卡并在那里打开列选择器。

按 **Esc**、在选择器外单击或再次单击加号，都会关闭选择器。

## 添加列

**选择列** 选择器从上到下包含：

- **最近使用** — 你最近通过选择器添加的字段。添加过一列之后才会出现这一栏。
- **搜索** 框 — 输入字段名称的一部分；**搜索结果** 来自所有分组。
- 按分组列出的字段：**任务**、**计划**、**约束**、**关系**、**资源**、**进度**、**已计算**、**基准**、**自定义** 和 **技术信息**。单击分组即可展开；旁边的数字是该分组中的字段数。
- 最下方是 **恢复默认** 按钮（见下文）。

单击某个字段即可把它添加为最后一列，选择器随即关闭。已经是列的字段带有勾选标记，不能再次选择。项目的活动代码和自定义字段位于 **自定义** 下，基准的字段位于 **基准** 下。

**已计算** 下有分析字段 **自由浮时**、**干扰浮时**、**接近关键** 和 **浮时路径** 等。它们只有在计算（**F5**）之后才有值，而 **接近关键** 和 **浮时路径** 还需要开启相应的排程选项——参见 [关键路径与高级分析](docs://gids-kritiek-pad-analyse)。

## 在列标题中调整列

- **移动** — 把列标题拖到其他位置。固定的列始终集中在最前面；未固定的列只能在未固定的列之间移动。
- **宽度** — 拖动列标题的右边缘（40 到 480 像素）。双击该边缘可使列宽适合标题和最长的值。使用键盘：将焦点放在边缘上，按左、右方向键，按住 **Shift** 可加大步长。
- **移除** — 鼠标指针移到列标题上时出现的减号。该字段仍可在列选择器中选择。
- 右键单击列标题可选择 **固定**（或 **取消固定**）、**自动调整** 和 **移除**。固定的列会移到最前面，与其他固定的列放在一起，并在横向滚动表格时保持可见（前提是所有固定的列能一起放进表格）。

## 开始、完成与计划日期

**开始** 和 **完成**（表格默认布局中的列）显示与甘特图中横道相同的日期：计算后的计划，首次计算之前则是输入的日期。在“开始”中输入其他日期，它就成为计划开始日期。输入其他“完成”日期时，自动计划的任务会相应改变工期；手动计划的任务则把它作为计划完成日期。之后按 **F5** 重新计算。再次输入相同的日期不会有任何变化。

**计划开始日期** 和 **计划完成日期** 字段显示输入的日期本身，即使计算移动了任务也是如此。只有手动计划的任务才能编辑计划完成日期：其他任务的完成日期由开始日期和工期决定。自动计划的汇总任务的开始和完成由其子任务得出，不能编辑。

## 恢复默认

**恢复默认** 位于列选择器底部。单击一次即可将该表格的列恢复为默认布局：包括显示哪些列、列的顺序和宽度，以及固定的列。额外添加的字段会从表格中移除，但仍可在选择器中选择。更新后也可以用它获得新的默认布局，例如用 **开始** 和 **完成** 代替 **计划开始日期** 和 **计划完成日期**：之前保存的个人布局不会自动改变。如果表格已经是默认布局，该按钮不可用。

## 保存、撤消与布局

列布局是本设备上的个人偏好：它适用于你的所有项目，不会保存在项目文件中。每个列操作——添加、移除、移动、调整宽度、固定或 **恢复默认**——都是一个步骤，可用 **Ctrl+Z** 撤消。

布局也可以记录列。它采用你创建布局时看到的表格的列布局；单击布局按钮时，会把它应用到当时显示的表格：在表格选项卡上是表格，在其他选项卡上是甘特图旁边的任务列表。参见 [保存和加载布局](docs://ref-layouts)。
