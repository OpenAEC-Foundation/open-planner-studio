# 创建和使用布局

目标：一键切换计划的视图，例如只显示关键任务、按班组显示任务，或使用不同的排序。

## 何时需要

在现场会议上，业主只想看关键任务。然后工地经理想按班组查看谁在何时需要。然后你又想看整个计划。反复设置筛选、分组和排序很麻烦。**布局**会把这样的视图保存为功能区中的一个按钮。

布局可以保存六项内容：筛选、分组、排序、Gantt 旁边任务表中的列、时间刻度，以及关系线和叠加层（基线、进度线、状态日期线、资源强调、浮时带和任务条颜色）。点击按钮时，只有你勾选的内容会改变。视图的其余部分保持不变。

你用布局来筛选、分组和排序。单独的按钮 *筛选…*、*分组…* 和 *排序…* 现在只能通过一个隐藏设置显示（见下文的注意事项）。

## 步骤

### 使用现有布局

1. 选择 *视图* 选项卡。在 *布局* 组中，每个布局都有一个按钮。默认是 *资源图*。
2. 点击它。*资源图* 会按资源对任务分组，在每组内按开始日期排序，并关闭关系线。有两个资源的任务会同时出现在两个资源下。
3. 再次点击可关闭布局。视图会恢复到你点击前的状态。

每次点击都是 *撤销*（Ctrl+Z）的一步，无论是开启还是关闭。

### 创建自己的布局

1. 在 *布局* 组中，点击 *新建布局*。*新建布局* 窗口会打开。
2. 输入 *名称*，然后选择 *图标*。
3. 在 *此布局保存哪些内容？* 下有六个带复选框的部分。新窗口会勾选所有部分，并填入你屏幕上的当前内容。取消勾选布局不得更改的所有内容。如果你只想要筛选，只保留 *筛选* 处于勾选状态。*采用当前视图* 会用你屏幕上的内容重新填入所有部分。
4. 设置各部分。
5. 点击 *保存*。

布局现在已是功能区中的一个按钮，但尚未应用。点击该按钮即可开启它。

### 设置筛选

在 *筛选* 下建立规则。点击 *+ 规则*，选择 *字段*、*运算符* 和值。如果你只想看关键任务：字段 *关键*，运算符 *等于*，值 *是*。字段包括 *任务名称*、*开始*、*完成*、*总浮时*、*进度* 和 *里程碑*，以及你自己的活动代码和字段，还有 *资源*。运算符取决于字段类型：文本可选 *包含*，数字和日期则可选 *介于*。

你能使用哪些运算符取决于字段类型：

- 文本（*任务名称*、*WBS*）：*等于*、*不等于*、*包含*、*开头是* 和 *为空*。
- 数字和日期（*总浮时*、*开始*、*进度*）：*等于*、*不等于*、*小于*、*小于或等于*、*大于*、*大于或等于*、*介于* 和 *为空*。使用 *介于* 时有两个字段：对于数字，提示为 *从* 和 *至*；对于日期，没有提示（第一个日期是开始，第二个是结束）。
- 是/否（*关键*、*里程碑*、*接近关键*）：*等于* 和 *不等于*，值为 *是* 或 *否*。
- 选项（*工作类别*、活动代码）：*等于*、*不等于*、*属于以下之一*（带复选框的值）和 *为空*。
- *资源*：*属于以下之一* 和 *为空*。
- *进行中*：只有 *介于*，带两个日期（从和到）。

使用字段 *进行中*、运算符 *介于* 和两个日期时，你会得到在该期间任何时刻都在进行的所有任务，例如六月中所有进行中的任务。

你用顶部的列表组合多条规则：*满足以下所有条件 (AND)* 显示满足所有规则的任务，*满足以下任一条件 (OR)* 显示至少满足一条规则的任务。使用 *+ 组* 可添加带有自己规则的子组。

筛选只看任务本身。该任务所属的阶段（摘要任务）会以灰色保持可见，因此你能看到任务属于哪里。如果你同时分组，这些灰色阶段会消失。

### 分组和排序

在 *分组* 下，使用 *+ 级别* 添加字段。分组级别最多有两级。不分组时，你会看到 WBS 树。在 *排序* 下，使用 *+ 级别* 添加字段，然后选择 *升序* 或 *降序*。有两级时，当第一级的值相等，第二级决定顺序。

### 不保存地快速试用

在窗口中点击 *应用但不保存*。勾选的部分会应用到屏幕上，但不会添加按钮。对于只需要用一次的筛选，这很方便。Ctrl+Z 可撤销此操作。

### 更改、复制或删除布局

右键点击布局按钮。你可以选择 *编辑…*、*复制* 或 *删除*。*删除* 会先要求确认。副本名为 *名称（副本）*。内置布局（例如 *资源图*）不能编辑或删除；请复制它来制作你自己的版本。

### 同时使用多个布局

不保存相同部分的布局可以同时开启。如果你有一个只保存筛选 *关键 等于 是* 的布局（例如命名为 *仅关键*），并同时开启它和 *资源图*（分组、排序、关系线），你会得到按资源显示的关键任务。如果两个布局保存同一部分，例如都保存筛选，第二个会接管，第一个会关闭。如果你再次关闭第二个，你会回到第一次点击之前的视图，而不是第一个布局。

## 注意事项和应用的行为

**你忘记取消勾选部分。** 同时保存列、时间刻度和叠加层的布局，每次点击都会把这些内容恢复为保存的状态。这时你的缩放会跳走，而你原本只想要筛选。请在窗口中检查，只勾选了你想要的部分。

**未完成的规则不显示任何内容。** 如果你没有为是/否字段选择值（它仍显示 *—*），或者 *进行中* 的日期留空，就没有任务符合条件，列表保持为空。请完成该规则。

**手动更改会关闭布局。** 如果你自己更改了布局保存的某个部分，例如在 *资源图* 开启时更改 *关系线*，该布局会退出，其他部分会恢复为布局开启前的视图。缩放会关闭保存时间刻度的布局，加宽某列会关闭保存列的布局。视图的其余部分则保持不变。*资源图* 不保存时间刻度，因此缩放不影响它。

**列适用于 Gantt 旁边的任务表。** *列* 部分保存时间线左侧表格的列。*表格* 选项卡上的表格保留它自己的列。如何选择列，请参见 [调整表格列](docs://howto-tabelkolommen-aanpassen)。

**降级和升级已禁用。** 只要筛选、分组或排序处于开启状态，显示的顺序就不是计划的顺序。此时 *降级* 和 *升级* 会被禁用，并显示提示 *筛选/分组/排序时不可用*。如需再次调整结构，请关闭布局，方法见 [调整结构](docs://howto-structuur-aanpassen)。

**状态栏不跟随。** 状态栏中的 *任务：* 显示整个项目的任务数量，即使筛选只显示其中一部分。

**布局保存在你的设备上，而不是项目中。** 应用会在此设备上保存你所有项目的布局和列。布局中的叠加层（基线、进度线和其余内容）适用于你的所有项目。当前开启的筛选、分组和排序属于当前打开的项目，但不会写入项目文件：保存并重新打开后，视图不再有筛选、分组和排序。它们也不会使项目被标记为“已修改”。

**单独的按钮已隐藏。** *列…*、*筛选…*、*分组…* 和 *排序…* 作为 *视图* 选项卡上的单独按钮，是旧的视图。你可以在 *应用设置* 窗口（标题栏中的 ⚙）的 *高级* 选项卡上，通过 *旧版功能* 下的 *显示经典视图按钮* 将它们调回。请优先使用布局。
