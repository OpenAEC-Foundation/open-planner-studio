# 同时处理多个项目

目标：同时打开多个计划，在它们之间切换，并分别关闭。

## 何时需要这样做

你在负责社区的住宅项目，但现场会议还涉及会所的翻新。或者你想把一个方案和原方案放在一起。每个项目都在各自的标签页中，有各自的任务、计算和时间范围。切换只需点击一次，你不会丢失任何内容。

## 步骤

### 打开第二个项目

1. 点击标签页右侧的加号（*开始项目*）。随即打开 *开始项目* 窗口。
2. 选择 *新建项目* 以创建空白计划，或选择 *打开现有项目* 以选择一个文件。*取消* 会关闭该窗口。
3. 选择 *新建项目* 后，在 *新建项目* 窗口中填写信息，然后点击 *创建*。

项目会出现在自己的标签页中，并立即成为当前项目。功能区中的 *新建* 和 *打开*、Ctrl+O 以及 *文件 › 示例* 中的示例，也会在新标签页中打开项目。应用只复用尚未编辑过的空白计划，而不新增标签页。

### 在项目之间切换

- 点击该项目的标签页。
- 按 Ctrl+1 至 Ctrl+9（macOS 上用 ⌘ 代替 Ctrl），切换到该位置的项目。位置从左往右计数。
- 点击标签页左侧的菜单图标（*所有项目*）。*打开的项目* 概览中，每个项目都有一张卡片，显示项目名称、文件名（如果项目有文件）、计划的缩略图、任务数、关键任务数和结束日期。点击卡片即可切换到该项目。按 Esc 可关闭概览。

每个标签页都有一个属于该项目的彩色圆点。名称后带有小圆点的标签页有未保存的更改。

如果标签页无法全部放入宽度，标签页与加号之间会出现两个箭头（*将标签页滚动到开头* 和 *将标签页滚动到末尾*）。每次点击会将标签页移动两个位置。当你已位于开头或末尾时，箭头显示为灰色。你也可以在标签页上用鼠标滚轮滚动。你选择的标签页总会自动移入可见范围。

### 关闭项目

点击标签页上名称旁边的叉号（*关闭*），或点击概览中卡片上的叉号。没有更改的项目会立即关闭。如果项目有未保存的更改，应用会显示 *未保存的更改* 窗口，并提供三个选项：

- *保存* 会先保存项目，然后关闭它。
- *不保存* 会关闭项目，并放弃这些更改。
- *取消* 会保持项目打开。

如果你取消保存，例如关闭保存对话框，项目会保持打开。

如果关闭最后一个项目，会保留一个名为 *新建计划* 的空白计划。

### 选择切换样式

你可以选择项目的显示方式。点击标题栏中的齿轮图标，打开 *应用设置* 窗口。进入 *外观* 标签页，然后在 *文档切换样式* 中选择一项：

- *横向标签页*：默认值。功能区下方的一排标签页。
- *纵向标签页*：左侧一个窄栏，每个项目有一个按钮（显示名称的前几个字母），还有一个加号。把鼠标悬停在按钮上，可以看到名称、文件名、任务数、关键任务数和结束日期。顶部的按钮会打开概览。
- *胶囊*：标题栏中的一个胶囊，显示当前项目的名称和计数，例如 *已打开 2 个*。点击它可打开概览并在其中切换。

三种样式都会打开同一个概览，Ctrl+1 至 Ctrl+9 在每种样式中都可用。

## 注意事项与应用的行为

**哪些内容属于项目，哪些是共享的。** 每个项目都有自己的视图：缩放和位置、带筛选、分组或排序的当前布局、拆分视图、关系线以及已折叠的阶段。切换到另一个项目后，你会看到该项目自己的视图。所有项目共享的内容有：功能区中选中的标签页、小地图、叠加层（基线叠加层、进度线等）、你选择的列、你的布局和报表选项。

**打开对话框时无法切换。** 只要有对话框打开，例如 *应用设置* 窗口或任务窗口，Ctrl+1 至 Ctrl+9 在应用中就不起作用。在浏览器中，它们会切换浏览器标签页。请先关闭对话框。Backstage 中 *项目设置* 里有未应用的更改，同样会阻止切换。

**Ctrl+1 至 Ctrl+9 按位置计数。** 快捷键会切换到该位置上的项目。如果关闭一个项目，其他项目的位置会前移。如果打开的项目超过九个，其余项目只能通过标签页或概览切换。

**计算和报表都作用于当前活动项目。** 计算（F5）、*导出 PDF* 和各报表都针对当前活动的项目。
