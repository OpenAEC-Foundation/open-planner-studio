# 管理资源

目标：在项目中创建、编辑和删除资源（人员、机器和材料），以便把它们分配给任务。

## 何时需要这样做

在把砌砖工或起重机放到任务上之前，该人员或机器必须先作为资源存在。资源会记录它有多少数量，以及它在哪些日子工作。应用据此判断某一天的工作量是否超出其能力。当人员配置发生变化时，你需要编辑资源，例如第二名砌砖工加入时。

两个术语。**最大单位数** 是每个工作日的产能：1 表示一个人或一台机器，2 表示两个。**分配** 是任务上的一个资源（见 [用曲线分配资源](docs://howto-resource-toewijzen)）。

## 步骤

### 创建资源

1. 选择 *资源 › 管理 › 新建资源*。资源面板会占满工作区，表格底部会出现一个空行。你也可以通过 *资源 › 管理 › 资源* 打开该面板，然后选择 *在项目中新建资源*。
2. 输入名称，例如 *Bricklayer*。
3. 选择 *类型*：*劳务*（默认）、*设备*、*材料*、*分包商* 或 *班组*。
4. 如有需要，填写其他字段。每个字段都有默认值：*最大单位数* 为 1，*日历* 为 *项目日历*。*费率/小时* 为空。只有类型为 *材料* 时才能填写 *单位*，例如 m³。
5. 按 Enter 或点击该行之外的区域。资源会出现在表格中。按 Enter 后，下方会立即打开一个空行，供你输入下一个资源。完成后按 Esc。

只有该行有名称后，它才会成为资源。按 Esc，或在没有名称时点击别处，应用不会创建任何内容。填写的顺序不影响结果：你可以先选择类型，再输入名称。

### 编辑资源

在该行中编辑字段。离开字段时，应用会保存名称、费率和单位；其他字段会立即保存。

- 只有 *最大单位数* 大于 0 时，应用才会接受该值。数值为 0 或更小时，该字段会显示红色边框，并恢复为之前的值。
- *日历* 决定资源在哪些日子工作。选择 *项目日历*，或选择它自己的日历。点击 *+ 资源日历* 可以新建一个日历，点击铅笔图标（*编辑…*）可以打开所选日历。如果某个任务在资源的日历规定的非工作日安排了工作，该日计为过度分配。如何创建资源日历，见 [设置资源日历](docs://howto-resourcekalender-instellen)。
- *费率/小时* 和 *合计*：*合计* 是该资源的工时乘以费率。一名抹灰工的工时为 32 小时，费率为每小时 50，合计为 1,600.00。表格底部是所有资源的总和。
- *班组* 会把一个资源归入类型为 *班组* 的资源之下。它只是分组：应用不会把成员的产能或负载累加到班组中。
- 该行左侧的彩色色块是资源的颜色。它只用于显示，不影响计划。

### 随时间变化的产能

你的第二名砌砖工只在七月19日才到岗吗？点击 *最大单位数* 旁边的箭头。在 *分时段产能* 下选择 *添加阶段*。每个阶段都有一个日期（*起始于*）和一个数值（*最大单位数*）。从该日期起，该数值生效。没有阶段时，始终使用固定值。

新阶段默认使用今天的日期和 1 个单位。两项都要更改，否则从今天起产能就是 1。

### 删除资源

1. 点击该行中的垃圾桶图标。
2. 如果资源有分配，应用会要求确认，例如 *“Bricklayer”有 4 项分配 — 是否删除？* 点击对号以删除，或点击叉号以取消。没有分配时，资源会立即消失。

该资源的分配会一并删除。如果某个任务的任务类型不是 *固定工期和单位*，应用会把已删除资源的工时分配给其余资源。视任务类型而定，这会改变它们的单位或任务的工期。如果工期发生变化，计划就不再是最新的。

你可以用 *撤销*（Ctrl+Z）撤销新建、编辑和删除操作。

### 侧栏中的小型概览

*资源 › 管理 › 资源停靠栏* 会在右侧栏中显示一个紧凑的概览，位于 *属性* 旁边。在这里你可以看到每个资源的名称和颜色，过度分配的资源旁边会有警告标志（*过度分配*）。这里只能更改 *最大单位数*。如果你选择一个或多个任务，概览只显示这些任务的资源。

## 常见问题及应用的处理方式

**只有类型 *材料* 会影响计算。** *劳务*、*设备*、*分包商* 和 *班组* 的处理方式相同。材料不计入任务的工期，也不参与资源平衡。在直方图中，*所有资源* 一行同样不计入材料。

**没有名称，就不会创建资源。** 空行会直接消失，不留痕迹。

**产能中的新阶段。** 如果你忘记更改日期和数值，产能从今天起就是 1。

**删除仍需要的资源。** 如果你误删，请立即按 Ctrl+Z。分配也会一起恢复。
