# 添加关系

目标：将任务链接在一起，使任务只在之前的工作完成后才开始，并在需要的地方添加等待时间（延隔）。

## 何时需要这个

没有关系时，应用不知道砌砖工只能在地基浇筑完成后才能开始。每个任务都会在项目开始时开始，完成日期也就没有意义。**关系**记录这个顺序。第一个任务是**前置任务**，第二个任务是**后续任务**。

你在建立计划、添加任务时，或发现两项工作原来互相依赖时，都需要添加关系。**延隔**是两个任务之间的等待时间，例如混凝土必须养护，或地面找平层必须干燥。

默认关系是 **FS**（完成-开始）：后续任务只能在前置任务完成后才能开始。应用还支持 SS、FF 和 SF，它们将开始或完成与另一个开始或完成相连。例如，使用 SS（开始-开始）时，抹灰只能在机电安装开始后才能开始。

不确定你需要哪种类型？在类型选择的下方，有一句使用真实任务名称的说明，例如 *Fundering 完成后，Metselwerk 才能开始。* 选择另一种类型，这句话也会随之变化。你可以在 *关系类型* 窗口、*依赖关系* 块以及 *前置任务*或*后续任务*列中看到它。

## 步骤

添加关系有四种方法。它们创建的关系相同，选择最适合你情况的方法即可。

### 链接两个所选任务

在任务表中工作时很有用。

1. 在任务表中，点击先开始的任务：前置任务。
2. 按住 Ctrl（Mac 上为 ⌘），点击接下来的任务：后续任务。
3. 选择 *首页 › 任务 › 链接 ▾ › 链接所选任务*。同一个按钮也位于 *计划 › 关系* 中。

应用会创建一个没有延隔的完成-开始关系。你会在 Gantt 和 *前置任务* 列中看到它显示为一个箭头；只有当应用拒绝该关系时，才会出现通知。该按钮只在恰好选中两个任务时有效。

### 在 Gantt 中绘制关系

连续添加多个关系时很有用。

1. 选择 *首页 › 任务 › 链接 ▾ › 绘制关系*。在 Gantt 上方会出现这条通知：*链接模式：在甘特图中从一个条形拖到另一个条形即可创建关系。按 Esc 退出。*
2. 在前置任务的任务条上按下鼠标，拖到后续任务的任务条上。一条带箭头的虚线会跟随鼠标。
3. 松开鼠标。会出现小窗口 *关系类型*，其中显示类型（默认 FS）和延隔输入框。
4. 如有需要，更改类型或延隔，然后按 Enter，或点击窗口以外的地方。关系随即创建。
5. 立即添加下一个关系：模式会保持开启。按 Esc 退出，点击通知中的 *停止* 按钮，或再次选择 *绘制关系*。

如果在 *关系类型* 窗口中按 Esc，则不会记录任何内容。若只需添加一个关系，无需开启此模式：拖动时按住 Shift，即可从一个任务条拖到另一个任务条。任务条右键菜单中的 *从此处开始建立关系* 会开启链接模式；拖动仍需你自己完成。在 *表格* 选项卡上，没有 Gantt 时，*绘制关系* 不可用。

### 在属性面板中添加关系

当你查看单个任务，并想添加它的前置任务或后续任务时很有用。

1. 选择任务。*属性*面板位于右侧；如果看不到，请通过 *视图 › 面板 › 属性* 将其打开。
2. 在 *依赖关系* 块中，点击 *添加关系*。
3. 如果另一个任务在前，方向保持 *前置任务*；否则选择 *后续任务*。
4. 输入另一个任务名称的一部分。用方向键和 Enter 选择正确的任务，或直接点击。
5. 选择类型（默认 FS），如有需要填写延隔。
6. 按 Enter，或点击勾号（*创建关系*）。

该任务的关系随后会列在 *依赖关系* 中，每项显示另一个任务的 WBS 编号、类型和延隔。

### 在前置任务列中输入关系

当你用键盘快速工作并知道 WBS 编号时很有用。

1. 点击任务表标题右侧的 **+**（*添加列*），在 *关系* 下选择 *前置任务* 列。*后续任务* 列的操作方式相同。
2. 在 *前置任务* 列中，点击后续任务的单元格。
3. 输入前置任务的 WBS 编号、一个空格和类型，例如 `2.6 FS`。在其后直接加延隔：`2.6 FS+1d`。多个前置任务用分号或逗号分隔：`3.1 FS; 3.2 SS+2d`。
4. 按 Enter。

你输入的内容会替换整个单元格。如果单元格中已有前置任务，也要一并输入（见易错点）。如果不输入，而是在单元格中按 Enter 或 F2，会打开一个输入框并保留现有关系：你可以按 WBS 编号或名称搜索任务，并为每个关系选择类型和延隔。

### 设置或更改延隔

无论使用上述哪种方法，都在类型旁边的框中输入延隔。若要更改现有延隔，请在 *依赖关系* 中操作：点击延隔框，输入新值，然后按 Enter。

- `3` 或 `3d`：3 个工作日。周末不计算在内。应用会显示 `+3d`。
- `3ed`：3 个日历日。周末计算在内，就像混凝土在周六和周日也继续养护一样。
- `-1`：负延隔（提前量）。后续任务可以提前一天开始，因此两个任务会重叠。
- `4h`：4 小时的工作时间；应用会将其显示为 `+4h`。如果前置任务是天任务，并且其日历没有自身的时段（例如标准日历），应用会将其换算为整数个工作日，并四舍五入到最接近的整数：`4h` 相当于 1 天，`2h` 相当于 0 天。在有自身时段的日历上，或在小时任务之后，延隔会精确按小时计算。
- `50%`：前置任务工期的一半。

示例：地基混凝土必须先养护，砌砖工才能施工，因此 *Pour foundation → Foundation brickwork* 之间设置一个延隔为 `3` 的 FS 关系。如果浇筑日是 2027年6月18日（星期五），砌砖工会在 6月24日（星期四）的 **计算** 之后开始：星期一至星期三是等待时间。使用 `3ed` 时周末计算在内，砌砖工会在 6月22日（星期二）开始。

### 最后：重新计算

新关系不会立即移动任何任务条；状态栏会显示 *已过期 — 请重新计算（F5）*。按 **计算**（F5），例如通过 *首页 › 进度 › 计算*。只有这样，后续任务才会获得新的日期。如果希望应用自动执行，请在 *设置 › 项目 › 应用设置* 下的 *计划* 选项卡中开启 *自动计算*。

## 易错点与应用的处理方式

**顺序颠倒。** 使用 *链接所选任务* 时，点击的顺序决定方向，而不是列表中的顺序。如果你先点击了较晚的任务，关系方向就会颠倒。在 *依赖关系* 中用垃圾桶图标将其删除，然后重新添加。

**在列中输入会清除原有内容。** 如果单元格中是 `3.4 FS; 3.2 FS`，而你只输入 `3.2 FS`，与 3.4 的关系会消失，且不会有任何提示。请输入所有前置任务，或使用 Enter 或 F2 添加，或按 Ctrl+Z 撤销。

**循环。** 如果添加的关系指回链中较早的任务，计划将无法计算。应用会拒绝此类关系：*此关系会在计划中形成循环（…），因此未创建。*，循环中的任务会列在括号中。请先删除闭合循环的关系。

**任务与其所属摘要任务。** 任务与其所属的摘要任务之间无法建立关系。应用会显示 *不允许在任务与其自身的（上级）摘要任务之间建立关系。*

**重复。** 如果关系已存在，应用会显示 *该关系已存在*，且不会有任何更改。

**较短的列内提示。** *前置任务* 列会给出同样的拒绝，并在单元格下方显示较短的文字：*此更改会在计划中形成循环。*、*此关系已存在。* 或 *任务不能与其自身的摘要任务建立关系。* 如果你只输入 WBS 编号，例如 `3.1`，则缺少类型，单元格会显示 *请使用类似 1.2 FS+2d 的格式。* 单元格保持打开；请更正输入，或按 Esc 取消。

**延隔没有半天。** 以天计的延隔总是整数：`1.5` 会变为 `+2d`。在没有自身时段的日历上，天任务之后的小时延隔会四舍五入为整数个工作日。无法识别的输入（例如一个单词）不会保存：输入框会跳回之前的值。
