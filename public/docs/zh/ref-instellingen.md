# 应用设置

本页列出应用的每个设置：作用、起始值、它改变的内容，以及在哪里找到它。关于项目的计算选项（计算配置文件、关键定义），请参见 [计算选项和约定](docs://ref-rekenopties-en-conventies)：这些选项属于项目文件，而不属于应用。

## 位置与工作方式

设置面板在三个位置，三处都是同一个面板：窗口顶部的齿轮、*设置 › 项目 › 应用设置* 和 *文件 › 应用设置*。面板有三个标签页：*外观*、*计划* 和 *高级*。下面每个设置只写出它所在的标签页。

更改会立即生效。没有 *应用* 按钮，也没有 *取消* 按钮。

**应用范围，不针对单个项目。** 本文中的所有设置都适用于你的全部项目，并属于这台设备。应用将它们保存在应用或浏览器的存储中，而不在项目文件中。因此，别人打开你的文件时，看到的是他们自己的设置。如果你清除浏览器存储，设置会恢复为起始值。

## 外观标签页

**主题** — 界面的配色方案。可选 *深色*、*浅色* 和 *高对比度*。默认：*深色*。作用：整个界面的颜色，包括 Gantt 和直方图。位置：*外观*。

**跟随系统主题** — 让操作系统的配色方案决定界面颜色。默认：关闭。作用：应用会根据系统显示为 *浅色* 或 *深色*；此时三个主题卡片会被禁用。*高对比度* 不跟随系统，需要你自己选择。如果你关闭此项，当时屏幕上的主题会保持不变。位置：*外观*，在 *主题* 下。

**语言** — 界面的语言。默认：如果应用支持你的浏览器或系统的语言，就使用该语言；否则使用英语。作用：应用中的所有文字。语言按其简写代码排序。阿拉伯语和波斯语会将界面从右到左镜像显示。帮助文章的语言要单独设置：在 *文件 › 帮助* 下的 *文档语言* 中。位置：*外观*。

**字体** — 整个界面的字体。可选 *默认*、*系统*、*衬线* 和 *等宽*。默认：*默认*。作用：窗口中的标题和文字，以及 Gantt 和直方图中的文字。网页应用不会自动跟随系统字体，因此你要在这里选择。位置：*外观*。

**文字大小** — 界面的缩放比例。可选 90%、100%、110% 和 125%。默认：100%。作用：功能区、面板和对话框的文字与布局会随之变大或变小；表格和 Gantt 的行高也会按比例变化。没有高于 125% 的选项，因为超过此值时，功能区中的按钮文字会分成多行。位置：*外观*。

**日期格式** — 日期在应用中的显示方式。可选 *日-月-年*、*月-日-年* 和 *年-月-日*。默认：*日-月-年*。作用：表格、对话框、报表和打印中的日期。文件和计算不会改变，只改变显示。位置：*外观*。

**时间格式** — 时钟时间在应用中的显示方式。可选 *24 小时制（13:00）* 和 *12 小时制（1:00 PM）*。默认：*24 小时制（13:00）*。作用：日历窗口中的时间、以小时计的任务的日期和时间（表格、拆分、消息），以及 Gantt 中的 *小时* 时间刻度。在时间字段中，你可以输入以下任一形式：*13:00*、*1300*、*13*、*1:00 PM* 或 *1 pm*。一天的结束，即午夜，写作 *24:00* 或 *12:00 AM*。文件和计算不会改变：它们始终使用 24 小时制。位置：*外观*。

**工期显示** — 任务的工期以哪个单位显示。可选 *自动（按任务自身单位）*、*始终按天* 和 *始终按小时*。默认：*自动（按任务自身单位）*。作用：任务表、Gantt 的任务条标签、提示框、打印和报表。选择 *自动* 时，天任务显示天，小时任务显示小时。选择 *始终按天* 或 *始终按小时* 时，应用会按任务日历中每天的小时数进行换算；如果任务自身的单位不同，则在括号中附上该单位，例如 `2.25d(18h)`。只改变显示；任务保留自己的单位。位置：*外观*。

**项目切换样式** — 如何在已打开的项目之间切换。可选 *横向标签页*、*纵向标签页* 和 *胶囊*。默认：*横向标签页*。作用：*横向标签页* 在功能区下方显示标签栏；*纵向标签页* 在左侧显示项目栏；*胶囊* 在标题栏中显示一个小的项目按钮。位置：*外观*。

### Gantt 部分

**只显示工作日** — 压缩时间轴。默认：关闭。作用：应用会跳过项目日历中的周末和假日，因此工期为 5 个工作日的任务，正好宽 5 列。*跳转到今天* 和 *适应项目* 的快捷方式也会按工作日计算。报表中有一个同名复选框，它独立于此设置。位置：*外观*，在 *甘特 › 时间轴* 下。

**放大很多时显示刻钟** — 一个额外的精细时间刻度。默认：关闭。作用：你可以放大得更多，小时刻度会多出一行刻钟。拖动小时任务的任务条时，可以对齐到刻钟，而不只是整点小时。只有开启 *启用小时计划* 时才会看到此项。位置：*外观*，在 *甘特 › 一刻钟缩放* 下。

**中断处的任务条** — 小时任务是否按工作时段分块绘制。可选 *从不拆分*、*选中时拆分* 和 *始终拆分*。默认：*选中时拆分*。作用：小时任务的任务条会按每个工作时段分别绘制，而不是画成一个连续的块。*选中时拆分* 只对选中的任务生效。此项只涉及小时任务。真正拆分的任务（使用 *拆分任务*）无论此设置如何，都会显示其中断。位置：*外观*，在 *甘特* 下。

**滚动与缩放 › 模式** — 滚轮在 Gantt 上的作用。可选 *位置*、*按键* 和 *缩放 + 拖动*。默认：*缩放 + 拖动*。作用：选择 *缩放 + 拖动* 时，滚轮以光标为中心缩放；Shift + 滚轮在行中滚动；拖动背景可平移时间线；Ctrl + 拖动（Mac 上为 Cmd）可绘制选框。选择 *位置* 时，滚轮的功能取决于光标所在的位置；Ctrl + 滚轮始终缩放，Shift + 滚轮始终水平滚动。选择 *按键* 时，你自己决定每个按键的作用。此选择也适用于拆分视图中的第二个时间线。位置：*外观*，在 *甘特 › 滚动与缩放* 下。

**滚动与缩放 › 屏幕划分** — 光标位于哪个区域，决定其功能。仅在 *位置* 模式中可见。可选 *左/右*、*上/下* 和 *右上角*。默认：*左/右*。作用：选择 *左/右* 时，滚轮在左半边垂直滚动，在右半边水平滚动。选择 *上/下* 时，滚轮在顶部 30%（靠近时间刻度）水平滚动，在其下方垂直滚动。选择 *右上角* 时，滚轮在右上象限水平滚动，在其余区域垂直滚动。位置：*外观*，在 *甘特 › 滚动与缩放* 下。

**滚动与缩放 › 垂直、水平、缩放** — 哪个按键对应哪个滚轮功能。仅在 *按键* 模式中可见。对每个功能，你可从 *滚动*、*Ctrl + 滚轮* 或 *Shift + 滚轮* 中选择。默认：*垂直* 为 *滚动*，*缩放* 为 *Ctrl + 滚轮*，*水平* 为 *Shift + 滚轮*。作用：如果你选择的按键已被占用，两个功能会交换按键。位置：*外观*，在 *甘特 › 滚动与缩放* 下。

## 计划标签页

**启用施工模式** — 为新项目设置面向施工的起始值。默认：开启。作用：开启时，新项目使用日历 *Bouwkalender NL*（含荷兰公共假日）；生成假日时可选择施工假日；提供分阶段模板 *住宅建筑* 和 *公共建筑 / 改造*；新任务的工作类别为 *施工*。关闭时，新项目使用不含假日的日历 *Standaardkalender*，只提供模板 *空白*，新任务的工作类别为 *其他*。若新任务的父任务带有工作类别，则新任务先沿用该类别；之后才应用 *施工* 或 *其他*。现有任务和日历不会改变。位置：*计划*。

**启用小时计划** — 以工作小时进行计划，与按工作日计划并存。默认：关闭。作用：时间刻度 *小时* 会出现在 *视图 › 时间刻度* 下；在 *日历* 窗口中，普通日历可以获得工作时段（*工作时间* 区块；已有工作时段的日历始终显示该区块）；*新建项目* 窗口会增加 *班次* 和 *新任务的默认单位* 两个选项。*项目设置* 也会增加 *新任务的默认单位* 选项。关闭时，应用以天为单位工作。已经以小时计的任务会保留并纳入计算；只有开启小时计划后，才能编辑它们的工期。位置：*计划*，在 *小时计划* 下。参见 [开启小时计划](docs://howto-urenplanning-aanzetten)。

**允许天与小时混合计划** — 是否可按任务选择单位。仅在开启 *启用小时计划* 时可见。默认：开启。作用：开启时，每个任务的工期旁边会显示 *工期单位* 下拉列表。关闭时，该下拉列表隐藏。位置：*计划*，在 *小时计划* 下。参见 [天与小时](docs://uitleg-dagen-en-uren)。

**一周始于** — 一周的第一天。可选 *星期一* 和 *星期日*。默认：*星期一*。作用：Gantt 和报表中时间刻度的周布局与周数（包括 Gantt 图的打印），以及 *日历* 窗口中星期的排列顺序。位置：*计划*。

**自动计算** — 计划一过时，就立即重新计算。默认：关闭。作用：关闭时，你需要自己按 *计算*（F5）。开启时，应用会在任务、关系或日历变化后的不到一秒内重新计算计划。拖动时或在字段中输入时，应用会等待；操作完成后只计算一次。计算失败后，只有你再做一次更改，才会再次计算。位置：*计划*，在 *计算* 下。

**使用任务类型** — 应用中的任务类型和工时字段。默认：关闭。作用：开启时，任务上会显示 *任务类型* 字段，分配的工时列会显示，表格列 *任务类型* 也可用。关闭时隐藏它们；工期和单位保持不变，工时随之变化。已含任务类型或工时数据的项目（例如来自 `.mpp` 或 `.xer` 文件），即使此设置关闭，也始终显示它们。位置：*计划*，在 *计算* 下。参见 [任务类型：工期、单位和工时](docs://uitleg-werkregels)。

## 高级标签页

**打开后显示说明** — 每种格式各有一个复选框：*Primavera 文件 (.xer)*、*MS Project 文件 (.mpp)*、*MS Project XML*、*Primavera P6 XML* 和 *CSV 文件*。默认：全部开启。作用：开启时，打开此类文件后会显示一个窗口，简要说明该格式：应用接收了什么、没有接收什么，以及保存和写回的方式。在该窗口中选择 *不再为 … 显示* 会清除此处的复选框；你可以在这里重新开启。IFC 文件、示例以及由 AI 助手或扩展打开的项目，永远不会显示此说明。位置：*高级*，在 *打开后显示说明* 下。参见 [打开和保存文件](docs://howto-bestand-openen-en-opslaan)。

**启用 AI 模式** — 让 AI 助手使用你的计划。默认：关闭。作用：开启时，会显示 *AI* 标签页，其中含 MCP 桥接，使 AI 助手可通过 Model Context Protocol 处理你的计划。关闭时，隐藏该标签页并停止桥接。位置：*高级*，在 *AI 模式* 下。参见 [连接 AI 助手（MCP）](docs://howto-ai-assistent-koppelen)。

**自动启动桥接** — 应用启动时自动启动 MCP 桥接。只有开启 *启用 AI 模式* 时才能开启此项。默认：关闭。作用：桥接立即可用，因此 AI 客户端无需你先打开 *AI* 标签页即可连接。此功能仅在桌面应用中有效，且每次启动只执行一次：如果你之后自行关闭桥接，它不会再次自动启动。位置：*高级*，在 *AI 模式* 下。

**启用调试终端** — 用于排查问题的日志面板。默认：关闭。作用：开启时，状态栏中会出现一个终端按钮，用于显示或隐藏日志面板。关闭时，面板随之关闭。位置：*高级*，在 *调试终端* 下。

**基准测试…** — 测量计划计算引擎的性能。作用：打开一个窗口，在其中生成所选大小的测试计划，并测量核心阶段。你打开的项目不受影响。它是一个按钮，而不是设置：没有需要记住的内容。位置：*高级*，在 *基准测试* 下。

**统计…** — 应用的下载次数。作用：打开 *下载统计* 窗口，其中显示 GitHub Releases 的公开数据；不会从你这里收集任何信息。它是一个按钮，而不是设置。位置：*高级*，在 *统计* 下。在该窗口中：

- *按操作系统的下载量* — 每个系统都有以下列：*下载*、*安装包*（人工下载的内容）和 *更新包*（应用中的更新程序获取的内容），并有一个 *合计*。在 Linux 上两者无法区分：更新程序获取的 `.deb`、`.rpm` 或 `.AppImage` 文件，正是人们手动下载的同一文件，因此这里只有 snap 文件计为安装包。其下方是 *应用中的更新检查*：已安装的应用中的更新程序从 GitHub 获取版本文件以查找新版本的次数。这些是检查次数，不是安装次数。
- *按版本* — 每个版本的下载量，并附日期；首先显示最新的六个，其余的用 *显示全部 … 个版本* 显示。
- *来源* — 数据的日期（GitHub Releases，每周更新）和 *立即刷新*。应用会将已获取的数据保留半小时。获取失败时，窗口会显示提示。通过 Snap Store 的安装不经过 GitHub，因此统计中没有这些安装。

**开始导览** — 再次显示入门导览。作用：关闭 *应用设置* 窗口，并从第一步开始导览。位置：*高级*，在 *导览* 下。

**版本** — 应用的版本号，附两个按钮。*检查更新* 会打开更新窗口。*更新内容* 显示当前版本的新内容。位置：*高级*，在 *版本* 下。

**显示经典视图按钮** — 已被取代的功能，位于 *旧版功能* 下。默认：关闭。作用：开启时，*视图* 标签页上会重新出现一组 *显示*，其中有单独的按钮 *列…*、*筛选…*、*分组…* 和 *排序…*。它们已被表格标题中的加号、布局按钮和布局窗口取代。位置：*高级*，在 *旧版功能* 下。

## 设置面板之外记住的显示选择

应用还会把这些选择保存在此设备上。但你要直接在对应的界面项上设置，而不是在设置面板中设置。

**基线叠加** — 当前基线显示为任务条下方的细条。默认值：开启。位置：*视图 › 基线与进度 › 基线叠加*。

**进度线** — 状态日期处的锯齿形进度折线。默认值：开启。效果：只有项目设置了状态日期，才会显示此线。它会取代单独的状态日期线。位置：*视图 › 基线与进度 › 进度线*。

**状态日期线** — 状态日期处的虚线。默认值：开启。效果：如果进度线已开启，则由进度线自己绘制该标记。位置：*视图 › 基线与进度 › 状态日期线*。

**资源强调色** — 在任务条下方显示一条细条纹，颜色为资源颜色。默认值：关闭。位置：*视图 › 基线与进度 › 资源强调色*。

**浮时带** — 浮时以带状显示在非关键任务条后面，已完成的任务除外。默认值：开启。位置：*视图 › 基线与进度 › 浮时带*。

**条形图颜色** — 任务条的颜色取决于什么。可从 *关键路径*、*按任务 — 自动* 和 *按类别* 中选择。默认值：*关键路径*。效果：同时作用于 Gantt 和报表。位置：*视图 › 基线与进度 › 条形图颜色*。

**直方图** — Gantt 下方的直方图条带。默认值：关闭。位置：*资源 › 直方图 › 直方图*、*视图 › 面板 › 直方图*，或按 Ctrl+Shift+H。你可以拖动该条带的边缘来设置其高度（默认值为 160 像素，范围为 80 到 480 像素）。

**小地图** — 时间线的概览图。默认值：关闭。位置：*视图 › 演示 › 小地图*。

**收起功能区** — 紧凑的功能区。默认值：关闭。位置：功能区右下角的箭头按钮。

**任务表的宽度** — 默认值为 350 像素，范围为 150 到 800 像素。你可以拖动任务表旁边的分隔线来设置，或者在分隔线获得焦点时使用左箭头键和右箭头键。

**右侧面板的宽度** — 默认值为 280 像素，范围为 200 到 900 像素。你可以拖动面板的边缘来设置。

**右侧面板中 *属性* 和 *警告* 的高度** — 默认值分别为 240 和 220 像素，范围为 120 到 2000 像素。打开资源列表时，*属性* 也保持这个高度。你可以用各区域之间的拖动手柄设置高度。应用不会记住各区域是展开还是收起的状态。

**同样会记住，在其他地方有说明** — 任务表的列（[调整任务表的列](docs://howto-tabelkolommen-aanpassen)）、你的布局（[创建和使用布局](docs://howto-layouts-gebruiken)）、报表选项（[报表类型](docs://ref-rapporttypes)）、你自己的计算配置文件模板（[计算选项和约定](docs://ref-rekenopties-en-conventies)）以及帮助的 *文档语言*（*文件 › 帮助*）也由应用保存在此设备上，而不是保存在项目文件中。
