# Instellingen

**设置**窗口保存应用设置：适用于本设备、与项目文件无关的偏好设置。每次更改都会立即应用并保存——没有确定按钮。会改变已计算计划的排程选项则存储在项目中——参见 [Projectinformatie](docs://ref-projectgegevens)。

## 打开方式——三个入口，内容相同

- 标题栏中的**齿轮**（⚙）。
- **设置**（功能区标签）→ **项目**功能区组 → **设置**。
- **文件** → **设置**（Backstage）。

三者显示完全相同的设置。根据您使用的版本不同，这些设置会分布在三个或四个标签中——第四个标签**应用程序**是最近从第一个标签的尾部拆分出来的——但无论哪种情况，各项设置本身及其作用都是相同的；本文将它们归类为**常规**、**语言**和**时间轴 / 缩放**。

## 常规标签

**外观：**

- **主题** — **深色**、**浅色**或**高对比度**；点击卡片切换。
- **字体** — **默认**、**系统**、**衬线**或**等宽**；覆盖界面所用的字体。网页应用不会自动跟随您的系统字体设置，因此这一项和下一项设置就是您自行选择字体的方式。
- **文字大小** — 90%、100%、110% 或 125%；缩放界面文字和布局。
- **文档切换样式** — 如何在打开的文档之间切换：**横向标签页**、**纵向标签页**或**胶囊**。
- **日期格式** — **日-月-年**、**月-日-年**或**年-月-日**。仅影响显示；文件和计算不受影响。
- **施工模式** — **启用施工模式**会在*新建*项目的默认设置之间切换：面向施工（含荷兰法定节假日的施工日历、建筑行业假期、阶段模板）或中性的、与施工无关的设置。无论哪种情况，现有项目都不受影响。

**应用程序：**

- **版本** — 应用的版本号（只读），旁边带一个**检查更新**链接，用于打开更新窗口。安装更新仅在桌面应用中可用；Snap 和 AppImage 安装通过各自的渠道更新。此外，应用自动更新后您首次打开它时，会自动弹出一个一次性的"已更新到最新版本！"对话框——版本跃迁、安装包的大小差异、距上次发布的天数，以及能够获取到的 GitHub 发行说明。这与上面手动点击**检查更新**链接是两个不同的、自动触发的时刻。
- **项目信息...** — 通往 [Projectinformatie](docs://ref-projectgegevens) 窗口的快捷方式。
- **导览** — **开始导览**重新播放入门导览。同一个重启入口也位于**视图**功能区标签 → **导览**，以及 Backstage（**文件** → **开始导览**）。
- **基准测试** — 打开内置的基准测试工具，用于衡量本机的计算/渲染性能。
- **AI 模式** — **启用 AI 模式**会显示带有 MCP 桥接的**AI**功能区标签，使 AI 助手可以通过 Model Context Protocol 处理您的计划；关闭后会立即停止正在运行的桥接。**自动启动桥接**（仅在 AI 模式开启时可用）会在应用启动时立即启用桥接，无需先打开 AI 标签——仅限桌面应用。完整说明请参见应用内的 AI 助手指南。
- **调试终端** — **启用调试终端**显示用于排查问题的日志面板。

## 语言标签

- **语言** — 应用的显示语言，立即生效。

## 时间轴 / 缩放标签

- **小时计划** — **启用小时计划**会开启小时时间刻度和具体工作时段。关闭时，新任务以天开始，现有小时任务仍保留精确值。开启后，按天和按小时任务可以自然共存。参见 [Kalenders & uren-planning](docs://gids-kalenders-uren)。
- **工期显示** — **自动（按任务自身单位）**、**始终按天**或**始终按小时**。
- **中断处的任务条** — **从不拆分**、**选中时拆分**或**始终拆分**：任务条是否在非工作日周围视觉拆分。
- **时间轴** — **仅显示工作日**压缩时间轴：跳过项目日历中的周末和节假日，因此一个 5 个工作日的任务恰好占 5 列宽，不管两者之间的日历是什么样子。
- **一周起始日** — **星期一**或**星期日**（时间刻度的周布局）。
- **深度放大时显示刻钟** — 在小时时间刻度上的额外一刻钟刻度。
- **计算** — **自动计算**会在计划一旦过期时自动重新计算，而不等待按 F5。
- **滚动与缩放** — **模式**：
- **缩放 + 拖动**（默认）— 滚轮进行缩放（以光标为中心）；拖动图表背景以平移视图；Shift+滚轮滚动行；Ctrl/⌘+拖动画出选择框。
- **位置** — 由光标位置决定滚动方向；配合**屏幕分割**（**左/右**、**上/下**或**右上角**）。Ctrl+滚轮 = 缩放，Shift+滚轮 = 水平滚动。
- **按键** — 通过拖拽方块，为每种控制方式（**滚动**、**Ctrl + 滚轮**、**Shift + 滚轮**）指定功能（**垂直**、**水平**、**缩放**）；拖到已被占用的位置会交换两者的控制方式。
