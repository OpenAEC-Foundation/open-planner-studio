# 任务对话框和属性面板

你可以在两个地方编辑任务：在 *编辑任务* 窗口中，以及在 *属性* 面板中。两者几乎共享所有字段。本文说明每个字段的作用、默认值以及你会注意到的效果。如何创建和设置任务，参见[添加任务和里程碑](docs://howto-taken-en-mijlpalen-toevoegen)。计算结果为何如此，参见[关键路径和浮时](docs://uitleg-kritiek-pad)。

## 两个位置

- **编辑任务** — 用于第一个选中任务的窗口。按 F2 打开，或双击 Gantt 中的任务条，或在 Gantt 或表格中右键点击任务并选择 *编辑*…。你的更改会保留在草稿中，直到你点击 *保存*（Enter）。*取消*（Esc）会放弃这些更改。名称为空时，*保存* 不可用。保存是 *撤销* 中的一个步骤，包括你在 *任务类型*、*依赖关系*、*分配* 和 *代码与字段* 部分所做的更改。这些部分在你编辑时已经作用于项目，*取消* 会将它们撤销。
- **属性** — 右侧栏中的面板，显示当前任务。每次更改都会立即生效。同一字段的连续更改在 *撤销* 中算作一步。没有任务时，面板显示 *选择一个任务以查看属性。* 用 *视图 › 面板 › 属性* 打开或关闭它。默认：开启。该面板位于 Gantt 旁边和 *表格* 选项卡上，不在 *IFC* 和 *报告* 上，也不在完整的资源面板下。

只在窗口中有：*父任务*，以及按钮 *保存* 和 *取消*。只在面板中有：垃圾桶 *删除任务*、底部的按钮 *计算*、*中断* 部分、*任务类型* 下的三个标记（长时间非工作时段、MS Project、已记录日期），以及在 *依赖关系* 中添加关系和跳转到链接任务。所有其他字段两处都有。窗口只对现有任务显示 *依赖关系*、*分配* 和 *代码与字段*。

如果你更改了会影响日期的内容，请按 *计算*。除非开启 *自动计算*，否则不会自动计算。

## 常规

- **名称**（在窗口中为 *名称 \**）— 任务在 Gantt、表格和报表中的名称。必填：空名称不会被保存。新任务的默认值：*新任务*。
- **WBS 编码** — 任务的结构编码，例如 `RB-301`。必填。使用 *计划 › 结构 › WBS auto* 时，该字段被禁用（提示：*WBS 编码会自动编号（计划 → 结构）*），因为此时由应用管理编码。
- **描述** — 自由文本。对计算没有影响。你可以在表格中将其显示为 *描述* 列。
- **工作类别** — 任务的工作类别。列表分为 *内置工作类别*（*施工*、*安装*、*拆除*、*物流*、*检查*、*搬迁*、*翻新*、*维护*）、*我的工作类别* 和 *来自此项目*。*其他* 只有在任务已经有该工作类别时才会出现。底部有 *+ 新建工作类别…* 和 *管理工作类别…*。默认：父任务的工作类别；否则为 *施工*（施工模式开启时，这是默认值）或 *其他*。作用：对计算没有影响。你可以按它分组和筛选，也可以按它为任务条着色。应用会在你的设备上保存自定义工作类别。选择它时，会将一份副本加入项目（*来自此项目*）。如果你在 *+ 新建工作类别…* 中输入的名称已在 *我的工作类别* 中（即使大小写不同），应用不会创建第二个工作类别，而是选择已有的那个。在 *管理工作类别…* 中，你只能编辑或删除自己的工作类别；空名称或已存在的名称不会被保存。如果你删除了已打开项目正在使用的工作类别，应用会先询问，项目中的副本保持不变。*来自此项目* 下的工作类别（例如来自他人文件的工作类别）只有在你于 *管理工作类别…* 中点击 *添加到我的工作类别* 后，才会进入你的列表。
- **日历** — 任务在其中计算工期、完成日期和浮时的日历。默认：*项目日历：{name}*。作用：使用自己日历的任务，其工作日与项目日历不同。更改后，按 *计算* 重新计算日期。参见[日历和工作日](docs://uitleg-kalenders)。
- **父任务**（仅在窗口中）— 将任务移到另一个任务之下。默认：当前的父任务。*- 无（根级）-* 将任务放在最顶层。若某个选择会在关系中形成循环，*保存* 时会拒绝该选择并显示消息，窗口保持打开。

## 备注

- **备注** — 任务上的检查清单。*添加备注* 添加一行。勾选（*完成*）会划掉该行。垃圾桶图标（*移除*）会删除它。没有行时，它显示 *暂无备注。* 对计算没有影响。表格中的 *备注* 列会在前面显示 ✓ 或 ○。

## 里程碑

- **里程碑** — 将任务设为里程碑。默认：关。作用：工期变为 0。对于摘要任务（有子任务的任务）和有资源分配的任务，应用会拒绝此设置并显示消息。请先移除分配。取消勾选后，*里程碑类型* 和 *强制（合同性）* 会消失。
- **里程碑类型**（仅对里程碑）— *自动*、*开始里程碑* 或 *完成里程碑*。默认：*自动*。作用：开始里程碑位于一天的开始，完成里程碑位于一天的结束。选择 *自动* 时，里程碑作为前置任务出现时按开始里程碑处理，位于一天的开始。
- **强制（合同性）**（仅对里程碑）— 标记合同性里程碑，例如检查或交付。默认：关。作用：它只是 Gantt 和报表中的标记，不会锁定日期。若要锁定日期，请使用约束或截止日期。

## 时间

- **开始**（在窗口中为 *开始日期*）— 显示开始日期。这与 Gantt 任务条和 *开始* 列的日期相同，不是原始的计划锚点。对于已开始的任务，这是实际开始日期，该字段为只读；请改为更改 *实际开始*。否则，显示的是计算出的开始日期。必填：字段为空时会回退。输入时的作用：新日期会成为计划锚点（列 *计划开始日期*）。如果任务有前置任务且尚未开始，应用会在该日期记录一个约束 *不得早于…开始 (SNET)*（或移动已有的 SNET），并显示消息。因此，*计算* 后任务不会更早开始。如果任务有 *ASAP* 或 *SNET* 以外的约束，应用不会应用该开始日期，并说明哪个约束决定开始日期。
- **工期** — 任务的工作时长。输入 `5d` 表示天，或输入 `12h` 或 `1h 30m` 表示小时（`u`、`hour` 和 `hours` 也可用）。不带单位的数字按任务的工期单位计算。天数始终为整数，小时可以有小数。无效输入会显示 *请输入整数天数或小时数，例如 2d 或 12h。*，并且字段会跳回原值。新任务的默认值：5 天（里程碑为 0）。摘要任务、吊床任务和工期为 0 的里程碑，该字段被禁用：它们的工期由其他任务决定，或为零。以小时计的任务在 *启用小时计划* 关闭时，该字段被禁用；该按钮与此同名。作用：按 *计算* 后，工期决定任务在其日历中的完成日期。若任务有资源和任务类型，由任务类型决定工时或单位如何随之变化。若任务已部分完成，应用会拒绝比已完成工时更短的工期。参见[天和小时](docs://uitleg-dagen-en-uren)。
- **工期单位** — 在 *天* 和 *小时* 之间选择，旁边有一个信息按钮。仅当 *启用小时计划* 和 *允许混合按天/按小时计划* 都开启时可见（开启小时计划时，后者默认开启）。作用：选择另一个单位时，如果结果可以精确换算，应用会立即转换工期。*撤销* 可一步恢复。如果无法精确换算，单位保持不变，应用会说明此事。没有有效工作时间的日历会拒绝切换。
- **任务类型** — 当工期、单位或工时之一变化时，工期 × 单位 = 工时 中的哪一项保持固定。选项：*项目默认（固定工期和单位）*、*固定工期和单位*、*固定工期和工时*、*固定工时* 和 *固定单位*。默认：项目默认。该字段旁的 i 图标说明当前适用的任务类型；在展开的下拉列表中，每个选项旁边都有这样的 i 图标。对于来自 MS Project 的任务，该说明会考虑已存储的投入量驱动设置。仅当 *应用设置*（*计划* 选项卡，*计算* 标题）中开启 *使用任务类型*，或文件本身包含任务类型或已存储工时时可见；并且仅对普通任务可见：不适用于摘要任务、里程碑、吊床任务或以已用时间计的任务。参见[任务类型：工期、单位和工时](docs://uitleg-werkregels)。

## 吊床任务

- **吊床任务（派生工期）** — 让工期由另外两个任务决定，而不是拥有自己的工期。默认：关。仅适用于普通任务，因此不适用于里程碑或摘要任务。开启后：*开始驱动* 显示带有完成-开始或开始-开始关系的前置任务。*结束驱动* 显示带有完成-完成或开始-完成关系的前置任务。每个任务后面都显示其关系类型。如果没有结束驱动，它会显示 *没有结束驱动（FF/SF）— 跨度将回退为零长度。*，工期为零。参见[制作吊床任务](docs://howto-hammock)。

## 约束和截止日期

对摘要任务而言，约束或截止日期没有作用。计算只计算叶子任务，摘要任务的日期由其子任务推导。

- **约束** — 任务的日期限制。选项：*越早越好 (ASAP)*、*越晚越好 (ALAP)*、*不得早于…开始 (SNET)*、*不得晚于…开始 (SNLT)*、*不得早于…完成 (FNET)*、*不得晚于…完成 (FNLT)*、*必须开始于 (MSO)* 和 *必须完成于 (MFO)*。默认：*越早越好 (ASAP)*，即无约束。选择 ASAP 后，任务的所有约束都会消失。选择 ALAP 后，次要约束会消失。作用（按 *计算* 后）：限制会移动任务，或使浮时变为负值。参见[约束和截止日期](docs://uitleg-constraints)。
- **约束日期** — 与约束对应的日期。除 *ALAP* 外，每个约束都会显示此字段。必填。新约束的日期为计划开始日期。
- **强制（钉住逻辑）** — 仅适用于 *MSO* 和 *MFO*。默认：关。开启后：该日期为硬性日期，会覆盖关系。即使早于其前置任务，也会固定任务条。违反时会在上游产生负浮时。第一次开启时，会显示一次说明。
- **次要约束** 和 **次要日期** — 第二个限制，只能是 *SNET*、*FNET*、*SNLT* 或 *FNLT* 之一（或 *（无）*）。当存在非 ASAP、非 ALAP 且非硬性钉住的主要约束时可见。它始终为软性。禁止的组合会显示红色边框和原因。次要约束不能为硬性，不能与 MSO/MFO 或硬性钉住一起使用，不能与 ASAP/ALAP 一起使用，并且必须是边界。主要约束和次要约束不能约束同一侧。有效组合例如 SNET 与 FNLT。
- **截止日期** — 完成日期的目标日期。空 = 无截止日期。作用：任务不会因此移动。若最早完成日期更晚，浮时会变为负值，应用会报告 *截止日期 … 已错过 — 最早完成 …*。

## 进度

- **进度（%）** — 从 0 到 100 的滑块。默认：0。作用：大于 0 时，应用会补全缺失的 *实际开始*。为 100 时，会填入 *实际完成*。状态随之变化：没有实际开始时为 *未开始*，有实际开始时为 *进行中*，有实际完成时为 *已完成*。剩余工期（*剩余*）为工期 ×（1 − 进度），对于按天计的任务四舍五入到整天，对于按小时计的任务四舍五入到整分钟。已完成工时计算到状态日期为止。如果还没有状态日期，应用会将其设为今天，并说明此事。摘要任务的该字段被禁用：其进度在 *计算* 后由子任务推导得出（*由子任务推导得出：请在子任务中修改进度。计算（F5）后摘要任务随之更新。*）。
- **实际开始** — 任务真正开始的日期。晚于状态日期的日期会被拒绝。在任务表中，以及在提问 *填写实际开始日期* 时，晚于实际完成日期的日期同样会被拒绝。如果任务计划在状态日期之后才开始，但现在有了进度，窗口会询问 *填写实际开始日期*。对于里程碑，只有一个字段 *实际日期*，代替 *实际开始* 和 *实际完成*。
- **实际完成** — 任务真正完成的日期。填写它会将进度设为 100，状态设为 *已完成*。清空它会将进度设回 0，状态设为 *进行中*。晚于状态日期的日期会被拒绝，与 *实际开始* 相同。
- **剩余** — 只读（里程碑除外）：以任务的工期单位计，还剩多少工期。

窗口将这些规则应用于草稿；只有在 *保存* 后才生效。参见[进度、状态日期和基线](docs://uitleg-voortgang)。

## CPM 结果

- **CPM 结果** — 上次计算结果的只读视图：*最早开始*、*最早完成*、*最晚开始*、*最晚完成*、*总浮时*、*自由浮时*、*干扰浮时* 和 *关键路径*（*是* 或 *否*）。浮时以工作日表示，保留两位小数。结果已过期或尚未计算？请按 *计算*。

## 依赖关系

- **依赖关系** — 此任务的关系，每条关系占一行。每行显示：链接的任务（在面板中为 WBS 编码，若没有则为名称；在窗口中为名称）；若关系是驱动关系，则显示闪电图标（*驱动关系 (driving)*，计算后显示）；关系类型（*FS*、*SS*、*FF* 或 *SF*）；延隔；以及删除图标。在面板中，WBS 编码是一个按钮：指向它会显示任务，点击会跳转到该任务。编码前的一个小标记显示角色：前置任务为金色圆点，后续任务为紫色方块。颜色与[追踪路径](docs://howto-pad-traceren)中相同。屏幕阅读器也能通过按钮名称读出角色。在窗口中，它是纯文本。只有任务有关系时，才会显示此部分。
- **延隔** — 输入数字和单位：`2d` 工作日，`3ed` 日历天，`2u` 或 `2h` 工作时间，`3eu` 或 `3eh` 日历小时，`50%` 表示前置任务工期的百分比，`-25e%` 表示按日历时间计算的百分比。负号表示提前量。不带单位时按工作日计算。无效输入会使字段变红，并恢复原值。参见[关系与延隔](docs://uitleg-relaties)。
- **添加关系**（仅在面板中）— 打开一个草稿行。在 *方向* 下选择 *前置任务* 或 *后续任务*。用 *搜索任务*… 按 WBS 或名称查找任务。选择类型和延隔，然后按 *创建关系*（或 *取消*）确认。若关系重复，或与任务自身的父任务相同，会被拒绝并显示消息，草稿行保持不变。

## 中断

只在面板中可用，不适用于里程碑、摘要任务、吊床任务、以已用时间计算的任务、手动计划的任务，或太短而无法插入中断的任务。

- **中断** — 任务工作中的暂停。每个暂停占一行：*之后*（暂停前的工时）、*暂停*（时长）和单位（*工作日*；以小时计的任务为 *小时*），下方显示其后一段的起止日期。资源平衡产生的暂停带有标记 *资源平衡*。时长为 0 的暂停会被移除；每行的垃圾桶图标（*删除中断*）同样会删除它。效果：任务条以断开的方式绘制，执行 *计算* 后，完成日期会按暂停的时长后移。
- **添加中断** — 在最长的一段中间添加一个时长为一个时间单位的暂停。没有空间插入暂停时，此项禁用。
- **删除全部中断** — 当中断来自源文件，且其格式无法在此编辑时出现（*这些中断来自源文件，其格式无法在此编辑。*）。此时你只能看到日期。

参见 [拆分任务](docs://howto-taak-splitsen)。

## 分配

- **分配** — 此任务上的资源。每个资源占一行：一个箭头、一个资源颜色的小方块、名称、*单位*、*工时（小时）* 和一个垃圾桶（*移除*）。行上方的表头标明各列。点击名称可显示 *曲线*、按钮 *工时分布…* 和 *移动到…*（位于其下方）。再次点击可隐藏它们。如果分配的曲线不是 *均匀*，或有自己的工时分布，名称旁会显示一个柱状图标，即使折叠时也一样。底部有一个列表 *分配资源*；在其中选择资源会以每天 1 个单位分配该资源。没有资源时，会显示 *请先创建资源（资源标签页）。*；所有资源都已分配时，会显示 *所有资源均已分配。* 对于里程碑或摘要任务，会提示无法分配。
- **单位** — 此任务每天使用该资源的量（每天单位数），数字需大于 0。字段最多显示两位小数；精确值在提示中显示。可以输入逗号或小数点。作用：直方图中的负荷和过度分配；若有任务类型，则影响工时。若分配来自 Primavera P6（`.xer` 或 P6 XML）且仍有剩余工作，这就是剩余速率（P6 中的 *剩余单位/时间*）。计划速率仍保存在表格列 *每日计划单位* 中。
- **工时（小时）** — 此资源在此任务上的剩余工时（以小时计）。仅当任务类型可见且该任务设有任务类型时才显示；对于材料，显示一个破折号。表头中的锁图标显示任务类型保护的是哪一项（*由任务类型保护…*）。字段中的警告三角（*与单位 × 工期不一致*）表示已存储的工时不等于单位 × 剩余工期；此时直方图以已存储的工时为准。
- **曲线** — 工时如何分布在工期内：*均匀*、*前置加载*、*后置加载*、*钟形*、*前期高峰*、*后期高峰*、*双峰* 或 *龟形*。默认：*均匀*。如果分配有自己的工时分布，会显示 *轮廓*，且列表被禁用；导入的曲线显示为 *导入的曲线*。
- **工时分布…** — 打开此分配在每个工作日的工时分布。参见[调整工时分布](docs://howto-urenverdeling-aanpassen)。
- **移动到…** — 将分配移到另一个尚未分配该资源的末级任务。仅当存在这样的任务时才可见。

## 代码与字段

- **代码与字段** — 只有项目中有活动代码或自定义字段时才可见。每个活动代码是一个列表，包含 *（无）* 以及以 `代码 — 说明` 形式显示的值；每种类型最多选择一个值。每个自定义字段都有一个适合其类型的输入框：*文本*、*数字*、*整数*、*成本*、*日期* 或 *是/否*。效果：对计算没有影响；你可以按这些字段分组和筛选，也可以将它们显示为列。参见 [代码与自定义字段](docs://howto-codes-en-velden)。

## 任务类型下的标记

只在面板中显示，且仅在适用时显示。

- **长时间非工作时段** — *此任务跨越一个 … 天的非工作时段（… 至 …）。*，或附加假日或施工假期的名称。当任务跨越连续 8 天或以上且包含至少一个假日的时段时出现。这是警告，不是拒绝；请检查计划是否确实应当如此。
- **MS Project 标记** — 一个标记：*跟随 MS Project 的工时分布*、*编辑后不再应用 MS Project 日期窗口 — …* 或 *自定义工时分布*，并附带 *了解更多*。它显示 MS Project 文件中的工时分布是否仍然决定日期。
- **已记录日期** — 在 *时间* 顶部、*开始* 正上方的一个块，只要应用显示的是文件中的日期就会出现。橙色：*你看到的是文件中的日期，而不是应用的计算结果。*（对于 Primavera 文件为 *你看到的是 Primavera 保存的日期，而不是应用的计算结果。*），其下方为 *重新计算时，此任务会发生变化。* 或 *重新计算时，此任务保持不变。*。如果文件没有包含此任务的全部信息，会多出第三行，列出缺少的值：*文件中没有此任务的全部信息。缺少：…*（对于 Primavera 为 *Primavera 没有保存此任务的全部信息。缺少：…*）。该块保持橙色。并附带 *了解更多*。参见[按记录显示的日期](docs://uitleg-datums-zoals-opgeslagen)。

## 面板的顶部与底部

- **删除任务** — 标题 *任务* 旁边的垃圾桶图标；会同时删除此任务及其子任务，作为一个步骤，可以用 *撤销* 撤回。之后计划就不是最新的，直到你按 *计算*。
- **计算** — 底部的按钮；与 *首页 › 进度 › 计算* 执行相同的计算。

## 这里找不到的内容

- **资源平衡优先级** — 不在窗口或面板中。你可以右键单击并选择 *优先级*（*低* = 100，*普通* = 500，*高* = 900），或在 *资源平衡优先级* 列中输入 0 到 1000 之间的数字来设置。默认：500。效果：资源平衡会优先保留优先级较高的任务不动；1000 会锁定任务，使资源平衡永远不会移动它。参见 [资源平衡](docs://uitleg-nivelleren)。
- **其他任务数据** — 任务所含的其余数据，例如列 *手动计划*、*颜色* 和技术列，只在表格中显示；参见 [表格列](docs://ref-tabelkolommen)。
