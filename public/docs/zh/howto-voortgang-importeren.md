# 从表格导入进度

目标：一次性把工地人员在表格中填写的进度导入计划，无需你逐个点击任务。

## 何时需要此操作

分包商或工地经理没有此应用，但每周都会报告其进展：完成了百分之多少、何时开始、何时完成。你向其发送一份包含你任务的表格，其填写三列后再发回。应用从中只读取每个任务的三个值：完成度、实际开始日期和实际完成日期。你计划的其余部分保持不变。应用如何处理这些进度，见[进度、状态日期和基线](docs://uitleg-voortgang)。

## 步骤

### 1. 设置状态日期并计算

按照[更新进度](docs://howto-voortgang-bijwerken)中的说明设置状态日期。工地经理填写到该日（含当日）的实际日期。如果计划已过时，应用会在制作表格之前重新计算。

### 2. 制作表格

选择 *计划 › 进度 › 导出进度表*。同一个按钮也在 *表格* 和 *报告* 选项卡上。应用会生成一个 Excel 文件，建议文件名为 *(project name)-voortgang.xlsx*；在浏览器中，文件会保存到你的下载内容中。更喜欢 CSV 吗？请选择 *文件 › 导出 › 进度表（CSV）*。Excel 表格也在这里，名称为 *进度表（Excel）*。

表格有八列。列名保留英文，后面附有一句简短的中文说明：

- `OPS Task ID`、`WBS` 和 `Name` 仅用于识别任务。请勿修改。
- `Start` 和 `Finish` 是计划的日期，仅供参考。应用绝不会将其写回。
- `Completion (%)`、`Actual Start` 和 `Actual Finish` 是需要填写的列。

Excel 表格已受保护（无密码）：只有三个填写列可以编辑。Excel 会检查百分比是否在 0 到 100 之间，以及实际日期是否为有效日期。阶段（摘要任务）以灰色标记，并带有 *— 摘要任务：请勿填写*。

### 3. 请人填写表格

对于每个任务，工地经理填写以下内容：

- `Completion (%)`：0 至 100（含）。应用也能读取小数，可用逗号或句点（例如 33,3 或 33.3）。CSV 中的说明仍要求填写整数：地区设置不同的电子表格可能会把 8,38 读成 838。
- `Actual Start` 和 `Actual Finish`：在 Excel 中，按你所在地区设置的日期格式填写；在 CSV 中，按 dd-mm-yyyy 或 yyyy-mm-dd 格式填写。

空白的单元格不会改变任何内容。因此，空单元格也不会清除现有进度；这只能在应用中完成。尚未开始的任务，其对应单元格应完全留空。

### 4. 读入表格

1. 选择 *计划 › 进度 › 从表格更新进度*（同样位于 *表格* 和 *报告* 选项卡上），或选择 *文件 › 导入 › 从表格更新进度*。随即打开 *从表格更新进度* 窗口。
2. 点击 *选择文件*…，然后选择填好的 `.xlsx` 或 `.csv` 文件。
3. 如果 CSV 中的日期含义不明，应用会询问 *日在前还是月在前？*，并以两种方式显示文件中的日期。点击正确的日期。
4. 现在你会看到预览。顶部有四个计数器：*已应用*、*未更改*、*等待关联* 和 *已拒绝*。其下方按任务列出会有哪些变化，例如 *完成度：0% → 100%*。
5. 检查预览，然后点击 *应用*。窗口会显示 *结果*，包括各计数器以及被拒绝的行及原因。最后点击 *关闭*。

你不能跳过预览。只要没有可应用的内容，*应用* 按钮就保持禁用。

### 5. 重新计算计划

读入表格本身不会重新计算。请按 **计算**（F5），例如通过 *计划 › 进度 › 计算*，除非已开启 *自动计算*。

## 不能直接匹配的行

应用会把每一行链接到一个任务：先按 `OPS Task ID` 匹配，否则按 WBS 编号匹配。

**关联存疑。** 如果应用只按 WBS 编号找到任务，该行会列在 *关联存疑* 下，并带有 *确认* 和 *更改* 按钮。如果你不做任何操作，该行也会被应用；因此请检查任务是否正确。*确认* 会把该行移出此列表；它不会改变将被应用的内容。*更改* 让你选择另一个任务。*清除关联* 可删除你自行建立的链接。注意：与其他项目使用相同 WBS 编号的表格仍会被链接，列在 *关联存疑* 下，并在你点击 *应用* 时被应用。

**等待关联。** 如果应用未找到任务，或找到多个相同 WBS 编号的任务，该行会列在 *等待关联* 下。在 *选择一个任务*… 中选择正确的任务；你可以按 WBS 编号或名称搜索。如果你不将其关联，该行会被拒绝。

## 常见问题及应用的处理方式

不匹配的行会因某个原因被拒绝。表格中的其余部分会继续处理。以下是主要消息：

- *实际日期晚于状态日期。* 请将状态日期设置得更晚，或更正表格。
- *此任务计划在状态日期之后才开始：请先在表格中填写其实际开始日期。* 应用不会自行推算开始日期；请在表格中提供。
- *百分比超出 0–100 范围。请检查小数点：在使用不同区域设置的电子表格中，“8.38” 可能被读作 838。*
- *摘要任务不能从表格接收进度。* 阶段的进度由其下方的任务决定。
- *实际完成早于实际开始。*
- *日期无法读取。* 以及 *百分比无法读取。*
- *填写的值互相矛盾。* 例如，有实际完成日期但完成度低于 100。
- *未找到此行对应的任务。* 表格中提到的任务 ID 和 WBS 编号在此项目中不存在。
- *此 WBS 编码出现在多个任务上——请手动关联此行。*
- *另一行已认领此任务。* 两行指向同一个任务。
- *被计划引擎拒绝。* 计划引擎本身的另一种拒绝，没有单独的消息。

如果整个文件被拒绝，窗口中会显示以下消息之一：*此文件没有“OPS Task ID”或“WBS”列，无法将行与任务关联。*、*此文件没有完成度、实际开始或实际完成中的任何一列。*、*此文件太大，无法作为进度表读取。*（超过 16 MB）、*此文件行数太多，无法作为进度表读取。*（超过 50,000 行），或 *此文件受密码保护，无法读取。* 或 *此文件无法作为进度表读取。*

**没有状态日期。** 如果尚未设置状态日期，且导入会应用进度，应用会将其设为今天并通知你。因此请先自行设置。

**一次撤销全部。** 整个表格只算一个步骤，可用 Ctrl+Z 一次撤销。

**只更新你填写的内容。** 与计划没有差异的行计为 *未更改*。表格中没有对应行的任务保持不变。
