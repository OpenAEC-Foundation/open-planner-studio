# 在 Gantt 中拖动、平移和缩放

目标：用鼠标操作时间轴。移动任务条或调整其工期，平移时间轴，用框选择任务，以及放大和缩小。

## 何时需要此操作

你在 Gantt 中看到砌砖工作必须晚两天开始，或者浇筑要多花一天。于是你想直接在任务条上修改。或者你有一个跨越数月的项目，想快速滚动到施工假日。鼠标有几种手势可用于此。每种手势的作用取决于你从哪里开始拖动，以及你的滚动设置。

## 步骤

### 移动任务条

1. 按住任务条的中间部分，水平拖动。开始和完成日期一起移动，以整天为单位。工期保持不变。
2. 松开鼠标。任务条会保留在新位置。此时计划需要重新计算：按 *计算*（F5），或者若开启了 *自动计算*，应用会自动执行。

如果任务有前置任务，应用会把新的开始日期记录为约束 *不得早于…开始 (SNET)*，并在你松开鼠标后说明。原因以及其他约束的情况，见 [约束与截止日期](docs://uitleg-constraints)。如果你把任务拖回原来的开始日期，原来的约束也会恢复。

如果你主要向上或向下拖动，而不是左右拖动，任务会移到另一行，日期保持不变。你在最初几个像素中选择的方向适用于整个拖动。因此，一次手势不会同时改变日期和结构。见 [调整结构](docs://howto-structuur-aanpassen)。

### 调整工期

1. 把鼠标移到 Gantt 任务条的右边缘。光标会变成左右方向的箭头。
2. 拖动边缘。拖动时，主题的强调色（默认为橙色）的小标签会显示任务此时将获得的工期，例如 *4d*。标签实时更新，因此你在松开鼠标前就能看到新工期。在右边缘时，小标签位于任务条内；在左边缘时，它位于任务条左侧。小标签的显示方式与工期列相同。
3. 松开鼠标。工期即为小标签所显示的工期。

左边缘移动开始日期，完成日期不变。因此任务会从开始日期一侧变短或变长。与移动时适用相同的 SNET 规则。拖动任务条中间时，小标签不会出现：工期不变。

工期按任务日历的工作日计算。周末和休息日不计入。按天计量的任务不能短于一个工作日。按小时计量的任务，应用会按鼠标下方时间刻度的步长取整：至少一小时；如果你放大到足够近，并且已开启 *深度放大时显示刻钟*，则取一刻钟。

一次拖动就是 *撤销* 中的一步，无论你拖动多久。在拆分任务的任务条上，边缘的作用不同。见 [拆分任务](docs://howto-taak-splitsen)。

### 平移时间轴

在空白背景上拖动会做什么，取决于你的滚动模式。在 *应用设置* 中，打开 *外观* 选项卡，在 *甘特 › 滚动与缩放* 下的 *模式* 中选择：

- **缩放 + 拖动**（默认）：若用鼠标左键在空白背景上拖动，时间轴会随鼠标移动，像地图一样。光标为手形。若拖动的是任务条，则开始的是任务条手势。
- **位置** 和 **按键**：同样的拖动会画出选择框。你可以用滚轮（见 [应用设置](docs://ref-instellingen)）或鼠标中键来平移时间轴。

**鼠标中键**（按下滚轮）在每种模式下都会平移时间轴，即使你从任务条上开始也一样。在另一个手势进行中，例如拖动任务条时，它不起作用。

### 用框选择任务

框会选中它所碰到的行中的所有任务。只有框的高度有效，时间刻度不计。

1. 从空白背景开始。在 *缩放 + 拖动* 模式下，你要按住 Ctrl（Mac 上为 ⌘）同时操作。在 *位置* 和 *按键* 模式下则不需要。
2. 拖动经过你要选择的行。选择区域会显示一个边框。
3. 松开鼠标。拖动时按 Esc，会取消框选，选择保持原样。

更多关于选择的内容，见 [选择、删除和撤销任务](docs://howto-taken-selecteren-verwijderen)。在任务表本身的空白处拖动没有任何作用。

### 放大和缩小

1. 使用 *放大* 和 *缩小*（*开始 › 缩放*），或使用 + 和 - 键。滚轮也可以缩放。何时缩放取决于你的滚动模式（见 [应用设置](docs://ref-instellingen)）。
2. 如果你想看到整个项目，选择 *视图 › 时间刻度 › 适应项目*，或按 Ctrl+0。*重置*（在 *视图* 选项卡上）或按 0 键，会把缩放恢复为默认值。
3. 状态栏右下角显示以每天像素数表示的缩放级别，例如 *缩放：15 像素/天*。

你缩小得越远，网格线就越少。每天 8 像素或更多时，每天一条线，周边界处的线更粗。每天 2 到 8 像素之间，只保留周边界。每天低于 2 像素（年级别）时，只保留月边界。否则画布会变成均匀的条纹，任务条会消失。灰色的周末和休息日，以及交替着色的周色带，在每个级别都保留。线条消失时，它们体现周的结构。在时间轴标题中，只有在有足够空间时才显示周数和日期数字。每天 40 像素或更多时，还会在日期数字前显示星期几。

如果任务名称能完整放入任务条，则显示在任务条中。如果放不下，例如缩小视图时，完整名称会显示在任务条右侧。

### 查看任务详情

将鼠标在任务条上停留不动。会出现一个小卡片，显示任务名称、*WBS*、*工期*、*开始*、*完成*、*状态*、*关键* 和 *总浮时*。拖动、平移、框选或打开右键菜单时，卡片会消失。

## 常见问题及应用的处理方式

**开始日期不移动。** 如果任务有前置任务，并且约束不是 SNET，例如 *越晚越好 (ALAP)*，应用不会采用你拖动的开始日期。松开鼠标后，应用会说明是哪个约束限制了开始日期。修改该约束即可移动开始日期。右边缘仍然有效，因为它只改变工期。

**手势的作用不同。** 在关系模式和拆分任务模式中，任务条手势的作用不同。按 Esc 可退出这些模式。如果你在任务条上拖动时按住 Shift，会创建关系，而不是移动任务条。见 [添加关系](docs://howto-relaties-leggen)。

**在位置或按键模式下，左鼠标键不平移。** 此时光标是普通箭头，而不是手形。请使用滚轮或鼠标中键，或把模式设为 *缩放 + 拖动*。

**在拆分任务的任务条的间隔处点击。** 会选中任务，但不会开始拖动或框选。
