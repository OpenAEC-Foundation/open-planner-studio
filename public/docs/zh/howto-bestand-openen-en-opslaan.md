# 打开和保存文件

目标：从文件打开项目，并保留你的更改。

## 何时需要此操作

你开始新的一天时，要继续昨天的项目；你从同事或其他程序收到一个文件；或者你想在做大改动前保存一个中间状态。应用在文件中保存哪些内容，以及为什么只有 IFC 能保存整个项目，见 [文件和格式](docs://uitleg-bestanden)。

## 步骤

### 打开文件

1. 选择 *首页 › 文件 › 打开*，或 *文件 › 打开*，或按 Ctrl+O（在 Mac 上为 ⌘+O）。*文件* 组也在 *表格* 选项卡上。
2. 选择文件。你一次只打开一个文件。在桌面应用中，以及在有文件访问权限的浏览器中（例如 Chrome 和 Edge），窗口会显示文件类型列表：*所有支持的类型*、*IFC 文件*、*CSV 文件*、*XML 文件*、*MS Project 文件* 和 *Primavera XER 文件*。
3. 项目会在新选项卡中打开。如果当前选项卡仍然为空且未更改，项目会在该选项卡中打开。
4. 如果文件不是 IFC，会出现一个窗口，简要说明该格式。绿色框说明应用接管了什么，琥珀色框说明什么未包含或只部分包含，蓝色框说明保存和写回的方式。*了解更多* 会打开该格式的指南。点击 *知道了* 关闭窗口。如果你不想再看到该格式的此说明，请先勾选 *对 … 不再显示*。之后你可以在 [应用设置](docs://ref-instellingen) 的 *高级* 选项卡中重新开启它。

IFC 文件会把文件名作为选项卡名称。其他格式的项目会使用项目名称。

应用可以打开 `.ifc`、`.csv`、`.xml`（MS Project XML 或 Primavera P6 XML）、`.mpp` 和 `.xer`。对于最后两种格式，请分别参见 [打开 MS Project 文件 (.mpp)](docs://howto-mpp-openen) 和 [打开 Primavera P6 文件 (.xer)](docs://howto-xer-openen)。

### 打开最近的项目

选择 *首页 › 文件 › 最近*，然后点击列表中的文件，或选择 *文件 › 最近*。列表会保留你最近打开、保存或导出的十个文件。此处同样适用：非 IFC 文件之后会出现该格式的说明。桌面应用会显示每个文件的路径，浏览器只显示名称。

如果应用无法再读取列表中的某个文件，例如你移动了它，该文件会从列表中消失，不会显示任何消息。在没有文件访问权限的浏览器中（例如 Firefox），*最近* 会保持为空。

### 打开示例

选择 *文件 › 示例*，然后点击一个示例项目。它会在选项卡中打开，但没有文件：因此 *保存* 会询问你想把它存在哪里。

### 保存

选择 *首页 › 文件 › 保存* 或 *文件 › 保存*，或按 Ctrl+S。接下来发生什么，取决于你的项目：

1. 如果项目已经有文件（因为你打开了 IFC 文件，或之前保存过），应用会写入该文件。不会出现窗口，除非是第一次保存架构不是 IFC 4.3 ADD2 的文件。这时应用会先询问 *保存为哪个 IFC 架构？*（见 [选择 IFC 架构](docs://howto-ifc-schema-kiezen)）。
2. 如果项目还没有文件，应用会询问保存位置。它会建议使用项目名称加 `.ifc` 作为文件名。之后，该文件就是项目的文件。
3. 如果你的浏览器只能通过下载保存（例如 Firefox），文件会进入下载文件夹，每次保存都会产生一个新的下载。在一次会话中第一次保存时，你会看到消息 *以下载方式保存：'name.ifc' 位于下载文件夹中。此浏览器不允许应用写入自己的位置，因此每次保存都会产生新的下载。在 Chrome、Edge 或桌面应用中，保存只会更新同一个文件。*
4. 如果你的浏览器无法写回项目的文件，应用每次保存时都会再次询问文件存放位置。这看起来像 *另存为*，但这是浏览器的限制。在一次会话中第一次保存时，消息 *此浏览器不允许应用写回 'name.ifc'。* 会说明这一点，并附有 [文件](docs://uitleg-bestanden) 的链接。

保存后，*未保存* 标记会消失：选项卡上的圆点、顶部项目名称前的星号，以及状态栏右下角的 *未保存* 文字。

### 另存为

选择 *首页 › 文件 › 另存为* 或 *文件 › 另存为*，或按 Ctrl+Shift+S。选择名称和位置（在 Firefox 中，应用会改为下载一个新文件）。之后，项目会使用这个新文件：下一次 *保存* 会写入这里。旧文件保持你上次保存时的样子。

### 关闭项目

点击选项卡上的叉号，或选择 *文件 › 关闭项目*。如果项目有你未保存的更改，应用会询问：*未保存的更改：'name' 有尚未保存的更改。* 你可以选择 *取消*（项目保持打开）、*不保存*（项目关闭，你的更改会丢失）或 *保存*（先保存，再关闭）。如果你在桌面上关闭整个应用（用关闭按钮、Alt+F4 或操作系统菜单），应用会对每个有更改的项目询问这一点；*取消*，或保存失败，都会停止关闭。正常关闭后，应用会清理本次会话的恢复副本，因此恢复窗口只会在真正崩溃后出现。如果项目有更改，而你关闭浏览器标签页或窗口，浏览器会要求确认。

## 可能的问题及应用的处理方式

**打开的 IFC 文件会立即成为你项目的文件。** *保存* 会覆盖该文件，即使它来自其他程序。如果你想保留原文件，请先选择 *另存为*。

**其他格式永远不会被覆盖。** 打开 `.csv`、`.xml`、`.mpp` 或 `.xer` 后，项目没有对应文件。*保存* 会写入一个新的 IFC 文件，并保持原文件不变。

**在 Firefox 中，每次保存都会生成新文件。** 应用无法写入你的文件。它每次都会下载一个新文件，文件名是项目名称，而不是你打开的文件名。

**Chrome 和 Edge 会请求许可。** 第一次 *保存* 你打开的文件时，浏览器会询问应用是否可以写入该文件。如果你拒绝，应用会打开一个窗口，让你选择新文件。在 Chrome 和 Edge 中，如果写入现有文件失败（例如文件已消失或被锁定），也会出现该窗口。

**关于重复 id 或不计入计算的关系的消息。** 打开文件后，消息可能会留在屏幕上。如果显示 *文件中有重复 id 的对象*，每个重复对象都会获得自己的 id，引用会指向第一次出现的对象。此时请检查关系和分配。如果显示 *无法纳入计算的关系*，该关系位于摘要任务上，因此不起作用，例如某个任务链接到它自己的摘要任务。文件本身保持不变。关于摘要任务上的关系会产生什么影响，参见 [关系](docs://uitleg-relaties)。

**保存可能失败。** 如果保存本身出错，应用会报告 *保存失败*，并给出原因。你的项目保持打开，并且仍标记为 *未保存*。
