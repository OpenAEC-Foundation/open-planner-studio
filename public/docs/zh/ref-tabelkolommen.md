# 表格列

任务表有 86 个固定列，另外为项目的每个活动代码和自定义字段各有一列，并为每个基线有八列。本文说明每一列显示什么、是否可以编辑，以及值以何种形式书写。如何选择和排列列，请参见 [自定义表格列](docs://howto-tabelkolommen-aanpassen)。

## 在哪里选择列

Gantt 旁边的任务表和 *表格* 选项卡中的表格各自有自己的列选择。表头右侧的加号会打开列选择器（窗口标题为 *选择列*）。在 *表格* 选项卡中，你也可以使用 *表格 › 列 › 列…*。选择器按类别列出各列：*任务*、*计划*、*约束*、*关系*、*资源*、*进度*、*已计算*、*基线*、*自定义* 和 *技术信息*。你可以按名称搜索，*最近使用* 位于顶部。*恢复默认* 会恢复默认列。

默认情况下，Gantt 旁边的任务表显示 *WBS*、*任务名称* 和 *工期*。*表格* 选项卡中的表格显示 *WBS*、*任务名称*、*工期*、*开始*、*完成*、*工作类别*、*关键*、*总浮时* 和 *进度*，另外还为项目的每个活动代码和自定义字段显示一列。

## 如何读取和编辑值

- **计算列** — 类别 *已计算* 中的列以及其他多个列为只读：它们来自计算结果。如果你尝试编辑只读单元格，应用会显示 *无法编辑此计算列。* 该文本是所有只读单元格的通用消息，即使该列并非计算列也是如此。如果因你更改了某项内容而导致这些列过期，它们旁边会显示 *已过期*，直到你按 *计算*。
- **日期** — 以你在 *应用设置* 中、*外观* 选项卡的 *日期格式* 标题下选择的格式显示。
- **工期和浮时** — 工期以任务的单位显示（`5d`、`12h`），或按同一选项卡中的 *工期显示* 显示（*自动（按任务自身单位）*、*始终按天* 或 *始终按小时*）。浮时以工作日显示，保留两位小数，小数分隔符为你所用语言的分隔符。
- **是/否** — 是/否值显示为 *是* 或 *否*；空值显示为破折号（—）。
- **编辑** — 输入或选择一个值。无效值会被拒绝，单元格下方会显示原因，例如 *请输入有效的工期，例如 5d 或 8h。* 或 *请输入 0 到 100 之间的百分比。* 粘贴一组单元格时会逐个单元格处理；只读单元格会被跳过，应用会报告跳过的数量。

## 任务

- **任务名称** — 任务的名称。可编辑；必填。摘要任务以粗体显示，名称单元格带浅色背景底纹；里程碑以粗体显示，颜色为里程碑颜色（与 Gantt 中里程碑同一色系）。普通任务保持不变。这只是格式：选择、拖动和编辑的操作方式相同。
- **描述** — 描述内容。可编辑；自由文本。
- **WBS** — WBS 代码。可编辑且必填，但在 *WBS auto* 开启时为只读。
- **工作类别** — 工作类别（*施工*、*安装*、*拆除*、*物流*、*检查*、*搬迁*、*翻新*、*维护* 或 *其他*）。可通过列表编辑。
- **自定义工作类别** — 项目中的自定义工作类别，或破折号。可通过项目自定义工作类别的列表编辑。
- **颜色** — 任务已保存的颜色，以颜色代码表示，例如 `#1a73e8`。可通过颜色选择器编辑。它保存在 IFC 文件中，但没有任何任务条或报表使用它；任务条颜色请在 *视图 › 基线与进度 › 条形图颜色* 下设置。
- **备注** — 备注以 `✓ text; ○ text` 形式显示。只要最多只有一条备注，即可编辑（然后编辑其文本）；备注超过一条时为只读。

## 计划

- **里程碑** — 任务是否为里程碑。可编辑。开启后工期变为 0；对于摘要任务和有分配的任务，应用会拒绝此操作。
- **里程碑类型** — *开始里程碑* 或 *完成里程碑*，或表示自动的破折号。仅可在里程碑上编辑。
- **强制里程碑** — 标记 *强制（合同性）*。仅可在里程碑上编辑。
- **资源平衡优先级** — 0 到 1000 之间的整数，默认为 500。可编辑。设为 1000 时，该任务在资源平衡中被固定。
- **拆分间隔** — 中断次数，显示为 `Split gaps: 2`，或破折号。只读；你在 *属性* 面板中编辑它们。
- **任务类型** — 任务的任务类型；留空表示项目默认值。可通过列表编辑，但在里程碑、摘要任务或吊床任务上为空且只读。只有在任务类型可见时（*使用任务类型*，或文件包含任务类型），才会在选择器中显示。
- **吊床任务（派生工期）** — 任务是否为吊床任务。可编辑，但里程碑或摘要任务除外。
- **日历** — 任务自身日历的 ID；空（—）表示项目日历。你可以从建议列表中输入或选择 ID；未知的 ID 会被拒绝。注意：该单元格目前显示内部 ID，而不是名称；最好在 *属性* 面板中选择日历。
- **工期类型** — *工作时间*（工期按日历中的工作日或工作小时计算）或 *已用时间*（工期按连续的时钟时间计算，不使用日历）。可编辑。
- **工期单位** — *天* 或 *小时*。可编辑，但摘要任务、吊床任务或里程碑除外；只有在换算精确且已开启 *启用小时计划* 时才能切换。
- **工期** — 任务的工期，按任务的单位或按 *工期显示* 显示。可编辑：输入 `5d`、`12h` 或 `1h 30m`；也可以输入任务单位的数字。在摘要任务、吊床任务以及工期为 0 的里程碑上为只读。
- **开始** — 显示的开始日期，与 Gantt 任务条的日期相同。对于已开始的任务，该日期为实际开始日期。可编辑。如果你为有前置任务的任务设置新的开始日期，该任务会在该日期上获得约束 *不得早于…开始 (SNET)*。在摘要任务或吊床任务上为只读，除非是手动计划；在已开始的任务上也为只读（*此任务已开始；其开始日期为实际开始日期。请通过进度进行更改。*）。
- **完成** — 显示的完成日期。对于已完成的任务，该日期为实际完成日期。可编辑：新的完成日期会变成新的工期。应用会拒绝里程碑、已用时间的任务和有中断的任务的此操作，以及完成早于开始的情况（*完成早于开始。*）。在摘要任务或吊床任务上为只读，除非是手动计划；在已完成的任务上也为只读（*此任务已完成；其完成日期为实际完成日期。请通过进度进行更改。*）。
- **计划开始** — 计算所基于的计划锚点（不一定是显示的开始日期）。可编辑；效果与在 *开始* 中输入相同。
- **计划完成** — 输入的完成日期。仅可在手动计划的任务上编辑；否则应用会显示 *计划完成日期仅适用于手动计划的任务。请通过“完成”列或工期更改完成日期。*

## 约束

- **约束类型** — 约束的类型，从 *越早越好 (ASAP)* 到 *必须完成于 (MFO)*。可编辑；没有约束的任务显示 *ASAP*。
- **约束日期** — 约束的日期。可编辑。
- **硬约束** — 标记 *强制（钉住逻辑）*。仅可在 *MSO* 和 *MFO* 上编辑。
- **次要约束类型** — 第二个边界的类型，或破折号。可编辑；表格提供所有类型，但不允许的组合会被拒绝：它必须是 *SNET*、*FNET*、*SNLT* 或 *FNLT*，主约束必须是边界（不能是 *ASAP*、*ALAP*、*MSO*、*MFO* 或硬约束），并且两者必须约束相反的两侧（下边界 *SNET*/*FNET* 配上上边界 *SNLT*/*FNLT*，或反过来）。
- **次要约束日期** — 第二个边界的日期。可编辑。
- **截止日期** — 完成的目标日期。可编辑。

## 关系

- **前置任务** — 前置任务，格式为 `WBS type±lag`，以 `; ` 分隔，例如 `1.2 FS+2d`。可通过输入相同格式进行编辑。你不能在此处添加外部关系，而要使用 *计划 › 关系 › 链接 › 添加外部关系…*。
- **后续任务** — 后续任务，格式相同。可编辑。
- **驱动关系** — 决定该任务日期的关系，显示为 `← 1.2`（前置任务）或 `→ 1.4`（后续任务）。只读；在按 *计算* 之前均已过期。
- **自由浮时**（类别 *关系* 中）— 每个关系的自由浮时，显示为 `← 1.2: 3d`。与 *已计算* 下的 *自由浮时* 不是同一列，后者显示任务本身的浮时。只读。
- **警告** — 每个关系的警告，例如 *顺序异常* 或 *未计入计算*。只读。另见 [通知和警告](docs://ref-meldingen)。

## 资源

- **分配的资源** — 分配的资源的名称，以逗号分隔。可编辑：添加名称会以每天 1 个单位分配该资源，删除名称会移除该分配。在里程碑或摘要任务上为只读。
- **每日分配单位** — 每个资源的单位，显示为 `Name: 1; Name: 0.5`，最多两位小数。存储的值保持精确。可在有分配的任务上编辑。
- **计划每日单位** — 每个资源的计划速率，显示为 `Name: 1.11`，最多两位小数，格式与 *每日分配单位* 相同。仅适用于来自 Primavera P6 且剩余速率不同的分配；此时 *每日分配单位* 显示剩余速率。只读。
- **分配曲线** — 每个资源的曲线，显示为 `Name: Uniform`。可在有分配的任务上编辑。
- **工作窗口开始** 和 **工作窗口完成** — 每个资源的工作窗口，来自导入的文件，显示为 `Name: date`。只读。
- **计划工时（小时）** 和 **实际工时（小时）** — 每个资源的计划工时和实际工时，以小时计，显示为 `Name: 617.14`，最多两位小数，来自导入的文件。只读。
- **剩余工时（小时）** — 每个资源的剩余工时，以小时计，显示为 `Name: 6` 或 `Name: 26.67`：即已保存的工时；否则为剩余工期 × 单位。可在适用任务类型的有分配任务上编辑，小数分隔符可用逗号或小数点。只有在任务类型可见时才会在选择器中显示。单元格中的黄色 ⚠ 表示已保存的工时与单位 × 剩余工期不同，与任务面板中 *工时（剩余）* 旁的 ⚠ 相同。

## 进度

- **状态** — *未开始*、*进行中* 或 *已完成*。可编辑，但摘要任务除外。
- **进度** — 完成度的百分比，显示为 `40%`。可输入 0 到 100 之间的数字进行编辑，但摘要任务除外。
- **实际开始日期** — 任务开始的日期。可编辑，但摘要任务除外。
- **实际完成日期** — 任务完成的日期。可编辑，但摘要任务除外。
- **实际工期** — 实际工期，以数字表示。可编辑，但摘要任务除外。
- **剩余** — 剩余工期，以任务的单位表示。可编辑，但摘要任务除外。
- **恢复日期** 和 **停止日期** — 来自 MS Project 或 Primavera 文件的运行中任务的恢复和停止。只读。

进度列遵循应用的进度规则：晚于状态日期的实际日期会被拒绝。在摘要任务上，应用会显示 *摘要任务的进度由其子任务推导得出，无法在此处修改。*

## 已计算

此类别中的所有列均为只读。

- **资源平衡延迟** — 资源平衡将任务延迟了多少个工作日；如果未应用资源平衡，则显示破折号。
- **最早开始** 和 **最早完成** — 计算得出的最早日期。对于已开始的任务，它们可能与 *开始* 和 *完成* 不同：计算配置文件 *Primavera P6* 会将进行中或已完成任务的最早开始日期设为状态日期。
- **最晚开始** 和 **最晚完成** — 任务仍可开始或结束而不延误项目的最晚日期。
- **自由浮时** — 任务在不延误后续任务的情况下可以推迟的工作日。
- **总浮时** — 任务在不延误项目完成的情况下可以推迟的工作日。如果无法满足约束或截止日期，则为负数。
- **关键** — 任务位于关键路径上时为 *是*。
- **干扰浮时** — 总浮时减去自由浮时。
- **近关键** — 近关键任务为 *是*。仅当 *标记为接近关键* 已开启时才会填写（*项目设置*，区块 *计算配置文件和选项*）；否则显示破折号。
- **浮时路径** — 浮时路径的编号，1 表示最关键的路径。仅当 *多条浮时路径* 已开启时才会填写；否则显示破折号。
- **已记录日期的来源** — 只要应用显示文件中的日期：对于文件未包含全部内容的任务，显示 *部分未记录*。只有在该视图中，此列才会在选择器中显示。在未记录的时间轴上，*未记录* 会显示在最晚日期和浮时列中。

另见 [关键路径和浮时](docs://uitleg-kritiek-pad)。

## 基线

每个项目基线都会添加列，列名前面带有基线名称（`<baseline> — Scheduled start`）。它们为只读。不在基线中的任务会显示破折号，提示文字为 *此基准中不存在*。

- **计划开始**、**计划完成** 和 **工期** — 基线记录的开始、完成和工期。
- **开始差异** 和 **完成差异** — 基线与显示的开始或完成之间的工作日数，按项目日历计算；任务晚于基线时为正数。
- **工期差异** — 当前工期减去基线中的工期，以工作日计。

## 自定义

- **活动代码** — 每个活动代码一列，列名为代码名称。显示所选值的代码。可编辑：你可以输入代码，或从建议中选择；未知的代码会被拒绝；如果某个代码出现多次，应用会要求你从列表中选择。
- **自定义字段** — 每个自定义字段一列，列名为字段名称。输入内容与字段类型相符：文本、数字、整数、成本、日期或是/否。可编辑。

这些列属于代码或字段所在的项目。另见 [代码和自定义字段](docs://howto-codes-en-velden)。

## 技术信息

此类别中的所有列均为只读。它们显示应用所保存、但不在普通列中显示的数据，例如用于检查导入内容。

- **任务 ID** — 任务的内部 ID。
- **父任务 ID** 和 **子任务 ID** — 父任务和子任务的 ID。
- **资源 ID** — 任务上资源的 ID。
- **分配 ID**、**分配任务 ID** 和 **分配资源 ID** — 此任务的分配、任务和资源的 ID。
- **工期（分钟）** 和 **剩余（分钟）** — 以分钟计的工期和剩余工期；仅对以小时计的任务填写。
- **资源平衡延迟（分钟）** 和 **已用资源平衡延迟** — 来自 MS Project 的资源平衡延迟（以分钟计），以及它是否按时钟时间计算。
- **手动计划** — 任务是否为手动计划。
- **MS Project 任务类型（导入）** 和 **投入量驱动** — MS Project 中的任务类型和投入量驱动标记。
- **Primavera P6 来源** — 来自 Primavera 文件的源字段，显示为 `key: value`。
- **明确的摘要任务** — 任务是否为没有子任务的明确摘要（来自 Primavera 文件）。
- **按时间分段的完成下限**、**按时间分段的开始锚点**、**按时间分段的工期段** 和 **按时间分段的轮廓** — 来自 MS Project 文件的工时分布，以日期和计数表示。
- **活动代码数据**、**自定义字段数据** 和 **备注数据** — 代码分配、自定义字段和备注的数量。
- **内部关系数据** 和 **外部关系数据** — 内部和外部关系的数量。
- 每个基线的 **里程碑** 和 **里程碑类型** 也在这里，按基线记录的内容显示。
