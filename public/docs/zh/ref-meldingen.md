# 通知和警告

应用会在四个地方告诉你正在发生什么：底部的状态栏、右侧栏中的 *警告* 面板、屏幕底部短暂出现的通知，以及功能区下方的条带。本文说明每个位置你会看到什么、何时出现，以及你能做什么。为何计划中的某项任务是关键任务，或某项资源过度分配，见 [关键路径和浮时](docs://uitleg-kritiek-pad)；如何解决过度分配，见 [解决过度分配](docs://howto-overbezetting-oplossen)；如何创建关系，见 [创建关系](docs://howto-relaties-leggen)。

## 四者的区别

- **状态栏** — 一行固定的计数器。它们来自上次计算，直到你再次计算前都保持不变。
- **警告面板** — 这些计数器背后的列表，包含上次计算发现的全部内容。点击后会带你到任务、关系或资源。它来自上次计算；不存储任何内容。
- **通知** — 关于你刚做过的操作的简短消息（保存失败、关系被拒绝、导入已读取）。信息会自动消失。错误会一直显示，直到你关闭它。通知不会出现在面板中。
- **功能区下方的条带** — 一个彩色条带，带有一段说明和一个按钮。它对应文档或某种模式的状态，只要该状态仍然适用，就会一直显示。见 *功能区下方的条带*。

## 状态栏

底部的栏从左到右显示：

- **任务：** — 叶任务的数量（不计摘要任务）。
- **里程碑：** — 里程碑的数量。
- **关键路径：N 个任务，N 个工作日** — 关键任务的数量和项目工期。仅在计算后可见。
- **结束：** — 计算得出的项目完成日期。仅在计算后可见；空项目没有这一项。
- **N 个截止日期已错过**、**N 个约束被违反**、**N 个顺序错误的关系**和 **N 个资源过度分配** — 每项都是带警告标志的按钮，仅在计数大于 0 且有计算结果时可见。点击会打开 *警告* 面板（提示：*打开警告面板（详情与导航）*）。如果你位于 *IFC* 或 *报告* 选项卡，应用会同时跳到 *首页*，因为那里没有右侧栏。*资源过度分配*计数器在资源和分配变更后也会更新；其他计数器只在 *计算* 后变化。这四个计数器只是一部分：面板额外显示的内容（被截断的提前量、被忽略的关系、没有完成驱动的吊床任务、被截断的完成日期、计划错误）不在状态栏中。
- **已过期 — 请重新计算（F5）** — 带警告标志（提示：*计划已过期 — 请重新计算（F5）*）。只要你更改了影响计划的内容且尚未重新计算，它就会立即显示。如果已开启 *自动计算*，它会保持隐藏，但计算出错时除外：此时它会保持显示。
- **选择：N 个任务** — 所选任务的数量；仅在有选择时可见。
- **刻度：** 和 **缩放：Npx/天** — 时间线的时间刻度与缩放级别。刻度由缩放决定。
- **未保存** — 只要文档中有未写入文件的更改，就会显示。
- **AI** — 带彩色圆点的 AI 字样，仅在 AI 模式开启时显示。提示为 *AI 桥接：*，后面是 *已关闭*、*已在端口 N 上运行*、*端口 N 被占用* 或 *错误*。点击会打开 *AI* 选项卡。
- **调试终端** — 终端按钮，仅在启用调试终端时显示；用于显示或隐藏终端（*显示调试终端* / *隐藏调试终端*）。

## 警告面板

- **打开** — *计划 › 进度 › 警告*、*视图 › 面板 › 警告*，或状态栏中的计数器。面板位于右侧栏中，在 *属性* 和资源停靠区下方，并会展开已折叠的栏。默认情况下面板是关闭的，且不会在两次会话之间记住。当它位于其他面板下方时，可在边缘拖动调整高度，该高度会被记住。右上角的叉号可关闭面板（*关闭警告*）。
- **标题行** — *N 个错误，N 个警告*。如果还没有计算过，会显示 *尚未计算 — 按“计算”(F5) 运行检查。*
- **计算** — 标题行中的按钮，只要计划已过期或尚未计算就可见。它的作用与功能区中的 *计算* 相同。
- **标题行中的警告标志** — 计划已过期时显示，提示为 *计划已过期 — 此列表来自上次计算。请重新计算 (F5)。* 列表不会被隐藏，只会标记为已过期。
- **空列表** — *没有警告。计划通过了所有检查。*
- **一行** — 顶部是位置（任务、关系、资源或项目），其下是说明。错误带有八角形标志，警告带有三角形标志。任务显示为 `WBS name`。关系显示为 `predecessor → successor (FS+2d)`，并带有类型和延隔。点击会跳到该位置（提示：*跳转到：…*），见下文。与你的活动任务（关系则为其后续任务）或直方图中所选资源相关的行会高亮显示。
- **顺序** — 先显示错误；然后按下列类型顺序排列，每种类型内按文档顺序（关系按其后续任务的顺序，资源按资源列表的顺序）。上次计算后被删除的任务、关系或资源会从列表中消失。

### 警告的类型

- **计划错误** — *无法计算计划：…*，后面附上原因，见下文。点击时：对于循环，应用会选中循环中的所有任务，并跳到第一个；对于其他错误，没有可跳转的位置，该行不是按钮。
- **截止日期已错过** — *已错过截止日期 {date} — 最早完成 {date}*。该任务有截止日期，但计算结果未满足它。点击会跳到该任务。修复方法：调整逻辑或工期，或移动截止日期。
- **违反限制** — *限制 {type and date} 被逻辑覆盖（负浮时）*。在不破坏逻辑的情况下无法满足该约束；浮时为负。点击会跳到该任务。见 [约束](docs://uitleg-constraints)。
- **顺序错误** — *顺序错误：后续任务的进度与关系矛盾*。后续任务的进度与关系类型不符，例如在完成-开始关系下，后续任务已在进行中，而前置任务尚未完成。点击会选中两个任务，并使后续任务处于活动状态。请检查实际日期或关系。
- **提前量被截断** — *提前量被项目开始截断 — 关系未被完全遵守*。关系的提前量（负延隔）延伸到项目开始之前。点击会选中两个任务。
- **关系被忽略** — *关系被忽略：前置或后续任务缺失或不是叶任务*。计算不会使用该关系。点击会选中仍然存在的任务。见 [关系](docs://uitleg-relaties)。
- **没有完成驱动的吊床任务** — *吊床任务没有完成驱动（无 FF/SF 前置任务）：其工期回落为零*。点击会跳到该任务。见 [吊床任务](docs://howto-hammock)。
- **完成日期被截断** — *完成日期被截断：日历没有为此任务留下可工作的窗口*。计算达到了它所搜索天数的上限，例如因为日历中有一段很长的连续休息日。点击会跳到该任务。见 [日历和工作日](docs://uitleg-kalenders)。
- **过度分配** — *N 天过度分配（first – last）*；若所有这些日子都是休息日，则加上 *资源按其日历在这些日子不工作*；若为混合情况，则加上 *其中 N 天资源按其日历不工作*。点击会选中在该资源上有分配的任务，打开直方图并在其中选择该资源。从 *表格*、*IFC* 或 *报告* 打开时，应用会跳到 *资源*。见 [资源面板](docs://ref-resourcepaneel)。

### 计划错误的原因

- *任务之间存在循环依赖：{path}* — 关系形成了一个循环。路径中包含这些任务；请反转或删除一个关系。
- *日历中未设置工作日* — 为日历至少设置一个工作日，见 [日历窗口](docs://ref-kalenders)。
- *任务“{task}”的天数工期无效*和*任务“{task}”的小时工期无效* — 任务的工期不是有效数字。
- *小时任务“{task}”的日历中没有有效的工作时间* — 以小时计的任务位于没有工作时间的日历上。
- *任务“{task}”的开始日期无效* — 任务的开始日期无效。

## 功能区下方的条带

条带位于功能区正下方、工作区上方。它包含一段文字和一个按钮。表示模式的条带没有 ×；其他条带可以用 × 关闭。以下是五种条带：

- **链接模式** — *链接模式：在甘特图中从一个条形拖到另一个条形即可创建关系。按 Esc 退出。* 只要 Gantt 中的链接模式开启，条带就会一直显示。按钮：*停止*。见 [创建关系](docs://howto-relaties-leggen)。
- **拆分模式** — *在甘特条上点击中断开始的那一天，然后向右拖动设定长度。按 Esc 退出。* 只要 *拆分任务* 开启，条带就会一直显示。按钮：*停止*。
- **文件中的小时计划** — *此文件包含按小时的计划。* 当打开的文件包含小时计划，而 *启用小时计划* 未开启时，会出现此条带。按钮：*启用小时计划*。见 [开启小时计划](docs://howto-urenplanning-aanzetten)。
- **结构已锁定** — *筛选/分组/排序时不可用*。当任务表已被筛选、分组或排序，导致降级或升级被拒绝时，会出现此条带。按钮：*清除*，它会移除筛选、分组和排序。
- **记录的日期** — 打开一个文件后，如果重新计算改动了其中的日期，会显示：*重新计算使 N 个任务（共 M 个）偏离了文件中的日期。* 按钮为 *显示记录的日期*。当该视图开启时，会显示：*你正在查看文件中记录的日期……* 按钮为 *重新计算*。见 [记录的日期](docs://uitleg-datums-zoals-opgeslagen)。

## 通知

通知显示在屏幕底部，也显示在表格、后台视图和演示模式中。通知是*错误*或*信息*。错误为红色，会一直显示，直到你点击叉号。信息会在 5 秒后消失（说明较多的通知会显示更久），只要通知栈发生变化，这些计时器就会重新开始。每个通知右上角都有一个叉号（提示文字为*关闭通知*），点击后会立即关闭该通知。点击通知的文字不会有任何作用。拒绝操作始终是错误：应用未能执行你的某项操作时，会显示通知，例如关系、工期、开始或里程碑被拒绝。因此，即使你暂时移开视线，也不会错过它。按 Ctrl+Z 或 Ctrl+Y 后，以及切换到另一个文档时，拒绝操作的通知会消失，因为此时它已不再正确。其他错误（例如*保存失败*）会一直显示。即使同一操作的其余部分已成功，也同样适用，例如粘贴到多个单元格时。如果涉及多个任务，下方一行会说明哪些任务未更改，例如*未更改：Foundation, Masonry。*超过五个任务时，结尾为*以及另外 N 个任务*。同一拒绝操作重复出现时，会合并为一行并显示计数。同时最多显示三条。如果出现第四条，最早的信息会先消失。如果没有信息，则先移除最早的拒绝操作通知，然后是最早的固定打开通知，最后才是最早的错误。因此，信息或拒绝操作通知绝不会挤掉其他错误，例如*保存失败*。通知栈会避开已打开对话框的按钮和固定的操作栏。打开文件时，如果应用在打开过程中填充、替换、修复或忽略了数据，该通知也会一直显示，直到你点击叉号：具体包括解析器或日历发现、数字格式问题、枚举回退、使用安全回退的 P6 排程设置、保护性基线回退、已忽略的基线引用、已被赋予开始日期的没有计划开始的任务、未导入的项目间关系或不属于任何项目的任务（P6 XML）、未导入的 MS Project 内容（MS Project XML 和 `.mpp`）或无法使用的 XER 源存档，以及关于重复 ID 和未计算关系的通知。如果只包含信息，而没有此类更改（例如项目数量、文档数量或文本编码），通知会在 5 秒后消失。

- **计数 ×N** — 带固定键的通知会将重复项合并为一行并显示计数，例如反复出现的保存错误，或你重复尝试的被拒绝关系。并非每个通知都会这样做。
- **了解更多** — 某些通知有一个*了解更多*链接，或有自己的主题（例如*任务类型说明*），可链接到后台视图 › 帮助中的指南。
- **操作按钮** — 关于计算配置文件的通知有一个按钮*打开计算配置文件*，可打开项目信息。

下面的列表只是部分通知，按主题分组。除非另有说明，否则它是信息。

### 保存、打开和恢复

- **保存失败**（错误）— *保存失败*，原因显示在其下方。在保存、另存为和导出报表时出现。
- **已保存为下载**（信息）— *已保存为下载：“{name}”现在位于你的下载文件夹中。…* 与*另存为*和导出一起出现，当环境不允许应用直接写入你选择的位置时。连续两次下载会合并在一起。
- **已保存为下载（说明）**（信息，15 秒）— *已保存为下载：“{name}”位于你的下载文件夹中。此浏览器不允许应用写入自己的位置，…* 与*保存*一起出现，适用于只能通过下载来保存的浏览器。每个会话显示一次，并附有文件说明的链接。
- **浏览器无法写回**（信息，15 秒）— *此浏览器不允许应用写回“{name}”。…* 在保存已有文件的项目时出现，当浏览器必须再次请求保存位置时。每个会话显示一次，并附有文件说明的链接。
- **自动保存失败**（错误）— *自动保存失败*，附原因。适用于自动保存到文件和崩溃恢复。
- **无法保存库**（错误）— *无法保存库*，在保存资源库时出现。
- **打开文件失败**（错误）— *打开文件失败*，附原因。例如打开最近使用的文件或导入的文件时。
- **旧版或受保护的 .mpp**（错误）— *此 .mpp 文件使用较旧的格式（Project 2007 或更早版本）…* 或 *此 .mpp 文件受密码保护…*，两者都建议你在 MS Project 中导出为 XML，然后打开该文件。
- **无效的 XER 文件**（错误）— 其中一条 *XER…* 文本，例如*这不是有效或受支持的 XER 文件。*或*XER 文件包含重复的表。*，并附上原因。
- **无法读取 IFC**（错误）— *无法读取 IFC*，附原因，显示在 IFC 视图中。
- **恢复**（错误）— *无法读取恢复的文件*、*恢复失败*和*有 N 个恢复文件无法加载，已被跳过。* 在意外关机后恢复时出现。
- **分支已保存为模板**（信息）— *分支已保存为模板“{name}”*。
- **来自扩展的消息**（信息；如果扩展报告错误，则为错误）— *扩展 {name}：{message}*。扩展每 10 秒最多可显示三条新消息，因此不会填满通知栈。如果扩展引导中的某个步骤失败，会显示*扩展 {name} 的一个步骤出错。引导将继续。*；如果扩展的项目文件无法打开，会显示*无法打开扩展 {name} 的项目文件 {file}。*。两者都是错误。
- **期间发生了更改**（错误）— *AI 助手或扩展的一项更改在此期间发生。…* 当你取消任务对话框，而 AI 或扩展在此期间更改了内容时：该更改之前的任务编辑不会被还原，并仍作为普通步骤保留在*撤销*下。

### 计算

- **无法计算计划**（错误）— *无法计算计划*，下方附原因（见*计划错误的原因*）。在*计算*时、切换文档时以及打开文件时出现。
- **状态日期已设为今天**（信息）— *状态日期已设为今天（{date}）。* 在没有状态日期的项目中输入进度时出现。应用会测量截至状态日期的进度，因此没有状态日期时无法处理进度。你可以在*计划 › 基线与进度 › 状态日期*下设置其他日期。附有*了解更多*链接，指向[进度、状态日期和基线](docs://uitleg-voortgang)。
- **工期短于已完成的工作**（错误）— *“{name}”已完成 {N}%：工期不能短于已完成的工作。工期未更改。*

### 关系和层级

- **关系被拒绝**（错误）— *该关系已存在*、*不允许在任务与其自身的（上级）摘要任务之间建立关系。*或*此关系会在计划中形成循环（{cycle}），因此未创建。* 循环中会列出任务，因此你可以知道应先删除或反转哪个关系。
- **移动被拒绝**（错误）— *此移动会在计划中形成循环（{cycle}）：摘要任务的关系同样适用于其子任务。未移动任何内容。*
- **移动后关系不再计入计算**（信息）— *移动后，有 N 个关系将任务与其自身的上级摘要任务相连；这些关系不再参与计算。*
- **插入时跳过关系**（错误）— *有 N 个关系未创建：链接无效…*，粘贴或插入分支时出现。下方一行会说明哪些关系，例如*未创建：Foundation → Masonry。*
- **导入后未计入的关系**（信息）— *N 个关系未能计入计算。请检查前置任务和后续任务列。*
- **导入后重复的 ID**（信息）— *此文件中有重复 ID 的对象：N。它们已被赋予各自的 ID…*

### 编辑任务

- **开始被记录为约束**（信息）— *“{name}”不早于 {date} 开始 (SNET)。* 当你更改有前置任务的任务的开始时出现。前置任务决定开始，因此应用会将你的日期记录为*不得早于…开始*（SNET）约束。重新计算（F5）后，任务不会早于该日期开始。如果任务已有此约束，则显示*“{name}”现在不早于 {date} 开始 (SNET)。*；同时更改多个任务时，显示数量。附有*了解更多*链接，指向[约束和截止日期](docs://uitleg-constraints)。
- **开始未应用**（错误）— *“{name}”的新开始未应用：该任务有前置任务，且约束 {type} {date} 决定其开始。请更改该约束以移动开始。*
- **里程碑被拒绝**（错误）— *N 个任务有资源分配，无法变为里程碑。请先移除这些分配。*或*N 个任务是带子任务的摘要任务，无法变为里程碑。* 在任务对话框、属性面板、右键菜单和表格中转换时出现。
- **分配已移至子任务**（信息）— *分配已移至子任务“{child}”。*或*N 个分配已移至子任务“{child}”。* 当扩展为有分配的任务添加子任务时出现。该任务变为摘要任务，而摘要任务本身不带分配。因此，分配会移至第一个新子任务。在应用本身中，你会在窗口*任务变为摘要任务*中选择此选项；此时不会显示此消息。附有*了解更多*链接，指向[调整结构](docs://howto-structuur-aanpassen)。
- **里程碑标记已移除**（信息）— *N 个任务不再是里程碑。* 里程碑获得子任务时出现。里程碑是没有子任务的时间点；有子任务后，它会变为摘要任务。附有*了解更多*链接，指向[调整结构](docs://howto-structuur-aanpassen)。
- **问题已过期**（错误）— *任务或分配在问题未回答期间已更改。未做任何更改；请再试一次。* 当你在窗口*任务变为摘要任务*中做出选择，但问题已不再匹配时出现。
- **摘要任务被拒绝**（错误）— *“{phase}”不能变为摘要任务：…*，附原因，以及*未更改任何内容。* 当扩展为有分配的任务添加子任务，而分配无法移至第一个新子任务时出现。在应用本身中不会出现此消息：那里，窗口*任务变为摘要任务*会询问如何处理，此时*移动*会被禁用。
- **粘贴时跳过的单元格**（错误）— *已跳过 N 个只读单元格（例如自动编号的 WBS 代码或计算列）。*
- **粘贴时清除的引用**（信息）— *N 个引用在本文档中不存在，已被清除（来自源文档的任务日历、自定义工作类别、活动代码或自定义字段）。*
- **结构已锁定**（错误；功能区下方的红色条）— *筛选/分组/排序时不可用*，附*清除*按钮。当列表已筛选、分组或排序时：执行降级、升级和拖动时，以及使用*在上方插入*和*在下方插入*时（右键菜单或快捷键）。该条会一直显示，直到你点击叉号、使用 Ctrl+Z 或 Ctrl+Y，或切换到另一个文档。参见[调整结构](docs://howto-structuur-aanpassen)。
- **任务已添加到末尾**（错误）— *新任务已添加到末尾。在筛选、分组或排序时，应用无法将其放在你的选择下方。* 附*清除*按钮。当选中任务、列表已筛选、分组或排序时，使用*任务*和*里程碑 ▾*。任务已添加，但位于底部。*清除*会移除筛选、分组和排序，并关闭该通知。参见[添加任务和里程碑](docs://howto-taken-en-mijlpalen-toevoegen)。
- **任务类型调整了工期**（信息）— *更改日历后，任务类型调整了 N 个任务的工期（工时不变，每天的小时数已改变）。* 附*任务类型说明*链接。

### Primavera (XER)

- **XER 文件已打开**（信息）— *已打开 XER 文件：N 个项目文档。* 每个文件只显示一条通知，即使该文件打开了多个项目。附有*了解更多*链接和下方的详细行。始终显示*找到的项目：N*。仅当数字大于 0 时显示：*已跳过的空项目：N。*、*已排除的基线项目：N。*、*已具体化的基线：N。*、*已忽略的悬空基线引用：N。*、*已使用保护性基线回退。*和*已保留的外部关系：N。*仅当编码不是 UTF-8 时显示：*选定的文本编码：{encoding}。*此外，当数字大于 0 时显示：*解析器发现：N。*、*日历发现：N。*、*数字格式问题：N。*、*枚举回退：N。*和*使用安全回退的 P6 排程设置：N。*
- **按 Primavera 记录的日期显示**（同一通知中的详细行）— *显示 Primavera 记录日期（未重新计算）的任务：N 个。* N 统计文件记录了日期的每个任务，包括没有差异的任务。或者，如果该模式未开启，则显示*N 个任务的日期与文件中的日期不同，你可以显示它们。*
- **XER 源存档不可用**（信息）— *此文件中的 XER 源存档不可用，已被略去；项目本身已完整打开。* 附原因（例如*原因：校验和与源字节不符——存档已损坏。*）和后果（*计划、计算配置文件以及 IFC 中的所有项目数据均已完整。…*）。打开一个 IFC 文件时，如果其中先前保存的 XER 源存档无法使用，会出现此通知。在意外关机后恢复时，如果恢复存储中已没有源存档，也会出现。
- **导出时丢失 XER 信息**（信息）— *导出为 {format} 会丢失 XER 源信息。* 将仅存在于 XER 文件中数据的项目成功导出为 IFC 以外的格式后出现。附*了解更多*链接。
