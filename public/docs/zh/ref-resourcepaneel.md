# 资源面板

资源面板是你管理资源的地方：哪些资源可用、产能多大、使用哪个日历。Gantt 下方的直方图和过度分配也属于它。本文说明每个字段和按钮的作用、默认值，以及你会看到什么变化。如何创建和分配资源，见[管理资源](docs://howto-resources-beheren)和[用曲线分配资源](docs://howto-resource-toewijzen)；如何解决过度分配，见[解决过度分配](docs://howto-overbezetting-oplossen)。

## 在哪里找到

- **完整面板** — *资源 › 管理 › 资源* 或 *视图 › 面板 › 资源*。它会占满工作区。右上角的叉号可关闭它。
- **资源停靠栏** — *资源 › 管理 › 资源停靠栏* 或 *视图 › 面板 › 资源停靠栏*：右侧栏中、紧挨 Gantt 的紧凑列表。见下文。
- **直方图** — *资源 › 直方图 › 直方图* 或 *视图 › 面板 › 直方图*：Gantt 下方的一个条带。见下文。
- **视图** — 如果你的项目属于某个资源库，面板右上角可以在 *资源库*、*项目* 和 *占用* 之间选择。没有资源库时，只有项目表。每次打开面板，它都从 *项目* 开始。这样你不会在不知情的情况下进入共享的资源库。

## 新建资源

- **在项目中新建资源**（在 *资源库* 视图中为 *在资源库中新建资源*）— 右上角的按钮。它会在表格底部打开一个草稿行。只有输入名称并离开该行，或按 Enter，资源才会创建。如果名称为空时点击别处或按 Esc，不会留下任何内容：没有资源，也没有 *撤销* 中的步骤。你可以按任意顺序填写字段，所有内容会一次写入。按 Enter 或下箭头会确认该行，并打开新的草稿行。按 Shift+Enter 或上箭头会确认该行，并回到表格。草稿行没有产能展开箭头、日历铅笔和垃圾桶，因为这些按钮作用于尚不存在的资源。*资源 › 管理* 中的 *新建资源* 按钮效果相同。
- **表格导航** — 在表格中，Enter、Shift+Enter 以及上下箭头可在行之间移动光标。在最后一行按 Enter 会打开新的草稿行。

## 项目视图

这是本项目所用资源的表格。每一行是一个资源。文字和费率的更改在你离开字段后立即生效，并在 *撤销* 下算作一步。

- **颜色** — 颜色选择器。默认值：调色板中第一个未使用的颜色。效果：Gantt 任务条下方资源强调色的颜色（*视图 › 基线与进度 › 资源强调色*），以及停靠栏中色块的颜色。
- **名称** — 资源的名称。空名称不会保留；字段会恢复为旧名称。
- **类型** — *劳务*、*设备*、*材料*、*分包商* 或 *班组*。新资源的默认值：*劳务*。效果：*材料* 有 *单位*，且不计入直方图中 *所有资源* 的合计；资源平衡会跳过材料。可以把 *班组* 类型的资源选为其他资源的 *班组*。其他类型的计算方式相同。
- **最大单位数** — 资源每天可用的量，是一个大于 0 的数字（允许小数）。默认值：1。效果：每天的产能。如果负荷更高，资源就会过度分配。旁边的箭头会展开 *分时段产能*；箭头旁的数字是阶段的数量。
- **分时段产能** — 阶段。每个阶段包含 *起始于*（一个日期）和 *最大单位数*。*添加阶段* 会添加一个阶段，日期为今天，值为 1。没有阶段时，显示 *尚无阶段 — 始终应用固定的最大单位数。* 效果：从某个阶段的日期起，使用该阶段的 *最大单位数*，而不是固定值。对于某一天，生效的是日期不晚于这一天的最后一个阶段。
- **日历** — 一个列表，包含 *项目日历*（默认）、项目的日历，以及用于新建的 *+ 资源日历*。铅笔（*编辑*…）会打开所选日历，对 *项目日历* 不可用。效果：资源工作的日期。在非工作日，产能为 0。如果该天已安排工作，资源会过度分配，原因为 *根据日历“…”，该资源这天不工作*。资源日历不会更改任务的日期。见[日历窗口](docs://ref-kalenders)。
- **费率/小时** — 每小时的成本。留空表示没有费率；无效数字会回退到原值。效果：对计划或负荷没有影响。费率决定 *合计* 列的值，保存在 IFC 文件中，并在导出到 MS Project（标准费率）和 Primavera P6 XML（每单位价格）时一并写入。
- **合计** — 只读：负荷工时 × 费率，保留两位小数；没有费率或负荷时显示 *—*。底部的 *合计* 行汇总所有资源。工时来自上次计算，按任务日历中每天的单位数 × 小时数计算。数据过期了？请按 *计算*。
- **单位** — 材料的计量单位，例如 `m³`。只能为 *材料* 类型填写（提示文字：*仅适用于「材料」类型的资源。*）。效果：仅作标签，不参与计算。
- **班组** — 资源所属的班组，从 *班组* 类型的资源中选择。默认值：*无*。效果：仅用于分组。班组的产能和负荷不是其成员的总和。
- **删除**（垃圾桶）— 删除该资源。如果资源有分配，应用会先询问 *“…”有 … 项分配 — 是否删除？*，并提供勾号确认和叉号取消。
- **移入资源库** — 只有在项目属于某个资源库，且资源的名称尚未来自资源库时才会出现。它会把资源放入资源库，或将其关联到同名的现有项，并报告结果（*已添加。*、*资源库中已存在——现已关联。* 或 *已关联到资源库中的现有项——数值不同，请查看标记。*）。
- **取消与资源库的关联** — 来自资源库的资源上的取消关联图标。它会移除来源。之后，所有字段都可以自由编辑。

没有资源时，显示 *尚无资源。添加一个开始使用。* 如果项目属于某个资源库，则显示 *此项目尚未使用资源库中的资源。*，并附带提示。

### 来自资源库的资源

来自资源库的资源有一个小型资源库图标（*来自资源库*）。它的 *名称*、*类型*、*费率/小时* 和 *单位* 此时为纯文本（*资源库数值——请在资源库视图中编辑，或将此资源与资源库取消关联。*），因为资源库决定资源是什么。*颜色*、*最大单位数*、产能阶段、*日历* 和 *班组* 仍可编辑，因为项目决定数量和时间。可能会出现两个标记：*存在差异 — 待决定*（点击会打开 *关联资源库* 窗口），以及 *资源库中已不存在*（并带有 *从项目中移除* 按钮）。

## 资源库视图

仅当项目属于某个资源库时才可用。见[使用资源库](docs://howto-resourcebibliotheek-gebruiken)和[管理和共享资源库](docs://howto-bibliotheken-beheren)。顶部有一条彩色提示：*此操作会编辑资源库数据，适用于所有项目——不在撤销范围内。* 表格与 *项目* 视图的字段相同，但有以下差异：

- 没有 *合计* 列，因为它是针对单个项目的计算。
- 一旦资源库中有资源，*班组* 列就会显示。
- *日历* 列提供资源库的日历，默认值为 *无日历*。
- **加入项目** — 将资源加入项目，并附带其日历的副本。报告 *已添加。* 或 *已存在于项目中。*
- **删除** — 询问 *要从资源库中移除“…”吗？此操作适用于所有项目，且无法撤销。*
- 没有资源时，显示 *资源池中尚无资源。*

## 占用视图

只读视图，显示所有打开文档中，每个资源库资源分别预订在哪里。这里没有新建资源的按钮。见[使用占用概览](docs://howto-bezettingsoverzicht-gebruiken)。

- **表格** — 每个资源库资源一行：*名称*、*文档*（资源所在的文档数）、*期间* 以及 *峰值 / 产能*（当天合并负荷的最高值与产能的对比）。红色的 *N 天重复预订* 表示，资源在多个文档中的预订超过了其产能。名称旁的箭头会展开文档，每个文档显示期间和峰值。点击某一行会显示该资源的直方图（*选择一个资源以查看直方图。*）。
- **统计范围** — 只统计在本应用中打开的文档（*此概览仅显示在本应用中打开的文档。*）。未计算的文档会在其所在行显示一条消息。当前激活的文档使用其上次计算的数值（*已过期：这些是上次计算的数值 — 请在此文档中按 F5。*）。其他文档由概览提前计算（*已为此概览提前计算 — 该文档本身仍显示旧日期，直到你在其中按 F5 或开启“自动计算”。*）；如果开启了 *自动计算*，概览会真正计算这些文档。如果计算失败，该文档不计入（*不计入：计划未计算 — 请激活此文档并按 F5。*）。没有预订资源时，显示 *打开的文档中没有预订资源库中的资源。*
- **排序** — 有重复预订的资源排在顶部，冲突天数最多的排在最前，然后按字母顺序排列。

## 资源停靠栏

右侧栏中的紧凑列表，位于 *属性* 面板旁边。每个资源显示：一个颜色块、名称（只读）、只要资源至少有一天过度分配，就会出现的红色三角 *过度分配*，以及可编辑的 *最大单位数*。如果选中了任务，则只列出这些任务的资源。标题栏中有 *完整面板*（打开完整面板）和 *关闭停靠*。没有资源时，显示 *尚无资源。添加一个开始使用。*

## 直方图

Gantt 下方的一个条带，按天显示资源的负荷。使用 *资源 › 直方图 › 直方图* 或 *视图 › 面板 › 直方图* 打开或关闭它。默认值：关闭；你的选择会被记住。默认高度为 160 像素，可以在 Gantt 与直方图之间的边缘拖动。

- **选择器** — 位于左侧、任务表下方的是一个列表：*所有资源* 固定在顶部，其下每个资源一行。点击某一行即可选择，方向键可在行之间移动。*资源 › 直方图 › 上一个* 和 *下一个* 的作用相同。行旁的红点表示该资源至少有一天过度分配；对于 *所有资源*，红点只检查非材料的资源。如果选中了任务，列表只包含这些任务的资源。如果你选择的资源不在其中，条带会暂时显示所选任务的 *所有资源*。
- **柱** — 每天一根柱：以单位表示的负荷。一条线表示产能；柱体中超过产能的部分为红色。左上角是最高值，单位为 *单位*。*所有资源* 会合计所有资源（材料除外）的负荷和产能。
- **提示框** — 将鼠标在某一天上停留片刻：*N 个任务在 {date} 有负荷*，并列出最多八个任务的名称。对于选中的资源，如果其日历在某天不工作，还会显示 *根据日历“…”，该资源这天不工作*。
- **条带中的消息** — 没有负荷时显示 *重新计算 (F5) 以显示负荷*，没有资源时显示 *尚无资源*。计划过期时，右上角显示 *⚠ 计划已过期 — 重新计算 (F5)*。
- **统计范围** — 每项分配每天的单位数，按 *曲线*（或 *工时分布*）分布到任务的工作日上；只计算末级任务，不计算里程碑。负荷会在 *计算* 之后，以及资源和分配有变更后刷新。如果你更改任务的日期，只有在 *计算* 之后才会计入。

## 过度分配

资源在某一天过度分配，是指其负荷高于其产能。产能在其日历的工作日为 *最大单位数*（含产能阶段），在非工作日为 0。在这里会计入材料。原因是产能不足，或资源按其日历在该天不工作。

你可以在以下位置看到它：

- **资源 › 过度分配** — 过度分配资源的数量，或 *无*。
- **状态栏** — *N 个资源过度分配*；点击会打开 *警告* 面板。
- **警告** — 每个资源一行，显示 *N 天过度分配（首日 – 末日）*。如果所有日期都是非工作日，则附加 *该资源按其日历在这些天不工作*；如果是混合情况，则为 *其中 N 天该资源按其日历不工作*。见[通知和警告](docs://ref-meldingen)。
- **直方图** — 柱中的红色部分，以及选择器中的红点。
- **停靠栏** — *过度分配* 三角形。

资源平衡可以通过让任务晚一些开始来解决过度分配。默认情况下，项目完成日期可能会移动；使用资源平衡的平滑模式时，它保持在浮时范围内。资源平衡无法解决必须在非工作日工作的资源。见[资源平衡](docs://uitleg-nivelleren)。
